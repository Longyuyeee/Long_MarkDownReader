# UX-48 顶部命令条文字溢出审计

## 问题

`测试结果记录.table.json` 的顶部按钮与筛选、冻结列控件共享一个 flex 容器。空间不足时按钮会参与压缩，但文字保持单行，造成“导出 CSV”“导出 XLSX”等文字越过按钮边界。窄窗口规则还会直接隐藏导出、增行、增列等命令，虽然避免拥挤，却让功能不可到达。

## 修复

- 新增统一 `data-command-strip` 布局合同：直接子控件不压缩，按钮、标签和菜单标题保持单行，空间不足时命令条横向滚动，并隐藏原生滚动条。
- Table 工具按钮使用内容宽度下限，图标按钮保持 32px 稳定尺寸；删除窄窗口直接隐藏命令的规则。
- Table、Workbook、Canvas、思维导图、Mermaid、PDF、PPTX、DOCX、ODT、日志和 YAML 共 11 个工作区接入同一合同。
- 命令条沿用全局滚轮横滑能力，鼠标停在工具栏时可用纵向滚轮浏览左右命令。

## 验收

运行 `node scripts/check-command-strip-layout.mjs` 与生产构建。安装态复测应覆盖默认宽度、约 900px 内容区和窄窗口，确认文字不穿出按钮、所有命令可横向到达、没有原生滚动条。
