# v1.0.26 发布说明

本版聚焦资料库搜索与参考阅读，减少“打开”和“参考”的混淆。

- 点击搜索结果，直接在主编辑区打开。
- 需要对照资料时，使用独立的“在侧边参考”；不再先预览再固定。
- 参考明确标为只读，支持在主编辑区打开或关闭；选文后可复制摘录及来源。
- 搜索结果支持上下键导航；窄窗参考上下排列，返回编辑后可继续输入。
- 修复返回编辑时焦点落回搜索按钮的问题，保留未保存草稿与显式保存原则。
- 选中参考文字可直接插入当前可编辑 Markdown 笔记，明确目标和插入位置，支持撤销/重做。
- 文本摘录携带来源查找锚点；参考支持手动刷新，失效来源可在确认新相对路径后重新关联，不自动保存。

参考显示磁盘上的有界内容，不是实时草稿镜像；直插仅面向 Markdown，其他编辑器使用复制方式。不包含多参考栏、跨重启恢复或全库自动跟踪重命名。来源文本改写后可能无法定位，会提示重新查找。

## 怎么使用

1. 在资料库搜索，点击结果即可在主编辑区打开。
2. 要一边写一边看资料，点击结果上的“在侧边参考”，再切回自己的 Markdown 笔记。
3. 在参考中选中文字，插入当前笔记；也可以复制选中文字及来源。插入后仍由你决定何时保存，支持撤销。
4. 点击笔记中的来源链接回到资料；文件已移动时，按提示重新关联到资料库内的新相对路径。资料内容更新后可手动刷新参考。

## 安装与边界

Windows 10/11 x64；提供 NSIS 和 MSI 社区安装包。本版没有 Authenticode 商业签名，可能出现“未知发布者”或 SmartScreen 提示；仅从官方 GitHub Release 下载并核对 SHA-256。

官方应用内自动更新观察需在发布后独立执行；覆盖安装验收不能替代它。自动更新不可用时可手动下载安装。
