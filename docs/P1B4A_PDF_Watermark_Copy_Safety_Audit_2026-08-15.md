# P1-B4A PDF 文字水印副本安全审计

审计日期：2026-08-15
阶段结论：**水印可靠副本的安全子集和验证合同已冻结；当前仍未开放水印写入。**

## 1. 需求对齐与结论

用户的基础目标是让管理器覆盖日常管理和基础编辑，并始终保持“左侧资料库 + 右侧编辑区”。文字水印属于常用 PDF 基础编辑，但不能为增加功能而破坏正文、表单、链接、批注或原工作区结构。本阶段只冻结后端与 UI 必须遵守的合同，不新增按钮、命令、路由或写入能力。

水印与 P1-B3 永久脱敏含义相反。脱敏必须移除源内容，因此采用全页栅格重建；水印需要保留可搜索正文和交互结构，因此采用源文档完整克隆、全量重写新副本并追加隔离矢量文字流。水印只是可见归属标记，不是脱敏、DRM、访问控制或防复制措施。

## 2. 威胁模型与风险

- **签名与认证失效**：任何新增内容都会破坏数字签名或认证语义，因此检测到签名、`/Perms` 或加密时强制阻断。
- **页面几何错误**：`MediaBox`、`CropBox`、`Rotate` 和 `UserUnit` 可能继承；只看页对象本身会导致水印偏移、裁切或旋转错误。
- **资源污染**：页面可能共享父级 `/Resources`。原地写入共享字典会污染其他页面，固定 `/F1` 或 `/GS1` 又可能覆盖源资源。
- **内容流污染**：缺失 `q/Q` 或直接拼接到原流会泄漏透明度、矩阵、颜色和字体状态；注解水印或可选图层又可被轻易隐藏。
- **字体与文字注入**：引用系统字体不可移植；直接插入 PDF 字面量会受到括号、反斜杠、控制字符和编码影响。
- **格式承诺漂移**：透明度、字体嵌入和新增内容可能影响 PDF/A；新增内容也不能继续声称原数字签名有效。
- **错误安全宣传**：水印可被专业工具移除，且水印文字会进入搜索和文本提取，界面必须明确披露。

## 3. 批准架构与首个安全子集

唯一批准路线是使用 lopdf 完整加载源文档，验证源 SHA-256、页树、签名/加密与资源预算，然后克隆整份文档并以非增量方式重写到新字节。每页解析继承后的 CropBox/MediaBox 和四分之一圈旋转，在裁切框视觉中心追加一条最后绘制的内容流。

追加流必须使用 `q`/`Q` 隔离图形状态，并以 `/Artifact <</Subtype /Watermark>> BDC` 与 `EMC` 标记为非正文语义装饰。字体和透明度资源名必须同时扫描本页及继承资源后分配私有唯一名称；本页得到独立资源字典，不得修改共享父字典。文字使用 Noto Sans CJK SC 2.004 的许可字形子集、Type0/CIDFont、Identity-H 和 ToUnicode，以十六进制 CID 串写入，不能引用未嵌入系统字体。

P1-B4B 首批只允许：资料库内 1～512 页、128 MB 以内、全部页面、1～64 个 Unicode 标量、单行居中斜向水印、18～72 pt 自动适配、-60°～60°角度、0.08～0.5 不透明度和受限灰度。控制字符、双向覆盖符、复杂塑形、彩色 Emoji、竖排文字、平铺、图片水印、页眉页脚水印和逐页不同内容暂不支持。

## 4. 冻结的保存与保真合同

- 仅生成同资料库、同目录的新 PDF；源文件和已有目标永不覆盖。
- 预验证绑定源摘要与输出摘要；保存必须复用同一参数并生成逐字节一致的输出。
- 输出必须是完整重写，Trailer 不得保留 `/Prev` 增量链。
- 页数、顺序、MediaBox、CropBox、Rotate，以及原内容流、字体、图片、表单、链接、批注、目录、附件、标签和元数据清单必须保持。
- 每页必须恰好追加一条平衡且资源可解析的私有水印流，源内容流不得改写。
- 保存后重新打开目标，复核结构、摘要、源不变和目标新建；任一门禁失败都不得报告成功。
- PDF/A、加密、签名/认证、非四分之一圈旋转、异常 UserUnit、页框或资源解析失败均阻断，不做静默降级。

## 5. 验证计划

自动样本至少覆盖：继承 MediaBox/CropBox/Rotate/Resources、共享资源字典、已有同名字体/ExtGState、直接与数组 Contents、表单 Widget、链接批注、目录、附件、元数据、Unicode 中文、括号和反斜杠、签名、加密、PDF/A 标记、异常页框、异常旋转、源摘要冲突、已有目标和资源预算。

后端结构复读必须证明每页水印流、私有字体与 ExtGState 可解析，水印文字逐页提取为期望 Unicode，原结构清单一致。真实桌面阶段使用 Poppler 独立渲染源/目标：水印在裁切框内可见且不裁切，非水印区域保持视觉稳定；同时在宽屏和窄屏完成预览、取舍说明、可靠另存、自动打开和草稿离开保护。

## 6. 后续实施顺序

1. P1-B4A（本阶段）：安全合同、边界、阻断项和验证计划完成；`currentWriteCapability=false`。
2. P1-B4B：实现隔离矢量文字水印后端、预验证、可靠新副本与攻击面测试，仍不增加 UI。
3. P1-B4C：只在原 `PdfView` 右侧加入水印面板，复用现有字号、状态组件和保存流程。
4. P1-B4D：真实 Tauri 宽窄屏、目标复开、Poppler 独立渲染和结构保真证据通过后，才登记 `watermark-copy` 为当前能力。

P1-B4 全部收口后再进入 P1-B5 元数据副本。图片水印、平铺模板和逐页差异属于后续增强，不能阻塞首个日常文字水印子集，也不能在没有独立证据时提前宣传。
