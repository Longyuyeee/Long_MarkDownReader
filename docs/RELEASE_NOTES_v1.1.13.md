# Long编辑 v1.1.13 · PDF 阅读成果变成可追溯笔记

在现有 PDF 工作面深化批注整理和笔记写作，不新增另一套阅读器。

- 批注可按摘录/评论关键词、页码、类型和颜色筛选，多选后按页码或颜色整理；每组列表 50 条，每次最多 200 条，隐藏选择数量明确显示，不静默截断。
- 按需打开笔记预览，保留实际页码、摘录、可选评论和来源链接。保留单条复制、插入、评论、颜色和删除，以及原有 PDF 工具。
- 修复插入批注直接代存 Markdown 的问题。现在只追加到明确选择的最新草稿，保留未保存正文、保存身份和冲突保护，仍由用户显式保存。
- 插入目标同时显示文件名和所属文件夹，区分重名笔记；异步期间目标关闭、改名、切换或批注更新时不误插入，只读目标保持保护。
- 新笔记由用户选择资料库内的新 `.md` 名称后保存，取消/失败保留预览，禁止覆盖已有文件或原 PDF。
- 新来源链接包含流式 SHA-256，返回时先核对内容；同名替换不错误定位，批注删除/页码失效明确告知。原 PDF 移动后可验证新相对路径、只重新关联草稿；旧链接兼容但提示未经内容摘要校验。
- 保留六种界面风格、深浅主题、正常动效与窄短窗口底部操作，不删除阅读、搜索、表单、OCR、脱敏、水印、文档属性或页面整理能力。

## 使用与边界

在 PDF 侧栏“批注”中筛选、勾选后点击“整理为笔记”，核对预览，再插入已打开的 Markdown 草稿或新建并保存笔记。来源缺失或变化时先核对原文件，不自动搜索同名文件猜测，不代存当前正文。

每次所选摘录与评论最多 4 MiB，笔记保存最多 8 MiB；PDF 阅读仍沿原 2 GiB 上限。摘要校验需要读取整份 PDF，大文件需要等待。OCR 本版沿用已有本地离线能力，不宣称识别效果新增提升。

Windows x64 未签名社区版（community-unsigned），系统可能提示未知发布者；企业 releaseCandidate=false。正式公开后可手动下载安装；本版应用内更新观测与整包安装验收独立记录，不借用旧版更新成功。

固定原安装包已完成独立同包验收，保留原 PDF、批注和未选文件摘要。实际安装、运行与发布证据见[发布审计](https://github.com/Longyuyeee/Long_MarkDownReader/blob/main/docs/V1_1_13_Unsigned_Community_Release_Audit_2026-10-18.md)，操作见[PDF 阅读笔记用法](https://github.com/Longyuyeee/Long_MarkDownReader/blob/main/docs/PDF_Reading_Notes_User_Guide.md)。下载安装后请核对同页 SHA256SUMS.txt。
