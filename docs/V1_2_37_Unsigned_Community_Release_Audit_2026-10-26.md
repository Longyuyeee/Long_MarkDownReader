# v1.2.37：TOML 多行正文编辑

当前开发目标：`1.2.37`；当前运行时版本：`1.2.37`；当前公开版本：`1.2.36`。当前阶段：**v1.2.37 TOML 多行正文编辑候选**。

## 用户变化

TOML 三双引号 `"""` 字段沿右键“修改值…”直接编辑可读正文，预填解析后的引号、反斜杠、Unicode、换行与接续行。用户输入作为文字处理，自动转义分隔符和反斜杠，保留多行基本字符串形式；无变化时精确保留原有转义拼写与物理折行。

只替换解析器确认的目标范围，保留其他字段、注释、BOM、原换行格式以及开启换行形式。嵌套、点号键、引号键和表数组字段沿既有入口处理；数组内多行字符串仍沿数组项原始值编辑，内联表等复杂结构保留源码入口。原有三单引号、日期与普通值操作继续可用。

复用现有弹窗与差异，应用只改草稿，一次撤销／重做，显式保存才写盘。预填失败时禁用空白输入与预览，重试成功后再编辑，避免覆盖后续输入；继续保护迟到结果、后续输入、旧差异、文件切换、保存失败重试和外部冲突完整副本。保留全部功能、风格与正常动效，不新增页面、常驻表单或介绍。
