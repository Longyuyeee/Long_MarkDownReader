- 顶部标签与全软件标题提示层统一。
- WebView 默认右键菜单按编辑语义收敛，专用菜单保持可用。
- 原生确认、提示和输入迁移到应用内对话框。
- 资料库长格式菜单的滚动、层级、透明度与窄屏边界修复。
- 应用内更新进度反馈和设置页交互细节修复。

## 已满足的发布前置

- v1.0.15 交互治理真实 Tauri 七图验收通过，运行时错误 0。
- v1.0.13 → v1.0.14 官方托管更新生命周期 12/12 通过，用户确认、SHA-256、自动重启和资料保留均已验证。
- 软件仍保持原始左侧资料库/功能入口、顶部标签和右侧阅读编辑区结构。

## 待执行发布门禁

1. 统一 `1.0.15` package、Cargo、Tauri 与能力事实源。
2. 通过完整补丁 Quality Gate 与生产依赖审计。
3. 构建无签名 NSIS 与 MSI，记录大小、SHA-256 和 `NotSigned` 状态。
4. 在 GitHub 托管 Windows 中完成当前候选的安装生命周期与安装后工作区检查。
5. 发布 GitHub Release，上传 NSIS、MSI 与 `SHA256SUMS.txt`，再从远端下载核对。

## 当前边界

- 候选不等于已发布；当前公开稳定版在 v1.0.15 Release 完成前仍为 v1.0.14。
- 社区安装包无 Authenticode 商业签名，Windows 可能显示未知发布者或 SmartScreen。
- 用户可手动下载安装，自动更新也必须先确认并通过 SHA-256 校验。
