# A0E 搜索与关联自动准备审计

日期：2026-08-04
范围：UX-07
状态：代码完成，待安装版复测

## 本步完成

- 首次选择资料库或检测到内容变化时，资料库页与工作台会在后台自动准备本地搜索和文件关系缓存，不再要求用户理解或手动“构建索引”。
- 状态统一为“搜索与关联：准备中 / 正在准备 / 可用 / 需要更新 / 需要处理”，并补充不会修改资料库文件的简短说明。
- “重新准备”“隔离损坏缓存”“清除本地搜索缓存”移入更多菜单；清除和隔离使用应用内确认框，并明确操作只影响 LongEdit 本机缓存。
- 处理快速切换资料库的竞态：前一个后台任务结束后，会继续检查并准备当前资料库。
- 保留后端安全边界：删除命令只删除应用缓存根目录下当前资料库对应的索引目录，不删除或改写源文件。

## 机器审计

- 新增 `check:index-auto-preparation-experience`，锁定自动触发、用户文案、更多菜单、确认说明及后端缓存删除边界。
- 更新 R3 数据韧性检查与 JSON 桌面证据脚本，使其与自动准备交互一致。

## 安装版复测

1. 首次选择测试资料库，确认无需点击按钮即可从“准备中”变为“可用”，期间文件仍可打开和编辑。
2. 修改或新增受支持文件，确认状态可自动更新，搜索结果最终包含新内容。
3. 从更多菜单分别执行重新准备、清除缓存和损坏缓存恢复，确认对话框正常且资料库文件字节不变。
4. 后台准备期间快速切换两个资料库，确认最终活动资料库也能进入“可用”。

安装版复测通过前，UX-07 只标记为“待复测”，不宣称已验收。
