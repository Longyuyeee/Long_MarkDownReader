# Long编辑 v1.0.11

v1.0.11 是 P1 有界格式编辑与知识工作台收口版本，重点补强图片和 PDF 的日常基础编辑，并把所有能力重新对齐到原有“左侧资料库 + 右侧编辑区”。

## 主要变化

- PNG、JPEG、WebP、BMP 在原媒体工作区支持旋转、翻转、精确裁剪、缩放、格式转换、JPEG 质量控制、EXIF 方向归一和隐私元数据清理，始终可靠另存新副本。
- PDF 原工作区新增标准 AcroForm 安全子集：中文单行文本、复选框、单选组和有界单选 Choice 均使用摘要锁定的新副本保存与复读验证。
- PDF 新增永久脱敏图片型副本、矢量中文文字水印，以及标题/作者/主题/关键词四字段文档属性可靠副本。
- 文档属性明确不是完整匿名化；永久脱敏明确会把目标转成图片型 PDF；文字水印明确不是 DRM 或内容保护。
- 43 类格式、91 个扩展名按直接编辑、有界可靠副本、预览或外部依赖三层完成发布事实收口。
- 知识图谱继续承担资料库派生关系探索；Canvas、OPML、Mermaid 和 Draw.io 承担思维导图与图形源编辑，两类能力不再混写。

## 安装与更新

- v1.0.10 用户可在 v1.0.11 发布后通过应用内检查更新；安装前仍需用户确认，并严格核对官方 NSIS 的大小与 SHA-256。
- 社区安装包仍为 `NotSigned`，Windows 可能显示未知发布者或 SmartScreen。只应从官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。
- 不发布旧 Tauri 更新器的 `latest.json` 或 `.sig`；更新信任继续来自固定 GitHub Release、严格附件名和 SHA-256。

## 能力边界

- PDF 不是任意正文排版编辑器；签名、加密、PDF/A 和不满足安全合同的结构保持阻断，源文件永不静默覆盖。
- DOCX、PPTX、XLSX 是有界基础编辑，不等价于完整 Word、PowerPoint 或 Excel；WPS 原生格式继续依赖外部 WPS。
- 知识图谱不是自由思维导图源编辑器；真实用户资料库上的推荐质量仍需用户授权后的长期观察。
- 本版本不包含 Authenticode 企业签名、宏执行、外部数据刷新或云协作。
