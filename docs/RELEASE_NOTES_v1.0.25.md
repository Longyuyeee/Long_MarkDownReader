# Long编辑 v1.0.25 — 搜索与参考阅读

## 新增与改进

- 搜索摘要展示命中附近文字并高亮关键词；同文件结果分组，PDF 页码、批注和对象结果可分别打开。
- Markdown、普通文本及 PDF 支持只读文字预览，不离开正在编辑的笔记即可判断资料是否相关。
- Markdown / 普通文本正文结果打开后定位关键词，支持上一处、下一处、位置计数和首尾循环；长段落定位到关键词所在行。
- 返回搜索时恢复关键词、筛选、选中项和列表位置。
- 预览可固定为参考，切换笔记或搜索时仍保留；窄窗口采用上下布局。
- 选中文字可复制摘录和来源链接；PDF 来源保留页码及已有批注位置。
- 修复切回 Markdown 草稿后未保存标记被错误清除的问题；编辑时不逐键扫描全文更新匹配计数。

## 使用方法与范围

搜索结果 → 预览内容 → 固定为参考 → 选择文字 → 复制选中文字及来源 → 粘贴到笔记。

参考展示磁盘上的部分文字，不能代替全文阅读；PDF 不是原页排版。全文通过“打开文件”查看。搜索结果限量展示，不代表全文所有匹配次数；文内导航按当前编辑模式或已加载内容计数。返回状态和固定参考不跨重启保存。来源采用库内路径，文件改名或移动后暂不自动修复链接；摘录暂不直接插入笔记。

## 安装与更新

适用于 Windows 10/11 x64。提供 NSIS EXE、MSI 和 SHA256SUMS.txt；自动更新沿用应用内下载与 SHA-256 校验流程。社区安装包未作 Authenticode 签名，可能显示“未知发布者”。请从官方 GitHub Release 下载。v1.0.4 用户仍需手动安装一次支持更新的新版本。
