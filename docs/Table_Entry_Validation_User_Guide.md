# Table 录入规则与纠错

在 `.table.json` 的列标题上右键，选择“录入规则…”。可以设置必填、整数或数值范围、真实日期、文本长度和允许的选项。设置后列旁出现“规则”入口，单元格会提示不符合规则的原因；原值不会自动转换或删除，输入中间状态也可以继续保留。

从表格上方“数据操作”打开“检查数据…”。有筛选时可只检查筛选结果，检查对象是符合筛选的所有记录，不只屏幕里显示的行。问题列表可定位原行，也可在弹窗中修改单项；“批量修正…”先查看前后值和影响数量，再应用到草稿。排序后仍按记录身份修改，筛选之外的行保持原样。

取消预览不修改内容；应用后可以一次撤销、重做，其他未保存输入保留。点击“保存”才写入文件。核对期间切换文档或改变草稿，需要重新检查，旧预览不会应用到新内容。

CSV/TSV 的规则只在当前打开的表格内临时使用，不写进 CSV 文件，也不单独使文件变为未保存。通过既有“创建 Table 副本”可以把规则和已保存数据一起保留；有数据草稿时先沿用现有保存提示，不多加操作。原文件仍保留。

带规则的 Table 使用 schemaVersion 2；没有规则的旧 Table 继续兼容 schemaVersion 1。旧版本软件不能编辑新版规则表格，以免保存时丢失规则。数值比较不经过浮点转换，前导零与长编号保留为原文本。日期采用 YYYY-MM-DD；选项为逐行的固定文本。

一次检查最多核对 100 万个有规则的单元格、列出 5000 个问题，超过时会明确提示分批处理，不把截断结果当成完整结果批量修改。修正历史受现有事务预算限制。跨单元格公式、关联字段规则和完整电子表格校验不在本版范围。

XLSX 已有固定列表校验继续使用原入口。本版同时统一直接输入、粘贴、填充与清空的拒绝规则：非法批量输入整体不应用；合法粘贴仍可一次撤销。单元格引用或公式来源的列表继续保留，不声称已计算这些规则。
