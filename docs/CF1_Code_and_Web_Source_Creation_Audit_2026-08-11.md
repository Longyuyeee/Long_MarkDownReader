# CF-1 代码与 Web 源文件新建审计

状态：**实现与自动化验收完成，隔离桌面证据待采集**

## 需求对齐

- 文件区“新建”继续使用现有文档、数据、图表与画布、代码与配置四组，不增加第二套文件管理器；代码与配置内部再按编程语言、Web 与查询、配置文件分层，避免小窗口长菜单挤压。
- JavaScript、TypeScript、Python、Rust、Go、Java/Kotlin、C/C++/C#、Shell/PowerShell、SQL 与 HTML/CSS/Vue 十个既有编辑格式族补齐主动创建能力。
- 多后缀格式按真实扩展名提供受控变体，共覆盖 32 个已注册后缀；菜单会显示格式名和后缀，不让用户猜测生成结果。
- 创建后进入既有专业源码编辑器，内容只保存在当前草稿；后续修改仍只有点击保存才写入源文件。

## 安全边界

- 前后端共同消费 `shared/file-formats.json`，后端只接受当前格式族注册的扩展名，`.exe` 等未注册请求会被拒绝。
- 创建目标必须通过 `WorkspaceGuard`，最终落盘使用 `write_new_bytes`；同名时生成稳定编号，绝不覆盖已有文件。
- 模板只生成文本，不编译、不运行、不调试，也不会连接数据库、请求网络或加载外部资源。
- 本阶段不改变外部打开关联、默认应用、索引安全边界或 v1.0.7 已发布事实。
