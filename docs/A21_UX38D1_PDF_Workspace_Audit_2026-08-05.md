# UX-38D1 PDF 工作区审计

## 结论

UX-38D1 已完成，PDF 从通用既有能力档案升级为独立验收档案。真实 Tauri Debug WebView2 已验证 PDF 打开、渲染、缩放、窄工作区布局，以及从知识图谱返回后的页码、双向滚动、缩放和侧栏上下文恢复。

本阶段不扩大 PDF 正文能力：原文保持只读，批注、OCR 与引用继续写入 sidecar；页面提取、合并和插入继续只生成可靠新副本。编辑和保存维度因此保持 partial，不宣称 PDF 正文等价编辑。

## 产品变更

- PDF 工作区按文件记忆精确滚动位置、当前页、缩放、适合宽度状态及侧栏状态。
- 从知识图谱返回 PDF 时恢复上述上下文，路由显式指定页码时仍以路由目标为准。
- 工具栏按实际工作区容器宽度响应，而不是只看主窗口宽度。
- 窄工作区的五个 PDF 侧栏标签改为两行紧凑布局，禁止逐字断行。
