# D1C 键盘焦点与关键流程可访问性审计

审计日期：2026-07-31

对应版本：0.7.0

## 结论

D1C 已完成高频编辑工作面的键盘焦点、控件名称和模式状态收口。D1A～D1C 至此完成统一体验阶段，但该结论不等同于完整 WCAG 认证。

## 本轮完成

| 工作面 | 修正内容 |
| --- | --- |
| JSON | 源码/树形视图向辅助技术暴露当前选中状态 |
| Table | 视图删除从嵌套的不可聚焦元素改为独立按钮；视图、冻结和清除筛选都有稳定名称或状态；标签布局保持可滚动 |
| Diagram | 结构、导出、节点/连线模式暴露选中状态；导出浮层具有明确对话框名称 |
| Canvas | 选择、连线和吸附状态可识别；缩放与恢复视图按钮具有稳定名称 |
| Workbook | 公式/结果模式暴露当前状态 |
| PDF | 翻页、颜色和关闭高亮按钮具有名称；侧栏采用 tablist/tab 语义；适宽、OCR、页面整理和区域批注暴露切换状态 |
| DOCX | 基础编辑面板暴露展开状态 |
| PPTX | 放映层可聚焦且有名称；Tab 焦点限制在放映控制内；Esc、方向键和空格只响应一次；关闭后焦点返回“放映”按钮 |

## 机器合同

新增 `npm.cmd run check:d1c-accessibility-contract`，并接入 `check:format-contract`。合同防止以下关键行为回退：

- Table 视图删除重新变成不可聚焦元素；
- PDF 翻页、颜色和侧栏语义丢失；
- JSON、Diagram、Canvas 的模式状态不再暴露；
- PPTX 放映层失去焦点接管、Tab 约束或焦点返回。

## 验证

- `npm.cmd run build`：通过；`vue-tsc --noEmit` 通过，Vite 转换 6172 个模块。
- `npm.cmd run check:d1c-accessibility-contract`：通过。
- 提交前继续执行当前开发审计、数据韧性、外部签名 fail-closed 和安全 Tauri 运行时合同。

## 阶段判断

D1 统一体验阶段已收口。项目仍未声明完整 WCAG 2.x 合规，屏幕阅读器组合、系统高对比模式和生产桌面环境的专项认证可在未来独立进行。

下一步进入 D2 跨格式安全降级回归：围绕只读、另存副本、sidecar、外部打开、源文件冲突和失败恢复建立统一测试矩阵，优先验证高风险格式不会因界面状态或跨路由切换而越过既定能力边界。
