# v1.1.27：标签整理与集合复用

文内标签右键、详情操作菜单可直接打开整理弹窗，选择已加载笔记后预览改名/合并、添加或移除。管理标签保持独立，未保存笔记与外部修改继续受保护，原始正文保留在历史中。

集合管理菜单新增条件导入、导出；单个集合也可从菜单导出。只复用名称和查找条件，不复制或移动文件，不携带资料库绝对路径与机器身份。支持普通搜索、筛选集合及现有图谱中心条件。

导入时可选择目标资料库，调整同名集合名称、目录、标签、文件类型、修改时间或图谱中心。失效条件逐项提示，可修改或取消勾选；保留原集合，取消不写配置，不自动切库。保存失败保留预览；新条件读入失败会保留原预览与错误并停用旧确认，导入不会清除文档草稿或未完成的集合设置。

Windows 社区安装包未签名，请从本 Release 下载并核对 SHA256SUMS.txt。MSI 提供构建与摘要核对，完整安装生命周期以 NSIS 为准。26→27 应用内更新观察独立待补，可手动下载安装。
