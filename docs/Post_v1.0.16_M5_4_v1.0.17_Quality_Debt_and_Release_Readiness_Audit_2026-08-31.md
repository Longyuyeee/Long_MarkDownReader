## 1. 开发目标与需求对齐

M5-4 不扩展产品范围，只处理 M5-3 明确记录的版本收口债务：两个 Workbook 复读失败、一个 PPTX 注册表断言漂移，以及一个知识索引全套并发不稳定。修正后必须用相同真实文件和全仓并发环境复测，不能通过删除断言或降低发布门获得表面通过。

| 项目 | 预期 | 修正前实际 | 根因与修正 | 修正后实际 |

质量债与源码发布门已经满足，因此 `1.0.17` 具备进入候选打包的条件。但当前二进制、Cargo、Tauri 和 npm 版本仍是 `1.0.16`，尚未生成 `1.0.17` MSI/NSIS，也未执行安装、升级、卸载生命周期；因此本阶段不能宣称安装包或 GitHub Release 已完成。
