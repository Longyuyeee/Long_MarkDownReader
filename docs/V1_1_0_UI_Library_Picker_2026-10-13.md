# 顶部资料库直接切换

按用户指定交互修改：顶部资料库名称不再直接跳设置，而是展开所有已配置资料库，当前项显示勾选且不可重复切换；路径通过悬停提示区分同名库，底部保留“管理资料库…”入口。

复用 store.updateConfig 的持久化和标签恢复流程。切换前同步 Vditor 尚未完成防抖的输入；存在任意脏标签则提示先保存，不自动代存、不丢弃。配置写入期间短暂禁止当前资料库界面交互，避免旧路径继续输入；失败恢复交互并保留原库及标签。

验证：`scripts/test-library-picker.mjs` 通过。实际 Vue 页面检查列表、脏文档拦截、配置失败保留与重试、直接切换、返回恢复标签、480px 窄屏。宽窄截图已查看，证据在 `docs/evidence/v110-library-picker/`。测试模拟原生 IPC，不冒充原生磁盘验收。`npm run build` 通过。未提升版本或发版。
