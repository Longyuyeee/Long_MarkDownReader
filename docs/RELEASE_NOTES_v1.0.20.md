# Long编辑 v1.0.20

v1.0.20 聚焦知识图谱在真实大型资料库中的可用性、性能和视觉层级，不扩大源文件写回范围。

## 主要变化

- 修复分数缩放下画布 backing store 反复调整造成的缩放闪烁。
- 拖动画布和节点使用 pointer capture；单击只选择，双击才打开，避免“点一下就进去”。
- 540 个孤立节点不再形成整屏社区大圆与重复文字；图例和筛选不会再在左上角重叠。
- 连接图增加视口裁剪和常量时间选中查找；180 节点/540 连接实测 Canvas draw 峰值由 7.1 ms 降至 5.1 ms。
- 普通进入默认零选择，不再自动弹出详情；状态环最多显示 24 个重点节点。
- 节点采用克制的语义色与微光，移除重复字母徽标；近景尺寸、恒定字号和标签碰撞规避提升密集图可读性。
- 顶部工具收敛为“图谱工具”，集中最短路径、节点比较、知识治理、导出、重排、撤销/重做、缩放、适配和全屏。

## 交互提示

- 拖动空白处移动画布，滚轮缩放。
- 单击节点查看选择状态，双击节点打开内容。
- 大图先使用“看全图”，再缩放或从缩略图定位；路径、比较和导出在“图谱工具”中。

## 安全与兼容性

支持 Windows 10/11 x64。社区安装包未使用 Authenticode 商业证书，Windows 可能显示“未知发布者”或 SmartScreen 提示；请仅从官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。应用内自动更新仍要求用户确认，并在安装前校验官方 NSIS 大小和 SHA-256。
