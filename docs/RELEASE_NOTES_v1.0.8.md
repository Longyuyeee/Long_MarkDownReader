# Long编辑 v1.0.8

v1.0.8 是代码文件创建、自动更新重启和外部文件独立窗口补丁。它保留 v1.0.7 的 XLSX 类型编辑、知识索引、格式能力和主题范围，不扩大宏执行或完整 Office 等价承诺。

## 主要变化

- 新建菜单新增 10 个代码与 Web 格式族，共覆盖 32 个注册后缀；后端使用注册表白名单、原子创建和重名不覆盖保护。
- 新文件先形成内存草稿，只有点击保存或按 `Ctrl+S` 才写入正文；关闭重开和重复创建均有真实桌面证据。
- 外部文件改用独立 `external-*` 顶层窗口。已有主资料库保持原路由，不会被新文件替换，也不会把外部文件追加成软件内标签。
- 37 类允许外部打开的编辑/预览格式全部经过统一路由测试；导入转换格式不会获得直接外部窗口权限。
- 外部窗口保留对应格式的完整工作区、撤销/重做、显式保存或只读边界，并隐藏资料库标签栏和主窗口更新提示。
- 自动更新助手隐藏运行，等待 NSIS 安装完成、校验退出码并重启当前 Long编辑可执行文件；更新弹窗明确告知安装后会自动重新打开。

## 安装与更新

- v1.0.8 候选完成质量门、安装包哈希和安装生命周期前，公开稳定版仍为 v1.0.7。
- v1.0.7 用户将在发布后通过应用内检查发现 v1.0.8，确认后下载并校验官方 NSIS 的 SHA-256。
- v1.0.4 及更早版本没有受控更新链，需要先手动安装 v1.0.5 或更高版本。
- 本版本仍未使用 Authenticode 商业签名，Windows 可能显示“未知发布者”或 SmartScreen。请只从官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。

## 能力边界

- 外部窗口与 Long编辑主资料库共享同一应用进程，但具有独立顶层窗口和路由生命周期；它不是主窗口中的额外标签。
- 外部编辑仍只在用户显式保存后写回源文件，并继续执行文件身份与冲突检查。
- 自动重启需要安装器成功退出；安装失败时不会把失败状态伪装成更新完成。
- 社区安装包保持 `NotSigned`，不代表企业签名候选或商业发布资格。
