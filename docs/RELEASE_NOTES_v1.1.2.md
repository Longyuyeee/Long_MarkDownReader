# Long编辑 v1.1.2

这一版完善资料库的日常文件整理，把常用操作放到右键菜单，用弹窗完成目录选择和回收恢复，同时精简侧栏，把更多空间留给资料。

## 主要改进

- **整理文件更方便**：右键可移动到、复制到、创建副本，也支持多选及应用内剪切、复制和粘贴。输入尚不存在的目标目录会自动创建，重名保留两份。
- **误操作可以恢复**：支持撤销本次会话最近一次成功移动；普通删除移到资料库回收站，可在弹窗选择恢复或永久删除。
- **移动后继续工作**：打开的标签、路径、收藏、最近访问、手动关系和文件显示样式随移动接续；副本继承独立的显示样式。
- **选择和快捷键更可靠**：单击打开一份文件，Ctrl/Shift 多选保留当前正文；文件栏快捷键只在文件区域使用，正文 Delete 不再误操作文件。
- **侧栏更简洁**：收集箱、智能集合、文内标签和关系面板移除重复标题、介绍及不必要的说明，原有操作和错误恢复入口保留；继续适配六种界面风格和既有动效设置。

## 下载与升级

支持 Windows 10/11 x64，提供 NSIS 和 MSI，普通用户建议选择 NSIS。可从本 Release 手动下载安装，或在软件内检查更新并确认安装。

本版为未签名社区版，Windows 可能提示“未知发布者”或 SmartScreen。请使用官方 Release，并核对附件 `SHA256SUMS.txt` 中的 SHA-256。

## 使用范围

剪贴板为应用内当前资料库的文件剪贴板；撤销记住当前应用会话的最近一次成功移动。回收站位于资料库的 `.longedit/trash`，搬迁资料库时请一并保留。恢复时如原位置已有同名项，会保留回收内容并提示先处理冲突。

现有 43 类格式、主题和风格选项保持。自定义模板、多文档操作深化、文本历史差异等后续计划不包含在本版。
