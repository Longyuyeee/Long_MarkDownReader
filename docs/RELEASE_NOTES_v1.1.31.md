# Long编辑 v1.1.31

本版深化 XLSX 连续录入与结果核对。

- 整数、小数、日期、文本长度与固定列表共用录入判定，直接输入、粘贴、清空和已有填充口径一致；非法批次整批保持原样。
- 单元格右键按需检查所选区域或筛选结果，查看问题位置、规则与范围，定位或预览修正到草稿，可撤销后保存。
- 筛选检查排除标题与隐藏行，修改绑定原单元格和当前草稿；保留其他未保存输入、其他工作表、公式和格式。
- 按工作簿的 1900/1904 日期系统处理日期，精确比较数值边界；公式及区域来源明确标为需另行核对。
- 修复撤销回原值后输入栏残留，防止下一次操作重新应用已撤销内容。保留全部现有功能及六种界面风格。
