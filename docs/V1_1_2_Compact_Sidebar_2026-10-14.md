# 侧栏内容精简（2026-10-14）

根据用户实际使用反馈，减少收集箱、智能集合、文内标签和笔记关系面板的重复文字，把空间用于文件与查询结果。功能继续保留，本批随文件管理正式发布为 1.1.2，源码已合并主分支；见 [发布记录](V1_1_2_Unsigned_Community_Release_Audit_2026-10-15.md)。

## 界面调整

| 面板 | 调整 | 保留的操作 |
| --- | --- | --- |
| 收集箱 | 移除大标题、简介、根目录重复名称、统计行、文件类型文字和底部教程；返回、新建、刷新、设置放在同一行；空目录只显示简短状态 | 新建笔记自动准备目录、筛选、文件打开、子目录/上一级、更换保存位置、异常重试和显式创建目录 |
| 智能集合 | 移除介绍卡片、常用条件的说明、底部教程；三个常用条件改为紧凑按钮；编辑/结果标题与返回同一行 | 全部筛选条件、保存/修改/删除、继续设置、当前搜索保存、旧搜索和关联集合、结果打开及来源 |
| 文内标签 | 移除大标题、重复“当前笔记”标题、介绍卡片和教程；文件名与未保存状态同一行，刷新随列表或结果显示 | 标签查找、添加标签、显式保存、篇数汇总、结果打开、旧文件搜索、只读限制和局部恢复 |
| 笔记关系 | 移除大标题、方向说明、通用“正文中的引用”文字和教程；直接显示“添加资料关系”按钮；图谱工具展开后直接显示操作 | 双向引用、草稿更新、同名选择、目标查找、图谱居中与右侧固定/取消、所有格式的手动关系 |

使用原有主题、文件行和动效变量，不改变用户的风格或动效设置。异常说明、输入标签、未保存状态、文件来源等影响操作判断的信息保留。

## 功能复测

五套实际组件浏览器流程共 **26 组检查、60 组布局** 通过，无页面异常。覆盖新建、筛选、保存、跳转、重试、只读、延迟回复隔离、六种风格与窄屏；另通过 7 项标签/链接文本规则、主题、字体及七入口检查。`npm run build` 通过类型检查与生产打包。

浏览器使用实际 App、LibraryMode、Vditor、表格、图谱和关系弹窗，原生 IPC 使用隔离模拟，不能代替安装版的运行结论。本批没有修改 Rust 实现；另外复测 **13 项原生文件系统测试**：收集箱 2 项、搜索/标签 7 项、手动关系 4 项，全部通过。覆盖目录创建、已有内容保留、目录失效、标签按篇统计、大写 MD、只按名称查找、关系持久化、原文件不变、移动迁移、并发去重及索引失效。

原生测试使用 `cargo test --locked --manifest-path src-tauri/Cargo.toml <模块> -- --nocapture`，模块为 `commands::inbox::tests`、`commands::search::tests`、`commands::file_relations::tests`，均通过。这是实际临时文件系统上的 Rust 测试，不是浏览器模拟结果，也不等同于新安装包验证。

- [收集箱流程](evidence/v112-sidebar-density/inbox/results.json)：根目录文件列表出现在面板顶部 120px 内，目录缺失恢复与新建仍可用。
- [集合流程](evidence/v112-sidebar-density/collections/results.json)：三个常用条件均可执行，完整筛选与旧集合兼容。
- [标签流程](evidence/v112-sidebar-density/tags/results.json)：写入草稿不直接保存，保存后刷新篇数和所选结果。
- [引用流程](evidence/v112-sidebar-density/relations/results.json)：双向引用、同名选择、局部重试、固定图谱和草稿更新可用。
- [手动关系流程](evidence/v112-sidebar-density/file-relations/results.json)：从精简后的侧栏直接打开关系弹窗，CSV、图片、JSON、PDF与其他附件仍可关联、保存、去重和移除。

测试脚本默认输出到新的 `v112-sidebar-density` 目录，支持 `LONGEDIT_BROWSER_EVIDENCE_DIRECTORY` 指定独立位置；不覆盖已发布 1.1.1 的证据。
