# Workbook 格式与异步填充边界审计

日期：2026-10-11。目标版本 1.1.0；当前仍未封板。本步延续草稿安全工作，不新增界面布局或扩大功能范围。

## 实际代码与修复

`src/views/WorkbookView.vue` 的自定义数字格式、行高、列宽在等待输入对话框后，原先没有复核文档/选区归属；公式填充在等待公式转换后也没有复核。这些入口现在复用 `captureEditContext`：检查工作簿对象、文档 epoch、读取代次、路径、资料库、选区和保存/外部模式状态；过期操作提示重试，不应用到变化后的目标。保存期间禁止启动这些编辑入口。

正常操作仍使用既有草稿和撤销逻辑。剪贴板入口仅改用重命名后的同一校验器，不改变既有操作语义。
