# XML 编辑器架构决策

更新日期：2026-07-24

## 1. 决策

XML 采用“源码是唯一事实源、Rust 权威分析、前端只消费带位置结果”的独立工作面，不把 XML 反序列化为普通对象后整体重写。

这样可以保留命名空间前缀、属性顺序、注释、CDATA、处理指令、实体字面量和原始排版。树形视图第一阶段只读；任何后续结构编辑都必须基于精确源码范围做局部补丁，并单独证明保真。

## 2. 安全边界

- XML 源码分析上限为 8 MiB。
- 最多分析 100,000 个元素、128 层深度，最多跨 IPC 返回 20,000 条提纲。
- 使用 `quick-xml` 流式解析，不加载网络或本地外部资源。
- 当前工作面禁止全部 `DOCTYPE`，因此不会进入外部实体、参数实体或实体扩展路径。
- 无效或不满足安全边界的 XML 默认不能覆盖磁盘；用户只能继续修复，或在明确确认后按原始源码保存。
- 写入复用 A1 文本内核的工作区守卫、内容签名、编码/换行保真和可靠替换。

## 3. 分批交付

1. A4-X1：权威分析、结构提纲、诊断、安全边界和保存门禁。
2. A4-X2：共享格式注册、独立 XML 工作面、源码高亮/折叠、诊断定位、只读树形提纲、草稿和可靠保存。
3. A4-X3：保真格式化门禁、创建、文本索引、全量回归与桌面审计入口。

## 4. 不在首批承诺的能力

- 不执行 XSLT、XPath 扩展函数、Schema 下载或 DTD 验证。
- 不解析或展开外部实体。
- 不把任意 XML 映射为可回写的 JSON 树。
- 不承诺 SVG、Draw.io、DOCX、PPTX 等 XML/ZIP 复合格式已经因此可编辑；它们必须各自建立格式、渲染和往返门禁。
