# v1.2.18：XML 元素创建与重命名

在 XML“元素与问题”提纲右键选择“添加子元素…”或“重命名元素…”，弹窗输入后预览，再应用到草稿；保留独立撤销，点击保存后才写入文件。

子元素支持普通文字、空容器、自闭合容器和清晰的子元素布局，特殊符号自动转义。重命名支持根元素、成对标签、自闭合和同名兄弟，只改选中元素名称，保留前缀、属性、注释、CDATA、原有排版与其他节点。复杂内容局部提示、保留输入并提供源码定位。

继续保护未保存内容、保存期间后续输入、失败重试和外部冲突副本。保留全部功能、主题和正常动效，不增加页面上的常驻表单。
