# v1.3.7：源码替换预览

当前开发目标：`1.3.7`；当前运行时版本：`1.3.7`；当前公开版本：`1.3.6`。当前阶段：**v1.3.7 源码替换预览候选**。

JSON、YAML、XML、TOML在既有查找面板按需打开替换预览，以分页弹窗查看将修改的位置及前后内容。原有直接替换操作保留，不强制每次确认。无匹配、无效正则或替换前后相同时就地反馈，不打开空弹窗。

确认后只将对应局部修改应用到当前草稿，作为一次可撤销操作；保存后才写回。沿用现有匹配、正则捕获组与选区范围语义。正文、查找条件、范围或已检测文件状态变化后停用旧预览，可刷新；切换文件关闭当前预览。只读文件隐藏替换预览，保留全部风格和正常动效。

预览最多10000个匹配，替换文字总长最多200万字符、涉及原文及替换总长最多400万字符；超出后提示缩小范围，不提供部分替换。每页20处，长文本只缩略展示，实际修改内容完整。保留既有JSON大文件分段边界，跨文件替换及重启后的预览持久化不计入本版。

检查进行中，尚未发布；当前可手动下载安装的公开版本为1.3.6。community-unsigned，企业releaseCandidate=false。NSIS实际安装、手动升级及卸载，与MSI构建摘要分别记录；应用内1.3.6→1.3.7自动更新实际观察独立pending。
