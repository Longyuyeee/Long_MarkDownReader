# v1.0.13 无签名社区版发布审计

状态：**候选证据已闭环，待发布并复核远端附件**

渠道：`community-unsigned`

企业发布候选：`releaseCandidate=false`

## 候选范围

- 主界面真实版本显示、更新状态提示及设置页精确入口。
- 紧凑更新提示与稳定的设置分类布局。
- 用户可见英文和内部开发编号清理。
- 43 类格式、91 个扩展名的能力与保存事实统一审计。
- Windows 安装包 SHA-256 与 Authenticode 采集器兼容性修复。
- v1.0.12 官方应用内更新观察已完成，作为当前发布基线。

## 发布前界面复核

- 修正前：更新提示宽度未稳定约束到传送后的 Naive UI 卡片；设置页整页滚动与 sticky 导航组合会在分类内容高度变化时校正导航位置。
- 修正后：更新卡片使用 460 px 显式响应式上限，发布说明只显示四条清理后的摘要；桌面设置页仅滚动右侧面板，分类切换时右侧回到顶部。
- 实际结果：设置导航在外观、格式与文件、系统与更新三类中的纵坐标均为 114 px；更新卡片在 1000×700 与 480×700 均完整位于视口，页面横向溢出和运行时错误均为 0。
- 证据：`docs/evidence/v1013-update-settings-ui/` 包含宽窄窗口截图和机器可读测量结果。

## 发布门禁

1. 冻结 `1.0.13` 版本事实源并通过完整 Quality Gate。
2. 从冻结提交构建无签名 EXE、MSI 与 NSIS，记录大小、SHA-256 和 `NotSigned` 状态。
3. 在 GitHub 托管一次性 Windows 环境执行 22 项安装生命周期与 18 项安装后工作区检查。
4. 回写候选证据并再次通过完整 Quality Gate。
5. 发布 GitHub Release，重新下载复核 MSI、NSIS 与 `SHA256SUMS.txt`。
6. 发布后单独验证官方 `v1.0.12 -> v1.0.13` 应用内更新、自动重启和合成资料保留。

## 当前边界

- 当前公开稳定版本仍为 v1.0.12，直到 GitHub Release 和远端附件复核完成。
- 社区安装包无 Authenticode 商业签名，Windows 可能显示未知发布者或 SmartScreen。
- 用户始终可以从官方 Release 手动下载安装；应用内更新也必须先确认并通过 SHA-256 校验。
- 候选测试和本地构建不能描述成正式发布；README 下载链接在发布前继续指向已验证的 v1.0.12。
