# LongEdit v1.1.16 · XLSX 常用操作更可靠

深化现有工作簿操作，让日常粘贴、编号、筛选与填充更加可靠；保留原有工作表、工具和显式保存流程。

- 带制表符、换行、引号及空尾格的复制/粘贴保持字段边界；整批可一次撤销。
- 前导零编号和超出电子表格可靠精度的长数字保留为文本；应用内复制区分普通文本与公式，公式按目标相对位置平移。
- 剪切移动公式保持原引用，复制才平移；粘贴与剪切分别保留撤销记录。
- 修复在筛选等输入框按删除、复制或粘贴时误操作网格草稿；点击网格后恢复工作簿键盘导航。
- Ctrl+V 使用系统粘贴事件，避免主动读取剪贴板时出现权限弹层导致粘贴未完成；菜单另保留“粘贴文本（自动识别）”。
- 数据面板增加“复制筛选结果”：包含表头，按会话结果顺序复制，不混入其他行，不改变原网格或当前选区。
- 长整数排序不再丢失精度；十进制填充避免浮点尾数，文本编号不当作数字序列。
- 超限、未加载目标、剪贴板读取期间切换文档或修改草稿均拒绝整批操作，不部分写入。所有修改仍需点击保存。

兼容边界：现有每批 10,000 格、工作面前 256 列、剪贴板及类型元数据各 10 MiB、单格 32,767 字符和公式 8,192 字符限制保留或对齐原生边界。外部及菜单纯文本粘贴没有类型记录；以等号开头的输入沿用公式语义，需保留应用内文本/公式类型时使用 Ctrl+V。应用内类型记录不携带来源文件路径。筛选结果最多分析前 50,000 数据行，界面明确提示；结果复制超过预算时需缩小筛选范围。
