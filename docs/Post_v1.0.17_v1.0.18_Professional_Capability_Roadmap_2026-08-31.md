# v1.0.17 之后的 v1.0.18 专业能力路线

当前公开/运行时版本：`1.0.17`

开发目标：`1.0.18`

发布候选：否

## M6-0 范围选择回执

真实代码盘点比较了图谱全屏、社区折叠/展开、治理环、YAML/XML/TOML Schema 与 ODP 备注编辑。唯一选中 **M6-1 图谱有界全屏生命周期与真实桌面审计**。

选择依据不是功能名称大小，而是现有安全基础：GraphView 已有稳定相机、缩略图、语义探索、ResizeObserver，以及 `1280×800`、`1000×700`、`720×680` 三档无溢出真实 Tauri 基线；三档 WebView 均记录 Fullscreen API 可用。当前产品仍没有图谱全屏入口，F11 只隐藏应用界面，不是真正的图谱全屏。

M6-1 只增加显式入口、`fullscreenchange` 状态同步、Escape/浏览器退出、路由卸载清理和画布重算。相机、选择、详情/路径/社区面板与缩略图必须保持，源文件必须不变。暗色、浅色、reduced motion 和三档窗口必须用真实 Tauri 记录预期与实际差异。

## M6-1 退出回执

图谱专属全屏已实现并完成真实桌面收口。暗色/reduced 与浅色/calm 两个 Tauri 会话各覆盖 `1280×800`、`1000×700`、`720×680`：6/6 次进入和 Escape 退出、2/2 次全屏路由卸载通过，运行时错误 0，源摘要不变。选择、相机姿态、选择历史面板和缩略图在三态保持。

真实测试依次暴露并修正三项差异：坐标级 CDP 事件没有 Fullscreen 用户激活，改为带 `userGesture` 的同按钮交互；应用提示层移除 `title` 后补充动态 `aria-label`；Document 先失活导致卸载 Promise 拒绝后补上有界处理。6 张亮暗宽窄截图已经人工复核。

当前唯一接续点为 **M6-2 v1.0.18 下一切片选择审计**。M6-1 单个有界 UI 生命周期增量不足以直接打包；M6-2 必须比较剩余候选与累计版本价值，再决定继续开发或进入版本收口。

## M6-2 选择回执

M6-2 决定停止扩大产品范围，唯一接续点为 **M6-3 v1.0.18 质量债与发布就绪审计**。M6-1 已形成完整、可见、真实验收的补丁能力；剩余社区代理折叠、结构化 Schema、治理环与 ODP 备注都会引入新的语义、依赖或生产者风险，不再混入同一补丁。

M6-3 只运行完整 Rust 测试和 `ci:patch-release`，复现并修正所有非预期失败。全绿前不提升版本、不打包；全绿后才允许进入原子版本迁移、候选安装包和完整安装生命周期，因此这一步是收口入口，不是已经发布。

## M6-3 质量与发布就绪回执

Rust 全仓为 **548 通过、0 失败、5 忽略**。完整 `ci:patch-release` 首次发现 v1.0.17 发布策略漏存托管运行 `33361759629`，且检查器误读不存在的企业候选字段；补齐回执并改为校验真实 `releaseCandidate=false` 后，同一完整门从生产构建开始复跑通过：6,275 模块、43 格式/91 扩展名、Rust locked check 和生产依赖 0 漏洞均达标。

唯一接续点为 **M6-4 v1.0.18 原子版本迁移与候选打包**。M6-3 本身没有提升版本或生成安装包；M6-4 必须记录真实 MSI/NSIS 大小、SHA-256、`NotSigned` 和当前 WebView2 烟测，之后仍不能跳过托管安装生命周期与远端发布验证。

## 延后边界

- 社区折叠/展开需要代理节点、聚合边、路径、证据、历史、缩略图、导出与恢复的统一语义，不能把现有过滤子图冒充折叠。
- 治理环没有稳定逐节点治理事实和可解释来源。
- YAML/XML/TOML Schema 仍缺 provider 信任、关联、解析、缓存、离线/隐私与诊断来源合同。
- ODP 备注在真实 LibreOffice/PowerPoint 生产者间不对称，继续只读。
- M6-1 不提升版本、不打包、不发布；完成真实审计后再决定 v1.0.18 的下一切片或版本收口条件。
