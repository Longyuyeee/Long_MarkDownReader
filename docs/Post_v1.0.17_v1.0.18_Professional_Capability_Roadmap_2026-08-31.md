# v1.0.17 之后的 v1.0.18 专业能力路线

当前公开/运行时版本：`1.0.17`

开发目标：`1.0.18`

发布候选：否

## M6-0 范围选择回执

真实代码盘点比较了图谱全屏、社区折叠/展开、治理环、YAML/XML/TOML Schema 与 ODP 备注编辑。唯一选中 **M6-1 图谱有界全屏生命周期与真实桌面审计**。

选择依据不是功能名称大小，而是现有安全基础：GraphView 已有稳定相机、缩略图、语义探索、ResizeObserver，以及 `1280×800`、`1000×700`、`720×680` 三档无溢出真实 Tauri 基线；三档 WebView 均记录 Fullscreen API 可用。当前产品仍没有图谱全屏入口，F11 只隐藏应用界面，不是真正的图谱全屏。

M6-1 只增加显式入口、`fullscreenchange` 状态同步、Escape/浏览器退出、路由卸载清理和画布重算。相机、选择、详情/路径/社区面板与缩略图必须保持，源文件必须不变。暗色、浅色、reduced motion 和三档窗口必须用真实 Tauri 记录预期与实际差异。

## 延后边界

- 社区折叠/展开需要代理节点、聚合边、路径、证据、历史、缩略图、导出与恢复的统一语义，不能把现有过滤子图冒充折叠。
- 治理环没有稳定逐节点治理事实和可解释来源。
- YAML/XML/TOML Schema 仍缺 provider 信任、关联、解析、缓存、离线/隐私与诊断来源合同。
- ODP 备注在真实 LibreOffice/PowerPoint 生产者间不对称，继续只读。
- M6-1 不提升版本、不打包、不发布；完成真实审计后再决定 v1.0.18 的下一切片或版本收口条件。
