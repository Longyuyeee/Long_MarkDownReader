# 1.3.3 规划：按文件隔离提纲筛选与继续浏览状态

当前公开版本1.3.2。本页仅为下一版规划，尚未实现。[已交付路线](Foundation_Deepening_Roadmap_1_3_0_to_1_3_2_2026-10-27.md)。

现状：四种结构化编辑器的筛选条件保存在组件内；资料库通过activeTabId重建编辑器，往返文件时会丢失局部筛选和展开状态，独立编辑路由复用组件时又可能沿用旧条件。TOML展开数组也采用局部状态，重新载入后需重新展开。1.3.2已解决行内导航和当前分析的定位接续；接下来深化在多份资料之间来回工作的连续性。

1. 在当前软件会话中按文件区分提纲筛选条件，A文件的搜索意图不覆盖B文件；返回A时恢复自己的条件。使用现有输入框和清除入口，不新增面板或常驻介绍。
2. 接续仍有效的展开项和语义节点；只在对应文件的最新分析就绪后恢复，内容变化、无匹配项或节点消失时自然回退。保存路径状态时不保存旧字节范围，不主动抢回编辑焦点。
3. 文件改名／移动时沿已有路径接续处理状态，文件关闭或切换资料库时清理相应会话状态。保留未保存内容、撤销、显式保存、迟到结果保护、全部风格与正常动效。

完成标准是用户在两份不同筛选条件、不同展开状态的资料之间往返，能继续原来的工作，正文和磁盘原件不被界面状态操作改写。本轮不承诺软件重启后的状态持久化，具体支持范围在实施时按实际代码确认。

实施接点：以[资料库嵌入编辑器](../src/views/LibraryMode.vue)、[现有结构化正文会话](../src/composables/useStructuredSession.ts)、[文件移动后的阅读接续](../src/services/fileReadingContinuity.ts)及[提纲导航](../src/composables/useSourceOutlineNavigation.ts)为依据。浏览状态独立于正文与保存回执；当前窗口内按资料库、路径、格式及外部文件身份区分，沿现有路径变化通知迁移。先完成四种格式的筛选隔离，再接续实际存在的展开项和有效语义选择，最后处理关闭文件与切换资料库后的清理。此处为实现顺序，不代表代码已经完成。
