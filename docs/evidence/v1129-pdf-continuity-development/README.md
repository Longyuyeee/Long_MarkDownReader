# v1.1.29 开发验证

`browser-opaque-final/` 是最终真实 Vue/Pinia/Vditor 页面 13 项交互验证，包含六种风格、草稿保护、迟到响应、过期预览、生成区内补写、三模式回滚及延迟单次撤销/重做，和 PDF 到目标笔记的直接入口。`annotations-final/` 是 PDF 批注右键编辑、返回位置/筛选/选择及未失焦输入离开保存 3 项验证。以上页面均使用明确的模拟 IPC，不作为实际安装验证。

`native-reading.log` 为 8 项实际原生来源读取与刷新测试。`local-quality.log` 为完整发布质量流程，生产依赖审计 0 漏洞；`frontend-build.log` 为最后页面接续修复后的类型和生产构建。单元与安装表达式契约 10 项另由发布质量流程执行。

较早目录保留开发原始结果：首次通用事务缺少重做光标书签、PDF 入口缺少编辑器完成加载后的再次调度，以及销毁时读取编辑器引发的提示均已修复；最终目录没有这些失败。早期 `annotations/` 仅因空的替身目标页面无高度导致可见性等待失败，后续改为等待路由已挂载，全部功能断言保留。真实同包安装与公开下载结果另行记录。

最终视觉复核确认弹窗使用主题实色 surface，六种风格均断言实际背景色。首轮构建 39519644997 的质量、1100 项功能和 1 项性能回归通过，但因透明弹窗影响阅读，在打包阶段取消；源码修正后重新固定，原运行日志保留，不作为最终安装包。`browser-frozen/` 等较早截图仅保留历史，`browser-opaque/` 首次启动因冷缓存导航 20 秒超时而未执行功能；后续只将导航预算设为 60 秒，全部功能断言保留。
