# 1.1.34 开发过程

当前公开基线 1.1.33（9961c0c2）。新默认章节链接只记录库内路径、标题和锚点；沿用大纲具名右键菜单，原绝对路径入口保留。文件移动与跨库复制复用现有事务、字节核对和草稿保护，不新增文件写入命令。

初次前端边界夹具把额外查询字段追加到 fragment 后，实际属于合法片段；修正夹具把额外字段放到查询中，产品规则未修改。Rust 真文件夹具的 BOM 转义在格式检查中发现后修正；全局格式检查同时显示既有 examples 文件的格式差异，未修改无关示例。前端 20 项章节与定位检查、3 项旧本地链接检查及原生驱动契约通过；类型检查通过。实际完整质量与安装结果待后续登记，不把模拟 IPC 当作安装证明。

初次新增真文件复制用例已验证配套文件和循环链接写入，最后比较把 Windows 普通路径和扩展路径当作不同文本；改为核对二者实际文件位置。另两项实际目录副本与事务改名/反向改名通过，原错误不记为通过，之后重跑为准。

7 项新增章节真文件检查、20 项跨库复制回归及 22 项移动事务回归通过。生产右键组件的 5 项页面检查通过，覆盖默认/本机链接、菜单过期、切库、六种风格、明暗及宽窄屏；页面中的文档和剪贴板是受控夹具，不是实际安装证据。版本候选和当前开发身份契约通过。

首次完整质量检查在发布文档缺少既有通道、企业候选与手动安装声明处停下。补齐真实发布边界后，从该步骤接续，原日志保留；不重复已经通过的构建和无关检查。之后原包构建仍会完整执行全部门禁。

接续检查发现旧 1.0.21 更新观察校验只列到 1.1.33 的显式后继边界；新增严格的 1.1.34 分支，绑定实际 1.1.33 源提交，保留旧安装和更新观察结论，并覆盖独立更新 pending 不可冒用旧成功。原错误日志保留。
