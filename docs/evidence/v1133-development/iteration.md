# 1.1.33 开发过程

源于路线的实际缺口：单份 PDF 跨库复制不携带旁边的批注，PDF 专用来源链接只被列为未接续引用。接入现有复制预览、逐项回执与失败项重试，未新建主页面入口。

本地首次执行页面脚本时没有配置已有的 Playwright 路径，尚未进入页面；使用现有运行时后 6 项新增页面和 9 项原复制回归通过。初次 Rust 阅读笔记夹具将生成标记直接放在 BOM 后，而现有前端同样不把这种位置识别为独立生成标记；夹具改为在普通标题之后放置合法独立标记，16 项跨库复制真文件测试通过。类型检查发现已完成行的推断类型缺少新统计字段，已明确列表项目类型。

全程使用自有夹具，不启动或重启用户日常软件。完整质量、原安装器及公开发布结果另行登记；目前不把这些本地模拟 IPC 检查当成安装证明。

完整质量检查首次停在发布文档缺少既有“手动下载安装”说明；补齐文档后，从该检查接续余下全部命令通过，未重复无关构建。原失败和接续日志均保留。全量 Rust 功能回归为 1116 项通过、1 项旧冷搜索夹具超出交互时间预算、5 项既有忽略；本版跨库复制 18 项均通过。同一冷搜索用例在其余编译及检查结束后、相同预算下隔离通过（0.86 秒），不修改或跳过断言；正式构建仍须重新跑完整功能回归。

本机工作簿性能回归在其余检查结束后独立执行仍未通过，第二次内部尝试 patch 为 6992 ms（标准 5000 ms）；原日志保留。工作簿代码没有改变，不调整预算，不将失败记为通过；正式构建必须在相同标准下完整通过。

初次正式构建 39601475258 的完整质量、1117 项功能与独立性能回归均通过；在打包期间复查发现新增批注字符串没有计入整批 64 MiB 文本缓存预算，因此主动取消，不用于发布。已把批注计入单项及整批预算，避免大量 PDF 的合法批注合计占用过多内存；18 项跨库复制真文件回归再次全部通过。需以补齐预算后的新固定构建、原安装器复核及发布结果为准。
