# Long编辑 v1.1.3

这一版继续完善日常记录和整理资料的基础操作。

- **自定义笔记模板**：从当前 Markdown 笔记保存模板，在新建菜单选择使用；支持标题、日期、时间变量、资料库默认模板和快速笔记复用。新增、修改、删除都在管理弹窗内完成。
- **多文档更顺手**：标签右键固定、关闭其他/右侧未固定标签、重新打开关闭标签；支持拖动排序、Ctrl+Shift+T 恢复关闭、Markdown 和文本阅读位置接续。固定与排序随资料库记忆。
- **标签和集合**：右键固定常用标签、按名称/数量排序；集合菜单调整顺序，支持拖动排序、多个标签同时筛选，记住结果排序和浏览位置。
- **直接维护资料关系**：关系面板显示当前文件的手动关系，任意类型资料都能查看、修改关系类型与说明、移除关系。编辑使用弹窗，不需要进入图谱，原文件内容保持。
- **TXT 历史与差异**：保存时保留修改前后版本，按需打开历史比较、恢复为 TXT 副本或保护草稿后替换编辑区。替换后仍需保存才写回原文件。
- **窄窗口操作**：复核“导航”展开后的新建菜单及模板弹窗，保留窄窗自动收起侧栏的现有行为。

现有文件管理、图谱、正文引用、主题、六种界面风格和动效选项保留。性能优化继续随功能开发进行。

模板、标签偏好和阅读位置存储在本机。管理备份不包含自定义模板正文；恢复管理配置保留本机模板。TXT 历史覆盖资料库内的完整文本编辑，外部文件及大文件范围预览保持原有行为。关闭标签恢复的是文档入口，不恢复已明确放弃的未保存修改。局部历史恢复、模板跨设备导入/导出不在本版范围。
