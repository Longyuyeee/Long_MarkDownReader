# UX-50A / EA-1 外部 Markdown 与 TXT 工作区审计

## 结论

EA-1 已关闭系统外部启动的第一组缺口。Markdown 与 TXT 均通过后端显式授权后打开，不会把未知格式或仅导入格式错误送入 Markdown 编辑器。

## 已完成

- Markdown 使用独立的外部工作区身份，默认隐藏大纲并占满可用宽高；用户可按需重新展开大纲。
- Markdown 正文不再固定限制为 800px，窄窗口顶栏允许换行且操作区可以横向滚动。
- Markdown 和 TXT 都显示返回入口、撤销/重做能力及显式保存边界；只有用户点击保存时才写回源文件。
- TXT 继续复用正式代码文本工作区，保留编码、BOM、换行符、查找替换和安全 HTML 预览能力。
- 外部路由由格式注册表驱动，只接受 `externalPolicy=edit` 的 Markdown 与 TXT，不再存在通用 `TempMode` 兜底。

## 安全与默认应用边界

- 本阶段没有扩大 Windows 文件关联。安装器仍只把 `.md` 和 `.markdown` 注册为“打开方式”候选。
- LongEdit 不直接写入 Windows 默认应用选择；默认程序继续由 Windows 系统界面和用户确认决定。
- JSON、PDF、表格、文档、图形和媒体尚未声明为系统外部启动已适配，必须在 EA-2 分组完成真实工作区授权后才能加入候选清单。
