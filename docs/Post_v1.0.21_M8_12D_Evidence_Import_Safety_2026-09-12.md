# M8-12D 证据导入安全收口

日期：2026-09-12。前置纠偏提交：`b36170ae`。

## 需求与实现

依据 M8-12B“截图必须实际复核、只有合格证据才能导入”的原始约束，修正 `import-v121-managed-updater-evidence.mjs`：

- 不再在文件内容验证前创建证据目录；预读全部文件并完成格式、生命周期、版本、摘要和隐私声明检查后再写入。
- 限定九个确切普通文件，拒绝额外文件和符号链接；已有目标仍拒绝覆盖。
- 要求显式传入视觉审阅 JSON，记录审阅者、时间，以及三张截图各自的文件名、SHA-256 和 accepted；审阅时间不得晚于导入时间。
- 审阅记录随导入清单保存；完成态检查器核对其与实际截图摘要一致。脚本不能代替实际视觉观察，也不能证明填写者真的看过图；操作者仍需如实审阅。
- 校验 run/artifact ID、digest、commit 和时间格式；不声称仅凭这些参数就完成远端来源真实性验证，导入前仍须核对 GitHub 运行和 artifact 元数据。

## 使用变化

原六个位置参数后新增第七个 `<visual-review-json>`。该文件放在 artifact 目录之外，结构如下；示意值不得作为真实验收证据：

```json
{
  "reviewer": "实际审阅者",
  "reviewedAt": "实际 UTC 时间",
  "screenshots": [
    { "path": "managed-updater-available.jpg", "sha256": "实际摘要", "accepted": true },
    { "path": "managed-updater-installing.jpg", "sha256": "实际摘要", "accepted": true },
    { "path": "managed-updater-current.jpg", "sha256": "实际摘要", "accepted": true }
  ]
}
```
