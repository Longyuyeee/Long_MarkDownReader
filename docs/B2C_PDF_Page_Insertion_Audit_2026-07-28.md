# B2C PDF 插入页面阶段审计

> 审计日期：2026-07-28
> 产品基线：LongEdit `v0.7.0`
> 开发分支：`main`
> 阶段状态：B2C 已完成，PDF B2 日常页面操作阶段收口；下一开发入口为 A3R JSON/JSONC 软件内创建

## 1. 阶段结论

B2C 已交付从另一份 Library PDF 选择明确页范围，并插入当前 PDF 的目标页前、目标页后或文档末尾。隔离预览和可靠保存均验证插入边界、跨文件页序、文本、页面尺寸、裁剪框与旋转，保存后自动重开新文件。

至此 B2A 页范围提取、B2B 多文件有序合并和 B2C 指定位置插页全部完成，PDF B2 日常页面操作阶段收口。LongEdit 仍只承诺经过门禁的页面级安全编辑子集，不宣称 PDF 正文、表单、签名或 Acrobat 等价编辑能力。

## 2. 已交付能力

- 来源 PDF 必须是当前 Library 内另一份文件，当前文件和来源文件不能相同。
- 来源页范围支持单页、连续范围和逗号组合，保留填写顺序并拒绝重复页。
- 插入位置支持目标页前、目标页后和文档末尾；后端使用 `0～当前页数` 的明确页面边界校验。
- B2B 页面合并内核收敛为通用页面序列组合器，B2B 整文件合并行为保持不变。
- 跨文件对象重新编号，页面资源、MediaBox、CropBox 和 Rotate 继承值在输出叶子页面物化。
- 输入总大小限制为 128 MiB、输出限制为 256 MiB、输入及输出页数限制为 20,000。
- 加密、损坏、签名、表单、附件、处理中源文件变化和其他高风险兼容对象稳定阻断。
- 保存摘要绑定来源范围与插入位置，只创建同目录新文件，拒绝覆盖当前 PDF、来源 PDF 或已有目标。
- 落盘后逐字节复读，并再次验证结构页数、文本顺序、页面几何和两份源文件不变。
