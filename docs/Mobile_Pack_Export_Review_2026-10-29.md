## 用户操作和返回

| 当前任务 | 页面与决定 | 返回／保护 |
| --- | --- | --- |
| 核对附件包 | 源笔记、实际导出文件／Android建议文件名、完整正文及附件清单入口；固定一个导出动作 | 原捕获正文、签名与草稿保持 |
| 查看完整正文 | 独立只读页，内容使用实际打包正文及改写后的附件引用 | 保留普通文字选区／真实滚动，长文继续复用既有分段和查找 |
| 查看附件清单 | 独立列表，显示完整相对路径、数量和体积 | 返回实际核对页或结果页，保留原入口和清单现场 |
| 导出成功 | 浏览器明确“已发起下载”，Android仅在成功回复后显示已核对；固定“完成，返回文档” | 完成直接回原编辑器；顶部返回仍只回核对，不写入或清空草稿 |
| 取消／失败／不完整回复 | 独立结果，显示真实原因及是否确实保留记录，主要动作是重试或重新选择位置 | 保留同一已准备包与编号；不能把不完整回复写成成功或已保留 |
| 从历史重试 | 结果属于选中的历史包，返回附件包详情，再返回原记录行 | 不覆盖本次准备导出的结果，不串记录或错误 |
| 从结果查看历史或正文 | 子任务返回到实际结果层 | 结果及入口DOM保持，焦点回到真实按钮 |
| 主动移除保留包 | 继续既有风险确认；成功移除后更新旧结果中的保留状态 | 已导出文件继续保留，结果不再声称本机记录仍存在 |

一般解释继续放问号。保留实际结果、目的地、完整内容计量和未保存提醒；删去重复的取消说明，压缩图标和长包名占用。所有等待操作均阻止重复触发和离开；已有来源重读、记录重读及移除保护继续生效。
