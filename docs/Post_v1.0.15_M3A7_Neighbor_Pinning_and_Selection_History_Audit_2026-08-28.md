# Post-v1.0.15 M3A-7 邻接固定与选择历史审计

日期：2026-08-28

阶段：M3A-7

发布候选：否

## 1. 原始需求复核与语义纠偏

路线图把“邻接固定与选择历史”列为 M3A 的最后一组功能，而更早的 `Professional_Knowledge_Workspace_Design.md` 对固定行为给出了明确产品语义：局部关系图应固定在编辑器右栏，并跟随当前活动标签。因而本阶段的“邻接固定”不是图谱节点坐标锁定，也不是新增收藏夹，而是把当前对象的局部图谱固定到编辑工作区右侧。

实际代码中 `LocalGraph.vue` 已具备 1/2/3 跳、关系筛选、语义边和证据卡片，但没有任何挂载入口。此次复用现有局部图谱，将固定偏好保存为设备本地状态；它不修改资料库、关系或用户正文。选择历史则只存在于当前全局图谱会话，不跨会话持久化。

## 2. 冻结的交互与状态语义

- 从全局图谱选中节点后，可将该节点打开到编辑器并把局部图谱固定在右栏；右栏随后跟随活动标签，而不是永久锁死在最初节点。
- 固定偏好属于设备本地 UI 状态，可随时取消；固定、跟随和取消均不写回用户数据。
- 选择历史最多保留 20 条，记录规范化后的选中节点集合与活动节点；连续相同选择去重。
- 从历史中回退后产生新选择时，截断原前进分支，保持常规历史栈语义。
- 图谱变化导致节点不存在时，恢复前按当前有效节点集合归一化；活动节点丢失时回退到仍有效的首个选中节点。
- 历史面板提供列表、上一个和下一个选择，并明确标注“会话内、不写回资料库”。

## 3. 实现中发现并修复的实际缺陷

首次真实桌面审计中，固定右栏已出现，摘要也显示 6 个节点和 7 条边，但 SVG 与直接关系卡片为空。原因是 Tauri 在 Windows 上可能返回带 `\\?\` 前缀的活动文件路径，而局部图谱节点 ID 使用普通盘符路径；组件此前用字符串直接相等判断中心节点。

现已通过工作区路径等价判断解析真实中心节点 ID，并将同一个规范中心 ID 用于子图筛选、布局、中心节点样式与直接关系证据。修复后局部图谱、节点和证据卡片均正常显示，并可继续跟随 `Brief.md`。该修复属于真实代码缺陷纠正，不是为放宽审计预期而调整证据。

## 4. 合同与真实桌面审计

纯状态合同验证了连续去重、回退/前进、回退后分支截断、缺失节点归一化和 20 条容量上限。真实 Tauri 固定资料库包含 17 个节点、17 条边、11 类对象和 6 类实际关系，结果如下：

| 项目 | 预期 | 实际 |
| --- | --- | --- |
| 选择序列 | 记录单选、全选、清空 | `1 → 17 → 0`，共 3 条历史 |
| 历史导航 | 可回退并前进 | `0 → 17 → 1 → 17` 全部正确 |
| 固定局部图谱 | 编辑器右栏展示真实邻接 | `NorthStar.md` 为 6 节点、7 边，节点和 3 条直接关系卡片可见 |
| 跟随活动标签 | 点击局部关系后切换中心 | 切换到 `Brief.md`，右栏路径与活动标签一致 |
| 取消固定 | 恢复普通编辑布局 | 右栏成功移除 |
| 响应式 | 1280/720 均无页面横向溢出 | 宽屏为右侧栏，窄屏为可关闭右侧浮层，均通过 |
| 安全性 | 不修改资料库 | 审计前后目录 SHA-256 一致 |
| 稳定性 | 零错误并可返回资料库 | 运行时错误 0，返回通过 |

证据位于 `docs/evidence/post-v115-m3a7-neighbor-pinning-history/`，包含 `desktop.json`、选择历史宽窄屏、固定局部图谱、跟随标签和窄屏截图。证据不包含用户内容，`releaseCandidate=false`。
