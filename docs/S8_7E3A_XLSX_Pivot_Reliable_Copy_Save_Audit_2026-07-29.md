# S8-7E3A XLSX Pivot 可靠新副本审计

> 审计日期：2026-07-29
> 分支：`main`
> 结论：标准本地 Pivot 可可靠另存为同目录新 `.xlsx`，原件覆盖继续禁止

## 1. 交付范围

本阶段把 S8-7E2D 已验证的完整隔离重建结果接入可靠落盘事务。首批白名单固定为一个行字段、一个列字段、一个 `sum` 值字段、无页面筛选的本地工作表来源 Pivot。

工作面只有在隔离布局扩缩容通过且不存在未保存草稿时才显示有效保存入口。用户提供同目录新文件名，保存成功后应用打开已验收副本。

## 2. 事务门禁

- 源文件必须通过工作区路径守卫、128 MiB 上限、当前签名和 OOXML 包校验。
- 保存请求绑定最近一次隔离输出摘要；来源或构建结果变化后必须重新验证。
- 文件名只允许单一 `.xlsx` 名称；路径片段、控制字符、非 XLSX 扩展名均拒绝。
- 目标必须不存在，且不得与源路径相同。
- `write_new_bytes` 使用同目录临时文件和硬链接原子创建，绝不覆盖已有目标。
- 落盘后逐字节核对隔离输出，并重新验证 OOXML 包、Pivot 身份、布局范围、字段数量和聚合语义。
- 保存前后两次核对源文件字节、签名和摘要。
- 写后验证失败时，只删除与本次输出字节完全一致的未验收副本。

## 4. 未开放能力

- 不覆盖源 XLSX，不替换已有目标，不允许带未保存草稿另存。
- 多度量、单轴变体、多层轴、页面字段、切片器、外部数据和未知扩展仍不可保存。
- 本阶段只证明 LongEdit 创建的新副本可结构与语义复读，不等于 Excel 应用已执行 refresh。
- Excel、LibreOffice、WPS 的刷新、保存、进程重启和重开证据仍待 S8-7E3B。
