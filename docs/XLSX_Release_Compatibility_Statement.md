# XLSX 发布兼容声明

更新日期：2026-07-21
兼容档案：`xlsx-progressive-editing-v1`
适用引擎：`calamine-ooxml-ironcalc-v14`
机器门禁：`shared/xlsx-release-gate.json`

## 1. 可公开使用的产品声明

LongEdit 提供 **XLSX 渐进式编辑（以公开兼容性矩阵为准）**。这表示用户可以在公开矩阵标记为“支持”的范围内读取、编辑和保存工作簿；标记为“受限”“保真”或“计划”的能力必须按各自边界解释。

当前版本不得宣传为“完整 Excel 等价”“100% Excel 兼容”或“无损编辑所有 XLSX 功能”。`xlsxRoundTrip` 总体能力继续为 `planned`；部分维度的可靠往返不能被推导为整个 XLSX 格式的完整等价。

## 2. 发布差异门禁

复杂 fixture 同时覆盖四个 Sheet、基础值、公式、样式、尺寸、合并、验证、Table、图表、图片、透视表、切片器、外部数据、打印布局和保护。复合内容/样式/结构编辑后：

- ZIP 部件集合不得新增或删除；
- 只有 `xl/worksheets/sheet1.xml` 和 `xl/styles.xml` 可以变化；
- 其他部件解压后必须逐字节一致；
- 修改后的语义值、样式和合并区域必须重新读取验证；
- 受保护 Sheet 写回必须拒绝且源文件保持逐字节不变。

## 3. Debug CI 性能预算

基准负载为 4 个 Sheet、10,000 行 × 12 列、1,000 行公式。预算用于发现性能回退，不代表所有设备的用户体验承诺。

| 操作 | 上限 |
| --- | ---: |
| 工作簿检查 | 2,000 ms |
| 读取 200 行分页 | 7,000 ms |
| 修改一个既有单元格并重建 XLSX | 5,000 ms |
| 检查、分页和写回总计 | 12,000 ms |
| 写回文件体积增长 | 5% |

这些预算由 Rust 自动化测试从机器事实源读取。降低负载、放宽预算或减少差异保护范围都必须同时修改门禁事实源并接受代码审查。

## 4. 当前发布结论

当前工作簿能力适合公开矩阵覆盖的本地渐进编辑、结构查看和保真保存场景。宏/VBA、Power Query、完整外部数据刷新、透视计算、像素级图表/打印还原、完整公式等价及所有高级对象编辑仍不属于当前发布能力。

详细分维度结论见 `XLSX_Public_Compatibility_Matrix.md`；技术写回边界见 `XLSX_Compatibility_Boundary.md`。
