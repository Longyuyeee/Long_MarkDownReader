# 专业工作台主页契约

更新日期：2026-07-21
状态：W7-1 / FR-WB-001 已完成

## 1. 产品入口

`/workspace` 是应用默认入口。主页聚合当前知识库的工作状态，而不是建立第二份内容数据库：

- 收藏和最近使用继续来自设备本地 Pinia 持久化状态。
- 待办从 Markdown 未完成任务语法 `- [ ]`、`* [ ]` 实时提取。
- 常用 Canvas 由收藏顺序和最近修改时间共同形成。
- 知识健康与索引状态复用现有图谱健康命令和可重建索引状态。
- 所有文件打开操作继续经过文件格式注册表和统一路由。

资料库、图谱和设置保留为一级操作入口；主页只聚合和导航，不复制编辑能力。

## 2. 后端边界

`get_workspace_overview` 必须先通过 `WorkspaceGuard` 解析知识库根目录，并在线程池执行扫描。扫描遵守以下限制：

- 只统计文件格式注册表声明的格式。
- 跳过符号链接、隐藏目录/文件和 `.assets` 附件目录。
- 单个 Markdown 待办源最大 20 MB，最多返回 24 个待办。
- 最多扫描 100,000 个目录条目；最近文件和 Canvas 各最多返回 8 个。
- 无法读取的单个目录或文件被隔离，不使整个主页失效。

概览是即时派生数据，不写入用户文件，也不成为事实源。索引、图谱健康和概览请求彼此独立；其中一个失败时，其他区块仍可呈现。

## 3. 验收证据

- Rust 回归覆盖已登记格式统计、Markdown 待办、最近 Canvas，以及隐藏目录、附件目录和未登记格式隔离。
- Vue 类型检查和生产构建验证按需路由、图标映射、响应式布局和文件打开契约。
- 普通浏览器不具备 Tauri IPC，不能作为桌面视觉验收环境；桌面发布以 Tauri Debug 构建和真实 WebView 为准。
