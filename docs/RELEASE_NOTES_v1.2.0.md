# Long编辑 v1.2.0

本版集中完善现有功能与界面，让正文、表格、文档和画布成为工作区的中心。

## 界面与操作

- 统一资料库与各类编辑器的标题、标签和工具位置，减少重复文字及介绍；需要时通过圆形问号查看说明。
- 小窗口按实际编辑区宽度收起辅助属性栏，保留原来的打开入口。修复 Table、PPTX、开放文档工具栏裁切及独立 Markdown 工具偏移；参考区打开时，工作簿与窄正文区的保存、模式和文档操作入口仍可使用。
- Canvas 的缩放、适应内容和保存靠近画布；思维导图、draw.io 属性按需打开，关闭面板保留输入。
- 图谱工具与筛选独立弹出，避免被工具栏裁掉；修复缩窗后导图视野空白。
- 完善右键子菜单与下拉提示让位，文件名和标签页不再显示遮挡操作的路径浮窗。
- 保留六种界面风格、主题、文档排版、文件显示样式和动效选项。

## 基础功能

继续保留文件管理、移动改名后的链接与图片接续、全文搜索、智能集合、文内标签、文件关系、工作现场、历史差异、内容备份，以及现有各格式的编辑和副本输出能力。错误提示与恢复入口保持局部呈现，避免普通操作失败覆盖整个工作区。

未保存的内容仍受原有保存、关闭、切换和冲突处理保护；本版不会因窗口缩放、风格切换或收起属性栏而自动保存草稿。
