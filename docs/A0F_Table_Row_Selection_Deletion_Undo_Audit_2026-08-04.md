# A0F 表格行选择、删除与撤销审计

日期：2026-08-04
范围：UX-11
状态：代码完成，待安装版复测

## 本步完成

- CSV、TSV 和开放 Table 的行号现在只负责选择或取消选择，不再点击即删除。
- 选中行后，状态栏显示明确的“删除选中行”命令；Delete 键也会先打开同一确认流程。
- 删除确认改用应用内对话框，并明确说明：操作先停留在内存草稿，只有点击保存才写入源文件，删除后可以撤销。
- 新增行和删除行共享独立的撤销/重做历史，提供工具栏按钮以及 Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z 快捷键；单元格输入聚焦时保留输入框自身的编辑历史。
- 行选择使用稳定 `rowId`，经过筛选和排序后仍指向同一条数据。
- 表格视图删除和离开脏表格的确认也迁移到应用内对话框，`TableView` 不再调用 `window.confirm`。

## 机器审计

- 新增 `check:table-row-editing-experience` 并接入补丁发布门禁。
- 生产构建、Dialog ACL、D1C 可访问性和 UI 一致性检查通过。

## 安装版复测

1. 点击 CSV/TSV 行号，确认只出现选中态且数据不减少。
2. 点击“删除”或按 Delete，分别验证取消、确认、撤销、重做；未点击保存时重开文件应保持原数据。
3. 确认删除并点击保存后重开文件，验证仅目标行被删除。
4. 在筛选和排序状态下选择一行，确认删除、撤销仍作用于同一 `rowId`。
5. 在单元格中输入后按 Ctrl+Z，确认优先撤销输入内容，不误触发行结构历史。

安装版复测通过前，UX-11 只标记为“待复测”。
