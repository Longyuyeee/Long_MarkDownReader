# S8-7E3C XLSX Pivot 布局新副本与生产者往返审计

> 审计日期：2026-07-29
> 分支：`main`
> 结论：单行轴、单列轴和三度量可靠新副本已开放，桌面生产者矩阵 9/9 通过

## 1. 阶段目标

S8-7E3A/E3B 已为标准一行轴、一列轴、单 `sum` Pivot 建立同目录可靠新副本，并完成 Excel、WPS、LibreOffice 3/3 往返。本阶段将 E2F 的单轴与多度量隔离包推进到真实保存入口，并要求每种布局独立通过三个桌面生产者。

## 2. 已完成能力

- `save_workbook_pivot_copy` 新增 `layoutVariant` 白名单：`row_only`、`column_only`、`multi_measure`。
- 每种布局绑定独立隔离包摘要；摘要、源签名或 Pivot 身份变化时拒绝保存。
- 目标仍限定为源目录内不存在的新 `.xlsx`；源覆盖、已有目标覆盖和未保存草稿继续拒绝。
- 工作面在布局验证结果中为三种布局分别提供文件名和可靠另存入口。
- 多度量使用 `sum(Field2)`、`count(Field1)`、`average(Field2)`。计数字段与行标签字段绑定，规避 LibreOffice 对同一数值字段重复计数度量的错误降级。

## 3. 生产者原生布局修正

首轮真实 Excel 审计发现 E2F 输出未排除隐藏轴项，且单列轴、多度量仍使用简化单表头布局。实现已修正为：

| 布局 | LongEdit 基准范围 | 输出单元格 | 右下角语义 |
| --- | --- | ---: | ---: |
| 单行轴 | `A3:B6` | 8 | `B6=4` |
| 单列轴 | `A3:D5` | 12 | `D5=4` |
| 三度量 | `A3:J8` | 60 | `J8=2` |

隐藏的行项 `b` 和日期项 `2022-01-02` 不再进入输出或总计。单列轴使用两级表头，多度量使用三级表头及标准数据伪轴 `x="-2"`。

## 4. 真实生产者矩阵

Excel `16.0/20228`、WPS Spreadsheets `12.0/26895`、LibreOffice Calc `26.2.4.2` 分别对三种布局执行：

1. 打开 LongEdit 可靠新副本；
2. 刷新 Pivot 并保存；
3. 退出桌面进程；
4. 使用新进程重开；
5. 复核对象数量、可见范围和右下角总计；
6. 使用 LongEdit 反向复读 OOXML 身份、轴字段、值字段来源和聚合。

结果为 `3 布局 × 3 生产者 = 9/9`。LibreOffice 将单列轴规范化为 `A3:C5`，但保存后与新进程重开一致，右下角总计仍为 `4`；该差异作为明确的生产者规范化记录，不视为坐标等价。

版本化证据位于：

- `docs/evidence/s8-7e3c-xlsx-pivot-layout-roundtrip/matrix.json`
- `fixtures/xlsx/output-reopen/s8-7e3c-*.xlsx`

## 5. 门禁

- 三份 LongEdit 基准均通过包、语义、输出值、样式和未触及部件复读。
- 九份生产者输出均无修复提示，刷新、保存、退出、新进程重开成功。
- 十二份 XLSX 均由 Rust 回归反向确认 `PivotTable1`、字段数量、字段来源和聚合。
- 机器合同固定 9/9 矩阵、文件大小、SHA-256、生产者版本和规范化状态。
- 原 fixture 和用户源文件在全部审计过程中保持不变。

## 6. 保留边界与下一阶段

- 多层行列轴、页面字段、切片器、外部连接和未知扩展继续阻断。
- 原件覆盖与已有目标覆盖继续阻断；本阶段不放宽到原子替换。
- 不承诺 Excel、WPS、LibreOffice 的像素级布局一致，只承诺白名单结构与聚合语义可稳定往返。
- 下一阶段 S8-7E3D 逐项评估 `count/average/max/min/product/countNums` 单度量可靠新副本；每个候选仍需独立通过 3/3 生产者往返。
