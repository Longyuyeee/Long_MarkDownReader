# 1.1.30 计划：轻量表格录入与纠错

状态：功能开发与针对性测试已完成，待完整构建及原包复核；1.1.29 仍是当前正式版。实际结果见 [开发记录](V1_1_30_Table_Entry_Validation_Development_2026-10-21.md)。以下保留原计划。

用户要完成的事：“持续填项目数据，找出日期或数值填错的记录，只修正这些行。”

先复用 TableView 的字段模型、行编辑弹窗、筛选、粘贴、事务历史和导出，不重复已有能力。按顺序推进：

1. 列头右键配置现有类型能准确表达的录入约束；不增加常驻配置表单。
2. 从具名菜单按需打开异常列表，定位稳定行身份与字段，回到原行编辑弹窗修正。筛选和排序后仍修改原记录。
3. 批量修正先预览前后值和受影响行，再作为一次可撤销操作应用；保留隐藏行、用户未保存修改、空值和文本编号前导零。
4. 验证 Table 保存重开及 CSV 导入导出，不静默将原始文本转换成数值。不能可靠表达的规则明确保留，不扩展为完整电子表格校验系统。

完成标准：错误位置可理解且准确；取消和一次撤销不丢草稿；隐藏行不误改；现有视图、导出和全部风格保持。
