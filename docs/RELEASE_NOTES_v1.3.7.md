# v1.3.7：源码替换预览

- JSON、YAML、XML、TOML在现有查找面板按需打开“预览替换…”弹窗，分页查看每处修改的前后内容，原有直接替换继续保留。
- 沿用当前查询、正则捕获组与显式选区范围。确认后只应用对应的局部修改，可一次撤销；显式保存才写回。
- 正文、查询、范围或已检测文件状态变化后停用旧预览，可刷新；切换文件关闭预览。只读文件保留查找，不显示替换入口。
- 没有匹配、无效正则及替换前后相同就地反馈。保留全部风格及正常动效。

每页20处，长文本缩略展示，实际修改完整。预览最多10000个匹配、200万字符替换文字及400万字符原文与替换总长；超出提示缩小范围，不提供部分预览。JSON大文件分段边界保持；跨文件替换和重启后预览持久化不计入本版。

8组组件重建／复用、72组风格／窗口及4个深色窄窗口；上版选区、查找和位置接续各8组／72组回归通过。固定源码完整检查、Rust1464项功能及1项性能、90组/835项安装任务通过；4份保存文件的BOM/CRLF和全文逐字节核对。

NSIS、MSI和SHA256SUMS.txt三份公开附件回下载核对通过。未签名社区版，可手动下载安装；NSIS完成实际安装、手动升级及卸载，MSI完成构建与摘要核对。应用内1.3.6→1.3.7自动更新实际观察独立待完成。
