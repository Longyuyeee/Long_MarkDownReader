# 1.2.15—1.2.16：补齐 XML 日常编辑

状态：仅规划，尚未实施；1.2.13 元素复制及 1.2.14 同级排序已发布。

## 当前代码依据与用户缺口

`src/views/XmlEditorView.vue` 已有元素提纲右键、属性值与文字修改、完整元素复制及上移/下移；`src-tauri/src/formats/xml.rs` 提供准确元素范围、可确认的同级间隔和有界属性值范围。现有属性入口只在元素有属性时出现，只能改值；删除元素、添加属性及移除属性仍需要手动定位源码。JSON 已有对象属性和数组项的增删，因此下一轮优先补齐 XML 的同类日常操作，继续深化基础功能。

| 版本 | 用户需要完成的事 | 交互与完成标准 |
| --- | --- | --- |
| 1.2.15 | 清除不需要的 XML 元素，避免手动框选错删相邻内容 | 提纲右键“删除元素…”，沿已有差异预览确认完整子树及必要空白；应用到草稿，可独立撤销，保存后才写盘 |
| 1.2.16 | 给现有元素补属性，移除无用属性 | 提纲右键进入现有属性弹窗，补齐“新增属性”和所选属性“移除”；名称和值在弹窗输入，沿已有差异预览应用，不增加常驻表单 |

## 1.2.15：元素删除

先支持父级仅由子元素和可确认空白组成的完整子树。保留未删除元素、内部排版、BOM、换行和文件声明，不整体序列化 XML。删除唯一子元素时保留原父级成对写法；根元素不删除，混合正文或外部注释、处理指令归属不明确时在当前操作中解释并定位源码。差异预览本身完成确认，不叠加无必要的二次弹窗。

核对首尾、唯一子元素、同名元素、空元素、内部注释与 CDATA、删除后路径与光标接续。未保存草稿、连续操作、独立撤销/重做、过期结果、来源切换、实际保存失败重试、外部冲突副本和重开均需保留用户内容。

## 1.2.16：属性新增与移除

复用“修改属性…”弹窗，无属性元素也提供入口。新增时校验 XML 名称、重复属性、引号与转义；移除时只删除所选属性及准确可确认的附属空白，保留其他属性顺序、引号和原文。命名空间声明与带前缀属性不能仅凭语法有效就假定语义不变：普通属性优先支持，涉及命名空间定义、前缀绑定或无法准确确认的情况给出局部解释及源码定位，不猜测修复。

实现前需补齐属性名、引号和完整属性的准确原文范围；现有值范围不能直接用于删除整个属性。新增、移除后的候选需重新分析，确认重复属性、结构与命名空间边界，再沿现有草稿预览接续。

核对无属性元素、自闭合与成对元素、多行属性、空值、Unicode、特殊字符、同名冲突、命名空间边界、现有属性值编辑回归，以及与 1.2.15 相同的草稿/保存接续。
