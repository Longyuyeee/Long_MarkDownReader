# UX-50N / EA-4D1 外部 Draw.io 工作区审计

日期：2026-08-07

## 本阶段结论

EA-4D1 已完成 `.drawio` 与 `.dio` 的外部直开、结构化基础编辑和显式保存。用户可从系统文件选择器、Windows 启动参数或格式能力页进入专用 Draw.io 工作区，不需要先建立资料库或导入副本。

外部能力现为：

- `edit`：27 类，只有点击保存并确认覆盖后才写回源文件。
- `preview`：8 类，只读且没有写回入口。
- `import`：8 类，继续要求导入、转换或系统打开。

## 需求与安全边界

- 外部 Draw.io 保留压缩与非压缩多页解析、页面切换、节点标签、几何、颜色、撤销重做和本地 SVG 投影。
- 预览不执行活动内容，不自动打开链接，也不加载外部图片；外链和外部图片只作为源数据与数量提示保留。
- 保存前使用应用内确认提示覆盖外部源文件；草稿只驻留内存，只有保存按钮或 `Ctrl+S` 才写回。
- 外部保存必须通过专用命令重新执行 XML、压缩页、资源协议和结构预算检查，通用文本 writer 不能绕过门禁。
- 读取返回源文件签名；保存前再次校验签名，源文件变化时拒绝覆盖并提示重新打开。
- 未知属性、非目标页面和未编辑单元格继续原样保留；失败路径不改动源文件。
- 安装器关联仍只有 `.md/.markdown`；是否让 Long编辑默认打开 Draw.io 继续由用户在 Windows 中逐项确认。

## 自动化证据

- `check:external-drawio-workspace` 锁定 27/8/8 能力计数、专用 writer、安全解析、引用隔离、外部界面和安装器关联。
- Rust 回归覆盖未授权写入、合法外部保存和外部修改冲突，失败路径逐字节保留源文件。
- 既有 E2B Draw.io 安全合同、UX-34 稳定性与 UX-38E 撤销/显式保存契约继续纳入总审计。
