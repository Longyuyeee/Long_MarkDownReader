# v1.0.9 无签名社区版发布审计

状态：**自动更新重启恢复补丁已实现，质量门与安装包证据待完成**

渠道：`community-unsigned`

发布门禁：`releaseCandidate=false`。在 v1.0.9 完成质量门、安装包证据和真实自动重启验证前，v1.0.8 仅提供手动下载安装；通过应用内更新完成覆盖安装后，需要用户手动重新打开 LongEdit。

## 当前结论

- 官方 `v1.0.7 -> v1.0.8` 托管运行 `31486852139` 已确认下载、SHA-256、覆盖安装和 v1.0.8 二进制写入成功，但自动重启失败。
- v1.0.9 改为安装后延迟启动、进程持续存活检查、失败重试和脱敏重启日志；4 个 Rust 更新器测试及社区更新合同已通过。
- v1.0.8 Release 与历史证据保持不变，不替换公开附件；恢复修复使用新的补丁版本和新的哈希链。

## 发布顺序

1. 完成本地补丁门禁与远端 Quality Gate，冻结产品源码提交。
2. 从冻结提交构建 v1.0.9 MSI/NSIS，记录版本、签名状态、大小和 SHA-256。
3. 在一次性 Windows 上完成安装生命周期，提交候选证据并通过第二次 Quality Gate。
4. 发布 v1.0.9 并远端复核三个附件，再执行官方 `v1.0.8 -> v1.0.9` 12/12 更新链，必须证明自动重启进程可用。

## 发布边界

- 当前公开版本仍为 v1.0.8；v1.0.9 尚未发布。
- 安装包无 Authenticode 商业签名，保留未知发布者与 SHA-256 校验说明。
- v1.0.8 更新链失败只允许本次恢复补丁作为显式例外，未来版本仍要求上一条官方更新链通过。
