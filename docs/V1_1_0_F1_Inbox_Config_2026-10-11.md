## 实现

- LibraryConfig 新增可选兼容字段 `inboxDirectory`，持久化为库内相对目录，空值使用 Inbox，“.”表示库根。旧配置无需迁移即可读取。
- 原生目录选择后，后端规范化路径、确认现有可读目录且在当前库内；越界、父目录跳转、非法名称被拒绝。写配置时再次验证相对路径语法，读取/写入文件继续走 WorkspaceGuard。
- 收集箱和快速笔记共用目录解析函数。修改设置不切换资料库、不清标签、不移动旧资料。配置保存失败恢复原 libraries 状态。
- 已打开快速笔记接收配置事件；仅空闲、无未确认保存请求且目标仍为旧收集箱时跟随新目录；自选目标及保存重试锁定目标不强改，正文不被替换。
- 收集箱保存偏好使用 `__inbox` 语义标识，避免下次打开仍锁住旧目录；兼容原默认 Inbox 绝对路径偏好。用户自选其他目标仍单独记忆，不混同库级设置。
- 脱敏管理备份不导出自定义目录；恢复时默认 Inbox，并明确提示重新设置。没有静默把自定义路径写入脱敏包。
