# C2D DOCX 字符样式与图片元数据隔离编辑审计

> 审计日期：2026-07-27
>
> 阶段范围：单运行基础字符样式与单个正文内嵌图片替代文本
>
> 结论：C2D 已完成；能力仍仅用于隔离预览，未开放 UI、另存或原件覆盖

## 1. 交付范围

C2D 在 C2A～C2C 的包级门禁和稳定目标身份上增加：

1. 为安全单运行文本返回基础字符样式目标；
2. 支持粗体、斜体、单下划线的组合添加、更新与全部清除；
3. 为安全正文内嵌图片返回替代文本目标；
4. 支持添加、更新与清除 `wp:docPr@descr`；
5. 样式和图片元数据均使用独立摘要握手与写后语义复读；
6. 继续复用临时副本、单部件差异和源文件不变证明。

读取报告新增：

- `editableStyleTargets`；
- `editableImageTargets`。

新增隔离预览命令：

- `preview_docx_style_patch_isolated_copy`；
- `preview_docx_image_alt_text_patch_isolated_copy`。

两个命令都只返回审计报告，不返回可保存 DOCX 字节。

## 2. 基础字符样式边界

样式目标必须同时满足：

- 已进入 C2B/C2C 安全文本目标清单；
- 段落只有一个 `<w:r>` 和一个 `<w:t>`；
- 运行属性不存在，或只包含 `w:b`、`w:i`、`w:u`；
- 布尔属性值仅接受标准 `true/false`、`1/0`、`on/off`；
- 下划线仅接受 `single` 或 `none`；
- 不包含颜色、字体、字号、语言、上标/下标、字符样式引用、复杂属性、注释或实体。

写入只生成规范化的 `w:rPr` 基础安全子集。三项样式全部关闭时移除目标安全 `w:rPr`。

## 3. 受限图片边界

图片目标必须同时满足：

- 位于正文顶层，不在表格中；
- 段落解析为单图片块；
- 只有一个 Drawing 和一个图片媒体部件；
- 使用 `wp:inline`，不使用 `wp:anchor`；
- 具有唯一、有效数值 `wp:docPr@id`；
- 图片通过内部 `r:embed` 关系引用；
- 不跟随外部关系。

本批只修改 `wp:docPr@descr`。图片二进制、关系、尺寸、裁剪、旋转、位置、名称、标题、浮动锚点、多图段落和嵌套图片全部保持只读。

替代文本最大 1,024 个 Unicode 字符，不允许控制字符；空文本表示移除 `descr` 属性。

## 4. 摘要与语义门禁

字符样式目标返回：

- 稳定目标 ID、正文块 ID、对象类型和文本；
- `bold`、`italic`、`underline`；
- `expectedStyleDigest`；
- 表格目标继续带零基行列坐标。

图片目标返回：

- 稳定目标 ID、正文块 ID和媒体部件；
- 图片名称与当前替代文本；
- `expectedMetadataDigest`。

提交时摘要必须与当前文件一致。写后重新读取整个 DOCX：

- 样式必须保持同一目标、块、类型、文本和表格坐标；
- 图片必须保持同一目标、块、媒体部件和名称；
- 新样式或替代文本必须与请求完全一致。

## 5. 包与文件安全

- 仅 `word/document.xml` 可以变化；
- 媒体部件逐字节保持；
- 未修改 OOXML 部件继续 raw-copy；
- 全部部件执行修改前后摘要对比；
- 输出写入独占临时文件并同步；
- 临时文件执行字节、摘要和结构重开验证；
- 最后复核源文件字节、摘要和文件签名；
- 临时文件退出时清理。

不存在 `save_docx` 或 `write_docx` 命令。

## 6. 回归证据

Microsoft Word 16 生产者 fixture 已证明：

- 标题可从无运行属性添加粗体与单下划线；
- 已生成的安全运行属性可再次复读并全部清除；
- 陈旧样式摘要与未变化请求被拒绝；
- 带颜色属性的复杂运行不进入样式目标清单；
- 内嵌图片可添加并清除替代文本；
- 图片媒体 `word/media/image1.png` 在前后保持逐字节一致；
- 陈旧图片摘要、控制字符和超长替代文本被拒绝；
- 将内嵌图片改为浮动 `wp:anchor` 后不进入图片目标清单；
- 命令边界临时副本重开通过，源 fixture 字节保持不变。
