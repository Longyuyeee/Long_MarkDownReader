# 文内标签：按主题找笔记

2026-10-14，接续用户反馈“文内标签 tab 用途迷惑，功能摊开且缺少设计”。在 `codex/inbox-experience` 上与收集箱、标签切换、智能集合改进一并开发；公开安装包仍为1.1.0，本轮尚未打包发布。

## 用途与页面安排

文内标签用于把同一主题的笔记找在一起。例如会议记录和项目方案都带有 `#项目`，点击这个标签即可查看相关笔记。标签来自 Markdown 正文，资料库列表汇总已经保存的笔记。

- **当前笔记**：显示文件名、现有标签及未保存状态，点击标签可查看相关笔记。“添加标签”按需展开，说明写入正文末尾；支持带或不带 `#` 输入、拒绝无效名称及重复标签。添加立即更新编辑区草稿和未保存状态，原文保持；用户保存后才更新资料库汇总。
- **资料库全部标签**：显示标签名和笔记篇数，可按名称查找；空状态用具体例子说明如何开始。完整用途说明放入折叠的“标签怎么用？”。
- **相关笔记**：点击标签后在原侧栏显示笔记列表，原文点击打开，当前标签页保持可见。提供返回全部标签、刷新及原有“在文件搜索中查看”入口。
- **状态反馈**：没有打开笔记、非 Markdown、只读文档分别给出简短提示，仍可浏览已保存的标签。汇总/查询失败只在面板内重试，详情折叠；读取失败时保留已经加载的标签列表。

使用现有主题、风格、文件显示及动效变量，保留七个侧栏入口和各套风格。旧添加、筛选、按标签搜索和打开笔记功能全部接续，未增加独立的标签数据库或强制整理流程。

## 修正的实际问题

1. 原 `get_all_tags` 按标签出现次数累计，页面却标为“篇”。现在同一笔记内的重复标签只计一篇，计数与标签查找结果含义一致。
2. 汇总对不存在的资料库原先返回空数组，页面无法区分“没有标签”和“读取失败”。现在根目录不可读时返回可恢复错误，前端提供局部重试。
3. `.md` 和 `.MD` 都能参与标签汇总和查找，与文件类型识别保持一致。
4. 原添加逻辑在不同编辑模式采用不同位置，带 `#` 输入可能重复符号；程序化设置正文后还可能没有同步草稿状态。现在统一写入正文末尾，并同步正文、未保存状态及字数；保存成功重新汇总。
5. 查询回执按资料库及请求序号核对，旧标签结果不能覆盖新选择；切换资料库清除旧汇总和当前选择。
