## 冻结设计与操作契约

[七屏设计](design/mobile-pdf-navigation-v2/index.html)覆盖目录、页面、书签、无目录、读取中、读取失败和章节位置失效。[冻结回执](evidence/mobile-pdf-navigation-task-2026-10-28/design-freeze.json)为 2026-10-28T01:54:23.619Z，源 SHA-256 为 1a3b1c644d11c2b716f111d04c210dbe356d80f1968947c019977fe5566ec9e9。基线完成后，先查看七张冻结图再修改运行时代码；后续修复未改设计源、时间或冻结图。

设计中的六张缩略图由同一真实测试 PDF 的原生 canvas.toDataURL 导出，记录源文件和 PNG 摘要；没有重画页面、替换内容或编辑原截图。保留旧 v1 设计作为历史，当前使用新 v2 目录。

- 导航铺满当前 PDF 工作区，显示当前文件、总页数和三种导航方式。原阅读控件隐藏且不可交互，底层阅读器保持挂载和原尺寸；去掉旧的背景缩小与遮罩布局，取消导航不引起阅读区域重排。
- 页签切换只改变当前导航方式，不增加返回层级。目录折叠、分页显示数量、各方式的滚动与正文焦点分别保留；点击当前页签不会重置位置。缩略图批次继续停留在用户浏览处，明确“回到当前页”才重置。
- 关闭导航再打开，恢复本次阅读会话中的导航方式、缩略图批次、滚动和可恢复的列表／输入焦点。导航状态不承诺跨关闭 PDF 或进程重启保留；原阅读页、缩放和位置仍由既有引擎持久化。
- 普通返回、继续阅读及帮助不改变阅读页；只有明确章节、缩略图或书签选择才跳转。帮助先关闭，书签删除确认先取消，再返回阅读器。完整 PDF 阅读位置、缩放、源码字节与其他笔记草稿保持原样。
- 页码表单和查找在导航下方保持挂载、隐藏并不可交互。取消导航后仍保留未确认页码和查找词，再返回只关闭其自身一层；明确选择新页面才收起这些工具回到阅读。它们本身仍使用旧界面，下一轮再分层。
- 书签面板首次进入后保留挂载，未确认名称、选区与焦点可跨页签／导航关闭继续；切换或关闭前沿用原本机草稿保护。保护失败留在原任务，保留输入，不能直接离开。现有书签编辑／删除表单没有在本轮重设计。
- 无目录如实给出页面入口，不从正文伪造目录。读取失败可重试或查看页面；位置失效显示具体原因，阅读位置不变。命名目的地和本地页引用沿用既有解析，外部动作继续禁用，返回拒绝迟到跳页。
- 目录预算仍为最多 500 项、13 层，缩略图每批最多六页并串行渲染。隐藏导航时卸载缩略图画布，继续使用原取消和释放逻辑；预览失败仍能打开对应页面。
- 删除重复的当前位置条，底部保留“继续阅读”动作。一般解释在问号，具体空状态、受限原因和失败仍可见。短视口让文件信息行让出空间，保留可滚动正文及返回动作；大字、深色与实际滚动另验收。

改动集中在 MobilePdfNavigation.vue 与 MobilePdf.vue 的导航宿主集成、帮助文案和一个专项命令。目录／目的地／缩略图算法、PDF 读取／渲染／手势／连续阅读引擎、书签与批注存储、共享 App、全局样式、存储会话和依赖均未修改。常驻 PDF 底栏仍是现有布局，后续继续收整。

## 实页核对与修复

[七屏并排对照与适配实页](evidence/mobile-pdf-navigation-task-2026-10-28/comparison.html)包含 13 张最终导航原图和一张旧导航短屏回归原图，均已逐张审阅。标准 390×872 截图仅去掉真实 28px 桥接提示条得到 390×844；大字时提示条自然换行，旧回归保留完整视口。没有移位、隐藏实际内容或补画截图来贴图。

[量测结果](evidence/mobile-pdf-navigation-task-2026-10-28/comparison.json)：252 项坐标属性最大偏差 0px，252 项字体、字重、行高、字距和颜色属性一致。三类导航图标的 SVG 路径与冻结源逐项断言，帮助与返回图标为 22×22。保留真实焦点、按下反馈和 PDF 栅格差异，不声明整屏逐像素相同。

[首个七组通过版本](evidence/mobile-pdf-navigation-task-2026-10-28/before-alignment-report.json)的[实际目录](evidence/mobile-pdf-navigation-task-2026-10-28/before-alignment-outline.png)仍有原触发按钮的系统点击色块留在新页标题中，[页面图标](evidence/mobile-pdf-navigation-task-2026-10-28/before-alignment-pages.png)也比冻结稿多了文字线条。这两处坐标／字体量测没有发现，实际看图后才修复：在正式导航与触发器范围内使用透明系统点击高亮及自身按下反馈，三类图标统一使用冻结路径。不是截图前模糊焦点或修改冻结稿。

测试适配的失败也保留：[首次命名跳页检查](evidence/mobile-pdf-navigation-task-2026-10-28/destination-wait-failure-report.json)在异步目的地尚未关闭导航时读取了旧页码，改为等待真实任务关闭、显示和目标阅读记录；[旧回归失败](evidence/mobile-pdf-navigation-task-2026-10-28/legacy-background-failure-report.json)仍通过无障碍角色寻找已隐藏的后台按钮，改为核对后台栏隐藏且 inert。旧回归显式选择目录、先返回阅读再切换主题，更新真实提示条裁切；历史 v1 对照不再作为当前界面的通过依据，原资产不改。九组任务均保留。

截图准备脚本最初有多余闭合括号，语法检查在浏览器启动前失败；修正后才冻结和实施，没有把该准备错误计成应用验证结果。两个实施前基线中，第二次另外导出原生缩略图 PNG；原始基线文件继续保留。
