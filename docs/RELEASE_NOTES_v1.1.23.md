# LongEdit v1.1.23

贴进笔记的图片与附件，现在更容易找到、定位和修复。

- 文件栏显示普通图片目录、`*.assets` 及软件插图使用的 `.assets`；搜索、集合与移动引用检查跟随同一规则，内部配置继续隐藏。
- 文件右键“更多操作 → 管理附件…”或文档操作菜单，查看当前 Markdown 草稿引用的本地文件、实际位置、行号与失效状态；任意文件可查找引用它的已保存 Markdown 笔记。
- “更换引用…”可选择现有文件修复路径。库外文件保留原件，防覆盖复制到附件目录；只将新引用应用到草稿，可撤销，仍需保存。原附件、共享来源和其他正文保留。
- 切换文档、继续输入、正在保存或整理文件时，拒绝迟到替换；读取失败只在弹窗中提示，可关闭继续操作。移动、改名和按项还原继续使用已有文件事务。

引用管理本轮支持普通相对 Markdown 图片、文件链接、引用式链接及可可靠识别的 HTML 路径，单篇正文最多 2 MiB；引用位置检查限已保存 Markdown，不代表所有格式或其他窗口草稿的完整引用审计。没有结果不表示可删除，本版不自动清理附件。取消更换后已复制的附件副本仍保留。

Windows 社区版提供 NSIS 和 MSI，签名状态沿用 community-unsigned。可手动下载安装；真实应用内升级观察另外记录。[使用方法](https://github.com/Longyuyeee/Long_MarkDownReader/blob/main/docs/Attachment_Management_User_Guide.md)。
