# F1 单文件移动引用影响清单

2026-10-11，接续 `3c5bcd5a`。本步只读预检，无 UI 修改、无正文改写、无执行入口。

## 实现

DependencyReport 新增 moveImpacts，并在归档预检存在目标路径时调用 report_move。对已定位的出链，以目标文档目录重新解释原链接，比较“应继续指向的位置”和“不改正文时的路径”；指向自身的链接，其应指向位置随文档移动。

状态区分 rewrite_required、same_destination、different_target、needs_review。入链只有解析路径确实匹配来源时列为需改写；文件名相同但定位到别处标为 different_target，候选本身仍保留。无法准确解析、缺失、Wiki/PDF 扩展等保持 needs_review。

报告包含原证据、方向、期望位置和原链接的新解释位置，给后续用户确认与改写策略提供依据，不生成可直接执行的字符串替换。

## 审计边界

仅按单文件移动预测，不处理同批多个引用对象同时移动，不锁定外部进程，也不承诺语法覆盖完整。same_destination 仅指可比较路径相同，不代表文件身份或内容未变；different_target 不是删除候选或解除门禁的许可。

没有修改正文、附件或引用者文件，没有处理跨库入链；草稿/保存互斥与安全写回尚未接。complete=false、canExecute=false 均保持。现有 dependency_candidates 仍保守阻止，不把新增分类当执行许可。未进行大库性能或 UI 验收。

## 验证

新增两个真实临时目录测试：移动目录并改名时图片出链、自身链接和确切入链均需改写，正文及目标不变；相邻目录下共享上级引用保持目标、同名不同文件不误判确切入链、Wiki 保留待核对。最终 `cargo test --locked --manifest-path src-tauri/Cargo.toml --lib archive -- --nocapture`：61 passed / 0 failed（新增 2 项，总数含既有名称筛选附带的 2 项压缩包测试）；git diff --check 通过。
