# 主编辑区高频操作

2026-10-13，用户确认 [高频操作静态方案](design/v1.1.0/high-frequency-actions-r1/main-editor.png) 后实施。保留新版布局，利用文档操作行与格式栏的空位展示精选高频入口。

Markdown 直接展示撤销、重做、标题、加粗、斜体、引用、无序/有序/任务列表、代码块、行内代码、链接和表格。“更多格式”继续保留表情、删除线、分割线、实时 Table 图表、代码主题、文章背景、AI、双栏预览、预览和原生模式切换。其右侧保留编辑模式（所见/IR/源码）、正文宽度、导出和历史快捷项。

文档标题旁提供收藏/取消收藏，右侧提供预览/返回编辑、专注、AI 辅助、参考、保存与文档操作。收藏复用原收藏列表；预览触发 Vditor 原有按钮，只观察该按钮的 class 以同步菜单和快捷项，不观察正文。编辑器重建和卸载清理观察器。AI 按钮保留鼠标选中的文字并打开原操作面板，不新增请求或替换策略。专注后状态栏保留明确的退出入口。

原文档操作菜单、七个单行侧栏入口、收集箱、刷新、新建内的文件夹/今日笔记、资料库切换和文档标签保留。宽窗格式工具保持一行；较窄编辑区域自动换行，不再按 720px/520px 隐藏模式、宽度或整个快捷组。极窄窗口给关系浮动入口留出空间，避免覆盖历史按钮。控件沿用现有主题和风格令牌。

`test-high-frequency-actions-browser.mjs` 已核对收藏、三种编辑模式下的预览/返回与未保存内容、原生菜单状态同步、选中文字后的 AI 面板、专注退出，以及六种风格在 1280/1024/480/320px 的 24 组布局。检查按钮是否可见、越界或被其他元素覆盖，查看实际截图；证据位于 [实际页面](evidence/v110-high-frequency-actions/results.json)。Vditor 模式转换的既有 Markdown 序列化会规范末尾空行，预览检查不将该格式差异计为内容丢失；专注前后按当时草稿逐字检查。

原资料库外壳和文档快捷项流程、8 项模式切换测试、608 处组件注册检查、最终 `npm run build` 均通过。查看 [当前主界面](evidence/v110-high-frequency-actions/main-editor.png)。浏览器使用实际 App/LibraryMode/Vditor 和隔离 IPC，不能作为原生导出/保存或安装包验收证据。本轮不涉及后端保存、公开版本号或发布。
