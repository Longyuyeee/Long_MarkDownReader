## 已完成

- 新增 `useResponsiveInspector`，YAML、XML、TOML 共用 760px 断点和视口跨越同步逻辑。
- 三个编辑器桌面端均可主动收起/显示结构面板，编辑区会稳定占满剩余空间。
- 窄屏默认隐藏结构面板；用户点击统一的右侧面板图标后切换到结构/诊断视图，不再把源码区压缩成狭窄列。
- 窄屏工具栏、标题宽度和状态栏信息密度已收紧，长文件名使用省略显示。
- 保存按钮统一显示“保存中 / 保存 / 已保存”，文档状态使用 `aria-live` 播报。
- 现有安全保存、非法源码显式确认、外部修改冲突保护、源码事实源和分析预算均未改变。

## 边界

- 本批不统一所有编辑器的内部领域控件，也不改变任何格式能力等级。
- 响应式结构面板状态只属于当前页面会话，不写入配置。
- D1 尚未整体完成；本批只关闭 YAML/XML/TOML 的高频一致性缺口。
- 真实代码签名仍不可用，R5N 保持 fail-closed。
