# P1-A3A 图片裁剪、压缩与隐私后端审计

审计日期：2026-08-15

阶段状态：后端完成，右侧交互待接入

## 需求对齐

本切片继续服务日常图片基础编辑，但不提前扩写公开 UI 能力。所有操作仍作用于资料库内 PNG/JPEG/WebP/BMP 的新副本；源文件、外部图片、GIF、ICO 和 AVIF 的边界不变。

## 新增安全子集

- 裁剪发生在 EXIF 方向归一、用户旋转和翻转之后，缩放之前；坐标加法使用溢出检查，区域必须完整位于当前像素边界内。
- JPEG 输出支持 `1–100` 质量，缺省为 `85`；质量参数用于非 JPEG 输出时明确拒绝，避免误导用户。
- 解码阶段读取 EXIF Orientation 并在像素层归一；输出全部从解码像素重新编码，不复制 EXIF、GPS、注释或其他容器元数据。
- 保存报告新增 `jpegQuality`、`orientationNormalized` 和 `metadataRemoved`，继续沿用源摘要、原子新建、落盘复读和源文件不变验证。

## 验证

- `cargo test formats::raster_image --lib --locked`：5 项通过。
- 合成带 EXIF Orientation=6 的 2×3 JPEG 被归一为 3×2，裁剪后 JPEG 输出不再包含 `Exif\0\0` 标记。
- 越界裁剪、部分缩放尺寸、超预算尺寸、非法 JPEG 质量、非 JPEG 质量参数及只读输入/输出格式均被拒绝。
- `npm run check:image-transform-copy` 锁定裁剪、质量编码、方向归一、元数据清理和保存报告合同。
