# Post-v1.0.15 M3B-1 语义缩放与社区远景审计

日期：2026-08-28

阶段：M3B-1

发布候选：否

## 1. 原始需求与实现边界

本阶段直接承接 `Post_v1.0.15_Professional_Capability_Enhancement_Roadmap_2026-08-25.md` 的 M3B“远景显示社区、中景显示关键节点、近景显示标题、状态和证据”，并执行 M3B-0 冻结的最小范围。实现必须复用 M3A 的稳定 Louvain 社区 ID、对象语义色和真实过滤子图，不能生成与事实无关的背景光斑或另建视觉专用社区事实源。

本次只完成密度感知的远/中/近层级、社区间聚合连接和社区进入/返回。中近景成员轮廓、路径曲线/平行边/标签/方向流动、缩略导航、聚类镜头、状态外环及持续帧收口仍属于后续 M3B/M3C，不在本阶段扩大完成范围。

## 2. 语义层级合同

层级不再只看固定缩放值，而使用 `effectiveZoom = zoom / max(1, sqrt(visibleNodeCount / 80))`：

| 层级 | 判定 | 显示合同 |
| --- | --- | --- |
| 远景 | 有效缩放 `< 0.42` | 隐藏单节点噪声，显示稳定社区摘要、节点数、内部联系数及社区间聚合连接 |
| 中景 | `0.42 ≤` 有效缩放 `< 0.85` | 保留全部节点身份与关系，只为按度数、修改时间和稳定次序选出的 8～28 个关键节点及当前焦点显示标题 |
| 近景 | 有效缩放 `≥ 0.85` | 显示全部当前节点标题和对象字形 |

17 节点固定输入在 100%、81%、39% 分别进入近景、中景、远景；纯函数门禁同时验证 1,000/5,000 节点在 100% 下会因密度压力进入远景，而不是重现默认比例标签爆炸。思维导图保持原层级渲染；路径、邻居、社区筛选和比较继续以真实可见子图为边界；SVG/PNG 导出仍导出真实节点与边，不把社区摘要伪装成用户数据。

## 3. 社区远景表达与操作

社区摘要继续使用 M3A-5 的成员派生稳定 ID。位置以成员质心为锚点，并通过确定性重叠分离保证同一输入得到同一几何结果；颜色取社区占优对象类型的统一语义色，连线宽度表达跨社区关系数量，不增加装饰光晕。摘要同时提供 Canvas 命中入口和键盘可达的底部社区按钮；进入后复用既有社区筛选、适合窗口和返回全部社区流程。

为避免新视觉层反向增加 M3C 风险，社区几何在布局/缩放有效变化时节流缓存，不在每个持续动画帧重新执行全量聚合。该措施只防止本阶段新增回归，不代表持续帧、Worker 或大图稳定时间已经完成。

## 4. 首次审计发现与纠偏

第一轮 1280×800 的三主题证据显示层级与社区进入正确，但人工检查 720×680 截图发现：页面虽然没有横向溢出，社区圆仍沿用宽屏相机偏移，部分摘要被裁到画布右侧；底部状态栏的“节点/连接”发生拆行。原结构化门禁只检查了导航条存在和页面宽度，没有捕捉画布对象边界，属于验收覆盖偏移。

现已增加响应式社区相机重定位：按语义图例和宽屏详情面板计算安全显示区域，窗口变化或进入远景时重新居中摘要，但不修改底层节点坐标、选择或用户资料；状态栏改为单行可滚动。Canvas 同时暴露“全部社区摘要在画布内”的只读状态，三档窗口门禁缺一即失败。重跑后的 720×680 暗色、浅色和高对比截图中五个社区均完整可见。

提交前总回归还发现 M3B-0 历史基线脚本把“当时存在的固定阈值”绑定为当前代码必须永久保留，导致本阶段正确替换阈值后误报。现已纠正为验证 M3B-0 冻结策略、原始桌面证据及其到 M3B-1 的阶段链；不修改历史事实，也不允许历史门禁阻止路线正常推进。

## 5. 算法与真实桌面结果

纯函数门禁验证：17 节点三层判定、1,000/5,000 节点密度远景、关键节点度数优先、两社区聚合边计数、社区内部边计数、重叠分离和重复构建几何一致。

真实 Tauri 使用 17 节点/17 边跨格式资料库，在 `dark`、`white`、`contrast` 三主题及 `reduced` 动效偏好下分别完成：

- 近景 100% → 中景 81% → 远景 39%，状态标识严格为 `near,middle,far`；
- 远景显示 5 个社区摘要和 5 个键盘入口；进入首个 4 节点社区后自动回到近景，并可返回远景；
- 1280×800、1000×700、720×680 均无页面级溢出，远景导航存在且五个 Canvas 摘要全部在边界内；
- 每个主题运行时错误为 0，审计前后资料库 SHA-256 一致并成功返回资料库。

证据位于 `docs/evidence/post-v115-m3b1-semantic-zoom-community-overview/`，不包含用户内容，`releaseCandidate=false`。全部主题和关键宽窄屏截图均已人工复核。

## 6. 结论与接续点

M3B-1 已满足本阶段退出条件，但不把整个 M3B 或 M3C 宣称完成。下一最小阶段冻结为 **M3B-2 社区轮廓与语义层级**：在中/近景围绕成员建立克制、主题适配的社区轮廓或色带，使远景主题身份在展开后连续可辨；不得移动真实节点、遮挡关系或用无语义光斑替代轮廓。完成后再根据实际差异选择路径表达或导航镜头。
