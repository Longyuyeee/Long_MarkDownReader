# C1C 图谱关系生命周期审计

审计日期：2026-07-31

阶段状态：已完成

发布状态：`releaseCandidate=false`

## 本批目标

在显式关系已有原文新增、删除和来源证据的基础上，为“共同标签”推断关系建立确认、隐藏和恢复生命周期，并让判断结果同时影响文件关系上下文、知识图谱、动态集合和健康治理。

## 已完成

- 文件关系上下文会把共同标签关系标为“待判断”或“已确认”。
- 待判断关系可确认或隐藏；已确认关系可改回推断；已隐藏关系进入折叠恢复区。
- 判断结果写入知识库内 `.longedit/graph-relation-decisions.json`，使用相对 Markdown 路径，不写入应用配置，也不修改 Markdown 事实源。
- 已确认且当前仍有共同标签的关系会进入全局/局部图谱，因此可参与动态子图智能集合计算。
- 已确认关系两端不再被健康治理误报为孤立文件；隐藏或恢复为推断后，不再影响图谱与孤立文件判断。
- 元数据使用可靠写入，并限制为 512 条、512 KiB、Markdown 相对路径和 `shares-tag` 白名单关系。
- 已删除或移动文件形成的过期记录会被安全忽略，不会阻断其余关系上下文。
- 损坏、越界、重复或未知状态的元数据会明确报错，不会静默接受。

- C1C 完成后的全量 Rust、契约与差异检查结果记录在本次提交中。

## 边界

- 生命周期仅用于推断关系。双向链接、Frontmatter、PDF 批注、Canvas/OPML/PPTX 结构关系继续由原始文件维护。
- “确认”不会把推断关系伪装成 Markdown 显式链接；共同标签消失时，该关系不会继续进入图谱或健康计算。
- sidecar 属于知识库本身；迁移知识库时应连同 `.longedit` 目录迁移。应用管理备份不会打包知识库内容。
- 当前没有真实代码签名证书，R5N 外部门禁继续保持 fail-closed，本批不改变 RC 状态。
