# v1.3.14：从文件链接回到来源

- 从 Markdown 本地文件链接、章节链接或关系页“我提到的”打开资料后，可在文档操作菜单或命令面板选择“返回链接来源”。没有有效记录时隐藏入口。
- 返回原标签，恢复原编辑模式、选区和阅读位置；复用已经打开的目标标签，保留两边的未保存内容与各自的撤销重做记录。
- 拖动标签调整顺序时保留返回记录，来源与目标的草稿继续独立接续。
- 支持按原有方式打开结构化文件、文本及其他已支持的资料；来源有效改名后沿用新位置，关闭或重新读取来源后停用旧记录。
- 文件暂时不可用时保留当前可操作页面，可修复文件位置后重试。导航只切换位置，不保存、不替换正文，保留全部风格与正常动效。
