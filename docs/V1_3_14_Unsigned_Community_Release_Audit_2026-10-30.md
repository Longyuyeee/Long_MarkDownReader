# v1.3.14：从文件链接回到来源

当前开发目标：`1.3.14`；当前运行时版本：`1.3.14`；当前公开版本：`1.3.13`。当前阶段：**v1.3.14 链接来源返回候选**。

本版深化现有文件链接：从 Markdown 正文的本地／章节链接，以及关系页“我提到的”中的双向链接打开主编辑区资料后，在现有文档操作菜单与命令面板按需出现“返回链接来源”。普通切换标签不记录历史，不新增常驻导航、说明卡片或确认步骤。

返回复用来源标签，恢复有效的编辑模式、完整选区与滚动位置。两边未保存内容继续保留；Markdown 编辑器复用时按原标签隔离撤销重做状态，并同步尚未经过输入回调的最后输入。只有显式保存写回正文。

记录绑定实际标签对象及资料库，最多保留20处。来源改名而正文仍一致时沿用新路径；关闭、重新读取或正文不再匹配时停用旧位置；迟到的打开请求核对当前文件、编辑模式和正文。来源文件暂时缺失时只显示局部提示，当前页面继续可操作，可恢复文件后重试。参考区及文内返回／前进继续使用原有入口。

保留全部风格、正常动效和已支持格式的打开方式。本版不含跨资料库历史、关闭标签后的草稿重建、跨文件前进或自动保存。

候选验证进行中，尚未发布；通过后可手动下载安装。community-unsigned（未签名社区版），企业releaseCandidate=false。NSIS实际安装、手动升级与卸载和MSI构建摘要分别记录；应用内1.3.13→1.3.14实际更新观察独立pending。不操作用户当前本机安装程序。

本次安装复查选择17组／166项受影响工作流、23类当前报告。80类未受影响报告和未变更Rust的完整功能结果独立引用已发布1.3.9基线，不计为本版重跑；每次当前安装包仍实际编译。完整107步源码质量检查交由同一次冻结构建执行。
