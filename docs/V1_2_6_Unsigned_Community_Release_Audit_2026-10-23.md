# v1.2.6：表格列位置调整

当前开发目标：`1.2.6`；当前运行时版本：`1.2.6`；当前公开版本：`1.2.5`。当前阶段：**v1.2.6 表格列位置调整候选**。

## 当前范围

按 1.2.5—1.2.6 既定路线，沿列标题右键提供向左、向右移动，边界方向禁用，保留录入规则入口。字段的标题、全部行值、推断类型与稳定 ID 一起移动；规则、排序和其他视图继续引用原字段，所有视图的列宽按字段身份重新排列。冻结仍表示最前 N 列，不增加常驻按钮、表单或说明。

## 草稿和撤销

列移动与新增列接入现有数据历史，每次操作可一次撤销重做。单元格、填充、行插入及复制使用原身份，不因列位置变化串列。新增列撤回时清理相应视图引用，重做恢复仍未被用户另行修改的配置；保留后来主动选择的字段和其他列宽。延迟类型刷新改为跟随字段 ID，避免移动后更新原来的偏移。

操作先进入当前草稿，沿显式保存入口写回；保存中的继续新增、失败重试、外部冲突及同文件定位接续原有保护。菜单保存原来源和草稿上下文，来源变化后停止旧目标。

## 开发检查

纯规划、实际生产回调、交错历史、各视图配置和延迟类型刷新，以及浏览器中的大、小窗口六种风格检查分别记账。浏览器使用真实 Vue 页面并明确模拟原生 IPC；Windows 原包检查尚未完成，不能以浏览器替代。本地 7 项生产规划及回调检查、2 项安装驱动和证据协议检查通过；前端构建、完整开发状态检查和生产依赖审计通过（生产依赖 0 项）。列操作 8 组、既有行操作 9 组、填充 9 组、批量粘贴 8 组及保存接续浏览器检查通过，[页面记录](evidence/v126-column-order-development/browser/result.json)。新增列撤回后的视图配置使用独立快照，重做不会覆盖用户后来选择；该情况由实际生产函数检查覆盖。

## 发布边界与后续

范围限现有 Table、CSV/TSV，不扩大 XLSX、公式计算或格式保真承诺。`community-unsigned` 未签名社区版，企业 `releaseCandidate=false`；固定源码构建、同包实际安装、保存重开和公开附件核对通过后发布，用户可手动下载安装。1.2.5→1.2.6 应用内自动更新实际观察独立 pending，手动升级与该观察分别记录。

本版交付后，1.2.5—1.2.6 路线完成，再从已实现的基础功能中核实下一轮需要深化的任务，写入路线文档，不把规划写成已完成功能。
