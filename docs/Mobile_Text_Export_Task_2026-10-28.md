## 已实现的操作

- 独立核对页显示来源文件与资料库、输出名称、格式和UTF-8体积。“查看完整文字”进入二级只读预览，导出动作固定在底部。
- 普通预览保留本次的选区及滚动；长文复用已有分段阅读、查找和段落定位，返回核对后再进入仍保留查询及所在段。空内容明确显示，仍可导出零字节副本。
- 返回顺序为说明 → 当前预览 → 核对或结果 → 原文档；预览从结果进入时返回结果。只读核对、预览和恢复查看不重建快照，不清空草稿。
- 成功后有独立结果与“完成，返回文档”，仍能查看同一份文字。完成后不重复提交；关闭并重新进入才捕获新快照。
- 浏览器只报告“已发起下载”，提示到下载记录核对；Android沿用原有回读成功后报告结果。Android显示“建议文件名”，不把默认名称误报为用户在系统选择器改名后的实际名称，也不编造落盘路径或打开文件能力。
- 处理中阻止重复提交与退出，取消回同一核对页。失败保留文字和同一恢复身份，可查看保存恢复记录后回来重试；从结果进入恢复也返回同一结果。
- 导出保护失败不再声称“已保护的内容”。确实发起下载但清理恢复记录失败时，保留明确状态及查看入口。

`textExport.ts`、存储、阅读预算、分段阅读、恢复组件及任务位置协议均未改动。原文、私有草稿、Markdown引用和已有恢复记录继续由原协议保护；导出不等于保存原文档。
