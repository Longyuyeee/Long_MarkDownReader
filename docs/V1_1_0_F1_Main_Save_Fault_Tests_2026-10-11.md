## 测试范围

新增 `scripts/test-main-text-save-lifecycle.mjs`，从 LibraryMode.vue 提取真实 saveCurrentFile，通过 TypeScript 转译在隔离上下文执行。IPC 使用可手动完成/拒绝的 Promise，标签、编辑器和提示使用测试替身；updateTabFromTextSnapshot 仅模拟正文、dirty 和签名更新。因此是保存动作的异步回归测试，不是 Vue 组件挂载、真实 Vditor、原生文件写入或慢磁盘验收。

8 个用例通过：

1. 从历史提交 `5251c5d7` 加载修复前动作，复现后续输入被覆盖，以及另一文档被旧回执写入。验证测试环境确实能暴露旧问题，而非仅检查实现文本。
2. 延迟回执期间继续输入，保留 dirty；签名更新后再次保存提交新正文及新签名。
3. 等待期间删除全部正文，空字符串仍作为未保存草稿保留。
4. 切换其他标签，不向新编辑器写入旧回执。
5. 销毁或替换编辑器，回执不访问失效工作面，保存计数释放。
6. IPC 写入失败，保留草稿/旧签名、显示错误；随后主动重试成功。
7. 同一实例保存中再次保存不发第二份旧请求，提示稍后重试。
8. 等待期间切换资料库，后续 Git 提交仍绑定原库。
