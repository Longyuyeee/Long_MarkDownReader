# 模板写作与文章交付

在资料库主编辑区完成“套模板—写正文—插入图片—导出交付”，不需要把快速笔记保存后再归档。

## 使用模板

“新建”仍可直接创建空白笔记或沿用此资料库的默认模板。需要先填写文章名称和字段时，选择“填写模板后新建…”，核对保存目录、标题和填充预览，再点击“在此新建”。已有同名笔记会追加序号，不覆盖。

在“新建 → 笔记模板 → 管理模板…”中编辑模板，或在文档操作中把当前草稿保存为模板。原有 `{{title}}`、`{{date}}`、`{{time}}` 继续可用；自定义字段写为 `{{param:作者}}`。字段值不会再次展开变量，未知变量保持原样。最多 16 个字段、每项 500 字；模板和填充结果上限 256 KiB。快速笔记保留简单正文编辑，可直接修改占位文字，不强制弹出额外流程。

## 插入本地图片

在编辑器“更多格式 → 本地图片…”选择图片，也可粘贴位图，或拖入主编辑区。图片复制到当前 Markdown 旁的 `.assets` 目录，正文使用相对引用；相同内容复用，不移动或删除共享原图。一次最多 16 张，单图不超过 8 MiB。

插图只修改草稿，仍须手动保存正文。插入期间切换文档或继续修改导致原快照失效时，不会把图片塞进另一篇笔记；已经复制的资源保留在原目录，界面会说明。

## 导出给别人阅读

在主编辑区点击“导出”，先看实际交付预览。此处导出当前草稿，不是上次保存的旧正文，也不会替你保存原稿。

- “独立 HTML…”：本地位图随文件携带，适合复制到另一目录阅读，不需要同时复制整库或搬走共享图片。使用新文件名；已有文件不直接覆盖。
- “Markdown 仅正文…”：只导出 Markdown 文字，图片仍依赖原相对路径。移动到其他目录后，需要另行保持对应资源布局；需要开箱可读的交付文件时建议选 HTML。
- “打印 / PDF…”：请求系统打印，在打印界面选择打印机或另存 PDF，并确认输出位置。取消不会改动原稿；看到打印框不代表 PDF 已生成，应检查实际文件。

需要可搜索、复制的 PDF 时，在浏览器打印预览的目标中选择“另存为 PDF（Save as PDF）”。它与 Windows 的“Microsoft Print to PDF”虚拟打印机不是同一个选项；不同驱动可能把文字变为不可检索的轮廓，生成后应重开核对。若预览页眉或页脚出现日期、软件标题或本地来源路径，不希望交付这些信息时，在“更多设置”中关闭“页眉和页脚”，确认预览后再保存。

导出最多 128 个不同图片引用，单图 8 MiB、本地图片合计 32 MiB；正文上限 8 MiB，独立 HTML 上限 64 MiB，重复内嵌图片也会增加交付体积。缺图、库外路径、超限和写入失败会明确提示，不会假装交付成功。在线图片不自动下载，预览中保留未携带说明和链接。

文字、列表、表格和本地位图按白底文章排版交付，保留显式字体、字号、行距等设置，不照搬软件界面的背景风格。可执行脚本、编辑器临时地址和交互嵌入不交付，复杂交互图请核对预览。HTML 使用阅读电脑已安装字体和后备字体，不另行打包字体文件；PDF 的字体和文字保留取决于所选打印引擎，应在生成后核对。应用内来源链接仍需要 Long编辑与原资料库。原稿、共享资源与其他文档不会因导出被改写。
