# F1 快照绑定与内存编辑预览审计

2026-10-11，接续 `3ca08642`。本步仅后端证据及内部纯内存预览，无 UI 修改或文件写回。

## 用户风险与实现

扫描后用户可能修改正文其他位置，即使链接文字不变，旧范围也不能继续使用。依赖证据现附加从同一份扫描文本计算的整文 SHA-256；内部 archive_edits::preview 要求文档路径及整文摘要一致，并再次解析确认目标范围和原文，拒绝过期证据与伪造范围。

预览按位置排序，完全相同的编辑去重，不同替换落在同一位置或范围重叠则拒绝。只接受受限 URL 编码字符集合，输出后再次解析核对每个替换目标与位置，避免把语法破坏当成成功。输入/输出均限制 2 MiB、提案最多 20000 项，输出长度在构造前检查。中文、换行、标签及外围语法保持不变。

## 验证与审计边界

新增 3 项测试覆盖：中文/CRLF/重复目标/尖括号图片及编辑去重；正文其他位置同长度变化、错误文档、冲突替换；错误 UTF-8 边界、原始中文目标、破坏语法、实体解码和无精确范围的引用式链接拒绝。没有降低既有断言。

验证命令：`cargo test --locked --manifest-path src-tauri/Cargo.toml --lib archive -- --nocapture`。最终回归 69 passed / 0 failed；本模块新增 3 项，总数含既有压缩包测试。`git diff --check` 通过。

本模块尚未接命令或 UI，替换目标由内部调用者提出，不自动生成归档目标路径，不保证路径语义/百分号编码正确。摘要证明输入内容匹配，不是文件身份锁，也不覆盖校验后外部进程修改。未实现草稿协调、事务写回、编辑计划持久化或完整恢复。大量提案匹配仍为线性嵌套查找，未做大库性能验收。complete=false、canExecute=false 和既有依赖门禁不变。
