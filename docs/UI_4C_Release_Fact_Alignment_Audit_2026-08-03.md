# UI-4C 发布事实对齐审计

日期：2026-08-03
当前阶段：UI-4C1 完成，下一步进入 UI-4C2 补丁发布级全面验证

## 审计结论

当前产品版本、Tauri 配置和能力矩阵均为 `1.0.1`。`shared/v1-community-release-policy.json` 证明 `community-unsigned` 渠道的 GitHub Release 已发布，因此面向用户的正确状态是“v1.0.1 社区版已发布”。

能力矩阵继续保持阶段 `R2` 和 `releaseCandidate=false`，其含义是企业签名发布候选仍需单独评估，不代表已经发布的无签名社区版仍处于收口中。原格式能力页将这两个事实混为一谈，显示了过期的“R2 收口中”。

## 本步修改

- 格式能力页从社区发布政策读取公开状态，显示“v1.0.1 社区版已发布”。
- 页面 tooltip 继续说明社区无签名渠道与企业签名发布候选相互独立。
- 新增 `check:ui4c-release-fact-alignment`，校验 package、Tauri、能力矩阵、社区发布回执、页面配置和审计文档。
- 新门禁加入 `ci:patch-release`，阻止版本和发布文案再次漂移。

## 需求对齐

本步不扩大“完整 Excel 等价编辑器”或新格式能力承诺，只修正已完成能力与真实发布状态的公开表达。41 类格式的能力等级、有限能力、外部依赖和安全保存边界保持不变。

## 下一步

UI-4C2 执行完整补丁发布门禁，复核当前开发审计、公开文档和版本升级范围。全部通过后再决定是否进入 `1.0.2` 版本提升与发布准备；未通过时记录明确阻断项，不提前修改版本号。
