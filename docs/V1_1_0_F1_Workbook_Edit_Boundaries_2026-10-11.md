# F1 工作簿快捷键及剪贴板边界

日期：2026-10-11；基线 `c824603a`；未封板。

## 实际问题与修复

原有保存期间禁用公式栏和撤销/重做等按钮，但全局键盘处理未检查 saving。后台实际 WorkbookView 中，编辑后保存、点击网格、按 Ctrl+Z/Delete，修改前测试失败（公式值变为空，而非保留提交内容）。此次测试通过 DOM 键盘事件复现，不是直接修改草稿 Map。

现在保存期间编辑快捷键 Ctrl/Cmd+S/V/X/Z/Y 和 Delete 不执行；撤销、重做、清空、粘贴和剪切函数也检查保存状态。这与现有按钮的保存边界一致。复制、箭头导航、工作表切换仍保持可用，本轮没有改变页面布局。

异步剪贴板在 await 后重新核对工作簿对象、文档 epoch、工作表读取代次、路径、资料库、选区和保存/只读状态。过期粘贴提示在目标选区重试；过期剪切已复制但不清除单元格，避免清除新的目标。没有读取或写入用户系统剪贴板。
