# v1.3.3：按文件接续提纲筛选与浏览状态

- JSON字段路径及YAML、XML、TOML提纲接续各文件的筛选和有效选择，切换文件后不必重新查找；空结果同样保留。
- JSON树接续源码／树形视图与折叠节点，TOML数组按当前源码重新展开。节点消失时自然回退，定位始终使用最新分析范围。
- 实际改名后沿原标签接续，干净标签关闭后重新打开从默认状态开始；状态只在当前窗口的打开标签间保留。
- 保护未保存正文，不抢正文、搜索框或弹窗焦点；保留现有输入框、右键、六种风格和正常动效，不增加常驻控件。

8组重建／复用场景、72组风格／窗口，上版导航72组和YAML删除12项回归通过。固定源码完整发布检查、Rust1464项功能及1项性能、86组/799项安装版任务通过。NSIS、MSI和SHA256SUMS.txt三份公开附件已回下载核对。
