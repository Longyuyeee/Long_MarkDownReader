# C2C DOCX 列表与表格隔离编辑审计

>
> 结论：C2C 已完成；后续 C2D 见 `C2D_DOCX_Style_Image_Isolated_Edit_Audit_2026-07-27.md`

## 1. 交付范围

C2C 在 C2A 包级门禁和 C2B 精确文本补丁上增加：

1. 安全列表项进入可编辑文本目标清单；
2. 安全表格单元格以 `table block + rowIndex + columnIndex` 绑定目标；
3. 列表项写后复读必须保持同一正文块与 `list-item` 类型；
4. 表格单元格写后复读必须保持同一表格块、行列坐标与 `table-cell` 类型；
5. 继续复用源文件签名、目标文本摘要、单部件差异、临时副本重开和源文件不变证明。

目标清单与 C2B 共用 `editableTextTargets`，补充以下类型和字段：

- `kind: list-item | table-cell`；
- 表格单元格返回零基 `rowIndex` 与 `columnIndex`；
- 非表格目标的两个坐标字段为 `null`。

隔离预览继续使用 `preview_docx_text_patch_isolated_copy`，命令只返回审计报告，不返回可保存 DOCX 字节。

## 2. 列表安全边界

列表项仅在以下条件全部满足时进入清单：

- 解析模型确认为 `list-item`；
- 位于正文顶层；
- 仅包含一个 `<w:t>`；
- 文本非空；
- 不包含修订、域、内容控件、超链接、批注、书签、绘图、嵌入对象、换行或符号等复杂载体。

编号定义、层级和段落属性不参与改写，仅精确替换 `<w:t>` 内容。

## 3. 表格安全边界

表格单元格仅在以下条件全部满足时进入清单：

- 位于正文顶层表格，不是嵌套表格；
- 单元格仅有一个段落；
- 段落仅有一个 `<w:t>` 且文本非空；
- `columnSpan == 1`、`rowSpan == 1`；
- 不是纵向合并续格；
- 解析后的单元格文本与 XML 段落文本完全一致；
- 不包含 C2B 已定义的复杂只读载体。

多段落单元格、横向/纵向合并单元格、合并续格、嵌套表格、空单元格和富文本单元格继续只读。

## 4. 语义与包级门禁

- 目标 ID 包含表格序号、行列坐标和原文本摘要前缀；
- 请求仍校验完整 SHA-256 原文本摘要；
- 新文本限制为 1～32,767 个 Unicode 字符且不得包含控制字符；
- XML 文本由 quick-xml 统一转义；
- 写后必须重新解析整个 DOCX；
- 列表项验证 `blockId + kind + text`；
- 表格单元格验证 `blockId + kind + rowIndex + columnIndex + text`；
- 仅 `word/document.xml` 可以变化；
- 未修改 OOXML 部件继续 raw-copy 并逐部件核对摘要；
- 临时副本完成同步、字节/摘要核对和结构重开；
- 最后复核源文件字节、摘要和文件签名未变化。

不存在 `save_docx` 或 `write_docx` 命令。

## 5. 真实 Word 回归

Microsoft Word 16 生产者 fixture 已证明：

- `Structured reading` 列表项进入目标清单并可隔离替换；
- `Available` 表格单元格以第 2 行第 2 列，即 `rowIndex = 1`、`columnIndex = 1` 进入清单；
- 列表项改写后保持原正文块和列表类型；
- 表格改写后保持原表格块、行列坐标和单元格类型；
- 含两个段落且横向合并的 `Capability matrix` 单元格不进入清单；
- 含两个段落且纵向合并的 `Status` 单元格不进入清单；
- 临时副本重开通过，源 fixture 字节保持不变。
