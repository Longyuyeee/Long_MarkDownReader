# PDF 阅读笔记

PDF 批注可以整理成有原页、摘录、评论和来源链接的 Markdown 笔记。原 PDF 和批注记录保持分开保存；整理笔记不会改写 PDF。

## 选择要整理的批注

在资料库打开 PDF，进入侧栏“批注”。用关键词查找摘录或评论，也可以按页码、颜色、类型筛选。页码支持 `1-5,8`。卡片仍可点击回原页、编辑评论和颜色，单条复制、插入和删除继续保留。

勾选需要的条目，或“全选筛选结果”。筛选改变不会偷偷丢掉已经勾选的条目，隐藏选择会显示数量；“清除选择”移除所有勾选。每次最多整理 200 条，超过时先缩小页码或其他范围，再分批整理。列表每组显示 50 条，可前后翻组。

## 预览和保存

点击“整理为笔记”，检查实际条目、页码、摘录和评论，可按页码或颜色组织，也可关闭评论。复制笔记会复制生成的 Markdown，不写文件。

插入已有笔记时，先选择已打开的 Markdown，再点击“插入草稿”。内容追加到该笔记末尾，不会代替你保存；原有未保存内容和保存冲突保护继续保留。确认正文后，仍需自己点击“保存”。目标未就绪、关闭或工作现场切换时，先重新打开目标再操作。

选择“新建并保存笔记”会弹出保存位置选择器。使用当前资料库内的新 `.md` 名称，已存在的文件不会被覆盖；取消或失败会保留预览。所选摘录和评论过大时需分批，正文保存上限为 8 MiB。

## 返回来源

保存后点击笔记内来源链接，可回到原 PDF 的页码和批注。新来源链接包含文件内容摘要；若同名 PDF 已被另一份内容替换，软件会阻止错误定位。校验大 PDF 时需要读取文件，请等待校验完成。

原 PDF 改名或移动后，可在提示中填写当前资料库内的新相对路径；只有内容与原来源完全一致才可重新关联。此操作只改笔记草稿，可撤销，仍需手动保存。内容备份恢复到另一资料库后，保持相对结构和 PDF 原字节时，来源摘要仍有效。

批注删除后会提示并回到原页；页码不再存在时提示核对来源。旧版本链接没有内容摘要，仍可使用，但需要自己核对来源，软件不会把它说成已通过内容校验。
