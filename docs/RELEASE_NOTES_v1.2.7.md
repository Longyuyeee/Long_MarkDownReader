# Long编辑 v1.2.7：JSON 数组项位置调整

右键 JSON/JSONC 数组中的记录，可直接上移或下移；首尾方向禁用。标量、对象和嵌套数组均移动完整原文，保留长数字、转义、内部注释及原有排版；注释归属不清时说明原因并保留内容。

复用现有差异预览，移动应用到当前草稿，可一次撤销重做，焦点及树形选择跟随原记录，树形视图可直接 Ctrl+Z 撤销、Ctrl+Y 或 Shift+Ctrl+Z 重做，无需切回源码。来源或草稿已变化时停止旧结果，保存失败及外部冲突保留未保存内容。保留全部现有功能、风格和正常动效，不增加常驻操作区。

未签名 Windows 社区版，完整发布检查与 450 项安装版功能任务通过，NSIS、MSI 与 `SHA256SUMS.txt` 三份公开附件已重新下载核对通过。1.2.6→1.2.7 应用内自动更新实际观察仍待完成，与手动安装升级分别记录。

结构化节点右键菜单按小窗口可用空间展开，空间不足时内部滚动，避免顶部操作出屏。
