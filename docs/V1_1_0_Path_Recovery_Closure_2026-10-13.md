# 路径不可用时的读取与恢复收口

2026-10-13 从 `df51cc8a` 接续。用户要求先处理完当前问题，本轮范围为路径报错、恢复重试和草稿保护。

## 已确认的问题与修复

### 文件夹读取失败被缓存为空

原 `handleLoadChildren` 在 `scan_directory` 失败后写入 `children = []`。磁盘断开或目录移走时会被当作空文件夹，目录恢复后再次展开也不读取；错误此前仅在控制台记录。

现在失败保留未加载状态，提示文件夹名称及重新展开的方式。资料库切换或刷新后，旧请求的结果与错误均不再修改当前树。Naive Tree 接收 `false` 完成失败流程，清理加载状态；下次展开重新请求。

### 手动重读提前清空缓存、失败仍报成功

原 `refreshCurrentFile` 在读盘前清除 `tab.content`，而 `loadFileToEditor` 处理失败后不返回结果，调用方仍显示“已同步磁盘最新内容”。未保存修改没有确认流程。

现在显式重读保留原内容、脏状态和磁盘签名，读取成功后才替换。读取失败恢复当前编辑内容且只提示失败；不重复触发同一缺失路径的历史请求。覆盖脏文档前复用现有警告弹窗，取消不修改内容；确认时复核文档、资料库、编辑器及内容，防止确认期间发生变化。重复读取、保存中的读取和读取中的保存被阻止。

## 接续边界

本轮可复现的读取/重试/草稿缺陷已修复。物理路径确实不存在时仍会报失败，不代替用户推断新位置或自动创建文件。本轮证明的是实际 debug 原生读盘与恢复，不是正式安装升级验收；也不能据此推断用户早先某一次报错的唯一来源。
