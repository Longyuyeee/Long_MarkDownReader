# PDF续读位置原生保护

本轮按元数据审计顺序处理PDF续读：页码、页内与横向位置、缩放、方向、连续阅读锚点接入原生 `pdf-reading-v1.json`。读取失败仍可阅读，但不会把首页当成新记录覆盖此前位置；保存确认后才显示“已记住”。返回、切换PDF、打开文字与查看收到内容前等待位置队列，失败允许离开并在返回页提示。

先核对 [Adobe Android查看方式](https://helpx.adobe.com/acrobat/mobile/view-manage-files/viewing-modes.html) 和 [Obsidian移动端](https://obsidian.md/help/mobile)，保留按需设置与逐层返回。调查来自官方资料，没有安装竞品走查，也不据此推断其内部持久化实现。[冻结规则与设计](design/mobile-native-pdf-position-v1/Interaction.md)先于阅读器接入；正常页沿用已验收参考，失败状态用独立组件原型出图。

原生文件按完整身份隔离，用本文件令牌及整个文件SHA-256比较后原子写入、读回。旧WebView键只在原生缺失时验证迁移，原键、其他资料与未知字段保留，不再静默裁成100条；超过5 MiB或记录损坏会显式失败。保存队列复制快照、合并最新位置；迟到的重试回复不会把用户新翻到的页面拉回。内容指纹变化从首页开始，同内容的非法页码不会被静默改成合法记录。

[原图对照册](evidence/mobile-native-pdf-position-2026-10-30/review.html)保留88张未经编辑的PNG及完整结果。正常阅读页、阅读方式弹层两组390×844原图像素差异0；错误状态组件390×64、字号和颜色与修订稿一致。示意稿底栏54px，实际65px，因此组件顶部相差11px，未移动截图像素掩盖。浏览器截图仅排除预览条；Android原图为1080×2280。

首轮实页暴露黄色正文对比度不足，改为高对比正文／动作颜色，警示图标保留黄色；原稿、失败页、修订决定和新稿均保留。旧设置脚本的故障注入键与时机已修正：先拒绝暂存再输入，避免输入已经确认后才模拟失败。过时连续阅读、旧批注恢复脚本仍使用已移除入口，其失败报告保留，未算作通过。
