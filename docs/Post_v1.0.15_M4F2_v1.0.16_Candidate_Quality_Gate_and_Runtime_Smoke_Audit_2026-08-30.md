## 候选身份与需求对齐

本阶段严格延续 M4F-0 的原始发布路线：功能范围冻结后先完成版本迁移，再对不可变候选执行完整质量门禁和运行烟测，只有通过后才能构建安装包。三轮安装生命周期先后发现 M2A2 后治理入口偏移、治理面板首次以打开状态挂载却不启动扫描，以及主题居中后未把对象身份写入 `Graph?root=` 的真实产品缺陷；纠偏后重新绑定的产品候选提交为 `757d54309ddb35f445344d909fa4c7ba2567bc58`，二进制版本为 `1.0.16`；当前公开版本仍为 `v1.0.15`。

首轮门禁发现的图谱紧凑字体、工作簿颜色语义、过时检查器和浏览器预览窗口边界问题均属于候选质量缺陷，不允许带病进入安装包阶段。M4F-3B 又修复设置页仍返回已移除建议的工作台问题，并把安装态验收对齐图谱治理面板。本阶段所有产品质量和运行证据已对新候选重新执行；审计状态与检查器的后续提交只记录事实和下一阶段，不改变候选产品源码。
