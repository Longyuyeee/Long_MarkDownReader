## 开发目标与需求对齐

本阶段只验证两个已公开官方 Release 之间的真实应用内更新，不构建安装包、不修改产品功能，也不把 M5-6 的直接安装覆盖升级冒充应用内更新结果。验收预期固定为：已安装 v1.0.16 发现 latest v1.0.17；用户确认前不下载或启动安装器；确认后下载并以 SHA-256 校验官方 NSIS；同目录静默覆盖；自动重启到 v1.0.17；首次启动显示最新版；合成资料库与配置在覆盖、卸载后保留。

执行只允许在 GitHub 托管的一次性 Windows 环境进行，不触碰用户主机或真实用户资料。
