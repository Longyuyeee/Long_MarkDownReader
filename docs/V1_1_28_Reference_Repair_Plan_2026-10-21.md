# 1.1.28 计划：引用来源与关系核对

状态：下一实施，尚未开发；1.1.27 已正式发布。接续 [十二版路线](Foundation_Deepening_Roadmap_1_1_21_to_1_1_32_2026-10-19.md)。

用户要完成的事：“引用的文件换了位置，能找到正确来源继续读，并尽量保留原来的页码和段落位置。”

先审计 `workspaceReference.ts`、`fileRelations.ts`、`FileRelationDialog.vue`、`pdfReference.ts` 与既有移动/改名后的图片、链接接续。复用能够准确识别的路径、文件身份和定位信息，不重复实现已交付的移动接续。

在引用和关系的具名菜单中打开“核对来源…”弹窗。区分文件缺失、暂时不可读与页码/位置失效，提供打开所在目录、重新定位或选择替代文件的实际动作。低频修复集中在弹窗，不新增常驻面板。

替换前预览旧/新来源和影响范围。保留可以核对的页码、批注身份、文本锚点及关系方向、类型与说明；无法确认的位置允许用户选定或继续保留原记录，不将猜测作为修复成功。修复结果可直接回到来源。

未保存笔记和外部变化继续受保护；取消不修改来源、引用或关系。既有管理标签、集合、图谱筛选及其他文件不随修复被隐式改变。

完成标准：移动后与同名文件能准确区分；失效位置有可操作退路；预览、取消、草稿保护和修复后回跳可用。实际实现及安装验证后再发布。
