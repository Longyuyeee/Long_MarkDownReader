## 1. 开发目标与结论

M3B-9 已完成只读语义缩略图、当前视口框、点击/拖动/键盘导航、首次进入相机同步、有界采样、三主题和响应式覆盖层避让。缩略图不绘制节点标签，不参与布局、不修改节点坐标持久化，也不写回资料库。

当前接续点前移到 **M3B-10 剩余专业视觉系统选择审计**：在聚类展开/折叠、图谱全屏和节点状态外环中重新核对信息增益与状态成本，只选择一个最小增量。M3C 性能重构继续独立延后。

## 2. 实现与需求对齐

| 需求 | 实现 | 验收 |
| --- | --- | --- |
| 只读全图方位 | 从当前可见节点坐标派生投影；语义对象类型决定点颜色 | 真实 17 节点全部显示；源摘要不变 |
| 有界成本 | 全量单次扫描计算边界，按稳定输入顺序等距采样，最多绘制 600 点 | 独立 5000 节点 oracle 返回不超过 600 点；无标签绘制 |
| 当前视口框 | 将主 Canvas 可视区域按实时 `viewX/viewY/zoom` 逆投影到缩略图 | 四会话全部保持框在缩略图边界内 |
| 点击导航 | 缩略图内容坐标逆投影为世界点，复用 M3B-7 相机目标和有界/reduced 合同 | calm `343ms/40帧`；reduced `8～25ms/0帧` |
| 拖动导航 | 指针捕获下直接操纵相机中心，保持当前缩放并实时更新视口框 | 四会话实际姿态变化且导航状态为 `minimap-drag` |
| 键盘导航 | 缩略图获得焦点后方向键按当前世界视口 15% 移动 | 四会话真实 `ArrowRight` 均改变姿态，导航计数达到 3 |
| 无前置操作初始化 | 主绘制循环主动同步实时相机诊断，不再等待首次相机按钮 | 三档窗口进入后 `cameraInitialized=true` |
| 覆盖层安全 | 宽屏在详情检查器左侧；窄屏详情存在时移到右上；远景抬高避让社区入口 | 4 会话 × 3 窗口共 12 次，对详情、图例、状态栏碰撞均为 0；远景入口碰撞 0 |
| 主题可读 | 背景、边框、焦点和视口框使用主题令牌，节点使用既有语义色 | 暗色、浅色、高对比截图人工复核通过 |

纯几何位于 `src/utils/graphMinimap.ts`，投影、逆投影、视口框和 5000 节点采样均由固定输入验证，不以截图看起来相近代替正确性。

## 4. 真实测试范围

- 会话：暗色 calm、暗色 reduced、浅色 reduced、高对比 reduced。
- 每会话窗口：`1280×800`、`1000×700`、`720×680`。
- 交互：初始相机同步、点击、拖动、真实方向键、远景社区入口、返回资料库。
- 安全：全部运行时错误为 0，资料库 SHA-256 前后一致。
- 证据：`docs/evidence/post-v115-m3b9-bounded-semantic-minimap/`，包含四份 JSON 和各窗口、点击、拖动、键盘、远景截图。

- 开发目标：全部完成；没有用静态装饰图冒充可导航缩略图。
