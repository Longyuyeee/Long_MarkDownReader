# v1.0.7 受控更新生命周期审计

状态：**托管执行合同已准备，等待远端质量门与一次性 Windows 运行**

## 目标

- 从官方 `v1.0.6` NSIS 安装开始，通过应用内检查发现官方 `v1.0.7`。
- 保持用户确认边界，确认前不得下载或启动安装器。
- 下载后核对 GitHub Release 中的严格文件名、大小与 SHA-256，再执行同目录静默覆盖。
- 验证 v1.0.7 首启、设置页“当前已是最新版本”、安装二进制身份及合成资料保留。
- 覆盖安装和卸载后都必须保留合成资料库与配置标记。

## 隔离边界

- 仅在 GitHub 托管 Windows 一次性环境运行，必须同时提供 `ConfirmDisposableMachine` 与 `AllowInstallerMutation`。
- 工作流只下载公开 Release 资产，不重建产品，不读取本机 LongEdit，也不包含真实用户资料。
- 当前安装包仍为 `NotSigned`；本观察不构成企业签名或商业发布资格。
