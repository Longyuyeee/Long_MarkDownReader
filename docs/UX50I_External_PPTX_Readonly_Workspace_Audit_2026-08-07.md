# UX-50I / EA-3F 外部 PPTX 只读工作区审计

日期：2026-08-07

## 本阶段结论

EA-3F 已完成 PPTX 外部只读工作区。PPTX 现在可由“打开外部文件”、Windows 启动参数或用户逐项选择的默认应用入口直接进入 LongEdit 演示文稿阅读器。外部模式保留幻灯片缩略图、结构化画布、搜索、定位、备注、兼容画像、受限图片预览和放映，不开放任何编辑或可靠副本保存能力。

外部打开能力现为：

- `edit`：23 类 Markdown、文本、代码和结构化源码，只有点击保存才写回。
- `preview`：图片、视频、PDF、ODS、ODP、DOCX、PPTX 共 7 类，只读打开且永不写回。

## 安全与产品边界

- 新增 `read_external_pptx_presentation`，只接受用户明确授权且注册为 `preview` 的 `.pptx`。
- 基础读取报告不包含编辑目标；文本、样式、图片、形状和幻灯片编辑目标只由资料库专属 `audit_pptx_edit_baseline` 产生。
- `prepareEditBaseline` 在外部模式直接拒绝运行，界面隐藏编辑准备、编辑安全基线、全部隔离补丁区和可靠另存副本区。
- 每个编辑区都显式检查 `!isExternal`，避免从同路径资料库会话切换时短暂显示旧编辑状态。
- PPTX 解析与图片提取后重新读取源文件并逐字节比对，变化即失败。
- 标题显示“外部演示文稿 · 只读 · 不会写回”，状态栏显示源文件未修改，并纳入统一标签与返回资料库流程。
- 资料库 PPTX 原有三生产者隔离编辑、可靠新副本和源文件只读策略保持不变。
- XLSX 继续保持 `import`；安装器关联仍只有 `.md/.markdown`。

## 自动化证据

- `check:external-pptx-preview`：通过，锁定独立授权、无编辑基线、无保存界面、源字节复核、资料库编辑保留和 XLSX 未开放。
- `commands::pptx::tests`：11/11 通过，包含格式门禁、只读零修改、隔离文本/样式/图片/形状/幻灯片编辑及三生产者可靠副本回归。
- `services::external_file_access::tests`：覆盖 PPTX preview 授权和禁止 editable 解析。
- DOCX、ODS/ODP 及既有外部能力契约：通过。
- `vue-tsc --noEmit`、Vite 生产构建和 `cargo check --locked`：通过。

## 保留边界

- 外部 PPTX 不创建副本、不修改原文件，也不把文件加入资料库索引。
- 放映是本地结构化投影，不执行动画、宏、嵌入对象或外部链接，不等价于 PowerPoint 原生放映。
- 复杂母版、SmartArt、图表、动画和未知 OOXML 对象继续保持只读保真或明确降级。
- 本阶段不宣称完整 PowerPoint 等价编辑；资料库模式仍是经过验证的有界编辑子集。
- 安装态仍需复测双击 PPTX、单实例二次打开、多生产者文件、放映退出、关闭标签和返回资料库。

## 下一入口

进入 EA-3G：单独审计 XLSX 外部只读工作区。必须把工作簿分页读取与所有写入、公式计算、透视表重建、数组公式和外部数据操作分离；外部命令只允许本地解析与分页读取，界面隐藏编辑工具和保存入口，并保持外部链接永不跟随。
