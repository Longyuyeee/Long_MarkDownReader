# v1.0.15 后 M4B-0 工作台对象行动选择审计

日期：2026-08-28

阶段：M4B-0

结论：通过选择审计；下一步为 M4B-1，不提升版本

## 1. 结论

M4B-0 已完成真实代码、保存边界与桌面现状审计。下一最小批次冻结为 **M4B-1：内部 Table 布尔任务行工作台行动闭环**。只识别 `.table.json` 中类型明确、值严格为 `true/false`、完成列名为“完成 / 已完成 / done / completed”且能解析文本标题的行；CSV/TSV 与任意布尔列不推断为任务。

本阶段没有修改 `WorkspaceHome` 或后端产品行为。现状仍是 Markdown 待办可直接确认完成、恢复及撤销，PDF 批注只有查看入口，M1 七类对象尚无工作台直接行动。M4B-1 只把 Table 的明确任务行并入现有“今天要做”，不新增格式统计或独立卡片。

## 2. 原始需求与实际代码

原始 M2 要求工作台只回答“继续做什么、今天要处理什么、哪里需要注意”；M4 要求 M1 新对象可从工作台定位并返回内部位置。两者共同约束是：工作台应提供有意义的行动，不是把每种格式的编辑按钮复制到首页。

| 事实 | 当前真实实现 | 对选择的影响 |
| --- | --- | --- |
| Markdown 待办 | `set_workspace_markdown_task_state` 校验资料库、签名、行号、文本与状态，可靠写入后可用新签名撤销 | 可复用交互和冲突模型 |
| PDF 批注 | “未引用批注”只打开精确批注，不直接修改 PDF 或批注 | 属于治理查看，不是写回模板 |
| Table | 内部表有稳定 row/column ID、显式 boolean 类型、内容签名、可靠写入和 `table-row` 定位器 | 能形成窄而完整的任务行动 |
| `WorkspaceHome` | 概览只提取 Markdown 复选框；Table 仅能作为最近文件打开 | 当前缺口真实存在 |

## 3. 七类候选选择

| 格式 | 决定 | 原因 |
| --- | --- | --- |
| Table | 选择 | 明确布尔列、稳定行列 ID、签名与可靠写入同时存在；与“今天要做”语义一致 |
| OPML | 延期 | 节点可定位和保存，但没有保留的完成语义，不能把任意节点/属性解释成任务 |
| DOCX | 延期 | 段落与标题没有任务状态；编辑需要对象上下文与草稿 |
| ODS | 延期 | 当前编辑必须另存新副本，工作台直接完成会隐藏目标路径选择 |
| ODP | 延期 | 只读；增加首页入口只会重复“继续工作” |
| PPTX | 延期 | 修改依赖对象操作、事务预览与确认保存，没有通用任务状态 |
| Workbook | 延期 | 完整草稿虽安全，但单元格还受公式、验证、合并与对象语义约束，没有保留任务 schema |

## 4. M4B-1 冻结边界

- 发现：只扫描资料库内 `.table.json`；只接受显式 boolean 完成列和严格 `true/false` 值；使用稳定 row/column ID。
- 标题：优先使用视图已有 `titleColumn`，否则使用第一个可用文本列；无标题则不进入工作台任务。
- 展示：并入现有待办列表、状态与来源筛选，不增加新的首页卡片或格式数量。
- 定位：点击正文通过共享 `table-row` 定位器打开精确行。
- 写回：新增窄后端命令，重新读取并核对资料库范围、文件签名、行 ID、列 ID、boolean 类型和旧值，只修改一个布尔值后可靠写入。
- 确认与撤销：完成/恢复前确认；成功回执携带新签名，撤销用新签名恢复旧值。
- 失败：旧签名、行列变化、类型或旧值变化均拒绝且文件不变；工作台刷新真实状态。
- 不包含：CSV/TSV 推断、其他六类格式修改、转换、版本提升和 release candidate。

## 6. 审计过程纠偏

首次运行没有进入产品断言：审计脚本在 PowerShell 内联生成含中文的 JSON 夹具，后端按真实字节解析时在第 8 行明确拒绝无效 JSON。测试改为仓库内固定 UTF-8 合成夹具并逐字节复制后重跑，通过真实解析、桌面和摘要门禁。失败没有被改写成通过，也没有放宽 Table schema。

## 7. 下一接续点

唯一接续点为 **M4B-1：内部 Table 布尔任务行工作台行动闭环**。先在后端建立有界发现与窄变更命令及 Rust 文件测试，再接入现有工作台待办模型，最后运行完成、恢复、撤销、冲突拒绝、精确定位、宽窄屏、性能和源文件恢复的真实 Tauri 审计。

转换披露、新转换类型、版本提升和发布冻结继续延期；`releaseCandidate=false`。
