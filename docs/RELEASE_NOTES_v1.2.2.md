# Long编辑 v1.2.2

PDF 批注编辑或删除错了，可以在批注右键、每条批注的“···”或批注搜索框旁的“···”菜单撤销、重做。支持新增批注、评论、颜色和删除；连续评论输入一次撤回，评论框内 Ctrl+Z 仍用于文字编辑。

保存失败会保留当前批注并提供重试；此时重新读取同一个 PDF，也会保留未保存的评论。PDF 或批注被其他操作修改时，保留当前评论并提示核对，避免覆盖外部修改。切换文件不会携带旧历史，已有阅读笔记正文保持不变。

此版本为未签名社区版。固定产品构建、Rust 功能与性能回归、414 项安装版功能任务及 NSIS 安装升级检查通过。Release 提供 NSIS、MSI 与 `SHA256SUMS.txt`，三份公开附件重新下载核对通过。应用内自动更新实际观察仍独立待完成。
