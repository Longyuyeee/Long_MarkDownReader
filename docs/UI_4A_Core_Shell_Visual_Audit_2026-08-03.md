# UI-4A 核心壳层视觉审计

日期：2026-08-03  
当前状态：已完成并接入补丁发布质量门禁

## 需求对齐

UI-4 要求使用真实样例检查专业浅色、专业深色、高对比主题，以及 Windows 100%、125%、150% 缩放。UI-4A 先覆盖资料库、工作台、设置、格式能力和知识图谱五个主壳层；主要格式编辑器矩阵在 UI-4B 继续。

## 审计实现

- `scripts/ui4-visual-matrix.mjs` 固定 3 个核心主题、3 档等效缩放和 5 个壳层工作面。
- `scripts/capture-ui4a-shell-visual-audit.mjs` 只连接真实 Tauri WebView2 CDP 目标，记录主题语义、物理/逻辑视口、根容器几何和页面溢出。
- 1280x820 物理窗口在三档缩放下分别使用 1280x820、1024x656、853x547 逻辑视口，模拟 Windows 缩放后的可用布局空间。
- 证据合同要求完整 45 张截图，拒绝缺失工作面、错误主题、错误缩放、页面横向溢出、页头正文重叠、底栏裁切、图谱工具栏溢出和过小图片。
- `scripts/check-ui4a-shell-visual-harness.mjs` 校验采集工具合同，`scripts/check-ui4a-shell-visual-audit.mjs` 校验接收证据。

## 首轮拒收与修复

首轮 45 张真实截图通过了原始几何合同，但人工复核拒绝接收，并发现两项图谱问题：

- 图谱根容器使用 `100vh`，叠加应用标题栏后超出实际路由工作区，底部状态栏被裁切。
- 150% 等效缩放下，图谱页头操作区出现明显横向滚动条。

修复提交 `4ce413b` 将图谱高度改为父容器相对 `100%`，在紧凑宽度隐藏低频导出命令并将教程收为图标按钮；证据合同同步加入底部状态栏越界和图谱工具栏内部溢出检查。首轮截图不作为接收证据，修复后进行了完整重采。
