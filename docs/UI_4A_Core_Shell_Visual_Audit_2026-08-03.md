# UI-4A 核心壳层视觉审计

日期：2026-08-03  
当前状态：采集器与证据合同已建立，真实桌面矩阵待执行

## 需求对齐

UI-4 要求真实样例、专业浅色/专业深色/高对比主题，以及 Windows 100%/125%/150% 缩放回归。UI-4A 先覆盖资料库、工作台、设置、格式能力和知识图谱五个主壳层；格式编辑器矩阵在 UI-4B 继续。

## 本阶段实现

- `ui4-visual-matrix.mjs` 固定 3 个核心主题、3 档等效缩放和 5 个壳层工作面。
- `capture-ui4a-shell-visual-audit.mjs` 只连接真实 Tauri WebView2 CDP 目标，记录主题语义、物理/逻辑视口、根容器几何和页面溢出。
- 1280x820 物理窗口在 100%/125%/150% 下分别使用 1280x820、1024x656、853x547 逻辑视口，模拟 Windows 缩放后的可用布局空间。
- 证据合同要求完整 45 张截图，拒绝缺失工作面、错误主题、错误缩放、页面级横向溢出、页头正文重叠和过小图片。

## 执行顺序

1. 先提交并推送采集器，形成可追溯的工具基线。
2. 在干净提交上运行 `npm run audit:ui4a-shell-visual`。
3. 人工复核三主题、三缩放代表截图，并运行 `npm run check:ui4a-shell-visual-evidence`。
4. 接收证据后将检查加入补丁发布门禁，再进入 UI-4B。

本阶段不会用普通浏览器截图冒充桌面证据，也不会在真实采集完成前声明 UI-4A 通过。

## 首轮真实采集发现

首轮 45 张真实截图通过原始几何合同，但人工复核拒绝接收，并发现两项图谱问题：

- 图谱根容器仍使用 `100vh`，叠加应用标题栏后超出实际路由工作区，底部状态栏被裁切。
- 150% 等效缩放下，图谱页头保留搜索、教程、治理和两个导出按钮，操作区出现明显横向滚动条。

修复将图谱高度改为父容器相对 `100%`，900px 以下隐藏低频导出命令并将教程收为图标按钮；证据几何合同同步增加底部状态栏越界和图谱工具栏内部溢出检查。首轮截图不作为接收证据，必须在修复提交上完整重采。
