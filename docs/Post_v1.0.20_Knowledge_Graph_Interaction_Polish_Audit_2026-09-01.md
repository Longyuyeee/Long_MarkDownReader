# v1.0.20 发布后知识图谱交互精修审计

日期：2026-09-01
状态：**产品修改与真实 Windows/Tauri 验证通过；尚未提升版本或构建新安装包。**

## 1. 用户反馈与代码根因

用户真实截图暴露四项问题：普通缩放继续越过可读下限后自动切入社区泡泡总览；社区图标持续闪烁/移动且压缩字体粗糙；单节点详情在高 DPI 桌面错误变成横铺底部面板；布局与主题仍使用原生下拉，三个画布主题差异不足。

真实代码审计确认：普通图谱缩放下限硬编码为 `0.1`；社区总览缓存把“布局已稳定”解释为每帧刷新，取景过程还会继续请求下一帧；Canvas `fillText(..., maxWidth)` 横向压缩长标题；`max-width: 1500px` 媒体规则让详情面板左右同时贴边；画布主题只改变少量背景色。

## 2. 需求对齐与修正

- 83 节点普通图谱最低缩放固定为 `58%`，180 节点约为 `64.5%`；连续缩小不能再进入社区泡泡层。
- 社区总览只保留给至少 240 个可见节点且聚合确实能降低复杂度的大图；最低范围为 `16%`。
- 社区几何只在缩放、可见图签名或布局修订变化时重建；取景差异小于 0.5px 时不再请求新帧。
- 社区标题改用 Inter/微软雅黑并按字符截断，不再使用 Canvas `maxWidth` 压扁字形。
- 单节点详情固定为右下角卡片，桌面宽度上限 380px、高度上限 520px；小屏才使用有界底部卡片。
- 布局、主题、思维导图深度改为 Naive UI 浮层选择器；主题文案明确其实际视觉含义。
- 专业、多彩、专注分别使用细网格、双色语义光域、纯净聚焦背景，不再只是近似底色。
