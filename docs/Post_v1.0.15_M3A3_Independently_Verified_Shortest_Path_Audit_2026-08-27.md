# v1.0.15 后续 M3A-3 独立验证最短路径审计（2026-08-27）

## 结论

M3A-3 已完成。全局图谱新增显式起点、终点选择和最短路径入口；找到路径后只显示路径节点与实际路径边，保留关系原始方向、类型、线型和当前子图图例，并持续显示跳数、节点链与“返回全图”。无路径时不隐藏全图，显示明确的“当前筛选范围内不连通”状态。

生产实现为独立纯函数 BFS。发现关系时把边作为双向邻接遍历，但结果继续携带并绘制原始 `GraphEdge`，没有把有向关系改写为无向事实。固定图谱使用另一份独立 BFS 距离 oracle 验证连通、并列最短、无路径、同节点和非法节点五种情况；并列路径按节点 ID 和关系类型稳定排序。

## 真实桌面结果

真实 Tauri 跨格式资料库中，`NorthStar → Evidence` 得到 3 跳路径：`NorthStar → Brief → PDF 批注 → Evidence`，画布从 17 节点/17 边缩减为 4 节点/3 边；返回后恢复 17/17。`NorthStar → Review.pptx` 显示无可达路径。1280×800 与 720×800 均无页面横向溢出，运行时错误为 0，可返回资料库，源文件 SHA-256 前后相同。

人工复核发现新增入口一度导致顶部模式按钮和链接教程换行，已纠正为不可收缩的单行控制项，由既有横向滚动承接空间不足；重新采集后宽窄路径面板、范围图例和返回入口均可读。

本阶段最终需求复核还发现 M3 路线要求 1～3 跳邻居聚焦，而此前 M3A-2 仅交付一跳。当前已补齐深度切换、单调扩展合同和真实桌面复验，并同步修正 M3A-2 审计，未通过缩小文档需求掩盖实现缺口。
