# Long编辑 v1.0.5

v1.0.5 是 v1.0.4 安装反馈后的稳定性与多格式体验收尾版本，重点解决文档切换卡顿、工作区挤压、控件一致性和媒体能力，并启用新的受控自动更新链。

## 主要变化

- 移除文档切换时的全屏加载遮罩和串行路由退场，增加超时、失败恢复和旧请求防覆盖，降低“正在打开知识库”卡死风险。
- 清理编辑区关系状态占位；文件上下文改为贴边浮动，侧栏按宽度在文字与图标模式间自适应。
- 文件树显示完整后缀和分类图标，支持为单个文件设置本机背景、文字颜色和标记图标。
- 全局横向工具栏、标签栏、表格标题和筛选区域支持滚轮横向导航，并统一隐藏原生旧式滚动条。
- 重构 Table 看板配置和长文本布局；压缩 XLSX 工具栏，统一复杂工作区命令尺寸与下拉控件主题。
- Markdown 首次打开正确进入所见模式；HTML、JSON、YAML、XML、TOML 和代码源码获得更丰富且满足对比度要求的语法颜色。
- 图片支持 PNG/JPEG/GIF/WebP/BMP/ICO/AVIF；视频支持 MP4/WebM/OGV/M4V，并按系统解码器尝试 MOV/MKV/AVI/MPEG/MPG。
- 媒体改为 Range 按需流式读取；视频新增快进快退、循环、静音、倍速、画中画、全屏和非阻断兼容提示。
- 自动更新改为固定 GitHub 最新稳定 Release、严格 NSIS 文件名和附件 SHA-256 校验，安装前必须由用户确认。

## 安装与更新

- v1.0.4 用户需要手动安装 v1.0.5 一次；v1.0.4 本身没有新的受控更新代码。
- 从 v1.0.5 起，应用每 24 小时自动检查，也可在设置页手动检查；后续稳定版本可在确认后自动覆盖安装。
- 本版本没有 Authenticode 商业签名，Windows 可能显示“未知发布者”。请从官方 Release 下载并核对 `SHA256SUMS.txt`。

## 能力边界

- MOV/MKV/AVI/MPEG/MPG 的实际播放取决于 Windows 与 WebView2 的解码器，不保证所有内部编码组合可用。
- Office、复杂 XLSX、高级 PDF 和旧格式继续遵守界面显示的只读、可靠副本或外部程序边界。
- 自动更新不使用遗失的旧 Tauri 私钥，不发布 `latest.json` 或 `.sig`。
