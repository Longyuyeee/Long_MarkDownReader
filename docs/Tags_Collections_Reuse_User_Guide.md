# 标签整理与集合条件复用

在文内标签上右键，或打开标签后的“…”菜单，选择 **整理这个文内标签…**。先勾选要处理的笔记，填写目标标签，再点“预览影响”。弹窗只列出当前已加载的笔记，最多 64 篇；需要其他笔记时可先加载更多，或沿用列表中的选择笔记入口。

改名或合并到同一标签会保留正文原有位置。添加、移除也沿用现有文内标签规则，包括代码块中符合该规则的标签；管理标签独立保留。预览会排除未保存笔记，执行前继续核对磁盘和窗口状态，不会自动替用户保存。原始正文保留在历史中，结果逐项显示，失败项不会被自动全量重试。

在 **智能集合 → 集合管理（…）** 中选择导入或导出；单个集合的菜单也能导出该集合。导出的 JSON 只包含名称与查找条件，不包含文档内容、资料库绝对路径或本机配置身份。现有普通搜索、筛选集合和图谱中心条件都可复用。

导入支持选择条件文件，也可展开“粘贴集合条件…”直接读入导出的 JSON。选择目标资料库后，逐项修改名称、相对目录、标签、文件类型、修改时间或图谱中心。条件会自动检查；“检查条件”可手动重试。不存在的目录、失效中心或不支持的类型会提示调整，取消勾选即可只导入其余有效集合。

同名集合保留，导入项会建议新名称，也可以自行修改。确认后只添加新集合，不创建、移动或复制匹配文件，不自动切换当前资料库。取消不会保存配置；保存失败保留预览。当前笔记草稿、已有集合、未提交的集合设置以及原结果排序、分页和位置保持独立。导出文件上限 1 MiB，当前集合总数沿用 64 个限制。
