# F1 链接原文范围审计

2026-10-11，接续 `efc554ba`。本步补引用改写计划所需的原文定位证据；不修改 UI、不写回文件、不开放归档执行。

## 问题与实现

此前依赖证据只有目标和行号，无法区分同一行重复链接，也不能据此替换正文。现在依赖证据新增可空的 destinationSpan，包含扫描时 UTF-8 字节 start/end（左闭右开）及 original 原文。不是 JavaScript 字符下标，也不能直接用于当前编辑器内容。

仅为解析器确认的内联链接/图片尝试定位：限定在解析事件范围内，原文目标必须与解析器目标完全一致；支持普通路径、百分号编码、片段、括号路径以及尖括号包围的含空格路径。范围不含标签、外围括号和尖括号。

引用式链接及定义、HTML、Wiki/PDF、带标题、解码后与原文不同的转义/实体等保持空范围，原有依赖证据不丢弃。不能将空范围理解为没有依赖，也不能把整个链接事件范围当目标范围替换。
