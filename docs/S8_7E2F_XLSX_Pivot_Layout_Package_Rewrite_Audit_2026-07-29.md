# S8-7E2F XLSX Pivot 布局隔离包重写审计

> 审计日期：2026-07-29

> 结论：功能实现完成，用户文件写回继续禁用

## 1. 本阶段目标

S8-7E2E 已证明七类聚合的完整临时包重建，以及单行轴、单列轴、多度量的内存语义。S8-7E2F 将后三种布局落到真实 OOXML 隔离包，要求 Pivot 定义、输出工作表、值、样式和未触及部件同时通过复读。

## 2. 已完成能力

- 单行轴：重写 `pivotFields/rowFields/colFields`、行列项、`location` 和输出工作表；S8-7E3C 的生产者审计进一步修正隐藏项过滤，输出为 `A3:B6`、8 个单元格。
- 单列轴：移除物理行轴并重建列轴和总计；S8-7E3C 升级为生产者原生两级表头，输出为 `A3:D5`、12 个单元格。
- 多度量：写入 `sum/count/average` 三个 `dataField`，使用标准 `x="-2"` 数据伪轴；S8-7E3C 升级为生产者原生三级表头，输出为 `A3:J8`、60 个单元格。
- 样式：从原 Pivot 输出提取表头、总计表头、行标签、总计标签和值样式，映射到扩展后的输出区域并逐格复读。
- 清理：布局收缩时清除旧输出范围中不再使用的坐标，避免残留数据。

三种布局与已有七类聚合共形成 10 个临时包。每个布局包均只存在于内存，返回摘要后丢弃，不修改用户文件。
