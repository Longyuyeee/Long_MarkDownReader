# v1.2.23：YAML 列表项新增与删除

YAML 提纲列表右键“追加列表项…”，某项右键“在此项后新增…”，只输入值；预览显示文本、数字、布尔或空值类型。“删除列表项…”直接预览。空列表可添加首项，删掉末项仍保留 `[]`。

支持普通单行项的块式与流式列表，保留其他项、字面量、独立注释、BOM 与换行。引用、嵌套集合及不明确的缩进／注释归属局部说明并提供源码定位，输入仍保留。

应用只改草稿，可撤销／重做，显式保存才写盘。继续保护后续输入、来源切换、保存失败重试及外部冲突副本；保留全部功能、风格与正常动效，无常驻表单。

未签名社区版；完整发布检查与 577 项安装版功能任务通过，NSIS、MSI 与 `SHA256SUMS.txt` 三份公开附件重新下载核对通过。应用内自动更新实际观察仍待完成，与手动安装升级分别记录。
