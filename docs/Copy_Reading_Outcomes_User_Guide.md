# 复制资料时带上阅读成果

在文件或文件夹上右键，选择“复制到…”，再选另一个资料库。沿用原目标预览和重名处理，不需要先整理或保存当前草稿。

出现“携带 PDF 批注和阅读来源”时默认勾选。预览会列出携带的批注条数和目标位置。复制单份 PDF 时，其已保存批注随文件一起复制；目标已有同名文件或批注时保留原件并使用副本名。打开副本可继续查看和整理批注。

复制阅读笔记时，已支持的 `longedit://pdf` 来源会带上配套 PDF 和批注，映射到目标库的实际路径。生成记录同步接续，自己的补写保留；之后更新阅读笔记仍沿原功能按需预览，不自动覆盖个人补写。普通 Markdown 相对引用沿用原关联资源复制。

预览后来源或批注改变，会停下受影响的项目。选择“重新核对未完成的…项”，只复制剩余项目；已完成项保留，收到不完整结果时沿原回执核对，不重复新建副本。取消预览不写入目标目录。

批注损坏、来源缺失或不支持的阅读来源，会在原预览中指出。可先核对原资料，也可以取消“携带 PDF 批注和阅读来源”，按原范围复制，并明确保留不能自动接续的引用。

范围：复制已保存文件，不代存或搬走当前草稿，不跨库剪切；历史、手动关系和 OCR 不自动跟随。批注沿用每份 PDF 最多 5,000 条、5 MiB 的既有限制；整批文件数沿原复制流程；笔记与批注的预览合计最多 64 MiB，过大时分批复制或取消携带。其他格式不改变既有能力。
