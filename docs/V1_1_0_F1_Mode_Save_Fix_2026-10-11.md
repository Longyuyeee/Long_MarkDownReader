# F1 模式切换重复回写修复与原生复验

2026-10-11，接续 `2f2c80e0`。上一轮模式切换后多余未保存标记在本轮限定场景中修复并复验。**仍未封板**，版本 1.0.26，目标 1.1.0。

## 根因与修复

switchEditorMode 重建 Vditor 后，初始化的 after 已经调用 loadFileToEditor；另有 100ms 轮询再次直接 setValue(content)，没有经过加载抑制或保存等待保护。这是第二条旧快照回写路径，会触发 input/dirty，也可能覆盖期间的新内容。测试使用旧 `2f2c80e0` 的真实函数复现这条回写。

移除轮询和第二次 setValue。切换前将编辑器最新内容放入原标签缓存，若与缓存不同则保守保留为 dirty，不清除已有 dirty；清理旧监听器，推进加载代次。下一 tick 初始化前复核代次与编辑器是否已被替换，随后只由统一加载流程恢复当前标签和协调未完成保存。没有改页面布局或为了验收强制清除 dirty。
