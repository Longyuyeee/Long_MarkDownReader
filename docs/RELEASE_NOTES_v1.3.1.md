# v1.3.1：YAML 多行字段删除

当前开发目标：`1.3.1`；当前运行时版本：`1.3.1`；当前公开版本：`1.3.0`。当前阶段：**v1.3.1 YAML 多行字段删除候选**。

普通映射的 literal/folded 多行字段沿已有右键“删除字段…”直接预览完整删除。应用只修改当前草稿，一次撤销恢复；显式保存才写入原文件。保留标题行注释为独立注释、其他独立注释、原文字节、BOM、换行和其他字段；删完最后一个字段保留明确的空映射。删除后选择相邻字段或空父映射，不增加页面控件或操作层级。

锚点、引用、标签、复杂键、集合及与列表起始符共用的含糊布局继续局部说明并定位源码，草稿仍保留。延续后续输入、迟到结果、切换文件、保存失败重试和外部冲突副本保护。

检查进行中；`community-unsigned`，企业 `releaseCandidate=false`。当前公开仍为1.3.0，本版尚未发布。NSIS实际安装与MSI构建摘要分别记录，应用内更新实际观察独立pending。
