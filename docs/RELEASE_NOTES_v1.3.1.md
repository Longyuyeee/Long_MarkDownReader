# v1.3.1：YAML多行字段删除

- 在结构提纲右键“删除字段…”，直接预览完整多行字段的删除，应用只改草稿，保存才写入原文件。
- 普通多行文字、折叠文字和空文字都可删除；保留标题行注释、独立注释、其他字段原文及BOM/换行，最后一个字段删除后仍是空映射。
- 删除后定位相邻字段或空父映射，支持连续删除与一次撤销；保护后续输入、迟到结果、换文件、保存失败重试和外部冲突完整副本。
- 修复“定位源码”退出弹窗后的焦点接续；保留全部既有功能、六种风格和正常动效，不增加常驻控件。

631项格式、新12项页面任务、18组风格/窗口及原有12项复制排序回归通过。完整发布检查、Rust1464项功能及1项性能、84组/782项安装版功能任务通过。NSIS、MSI与SHA256SUMS.txt三份公开附件已回下载核对。
