## 🎨 主题系统全面扩展

### 新增功能

  - 🍦 **奶油温暖** (cream) - 米黄奶油色，温暖治愈
  - 💜 **紫梦幻境** (purple) - 淡紫薰衣草，梦幻神秘

  - 原有 5 个：白色、绿色、蓝色、粉色、深色

#### Vditor 编辑器智能跟随
- **自动主题切换**：编辑器主题跟随系统深色/浅色模式
- **智能代码高亮**：切换主题时自动选择匹配的代码高亮方案
  - 深色主题 → 深色代码主题（atom-one-dark、github-dark 等）
  - 浅色主题 → 浅色代码主题（github、vs、xcode 等）
- **实时同步**：主题更改立即生效，无需重启

#### 可视化主题选择器
- **预设卡片网格**：设置页新增精美卡片布局
- **直观展示**：图标 + 名称 + 描述 + 标签（色调+风格）
- **一键应用**：点击卡片立即应用完整配置
- **活动状态**：当前预设高亮显示

### 技术改进

- **新增配置文件** `src/config/themePresets.ts`：集中管理预设配置
- **扩展样式系统** `src/styles/themes.scss`：3 个新色调的完整 CSS 变量定义
- **优化主题监听** `src/views/LibraryMode.vue`：智能判断深浅色并自动切换代码高亮
- **重构设置界面** `src/views/SettingsView.vue`：预设卡片网格 + 高级定制选项
