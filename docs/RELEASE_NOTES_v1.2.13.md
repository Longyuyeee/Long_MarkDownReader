# Long编辑 v1.2.13：XML 元素复制

XML“元素与问题”提纲右键“复制元素”，预览后在原元素后插入完整副本，保留属性、命名空间、文字、CDATA、内部注释及排版。支持同名元素、空元素和连续复制，不自动改写业务标识符；父级混合内容或外部注释归属不明确时，局部提示并定位源码。

沿已有差异预览、独立撤销、草稿接续、保存失败重试和冲突副本保护未保存内容，保留全部功能、风格和正常动效，不增加常驻表单。

未签名 Windows 社区版，完整发布检查与 497 项安装版功能任务通过，NSIS、MSI 与 `SHA256SUMS.txt` 三份公开附件已重新下载核对通过。应用内自动更新实际观察仍待完成，与手动安装升级分别记录。
