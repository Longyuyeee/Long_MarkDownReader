# v0.6.0 主题系统升级文档

## 概述

本次更新将主题系统从 5 个基础色调扩展到 **8 个独特风格**，并新增 **10 个精心设计的主题预设**，实现了色调（theme）+ 风格（style）+ Vditor 渲染配置的完整组合系统。

## 新增色调 (3 个)

### 1. Cream（奶油温暖）
- **色调代码**: `cream`
- **背景色**: `#faf7f2` (米黄奶油色)
- **主色**: `#e67e4d` (温暖橙色)
- **适用场景**: 温暖治愈、长时间阅读
- **风格搭配**: 推荐 soft（柔和）

### 2. Purple（紫梦幻境）
- **色调代码**: `purple`
- **背景色**: `#f6f4fb` (淡紫薰衣草色)
- **主色**: `#7c3aed` (神秘紫罗兰)
- **适用场景**: 梦幻神秘、创意灵感
- **风格搭配**: 推荐 glass（玻璃）

### 3. Amber（琥珀复古）
- **色调代码**: `amber`
- **背景色**: `#fef8f1` (琥珀暖黄)
- **主色**: `#d97706` (复古琥珀金)
- **适用场景**: 温暖复古、知识沉淀
- **风格搭配**: 推荐 soft（柔和）

## 技术实现

### 1. 样式系统扩展
**文件**: `src/styles/themes.scss`

新增了 3 个色调的 CSS 变量定义：
```scss
body[data-theme="cream"] { ... }
body[data-theme="purple"] { ... }
body[data-theme="amber"] { ... }
```

每个色调都定义了完整的变量集：
- `--theme-bg`: 主背景色
- `--theme-surface`: 表面层背景
- `--theme-primary`: 主题色
- `--theme-text`: 文字颜色
- `--text-secondary` / `--text-tertiary`: 次要文字

### 2. Store 状态扩展
**文件**: `src/store/app.ts`

- 扩展 `THEME_MAP` 增加 3 个新色调映射
- 更新 `theme` 类型定义支持新增色调
- 所有主题相关逻辑自动支持新色调

### 3. 设置页 UI 升级
**文件**: `src/views/SettingsView.vue`

#### 新增预设卡片网格
- **布局**: 响应式网格，每个卡片 200px 最小宽度
- **内容**: 图标 + 名称 + 描述 + 标签（色调 + 风格）
- **交互**: 点击应用，hover 高亮，active 状态显示边框光晕
- **样式**: 支持 6 种风格的视觉呈现

#### 导入预设配置
```typescript
import { themePresets, type ThemePreset } from '../config/themePresets'
```

#### 核心函数
- `applyPreset(preset)`: 应用完整预设（色调 + 风格 + 代码主题）
- `isPresetActive(preset)`: 判断预设是否激活
- `getThemeLabel(theme)` / `getStyleLabel(style)`: 获取标签文本

### 4. Vditor 主题跟随
**文件**: `src/views/LibraryMode.vue`

#### 初始化时智能判断
```typescript
const isDarkTheme = store.theme === 'dark'
const vditorContentTheme = isDarkTheme ? 'dark' : 'light'
const vditorEditorTheme = isDarkTheme ? 'dark' : 'classic'
```

#### 主题切换监听优化
- 监听 `store.theme` 变化
- 自动判断深色/浅色系
- 智能切换代码高亮主题（深色 ↔ 浅色）
- 同步 Vditor 内容渲染主题

**深色代码主题**:
- atom-one-dark
- github-dark
- dracula
- vs2015
- tokyo-night-dark
- monokai
- native

**浅色代码主题**:
- github
- vs
- xcode
- atom-one-light

## 用户体验提升

### 1. 一键应用预设
用户无需分别选择色调、风格、代码主题，点击预设卡片即可一键应用完整配置。

### 2. 实时预览
所有主题更改立即生效，无需重启应用。

### 3. 智能适配
- 切换到深色主题时，自动切换深色代码高亮
- 切换到浅色主题时，自动切换浅色代码高亮
- 编辑器背景色跟随主题色调

### 4. 保留高级定制
预设下方保留"高级定制"区域，允许用户精细调整每个参数。
