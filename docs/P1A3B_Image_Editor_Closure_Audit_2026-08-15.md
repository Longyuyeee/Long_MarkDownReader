# P1-A3B 图片基础编辑收口审计

审计日期：2026-08-15

阶段状态：已完成并具备真实桌面证据

## 需求对齐

图片编辑继续位于初版“左侧资料库 + 右侧编辑区”结构内，没有打开新页面。资料库内 PNG/JPEG/WebP/BMP 使用可靠副本编辑；外部图片、GIF、ICO、AVIF 仍只读，源文件不会被覆盖。

## 完成能力

- 旋转、水平/垂直翻转、精确数值裁剪、锁定比例缩放、PNG/JPEG/WebP/BMP 转换。
- JPEG 质量 `1–100`，默认 `85`；非 JPEG 不展示伪质量控制。
- EXIF 方向在像素层归一，副本重新编码并移除 EXIF、GPS、注释等容器元数据。
- 裁剪、缩放和格式参数均通过后端边界验证；保存继续执行源摘要冲突保护、目标不覆盖、原子新建、结构复读与源文件不变确认。

## 实际审计与修复

真实桌面自动化输入裁剪 `x=120, y=60, 600×360`，再锁定比例缩放到 `300×180` 并以 JPEG 质量 `72` 保存。首轮证据发现缩放比例错误地引用原图 `960×540`，界面计算为 `300×169`；已改为引用裁剪后的工作尺寸并重新采集，界面与落盘结果均为 `300×180`。

## 验收证据

- 1280×800：编辑面板位于右侧，宽度 286 px，主舞台仍有 723 px，无文档横向溢出。
- 720×680：编辑面板响应式移动到预览区下方，宽度 509 px，控制可滚动到达，无文档横向溢出。
- 后端报告：`saved_verified`、JPEG 质量 72、方向归一、元数据已清理、源文件未变、副本复开。
- 两种视口运行时错误均为 0；证据 JSON 不包含本机源/目标路径或用户内容。
- 证据目录：[`evidence/p1a3b-image-editor`](./evidence/p1a3b-image-editor)。
