# P1-B2B2 PDF 文本表单可靠副本工作区审计

审计日期：2026-08-15

阶段状态：基础拉丁单行文本闭环完成，下一步扩展 Unicode 与字段类型

## 需求对齐

表单编辑继续位于原 PDF 右侧工作区，不打开新界面；左侧资料库、文档标签、PDF 工具栏和页面阅读区均保持原结构。外部 PDF 无填写入口。

## 实现与边界

- `inspectable` 且无风险的唯一命名单行 `Tx` 字段出现副本文本输入；多行、密码、动作和其他类型保持只读。
- 草稿变化立即使旧验证失效；必须先完成隔离验证，得到输出摘要后才能可靠另存。
- UI 明示源 PDF 与已有文件不会覆盖，并沿用原有紧凑字号、主题变量、状态提示和侧栏滚动。
- 当前只接受基础拉丁值；Unicode 字体嵌入、复选框、单选和选择字段不在本阶段能力声明内。

## 真实桌面证据

临时标准 AcroForm 在真实 Tauri WebView2 中完成 `Alice Example -> Bob QA`：1280×800 与 720×680 均保持原工作区结构、根级横向溢出为 0、验证和保存操作可达。新 PDF 复开后规范字段值为 `Bob QA`，关联 Widget 具有非空正常外观；源 SHA-256 不变，运行时错误为 0。截图和结构化证据位于 `docs/evidence/p1b2b2-pdf-form-copy/`，不含用户内容。
