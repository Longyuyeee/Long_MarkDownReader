# 查找和修复附件

在文件栏右键文件，选择“更多操作 → 管理附件…”，或打开笔记后使用“文档操作 → 管理附件…”。查看 Markdown 笔记时会使用当前草稿，不会为了查询自动保存。图片目录、`笔记名.assets` 和软件插入图片使用的 `.assets` 现在也能从文件栏展开和整理。

选择一项可查看实际路径、引用行及可用状态，打开文件或查看所在位置。“查看引用”查找资料库内哪些 Markdown 笔记使用它，也包括当前窗口里已打开的完整未保存笔记。同一篇以当前草稿为准：刚加的引用会显示，刚删的引用不会从磁盘旧文中重复出现。结果标明“未保存”或“已保存”，显示行号和引用处数；点击复用已打开的笔记，保留当前输入与阅读位置。查询不会自动保存。

查询期间或点击结果前若有新输入，会提示“刷新引用”，重新查找即可。读取失败或超限也在弹窗内提示，仍可刷新、返回和关闭。弹窗的“检查范围”可按需展开：其他窗口的草稿、库外文档和非 Markdown 引用不在本次范围；单篇 2 MiB、总计 32 MiB 等限制沿用。其他类型的文件也可从右键查找引用。没有结果不表示所有格式、库外文档或其他窗口的未保存内容都已经检查过。

文件丢失或需要换一份时，选择“更换引用…”。选库内文件直接关联；选库外文件会保留原件、防覆盖复制到笔记附件目录。确认“应用到草稿”只更改这篇笔记的对应引用，其他正文和原附件保留，可以撤销，仍需手动保存笔记。取消更换时，已生成的附件副本仍保留在目录中。

移动或改名仍使用文件栏已有操作，图片与文档链接沿用原事务接续；可从右键“最近操作…”查看及按项还原。遇到新输入、正在保存、路径变化或不能可靠识别的语法时，软件会保留当前状态，在弹窗内说明原因，不以旧预览覆盖草稿。
