# 查找和修复附件

在文件栏右键文件，选择“更多操作 → 管理附件…”，或打开笔记后使用“文档操作 → 管理附件…”。查看 Markdown 笔记时会使用当前草稿，不会为了查询自动保存。图片目录、`笔记名.assets` 和软件插入图片使用的 `.assets` 现在也能从文件栏展开和整理。

选择一项可查看实际路径、引用行及可用状态，打开文件或查看所在位置。“查看引用”查找哪些已保存的 Markdown 笔记使用它，点击结果打开对应笔记。其他类型的文件也可从右键查找引用。没有结果不表示所有格式、库外文档或其他窗口的未保存内容都已经检查过。

文件丢失或需要换一份时，选择“更换引用…”。选库内文件直接关联；选库外文件会保留原件、防覆盖复制到笔记附件目录。确认“应用到草稿”只更改这篇笔记的对应引用，其他正文和原附件保留，可以撤销，仍需手动保存笔记。取消更换时，已生成的附件副本仍保留在目录中。

移动或改名仍使用文件栏已有操作，图片与文档链接沿用原事务接续；可从右键“最近操作…”查看及按项还原。遇到新输入、正在保存、路径变化或不能可靠识别的语法时，软件会保留当前状态，在弹窗内说明原因，不以旧预览覆盖草稿。
