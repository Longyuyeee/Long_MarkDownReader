# 保存的搜索与动态集合契约

更新日期：2026-07-22
状态：W7-2 / FR-WB-002 已完成

## 1. 产品行为

智能集合保存查询条件，不保存结果副本。每次从资料库侧栏或专业工作台打开集合时，应用重新调用现有跨格式搜索：有效索引优先，索引缺失、损坏或过期时实时扫描降级。因此新增、修改或删除用户文件后，集合结果会自然更新。

每个保存项包含：

- 稳定设备 ID、显示名称和查询文本。
- 所属的已登记知识库路径。
- 零个或多个可索引文件格式过滤器；空过滤器表示全部格式。
- 创建时间，用于工作台和侧栏排序。

保存项位于应用设备配置，不写入知识库，不进入图谱，也不是用户内容事实源。删除集合不会删除文件、索引或搜索结果指向的内容。

## 2. 安全与规模

- 最多保存 64 个集合；名称最多 80 个字符，查询最多 500 个字符。
- 单个集合最多包含 8 个互不重复的格式过滤器。
- 格式必须来自共享文件格式注册表，并声明可索引能力。
- 集合必须属于当前配置中已登记的知识库。
- ID 必须非空、唯一且不超过 80 个字符。
- 配置写入继续使用现有可靠写入；失败时前端内存状态回滚，不显示假成功。

后端在每次保存完整配置前执行上述验证，不能依赖前端控件约束。

## 3. 工作流

资料库全文搜索支持格式多选过滤和“保存当前搜索”。集合面板负责重开与删除；专业工作台显示当前知识库最近创建的集合并直达动态结果。标签查询也可保存，格式过滤仍遵守 Markdown 结果类型。

W7-2 不提供固定结果集、共享云集合、跨设备同步或知识库内专有集合文件。若未来需要可移植集合，应先设计开放格式和迁移契约，不能直接把设备配置宣传为可共享内容。

## 4. 验收证据

- Rust 回归覆盖合法配置、重复格式、未知格式和未登记知识库拒绝。
- TypeScript 和生产构建覆盖配置往返、失败回滚、路由查询与格式过滤。
- 原有索引化搜索回归继续证明索引优先和实时降级；本批不复制搜索实现。
- Tauri Debug 构建验证配置 IPC、资料库侧栏和工作台路由完整链接。
- 发布审计发现 Sass 传递依赖 `immutable 5.1.5` 命中新披露的高危拒绝服务公告；锁文件最小升级至 `5.1.9` 后，`npm ci` 可复现且生产依赖审计为 0 漏洞。
