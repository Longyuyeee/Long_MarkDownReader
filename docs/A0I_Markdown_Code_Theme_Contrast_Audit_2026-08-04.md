# A0I Markdown 代码主题对比度审计

日期：2026-08-04
对应需求：UX-20
结论：代码与主题合同已完成，等待下一安装包复测。

## 根因与修复

- 原实现会同时加载应用主题、Vditor 内容主题和任意 Highlight.js 风格；首次打开与主题切换的处理还不一致，可能形成深色背景配暗文字或浅色背景配亮文字。
- 新增统一 Markdown 外观解析器。浅色、深色和高对比模式只使用各自兼容的 Vditor/高亮资源，并覆盖首次加载、资料库编辑器、外部编辑器和实时切换。
- 九个应用主题统一定义代码块背景、正文、关键字、字符串、数字、注释、函数、变量、操作符、光标和选区令牌；Highlight.js 外部风格不能再覆盖核心可读颜色。
- WYSIWYG、IR、源码和预览共用同一合同，不改变 Markdown 内容或保存逻辑。

## 自动验证

- `npm run build`：通过，前端生产构建完成。
- `check:markdown-code-theme-contrast`：覆盖全部九个主题；语法文字最低达到 `4.5:1`，光标最低达到 `3:1`。
- 实际计算最低值：浅色 `5.06:1`、深色 `7.07:1`、高对比 `8.23:1`。
- 专项门禁已加入 `ci:patch-release`。

## 安装包复测

1. 用包含 TypeScript 代码块、行内代码、注释、字符串和模板字符串的 Markdown 样本复测九个主题。
2. 分别检查所见、IR、源码、预览和外部 Markdown；光标、选区及横向滚动必须清晰。
3. 编辑中实时切换浅色、深色和高对比主题，不应闪现黑字黑底、浅字白底或遗留旧高亮背景。
