# 1.2.7—1.2.8：在结构中直接整理和复用内容

状态：1.2.7 数组项位置调整已正式发布，本路线 1/2 版完成；[发布记录](V1_2_7_Unsigned_Community_Release_Audit_2026-10-23.md)。下一版 1.2.8 字段与数组项复用尚未实施，继续按既定顺序推进，保留全部现有功能、风格和正常动效。

## 依据：避免重复开发已有功能

当前 `TextEditorView.vue` 已提供带选区、逐处替换及全部替换预览的 `DocumentFindReplace`，不是待补的空白能力。`JsonEditorView.vue` 及 Rust `formats/json.rs` 已支持修改标量、对象键改名、对象添加字段、数组末尾追加及删除；节点右键同时提供定位和复制源码。当前缺少数组项位置调整，也缺少直接复用一整个字段或数组项的动作，用户需要手工剪贴并处理逗号。

| 版本 | 用户要完成的事 | 入口 |
| --- | --- | --- |
| 1.2.7 | 把 JSON 数组中的一条记录调到相邻位置，保留内容 | 数组项右键：上移、下移，边界禁用 |
| 1.2.8 | 复用相似配置或记录，再只修改不同部分 | 字段右键：复制为新字段…；数组项右键：复制此项 |

## 1.2.7：数组项位置调整

依据当前分析结果定位父数组和完整项范围，只移动同一数组内的相邻项，不用旧路径或字节偏移猜测已经变化的内容。支持标量、对象、嵌套数组，保留原始数字文本、字符串转义、前导缩进与换行；不通过整体解析后重新序列化来改写全文。

从用户选中的项发起，边界明确禁用；完成后继续定位到原记录的新位置。正常整理不要求输入目标序号或手动剪贴。复用现有结构变更流程和必要的差异预览，不叠加第二次确认；成功作为一次具名源码编辑，可与其他未保存编辑交错撤销重做，仍由原保存入口写入。

JSONC 先核对相邻项间注释的归属：能够完整保留才支持；含归属不明的注释则具体说明该次操作暂不可用，不默默移丢注释、不扩大为“支持任意 JSONC 无损重排”。只读、大文件分段、无效源码、分析过期和异步切换来源沿既有状态禁用或拒绝，原文和其他草稿保持。

核对用户任务：首尾边界；中间对象或嵌套项移动和一次撤回；长数字及转义原文；有其他未保存内容时接续；来源变化与保存失败、外部冲突；大小窗口和主题下的菜单及定位。仅处理当前 JSON/JSONC 支持范围，不扩成 YAML/XML/TOML 结构搬运。

## 1.2.8：字段和数组项复用

复用当前草稿中的完整节点，而不是重新读磁盘。数组项复制到原项旁，副本成为独立内容，选择和定位跟随副本；无需新增常驻面板。对象字段用“复制为新字段…”弹窗输入新键，默认选中建议名称，沿现有对象添加字段能力校验重名，不能覆盖同名字段；出错保留输入，不要求用户重新操作。

保留节点内部原始文本、嵌套结构、长数字、字符串转义和可明确归属的注释，不改动其他属性或数组项。复用当前结构差异及会话机制，避免增加另一套编辑、保存和冲突流程；一次复制形成一个可撤销步骤，与 1.2.7 的移动及现有改名、改值交错使用仍对应正确内容。

核对用户任务：复制标量及多层对象；新字段重名纠正；数组副本独立修改；复制和移动交错撤销；JSONC 原文与注释边界；保存重开、失败重试与来源切换。限制和不支持原因应贴近当前动作，不能遮住整个工作区。

## 每版交付

一版完成后再推进下一版。按受影响功能核对实际用户任务和保存保护，固定同一 Windows 安装包完成实际安装、重开和回归再发布。更新 README、Release、开发摘要和实际证据；浏览器模拟 IPC 与原生安装检查分别记录，规划不当作已实现功能。
