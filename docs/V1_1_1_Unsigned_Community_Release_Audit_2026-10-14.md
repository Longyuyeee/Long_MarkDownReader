# v1.1.1 社区版发布收尾

当前状态：发布准备中，公开版本仍为 v1.1.0。本文件随实际构建、安装与发布结果更新，不继承上一版验收结论。

本版范围为收集箱、标签切换、智能集合、文内标签、关系面板及跨格式手动关系六项用户体验改进。既有格式能力、主题与动效保留；不新增 Office/PDF 写回或网页采集能力。

发布渠道继续为 `community-unsigned`，企业发布能力矩阵保持 `releaseCandidate=false`。社区版提供 MSI/NSIS 与 SHA-256，可通过官方 Release 手动下载安装或软件内确认更新，Windows 的“未知发布者”提示继续如实说明。
