# v1.3.8：按处选择替换

- 四种结构化源码编辑器的现有预览支持逐处勾选，默认全选；翻页保留选择，底部显示实际应用数量，全不选时禁止提交。
- 只修改选中的位置，未选择内容及其他草稿保持原样；可一次撤销／重做，显式保存才写回。
- 应用后回到当前编辑区，可直接继续输入或撤销；取消返回原查找入口，切换文件不抢焦点。
- 正文、查询、范围或已检测状态变化后停用旧预览；刷新重新全选当前结果并明确提示。保留原有直接替换、只读保护、全部风格及正常动效。

8组组件重建／复用、72组风格／窗口及4个深色窄窗口；上版预览、选区、查找和位置接续分别8组／72组回归通过。固定源码完整检查、Rust1464项功能及1项性能、91组/844项安装任务通过。4份保存结果的BOM/CRLF及全文逐字节核对，实际界面8张截图已核对。

NSIS、MSI和SHA256SUMS.txt三份公开附件回下载核对通过。未签名社区版，可手动下载安装；NSIS完成实际安装、手动升级及卸载，MSI完成构建与摘要核对。应用内1.3.7→1.3.8自动更新实际观察独立待完成。

沿用既有预览数量／文字预算及JSON大文件分段边界；跨文件替换、重启后预览或选择持久化不计入本版。
