# LongEdit v1.1.22

文件整理之后，重启也能查清改了什么、现在在哪。

- 文件栏空白处右键 **最近操作…**（文件右键位于“更多操作”内），查找移动、改名和复制记录，查看原位置与操作后位置；后续又移动或改名时继续接续定位。
- 对可核对的移动和改名，支持 **还原此项**；只处理所选项目，其余记录保留。图片、链接和历史沿用原有接续逻辑。
- 文件或关联文档后来有修改、原位置出现同名文件时，保留现状并说明原因。未保存草稿继续保留，不因查看记录强制保存。
- 未完成的移动可直接进入原有核对弹窗；复制记录只供查看，清除记录不会删除文件和附件。

本版只记录升级后发生的整理操作。较大文件和暂不能充分核对的项目提供位置记录；不提供任意正文修改或永久删除的万能撤销。

Windows 社区版提供 NSIS 和 MSI，签名状态沿用 community-unsigned。可手动下载安装；应用内自动升级的真实观察与安装包发布分别记录。
