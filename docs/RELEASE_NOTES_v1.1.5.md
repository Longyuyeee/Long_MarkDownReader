# v1.1.5 · 安全导入与搜索一致性

本版补强现有资料整理和查找流程，不增加额外归档步骤。

- 外部资料同名时保留两份，不覆盖已有正文或图片。Markdown 本地图片迁移到独立资源目录，缺失或越界明确失败，不报告虚假完成。
- 多文件导入逐项显示结果，只重试失败项；导入后列表刷新失败不会重复复制已成功文件。未保存的外部笔记要求先保存，不自动代存。
- 命令面板和资料库复用知识搜索。支持多个关键词、双引号短语、`-排除词`；命令面板可选当前资料库或全部已配置资料库，结果在主编辑区打开。
- 修复快速输入、关闭重开和切换命令模式时旧结果回填；加载、无结果、失败及部分库不可用分别提示。
- 跨库打开前捕获尚未提交的编辑输入，保护未保存草稿；修复范围下拉遮挡与短窗口键盘结果滚动。

社区版安装器未做 Authenticode 签名，Windows 可能显示未知发布者。发布前此文件为候选说明；安装器摘要、升级及安装态结果以本版发布审计为准。
