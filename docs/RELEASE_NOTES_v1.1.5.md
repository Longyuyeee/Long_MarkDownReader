# v1.1.5 · 安全导入与搜索一致性

本版补强现有资料整理和查找流程，不增加额外归档步骤。

- 外部资料同名时保留两份，不覆盖已有正文或图片。Markdown 本地图片迁移到独立资源目录，缺失或越界明确失败，不报告虚假完成。
- 多文件导入逐项显示结果，只重试失败项；导入后列表刷新失败不会重复复制已成功文件。未保存的外部笔记要求先保存，不自动代存。
- 命令面板和资料库复用知识搜索。支持多个关键词、双引号短语、`-排除词`；命令面板可选当前资料库或全部已配置资料库，结果在主编辑区打开。
- 修复快速输入、关闭重开和切换命令模式时旧结果回填；加载、无结果、失败及部分库不可用分别提示。
- 跨库打开前捕获尚未提交的编辑输入，保护未保存草稿；修复范围下拉遮挡与短窗口键盘结果滚动。
- 修复选过范围或打开被阻止后 Esc 无法关闭面板；取消时返回原编辑焦点，换库持久化期间明确等待并避免重复打开。
- 修复 Windows 上通过“打开外部文件”创建独立窗口可能卡住的同步调用问题，保持原有文件授权和编辑入口。
- 修复 Windows 规范路径格式不同时，搜索结果明明属于已配置资料库却无法打开的问题；不放宽目录边界检查。
- 修复 Markdown 保存完成后，相同内容的延迟通知又误标“未保存”、导致无法换库或存入资料库的问题；真正的新输入仍受草稿保护。
- 修复从搜索切换资料库后文件栏可能一直空白的问题；库内层级展开和正常文件夹动画保留，无需用户手动刷新。

社区版安装器未做 Authenticode 签名，Windows 可能显示未知发布者。发布前此文件为候选说明；安装器摘要、升级及安装态结果以本版发布审计为准。

## 怎么使用

查资料时可直接输入普通关键词；输入 `项目 预算 -旧版` 表示一份资料需要同时含“项目”和“预算”，并排除含“旧版”的资料。输入 `"交付范围"` 则匹配这段连续文字。点击顶部“命令”或按 `Ctrl+P` 打开面板，在输入框旁选择当前资料库或全部资料库。这里的“全部”只指你已添加的资料库，不扫描整台电脑。

把外部文件拖进资料库时，同名项自动保留两份，不替换旧内容。部分失败会列出未完成文件：修正缺图或路径后，点“重试未完成的…项”；已完成项不再导入。若提示只是目录刷新失败，刷新列表即可，不要再次拖入整批文件。

外部笔记有未保存修改时，先点击保存，再存入资料库。跨库打开搜索结果同样需要先保存当前草稿；软件不会替你保存或直接丢弃修改。

## 支持边界

Markdown 附带图片迁移支持 UTF-8、单份最多 20 MiB、512 处图片路径，以及所选文档目录内的普通相对图像路径（包括子文件夹）。本地图片写入新的独立 `.assets` 目录，仅改导入副本中的对应引用，原文和原图不变。远端/data 图片引用保留，不代表下载了远端资源。

本版不是完整附件归档：不会搬迁所有文档超链接或任意附件；授权目录外的图片、缺失资源、非图像目标及不能可靠识别的复杂语法会拒绝，不会猜测替换。跨库有暂时不可用的资料库时会说明不完整范围；最多显示 200 条结果，可以加关键词缩小范围。

导入副本与图片资源目录仍通过普通相对链接关联。本版不包含之后单独移动 Markdown 文件时的资源引用重写；这与导入时防覆盖、复制图片是两个不同能力，不能混为一项已完成验收。
