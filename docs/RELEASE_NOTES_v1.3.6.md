# v1.3.6：只查找和替换选定的一段内容

- JSON、YAML、XML、TOML的现有查找面板增加“仅选区”和匹配数量；用户主动开启后才限定范围。
- 上一项／下一项、选中全部、替换当前项和全部替换都遵守选区，普通选文Ctrl+F仍带入查找词。
- 范围随编辑和撤销／重做接续；各文件独立保留。快速切换时继续校验范围，不抢焦点或跳到匹配。
- 外部正文变化或范围被删除时保留输入并暂停替换，可重新选区或关闭范围。
- 替换只修改当前草稿，显式保存才写回；只读保护、全部风格及正常动效保留。

8组组件重建／复用、72组风格／窗口及4个深色窄窗口，上版查找与阅读位置各8组／72组回归通过。固定源码完整检查、Rust1464项功能及1项性能、89组/826项安装任务通过；4份保存文件的BOM/CRLF和全文逐字节核对。

NSIS、MSI和SHA256SUMS.txt三份公开附件回下载核对通过。未签名社区版，可手动下载安装；NSIS完成实际安装、手动升级及卸载，MSI完成构建与摘要核对。应用内1.3.5→1.3.6自动更新实际观察独立待完成。

范围接续限当前窗口打开的标签，关闭后重开及切换归属重新开始。JSON大文件分段查找沿原边界；跨文件替换和软件重启后的范围持久化不计入本版。
