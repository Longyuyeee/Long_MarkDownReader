# 可重建本地知识索引契约

更新日期：2026-07-21
实施批次：I7-1 / FR-INDEX-002

## 1. 定位

本地知识索引是从用户文件派生的性能缓存，不是内容事实源。删除、损坏或版本不兼容时，应用必须能只依赖知识库文件、公开 sidecar 和格式适配器重新构建索引。

索引保存在 Tauri 应用缓存目录的 `knowledge-index-v1/{workspaceFingerprint}/snapshot.json`。知识库内不创建隐藏索引文件，Git 仓库和用户同步目录不会被缓存污染。

## 2. 快照内容

schema v1 包含：

- `workspaceFingerprint`：规范化知识库路径的摘要，用于隔离多个知识库。
- `builtAt`：构建完成时间。
- `sources` 与 `sourceDigest`：可索引源文件及 PDF 批注/OCR sidecar 的相对路径、大小和纳秒级修改时间。
- `objects`：G7-3 的 KnowledgeObject，以及注册表中 `text` indexer 输出的纯文本/Mermaid 文件级对象。
- `relations`：统一关系的来源、目标、类型和方向。
- `searchSegments`：向后兼容的跨格式搜索段；保存标题、路径、对象类型、匹配类型和正文，并为 PDF 保存页码、批注 ID 与提取状态。旧快照缺少该字段时按空数组读取并回退实时扫描。

索引不保存 API Key、连接字符串、系统凭据或知识库外路径。工作区路径只参与本地缓存目录摘要，不写入公开格式文件。

## 3. 生命周期状态

| 状态 | 含义 | 用户操作 |
|---|---|---|
| `missing` | 尚未构建或已删除 | 重建 |
| `building` | 正在扫描和可靠写入 | 查看进度，不可重复构建或删除 |
| `ready` | schema、工作区和源清单均匹配 | 可使用 |
| `stale` | 用户文件或 sidecar 已变化 | 重建 |
| `corrupt` | JSON、大小、schema 或工作区标识无效 | 删除或重建 |
| `error` | 最近一次构建失败 | 查看错误并重试 |

资料库侧栏显示状态、对象/关系数量及重建、删除入口。重建采用同目录临时文件、恢复备份和原子提升；旧快照只有在新快照完整写入后才会被替换。

## 4. 安全与规模边界

- 单个快照最大 128 MB。
- 最多 100,000 个源文件、250,000 个对象、500,000 条关系和 500,000 个搜索段。
- 符号链接、隐藏目录和 `.assets` 目录不进入清单。
- 删除命令只能删除由固定缓存根和工作区摘要计算出的目录，不能接受任意缓存路径。
- 构建中拒绝并发重建和删除。

## 5. 当前边界

I7-1 完成版本化快照、全量重建、删除、状态、进度和源签名失效检测。I7-2 增加 Markdown、纯文本、Canvas、Table、OPML 和 PDF 的搜索段；PDF 正文、OCR 与批注分别保留页级定位。

全文搜索只在快照为 `ready` 且 `searchSegments` 非空时读取索引。缺失、旧快照、构建中、错误、损坏和 `stale` 状态均回退实时扫描，因此删除缓存或重建失败不会让用户失去搜索能力。下一次重建仍为全量构建，不宣称已实现文件级增量更新。
