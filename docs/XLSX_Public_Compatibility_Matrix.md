# XLSX 公开兼容性矩阵

更新日期：2026-07-22
适用引擎：`calamine-ooxml-ironcalc-v14`
机器事实源：`shared/xlsx-compatibility-matrix.json`

## 1. 状态定义

- **支持**：能力已进入产品路径，并由自动化测试验证。
- **受限**：只支持公开说明的子集，不能推断为 Excel 等价。
- **保真**：不读取或编辑该对象，但保存其他内容时保持原 OOXML 对象。
- **计划**：尚未开放，不应出现在可用功能承诺中。

“可读取”“可编辑”“可计算”“可往返”是四件不同的事。本矩阵按维度公开能力，避免用一个笼统的“支持 XLSX”掩盖真实边界。

## 3. S6-10 命名区域契约

后端直接解析 `xl/workbook.xml`，保留名称、公式、工作簿或工作表作用域、隐藏标记，并只为安全的单一 A1 引用生成导航坐标。常量名称、公式名称、多区域、外部工作簿引用不会被伪装成可导航范围。

工作簿名称框只显示非隐藏且目标 Sheet 存在的单一区域。选择后切换 Sheet、加载对应分页、选中完整范围并滚动到左上角。超过当前 256 列预览边界的范围会明确提示，不会静默跳到错误位置。

命名区域公式由 IronCalc 在内存中显式重算；fixture 使用 `SUM(AmountRange)` 验证草稿修改后的依赖传播。S8-3A 新增受内容签名保护的名称事务：工作簿级与 Sheet 级安全单一 A1 区域可创建、更新引用、改名和删除，写回后执行包校验与语义重读。名称遵循 Excel 长度、字符、单元格引用和作用域唯一性约束；隐藏名称及 `_xlnm.*` 系统名称只读。为避免静默破坏公式，名称被公式引用时拒绝改名或删除；当前不做公式迁移。

## 4. S6-10 Fixture 证据

`compatibility-baseline.xlsx` 现在固定包含：

- 工作簿级 `AmountRange`、`ReportWindow`、`TaxRate`；
- Sheet 级 `Details!Codes`；
- 日期、带时间日期以及各自数字格式；
- 缓存为 `#DIV/0!` 的错误公式；
- 引用 `AmountRange` 的公式与缓存结果。

测试覆盖读取语义、全局/局部作用域、名称导航所需坐标、命名区域重算，以及修改普通单元格后 `workbook.xml`、日期和错误值保持不变。

## 5. S6-11 结构化数据契约

冻结窗格通过独立、受内容签名保护的结构命令写回，仅修改目标 Sheet 的 `sheetView/pane`；存在未保存单元格草稿时前端禁止结构写回，外部修改冲突会整次拒绝。

工作面读取工作表 `autoFilter`、关系文件指向的 Table 定义和数据验证规则。S8-2C 将排序筛选从纯会话状态升级为签名保护的 OOXML 事务：普通 Table 与工作表 AutoFilter 均可写入单列“包含”条件、单列升/降序状态并清除全部条件，重载后恢复同一视图；源数据行顺序不被改写。多列组合、Top10、动态、颜色、图标和日期分组筛选标记为只读，应用新条件时拒绝覆盖，用户明确确认后才允许整组清除。数据区仍最多预加载 50,000 行。

S8-2A～S8-2B 提供 Table 生命周期事务：可从单一连续选区创建普通 Table，把已有普通 Table 扩缩到选区并按首行同步列定义，也可改名、选择内置样式、控制首列/末列与行列条纹，以及转换为普通区域或删除 Table 定义并保留单元格数据。事务同步维护工作表 `tableParts`、关系部件、内容类型和 Table XML；全局名称冲突、结构化公式引用、活动筛选、汇总行、计算列和扩展元数据会整批拒绝。

S8-3B 为数据验证增加独立、签名保护的 OOXML 事务。工作面可从单一连续选区创建列表、整数、小数、文本长度和自定义公式规则，编辑公式、比较方式、错误提示与输入提示，重新应用范围或删除规则；写回同步维护 `dataValidations/@count` 并执行包校验和语义重读。规则范围不允许与另一条规则重叠，受保护 Sheet、外部工作簿引用和包含扩展子节点的复杂规则拒绝编辑。

字面量列表、整数/小数常量比较和文本长度规则继续执行保存前约束；引用公式、命名范围和自定义公式虽然现在可以安全写入和往返，但无法在当前本地验证器中可靠求值，因此不伪装成完整 Excel 验证引擎。验证公式 XML 实体按完整文本重组，避免 `>`、`<`、`&` 被拆段。

S8-3C1 为条件格式增加独立、签名保护的 OOXML 事务。工作面按优先级执行基础数值 `cellIs` 比较并应用 RGB 填充、文字色和粗体，遵守 `stopIfTrue`；连续选区可创建、编辑、重新应用范围或删除单规则条件格式。写回追加 `styles.xml/dxfs` 并维护工作表 `conditionalFormatting/cfRule` 与优先级，之后执行包验证和语义重读。受保护 Sheet、无效范围、非有限数值、无视觉样式及复杂规则拒绝编辑；公式表达式、色阶、数据条、图标集、主题/索引 DXF 和多规则组仍只读并原样保真。

S8-3C2A 开放直接引用比较表达式：左值为同 Sheet 的 `A1/$A1/A$1/$A$1` 单元格引用，右值为有限数字、双引号文本或布尔字面量；数字支持六类比较，文本和布尔仅支持等于/不等于。相对引用以首个 `sqref` 左上角为基准随目标单元格迁移，越界引用不执行。函数、区域、跨 Sheet、外部引用和复合表达式不进入本地求值或编辑路径，但原 XML 继续保真。

S8-3C2B1 开放固定数值阈值双色/三色色阶。工作面按相邻阈值执行 RGB 线性插值，低于或高于端点时使用端点颜色，非数值单元格不着色；创建和编辑要求 2 或 3 个严格递增有限数值及同数量 RGB 颜色。色阶直接写入 `cfRule/colorScale`，不会追加 `styles.xml/dxfs`。`min/max`、百分位、百分比和公式动态阈值需要完整范围统计，当前只读并保真，绝不使用已加载分页样本替代全量数据。

S8-3C2B2 增加后端完整范围统计：工作表分页读取时扫描目标 `sqref` 中全部数值单元格，为 `min/max/percent/percentile` 计算 `resolvedValue`，前端只消费该解析值，不从可见分页推断全局阈值。百分比基于全范围最小/最大值，百分位使用包含端点的线性排名插值。单 Sheet 最多解析 64 条动态色阶，百分位累计最多 1,000,000 个数值；超限或解析后逆序时规则只读。公式阈值仍只读保真。

S8-3C2C1 开放标准 OOXML 非负固定阈值数据条：两个 `num` 阈值满足 `0 ≤ min < max` 时，工作面按比例渲染颜色条，并可编辑颜色、数值显隐和 0～100 条长。写回不追加 DXF；动态阈值、负值轴、方向、边框/渐变等扩展属性只读保真。解析器明确忽略 `x14:` 扩展条件格式容器，避免将其误作基础 `conditionalFormatting`。

S8-3C2C2 将完整范围统计扩展到数据条：`min/max/percent/percentile` 返回稳定解析值，固定阈值可为负数；全正、全负和跨零区间分别渲染，跨零时从按最小/最大值比例计算的自动轴向两侧延伸。标准 `dataBar` 可创建和编辑；`x14:` 负值颜色、显式轴位置、方向、边框及渐变仍只读保真。

S8-3C2D 开放 Excel 2007 标准 3/4/5 图标集。方向、信号灯、旗帜、标志、符号、评级与分区图标族支持读取、轻量语义渲染、创建、编辑、重新应用范围和删除；`num/percent/percentile` 阈值由完整范围解析，并支持严格/包含边界、反向顺序和仅显示图标。写回标准 `iconSet/cfvo` 且不修改 DXF。自定义混合图标、公式阈值及 `x14:` 专属星形/三角形/方框族只读保真；工作面使用 Unicode 语义符号，不宣称复刻 Excel 原生图标像素资源。

S8-3C3A 增加重叠规则管理。工作面可在当前单元格命中的规则间切换，显示类型、全 Sheet 优先级和 `stopIfTrue` 冲突语义；可编辑的独立单规则组可提高或降低优先级。后端按稳定顺序交换并将优先级规范化为连续整数，只改写标准 `cfRule@priority`，因此跨过只读复杂规则时也不会重写公式、DXF 或视觉定义。同一个 `conditionalFormatting/sqref` 容器内的多条规则仍整体只读，规则级拆分、合并、更新和删除尚未开放。

S8-3C3B 将身份扩展为 `groupIndex + ruleIndex`。同一个 `conditionalFormatting/sqref` 容器内，每条规则独立判定可编辑性；受支持规则可逐条更新、删除和参与优先级调整，未知或复杂兄弟规则保持只读。写回只替换目标 `cfRule`，其他 XML 事件原样复制；删除最后一条规则时移除空容器。由于组内规则共享 `sqref`，单条规则不能直接改变选区；显式拆分和重新组合留待后续批次。

S8-3C3C1 开放显式拆分和重新组合。拆分从共享组抽取目标 `cfRule` 原始事件，以当前连续选区建立独立 `sqref` 容器；组合把独立规则原始事件追加到范围完全相同的稳定目标组，再删除空源容器。两种事务不重建公式、阈值、样式、优先级或 DXF。只开放本地可执行的受支持规则，复杂只读规则不能借拆分改变引用语义。

S8-3C3C2 开放复杂条件表达式安全子集。支持 `AND`、`OR`、`NOT` 递归组合、比较两侧 A1 相对/绝对引用及数字/文本/布尔字面量；公式最多 512 字符、8 层嵌套、每个逻辑函数 8 个参数、总计 8 个引用。工作面按首个 `sqref` 锚点执行相对引用和短路求值，并为可见规则自动读取缺失的依赖分页。越界或读取失败不触发样式；区域、跨 Sheet、名称、外部引用、算术、未知函数与超限表达式只读保真。

S8-4A 为绘图对象建立由 Drawing 部件路径、锚点序号和 OOXML 对象 ID 组成的稳定身份。标准 `twoCellAnchor` 对象支持在结构卡片中选择、编辑名称/替代文本，并把当前连续选区应用为新的起止锚点；事务受内容签名、工作表保护、包校验和可靠写回约束，只改写目标锚点或 `cNvPr` 属性，Chart、媒体和关系部件逐字节保持。`oneCellAnchor`、绝对锚点和缺失稳定 ID 的对象继续只读。

S8-4B 开放已有标准图表标题和公式型系列引用。标题只改写现有富文本容器；分类与数值引用必须指向本工作簿中存在工作表的一维 A1 区域、点数相同且单系列不超过 10,000 点，外部、联合、二维和未知结构拒绝写入。修改引用会移除目标系列旧缓存，语义重读后再可靠写回。工作面直接读取源单元格生成柱形、折线、饼图或散点受限预览，最多显示 10 个系列和 60 个数据点；这不是 Excel 样式与布局的像素级复刻。

Fixture 新增首行首列冻结、Details 自动筛选和列表验证，以及 Inventory Table。回归验证冻结窗格写入/取消、签名冲突拒绝、无效列表值拒绝和 Table 部件往返保真。

## 6. S6-12 图表与绘图对象契约

后端仅沿工作表内部关系读取 Drawing 部件，并继续沿 Drawing 关系识别图表与图片；外部关系和 `xl/` 之外的目标不会跟随。页面模型公开稳定对象 ID、名称、替代文本、锚点类型、起止锚点和部件路径；图表额外公开类型、标题以及带稳定序号的系列名称、分类公式和值公式。标准双单元格锚点开放受签名保护的元数据、移动/缩放、已有标准标题和内部一维公式系列引用事务，其他锚点保持只读。

工作面以结构卡片呈现对象，可查看范围和系列来源、选择对象并跳转；选中图表后按真实源单元格生成统一组件预览。当前没有复刻 Excel 的布局引擎、主题样式、坐标轴、标签和图片像素渲染，也不能创建、删除或切换对象类型，因此显示和编辑均为“受限”。

Fixture 的 Inventory Sheet 固定包含柱形图和嵌入图片。回归验证关系解析、锚点、标题、系列公式和替代文本；普通单元格写回后 Drawing XML、关系、Chart XML 与图片二进制必须逐字节保持。

## 7. S6-13 透视表、切片器与外部数据契约

工作簿检查阶段只读取 XLSX ZIP 内部的 Pivot Table、Pivot Cache Definition、Slicer、External Link、Connections 和关系元数据。透视表公开名称、所属 Sheet、缓存 ID、来源类型/Sheet/区域、连接 ID与刷新标记；切片器公开名称、缓存名和所属 Sheet；外部链接只公开对象类型、缓存项数量和目标类别。

所有 `TargetMode="External"` 关系只计数和分类，绝不跟随目标，不发起网络请求，也不读取知识库外文件。连接字符串、命令、凭据以及完整外部路径不会序列化到前端。工作面提供高级数据对象状态条和安全模式提示，但不执行 Pivot Cache 刷新、透视计算、外部查询或切片器筛选。

Fixture 固定包含工作表来源透视缓存、透视表、切片器、外部工作簿关系和带敏感占位连接字符串的数据连接。回归验证脱敏输出，并在普通单元格写回后逐字节保持所有相关部件。

## 8. S6-14 打印布局与保护契约

后端读取单个连续 A1 打印区域、页边距、纸张、方向、缩放/适页、打印网格线与标题、页眉页脚文本，以及工作簿和 Sheet 保护状态。工作面只提供结构化摘要，不模拟 Excel 分页引擎，不生成像素级打印预览，也不开放页面设置和页眉页脚编辑。

保护模型只公开是否启用、是否存在密码保护以及被阻止的操作类别；密码、旧式密码校验值、哈希值和盐不会进入 IPC。受保护 Sheet 的内容、样式、尺寸、合并和冻结窗格写回统一拒绝且文件字节保持不变；本产品不绕过密码、不解锁文件，也不把“可读取保护状态”解释为“可编辑受保护内容”。

Fixture 固定包含 Summary 的 `A1:F5` 打印区域、A4 横向适页、页边距、打印选项和奇数页页眉页脚，以及独立 Protected Sheet 和工作簿结构保护。回归验证完整读取、敏感保护值不序列化、受保护写入拒绝，以及普通单元格写回后页面设置和工作簿保护 XML 逐字节保真。

## 9. S6-15 发布差异、性能与兼容声明

机器发布档案为 `xlsx-progressive-editing-v1`。复杂 fixture 的复合内容、样式与结构写回必须保持 ZIP 部件集合完全一致，只允许目标工作表和 `styles.xml` 变化，所有其他部件解压后逐字节一致；写回后还必须重新读取修改语义。工作簿基准固定覆盖 4 个 Sheet、10,000 行 × 12 列和 1,000 行公式，并对检查、分页、写回、总耗时和文件增长设置 Debug CI 硬预算。

唯一允许的总体产品表述是“XLSX 渐进式编辑（以公开兼容性矩阵为准）”。当前不得宣传“完整 Excel 等价”“100% Excel 兼容”或“无损编辑所有 XLSX 功能”。部分维度的“支持”或“保真”不能推导为整个 XLSX 格式完整等价；正式声明见 `XLSX_Release_Compatibility_Statement.md`。

## 10. 安全与保真边界

S8-1A 的行列隐藏和大纲分组通过独立签名保护事务写回，只修改目标 Sheet 的 `row/col` 状态属性。不同宽度或样式的列区间保持拆分；受保护 Sheet、超过 7 级大纲、重叠列状态和超过 10,000 项的请求整批拒绝。详细契约见 `Workbook_Row_Column_Outline.md`。

S8-1B2A～S8-1C 的事务迁移目标 Sheet 行列与范围载体、跨 Sheet 公式、定义名称、Table 范围、Drawing 行列锚点、Chart 系列公式和计算链；完整删除普通范围对象时同步父节点计数。单一连续整行整列选择均已开放前端入口，并加入草稿/保护拦截、删除确认、旧历史清理、重载选区和已加载公式重算。通用行列事务仍拒绝完整 Table 删除或列数变化；S8-2B 已通过独立 Table 生命周期事务开放安全删除/转区域。透视表、批注、嵌入对象、未知扩展和活动筛选条件继续明确拒绝。详细契约见 `Workbook_Structure_Migration.md`。

- 名称最多 10,000 个，名称最多 255 字符，公式最多 8,192 字符。
- 单 Sheet 最多解析 10,000 条数据验证、10,000 个验证范围；会话排序筛选最多加载 50,000 行。
- 单 Sheet 最多读取 1,024 个绘图对象，单图表最多 256 个系列；标题和替代文本有长度上限。
- 高级数据对象和外部关系分别设置 4,096 项上限；元数据文本最多 1,024 字符，连接字符串不会进入公开模型。
- 页眉页脚文本最多 8,192 字符；保护元数据只公开布尔状态和受限操作类别，不公开密码校验值或哈希材料。
- 外部引用不生成导航目标，不触发网络或额外文件访问。
- ZIP 单部件与总解压上限继续生效。
- 只有矩阵中标记为“支持”的维度才能作为产品承诺；“保真”不等于“可读取”或“可编辑”。

矩阵结构由 `npm run check:workbook-contract` 校验，发布档案由 `npm run check:xlsx-release-gate` 校验，二者均已纳入 `ci:check`。新增或升级工作簿能力时必须同时更新机器矩阵、发布档案、fixture、测试证据和本文件。
