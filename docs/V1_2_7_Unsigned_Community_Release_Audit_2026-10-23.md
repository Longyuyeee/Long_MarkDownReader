# v1.2.7：JSON 数组项位置调整

当前开发目标：`1.2.8`；当前运行时版本：`1.2.7`；当前公开版本：`1.2.7`。当前阶段：**v1.2.7 已发布**。

## 当前范围

按 1.2.7—1.2.8 既定路线，JSON/JSONC 数组项右键提供上移、下移，边界禁用。按当前分析定位父数组和完整值范围，只交换相邻项的原始文本，其他逗号、缩进和换行留在原位置；保留长数字、字符串转义和内部注释，不整体重新序列化。归属不清的邻接注释就地拒绝并说明原因，原文不变。

## 草稿与操作接续

沿现有差异预览应用到草稿，形成一次可独立撤销重做的编辑；不增加常驻按钮、介绍或第二次确认。移动后源码焦点及树形选择继续跟随原记录。来源、草稿、分析发生变化时停止旧菜单、异步结果或预览，保存失败、外部冲突继续沿现有保护保留内容。只读、大文件分段和无效源码不能执行。

## 当前检查

原生解析与文本移动回归、真实 Vue 页面和 CodeMirror 的浏览器任务分别记录。浏览器明确模拟原生 IPC；Windows 同一原包独立检查已完成，见后文。

## 发布边界和下一步

发布渠道为 `community-unsigned`，未签名 Windows 社区版，企业 `releaseCandidate=false`；固定源码构建、同包安装与保存重开、公开附件摘要核对均已完成，本版已发布，用户可手动下载安装。1.2.6→1.2.7 应用内自动更新实际观察独立 pending。

本版仅处理 JSON/JSONC 数组相邻移动。下一版 1.2.8 按[既定路线](Foundation_Deepening_Roadmap_1_2_7_to_1_2_8_2026-10-23.md)深化字段和数组项复用，尚未实施，不扩大到其他结构化格式。

## 树形撤销补充与重新固定

初次固定提交 `68022f3d7e7df4844e74de600027cdbe17bccd6d` 的源码完整检查和 1136 项 Rust 功能回归通过，但安装包任务 39862402015 在收尾中主动停止，未用于发布。进一步核对发现树形移动后，Ctrl+Z 仍依赖隐藏的源码焦点，需切视图才能直接撤回；现补上树形视图 Ctrl+Z、Ctrl+Y/Shift+Ctrl+Z，并将移动后的焦点放回树形区域。输入框、弹窗、只读、加载和保存中的快捷键不抢占。浏览器任务核对无需切视图直接撤销重做，原生同包任务同步覆盖。固定最终源码重新构建，不复用不含此修复的旧包。

原生检查在记录草稿保护结果后，通过真实按钮明确放弃本流程的临时草稿，避免影响后续工作现场和历史重启流程；只清理测试机内自己创建的样例，未接触用户资料。
