# v1.2.7：JSON 数组项位置调整

当前开发目标：`1.2.7`；当前运行时版本：`1.2.7`；当前公开版本：`1.2.6`。当前阶段：**v1.2.7 JSON 数组项位置调整候选**。

## 当前范围

按 1.2.7—1.2.8 既定路线，JSON/JSONC 数组项右键提供上移、下移，边界禁用。按当前分析定位父数组和完整值范围，只交换相邻项的原始文本，其他逗号、缩进和换行留在原位置；保留长数字、字符串转义和内部注释，不整体重新序列化。归属不清的邻接注释就地拒绝并说明原因，原文不变。

## 草稿与操作接续

沿现有差异预览应用到草稿，形成一次可独立撤销重做的编辑；不增加常驻按钮、介绍或第二次确认。移动后源码焦点及树形选择继续跟随原记录。来源、草稿、分析发生变化时停止旧菜单、异步结果或预览，保存失败、外部冲突继续沿现有保护保留内容。只读、大文件分段和无效源码不能执行。

## 当前检查

原生解析与文本移动回归、真实 Vue 页面和 CodeMirror 的浏览器任务分别记录。浏览器明确模拟原生 IPC；Windows 同一原包检查尚待完成，不能用浏览器替代。结果完成后补充。

## 发布边界和下一步

发布渠道为 `community-unsigned`，未签名 Windows 社区版，企业 `releaseCandidate=false`；固定源码构建、同包安装与保存重开、公开附件摘要核对完成后发布，用户可手动下载安装。1.2.6→1.2.7 应用内自动更新实际观察独立 pending。

本版仅处理 JSON/JSONC 数组相邻移动。下一版 1.2.8 按[既定路线](Foundation_Deepening_Roadmap_1_2_7_to_1_2_8_2026-10-23.md)深化字段和数组项复用，尚未实施，不扩大到其他结构化格式。

## 开发检查结果

JSON Rust 模块 36 项通过，其中新增 8 项移动回归覆盖 UTF-8 中文位置、完整子树和其他草稿、CRLF 与制表符、尾逗号、内部和邻接注释、首尾与单项边界、无效或过期范围及重复字面量。新原生流程与证据校验协议 2 项通过，版本变更协议 3 项通过。

真实 Vue/CodeMirror 浏览器 8 组任务通过，覆盖完整记录、独立撤销重做、首尾边界、嵌套、延迟结果、过期预览、显式保存及树形定位；六种风格、1440×960 和 800×640 窗口检查菜单范围，包含深色。现有 JSON/YAML/XML/TOML 浏览器 55 项回归通过，覆盖保存期间继续输入、来源切换、失败读取、冲突副本、定位、结构编辑与一次撤销。浏览器明确模拟原生 IPC，保存内容使用模拟文件；与后续真实安装包证据分开记账。

小窗口检查发现节点菜单上方操作可能出屏，现按鼠标上下方可用空间展开并内部滚动，不删操作。精度风险提示改为“部分结构操作受限”，准确区分可保留字面量的原文移动和现有受限操作。

完整本地发布检查通过。常规动效保留，未控制或重启用户日常应用。本地记录位于 [页面证据](evidence/v127-json-array-development/browser/report.json) 与 [既有结构化编辑回归](evidence/v127-json-array-development/structured-regression/report.json)。
