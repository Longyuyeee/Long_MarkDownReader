# Long编辑 v1.2.6：表格列位置调整

右键列标题可向左或向右移动字段，让常用内容靠前。标题、所有记录的原文、字段类型、规则和列宽保持对应；看板、图表、仪表盘和排序继续使用原字段，冻结仍为最前 N 列。边界方向禁用，录入规则入口继续保留，不增加常驻操作区。

列移动与新增列均可一次撤销重做，与单元格、填充及行操作交错使用不会串列。保存期间继续新增、保存失败重试和外部冲突保留草稿。延迟类型刷新跟随字段身份；新增列撤回与重做会保留用户后续主动修改的视图选择。

适用于现有 Table、CSV/TSV，保留全部现有功能、主题和正常动效。未签名 Windows 社区版；完整发布检查与 442 项安装版功能任务通过，NSIS、MSI 与 `SHA256SUMS.txt` 三份公开附件已重新下载核对通过。1.2.5→1.2.6 应用内自动更新实际观察仍待完成，与手动安装升级分别记录。
