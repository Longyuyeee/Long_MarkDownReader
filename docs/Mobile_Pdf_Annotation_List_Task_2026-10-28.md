我们采用“摘要列表 → 完整详情 → 显式回到原文”，便于先读完自己的想法及摘录，避免点卡片立即跳页；原文的返回按钮明确显示“返回批注详情”。这是项目取舍，不声称与竞品完全相同。

## 已接入的行为

- 批注整页默认只显示摘要、页码、颜色和条目类型；点条目看完整详情。编辑使用上一阶段的独立任务页，删除、选入笔记及重读放在详情更多菜单。
- 列表即时查找；筛选是独立页面，颜色使用原生单选框，当前页／已选范围按需选择。应用才改变范围，返回保留待应用选择；重置只改本次准备。深列表也能通过顶部更多进入筛选，无变化的应用保留原滚动。
- 列表、详情、筛选和原有整理页分别保留位置与焦点；保留查询 DOM 原值、选区、展开批次、编辑草稿及已选条目。详情 → 原文 → 返回恢复原详情，期间打开设置不丢掉这条返回链。
- 删除先显示具体对象及影响，取消逐层回去；成功回列表并聚焦撤销。保存失败／冲突先重读核对，恢复记录跨重载保留；不把未确认的删除报告为成功。
- 一般说明通过页面问号查看，关闭仅消费说明层；待应用筛选不丢失。权限、读取失败和删除失败就地保留有用信息。损坏的 JSON 不再直接显示英文解析异常，原文件保持原样并可重读。
- 打开整页批注时遮蔽阅读视图及画布、阻止底层操作并暂停连续阅读。复制受限时只查找自己的可用想法，隐藏的摘录也不能通过搜索推断。

批注格式、存储、删除恢复、整理引擎和独立编辑组件与基线一致。原 PDF、原有 Markdown 及其草稿的内容／字节保留断言通过。
