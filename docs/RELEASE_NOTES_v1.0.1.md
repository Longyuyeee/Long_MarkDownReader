# Long编辑 v1.0.1

v1.0.1 是 Long编辑首个正式版之后的品牌与工作区结构补丁。它不扩大格式能力宣传边界，重点解决应用图标不统一、文件页面结构分裂和后开发界面风格漂移的问题。

## 更新内容

### 新品牌图标

- 采用用户确认的 `L + 金色钢笔轮廓` 方案：深海军蓝圆角底、金色编辑轮廓和笔尖转角。
- 图形主体相较早期候选更大，适配桌面图标和 README 展示。
- 已统一生成 Windows ICO/PNG 与商店尺寸、macOS ICNS、Android mipmap 和 iOS AppIcon。
- 应用标题栏、工作台页头、空状态和 README 使用同一品牌源。

### 文件统一在资料库右侧打开

- PDF、CSV/TSV、XLSX、Mermaid、OPML 思维导图和 JSON Canvas 纳入资料库嵌入工作区。
- 文件树、工作台、命令面板、统一标签页与 Canvas 文件节点继续保留管理器上下文。
- 修复 ODF 嵌入组件映射缺失。
- 文件页面根节点改为容器相对尺寸，避免 `100vh/100vw` 在右侧区域产生溢出或看起来像另一套界面。

### UI 一致性收口

- 增加统一工作区工具栏、控件和状态栏尺寸令牌。
- 嵌入页面统一边界、圆角、工具栏高度和主题背景，移除重复阴影。
- 扩展文件关系上下文到文档、演示、工作簿和图表页面。
- 完成全局静态与浏览器视觉审计；剩余字号、直接颜色和管理页壳层迁移已记录到审计文档，不在本补丁中冒进替换。

## 能力边界

v1.0.1 继承 v1.0.0 的格式能力：日常管理、阅读和基础编辑是产品基线；DOCX/PPTX/XLSX/ODF/PDF 的复杂结构继续采用受限编辑、可靠副本、旁车数据或外部应用打开。软件不会把格式识别能力描述成完整无损编辑。

格式注册表仍以仓库中的 `shared/file-formats.json` 为唯一产品合同。界面展示覆盖保存、受限覆盖、保存副本、旁车文件或只读边界。

## 安装、升级与回滚

- 支持 Windows 10/11 x64。
- 可在 v1.0.0 上覆盖安装，知识库目录、应用设置和历史副本不会被安装器删除。
- 软件每 24 小时最多自动检查一次更新，也可在设置中手动检查。
- v1.0.1 更新包继续使用与 v1.0.0 相同的 Tauri 更新公钥签名，已安装的 v1.0.0 可以验证本版本。
- 如需回滚，可先备份知识库和设置，再卸载 v1.0.1 并从 GitHub Releases 安装 v1.0.0；不要让旧版本覆盖新格式文件的唯一副本。

## 安全说明

本版本没有 Windows Authenticode 代码签名。安装时 Windows 可能显示“未知发布者”或 SmartScreen 提示。请只从 `Longyuyeee/Long_MarkDownReader` 官方 GitHub Releases 下载，并核对 `SHA256SUMS.txt`。

Tauri 更新签名用于验证更新包完整性，不等同于 Windows 发布者身份签名。更新私钥保存在本地被忽略的 `.release-secrets/` 中，不进入 Git 历史、安装包附件或 Release 说明。
