# v1.0.9 受控更新生命周期审计

状态：**官方 v1.0.8 到 v1.0.9 自动重启验收工具已就绪，等待托管 Windows 执行**

## 目标

- 从官方 `v1.0.8` NSIS 安装开始，通过应用内检查发现官方 `v1.0.9`。
- 保持用户确认边界，确认前不得下载或启动安装器；下载后严格核对官方附件大小与 SHA-256。
- 验证同目录覆盖安装后由更新助手自动重启 `v1.0.9`，测试脚本不得手动启动新版应用。
- 在自动重启的进程中确认当前版本、进程持续存活和合成资料保留。
- 覆盖安装和卸载后都必须保留合成资料库与配置标记。

## 隔离边界

- 仅在 GitHub 托管 Windows 一次性环境运行，必须同时提供 `ConfirmDisposableMachine` 与 `AllowInstallerMutation`。
- 工作流只下载公开 Release 资产，不重建产品，不读取本机 LongEdit，也不包含真实用户资料。
- 当前安装包仍为 `NotSigned`；本观察不构成企业签名或商业发布资格。

## 验收门槛

共 12 项检查必须全部通过。其中 `automatic-relaunch-after-managed-update` 必须来自更新助手拉起的进程，测试脚本不会手动启动新版应用；若新版进程未出现或立即退出，流程直接失败并上传中间证据与脱敏重启日志。

## 下一步

先让本合同通过 Quality Gate，再运行 `V1.0.9 Managed Updater Lifecycle`。只有托管 Windows 返回 12/12、证据导入并通过最终门禁后，才能将 v1.0.9 自动更新重启恢复标记为收口。
