# G16 孤立对象行动队列审计（2026-08-01）

## 结论

G9–G15F 已让知识网络指标、治理建议、观察闭环和回执审阅进入日常工作台，但审计发现“处理孤立对象”仍只给出数量和建议，不告诉用户应该从哪个对象开始。G16 在工作台“知识网络脉搏”中增加“优先连接”行动队列，直接列出最多 6 个孤立对象；用户点击后在右侧当前知识图谱中以该对象为中心定位。

当前状态为 `knowledge-isolation-action-queue-source-validated-installed-acceptance-next`，`releaseCandidate=false`。这是一项管理入口增强，不表示真实用户资料库或安装版导航已经验收。

## 产品与安全边界

- 队列复用统一知识图谱模型，不扫描额外目录、不采集新内容。
- 只返回对象 ID、标题、对象类型和固定为 0 的关系数；最多 6 项。
- 结果按标题和对象 ID 确定性排序，避免刷新时随机跳动。
- 点击只复用现有 `Graph?root=` 当前窗口导航，进入局部图谱后仍由用户决定是否建立关系。
- 队列不会自动创建关系、修改文件、写入标签或更改索引事实源。
- 窄屏下从双列降为单列，字号、按钮、边框与现有工作台知识网络区域一致。

## 验收和下一步

源码验收已通过：两项 Rust 定向回归分别覆盖统计/单项队列与 8 个孤立对象的排序/6 项上限；前端生产构建成功，G9–G16 图谱产品合同全部通过。下一步在安装版合成资料库确认队列可见、条目数量受限、点击后在当前窗口居中定位正确孤立对象。真实资料库价值验证和签名 Windows 客户端仍是独立外部门禁，软件不会自动替用户建立关系。
