## 真实环境与证据

- Windows / Tauri / WebView2，1440×900，DPR 1.25，暗色主题。
- 180 个合成 Markdown 节点、540 条真实解析关系、6 个社区；源文件哈希前后不变。
- 默认零选择、空闲连续绘制关闭；选择特效结束后再次回到空闲。
- 截图和结构化证据位于 `docs/evidence/post-v119-m8-5-graph-visual-performance/`，未包含用户资料库内容。

本轮只提升知识图谱显示、交互反馈和密集场景绘制，不新增图谱语义、不改变 Markdown/Canvas 写回范围。v1.0.20 的功能范围现已具备进入完整补丁质量门和托管 MSI/NSIS 生命周期的条件；在托管候选、哈希冻结和公开附件回下载完成前，仍不得宣称 v1.0.20 已发布。
