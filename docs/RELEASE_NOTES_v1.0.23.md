# v1.0.23 — 版本身份与更新提示修复

本版集中修复“我到底运行哪个版本”以及发布页打开失败时的更新状态提示。

- 侧栏、设置与能力页统一显示实际运行版本，不再把下一开发目标当作已安装版本。
- DEV 只在开发前端显示；正式前端不因开发政策字段误标开发版。
- 打开官方发布页不会冒充更新检查，也不会把“已是最新”改成“发现更新”。
- 发布详情打开失败单独说明原因，不覆盖更新状态；可以重试，已有更新弹窗保持可见。

安装生命周期 22 项、工作面 18 项、路由 11 项、管理回滚 7 项及版本身份 4 项通过；三张版本原图已核对。首轮设置截图过早捕获的缺口通过同包可见性复验收口，原始记录保留。

不扩大现有格式编辑范围；社区包仍未签名，Windows 可能提示“未知发布者”。只从官方 Release 下载并核对 SHA-256。自动更新需要用户确认；官方 v1.0.22→v1.0.23 应用内更新仍需发布后独立观察，不能用安装流程代替。

已知待改进：部分图谱操作说明仍有局部遮挡；关闭按钮与 Alt+F4 的策略一致性将作为下一版本优先方向。本版不宣称所有图谱体验问题已解决。
