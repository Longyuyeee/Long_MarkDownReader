# P1-B2A1 PDF 表单结构检查后端审计

审计日期：2026-08-15

阶段状态：只读后端完成，右侧表单检查面板待开发

## 需求对齐

本切片是 PDF 表单填写前的强制安全入口，只检查资料库内 PDF，不写源文件、不生成副本、不改变外部 PDF 的只读策略。它不会把“检测到字段”提前描述为“已经支持填写”。

## 实现边界

- 同时遍历 `/AcroForm/Fields` 规范字段树和每页 `/Annots` 的 `/Widget`。
- 解析 `/Parent`、`/Kids`、继承字段类型和标志，建立字段与 Widget 关联。
- 汇总文本、按钮、选项、签名和未知类型，报告当前值、默认值、选项数、只读/必填、多行、密码与动作风险。
- 密码字段只报告类型和标志，不返回 `/V` 内容。
- 检查 `/AP /N` 正常外观，缺失外观单独计数，不使用 `/NeedAppearances` 冒充外观正确。
- 输入上限 128 MiB，字段 10000、Widget 20000、树深 64，字段字符串最多 4096 字符。
- 命令只接受 WorkspaceGuard 内现有 `.pdf`，返回源 SHA-256；没有写入路径和目标参数。

## 风险诊断

以下情况保持 `blocked`，可查看诊断但不能进入后续填写候选：

- 加密、数字签名或权限签名；
- XFA、文档 JavaScript、字段/Widget 动作；
- 重复完整字段名、孤儿 Widget；
- 字段树循环/复用、无效字段或 Kids 引用、直接字段字典等结构歧义；
- 签名字段。

无表单返回 `no_form`；结构无歧义且无主动内容风险时返回 `inspectable`。可填写候选目前只统计非只读、有关联 Widget 的 `Tx`、`Btn`、`Ch`，不执行写入。

## 验证

Rust 合成 PDF fixture 覆盖：

- 规范文本字段与页面 Widget 的关联、现值、缺失外观和候选统计；
- 重复字段名与孤儿 Widget 同时稳定阻断；
- XFA 与文档 JavaScript 稳定阻断；
- 密码字段现值不出现在报告中；
- 空文件与超过 128 MiB 输入在解析前拒绝。

`cargo test formats::pdf_forms --lib --locked`、`cargo check --locked` 和机器合同均作为本阶段门禁。
