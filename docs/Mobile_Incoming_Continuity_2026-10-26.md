# 手机端收到内容与原任务接续

本轮从 2026-10-26 开始，验证收尾跨至香港时间 10-27。按阶段 1B 推进“在编辑或阅读中收到其他应用的内容，选择核对，取消后继续原任务，确认后打开独立副本”。沿用移动分支与独立目录，未修改桌面工作目录、原生接收协议或数据格式。

## 观察与竞品复核

改前实际页面存在三个断点：查看收到内容会卸载原编辑器；多项接收直接选择最新一项；关闭核对页回资料库而不是原编辑现场。[改前采集](evidence/mobile-incoming-continuity-2026-10-26/before/report.json) 的三个缺陷字段均为 `true`，`captureCompleted` 仅表示观察完成。代码另有 PDF 接收错误影响正常文件路由的问题。

| 官方资料 | 可以确认的流程 | 本项目的设计判断 |
| --- | --- | --- |
| [Notion Web Clipper](https://www.notion.com/help/web-clipper) | Android 从系统分享进入后，填写名称、选择工作区和页面或数据库，再保存。 | 先辨认内容与目标，再明确存入；不在收到时替换正在写的笔记。 |
| [Zoho Notebook Link Cards](https://help.zoho.com/portal/en/kb/notebook/find-and-organize-your-notes/articles/create-and-manage-link-cards-in-zoho-notebook) | 官方移动浏览器分享流程是选择 Notebook、选择笔记本，再保存链接。 | 保持可辨认的接收项、目标和保存动作。网页抓取与 Link Card 属于竞品能力，本项目继续按分享原文保留链接。 |
| [Android 导航原则](https://developer.android.com/guide/navigation/principles) | 应用任务内部，标题栏向上与系统返回沿页面历史回退。 | 移除确认先回核对，核对再回收到列表，最后回原任务。 |

调研采用官方文档，没有安装、运行或录制竞品 App。“混合类型收件列表”和保留本项目副本核对步骤属于产品设计判断，不声称竞品采用同样的收件箱。

## 正式页面与返回契约

- 收到时只显示提醒，不抢焦点；打开列表前保护草稿和 PDF 当前输入，保护失败留在原任务，接收项不变成已查看。
- 列表只显示名称、类型、新收到或已查看状态。文字、PDF、笔记附件包分别进入二级核对页面；列表保持挂载，返回恢复滚动和行焦点。
- 阅读某一项只确认该项已查看。新到达的内容加入列表，不替换正在核对的内容；本次任务内已查看项继续保留，退出后从设置中的对应记录继续。未查看项继续提醒。
- 文字复用完整原文核对、存入和移除实现；PDF复用实际首页预览与字节核对；附件包复用正文、清单和图片预览。接收核对不展开全部历史或选择其他源文件的操作。
- 错误有独立页面。返回保留接收提示，只有“知道了”才清除；清除失败可重试，确认前发现提示变化时先展示新提示，再次确认才清除。错误不会代替正常文件决定核对类型。
- 返回与取消保留原编辑器、输入、撤销历史，PDF保留同一阅读器和画布。只有明确存入并成功打开副本才结束接收任务；失败保留核对页和既有回执，重复打开复用同一目标身份。
- 可选解释放到问号；接收失败、移除后果和存入位置属于操作所需信息，保留在对应页面。

失败验证还发现，`DocumentSession.open` 的加载状态会暂时卸载原编辑器。现有工作区在核对层尝试打开新文档时保持挂载；加载失败不重建原编辑器。PDF切换到文字也先完成文字读取，再处置原 PDF，避免读取失败提前关掉原阅读现场。

## 验证与边界

最终结果和构建摘要见 [验证清单](evidence/mobile-incoming-continuity-2026-10-26/verification.json)。生产构建通过；289 项逻辑验证及 65 组相关浏览器任务通过（接收14、PDF接收11、导入分层9、位置返回8、恢复9、帮助14）。接收任务包含7次无障碍扫描。逻辑验证后仅调整 Vue 挂载/隔离与浏览器用例，未改领域算法或存储实现。接收集成验证使用独立合成数据和浏览器接收记录，检查原文件、私有草稿、BOM/混合换行、PDF与附件包字节、逐层返回、新到达、错误确认、读取失败、打开失败重试、长列表、窄屏大字号和键盘焦点。

历史浏览器用例按新的列表入口调整操作，保留独立副本、字节核对和失败重试断言。失败候选均保留原始截图和报告；一次测试故障注入把目标文件从浏览器适配器的读取结果中整体省略，连带影响其整库保存，已改为只拒绝目标身份的读取，不恢复或改写生产数据来通过验证。

本轮未启动 Android 模拟器、未进行原生 Intent/URI授权、真实系统键盘、TalkBack或实体机验收，也未产生新 APK。浏览器中的返回桥调用不等同于 Android 系统返回验证。现有原生接收实现保持原样，已查看回执与全局接收提示仍使用既有确认接口；这里没有新增系统分享能力或网页抓取。
