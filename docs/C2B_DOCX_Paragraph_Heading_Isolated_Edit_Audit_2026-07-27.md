## 1. 交付范围

C2B 在 C2A 包级安全底座上增加：

1. 读取报告返回可编辑文本目标清单；
2. 每个目标包含稳定目标 ID、正文块 ID、对象类型、当前文本和文本 SHA-256；
3. 请求同时校验源文件签名、目标 ID 和原文本摘要；
4. 只替换目标段落唯一 `<w:t>` 文本节点的精确字节范围；
5. 使用 quick-xml 转义替换文本并支持标准、十进制和十六进制 XML 字符引用；
6. 输出再次读取，确认同一正文块、同一对象类型和新文本一致；
7. 继续复用 C2A 的单部件差异白名单、临时副本重开和源文件不变证明。

新增命令：

- `preview_docx_text_patch_isolated_copy`

该命令只返回审计报告，不返回 DOCX 字节。

## 2. 可编辑目标

本批仅列出同时满足以下条件的对象：

- 位于主文档正文顶层；
- 解析模型类型为普通段落或标题；
- 只有一个 `<w:t>` 文本元素；
- 文本非空；
- 不位于表格或内容控件内；
- 不包含列表定义、修订、域、批注锚点、脚注/尾注引用、超链接、书签、权限范围、绘图、嵌入对象、换行、制表符或符号载体。

列表、表格单元格、多文本节点富文本段落及任何无法证明局部保真的结构保持只读。

## 3. 输入与语义门禁

- 新文本不得为空；
- 最多 32,767 个 Unicode 字符；
- 不允许换行、制表符和其他控制字符；
- 新文本必须与原文本不同；
- 目标 ID 必须仍存在于当前文件；
- 文本摘要必须与读取报告一致；
- XML 统一使用 quick-xml 转义，不进行字符串拼接式实体替换；
- 写后目标必须保持相同 `blockId` 与 `kind`，且复读文本与请求完全一致。

任何门禁失败都会终止整个隔离预览。

## 4. 包与文件安全

C2B 完整继承 C2A：

- `word/document.xml` 是唯一允许变化的 OOXML 部件；
- 输出部件清单必须与源包一致；
- 未修改部件通过 raw-copy 保留；
- 所有部件执行修改前后摘要比对；
- 输出写入独占临时文件并同步；
- 临时文件执行字节、摘要和结构重开验证；
- 最后复核源文件字节、摘要和文件签名；
- 临时文件退出时清理。

不存在 `save_docx` 或 `write_docx` 命令。

## 5. 回归证据

真实 Microsoft Word fixture 验证：

- 标题进入安全目标清单；
- 普通分页前段落进入安全目标清单；
- 带批注锚点的段落不进入清单；
- 列表项和表格文本不进入清单；
- 安全普通段落支持包含 `&`、`<`、`>` 的新文本；
- 写后正文语义、块 ID、对象类型和包差异全部通过；
- 源 Word fixture 字节保持不变。

拒绝路径覆盖：

- 陈旧文件签名；
- 陈旧文本摘要；
- 不存在或复杂只读目标；
- 空文本、未变化文本、控制字符和超长文本；
- 包级差异越界与结构重读失败继续由 C2A 阻断。

本批同时修复现有 DOCX 阅读器对 XML `GeneralRef` 事件的遗漏，标准实体和数字字符引用现在能进入可见正文模型。
