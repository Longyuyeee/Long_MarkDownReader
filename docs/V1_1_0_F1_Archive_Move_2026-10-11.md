# F1 归档无覆盖移动原语审计

日期：2026-10-11，接续 `fa300a10`。本步仅后端内部服务，无 UI 修改、无归档执行命令、无升版或发布。

## 实现与边界

新增 `services/archive_move.rs`。Windows 使用 `MoveFileExW`、flags=0，目标冲突由操作系统拒绝，不依赖“先 exists 再 rename”的时间窗口；没有覆盖、跨卷复制删除或重启后执行回退。参见 [微软 API 说明](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw)。其他平台返回不支持，不降级到可能覆盖的 `fs::rename`。

执行前校验资料库范围、既存目标目录、普通来源文件、文件名、扩展名和相同路径。批次按顺序为每项保留来源、目标、成功或具体错误；一项失败不吞掉前面结果，也不跳过后续独立项。不回滚、不自动重试、不因源文件消失而推断之前已成功。

这是磁盘移动原语，不是完整归档事务：未协调未保存草稿、文件身份、链接、历史、标签、索引；路径校验和移动之间仍可能有外部进程替换来源或父目录。没有持久化执行日志/崩溃恢复；不能声称抗恶意并发替换或断电持久性。已有拖动 `move_item/move_items` 没有改接此服务，其历史迁移忽略错误的问题仍待统一解决。

因此本服务仅 crate 内可见，未注册 Tauri 命令、未接任何用户入口，预检 `canExecute` 仍为 false。服务暂时允许 dead_code 是明确的接入门禁，不是已交付用户功能。跨卷失败未在本机第二卷实测；符号链接、网络盘与各种文件系统矩阵仍待验证。
