# Long编辑 视觉系统开发计划

> 日期：2026-07-10  
> 版本：v2.0  
> 核心理念：**扁平、优雅、精致、华丽** —— 不克制的精致感

## 1. 设计哲学

### 1.1 核心原则

**扁平但不寡淡** - 用细节密度而非厚重层级创造深度  
**优雅但不冷淡** - 用流畅动效和呼吸感营造温度  
**精致到每一像素** - 所有状态、过渡、边界都精心打磨  
**华丽但不俗气** - 用丰富色彩、细腻渐变、精妙光影展现品质

### 1.2 设计关键词

- **Flat Premium** - 扁平高级感
- **Quiet Luxury** - 低调奢华
- **Local-first Knowledge Studio** - 本地优先的知识工作台
- **Breathing Interface** - 有呼吸感的界面
- **Detail Density** - 细节密度

### 1.3 与"克制"说再见

❌ 不要：保守的色彩、单调的灰度、简陋的过渡、千篇一律的卡片  
✅ 要做：丰富的主题色、细腻的渐变、华丽的动效、独特的视觉个性

每种风格都应该有**强烈的视觉记忆点**，让用户一眼就能感受到差异。

## 2. 六大视觉风格体系

每种风格不只是换颜色，而是完整的视觉语言：

| 风格 | 关键词 | 色彩策略 | 边框策略 | 阴影策略 | 动效性格 |
|------|--------|----------|----------|----------|----------|
| **Soft** | 柔和、温暖、舒适 | 暖色调、低饱和度渐变 | 圆润（8-12px） | 柔和扩散 | 缓慢舒展 |
| **Neo** | 未来、科技、锐利 | 高对比、霓虹强调 | 锐利（2-4px） | 硬质投影 | 快速弹性 |
| **Glass** | 晶透、轻盈、现代 | 高亮度、透明层叠 | 细边线（1px） | 多层次叠加 | 轻快漂浮 |
| **Airy** | 空气感、呼吸、留白 | 低饱和度、大量留白 | 极细（0.5px） | 极浅 | 轻柔平滑 |
| **Minimal** | 极简、专注、克制 | 黑白灰为主、点缀色 | 几何（0或4px） | 无或极弱 | 直接利落 |
| **Sharp** | 锋利、专业、严谨 | 高对比度、纯色块 | 直角（0px） | 清晰硬边 | 精准快速 |

### 2.1 风格升级要点

现有风格只是"变色"，需要升级到"完整视觉系统"：

**Soft 升级方向**：
- 背景：柔和渐变（米色→浅粉→淡紫）
- 卡片：奶油质感，8-12px 圆角
- 按钮：果冻感，hover 时轻微膨胀
- 动效：缓入缓出，300-400ms

**Neo 升级方向**：
- 背景：深空感（深蓝→紫黑）+ 霓虹点缀
- 卡片：硬质科技感，2-4px 圆角，发光边线
- 按钮：脉冲发光效果
- 动效：快速弹性，120-180ms

**Glass 升级方向**（不用 backdrop-filter）：
- 背景：多层半透明叠加
- 卡片：透明度 0.8-0.9，细边线，内阴影
- 按钮：玻璃质感（用渐变模拟）
- 动效：轻盈漂浮感

**Airy 升级方向**：
- 背景：大量留白，纸张质感
- 卡片：极简边框，0.5px 细线
- 按钮：悬浮卡片感
- 动效：柔和呼吸感

**Minimal 升级方向**：
- 背景：纯色或极浅纹理
- 卡片：几何分割，0 或 4px 圆角
- 按钮：纯色块，强对比
- 动效：直接快速

**Sharp 升级方向**：
- 背景：高对比网格
- 卡片：直角硬边，清晰投影
- 按钮：锐利切换
- 动效：精准快速，无缓动

## 3. 华丽细节清单

### 3.1 色彩华丽化

✅ **丰富的渐变**
- 背景支持 2-3 色渐变
- 卡片支持光影渐变
- 按钮支持光泽渐变
- 文字支持渐变（标题、强调）

✅ **主题色丰富化**
- 不只一个主色，每个风格 3-5 个协调色
- 支持动态调色板
- 强调色、警告色、成功色都有风格化变体

### 3.2 动效华丽化

✅ **丰富的过渡**
- 页面切换：滑动 + 渐变 + 缩放组合
- 卡片悬停：提升 + 发光 + 轻微旋转
- 按钮点击：涟漪 + 脉冲 + 颜色波动
- 拖拽：弹性跟随 + 半透明预览

✅ **微动效**
- 光标跟随效果
- 波纹扩散
- 粒子点缀（轻量）
- 悬浮呼吸

### 3.3 质感华丽化

✅ **材质模拟**
- 纸张纹理（Airy）
- 金属光泽（Neo）
- 玻璃折射（Glass）
- 绒面质感（Soft）

✅ **光影效果**
- 内阴影 + 外阴影组合
- 光晕效果
- 高光反射
- 边缘发光

## 5. 技术实现策略

### 5.1 CSS 架构

```
src/styles/
├── tokens.scss          # 基础 token
├── motion.scss          # 动效系统
├── themes.scss          # 6 种风格主题
├── components/          # 组件样式库
│   ├── buttons.scss     # 按钮组件
│   ├── cards.scss       # 卡片组件
│   ├── forms.scss       # 表单组件
│   └── animations.scss  # 动画库
└── utils.scss           # 工具类
```

### 5.2 风格切换机制

```typescript
// 风格配置结构
interface VisualStyle {
  name: string;
  colors: {
    primary: string[];      // 渐变数组
    background: string[];   // 背景渐变
    card: string[];         // 卡片渐变
    // ...
  };
  borders: {
    radius: string;         // 圆角策略
    width: string;          // 边框粗细
    style: string;          // 实线/虚线
  };
  shadows: {
    card: string;           // 卡片阴影
    hover: string;          // 悬停阴影
    active: string;         // 激活阴影
  };
  motion: {
    curve: string;          // 缓动曲线
    duration: number;       // 基础时长
    character: string;      // 动效性格
  };
}
```

### 5.3 华丽效果实现

**渐变背景**：
```scss
background: linear-gradient(135deg, var(--bg-start), var(--bg-mid), var(--bg-end));
```

**发光效果**（无 blur）：
```scss
box-shadow: 
  0 0 0 1px var(--glow-color),
  0 0 20px -5px var(--glow-color),
  inset 0 0 20px -10px var(--glow-color);
```

**按钮光泽**：
```scss
background: linear-gradient(180deg, 
  rgba(255,255,255,0.2) 0%, 
  rgba(255,255,255,0) 50%,
  rgba(0,0,0,0.1) 100%
);
```

**悬停提升**：
```scss
&:hover {
  transform: translateY(-2px) scale(1.01);
  box-shadow: var(--shadow-lifted);
}
```

## 8. 反模式警告

❌ **不要做的事**：
- ❌ 保守的灰度配色（这不是后台管理系统）
- ❌ 单调的白色卡片（每种风格都应该有独特质感）
- ❌ 简陋的 CSS transitions（要有性格的动效）
- ❌ 千篇一律的圆角（每种风格的圆角策略不同）
- ❌ "安全"的设计选择（要大胆展现华丽感）

✅ **要追求的效果**：
- ✅ 用户切换风格时有"哇！"的惊喜感
- ✅ 每个界面都有视觉记忆点
- ✅ 动效流畅且有性格
- ✅ 细节密度高，经得起放大审视
- ✅ 华丽但不卡顿（性能与美感平衡）
