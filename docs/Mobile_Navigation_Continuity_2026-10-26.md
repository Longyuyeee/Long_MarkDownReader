# 手机端第一阶段 A：打开文档后回到原处

用户任务：在长文件列表中筛选、展开更多、进入文件夹并阅读资料，然后逐层返回；切换搜索、最近、设置后继续原来的浏览。返回不应清掉筛选、跳过目录或丢失未保存输入。

本轮在手机分支完成这一切片，起点为 `4e32842a3`。沿用已有手机设计，继续保留问号和按需展开的工具。未修改桌面工作目录，未改产品版本、原生包身份或发布制品。

## 实际观察与设计决定

清理前用同一批隔离示例数据操作：筛选「项目」，展开 100 个文件夹，打开第 85 个项目和其中笔记，再返回父目录。原界面清空了筛选，显示 160 行，滚动由 6649px 变为 7172px。原始截图及数据在 [改造前记录](evidence/mobile-navigation-2026-10-26/before/result.json)，该记录只表示完成基线采集，不是验收通过。

本轮采用以下规则：

| 用户动作 | 实际行为 |
| --- | --- |
| 从文件夹返回父目录 | 恢复父目录自己的筛选、展开数量与滚动，并将焦点交回进入的文件夹。子目录的筛选独立保存。 |
| 从资料、搜索、最近打开文档 | 记录真正的来源。文档打开成功后才提交返回来源；打开失败不能把旧任务的返回位置替换掉。 |
| 从搜索结果阅读 | 先返回关闭文内查找，再返回搜索结果；恢复查询、结果滚动和选中结果，不重新唤起输入键盘。 |
| 切换根导航 | 恢复各页浏览位置。再次点当前导航不清空筛选或回到顶部。 |
| 多次快速按返回 | 导航或关闭尚在进行时只消费当前任务，避免连续关掉文档再退目录。 |
| 未保存输入无法保护 | 留在编辑页，保留文字并显示真实错误。重试保护成功后才返回；已解决的本次错误不继续挂在资料列表上。 |
| 切换资料库 | 分别恢复各库的目录和名称筛选。停止外部访问后回到手机资料库已有的浏览状态，保留源文件和草稿。 |
| 文件顺序或内容变化 | 尽量保留原滚动。若目标行移动到视口外，优先让该行可见；目标不再存在时回退到页面标题，不伪造旧列表。 |
| 新建笔记不符合原筛选 | 新建任务完成后以新文件可见为优先，只在原筛选会隐藏它时解除该筛选，并展开到目标行；普通阅读返回仍保留原筛选。 |

实际测试又发现停止外部访问后，旧「外部」筛选残留在手机资料库中导致空列表。已修复为恢复本机库的浏览状态，并在资料库面板关闭后恢复视口；失败候选保留在本机，不作为最终证据。

截图复核也发现触屏上的残留 hover 会高亮另一行。现将鼠标悬停效果限于支持悬停的精细指针设备，返回后的焦点行使用明确的背景反馈。切库位置以实际切换前的页面为准：如果用户已滚到顶部打开资料库选择器，不强行回到更早的阅读位置。

## 成熟移动应用的对应依据

- Notion 的移动文档把首页、搜索、收件箱和创建分为导航入口，并把其他动作放入上下文菜单。我们沿用「每个入口服务一个当前任务」的分层原则；本轮保留现有根导航，三项导航的视觉迁移仍属于后续阶段。[Notion 移动工作区](https://www.notion.com/en-us/help/workspaces-on-mobile)
- Obsidian 的移动导航提供回退、前进和文档切换；编辑工具栏随编辑场景出现。由此选择保留原阅读任务与来源上下文，继续使用已有编辑内核和工具，不增加第二套常驻操作。[Obsidian Mobile](https://obsidian.md/help/mobile)
- Android 官方多返回栈说明要求切换底部导航时保留各个流程的位置；返回栈按后进先出处理。这里把这一规则落实为页面视图记录和单次异步导航消费，原生导航接入仍需单独验收。[多返回栈](https://developer.android.com/guide/navigation/backstack/multi-back-stacks)、[返回栈](https://developer.android.com/guide/navigation/backstack)

调研方式是官方操作文档与本项目实际浏览器页面对照，查阅日期 2026-10-26。本轮没有安装或录制竞品，也不据其文档推测内部草稿实现。

## 源码与本地验证

`src/mobile/viewHistory.ts` 保存页面位置、筛选、已展开数量和焦点标识，最多记忆 128 个页面，采用有界缓存。只在当前运行期间保留，不写入本地文件或浏览器存储；文档正文和草稿继续由已有 `DocumentSession` 管理。页面记录采用资料库 ID 与库内位置，不把 Android 授权句柄转换为桌面路径。

`MobileApp.vue` 负责将真实打开、返回、切库和面板关闭事件接入这些记录，保留原有沙箱阅读 iframe 的关闭兼容处理。异步导航期间消费重复返回，关闭前仍调用现有草稿保护。`LibrarySearch.vue` 在离开前记住视口，避免卸载阶段覆盖原位置。

新专项 `scripts/test-mobile-navigation-browser.mjs` 使用独立浏览器上下文、自造文档和明确的存储失败注入；通过实际按钮、输入、文件选择器和已有返回桥测试。正文、源文件和草稿分别断言，不用截图代替保存正确性。
