# LongEdit C4B PPTX 文本与备注隔离补丁审计

审计日期：2026-07-27

阶段结论：**C4B 已完成，下一开发入口为 C4C 基础字符样式、形状文本与替代文本安全子集**

## 1. 目标与边界

C4B 在 C4A 原件保护基线上交付第一个可操作的 PPTX 编辑垂直切片，但仍不写入用户文件：

1. 枚举安全的单文本形状；
2. 枚举安全的演讲者备注文本；
3. 使用稳定目标 ID、文本 SHA-256、目标部件 SHA-256 防止过期修改；
4. 只在内存和临时 PPTX 副本中应用替换；
5. 差异必须精确限制为一个 slide XML 或 notesSlide XML；
6. 其余 OOXML 部件必须原样复制并逐摘要一致；
7. 隔离输出必须通过结构复读和目标语义复读；
8. UI 只提供“验证隔离补丁”，不提供保存、覆盖或另存。

## 2. 安全目标规则

### 2.1 幻灯片文本

只有同时满足下列条件的普通 `p:sp` 形状才进入编辑目标：

- 具有稳定 `cNvPr id`；
- 存在文本体；
- 恰好一个 `a:t` 文本元素和一个文本事件；
- 文本非空且不超过 32767 个字符；
- 不包含字段、显式换行、制表符、超链接或外部内容载体；
- 不属于图片、组合、连接线、图表、SmartArt、媒体或 OLE。

多段正文、多运行样式文本和复杂载体继续保持只读。

### 2.2 演讲者备注

- 优先选择 notesSlide 中唯一的 `body` 占位符；
- 对没有 `body` 标记的生产者，只有当 notesSlide 恰好存在一个安全文本形状时才允许；
- 幻灯片编号字段、页眉页脚和其他占位符不进入编辑目标；
- PowerPoint、WPS 和 LibreOffice 三种 notesSlide 结构均有真实样本回归。

## 3. 隔离补丁实现

`src-tauri/src/formats/pptx_edit.rs` 新增：

- `PptxEditableTextTarget`
- `PptxIsolatedTextPatchReport`
- `inspect_pptx_editable_text_targets`
- `build_pptx_text_patch_isolated`

补丁流程：

1. 重新枚举安全目标，拒绝已失效或不再安全的目标 ID；
2. 比对目标文本摘要和目标部件摘要；
3. 使用 XML 转义库生成安全替换文本；
4. 只重建目标 XML，其他 ZIP 条目使用 `raw_copy_file`；
5. 比较输入和输出全部部件名称及摘要；
6. `changedParts` 必须严格等于目标部件；
7. 重新解析输出 PPTX；
8. 再次枚举输出目标，验证同一稳定 ID 的文本等于替换值。

命令 `preview_pptx_text_patch_isolated_copy` 进一步执行：

- WorkspaceGuard 与扩展名校验；
- 源文件签名握手；
- 真实临时副本写入、同步、复读和自动清理；
- 审计后源文件签名、摘要和字节复核；
- `writesUserFile=false`。

## 4. 原界面工作流

C4B 控件继续位于 Library 右侧 PPTX 详情面板：

1. 用户先点击“编辑准备”建立 C4A 基线；
2. 面板列出安全的幻灯片文本和备注目标；
3. 用户输入单行替换文本；
4. 点击“验证隔离补丁”；
5. 面板显示变化部件数量、其余部件保全数量、语义复读和源文件写入状态。

该流程不会修改当前画布，也不会让标签页进入待保存状态，因为输出仅用于隔离验证。界面明确显示“不写入当前文件”和“原文件未修改”。

## 7. 下一步：C4C

C4C 按保守子集推进：

1. 为单运行文本枚举字号、字体、颜色、粗体、斜体、下划线和对齐状态；
2. 只允许不会改变运行数量和段落结构的样式补丁；
3. 评估普通形状文本和图片替代文本的安全目标；
4. 所有修改继续复用 C4A/C4B 单部件差异、临时副本和源文件不变门禁；
5. 继续不提供用户文件保存，直至冲突检测和可靠另存阶段。
