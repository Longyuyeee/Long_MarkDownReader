# B0 PDF 页面整理草稿审计

更新日期：2026-07-27

开发分支：`codex/a4-format-closure`

对应 Draft PR：#6

审计结论：**B0 已完成页面级操作模型和非破坏式桌面预览，但尚未生成或保存新 PDF。下一步进入 B1A 写入引擎、许可证、保真与隔离副本决策。**

## 1. 目的对齐

本阶段直接对应用户最初提出的“在管理器中阅读和基础编辑 PDF”。完整 PDF 正文排版编辑接近独立 Office/Acrobat 产品量级，首个可控闭环应先解决日常页面整理：

- 旋转页面；
- 调整顺序；
- 排除待删除页面；
- 明确新页码与原页码映射；
- 支持撤销、重做和离开保护；
- 在可靠另存实现前绝不改写源文件。

知识图谱、批注、OCR 和正文搜索继续有效，但不替代 PDF 页面编辑能力。

## 2. 审计起点

现有 PDF 工作面使用 PDF.js 进行本地阅读、文本层、搜索、缩略图和目录展示。Rust 后端只提供受知识库边界、文件签名和范围上限保护的读取命令；批注和 OCR 分别写入公开 sidecar。仓库当前没有经过真实 fixture、许可证和未知对象保真验证的 PDF 重写引擎。

因此 B0 不增加写回命令，也不把内存草稿宣传为已保存编辑。

## 3. 已实现能力

### 3.1 页面身份与不可变计划

每个计划条目保存：

- 稳定 `id`；
- `sourcePage` 原始页码；
- 相对旋转角度 `0/90/180/270`；
- `removed` 排除状态。

旋转、改序和排除均返回新的计划快照，不修改历史快照。预览旋转叠加在 PDF 原页自带旋转之上，不覆盖源页面方向。

### 3.2 页面整理工作面

PDF 原工作面新增“页面整理”入口和左侧页面栏：

- 同时显示“新第 N 页”和“原第 N 页”；
- 旋转页面缩略图并显示角度；
- 向前/向后改序；
- 排除和恢复页面；
- 始终至少保留一页；
- 汇总旋转、改序、排除和剩余页数。

页面栏明确显示“仅在内存中预览，不会修改源 PDF；可靠另存将在 B1 开放”。主阅读区继续展示源文件，避免把草稿误认为已保存结果。

### 3.3 历史与丢失保护

- 撤销/重做最多保留 60 个快照；
- 支持按钮、`Ctrl+Z`、`Ctrl+Y` 和 `Ctrl+Shift+Z`；
- 重置回源文件顺序和方向；
- 有草稿时标题显示“页面草稿”；
- 跳转其他文件、离开路由或关闭窗口前提示草稿将丢失；
- 路由内仅改变页码/批注定位不会误触离开提示。

## 4. 自动化与真实桌面证据

新增机器合同 `npm run check:pdf-page-plan-contract`，验证：

- 三页初始计划；
- 左旋 `-90°` 规范化为 `270°`；
- 操作不修改输入快照；
- 改序、排除和变更摘要；
- UI 撤销/重做、最少一页、路由/窗口离开保护；
- B0 后端不存在 PDF 文档写回命令。

真实 Tauri Debug/WebView2 使用两页 PDF 验证：

1. 原第 1 页向右旋转 90°；
2. 原第 1 页移动到第二位；
3. 原第 1 页标记排除；
4. 页面栏显示原第 2 页成为新第 1 页；
5. 撤销恢复页面，重做再次排除；
6. 重置后草稿状态清除；
7. 后续 Table、Canvas、文本、配置、日志和进程重启回归继续通过。

当前桌面门禁为 **29/29 项检查、21 张真实 Tauri 截图**。B0 证据为 `docs/evidence/a5-stage-a/b0-pdf-page-plan-preview.jpg`。

## 5. 当前能力声明

| PDF 能力 | 状态 |
|---|---|
| 阅读、缩略图、目录、文本层、搜索 | 已完成 |
| 批注、Markdown 引用、OCR、索引、图谱关系 | 已完成 |
| 页面旋转/改序/排除草稿与撤销重做 | B0 已完成 |
| 生成新 PDF、可靠另存和重开 | 未完成 |
| 提取、拆分、合并、插页 | 未完成 |
| 加密、表单、签名、附件保真 | 未完成，必须先审计 |
| PDF 正文排版重写 | 长期高级能力 |

因此当前仍不能宣称“PDF 页面编辑闭环完成”。只有 B1 生成的新文件通过第三方重开、页数/尺寸/方向验证、源文件字节不变和高风险对象阻断后，首批页面编辑才可升级为可保存能力。

## 6. 下一开发入口

进入 **B1A PDF 写入引擎与隔离副本决策**：

1. 比较候选引擎的许可证、维护、安全记录、离线能力和 Windows 包体积；
2. 用真实 PDF 覆盖对象流、交叉引用流、原始旋转、书签、表单、附件、加密和数字签名；
3. 第一批只在临时/隔离副本执行旋转、改序和排除，不触碰用户源文件；
4. 对新副本执行 PDF 复读、页数、MediaBox/CropBox、旋转、文本可提取性和第三方打开验证；
5. 表单、附件、加密、签名或未知结构无法证明保真时稳定阻断；
6. 通过后再接 B1B“另存为新 PDF”界面和外部冲突保护。

默认覆盖源 PDF 继续禁止。提取、拆分、合并和插页进入 B2，不与第一批可靠另存混合。
