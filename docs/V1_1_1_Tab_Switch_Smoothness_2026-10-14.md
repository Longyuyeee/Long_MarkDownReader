# 表格文档与侧栏标签切换平滑化

2026-10-14，接续用户反馈“切换 tab 界面会闪动一下”。基于 1.1.0，在 `codex/inbox-experience` 上与收集箱改进一并开发，尚未打包发布。

## 原因与改动

主编辑区的专用组件原本使用文档路径作为 key。两张 `.table.json` 或 CSV/TSV 之间切换，会销毁上一张表的整个组件，再挂载新组件；新表读取期间使用加载状态替换网格，造成短暂清空与布局重建。

- 同一资料库的 Table 类组件复用稳定容器；按资料库和外部文件上下文区分，其他专用格式继续保留原有生命周期。
- 新表读取时保留上一张表的标题、工具栏与网格，使用 `inert` 暂停其中的交互，快捷键入口也检查加载状态。新数据就绪后统一替换，避免旧数据被编辑或保存到新路径。
- 快速读取不显示短暂加载页；较慢的切换在180ms后显示小提示。首次打开仍显示加载状态，失败仍显示目标表的错误及重试入口，不把旧数据冒充读取成功。
- 按已经显示的文档身份记录阅读位置，切换前保存上一张表的滚动位置；首次访问从顶部开始，再次返回恢复原位置。补齐异步位置恢复后的过期请求检查。
- 侧栏页签取消串行退场/入场，前后内容交叠过渡，保留用户的动效速度与减少动效选项。退场层不接收点击，不再留出空面板。
- 文档标签只在路由成功后更新选中状态；取消未保存提示或导航被后续点击取代时，不错误激活目标标签。明确放弃草稿并完成切换后，同步清除上一文档的未保存标记。
