# Long编辑 v1.1.32

已正式发布于 2026-10-21T11:48:57Z，原安装器公开下载与摘要核对通过。

备份恢复后可以接着原来的工作，不必重新找文档和阅读位置。

- 资料内容包可选保存工作现场：打开文件、固定标签、阅读位置、搜索和参考资料；未保存正文不进入内容包。
- 恢复完成后按需弹窗接续，可选择文档、逐项定位或一次映射整个文件夹，参考与阅读位置一起更新。
- 有未保存内容时先记住恢复现场，保留原资料库和草稿；没有草稿时可直接切换继续。迟到的设置写入不能清掉新输入。
- 旧内容包仍按原流程恢复，主页面不增加常驻表单，保留全部既有功能、六种风格和正常动效。
