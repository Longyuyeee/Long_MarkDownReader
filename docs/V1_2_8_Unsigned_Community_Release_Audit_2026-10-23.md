# v1.2.8：JSON 字段与数组项复用

当前开发目标：`1.2.8`；当前运行时版本：`1.2.8`；当前公开版本：`1.2.7`。当前阶段：**v1.2.8 JSON 字段与数组项复用候选**。

## 用户操作

对象字段右键“复制为新字段…”输入名称，默认选中未占用的建议名；同级重名保留输入并提示，不覆盖原字段。数组项右键“复制此项”，完整副本放在原项旁。副本成为独立内容，源码定位和树形选择跟随副本，仍可直接撤销重做；无需新增常驻面板。

复制读取当前草稿，保留完整节点、长数字、转义、嵌套结构和内部注释。只编码新字段名，不整体反序列化再重写。节点旁注释归属不清时局部拒绝并说明原因，内容保持。新增八项 Rust 回归覆盖这些边界。

## 草稿接续

复用现有差异预览、一次撤销、保存及冲突流程，复制与移动、改值交错使用；来源或草稿变化时旧操作停止，切换文件关闭旧名称弹窗、菜单和预览。只读、无效源码、分析过期和分段模式不能执行。保存失败和外部冲突保留未保存内容。
