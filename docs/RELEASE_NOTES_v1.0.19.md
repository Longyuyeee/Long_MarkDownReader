# Long编辑 v1.0.19 发布说明

状态：候选准备中，尚未公开发布

v1.0.19 聚焦 v1.0.18 之后完成真实验收的最小增量：为资料库内 JSON/JSONC 增加离线、有界、只读的本地 JSON Schema sidecar 验证。

## 新增

- 对 `document.json` / `document.jsonc` 确定性发现同目录 `document.schema.json`。
- 支持 Draft 2020-12、JSONC 注释/尾随逗号、内部 fragment 引用和最多 200 条脱敏诊断。
- 在既有 JSON 编辑器中分开显示语法与 Schema 状态、来源、JSONPath、行列，并可点击定位源码。
- sidecar 变化可自动刷新；未配置 Schema 时不制造业务错误。

## 安全与边界

- Schema 最大 1 MiB、5 万节点、64 个引用；网络、远程 URI、文件引用与跨目录软链接全部拒绝。
- 外部文件、大文件范围模式和 `.schema.json` 自身递归发现均关闭。
- 验证过程不写文档或 Schema；显式保存和磁盘冲突保护保持不变。
- 当前社区候选仍为 `NotSigned`，Windows 可能显示未知发布者或 SmartScreen 提示。

## 验证与发布状态

功能阶段已通过 13 个命令测试、9 个内核测试和真实 Tauri 1280×800 / 720×680 状态矩阵；全仓 Rust 为 559 通过、0 失败、5 忽略，完整补丁发布门和生产依赖 0 漏洞已通过。

候选安装包尚未构建；构建后仍必须完成本地 WebView2 烟测、GitHub 托管安装生命周期、最终制品冻结、公开附件回下载复核和 v1.0.18 → v1.0.19 官方应用内更新观察，不能跳过安装生命周期直接发布。
