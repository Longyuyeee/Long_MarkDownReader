# Long编辑 v1.0.2

v1.0.2 是品牌统一、界面治理和发布事实收口补丁，不扩大复杂格式的能力承诺。

## 更新内容

- 全部应用入口更换为新图标：放大的实心金色 `L`、金色编辑笔尖与深蓝底。
- 完成受管文件路由收口，资料库内文件统一在右侧工作区打开并保留管理上下文。
- 完成 UI-1 至 UI-4：字号、共享组件、颜色与状态语义、管理页壳层和真实视觉回归均已纳入补丁门禁。
- 完成 144 张真实 Tauri WebView2 截图审计，覆盖核心壳层、11 类主要编辑器、三种核心主题与三档缩放。
- 主题注册表提供 3 个核心主题、4 个已验证场景预设和 12 个兼容外观组合。
- 修复 PDF、表格、工作簿、思维导图和 Canvas 在嵌入与窄宽度场景中的裁切、溢出和定位问题。
- 版本、能力矩阵、发布页面和文档统一到 `1.0.2`。

## 能力边界

本版本继续登记 41 类格式：29 类已验证、6 类为有限能力、6 类依赖外部程序。DOCX、PPTX、XLSX、PDF、ODF 和旧 Office 格式不会被描述为完整无损等价编辑；界面会显示只读、有限编辑、保存副本、旁车数据或外部应用接管状态。

## 安装与更新

- 系统：Windows 10/11 x64。
- 安装包：NSIS `.exe` 与 MSI `.msi`。
- Windows 代码签名：无，可能显示“未知发布者”或 SmartScreen 提示。
- 分发方式：仅从官方 GitHub Release 手动下载安装，并核对 `SHA256SUMS.txt`。
- 自动更新：本补丁不提供。原 Tauri 更新私钥在当前发布环境不可用，因此不发布无法由旧客户端验证的 `latest.json` 或 `.sig`；仓库中的原更新公钥保持不变。

## 发布文件

- `LongEdit_1.0.2_x64-setup.exe`
- `LongEdit_1.0.2_x64_zh-CN.msi`
- `SHA256SUMS.txt`

安装包 SHA-256 将在构建完成后写入本节，并随 GitHub Release 一同发布。

## 升级与回滚

v1.0.2 沿用既有应用标识、安装升级代码和用户数据路径，可从 v1.0.1 覆盖安装。回滚前请先备份知识库与设置，再卸载 v1.0.2 并从官方 Release 安装所需旧版本；不要用旧版本覆盖写入仅由新版本维护的副本。
