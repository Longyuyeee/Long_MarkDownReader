# D1B 复杂工作面一致性收口审计

审计日期：2026-07-31

对应版本：0.7.0

## 结论

D1B 已完成 JSON、Table、Diagram、Canvas、Workbook、PDF、DOCX、PPTX 八个高频复杂工作面的集中收口。本轮不扩展格式写入能力，只统一用户可见状态、辅助技术播报和窄屏操作优先级。

## 本轮完成

| 工作面 | 完成内容 | 保持不变的安全边界 |
| --- | --- | --- |
| JSON | 保存按钮统一为“保存中/保存/已保存”；文档和底部状态可播报 | 非法源码仍需显式确认，外部修改与只读保护不变 |
| Table | 保存状态与动态提示可播报；620px 以下标题、筛选和保存入口稳定换行；视图标签可横向滚动 | CSV/TSV 与 LongEdit Table 的原保存、转换和导出规则不变 |
| Diagram | 保存、渲染和语法错误状态可播报；620px 以下保留模板、结构、导出和保存优先级 | Mermaid 严格安全渲染、离开保护和导出限制不变 |
| Canvas | 自动保存与手动保存统一为“保存中/保存/已保存”；窄屏标题和状态不挤压工具栏 | JSON Canvas 自动保存、离开保存和失败提示不变 |
| Workbook | 保存按钮在无草稿时明确显示“已保存”；草稿、载入、结构更新和计算状态可播报 | XLSX 保护、数组公式、外部数据和高级对象阻断不变 |
| PDF | 批注 sidecar、页面草稿、隔离验证、可靠副本和阻断原因采用 status/alert 语义 | PDF 原文件不覆盖，高风险特性与复读门禁不变 |
| DOCX | 高级对象只读、隔离验证、保存进度和失败结果可播报 | 原件只读，只允许经验证的同目录新副本 |
| PPTX | 可靠另存面板、失败结果和底部验证状态可播报 | 原文件不写回，可靠副本白名单和三生产者证据不变 |
