# v1.2.40：YAML 多行条目复制排序

当前开发目标：`1.2.40`；当前运行时版本：`1.2.40`；当前公开版本：`1.2.39`。当前阶段：**v1.2.40 YAML 多行条目复制排序候选**。

## 用户变化

多行列表项沿现有右键“复制为新项…”／上移／下移进入差异，应用只改草稿，一次撤销／重做，显式保存才写盘。用户不必手动选择完整的缩进和段落。未增页面、常驻表单或说明卡片，全部功能、风格与正常动效继续保留。

基于解析器确认同一普通列表、目标项、相邻项和完整物理块；复制正文与块头行尾注释，移动交换两个完整条目，独立注释及其间隔保留原位。正文内以#开头的文字仍属于正文。保留`|`／`>`形式、缩进与chomp标记、段落、BOM、CRLF和其他内容。重新解析证明仅新增对应值或交换对应两项，并由新解析范围定位条目，避免选中相邻内容。

复杂集合、锚点／别名／标签、紧凑嵌套及含混独立注释保留源码入口。空的clip块移至文件末尾时，解析器会赋予不同的结尾换行；不能保持原值时在局部弹窗说明并保留原稿，不改写块形式。原有单行／流式列表路径继续保留。

保护后续输入、迟到变换、旧差异、文件切换、失败重试与完整冲突副本；没有自动保存或丢弃草稿。NSIS实际安装、手动升级及卸载与MSI构建摘要分别记录。
