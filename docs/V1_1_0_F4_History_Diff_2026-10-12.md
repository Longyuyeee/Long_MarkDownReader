# F4 历史差异与安全恢复实施审计

用户已确认 F3/F4 方案。历史入口保持原位；点击或键盘激活快照现在先比较，不立即替换正文。

## 已实现

- 左右对比当前草稿/磁盘与所选历史版本，标记增删行。默认主操作“恢复为副本”，替换编辑区必须再次明确确认。
- 原生命令重新读取快照与磁盘，记录内容签名。执行恢复前重新核对；文件或快照变化则要求重新比较。
- 副本使用唯一递增名称，复用可靠原子新建（不覆盖），创建后从主编辑区打开。原文件及其未保存标签不被覆盖。
- 替换前必须成功保存当前草稿到历史；保护失败不返回替换内容。返回后再次核对文件、草稿、编辑器、在途保存及比较对象，任何变化都不替换。载入历史后显式标记未保存，不自动写磁盘。
- 读取比较内容上限 20 MiB，目前支持库内 UTF-8 Markdown。非支持编码或过大文件明确报错。差异预览限制输入字符数、行数及 LCS 工作量，超限明确提示简化/截断；恢复仍使用完整快照。
