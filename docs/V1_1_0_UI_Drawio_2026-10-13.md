# Draw.io 页面导航与布局审计

实际 480×800 页面确认旧窄布局把页面列表压缩至不可见，用户难以切换多页文档；长文件名也与操作行争夺宽度。

修正：窄页面为页面列表保留 150px 可滚动区域，画布和属性区依次滚动访问；文件身份和操作分行；页面列表可独立滚动。无标签栏时改为两行根网格，避免多余自动轨道挤占画布。不改节点模型、转换与保存链路。
