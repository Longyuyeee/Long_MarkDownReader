# v1.0.15 后 M3B-2 社区轮廓与语义层级审计

日期：2026-08-28
开发线：`1.0.16`；运行时与当前公开版本：`1.0.15`
结论：M3B-2 通过；整个 M3B、路径视觉、导航镜头与 M3C 尚未完成。

## 1. 需求对齐与范围

本阶段直接对照专业能力路线图的“社区轮廓、语义色带和层级明暗表达主题”，并继承 M3B-1 的接续约束：远景社区身份必须在中近景连续可辨，轮廓不得移动真实节点、遮挡关系或成为无语义背景光斑。本阶段不实现曲线/平行边、路径方向流动、关系标签、缩略图、聚类镜头或 M3C 大图性能。

## 2. 实际实现

- 使用既有稳定 Louvain 社区 ID，不建立第二套聚类事实。
- 从当前可见成员坐标生成带节点半径和缩放留白的确定性凸包；单节点也有确定性圆形包络。
- 轮廓只在 Canvas 绘制阶段消费，位于真实关系、箭头、节点、选中态和标题之下，不进入力布局、布局保存或导出。
- 中景使用占优对象类型的语义色，绘制较明确的色带、实线边界及“社区名 · 成员数”；近景降低填充、改为虚线边界并让完整节点标题优先；远景不重复绘制轮廓，继续使用 M3B-1 摘要。
- 增加轮廓数量与成员包覆 DOM 门禁，以及纯函数的确定性和节点坐标不变检查。

## 3. 审计结果

| 项目 | 实际结果 |
| --- | --- |
| 纯算法 | 两个三节点社区生成两个稳定凸包；重复计算逐字节一致；输入节点坐标前后完全一致 |
| 语义连续性 | 17 节点真实图谱在近/中景各有 5 个轮廓，远景为 0 个成员轮廓和 5 个社区摘要 |
| 成员包覆 | 三主题的近景、中景以及三档中景视口均为 `coversMembers=true` |
| 主题 | dark、white、contrast 全部通过，关系线和箭头保持在色带之上 |
| 视口 | 1280×800、1000×700、720×680 均无页面横向溢出 |
| 安全 | 三主题运行时错误均为 0，测试资料库 SHA-256 前后一致并成功返回资料库 |

真实截图复核中，720×680 中景的图例、5 个社区轮廓和底部状态栏均可达。高对比主题的重复审计进一步暴露 M3B-1 遗留的偶发远景越界：当轮廓总宽度超过避让图例后的安全区，旧相机会从安全区左缘排布。现改为安全区足够时在安全区居中，不足时退回整幅 Canvas 居中，三主题远景边界门禁重新通过。

证据位于 `docs/evidence/post-v115-m3b2-community-contours-semantic-hierarchy/`，包含三主题近/中/远景、三档窗口截图和 `desktop-*.json`。

## 4. 接续点

下一最小阶段冻结为 **M3B-3 路径与关系视觉表达选择审计**。先核对实际网络直线、平行边重叠、关系标签、路径方向表达、证据面板遮挡和减少动效消费，再选择最小实现；不得因 M3B-2 通过而宣称整个 M3B、导航镜头或 M3C 已完成。
