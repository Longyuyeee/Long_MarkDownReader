# Long编辑 v1.1.34

已正式发布于 2026-10-21T18:46:06Z，原安装器公开下载与摘要核对通过。

章节链接随资料库、文件位置和副本一起接续。

- 大纲右键“复制章节链接”默认生成库内可移植地址，保留“复制本机章节链接”和旧链接兼容。
- 库内移动、改名以及跨库复制接续目标路径，配套笔记一起复制，原文和个人补写保持。
- 点击优先使用已打开的目标草稿，保留当前输入；标题改名、删除或文件缺失给出局部提示，不猜测跳转。
- 修复查找替换后单次撤销偶尔不恢复文字的问题，保留替换前的正文和已有草稿。
- 保留全部既有功能、六种风格和正常动效，不增加主页面常驻表单。
