# 资料内容备份与恢复

从“设置 → 隐私与诊断 → 资料内容备份”备份已经保存在磁盘上的资料，恢复到新位置后继续使用。内容包包含你选中的文件、附件、PDF批注及可选的Markdown/TXT历史，不等于整份应用环境的镜像。

## 备份资料

1. 点击“备份资料”，选择资料库。可以备份整个库，也可以选择库内的相对子目录。
2. 选择文档与数据、图片及其他附件、PDF批注；需要带走Markdown/TXT历史时再勾选历史。批注和历史依赖对应源文档，取消文档会一并取消这两项。
3. 点击“预检所选内容”，核对数量、大小、内容预览和未包含清单。预检只读磁盘，不会自动保存正在写的文档。如果需要包含刚写的内容，请先正常保存，再重新预检。
4. 选择源资料库以外的新ZIP文件位置并导出。软件复核源文件和包内摘要，完成后显示保存路径及SHA-256。同名备份不会被覆盖，建议使用日期或项目名称区分。

预检后继续编辑了源文件，可能会看到“发生变化，请重新预检”。重新核对范围后再导出即可；软件不会悄悄使用旧清单，也不会自动替你保存草稿。

## 恢复到新位置

1. 点击“从备份恢复”，选择资料内容ZIP。管理备份请使用上方独立的“管理备份 → 导入恢复”，不能混用。
2. 等待清单、大小、路径和逐文件摘要校验完成，核对内容和未包含项。
3. 选择父目录，填写一个尚不存在的新文件夹名称。恢复目标不能在现有已配置资料库或应用配置/缓存内部；已有目录即使为空也不会被合并或覆盖。冲突时换一个新名称，不必删除原目录。
4. 点击“恢复到新目录”。完成后可点击“添加到资料库”，再自行切换；软件不会自动切库或替换当前草稿。

导出时选择了子目录，恢复后会保留这段库内相对目录，便于文件之间的相对图片和链接继续对应。PDF修改时间及配套批注一起保留；选中的历史会绑定到恢复后的新文件路径，保留重要版本状态与备注。请实际打开恢复副本确认后再处理旧资料。

## 包含范围与限制

| 内容 | 规则 |
| --- | --- |
| 文件内容 | 来自明确选择的磁盘范围，不包含尚未保存的正文 |
| 图片与附件 | 需要勾选附件，并确保文件位于所选范围；不会跟随范围外链接自动收集 |
| PDF批注 | 与源PDF配套校验；不自动携带应用的其他临时缓存 |
| 历史 | 默认不选；支持Markdown/TXT历史，包括保留状态与备注，不代表所有格式都有历史 |
| 隐藏项、依赖目录与已知敏感配置 | 排除并显示原因；回收站等隐藏目录不在内容包范围内 |
| 设置、凭据与模板 | 不读取应用凭据；管理备份、工作现场和模板仍各用原来的独立入口 |
| 大小 | 未压缩总量最多512MiB、单文件128MiB、10000个文件条目；大库请选择子目录分包 |
| 恢复方式 | 完整校验后恢复到新目录，不支持原位覆盖或合并；原资料保持不变 |

内容包**未脱敏、未加密**。选中的文档可能包含私人资料，分享或上传前请自行检查。SHA-256用于核对完整性，不提供加密或来源身份认证。

## 失败与取消

损坏包、缺失源、源变化、容量预算不足或目录冲突会阻止完成，不会把部分产物称作成功。任务执行中可以请求取消；若已经进入最终提交阶段，会明确告知取消未接受，等待最终结果即可。

正常失败或已受理取消会清理本次自有暂存。异常中断、清理或回退未完成时，提示会指出需核对的暂存与记录位置，请保留这些材料；软件不会自动全量重试或覆盖现有内容。解决原因后重新预检/选择新位置，不要把未完成暂存当作成功备份。
