# v1.2.34：YAML 多行文本编辑

普通 YAML 字段右键“修改值…”即可编辑多行说明文字，弹窗直接预填可读文本，无需手写块标记或缩进。支持普通 literal 块、嵌套及列表内映射字段，保留原块头、注释、缩进和其他内容。

改变结尾换行时自动调整必要的标记，并在差异标题中明确显示换行数量。确认后只改草稿，一次撤销／重做，显式保存才写盘；折叠块、引用和复杂内容仍可定位源码。

继续保护未保存内容、延迟预填与修改结果、后续输入、旧差异、文件切换、保存失败重试与外部冲突完整副本。错误时保留输入，保留全部既有功能、风格和正常动效。

未签名社区版；完整检查与实际安装检查仍待完成，尚未发布。应用内自动更新实际观察独立记录。
