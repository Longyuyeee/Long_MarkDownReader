# Long编辑 v1.0.6

v1.0.6 是 v1.0.5 之后的外部打开、逐格式默认应用与体验证据收口版本。它不扩大 Office 等价编辑承诺，重点是让已经支持的格式在知识库内打开和从 Windows 外部打开时使用同一套专业工作区与保存边界。

## 主要变化

- 外部打开覆盖 43 类注册格式：29 类可编辑、8 类只读预览、6 类通过显式转换或系统桌面应用处理。
- Markdown、文本、日志、代码、结构化数据、Table、Canvas、Draw.io、Mermaid 与 OPML 外部打开后进入各自专用编辑器，保留撤销、重做、冲突保护和显式保存。
- 图片、视频、PDF、DOCX、ODS、ODP、PPTX 与 XLSX 外部打开后使用授权只读预览，不把知识库内的有界写入能力错误扩展到任意外部文件。
- 格式能力页可为 37 类格式、85 个扩展名逐项注册 LongEdit 的“打开方式”候选；最终默认应用仍由用户在 Windows 中确认。
- 安装器继续只声明 Markdown 关联，不会因为应用支持更多格式而静默接管全部扩展名。
- 修复 Unicode/空格路径、Windows 设备路径和已有实例二次文件转交；卸载会清理 LongEdit 自己的候选项并保留用户文件与 Windows 原默认值。
- UX-01 至 UX-41 基础体验清单完成有界回写，格式、路由、默认应用与安装证据漂移会阻断补丁质量门。

## 安装与更新

- v1.0.5 用户可在应用发现 v1.0.6 后确认更新；安装器下载前后必须匹配官方 GitHub Release 的 SHA-256。
- v1.0.4 及更早版本没有受控更新链，需要先手动安装 v1.0.5 或直接安装 v1.0.6。
- 本版本没有 Authenticode 商业签名，Windows 可能显示“未知发布者”或 SmartScreen。请只从官方 Release 下载并核对 `SHA256SUMS.txt`。
- `1.0.5 -> 1.0.6` 的真实应用内覆盖安装与资料保留观察需要在 v1.0.6 附件发布后完成。

## 能力边界

- 完整 Excel、Word 或 PowerPoint 等价编辑仍是长期方向；当前复杂公式、宏、跨部件对象和未验证生产者结构继续只读、阻断或可靠副本。
- MOV、MKV、AVI、MPEG、MPG 的应用内播放取决于 Windows/WebView2 解码器；不支持时应提示并允许外部播放器打开。
- 默认应用候选必须逐格式由用户触发，LongEdit 不直接替用户更改 Windows 默认值。
- 社区安装包保持 `NotSigned`，不代表企业签名候选或商业发布资格。
