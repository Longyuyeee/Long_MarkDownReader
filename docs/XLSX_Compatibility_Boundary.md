# XLSX 基础兼容边界 1.0

> 本文描述 v0.7.0 当前已交付能力，不是长期产品上限。完整 Excel 等价编辑已进入 FR-DATA-009，内核契约与兼容性门禁见 `Workbook_Engine_Interface.md`。

状态：S6-8 已实现

定位：安全预览、渐进导入与基础内容/样式保真编辑，不宣称替代 Microsoft Excel。

## 1. 已支持

- 知识库直接识别并打开 `.xlsx`。
- 多 Sheet 标签切换。
- 单元格字符串、整数、浮点数、布尔、日期/时间和错误值读取。
- 工作簿级与 Sheet 级命名区域读取；名称框支持安全单一 A1 区域跨 Sheet 导航，命名区域公式可参与显式重算。
- 公式文本与工作簿内已有的缓存结果切换显示。
- 行分页读取、二维虚拟滚动；单页最多返回 2,000 行，后端单次上限 5,000 行。
- 预览最多显示前 256 列，并明确提示截断；工作表实际行列数仍显示。
- 选中 Sheet 转换为开放 `.table.json`，原 XLSX 不修改；第一行作为字段名，空字段名自动补齐。
- 转换后可使用 Table 编辑、类型推断、看板、图表与 Markdown/Canvas 图表引用。
- 选择并编辑源工作簿中已存在的文本、数字、布尔和公式单元格，或清空其内容。
- 在数据区域外创建空白单元格；工作表 XML 保持行列有序并同步扩展有效范围。
- 连续区域支持拖拽/Shift 选择、TSV 复制粘贴、剪切、清空和批量撤销重做。
- 支持当前工作区整行、整列、左上角全选，以及最多 32 个 Ctrl/Cmd 多区域选择；格式与清空操作对重叠区域去重并形成一次历史记录。
- 填充柄支持模式复制、一维数字序列外推和基础样式复制；公式按目标偏移迁移 A1 相对/混合引用，绝对引用保持不变，越界生成 `#REF!`。
- 支持显式重算当前已加载公式：当前未保存草稿在内存模型中参与同 Sheet 和跨 Sheet 依赖求值，循环引用及不支持公式显示明确错误；单次最多返回 10,000 个公式结果。
- 读取和写回默认/自定义行高与列宽，前端使用稀疏偏移的可变尺寸虚拟网格；支持选中行列批量设置或恢复默认尺寸。
- 读取、渲染、合并和取消合并矩形区域；合并区域只允许编辑左上角锚点，重叠范围或非锚点含有内容时整批拒绝。
- 读取并渲染单元格基础字体、RGB 文字色、RGB 填充色、边框、水平对齐、换行和数字格式分类。
- 连续区域可编辑字体、字号、粗体、斜体、下划线、文字色、填充色、所有边框、水平对齐、换行和常用数字格式；样式操作作为单次批量历史记录。
- 读取 `cellStyleXfs/cellStyles` 命名样式并按名称应用；主题色、tint 与 64 色索引调色板解析为 RGB，四条边框独立读取、渲染和写回。
- 自定义数字格式以 `custom:` 稳定契约读取和受限编辑，写回时分配并去重 `numFmtId`；单条格式最多 128 字符。
- 条件格式当前不参与视觉计算和规则编辑，但内容或样式写回会保留原有 `conditionalFormatting`、`dxf` 和未知规则。
- 支持读取和签名保护写回冻结窗格；支持取消冻结，存在未保存内容草稿时不执行独立结构写回。
- 读取自动筛选、Excel Table 范围/列/样式和数据验证规则；提供最多 50,000 行的非破坏性会话排序筛选，并对字面量列表与基础标量验证执行保存前约束。
- 编辑草稿支持撤销/重做、未保存提示和快捷保存；外部修改会触发签名冲突而不是被覆盖。
- 写回只替换目标工作表中的目标单元格节点，未编辑 OOXML 部件保持原始字节。

读取引擎使用纯 Rust [calamine 0.36.0](https://docs.rs/calamine/0.36.0/calamine/)，依赖精确锁定并纳入 Cargo.lock。

## 2. 公式语义

工作簿预览同时读取公式文本和文件中保存的缓存结果，并提供基于 IronCalc 0.7.1 的按需重算：

- Excel/LibreOffice 保存过且包含缓存结果时，显示该结果。
- 缓存缺失或草稿改变依赖时，可点击“重算”刷新当前已加载公式；结果只驻留内存，不静默覆盖 XLSX 缓存值。
- 外部工作簿链接不会发起网络或文件访问；循环引用、不支持函数和不兼容语义以公式错误呈现。
- 转换为 Table 时写入缓存结果，不把公式转换成 LongEdit 公式。

这能在提供依赖传播的同时，避免应用用非完全等价的计算结果静默改写财务或业务文件。

## 3. 安全与规模限制

- 文件必须位于当前知识库，并通过 `WorkspaceGuard` 解析。
- XLSX 最大 128 MB。
- 预览返回列最多 256；转换遵守 Open Table 的 200,000 数据行、512 列和 64 MB 输出限制。
- 解析和转换在线程池执行，不阻塞 Tauri 主线程。
- 转换创建新文件，重名时递增命名，不覆盖 XLSX 或已有 Table。

## 4. 暂不支持

- 跨不连续区域的 TSV 复制，以及粘贴时按目标位置迁移公式引用；当前公式迁移用于填充柄。
- 行列插入删除、隐藏/分组和更完整的工作表结构编辑；Table 创建、改名、扩缩范围与持久化排序筛选条件尚未开放。
- 自动重算、重算结果写入 XLSX 缓存，以及易失函数、动态数组、命名区域增删改和全部 Excel 函数的完整等价；外部链接、数据连接、Pivot Cache、Power Query、数据模型和宏/VBA 只做脱敏识别与保真，不执行或刷新。
- 条件格式的视觉计算与规则编辑，以及图表/图片的像素级渲染和对象编辑、批注、公式/自定义数据验证求值及打印设置的视觉还原；图表/图片结构、锚点和系列引用已经可读并可定位，打印区域与页面设置已有只读摘要。
- 打印预览、分页计算、页面设置/页眉页脚编辑，以及渐变填充、主题字体、垂直对齐、文本旋转和高级保护属性的完整还原；保护状态只读，不支持修改保护或密码解锁。
- `.xls`、`.xlsb`、`.ods` 的产品入口，尽管底层读取库可能覆盖其中部分格式。

因此 FR-DATA-006 与 FR-DATA-009 当前仍标记为“部分完成”。S6-15 已建立复杂 fixture 全包差异白名单、10,000×12 Debug CI 性能预算和机器可读发布档案；总体 `xlsxRoundTrip` 仍为计划，不能宣传完整 Excel 等价。S8-1A 已完成行列隐藏、取消隐藏和 0–7 级大纲分组；S8-1B1 已冻结插删坐标迁移规则并开放只读预览，但尚未写回文件。下一步进入 S8-1B2 整行插入删除包级事务。详细分维度边界见 `XLSX_Public_Compatibility_Matrix.md`，发布口径见 `XLSX_Release_Compatibility_Statement.md`。
