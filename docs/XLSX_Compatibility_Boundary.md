# XLSX 基础兼容边界 1.0

> 本文描述 v0.7.0 当前已交付能力，不是长期产品上限。完整 Excel 等价编辑已进入 FR-DATA-009，内核契约与兼容性门禁见 `Workbook_Engine_Interface.md`。

状态：S6-5 已实现

定位：安全预览、渐进导入与基础内容/样式保真编辑，不宣称替代 Microsoft Excel。

## 1. 已支持

- 知识库直接识别并打开 `.xlsx`。
- 多 Sheet 标签切换。
- 单元格字符串、整数、浮点数、布尔、日期/时间和错误值读取。
- 公式文本与工作簿内已有的缓存结果切换显示。
- 行分页读取、二维虚拟滚动；单页最多返回 2,000 行，后端单次上限 5,000 行。
- 预览最多显示前 256 列，并明确提示截断；工作表实际行列数仍显示。
- 选中 Sheet 转换为开放 `.table.json`，原 XLSX 不修改；第一行作为字段名，空字段名自动补齐。
- 转换后可使用 Table 编辑、类型推断、看板、图表与 Markdown/Canvas 图表引用。
- 选择并编辑源工作簿中已存在的文本、数字、布尔和公式单元格，或清空其内容。
- 在数据区域外创建空白单元格；工作表 XML 保持行列有序并同步扩展有效范围。
- 连续区域支持拖拽/Shift 选择、TSV 复制粘贴、剪切、清空和批量撤销重做。
- 合并区域只允许编辑左上角锚点；区域操作命中其他成员单元格时整批拒绝。
- 读取并渲染单元格基础字体、RGB 文字色、RGB 填充色、边框、水平对齐、换行和数字格式分类。
- 连续区域可编辑字体、字号、粗体、斜体、下划线、文字色、填充色、所有边框、水平对齐、换行和常用数字格式；样式操作作为单次批量历史记录。
- 编辑草稿支持撤销/重做、未保存提示和快捷保存；外部修改会触发签名冲突而不是被覆盖。
- 写回只替换目标工作表中的目标单元格节点，未编辑 OOXML 部件保持原始字节。

读取引擎使用纯 Rust [calamine 0.36.0](https://docs.rs/calamine/0.36.0/calamine/)，依赖精确锁定并纳入 Cargo.lock。

## 2. 公式语义

工作簿预览同时读取公式文本和文件中保存的缓存结果。LongEdit 不包含 Excel 公式计算引擎，也不会重新计算公式：

- Excel/LibreOffice 保存过且包含缓存结果时，显示该结果。
- 缓存缺失时仍显示公式文本，但结果可能为空。
- 转换为 Table 时写入缓存结果，不把公式转换成 LongEdit 公式。

这能避免应用用不兼容的计算器静默改写财务或业务结果。

## 3. 安全与规模限制

- 文件必须位于当前知识库，并通过 `WorkspaceGuard` 解析。
- XLSX 最大 128 MB。
- 预览返回列最多 256；转换遵守 Open Table 的 200,000 数据行、512 列和 64 MB 输出限制。
- 解析和转换在线程池执行，不阻塞 Tauri 主线程。
- 转换创建新文件，重名时递增命名，不覆盖 XLSX 或已有 Table。

## 4. 暂不支持

- 整行/整列、多区域选择、填充柄和粘贴时公式相对引用迁移。
- 行列尺寸、合并区域、命名样式和工作表结构编辑。
- 重新计算公式、外部链接、Power Query、数据模型和宏/VBA。
- 合并单元格、条件格式、图表、图片、批注、数据验证和打印设置的视觉还原。
- 行高、列宽、主题色/索引色、渐变填充、混合边框、自定义数字格式及高级保护属性的完整还原。
- `.xls`、`.xlsb`、`.ods` 的产品入口，尽管底层读取库可能覆盖其中部分格式。

因此 FR-DATA-006 与 FR-DATA-009 当前仍标记为“部分完成”。下一阶段继续沿分层工作簿内核扩展整行整列、多区域选择、填充柄和公式相对引用迁移。
