本项目沿用本机 sidecar 批注，不将其等同竞品的内嵌批注、账号同步或共享审阅。

## 实现与操作

- 新增 `MobilePdfAnnotationEditor.vue`：独立任务页展示文件、页码／类型、颜色与评论。编辑覆盖阅读工作区，并隐藏、禁止操作底下的阅读控件和旧面板。
- 颜色只显示当前值，点开四种带文字标签的选择；原文先显示摘要，点开完整摘录。返回先关短弹窗，再返回批注列表；本机输入不因返回而放弃。
- 列表新增“继续这次输入”，恢复评论、选区、颜色和输入位置；保留原筛选、摘录选择、列表滚动与入口焦点。保存才更新正式批注，放弃输入需要独立确认。
- 草稿保护读取 textarea 中实际可见的 IME 值；配额失败阻止返回并保留原输入。保存中阻止返回和重复提交；写入失败可重试，冲突不覆盖较新记录，需明确放弃并重新读取后再修改。
- 保留提交成功但草稿清理失败后的新 revision，重试更新同一个编号，不重复新增。原 PDF、引用位置、批注编号和已有未知字段均保留。
- 一般说明进入编辑页专属问号，不混入笔记整理说明；不再常驻“输入已暂存”等文字。必要错误仍在操作位置显示。视口缩短时保持聚焦输入可见，短确认正文可聚焦滚动，弹窗内限制 Tab 焦点。
