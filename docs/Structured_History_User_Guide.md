# 结构化源码历史与恢复

资料库内的 JSON/JSONC、YAML/YML、XML、TOML 可从源码编辑器工具栏、保存按钮旁的 **文档操作 → 历史与差异…** 打开。每次显式保存会记录保存前、后的源码；首次尚未保存过的文件可能没有历史记录。相邻相同版本不重复记录。

选择一个历史版本，先查看它与“当前编辑区草稿”或“磁盘已保存内容”的差异。可以搜索版本、保留重要版本及添加备注，入口沿用原历史列表的菜单。

- **恢复此处**：只将这一处差异恢复到当前草稿，保留其他未保存的修改。
- **替换编辑区…**：确认后先保护当前草稿，再载入选中的整份历史。恢复可用 Ctrl+Z 一次撤销，仍需点击保存才会写回原文件。
- **恢复为副本**：在原目录创建同扩展名的恢复副本，保留现有可读编码、BOM 和换行策略；原文件与原草稿保留。

继续输入、切换文件、保存或磁盘变化后，旧的恢复请求不会覆盖新内容。弹窗提示重新比较时，关闭差异后再次选择版本即可；遇到保存冲突，继续使用已有比较与副本操作。

只读文件可以比较历史，恢复按钮会停用。语法有问题的源码仍可以比较，保存时继续沿用对应格式的确认或校验。外部文件与 SVG 沿用原能力；既有编码/NUL、大文件读取和 20 MiB 完整历史比较边界保留。
