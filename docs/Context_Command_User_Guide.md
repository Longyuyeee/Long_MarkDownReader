# 按当前文件查找操作

点击顶部“命令”，或按 Ctrl+P，在窗口中选择“操作”。输入“附件”“历史”“录入检查”“阅读笔记”等词即可查找。原来的 `>` 命令前缀仍可使用。“资料”继续搜索文件和正文，支持原有跨库搜索与侧边参考。

| 当前内容 | 可找到的操作 |
| --- | --- |
| Markdown 笔记 | 管理附件、历史与差异、查找替换、保存、导出 HTML |
| 含阅读笔记的 Markdown | 更新 PDF 阅读笔记，打开原有预览窗口 |
| Markdown 笔记中已固定的参考资料 | 核对参考来源，保留当前笔记内容 |
| CSV、TSV、Table | 检查全部记录；有筛选条件时可检查筛选结果 |
| 工作簿 | 检查所选区域、检查筛选结果 |
| 库内 JSON、YAML、XML、TOML 源码 | 源码历史与差异 |
| 库内普通文本 | 历史与差异 |
| 资料库内的 PDF | 查看批注；选中批注后可整理阅读笔记 |

只显示当前文件支持的操作，读取或保存期间暂不可执行的项目不提供。操作打开既有面板或弹窗，检查不会自动保存正文。原有右键、文档操作菜单、快捷键都保留。

命令绑定打开窗口时的文档；窗口打开后如果切换文件，旧结果会提示重新打开，避免误操作另一份资料。未保存内容继续由原有草稿保护和保存流程接续。PDF 批注整理沿用原有批注保存流程。

Ctrl+P 由应用优先处理，打开命令时保留原编辑和预览状态；F11 等工作区原有快捷键继续使用。
