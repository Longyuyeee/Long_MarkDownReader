# 核对与修复来源

参考面板的“参考来源操作”菜单选择“核对来源…”。原文件移走或暂时不可读时，可查看所在位置、按文件名查找新来源，并从相对路径区分同名文件。确认前显示旧/新位置及影响范围，取消不会修改记录。

关系栏中打开单条关系的操作菜单，选择“核对来源…”。修复只改变这条关系的另一端，保留方向、类型和补充说明。确认后可直接打开新来源；关系在核对期间被其他操作改变时，会提示重新核对。

笔记中失效的“来源”或 PDF 批注链接也可打开核对窗口。修复只进入当前草稿，可撤销，请手动保存；其他草稿和原文件不会被覆盖。代码中的示例链接、代码围栏和普通文字保持不变。无法准确识别的链接仍可手动编辑，不会强行替换。

原页码、批注身份与文字位置必须核对成功才按原定位修复。找不到或出现多个相同文字、大 PDF 暂时无法确认位置时，可以保留原记录，或明确选择“只关联文件，取消原定位”，之后重新定位。修改页码会取消旧批注定位。
