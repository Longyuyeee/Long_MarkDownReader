# UX-43 图片与视频工作区审计

日期：2026-08-06

## 结论

LongEdit 现已注册 43 类格式。新增图片和视频两个格式族，均在资料库中使用独立只读媒体工作区打开，不修改、不索引也不上传源文件。

## 图片能力

- 支持 PNG、JPG/JPEG、GIF、WebP、BMP、ICO 和 AVIF。
- 提供适应窗口、100% 显示、连续缩放、左右旋转和透明背景网格。
- 显示 MIME、文件大小和像素尺寸；100 MiB 以上交给外部程序处理。

SVG 继续使用现有安全源码编辑与净化预览工作区，不降级为普通图片查看。

## 视频能力

- 支持 MP4、WebM、Ogg Video 和 M4V 文件识别。
- 使用系统 WebView 原生播放控件，提供播放速度和全屏入口。
- 显示 MIME、大小、分辨率和时长；128 MiB 以上交给外部播放器。
- 实际可播放编码取决于当前 Windows WebView2 的编解码器；容器受支持不等于任意编码都能解码。

## 安全与性能

后端先通过 `WorkspaceGuard` 确认媒体属于当前资料库、扩展名已注册且大小未超预算，只对该次确认后的规范化文件路径授予只读权限。前端使用 Blob URL 解码，并在切换文件或卸载工作区时立即释放 URL。

## 验证

真实 Tauri WebView2 回归已覆盖透明 PNG 的加载、缩放和旋转，以及运行时 WebM 的元数据读取、原生播放界面和 720px 窄窗口。页面溢出、阻断错误与运行时错误均为 0。证据位于 [`evidence/ux43-media-workspace`](./evidence/ux43-media-workspace/)，专项门为 `npm run check:media-workspace`。
