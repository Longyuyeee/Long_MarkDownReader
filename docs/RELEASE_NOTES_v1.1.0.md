# Long编辑 v1.1.0

这一版集中提升编辑空间、界面一致性和日常资料工作流。

## 主要改进

- 全界面改版，统一导航；文档标签与快捷操作合并，给正文更多空间，切换文档不再重排标签。
- 快速笔记直接选择保存位置；新增命名工作会话、智能集合、Markdown 历史差异与安全恢复。
- 更多界面风格、正文/代码字体和排版选项；文件可自定义图标与颜色，目录层级更清楚。
- 文档名称可直接点击改名；参考阅读、导出和历史等常用操作更容易找到。
- 修复文件树跳动、选中文件闪烁、菜单与浮窗闪烁、专注模式变形及切换样式后的编辑器异常。
- 文件路径暂不可用支持重试；重新读取失败保留未保存内容。

## 下载与升级

支持 Windows 10/11 x64，提供 NSIS 和 MSI。建议普通用户选择 NSIS。
应用可自动检查更新，但下载与安装必须确认；也可从本 Release 手动下载安装。
这是未签名社区版，Windows 可能提示“未知发布者”或 SmartScreen，请核对附件 SHA256SUMS.txt 的 SHA-256。

## 能力边界

现有 43 类格式能力不变，有限编辑和只读边界继续保留。本版历史差异恢复针对 Markdown；纯文本历史差异和网页正文采集留待后续。
完整发布与验收证据见 [发布审计](https://github.com/Longyuyeee/Long_MarkDownReader/blob/main/docs/V1_1_0_Unsigned_Community_Release_Audit_2026-10-13.md)。
