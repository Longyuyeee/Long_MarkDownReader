# P1-A2 图片编辑工作区审计

审计日期：2026-08-15

阶段状态：已验收

## 需求与 UI 对齐

图片编辑继续嵌入初版“左侧资料库 Tab + 右侧编辑区”结构，没有新增顶层窗口。编辑入口位于现有媒体工具栏，宽屏使用右侧属性面板，窄窗口把同一面板折叠到图片舞台下方；字号、控件高度、边框、颜色和状态语义复用工作区主题变量。

资料库内 PNG、JPEG、WebP、BMP 支持旋转、水平/垂直翻转、锁定比例缩放、格式选择和另存副本。GIF、ICO、AVIF 与所有外部图片仍然只读，源图片没有覆盖入口。

## 安全保存闭环

编辑模式先调用 `inspect_image_edit_source` 获取源 SHA-256 与原始尺寸；另存时把身份和变换计划提交给 `save_image_transform_copy`。后端限制路径、格式、边长、像素、内存和文件大小，拒绝过期源或已有目标，原子新建后复读字节、摘要与尺寸，并再次确认源文件不变。

## 真实桌面证据

- 1280×800：右侧面板宽 `286 px`，图片舞台宽约 `723 px`，文档横向溢出为 `0`。
- 720×680：面板移动到舞台下方，宽约 `509 px`，文档横向溢出为 `0`，面板内部滚动保持所有命令可达。
- 交互：960×540 PNG 完成右转、水平翻转、锁比缩放到 480×270，并选择 WebP。
- 保存：报告为 `saved_verified`，`sourceUnchanged=true`、`targetReopened=true`；保存副本以 480×270 WebP 在同一右侧媒体工作区重新打开。
- 运行时：阻断错误 `0`；两张截图已经人工复核，未包含用户内容或本机用户路径。

证据位于 [`docs/evidence/p1a2-image-editor`](./evidence/p1a2-image-editor)，由逐文件 SHA-256 清单和 `npm run check:p1a2-image-editor` 保护。
