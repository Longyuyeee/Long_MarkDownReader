# Long编辑 v1.0.1 无代码签名社区版发布审计

审计日期：2026-08-02

发布通道：`community-unsigned`

目标版本：`v1.0.1`

## 结论

v1.0.1 是基于已完成安装生命周期验证的 v1.0.0 制作的品牌与工作区 UI 补丁。版本继续采用无 Windows Authenticode 签名的社区发布方式，并沿用 v1.0.0 的 Tauri 更新公钥。发布前必须完成前端构建、Rust 锁定依赖检查、格式与主题合同检查、NSIS/MSI 安装包构建、更新签名和 GitHub 质量门禁。

本补丁没有宣称重新完成一轮隔离 Windows 环境的安装、升级、卸载全生命周期测试。其基础安装证据继承自 [v1.0.0 发布审计](V1_0_0_Unsigned_Community_Release_Audit_2026-08-01.md)；v1.0.1 重点校验版本一致性、资源打包、界面结构、构建产物和更新签名连续性。

## 本次变更范围

- 将用户选定的深海军蓝底、金色钢笔轮廓 `L` 图标应用到桌面安装包、各平台图标、应用标题栏、工作台和 README。
- 将 PDF、表格、工作簿、图表、思维导图和 Canvas 等日常文件统一纳入资料库右侧工作区。
- 修复 ODF 嵌入编辑器映射遗漏，并移除多个工作区根节点对视口尺寸的错误依赖。
- 增加工作区尺寸令牌并完成全局 UI 一致性审计；剩余治理项在 UI 审计文档中分阶段跟踪。
- 将产品和安装包版本从 1.0.0 提升到 1.0.1。

## 安全与签名边界

- Windows 安装包没有 Authenticode 发布者签名，系统可能显示“未知发布者”或 SmartScreen 提示。
- Tauri 更新签名只验证更新包完整性，不证明 Windows 发布者身份。
- 更新私钥只存放于被 `.gitignore` 排除的 `.release-secrets/`，不得进入 Git、构建附件或日志。
- 发布资产必须包含 `SHA256SUMS.txt`，用户应只从本仓库 GitHub Releases 下载并核对哈希。

## 发布门禁

发布前核对：

1. `package.json`、`Cargo.toml`、`Cargo.lock` 与 `tauri.conf.json` 版本均为 1.0.1。
2. 前端生产构建和 `cargo check --locked` 通过。
3. 主题、格式和 v1 社区发布合同通过。
4. NSIS、MSI 及其更新签名由同一受保护的更新私钥生成。
5. `latest.json` 指向 v1.0.1 官方 Release 资产且使用 NSIS 更新签名。
6. GitHub Actions 质量门禁通过后才能发布正式 Release。

## 已知边界与后续计划

v1.0.1 解决结构性 P0 问题，但不代表历史 UI 样式已全部迁移。当前仍存在大量微字号、直接颜色值和格式编辑器内部的专属控件。后续按 [v1.0.1 UI 一致性审计](UI_Consistency_Audit_v1.0.1_2026-08-02.md) 的 UI-1 至 UI-4 推进共享组件、颜色语义、管理页壳层和视觉回归门禁。
