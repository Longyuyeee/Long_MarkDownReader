# Workbook 结构写入接续审计

日期：2026-10-11。目标 1.1.0，未封板。延续数据验证保存边界，不改界面布局。

## 最新：行列结构写入与回读保护

`commitStructure` 已接入保存锁、窗口在途登记和原文档/路径/资料库/epoch 归属校验。旧回执不替换新文档或清空其历史；失败带原文件路径，所有返回路径释放锁。未切表时保留插入/删除后的行列定位；切表后刷新当前表，不拉回原表。`restoreAxisSelection` 在读取 Sheet、读取目标页、等待渲染之后分别复核代次和文档，防止继续恢复过期选区、滚动或计算。

验证：17 项边界测试与类型检查通过，新增正常/切表/替换文档/epoch 变化/失败的写入回执场景。后台实际页面验证行列确认取消、插入行失败重试、写入期间公式栏禁用、切 Sheet2 后不跳回、回 Sheet1 看到插入空白行、删除该空白行后原内容恢复。已查看 [插入后返回原表](evidence/v110-workbook-structure-confirm-browser/row-insert-return.png)。

证据限制：结构写入用受控 IPC 模拟，只模拟普通行数组插入/删除，不证明真实 XLSX 中公式/Table/图表引用迁移正确；列写入及原生迁移未在本页面测试中执行。回读各阶段中途切换的全面专项仍待补齐，不把代次检查视为全链路验收。未接管桌面，未修改布局。

下一步行列隐藏/分组写入，再处理筛选、命名区域、绘图等剩余入口和原生回归。整体仍未封板。

## 最新：行列删除确认边界

实际代码在打开删除确认后直接用当前工作表提交原行列范围，未复核编辑目标。本步 `applyStructureAction` 在保存期间禁止进入，并捕获上下文供删除确认复核；失效则要求重新确认。`commitStructure` 提交前再次检查保存/结构忙碌、受保护状态与未保存草稿，避免确认期间状态改变后继续写入。

验证：16 项边界测试通过，新增行/列有效与过期确认及提交时忙碌/保护/草稿复核；类型检查通过。`test-workbook-structure-confirm-browser.mjs` 通过实际第一行/A 列标题进入删除确认并取消，原内容保持，已查看 [行确认](evidence/v110-workbook-structure-confirm-browser/row-delete-confirm.png) 与 [列确认](evidence/v110-workbook-structure-confirm-browser/column-delete-confirm.png)。测试最初误选左上角全选格，结构入口正确禁用；改为按可见行号/列名定位后通过，未修改产品来迁就测试。

本步浏览器没有执行结构写入/真实删除；过期确认是函数级模拟，不代表穿过遮罩操作。尚未解决 `commitStructure` 的写入回执归属、编辑锁、窗口在途登记和 `restoreAxisSelection` 回读协调；下一步继续这些事项，再处理行列隐藏/分组。原生迁移与恢复验收、版本整体闭环仍待完成，未封板。

## 最新：清空确认保护与限宽诊断

清除打印区域、全部清空页眉页脚原先在确认回调直接使用当前草稿。本步捕获编辑上下文和相关草稿快照，确认时若目标变化、草稿已修改或当前不可编辑，则提示重新确认，不清空、不提交。正常取消保留内容，正常确认维持原流程。

验证：14 项边界测试通过，新增两个入口分别覆盖正常确认、目标过期、草稿变化和忙碌四种情形；类型检查通过。后台实际页面验证两个清空入口的取消/确认，页眉清空后重开为空，打印区域清除后按钮禁用；三个设置弹窗原有失败重试/重开回归也通过。已查看 [清空确认截图](evidence/v110-workbook-page-settings-browser/clear-header-confirmation.png)，文案、按钮与底层草稿可见。目标变化场景是函数测试，不冒充用户穿过遮罩切表。模拟 IPC 不证明原生文件写入。

限宽诊断：实际浏览器检查三个弹窗的编译 CSS，均为 `[data-v-336190fd] .…-modal` 这类要求作用域祖先的选择器，`element.matches` 均为 false。弹窗通过 Teleport 离开该祖先，使 `:deep` 限宽规则无法匹配；截图保留几乎全宽现象。本步未修改布局。下一步若调整限宽，应先展示示意并获确认，保留全部现有输入和按钮；同时仍可推进其他非布局的写入边界工作。

剩余结构入口、完整原生验证及版本功能闭环仍待完成，未封板。

## 最新：页面设置、打印选项、页眉页脚

三个入口统一使用 `writePageSetting`：提交参数深复制快照、保存锁、窗口在途登记、文档对象/路径/资料库/epoch 归属检查、当前表与选区刷新、原文件错误提示。失败保留弹窗及输入，成功仅在原上下文仍有效时关闭弹窗。保存期间弹窗输入区域 inert，禁止继续修改即将被回读覆盖的草稿；取消仍可关闭弹窗但不撤销已经提交的写入。未变更布局与后端格式合同。

验证：边界测试 13 项通过（新增快照不受后续修改影响、成功/文档替换/失败与锁释放），类型检查通过。`test-workbook-page-settings-browser.mjs` 使用实际 WorkbookView，分别设置横向、打印网格线、页眉“客户交付清单”，各自失败后内容保留、重试成功、重新打开仍显示保存值；模拟 IPC 不等于原生持久化。

已查看截图：[页面设置](evidence/v110-workbook-page-settings-browser/page-layout-retry.png)、[打印选项](evidence/v110-workbook-page-settings-browser/print-options-retry.png)、[页眉页脚](evidence/v110-workbook-page-settings-browser/header-footer-retry.png)。按钮、错误提示、保留输入可见；同时发现弹窗几乎全宽，未呈现样式中预期的限宽。需进一步核对 Teleport/scoped 样式及真实运行环境，不能宣称 UI 全面通过。正式布局调整仍遵守先示意后审批要求。本步未接管桌面。
