## 基线与项目审计结论

- 工作目录：`C:/Users/39633/.codex/worktrees/mobile-0-1-0-foundation/MDReader`。
- 分支：`codex/mobile-0.1.0-foundation`；基线为 `v1.2.11` / `6a965dc776c69eecf3904b1fe3d056b19f70d84a`。
- 实现提交：`5065eb5e`、`9eaca526`、`bb407f0a`。本轮没有修改桌面原目录文件。
- Vue、TypeScript 和 CodeMirror 可以用于移动页面。桌面布局、窗口、托盘、进程、更新器和路径型文件命令需要平台边界，无法靠缩小窗口完成迁移。
- 现有 Rust 文档能力继续保留在仓库，当前先对桌面初始化和依赖进行条件编译隔离。移动首批只接入文本；PDF、表格、Office 等公共业务还需逐项抽离和验证。
- Android 外部目录通过 SAF 的持久授权 URI 访问；不能假设 URI 是桌面路径。资料身份使用资料库 ID 和相对文件名，原生接口只接受已登记目录。
- 桌面凭据、Git 和外部转换程序不能直接算作 Android 已支持。后续凭据需专门接入平台安全存储，苹果平台仍需 macOS 构建及独立文件适配器。

## 代码与原生边界

| 位置 | 本轮职责 |
| --- | --- |
| `mobile.html`、`src/mobile` | 独立入口、手机页面、CodeMirror、资料接口与会话协调 |
| `tsconfig.mobile.json`、Vite mobile mode | 移动类型检查、依赖缓存和构建入口；不加载桌面主页面 |
| `src-tauri/src/lib.rs`、Cargo target dependencies | 区分桌面和移动初始化，保留桌面命令与插件 |
| `src-tauri/plugins/mobile-storage` | Android 应用内库、SAF、恢复草稿及真实读写 |
| `src-tauri/gen/android` | 已纳入版本控制的原生源码、Manifest、Gradle 配置和 wrapper |
| `scripts/build-mobile-debug.ps1` | 构建 debug APK，并记录 ABI、摘要、源提交与签名类型 |
| `scripts/mobile-emulator-ui.ps1` | 使用指定测试设备和新鲜无障碍快照操作模拟器 |

原生 IO 串行执行；应用内文件及草稿使用 AtomicFile。外部保存先核对 SHA-256，保留原文和候选内容的私有恢复材料，再写入并回读确认。SAF 提供器没有通用的原子替换或 compare-and-swap 保证；本轮未把外部写入描述为原子操作。失败写入记录的浏览、导出界面仍待接入。

首批文本要求 UTF-8，大小上限 4 MiB。目录先显示最多 1,000 项并提示部分结果。浏览器预览使用独立本地数据并明确显示预览提示；Android 存储失败不会回退为浏览器假数据。
