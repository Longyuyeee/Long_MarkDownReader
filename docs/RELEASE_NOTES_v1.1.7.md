# v1.1.7 · 保存与历史更顺手

本版说明为未发布草案。2026-10-17 用户已要求恢复开发，正在完成最后历史并发保护及固定安装器验证；当前正式版仍为 1.1.6。完成项与待办见 [开发记录](V1_1_7_Save_History_Development_2026-10-16.md)，原 [暂停交接](V1_1_7_Development_Pause_Handoff_2026-10-16.md) 保留为历史快照。以下列出已实现的候选功能，不代表已发布。

- Markdown、TXT 保存遇到外部修改时，可以直接比较差异、继续编辑、另存当前副本，或保留草稿后使用磁盘版本。操作期间新增的输入不会被迟到结果覆盖。
- 普通 Markdown 保存会保留修改前后的版本，不必等待定时历史。历史写入失败时明确区分文件是否已经保存，继续保护尚未保存的新输入。
- 历史支持查找正文和备注、按日期查看版本；比较时可跳转上一处或下一处差异，继续支持局部恢复与撤销。
- 历史条目右键可保留重要版本、添加备注。普通历史数量清理保留重要版本；移动、改名后备注与保留状态一起接续。
- 修复改回旧内容时遗漏一次历史记录的问题。历史无法读取时，在原位置提供重试。

操作仍集中在现有历史入口、右键和按需弹窗。正常编辑、保存不增加步骤，现有风格和动效保留。

未签名社区版（community-unsigned），Windows 可能提示未知发布者。仅从官方 GitHub Release 手动下载安装并核对 SHA-256。自动更新仍通过现有 GitHub Release 校验机制提供；正式版到本版的应用内更新观察单独记录，不以覆盖安装代替。
