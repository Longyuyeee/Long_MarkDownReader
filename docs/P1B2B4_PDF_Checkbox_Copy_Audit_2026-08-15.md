# P1-B2B4 PDF 复选框可靠副本审计

日期：2026-08-15
状态：已完成；下一入口为 P1-B2B5 单选组可靠副本

## 1. 需求与结论

本阶段继续对齐“在原管理器右侧工作区阅读、基础编辑并成体系管理常用格式”的初始需求，没有新建页面或脱离左侧资料库/右侧编辑区的产品结构。PDF 表单能力从中文单行文本扩展到标准复选框；它仍是可靠新副本，不是源文件覆盖，也不被描述为任意 PDF 正文编辑。

可编辑范围严格限定为：字段可填写、无动作、按钮类型明确为 checkbox、实际导出值恰好一个，且关联的每个 Widget 都具有 `Off` 与该导出值对应的非空 `/AP /N` 外观。单选组、按钮、选择字段、重复/歧义结构、XFA、JavaScript、签名、加密和缺失外观继续阻断。

## 2. 已交付能力

- 只读检查报告新增按钮种类、导出值、Widget 正常外观状态集合及当前 `/AS`。
- 原 PDF 表单侧栏根据真实导出值展示复选框，不假定导出值一定为 `Yes`。
- 隔离预览与可靠另存使用通用表单命令，同时保留既有文本命令兼容边界。
- 勾选时规范字段 `/V` 与所有 Widget `/AS` 写入真实导出 Name；取消时统一写入 `Off`。
- 保存后复读字段有效值与每个 Widget 外观状态；不一致即阻断或清理失败目标。
- 纯复选框副本不嵌入文本字体，避免无关资源膨胀。
