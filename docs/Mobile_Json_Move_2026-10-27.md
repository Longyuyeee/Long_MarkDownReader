## 页面与返回契约

[五屏设计](design/mobile-json-move-v1/index.html)覆盖前移容器、后移容器、标量、无需改变与核对失败。[冻结回执](evidence/mobile-json-move-2026-10-27/design-freeze.json)为 `2026-10-27T04:59:21.167Z`，早于运行时代码修改；设计源 SHA-256 为 `418fd7cdbb13da5a69e9441ed0a8c1b11bbf9fa6cef3b186a085fd6e6350eb0e`。

- 操作菜单仅选择动作，原来留在详情页里的最后一组移动表单与范围核对已移出。选择前移或后移进入独立页面，隐藏底层浏览与编辑控件。
- 原路径采用 JSON 的 `[0]` 起始位置；摘要用“第 2 项 → 第 1 项”表达用户顺序。两张卡片按移动后的顺序排列，包含目标位置、类型与原内容，移动项另有文字标识及边框。含义说明收进 `?`。
- 打开后自动检查完整候选，仍需显式“应用到草稿”。检查中可停止；停止、失败与超时不能应用，可重新核对。相邻两项原文完全相同则提示无需改变并禁用应用；`1` 与 `1.0` 等不同原写法仍可交换。
- 返回和“取消移动”回原操作菜单，并聚焦最初选择的前移或后移动作。再返回父层或查找结果，恢复筛选、分页、滚动与原项焦点。帮助关闭回帮助按钮；每次返回只消费一层。
- 返回、取消和暂停终止未完成工作；切换方向、目标、原文或文稿身份不复用过期候选。根值、对象字段和只读内容没有移动动作；数组首项不能前移，末项不能后移，唯一项两方向均禁用。
- 应用回原源码编辑器并恢复焦点，一次应用对应一次撤销事务。草稿保护失败仍保留已移动的源码和撤销能力，已保存文件及其他草稿不变；只有显式保存才写入文件。
- 长预览明确提示仅展示部分，实际移动完整项。正文独立滚动，操作栏可达。无新增常驻解释段落。

范围补丁引擎、工作线程、MobileApp 的返回分发与草稿/保存实现没有修改。现有引擎重新从准确原文定位相邻项，交换完整内容范围，保留分隔符及其他源文，再验证完整候选；不解析为 JS 对象后重新序列化整份 JSON。混合换行、BOM、转义、重复键、大数和内部嵌套原写法保持。
