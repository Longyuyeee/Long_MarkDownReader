# P2-B 图片色彩调整真实桌面审计

审计日期：2026-08-20

结论：通过。图片基础编辑新增亮度、对比度和饱和度调整，继续保持资料库内可靠另存副本与源文件不覆盖。

## 1. 目标与实现

- 右侧现有图片编辑侧栏新增三条范围明确的滑杆和“恢复原色”，没有新增独立页面。
- 亮度与对比度限制为 `-100..100`，饱和度限制为 `0..200`；后端拒绝越界参数。
- 画面提供即时 CSS 预览，另存时由 Rust 对解码后的真实像素执行确定性处理。
- 输出继续执行源摘要冲突检查、目标不覆盖、结构复读、隐私元数据移除和源文件复核。

## 2. 预期与实际

| 验收项 | 预期 | 实际 |
| --- | --- | --- |
| 调整参数 | 亮度 `+20`、对比度 `+15`、饱和度 `0` | 保存报告完全一致 |
| 像素效果 | 饱和度为 0 后采样 RGB 相等 | 独立采样为 `134/134/134/255` |
| 文件安全 | 源 SHA-256 不变，目标摘要不同且可复开 | 全部满足，目标为 `960 x 540` PNG |
| 宽屏布局 | 1280×800 无页面横向溢出 | 溢出 `0`，侧栏宽 `286 px` |
| 窄屏布局 | 720×680 无横向溢出，编辑区堆叠可用 | 溢出 `0`，侧栏宽 `509 px`，三项滑杆可见 |
| 运行时 | 无 Promise、Console 或 WebView 错误 | `runtimeErrorCount = 0` |

## 3. 真实测试

- Rust 真实 PNG 解码、像素处理、编码与复开：6 个图片测试通过，0 失败。
- Vue TypeScript 与 Vite 生产构建通过，6234 个模块完成转换。
- 真实 Tauri WebView2/CDP 完成打开、调整、宽窄屏截图、IPC 另存和目标复开。
- 独立 `System.Drawing` 验证源/目标摘要、目标尺寸与目标像素，不依赖应用返回值判断图像效果。
- 脱敏证据位于 `docs/evidence/p2b-image-color-adjustments/`，不包含用户内容。

## 4. 能力边界

当前不是专业图像制作软件：不提供图层、蒙版、局部画笔、ICC 色彩管理或无损 RAW 工作流。GIF、ICO、AVIF 与外部图片仍只读；可编辑格式仍只有 PNG、JPEG、WebP 与 BMP。
