# Long编辑 v1.0.0

v1.0.0 是 Long编辑首个面向日常使用的社区正式版。产品目标是把常用文档、开发文本、图表和知识关系放进同一个管理器，在文件库右侧完成阅读、基础编辑、关联与检索。

## 核心能力

- 统一资料库：工作区、文件树、最近记录、标签、收藏、全文检索、保存搜索、管理备份和知识索引恢复。
- 文本与开发格式：Markdown、TXT、JSON、YAML、XML、TOML、日志等在右侧工作区读取和基础编辑；TXT/JSON 已完成安装后保存、重开验证。
- PDF：阅读、缩略图和页面导航、文本提取、OCR、批注，以及提取、合并、插入等页面级副本工作流。
- 表格：CSV/TSV 与开放表格基础编辑；XLSX 提供受约束的单元格、样式、公式、图表和部分 Pivot 副本工作流。高风险结构会降级为只读、可靠副本或外部应用打开。
- 文档与演示：DOCX/PPTX 支持读取、预览和经过验证的受限副本编辑；旧 DOC/XLS/PPT 采用源文件不变的隔离转换流程。
- 图表与思维导图：Mermaid、Draw.io、OPML、Canvas 等格式进入独立结构化工作面，并继续嵌入文件库右侧区域。
- 知识图谱：跨 Markdown、文本、PDF、Office、图表与思维导图建立对象和关系；首页知识网络脉搏、主题居中、孤立对象行动队列和结果回执让图谱成为管理入口，而不只是可视化页面。
- 软件更新：每天最多自动检查一次，也可在设置中手动检查；更新包必须通过内置 Tauri 公钥完整性校验。

格式注册表共 41 类、74 个扩展名：29 类已验证，6 类已验证但有明确限制，6 类依赖外部应用。软件会在界面中显示每种格式的真实能力边界，不把“能识别/能打开”表述成“可完整无损编辑”。

## 安装与安全说明

本版本没有 Windows Authenticode 代码签名。安装时 Windows 可能显示“未知发布者”或 SmartScreen 提示，这是本社区发布渠道的已知状态。请只从本项目 GitHub Releases 下载，并核对发布页附带的 `SHA256SUMS.txt`。

Tauri 更新签名用于验证更新包完整性，不等同于 Windows 发布者身份签名。更新私钥未进入仓库或发布资产。
