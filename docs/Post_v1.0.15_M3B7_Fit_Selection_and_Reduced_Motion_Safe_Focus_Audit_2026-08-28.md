## 1. 开发目标与完成结论

本阶段按 M3B-6 冻结范围完成一个最小完整镜头增量：适应当前可见选中节点、可中止且有固定上限的节点聚焦、应用或系统 reduced 下立即到达同一几何结果，以及 720px 工具栏末端命令完整可达。没有引入缩略导航、聚类折叠、图谱全屏、状态环或 M3C 性能声明。

M3B-7 已通过真实 Tauri calm/reduced 验收。当前接续点前移到 **M3B-8 剩余导航系统选择审计**，先根据真实代码和已完成能力选择缩略导航、聚类镜头或全屏中的下一个最小增量。

## 2. 实现与需求对齐

| 需求 | 实现 | 验收结论 |
| --- | --- | --- |
| 适应选择 | 新命令只读取 `visibleNodes ∩ selectedNodeIds`，复用全图适配的节点边界、缩放限制和面板安全区域 | 两会话分别真实框选 3、4 个节点，最终姿态与独立边界 oracle 一致 |
| 有界聚焦 | 所有 `selectAndCenter` 入口经 `nextTick` 等待详情面板后进入统一相机任务；calm 为 180～280ms 三次缓入缓出 | calm 实测 344ms（含事件/轮询）、43 帧，完成后像素稳定 |
| 目标替换 | 新聚焦覆盖旧任务并增加取消计数；过渡期间每帧读取目标节点最新坐标 | 连续 `North → Brief` 实测取消旧任务 1 次，最终完成新目标 |
| 减少动效 | 应用 `motionSpeed=reduced` 或系统 `prefers-reduced-motion` 时直接应用同一目标姿态 | reduced 实测约 38ms、0 过渡帧，完成后像素稳定 |
| 搜索稳定性 | 查询变化只更新可见集合，不再无条件重启力布局；结构过滤变化仍重启布局 | 修正 M3B-6 中聚焦 260ms 后继续变化的真实缺口 |
| 详情安全区 | 单节点聚焦根据详情面板与 Canvas 的真实重叠选择最大可用区域 | 详情面板存在时选中节点目标落在剩余视口中心 |
| 窄屏命令 | 新增末端留白并为两个命令提供稳定测试身份 | 1280/1000/720 三档下两个末端命令均完整可达 |
| 源安全 | 相机、选择与筛选均为会话派生状态 | 两会话资料库 SHA-256 前后一致 |

相机几何独立在 `src/utils/graphCamera.ts`：边界适配、点聚焦、缓动和姿态插值均由纯函数提供，机器合同使用固定输入验证，不以 Canvas 看起来合理代替正确性。

## 3. 真实测试中的预期、实际与修正

| 测试阶段 | 预期 | 首次实际 | 修正与最终结果 |
| --- | --- | --- | --- |
| 键盘清选 | 自动化模拟真实 Canvas Escape | 测试错误地把事件直接派发到 `window`，产生 1 条 `Uncaught` | 改为向 Canvas 派发并冒泡；calm/reduced 最终均为 0 运行时错误 |
| reduced 截图稳定 | 即时应用后画面稳定 | 首次在状态改变后、下一次 Canvas 绘制前取像，误报不稳定 | 状态完成后等待一个有界绘制窗口再比较；最终前后像素一致 |
| calm 聚焦 | 有过渡、固定时间结束 | 344ms、43 帧，结束后 300ms 像素不再变化 | 与 280ms 产品时长及 50ms 轮询边界一致，通过 |
| reduced 聚焦 | 不产生过渡帧 | 约 38ms、0 帧，最终几何与点聚焦 oracle 一致 | 通过 |
| 适应选择 | 真实多选且只适配选择 | calm 框选 3/17 节点并推进 47 帧，reduced 框选 4/17 节点且为 0 帧；最终姿态与边界 oracle 一致 | 通过 |
| 720px 可达性 | 新旧末端命令完整在控制区内 | 工具栏可滚动，两按钮矩形均完整进入控制区 | 关闭 M3B-6 的约 12px 裁切缺口 |

证据位于 `docs/evidence/post-v115-m3b7-fit-selection-reduced-motion-focus/`，包括 calm/reduced JSON、三档工具栏截图、节点聚焦截图和适应选择截图。结构化 JSON 保存几何、帧数、持续时间、取消次数、像素稳定性、错误消息、源摘要和返回状态，不保存临时资料库绝对路径。
