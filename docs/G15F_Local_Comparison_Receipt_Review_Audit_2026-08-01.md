# G15F 匿名改善回执本地审阅审计（2026-08-01）

## 结论

G15E 已把真实资料库的基线—治理—复查顺序做成设置页四步引导，但复查回执保存后只能离开软件手工阅读 JSON。G15F 增加“审阅回执”：用户主动选择本地改善对比 JSON，软件严格校验后在原设置页展示覆盖率、关系数量、已连接对象、孤立对象、结论和受限成就，不创建新窗口。

当前状态为 `hosted-installed-local-receipt-review-passed-real-user-review-next`，`releaseCandidate=false`。本阶段已完成本地解析、界面、前端生产构建、Rust 定向回归和安装态验收；不代表已经审阅任何真实用户回执。

## 严格输入与隐私边界

- 只接受用户主动选择的 `.json`，大小不得超过 1 MiB。
- 顶层、基线、当前值和变化对象都必须具有精确字段集合；任何未知字段都会拒绝，避免文件暗含路径、正文或自定义敏感字段却仍被标记为安全。
- 必须匹配 G15B schema、证据级别和四项 false 隐私标志；结论和成就只能取受限枚举。
- 基线与当前的连接计数、覆盖率、时间差和六项聚合变化必须自洽；篡改或不一致回执会被拒绝。
- 选择路径只作为单次命令参数，不写入会话状态、配置、历史或界面，也不会上传。
- Vue 只渲染经过 Rust 校验的数值和受限枚举，用户重新加载页面后必须再次选择文件。
