## M7-0 范围选择回执

真实代码盘点重新比较结构化 Schema、图谱代理折叠、治理环和 ODP 备注。唯一选择 **M7-1 本地 JSON Schema sidecar provider/mapping 可行性审计**：JSON/JSONC 已有有界解析、稳定路径与行列、诊断和安全保存基础，最接近最初“可选 Schema、错误路径定位、未配置零误报”的要求。

M7-1 不直接开放完整 Schema Studio，只冻结本地同目录确定性映射、大小/引用预算、来源说明、实例路径定位和安全失败。联网、远程 `$ref`、YAML/TOML 投影、XSD、源码写入和版本提升全部关闭。完成真实样本与桌面基线后，再决定是否进入 M7-2 有界产品实现。

## 延后边界

- YAML/TOML 到 JSON Schema 的投影需要独立处理标签、多文档、数字和日期等语义。
- XML 使用 XSD，import/include、namespace 与外部资源必须单独建模。
- 社区代理折叠仍缺代理身份、聚合边、路径/证据、历史、缩略图、导出和相机恢复合同。
- 治理环仍缺逐节点事实、来源与解释。
- ODP 备注仍受 LibreOffice/PowerPoint 生产者保真不对称阻塞。
