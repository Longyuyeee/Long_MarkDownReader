# P1-B4C PDF 文字水印原右侧工作区审计

审计日期：2026-08-16
阶段状态：工作区完成，真实桌面证据待 P1-B4D

## 1. 需求对齐与结论

本阶段严格对齐用户要求的初版界面：正常左侧 Tab/侧栏与右侧 PDF 编辑区。文字水印作为原 `PdfView` 的工具栏动作和侧栏 Tab，不新增路由、独立窗口或全屏编辑页面；外部 PDF 继续只读且不显示水印入口。组件使用现有工作区颜色、边框、圆角、字号变量和 `WorkspaceStateNotice`，没有建立另一套 UI 风格。

## 2. 工作区交互

- 输入 1～64 字符文字，调整 -60～60 度、8%～50% 透明度和 0～85% 灰度。
- 面板提供轻量样式预览；最终字号由 Rust 后端按每页旋转后包围盒在 18～72 pt 内决定。
- “生成并验证水印副本”先计算当前 PDF SHA-256，再调用隔离后端；修改任何参数都会清除旧输出摘要和确认状态。
- 只有后端返回 `isolated_verified` 才显示页数、输出大小、自动字号、新副本文件名、风险确认和保存动作。
- 保存绑定预览的源/输出摘要，只创建新 `.pdf`，完整落盘复读后通过 `openManagedFile(..., 'replace')` 在同一管理工作流打开目标。

## 3. 风险提示与草稿保护

面板首屏明确说明：水印是可见归属，不是永久脱敏、DRM 或防复制；文字可搜索、提取、编辑或移除。保存前必须再次勾选确认。水印文字非空即视为编辑草稿，标题显示“水印草稿”，路由离开、文件切换和窗口关闭均进入现有 PDF 草稿保护；保存成功后才清空。

## 4. UI 一致性与响应式边界

面板宽度与永久脱敏侧栏同为 300 px，内部字号统一使用 `--text-compact`，输入、按钮、提示与原工作区 token 对齐。工具栏继续使用已有横向滚动命令条，新增动作不会把右侧编辑区变成新窗口。宽窄屏真实证据留给 P1-B4D，本阶段以 Vue 类型检查、生产构建、静态结构门禁和 UI 一致性门禁作为实现验收。

## 5. 能力边界与下一步

当前公开能力只覆盖资料库内全部页面、单条居中斜向文字；平铺、图片、页眉页脚、水印模板、局部页选择及外部 PDF 写入均未开放。P1-B4D 将验证真实 Tauri 宽窄屏、草稿离开保护、中文参数、预验证、风险确认、可靠另存、目标复开，以及 pypdf/Poppler 对源不变、结构保真、每页文字和无裁切的独立检查。通过前不能宣称 P1-B4 完全收口。
