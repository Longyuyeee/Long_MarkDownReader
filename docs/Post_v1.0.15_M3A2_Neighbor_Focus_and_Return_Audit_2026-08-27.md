# v1.0.15 后续 M3A-2 邻居聚焦与返回审计（2026-08-27）

## 结论

M3A-2 已完成并在后续需求复核中补齐。选中节点详情新增“聚焦直接邻居”，以选中节点为中心提供 1/2/3 跳可逆诱导子图；页面持续显示焦点、跳数、当前节点/关系数量和“返回全图”。聚焦状态只存在于当前前端会话，不写入文件或持久筛选。

真实 Tauri 跨格式资料库从 17 节点/17 边按 1/2/3 跳依次聚焦，结果分别为 3 节点/3 边、6 节点/7 边、8 节点/9 边；图例同步当前子图，点击返回后恢复 17 节点/17 边。运行时错误为 0，可继续返回资料库，临时资料库 SHA-256 前后相同。

## 需求对齐与边界

- 复用 M3A-1 的统一对象/关系语义，没有另建类型或颜色映射。
- 聚焦只改变可见集合，不改变事实源、关系数据、筛选持久值或保存行为。
- 本步骤实现一至三跳邻居发现和返回，不把它扩张为最短路径、社区发现或性能优化。
- 公开/运行时版本仍为 `1.0.15`，开发目标仍为 `1.0.16`，`releaseCandidate=false`。
