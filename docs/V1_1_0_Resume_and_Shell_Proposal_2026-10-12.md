# v1.1.0 恢复开发与主编辑区方案

用户于 2026-10-12 要求“你思考一下开发情况 接续一下之前的开发吧”，此前暂停已结束。当前运行和公开版本仍为 **1.0.26**，开发目标为 **1.1.0**。本记录不表示封板或发布。

## 当前优先级

F1 直接选目录保存、F2 工作现场恢复、F3 智能集合、F4 历史差异与副本恢复已有实现和验证。下一步把这些功能放进容易理解的日常工作流程，首先整理主编辑区；不再扩展已取消的强制归档流程，不增加格式数量作为本版主要卖点。

先修复新增功能与旧 CI 检查之间的冲突，再完成 UI-SHELL-01 的具体示意与功能位置对应表。用户随后明确回复 **“可以，按这个方向实施”**，本页方向已获批准并完成主编辑区第一批正式实施；不代表其余页面已批准。

## 本次已完成的代码修正

- 配置检查允许 debug 测试在**明确指定的隔离配置目录**保存，仍检查两个测试环境变量、debug 编译边界，以及未指定隔离目录时禁止写配置。生产路径没有修改。
- 工作现场检查允许重启后恢复阅读位置，继续限定最多 24 条视图状态；调用现有行为测试验证草稿正文、选区正文和参考摘录不会被当成恢复元数据保存。
- Markdown 模式检查对齐配置事务的 `next` 快照，继续验证默认所见即所得、旧偏好迁移与用户显式选定模式。
- 参考文档测试接入真实的参考持久化服务，补切回资料库恢复原参考的断言。搜索卸载测试补齐历史比较的独立清理依赖，继续实际执行生产搜索调度与 Vue 卸载。

这些检查修改修复陈旧假设和测试环境遗漏，没有为了通过检查删除用户行为断言。后续正式布局修改只在用户确认 UI-SHELL-01 后进行。

## 用户确认后的正式实施

- 主编辑区增加资料库操作行：导航可收起，资料库设置、快速笔记和命令入口直接可见。命令按钮复用应用的命令面板，增加事件入口但没有修改其他页面布局。
- 七个导航入口改为原生按钮，保留文字及原有功能，紧凑宽度分行排列；搜索移到导航上方，任意导航页都能开始搜索。
- 标签栏保留原有全部标签操作；“保存”和“参考”单独显示。编码、导出、外部应用、脑图、编辑模式、正文宽度及历史等归入有名称的“文档操作”菜单。
- Vditor 常用格式留在正文上方，其他格式、图表、代码风格、背景色、AI、预览等使用编辑器原生“更多格式”菜单；没有替换编辑器或移除功能。
- 文档状态移到底部，保留编码、范围只读、继续读取、字数/阅读量/光标信息。专注模式保留“退出专注”，修复正文层覆盖退出按钮的问题。
- 参考可临时收起且保留来源；没有参考时给出查找资料入口。窄窗口自动收起导航，可展开操作；参考在正文下方继续阅读。
- 实际操作复现编辑模式切换在配置事务提交前初始化、读到旧偏好的问题：现在先完成配置保存，再重建编辑器；失败保留原编辑器，等待期间继续输入的内容也保留，离开原文档后不销毁新的编辑器。
- 所有新增布局样式限定在 LibraryMode。沿用主题与动效变量、原有智能降级和减少动效支持，没有统一关闭动画。

### 现有功能 → 建议位置 → 实施后需复核的用户动作

范围为 `LibraryMode.vue` 的资料库主编辑区和工作区外壳；各格式内部编辑器、工作台、图谱与设置等页面保留现有实现。公共组件或样式如影响其他页面，另出示意并确认。

| 现有功能 | 建议位置 | 用户动作 |
| --- | --- | --- |
| 资料库切换、新建、管理及异常恢复 | 顶部资料库菜单；原非阻断恢复提示 | 目录失效时仍能操作，重试、换库或创建目录 |
| 文件与正文搜索、格式筛选 | 左侧搜索及现有结果筛选 | 中文查询、改格式、清空和失败重试 |
| 搜索分组、摘要、高亮、对象/页码定位、返回原查询 | 搜索结果区，主编辑区匹配导航 | 从结果打开资料，再返回查询与位置 |
| 显式侧边参考 | 文档右上“参考”及结果里的参考动作 | 普通结果打开主区；参考不被其他查询替换 |
| 参考刷新、重关联、主区打开、复制/插入摘录、来源回跳 | 参考栏内有名称的操作 | 边看边写，失效后重关联，插入后可撤销 |
| 文件树展开、拖动、重命名、删除、移动、显示样式 | 文件入口与原上下文菜单 | 整理文件，不丢原有操作 |
| 新文件、多格式新建、新文件夹、模板、每日笔记、刷新 | 文件区“新建”菜单 | 创建文件或目录，打开今天的笔记 |
| 当前文档大纲 | 左侧“大纲” | 点击标题回到正文位置 |
| 收藏与最近访问 | 左侧“最近” | 继续最近文件、打开收藏 |
| 智能集合/原常用搜索、条件编辑与实时结果 | 左侧“智能集合” | 选择项目近期资料并调整筛选条件 |
| Markdown 标签 | 左侧“标签” | 按正文标签找 Markdown |
| 链出与反向链接 | 左侧“关系” | 从引用关系打开相关文档 |
| 本地历史、差异比较、恢复副本及保护后替换草稿 | 左侧“历史”及文档操作菜单 | 先比较再恢复，副本不覆盖原文 |
| 索引状态、准备进度、取消和重建 | 导航底部状态及选项 | 搜索准备中仍可编辑，并可取消 |
| 收集箱、工作台、图谱、设置和更新 | 导航底部；原页面功能保留 | 返回主区时恢复工作现场 |
| 工作区标签、dirty、关闭及标签上下文菜单 | 正文上方标签栏 | 切换文档，未保存关闭时获得提示 |
| 保存与保存失败重试 | 明确的“保存”及底部状态；Ctrl+S 保留 | 保存慢或失败时草稿仍在，继续输入不被清除 |
| Markdown 撤销/重做、全部格式与插入工具 | 常用格式行和“更多格式” | 所有现有 Vditor 工具仍可找到 |
| 所见、IR、源码三种模式 | 文档操作内“编辑模式” | 用户选定后记忆，切换不制造重复回写 |
| 600/800/宽屏正文宽度 | 文档操作内“正文宽度” | 根据窗口和阅读偏好调宽度 |
| 编码/BOM/换行、外部应用、重读、导出、脑图 | 文档操作内同名入口 | 保留格式边界，操作前保护未保存内容 |
| 格式能力、范围只读、继续读取、阅读量与光标位置 | 状态栏及对应文件内工具 | 大文件继续读取，不把只读当成可保存 |
| 专注/F11、快捷键与命令入口 | 顶部命令、状态栏专注及原快捷键 | 专注后能明确退出，键盘操作保留 |
| 导航收起、宽度拖动和跨会话视图恢复 | 顶部“导航”、原拖动边界及恢复服务 | 小窗口留出正文，重开恢复合理位置 |

示意只演示主要布局和局部状态，不模拟磁盘写入、原生 PDF 阅读和全量菜单弹窗。正式实施须复用已有动作和编辑器，不能把示意交互直接替代生产功能。

## F5 网页收集评估与建议

代码已有 `reqwest`、`scraper` 和 `get_url_title`，当前命令只提取标题，**尚没有网页正文转 Markdown 的产品能力**。已有本地 HTML 预览与 Markdown 导出也不等于网页收集。

对用户有价值的最小范围仍是“粘贴公开文章链接 → 查看标题和正文预览 → 选择资料库/目录 → 保存 Markdown”，保留原网址与采集时间，失败保留输入。不做浏览器扩展、登录抓取或整站下载。

需要补实际正文提取、标题/编码处理、相对图片与链接转换、超时/非文章页面反馈，并复用直接选目录保存流程。若默认下载所有图片或追求任意网页完整还原，会明显扩大本版范围。

**建议先收口 F1–F4 和主编辑区，再单独确认 F5 的最小界面与是否纳入 1.1.0。** 这是范围建议，尚未代用户作出延期或纳入决定，F5 保留为待确认候选。
