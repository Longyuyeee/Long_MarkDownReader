# Long编辑 v1.1.9 · 工作现场可迁移，接续更可靠

候选发布说明，安装与同包验收未完成前不代表已经发布。

## 从已有入口接着工作

- 工作台“管理现场”可导入、导出工作现场；保留命名、重命名、删除、最近/待办/收藏功能。
- 迁移文件只记录资料库内相对路径、顺序、固定标签和阅读位置，不包含正文或草稿；换电脑请另外复制原文件。可选择导入的目标资料库，不自动切走当前项目。
- 导入先核对可用和缺失文件，可重新定位，或先保存记录、恢复可用部分；缺失项保留，不静默删除。
- 相同来源不重复添加，已有导出文件不覆盖；格式、路径和配置库边界不合法时明确拒绝。

## 接续不替用户作主

- 当前未保存内容及其活动文档保留，不自动代存；保存中等待完成，过期预检和过期记录需重新确认。
- 失败保留输入和原记录；阅读、搜索、参考及标签元数据尽可能事务回滚。
- 超过 24 份文件的阅读位置惰性恢复，不扩大正文缓存；旧版超过 128 份文件的本地现场仍可分批接续。新迁移文件最多 128 文件、256 KiB。
- 导出默认不携带可选搜索/参考，用户明确选择后才包含；排除正文、草稿、搜索摘要、密钥和旧根绝对路径。文件名和选择携带的搜索词仍可能私人，请谨慎分享。

## 兼容与发布边界

Windows 10/11 x64 未签名社区版，可能提示“未知发布者”；从正式 GitHub Release 下载并核对 SHA-256。保留现有六风格、正常动效和全部原功能，不宣称完整 Office 等价。自动更新观察与手动安装是独立证据。
