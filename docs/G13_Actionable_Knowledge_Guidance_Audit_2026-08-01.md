# G13 可执行知识网络建议审计（2026-08-01）

## 结论

G13 把知识网络从“展示统计数字”推进为“给出下一步行动”。工作台知识网络脉搏现在根据关系覆盖、孤立对象、关系数量和关系类型数量，显示一条最优先的改善建议，并可直接进入右侧统一图谱工作面执行。匿名观察预览与本地 JSON 回执也包含相同的结构化建议代码。

建议完全本地、确定性计算，不读取正文、文件名、对象 ID 或绝对路径，不调用模型，不联网，也不会自动上传。当前状态为 `actionable-local-guidance-implemented-real-user-execution-next`，`releaseCandidate=false`。

## 决策范围

机器规则覆盖六种状态：建立首个知识对象、建立首条关系、提升关系覆盖、连接孤立对象、丰富关系语义，以及网络健康达标。每条结果仅包含稳定代码、优先级、当前聚合值和目标聚合值；界面负责把代码转换成与原工作台字号、颜色和交互一致的中文行动文案。

规则刻意保持保守：覆盖率目标是 70%，关系类型建议目标是 3 类；这些是产品引导阈值，不是对用户资料质量的绝对评价。用户始终可以忽略建议并直接使用图谱。

## 验证与审计边界

Rust 回归覆盖空网络、无关系网络、低覆盖网络和健康网络；G12 的机密数据泄漏测试继续验证新增建议不会携带测试植入的标题、ID、文件名与 Windows 路径。机器合同锁定后端规则、工作台入口、匿名预览和发布边界。

真实资料库观察仍需用户明确授权执行，本阶段不能代替真实用户结论。正式 1.0.0、自动更新与 Release 仍须完成 R5N 签名、Windows 10/11 签名客户端证据和人工批准。

## 下一步

下一步为 `G13-consented-real-library-execution`：用户在真实资料库中检查工作台建议，并可在设置页预览匿名观察。只有用户主动保存、检查并提供聚合回执后，才能记录真实覆盖率、孤立比例和建议命中情况；不得收集或要求正文与路径。
