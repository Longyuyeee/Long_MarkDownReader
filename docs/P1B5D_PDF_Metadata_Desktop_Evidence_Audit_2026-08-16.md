# P1-B5D PDF 文档属性真实桌面与独立验证审计

结论：通过

## 1. 阶段结论与需求对齐

PDF 标题、作者、主题、关键词四字段编辑已经在原资料库壳层和 `PdfView` 右侧工作区完成真实桌面收口，没有新增窗口、路由或另一套视觉体系。它满足“日常管理与基础编辑”的有界需求：读取现有属性、修改草稿、验证、可靠另存并继续在同一资料库中管理目标副本。

该能力不是 PDF 匿名化或完整隐私清理。正文、批注、附件、表单和其他嵌入数据仍可能包含身份信息；现有 XMP、自定义 Info 键、签名、加密、PDF/A 与异常结构继续阻断。

## 2. 真实桌面工作流

隔离 Tauri custom-protocol 应用通过 WebView2 CDP 完成两页 PDF 的打开、既有元数据复读、四字段编辑、主题字段清空、属性草稿标记、离开路由拦截、隔离预验证、风险确认、可靠另存和目标自动重开。目标标题为“知识图谱专业管理 P1B5D”，作者和中文关键词正确复读，主题键确认不存在。

1280×800 与 720×680 两种视口均保持左侧资料库、右侧原 PDF 编辑区和 299 px 属性面板；页面级横向溢出为 0，保存按钮可达，运行时错误为 0。源 PDF 在操作前后的 SHA-256 完全一致。

## 3. 独立输出验证

独立 `pypdf + Poppler + Pillow` 门禁确认：源和目标均为两页；请求字段一致；空主题从 `/Info` 中真实删除；Creator、Producer、CreationDate、ModDate、Trapped 保持；原文字、页面几何和链接批注数量一致；目标 trailer 不包含增量 `/Prev`。

纵向页和横向页分别以 144 DPI 渲染，源与目标逐像素完全一致。十项证据文件均记录字节数与 SHA-256，清单拒绝后续静默替换。

## 4. 视觉复核

四张桌面截图已人工复核：宽屏草稿、宽屏验证、窄屏验证和保存重开均使用既有字号、按钮、边框、语义色和侧栏结构；中文没有截断或乱码。窄屏保留固定侧栏和可滚动 PDF 画布，这是现有工作区在 720 px 宽度下的有界布局，不产生文档外层溢出。

## 5. 能力边界与下一步

P1-B5 至此完成合同、后端、原工作区、真实桌面和独立输出验证。PDF 现有高级安全副本范围包括页面整理、提取/合并/插页、标准表单安全子集、永久脱敏图片型副本、文字水印和四字段描述属性；任意正文重排、签名或加密 PDF 写回、完整匿名化、自由 Choice、多选 Choice 与源文件覆盖不在承诺内。

下一步不继续扩张 PDF 范围，而是执行 P1 总收口审计：对照最初“日常管理、基础编辑、成体系管理、统一原工作区”的目标复核所有格式能力与边界，修正文档偏移后再进入 `1.0.11` 无签名社区版发布流程。
