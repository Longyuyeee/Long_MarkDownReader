# LongEdit 开发进度与后续阶段审计（2026-07-23）

## 1. 审计结论

项目当前已从 Markdown 阅读器演进为具备知识库治理、跨格式对象关系、专业工作台和渐进式 XLSX 编辑能力的本地知识管理系统。实际功能进度已完成至 **S8-5A：基础页面布局编辑**。下一开发入口为 **S8-5B：页眉页脚受限编辑**；保护设置修改继续等待独立凭据与威胁模型。

当前版本可以继续开发，但不应宣传为“完整 Excel 等价”或“完整 Office 套件”。公开口径仍应保持：XLSX 渐进式编辑、图表与高级数据对象受限、外部数据默认离线、兼容边界以机器可读矩阵和公开矩阵为准。

## 3. 已完成能力审计

### 3.1 专业知识管理基础

- 文件能力由共享格式注册表统一驱动，当前覆盖 8 类格式、11 个扩展名；创建、打开、扫描、索引和外部授权不再依赖分散白名单。
- WorkspaceGuard、外部文件授权、可靠写入、内容签名和恢复机制已进入主要读写链路。
- 专业工作台提供最近、收藏、待办、Canvas、保存搜索、动态集合和知识库健康治理。
- 本地索引可删除、重建、报告状态，并在失效或损坏时安全回退实时扫描，不成为唯一事实源。

### 3.2 知识图谱与思维导图

- G7-2 已完成七类 Markdown 语义关系的创建与删除，写回受路径、关系类型、内容签名和原始语法证据保护。
- G7-3 已将 PDF 批注、Canvas 节点、Table Chart 和 OPML 节点纳入细粒度跨格式对象关系。
- OPML 已具备树形/思维导图双视图、拖拽层级、折叠、搜索、撤销重做、可靠往返和 Canvas 投影。
- 当前短板不是“没有图谱”，而是图谱在日常文档工作面中的入口仍不够持续：关系上下文、路径解释、对象级影响分析和思维导图同步需要在 G8 主线继续增强。

### 3.3 XLSX 渐进式编辑

- S8-1 已完成行列隐藏/分组、整行整列插入删除、公式及相关对象坐标迁移。
- S8-2 已完成普通 Excel Table 创建、扩缩、列同步、改名、样式、转换/删除及基础持久化筛选排序。
- S8-3 已完成命名区域、数据验证和受限条件格式生命周期；条件格式覆盖基础规则、安全 `AND/OR/NOT` 表达式、色阶、数据条、标准图标集、多规则优先级及拆分/组合。
- S8-4A 已完成绘图对象稳定身份、选择、名称/替代文本编辑及标准双单元格锚点移动缩放。
- S8-4B 已完成已有标准图表标题、内部一维公式系列引用编辑，并直接读取源单元格生成受限本地预览。
- S8-4C 已完成从含表头连续选区创建柱形、折线、饼图和散点图，安全删除目标图表，以及标准结构间的受限类型切换。
- S8-4D1～D3 已完成标准单轴标题、图例位置、系列显示名、基础图表级标签和有限直接 RGB 系列颜色；本地预览消费相同的轴标题、图例方位、颜色和标签设置。
- S8-4D4 已完成四类真实 XLSX fixture、命令边界保存重读、专业浅色四类视觉矩阵、专业深色/高对比代表场景，以及真实 Tauri 标题编辑、保存、进程重启和重开验证。
- S8-5A 已完成单连续打印区域设置/清除、纵横方向、五种常用纸张、百分比/适页缩放和六项页边距；真实 Tauri 已完成横向 A4 保存和重新读取。

### 3.4 仍然明确受限的能力

- `.xls`、`.xlsb`、`.ods` 尚无正式产品编辑入口。
- 图表高级主题色绑定、透明度/色调变换、渐变/图片/图案填充、逐点样式、高级轴格式、组合图、三维图和未知扩展继续只读。
- 页眉页脚和保护设置仍以读取、显示和拒绝绕过为主；页面布局不提供分页计算或打印预览。
- 易失函数、动态数组、完整区域运算和 Excel 全函数语义尚未完成。
- 透视表刷新、切片器交互和外部数据查询未开放；软件不会隐式访问网络或外部文件。
- PDF 以阅读、批注、OCR sidecar 和索引为主，不是通用 PDF 内容重排编辑器。

## 5. 工程风险排序

### P1：工作簿核心体积与变更耦合

`src-tauri/src/formats/workbook_ooxml.rs` 约 13,160 行，`src/views/WorkbookView.vue` 约 3,097 行。继续直接叠加图表、页面和公式能力会放大审查、冲突和回归成本。S8-4C 必须同步建立 `workbook_ooxml/chart` 与前端图表工作面边界，不以单文件继续增长作为默认实现方式。

### P2：桌面端 E2E 自动化仍需扩展

S8-4D4 已补真实 Tauri WebView 的图表保存重开与主题视觉证据，但执行仍包含人工桌面操作。后续可将 Debug 隔离知识库能力接入跨平台 WebDriver，并继续补多窗口尺寸；在此之前，每个可见功能仍须提供可复核的桌面步骤和截图证据。

### P1：产品能力口径风险

本地预览证明数据引用可解释，不代表复刻 Excel 样式、布局或计算结果。公开文档、发布页和演示必须继续引用兼容性矩阵，不使用“完整 Office”“完整 Excel”或“无损编辑所有 XLSX”等表述。

### P2：累计批次过大

本项目按当前约定直接在 `main` 连续推进。每个子阶段仍须保持独立提交、完整门禁、文档审计和推送后远端一致性核对，避免多个未验收阶段堆入同一提交。

### P2：知识图谱存在感仍需产品化

图谱底层对象、关系和索引已具备，但文档工作流中仍缺少持续可见的“当前文档关系侧栏、关系路径解释、影响范围和一键投影思维导图”。这应作为 G8 产品主线推进，而不是继续扩展底层图算法后才补 UI。

## 6. 后续开发步骤

### 阶段 1：S8-4C 基础图表生命周期（已完成）

目标：支持从连续选区创建柱形、折线、饼图和散点图；支持安全删除和受限类型切换。

退出条件：

- 已可靠新增 Chart、Drawing、关系和内容类型部件，并按现有包内容分配无冲突编号、关系 ID 与对象 ID。
- 已仅删除目标锚点及关系；Chart 部件只在无其他 Drawing 关系引用时清理，同一 Drawing 的其他对象保持。
- 已仅开放标准柱形、条形、折线、饼图和散点图之间的兼容切换；未知扩展、组合结构和不安全系列公式拒绝修改。
- 已抽离 `workbook_chart` 子模块，并新增创建、切换、删除全生命周期包校验与语义重读回归。
- 内容签名与工作表保护继续由统一命令事务和 Drawing 写入入口强制执行；真实 Tauri WebView 的创建、保存、重开仍需在发布候选阶段补桌面 E2E 证据。

### 阶段 2：S8-4D 图表表达能力（已完成）

目标：开放标准坐标轴标题、图例位置、数据标签、系列名称和有限主题色；本地预览与写回模型保持一致。

完成情况：S8-4D1 已完成标准单轴图表的分类轴/数值轴标题和图例位置；S8-4D2 已完成标准安全图表的系列字面显示名和基础图表级数据标签；S8-4D3 已完成有限直接 RGB 系列颜色，并让本地预览同步轴标题、图例方位、系列颜色和低密度标签；S8-4D4 已完成四类真实 fixture、命令边界往返、三主题桌面视觉证据和 Tauri 保存重开。组合、多轴、三维、带未知扩展、高级逐点标签及复杂样式保持只读。

退出条件：标准柱形/折线/饼图/散点图逐项验收；组合图、三维图、自定义扩展和高级布局继续只读保真；完成真实 Tauri 视觉矩阵。

### 并行产品阶段：G8 图谱产品化增强

目标：显著增强知识图谱在日常管理中的存在感。

固定顺序：

1. G8-1 当前文档关系侧栏：入链、出链、同标签、跨格式对象和关系证据始终可见。
2. G8-2 路径与影响分析：解释两个对象为何相关，重命名/删除前展示受影响对象。
3. G8-3 图谱到思维导图：按中心节点、深度和关系类型投影为可编辑 OPML/Canvas，并定义同步与冲突边界。
4. G8-4 图谱工作台：保存图谱视图、集合联动、时间/类型筛选和健康治理入口统一。

### 阶段 3：S8-5 页面布局与保护（S8-5A 已完成）

S8-5A 已开放打印区域、方向、纸张、页边距和缩放，并完成命令往返、保护拒绝、生产构建和真实 Tauri 保存验证。下一批 S8-5B 开放页眉页脚；保护设置必须单独设计凭据与威胁模型，没有明确授权时继续拒绝解锁或绕过。

### 阶段 4：S8-6 公式语义

按函数族扩大覆盖，随后处理数组公式、动态数组和溢出语义。每个函数族必须同时具备依赖分析、错误传播、缓存策略和 Excel fixture，不能只实现表达式求值。

### 阶段 5：S8-7 高级数据对象

透视表、切片器、外部链接和数据连接分别验收。默认保持离线；任何刷新动作都必须由用户显式触发，并显示来源、凭据、网络和文件访问范围。

### 阶段 6：S8-8 等价发布审计

完成真实复杂工作簿差异、故障恢复、性能、桌面 E2E、视觉矩阵、安装包和公开声明审计。只有机器矩阵与真实 fixture 同时达到目标，才重新评估更强的 Excel 等价表述。
