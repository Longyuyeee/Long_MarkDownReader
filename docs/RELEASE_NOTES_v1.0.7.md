# Long编辑 v1.0.7

v1.0.7 是完整能力范围冻结后的 Excel 类型编辑与本地知识搜索补丁。它延续 v1.0.6 的外部打开、逐格式默认应用和体验收口，不扩大宏执行、外部数据刷新或完整 Office 等价承诺。

## 主要变化

- 七种经典 Excel 错误值进入 XLSX 显式编辑、撤销/重做、区域粘贴和保存复读链；读取引擎无法稳定复读的扩展错误继续阻断类型化写回。
- 已有日期型单元格支持 ISO 日期、日期时间和时间输入，使用真实日历校验，并按工作簿 1900/1904 日期系统转换 Excel 序列。
- 日期时间编辑保留原数字格式；普通空白格不会被隐式猜测为日期，持续时间与虚构日期 `1900-02-29` 保持只读边界。
- XLSX 现在可按工作表进入资料库持久索引和实时回退搜索；搜索结果会打开工作簿并切换到命中的工作表。
- 索引只读取文件内缓存值，不执行公式、不刷新外部数据、不访问外部连接，也不会修改源文件。
- 工作簿索引具备 ZIP 容器预检和固定资源预算，异常条目数、展开量或压缩比会在内容解析前 fail-closed。
- 格式、主题、Office 高级对象和外部打开范围已冻结；没有真实生产者证据的复杂写回继续留在后续证据门禁。

## 安装与更新

- v1.0.7 已完成远端质量门、安装包哈希、托管安装生命周期和公开附件复核，是当前稳定版。
- v1.0.6 用户可通过应用内检查发现新版本，确认后下载并校验官方 NSIS 的 SHA-256；托管应用内覆盖更新已完成 11/11 检查，首启、最新版状态及覆盖/卸载后的合成资料保留均通过。
- v1.0.4 及更早版本没有受控更新链，需要先手动安装 v1.0.5 或更高版本。
- 本版本仍未使用 Authenticode 商业签名，Windows 可能显示“未知发布者”或 SmartScreen。请只从官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。

## 能力边界

- Long编辑不执行 XLSM 宏，不刷新外部数据连接，不将本地公式引擎描述为 Microsoft Excel 的完整替代品。
- 错误值和日期时间编辑只对能够稳定识别、校验和复读的单元格开放，无法证明安全的结构保持只读。
- Excel/WPS/LibreOffice 三生产者动态数组写回仍等待外部证据，不阻塞本次社区补丁发布。
- 社区安装包保持 `NotSigned`，不代表企业签名候选或商业发布资格。
