# v1.0.15 后 M1C-B ODS 有界单元格值审计

日期：2026-08-27
版本：`1.0.15`
结论：通过；ODS 从结构化只读预览提升为资料库内基础单元格编辑与可靠新副本，ODP 和外部 ODS 保持只读。本阶段不是发布候选。

## 1. 交付范围

- 只开放未重复、未合并、无公式、单段纯文本的 ODS 字符串和有限数值单元格。
- 双击单元格进入内存草稿，支持撤销、重做、`Ctrl+S`、离开保护和明确的未保存状态。
- 保存只创建源文件同目录的新 `.ods` 副本；拒绝覆盖源文件或已有目标。
- 写入前校验源 SHA-256 和目标值摘要，写入后复核目标字节、ODF 结构、目标语义和源文件不变。
- ZIP 包只重写 `content.xml`，其余样式、manifest、媒体和未知部件逐成员保持。
- 公式、合并单元格、重复行列、富文本、风险包、ODP 和外部打开不获得保存入口。

## 3. 真实测试

- Rust ODF 定向测试：22 项通过，覆盖真实 ODS/ODP 读取、目标清单、文本/数值补丁、公式拒绝、陈旧摘要拒绝、同目录文件名约束、可靠另存和拒绝覆盖。
- 生产构建：`npm run build` 通过。
- 既有格式、E1C、外部 ODF 与 M1C-A 契约均通过。
- 真实 Tauri：实际输入、撤销、重做、保存提示、新标签复开、960×720 几何和 0 运行时错误通过。
- LibreOffice 26.2.4.2 使用隔离配置独立转 CSV/PDF；CSV 首格与预期完全一致。

## 4. 边界与下一步

M1C-B 没有把 ODS 宣称为 Excel/Calc 等价编辑器。公式只显示生产者缓存值，复杂对象继续保持或阻断；外部 ODS 不允许写入，ODP 继续只读。

下一阶段为 **M1C-C ODS 公式与样式可行性审计**：先固定公式命名空间、缓存值、样式继承和生产者规范化差异，再决定是否开放任何更小对象。未完成 LibreOffice 独立往返、未知部件保持和失败样本前，不更新公开能力；若风险不可控，M1C 可在当前基础编辑范围收口。
