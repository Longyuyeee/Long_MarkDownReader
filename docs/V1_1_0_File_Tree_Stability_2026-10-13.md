# 文件栏展开稳定性、按压闪烁与层级表达

用户反馈文件夹展开/收起时条目上下跳动，点击自定义样式文件会闪烁，父子文件难以辨认。基线为 `e841e997`。

## 定位与修复

1. 文件行使用纵向 margin，动画临时包裹子节点时，包裹前后外边距的折叠关系发生变化。实际逐帧记录发现展开末尾反向移动约 3.98px，收起末尾约 4px。将行间距移至 Naive 的每行外层 wrapper padding，行本身 margin 清零；保留原密度、高度和展开动效，临时动画容器与正常状态获得一致的占位尺寸。
2. Naive 的 `:active` 按压背景优先级高于自定义文件栏样式，而组件按压色已设置为 transparent。自定义淡紫背景按下80ms后实际变为 alpha约0.12，松开后恢复。为文件栏非禁用、可选且尚未选中的行增加正确优先级的按压反馈，沿用该行颜色；自定义选中背景/文字/描边仍按用户设置执行。修复后按压背景 alpha=255/255，行高度不变。
3. 启用既有树组件的层级连接线，文件夹名使用600字重，子级保持逐层缩进。根级文件不画虚假的连接线；深度按现有 Windows 长路径/UNC/斜杠统一身份计算。线条颜色随主题变化，连接线补偿实际行间距。没有用不同颜色代替父子关系，也不改文件排序或拖动语义。

## 检查

- `scripts/test-file-tree-stability-browser.mjs --baseline` 保存修改前实际页面和逐帧数据；默认运行对当前行为断言，不将基线失败转换为通过。
- 默认运行通过：自定义背景按压保持不透明、选中色保留、行高度稳定；六种风格及紧凑/宽松两种显式密度的16次展开/收起采样中，父行保持固定位置，下方条目沿一个方向运动，无反向跳动；三级文件名缩进递增且具有连接线。
- `scripts/test-file-tree-polish-browser.mjs` 原18组浅/深/高对比状态及密度、图标动效、键盘、右键和多选通过。选中动效终点使用条件等待，仍要求选中指示、独立反馈及无内层背景，不放宽断言。
- `scripts/test-file-tree-drag-browser.mjs` 移动、排序、取消、目的地提示及样式/草稿延续六组通过。
- `npm run build`、`git diff --check` 通过。实际改后侧栏截图已查看。
