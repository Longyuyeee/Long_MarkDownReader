# Post-v1.0.15 M3B-0 专业视觉基线选择审计

日期：2026-08-28

阶段：M3B-0

发布候选：否

## 1. 原始需求与审计边界

本次直接对照 `Post_v1.0.15_Professional_Capability_Enhancement_Roadmap_2026-08-25.md` 的 M3B，而不是按当前画面反推需求。原始范围包括：社区轮廓与语义层级、曲线/平行边/关系标签/路径方向流动、远中近语义缩放、缩略导航与聚类镜头、克制的状态外环，以及主题可读性和减少动效。

M3B-0 只记录修正前代码与真实桌面事实并选择一个最小实现，不修改产品渲染行为，不把截图观感等同于验收通过，也不提前处理属于 M3C 的 Worker、空间索引、脏帧和 5,000 节点性能收口。

## 2. 实际代码事实

`GraphView.vue` 当前具备 M3A 已冻结的 11 类对象形状/色彩、关系线型、方向箭头、语义图例、稳定社区筛选和路径证据；工具栏可横向滚动，窄窗口没有页面级横向溢出。这些能力应保留。

专业视觉与镜头仍存在以下真实差异：

| 原始要求 | 修正前实际代码 | 影响 |
| --- | --- | --- |
| 远/中/近语义缩放 | 只按 `zoom > 0.3/0.4/0.55` 分别显示边、全部标题和字形，不考虑节点密度、重要性或社区 | 大图默认比例标签爆炸；远景则同时失去关系和语义 |
| 远景社区、社区轮廓 | Louvain 结果只用于卡片与子图筛选，无社区摘要节点、轮廓或色带 | 用户看不到全局主题结构 |
| 曲线和平行边分离 | 关系网络使用直线；仅思维导图使用 Bézier | 平行关系叠在一起，方向和类型难辨 |
| 关系标签、路径方向流动 | Canvas 不绘制关系标签或路径流动；路径主要靠证据面板 | 不打开面板无法读出关系语义，面板又会遮住路径主体 |
| 导航与聚类镜头 | 只有适合全图；无缩略图、适应选择、聚类展开/折叠和图谱级全屏 | 大图缺少空间定位与逐层进入路径 |
| 减少动效 | 设置支持 `reduced`，但图谱组件不读取 `store.motionSpeed`，布局稳定后仍持续 `requestAnimationFrame(loop)` | 偏好未进入图谱合同；持续帧收口属于 M3C，不能在本阶段误报完成 |

## 3. 既有大图证据复核

M3-0 的真实基线仍有效：1,000 节点首次可见 638ms、稳定 11,654ms；5,000 节点首次可见 19,378ms、稳定 115,802ms。两档均可返回资料库、运行时错误为 0、源文件不变，但截图在默认/保存缩放下出现严重标签重叠。这里仅把它们用作信息密度与后续性能边界，不宣称 M3B-0 改善了性能。

## 4. 真实 Tauri 视觉基线

审计使用暗色主题、`reduced` 动效偏好和 17 节点/17 边跨格式资料库，覆盖 11 类实际对象和 6 类实际关系。结果如下：

| 场景 | 实际结果 |
| --- | --- |
| 默认 100% | 17 个节点全部显示标题，局部已有重叠；图例和详情可读 |
| 远景 28% | 固定阈值同时关闭边与标题，只剩无社区含义的彩色点阵 |
| 近景 157% | 标题和对象字形清楚，但仍无关系标签或平行边分离 |
| 社区 4 节点 | 只显示筛选后的 4 节点/3 边与范围条，无社区轮廓或全局上下文 |
| 路径 3 边 | 三条边证据完整，但证据面板覆盖路径主体；Canvas 无关系标签、无方向流动 |
| 720×680 | 页面无横向溢出，工具栏可滚动；路径面板覆盖画布而非挤压画布，无缩略导航图 |

运行时错误为 0，审计前后资料库 SHA-256 一致，成功返回资料库。截图与 `desktop.json` 位于 `docs/evidence/post-v115-m3b0-professional-visual-baseline/`，不包含用户内容，`releaseCandidate=false`。人工逐张复核已确认截图与结构化结果一致。

## 5. 选择与开发顺序纠偏

下一最小阶段冻结为 **M3B-1 语义缩放与社区远景**。它应先建立由缩放与密度共同决定的稳定层级：远景显示可识别、可进入的社区摘要；中景显示关键节点及必要关系；近景再显示标题、状态与证据入口。层级切换必须稳定、可测试，并保留 M3A 的筛选、路径、选择与图例语义。

选择它而不是先做路径动画、缩略图或装饰效果，原因是当前 1,000/5,000 节点不可读和 28% 远景信息归零都来自同一缺口；社区远景同时是后续聚类展开、缩略导航和镜头定位的前置合同。不得用背景光斑替代社区语义，也不得把 M3B-1 扩大成 M3C 性能重构。

M3B-1 完成后应独立审计默认、远景、中景、近景、社区进入/返回、1280×800/1000×700/720×680、暗色/浅色/高对比和 `reduced` 偏好，再提交并推送；随后才选择关系路径表达或导航镜头的下一最小阶段。
