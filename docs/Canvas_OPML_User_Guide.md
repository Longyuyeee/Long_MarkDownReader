# Canvas 与 OPML：整理、保存和接续

本文对应 v1.1.19 的操作界面；是否已经公开，请以 [发布审计](V1_1_19_Unsigned_Community_Release_Audit_2026-10-18.md) 为准。Canvas 是卡片和连线画布，OPML 是主题大纲与思维导图。它们保留各自格式，不会因为打开而自动写回。

Canvas 常规编辑保存会规范化 JSON 排版，不是任意第三方扩展的原始字节编辑器，也不承诺超出 JavaScript 安全数字范围的扩展数值字面量保真。软件内整理文件时的来源引用改写则只替换对应路径，保留其他原文字节。对第三方工具专用扩展，请保留原件和备份。

## 编辑后怎样保存？

点击页面的“保存”，或按 Ctrl+S。看到“已保存”或“已与磁盘同步”才表示这一份内容已确认写入。保存期间继续输入的新内容仍是草稿，需要再次保存。

切换文件或重新读取时，如果有未保存内容，可以取消并回到原页保存，或明确放弃后离开。取消不会清空草稿。同一文件的节点定位只移动到目标，不会重新从磁盘读入覆盖当前编辑。

如果提示文件被其他程序修改，当前草稿和对方磁盘内容都会保留，不会强行覆盖。先核对两边需要的内容；只有决定采用磁盘版本时，才使用“重新读取”并确认放弃当前修改。读取失败也不会被当成保存成功。

## 画布的文件卡片怎么用？

点选文件卡片，可以查看精确路径和来源状态；“打开来源”在主编辑区打开该文件。找不到来源时，使用“重新指定”，输入相对资料库根的路径，例如 `项目资料/会议纪要.md`，而不是只输入可能重名的文件名。

重新指定先修改画布草稿，点击保存才写入。资料库内使用软件的改名、移动功能时，已保存的画布引用通过同一整理事务接续；相关文件有未保存草稿时会先阻止整理，不会代存或猜测覆盖。直接在资源管理器移动文件不等同于完成了这个事务，可能需要手动重新指定。

外部画布不会自动获得其引用文件的读取权限。把一个外部文件交给软件打开，不代表授权读取它所在目录的其他文件。

## 分组和视角

拖动分组背景，会带上完全位于分组内的卡片；拖动卡片本身仍移动这张卡片。轻微点按抖动不算移动，撤销可恢复分组和卡片的位置。需要重新找到内容时使用“适应内容”；缩放、定位和调整窗口大小不会代替保存。

工具栏空间不足时可以横向滚动，也可以使用 Tab 定位按钮并按 Enter。右侧参考区不需要时可以关闭，将空间留给画布。

## OPML 提示“无法无损保留的扩展”怎么办？

展开提示查看具体原因。软件仍允许编辑支持的主题、备注和属性，但不会用不完整的结果覆盖原件。

需要交付当前内容时，点击“另存副本”或“另存兼容副本”，核对将不包含的扩展，确认后用新文件名保存。已存在的同名文件不会被覆盖。库内文件的副本放在原文件夹；外部 OPML 的副本只放在当前资料库根，不扩大外部目录授权。

成功另存也不会清空原页草稿或自动改成编辑副本，原件仍保留。请根据页面返回的新路径核对副本，想继续编辑副本时再主动打开它。兼容副本不是未知 XML 扩展的无损往返承诺。
