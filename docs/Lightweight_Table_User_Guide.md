# 轻量表格编辑与交付说明

CSV、TSV和开放Table继续使用原表格工作区；Table的看板、图表和仪表盘入口保留。所有修改先留在草稿，只有点击保存才写入文件；离开未保存表格仍会提示。

## 选择、复制与粘贴

单击普通格子照常编辑文字；按住Shift点击另一个格子可选中两者之间的矩形范围。状态栏显示行数和列数，并可复制、清空或取消选区。Ctrl+C/Ctrl+X操作选区；只有一个格子并选中了其中部分文字时，保留普通文本复制/剪切习惯。

从表格软件复制的内容通常以制表符分列、换行分行。粘贴从当前格或选区左上角开始，支持引号、字段内换行、空尾格和中文。对多格选区粘贴一个值会填满该选区。普通单格粘贴单行文字仍按输入光标插入，不强制覆盖整格。

筛选/排序后的操作按开始时的可见行定位，隐藏行不变。未筛选未排序时，向下粘贴可补行；否则超出可见行会整次拒绝。超出现有列时先用“＋ 列”补足，不静默截断或只粘贴一部分。单次复制/粘贴最多2MiB、20,000格，超限请缩小范围或分批进行。

## 多行内容与撤销

含换行的格子以“⏎”提示，不用单行输入框压平原内容。点击“↵”按钮、双击或在该格按Enter可打开多行文本区；取消不修改，确认只写入草稿。原格使用统一CRLF时显式编辑仍保留该换行风格。

单元格、表头、看板字段、粘贴/清空及行增删加入数据历史。连续输入可按一次编辑撤销，批量粘贴可一次撤销/重做；Ctrl+Z、Ctrl+Y或工具栏按钮均可使用。排序后按稳定行列身份恢复，不按屏幕行号猜测。历史最多100次、8MiB；新增列与视图配置不在该撤销范围。撤销已保存内容仍只改变草稿，需要再次保存才写回文件。

## 保存与交付边界

保存中继续输入或粘贴，新修改仍待保存；写入失败保留草稿，文件被其他程序修改时不猜测覆盖。CSV/TSV继续保留原编码、BOM和物理换行，无法编码的内容会明确失败，不静默替换文字。

Table可导出CSV或XLSX。XLSX仅将能安全往返的常规数值写为数字，前导零、长编号和不能原样往返的数字外观按文本保留；公式外观文本不生成公式。CSV没有单元格类型，其他软件可能自动解释编号、日期或公式，应核对对方的导入设置；Long编辑不通过加前缀改变原始值。导出使用已保存正文，未保存时会提示先保存，不会自动代存。创建Table副本不会更改原CSV/TSV。
