## 1. 目标与需求对齐

C4D 对齐用户最初提出的“在统一管理器中完成日常阅读、基础编辑和成体系管理”，但不追求完整 PowerPoint 等价。本阶段把 C4A～C4C 已验证的文本、演讲者备注、基础字符样式、形状文本样式和图片替代文本补丁，接入安全的真实落盘链路。

阶段退出标准为：

1. 编辑仍发生在原 Library 右侧 PPTX 工作区，不创建独立编辑窗口；
2. 只有通过隔离副本预览的操作才能保存；
3. 只能在源文件同目录原子创建新的 `.pptx`，禁止覆盖源文件或已有目标；
4. 保存前后均检查源文件签名，保存结果必须逐字节复读、结构复开和语义复开；
5. 失败时只允许清理本次创建且内容完全相同的目标，不扩大删除范围；
6. 新副本可重新进入统一阅读、搜索、关系和管理工作区。

## 2. 已交付能力

### 2.1 统一编辑操作

后端使用带类型标记的 `PptxPatchOperation` 统一三类受限操作：

- `text`：单个安全文本目标或演讲者备注；
- `style`：单运行文本、文本框或形状文本的字体、字号、颜色、粗体、斜体、下划线和对齐；
- `imageAltText`：单个内嵌图片的替代文本。

每个操作都携带目标摘要与 OOXML 部件摘要。参数变化会使旧预览立即失效，避免保存与用户当前表单状态不一致。

### 2.2 可靠无覆盖保存

`save_pptx_patch_copy` 复用 `reliable_write::write_new_bytes`：

- 工作区守卫同时约束源路径和目标路径；
- 目标必须是同目录的安全 `.pptx` 文件名；
- `target == source`、已有目标、陈旧源签名和陈旧预览摘要全部拒绝；
- 保存前重新执行操作并比对预览输出 SHA-256；
- 只允许一个已验证 OOXML 部件变化，其余部件逐字节保留；
- 落盘后读取目标字节并再次解析、重建操作和比较语义结果；
- 最后再次验证源文件字节、摘要和签名未变。

当前公开保存模式明确为 `copy`，不提供覆盖原件命令。

### 2.3 右侧工作区交互

编辑安全基线、隔离预览和可靠另存全部位于既有 PPTX 详情栏，复用原主题、字号、间距和按钮变量。保存面板只在最新操作通过隔离验证后出现；成功后显示结构复开、语义复开和源文件不变结果，并可直接打开已验证副本。

## 4. 当前能力判定

PPTX 当前已经具备：

- 结构化阅读、缩略图、备注、放映、搜索和精确对象定位；
- 索引、文件/幻灯片知识对象、关系侧栏和图谱回流；
- 文本/备注、基础字符样式、形状文本样式和图片替代文本的受限编辑；
- 不覆盖原件的可靠新副本保存；
- 应用内写后结构与语义复读；
- PowerPoint/WPS/LibreOffice 三生产者源文件输入回归。

仍不能宣称：

- 完整 PowerPoint 编辑器；
- 原文件覆盖保存；
- 多段复杂文本、图片二进制替换、形状增删、幻灯片增删改序；
- 母版、主题、动画、SmartArt、复杂图表和未知扩展编辑；
- C4D 输出副本已经由三种外部演示软件实际复开。
