# v1.2.30：TOML 字段复制

字段右键“复制为新字段…”，只填新名称，直接预览。默认选中同级不重名的副本名；字段值直接取当前未保存的草稿，不必重新输入。应用后选中并高亮新字段，方便接着修改，一次撤销／重做，显式保存才写入文件。

新字段紧跟原字段，保留普通单行标量的原值、引号、数字和日期时间写法、等号空白、缩进和明确附着的行尾注释；独立注释保留原位，BOM、换行及其他字段不变。点键、数组表、集合、多行值或归属不明时，局部说明并提供源码定位，保留名称与草稿。

保护后续输入、延迟结果、旧预览、文件切换、保存重试和完整冲突副本，保留全部现有功能、主题与正常动效。不增加常驻表单或按钮。
