# v1.2.19：YAML 字段重命名

在 YAML“文档结构与问题”提纲右键选择“重命名字段…”，预填字段名，弹窗输入后预览，再应用到草稿；保留独立撤销，点击保存后才写入文件。

支持块式／流式映射中的普通字符串键，只改当前字段名，保留值、注释、锚点／别名、数字原文及排版。保留引号风格，true、null 或数字等名称自动保持字符串类型。连续改名接续最新路径和定位。

同级重名、复杂内容或不明确归属局部提示，保留输入并提供源码定位。继续保护未保存内容、保存期间后续输入、失败重试和外部冲突副本；保留全部功能、主题和正常动效，不增加常驻表单。
