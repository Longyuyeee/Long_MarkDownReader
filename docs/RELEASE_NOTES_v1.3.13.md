# v1.3.13：返回后继续前进

- 返回原位置后，在现有文档操作菜单或命令面板选择“前进到刚才的位置”，再次查看刚才的结构节点或查找结果。
- JSON、YAML、XML、TOML均支持当前文档最近20处往返记录，接续选区、滚动和有效视图；JSON树形无效时保留草稿并回到源码。
- 修复多层树形往返后切回源码时滚动回到顶部的问题，隐藏期间也保留正确的阅读位置。
- 修复通过文档菜单前进到源码开头时，编辑器重新获得焦点却滚回旧位置的问题。
- 普通编辑接续有效位置，主动定位新目标会清除旧前进分支，更换文件或重载停用旧记录。
- 导航不编辑、不保存、不增加正文撤销步骤，支持只读文件，保留全部风格与正常动效，不新增常驻面板。
