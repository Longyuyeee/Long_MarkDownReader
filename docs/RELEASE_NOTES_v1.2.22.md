# v1.2.22：TOML 字段新增与删除

在 TOML 提纲的普通表或字段上右键“新增字段…”，自动使用当前表，只填名称和值；名称中的点保持单个键，预览显示实际值类型。空白提纲右键可从文档根部新增。

字段右键“删除字段…”直接预览，支持普通单段键及单行完整值，包括日期、数组和内联表。保留其他字段、表头、注释及后续表；多行、点键、隐式表与数组表整理提供局部说明和源码定位。

应用仅改草稿，可撤销／重做，显式保存才写盘。错误保留名称和值，继续保护后续输入、保存失败重试及外部冲突副本；保留全部功能、主题和正常动效，不增加常驻表单。

未签名社区版；完整发布检查与 569 项安装版功能任务通过，NSIS、MSI 与 `SHA256SUMS.txt` 三份公开附件重新下载核对通过。应用内自动更新实际观察仍待完成，与手动安装升级分别记录。
