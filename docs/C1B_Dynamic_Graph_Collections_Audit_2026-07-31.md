# C1B 动态图谱智能集合审计

审计日期：2026-07-31

阶段状态：已完成

发布状态：`releaseCandidate=false`

## 本批目标

把 C1A 的一次性项目笔记继续推进为可持续刷新的管理入口。用户可以从 Markdown/PDF 图谱中心保存 1～4 层动态子图，之后从首页、集合侧栏或文件关系上下文重新进入。

## 已完成

- 图谱节点详情新增“保存为智能集合”。
- 集合保存知识库相对 `graphRoot` 与 `graphDepth`，不保存旧机器绝对路径。
- 每次打开集合都复用 `build_local_graph` 实时计算当前文件级子图，关系变化后无需重新保存集合。
- 统一工作区使用独立集合状态展示结果，不把集合名称伪装为全文搜索词。
- 首页智能集合、Library 集合侧栏和文件关系上下文均可识别并打开图谱集合。
- 文件关系上下文可实时判断当前文件是否属于图谱集合。
- 配置验证限制 Markdown/PDF 根节点、1～4 层深度、安全相对路径和唯一内部查询标记。
- 管理备份导出与路径重映射恢复会保留图谱根节点和深度。
- 旧版本忽略新增字段时仍能把内部查询标记作为普通保存搜索读取，不会因空查询阻断整个配置。

## 边界

- 动态集合当前保存文件级节点，不把 PDF 批注、幻灯片、Canvas 子节点等内部对象重复列为独立集合成员。
- 图谱根节点删除或移出知识库后，集合会明确打开失败，不会静默改指其他文件。
- 当前没有真实代码签名证书，R5N 外部门禁继续保持 fail-closed；本批不改变 RC 状态。
