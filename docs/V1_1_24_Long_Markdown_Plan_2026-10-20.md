# 1.1.24 计划：长 Markdown 的阅读与章节组织

状态：仅规划，尚未实施。接续 [十二版路线](Foundation_Deepening_Roadmap_1_1_21_to_1_1_32_2026-10-19.md)，在 1.1.23 附件管理正式发布后按顺序推进。

用户要完成的事是：“长方案里有重复标题、表格和代码，我想调整一节的位置或层级，然后回到刚才的位置继续写。”

先核对现有 `useOutline.ts`、Vditor 三种编辑模式和阅读位置接续。大纲定位应绑定实际标题范围，不能按标题文字猜测；切换文件、刷新提纲及撤销后仍能回到正确位置。

高频动作放在大纲标题右键：复制章节链接、调整标题层级、上移或下移整节。保留正文附近现有按钮；跨节改动按需预览，不添加常驻操作表单或新的侧栏。当前模式不能可靠映射时保留只读定位，并明确提示可用方式。

章节边界以可靠源码映射为准，保留节内图片、代码围栏、表格及嵌套列表；一次操作形成一次可撤销修改。操作绑定当前文档与最新草稿，预览后继续输入、切换模式或文件时不覆盖新内容，不为整理章节强制保存。

围绕含重复标题的长文验证定位、章节移动、层级调整、撤销与保存复开。性能只检查本版影响的输入、大纲更新和章节操作，保留正常动效，实际卡顿时沿用已有自适应处理。完成后走现有固定安装器与用户工作流检查，更新 README 和 Release。

1.1.25 仍按既有路线推进，不并入本版。
