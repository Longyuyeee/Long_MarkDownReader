## 本步界面调整

实际打开480px HTML 页面发现：固定高度工具行挤住文件身份，编码项隐藏“读取/保存”标签，末尾换行文字被压成多行。改为按内容容器宽度响应式排列文件身份和操作行；保留操作，可横向滚动，查找替换/跳转行增加文字。编码/BOM/换行/末尾换行及置信提示保留完整标签，空间不足时滚动，不修改保存策略。

HTML 预览说明改为可换行，窄窗不隐藏隔离规则。源码/安全预览、当前草稿、显式保存及原有 HTML 清理与空 sandbox 保持。状态栏维持单行可滚动。来自搜索的匹配导航分配独立网格行，避免落入隐式网格挤占编辑区。

未修改编码读取/写回、外部文件授权、敏感变量遮罩、范围读取、外部修改冲突保护、显式保存和语言支持逻辑。未增加原方案之外的执行脚本能力。
