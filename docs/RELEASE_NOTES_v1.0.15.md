# Long编辑 v1.0.15

v1.0.15 是桌面交互一致性、应用内更新反馈与浮层稳定性增强版本。

## 主要变化

- 顶部文档标签改用现代化应用提示层，完整显示文件名、路径和未保存状态，不再依赖浏览器原生 `title`。
- 全软件静态与动态标题提示统一使用主题化浮层，支持鼠标、键盘焦点、ARIA、Escape 关闭和视口边界保护。
- 普通软件区域右键不再弹出 WebView 默认的“粘贴、全选、更多工具”；输入框、CodeMirror、Vditor 等真实编辑区域仍保留必要的文字操作。
- 文件树、画布等已有专用右键菜单继续正常工作。
- 原生 `confirm`、`alert`、`prompt` 已迁移到软件内对话框，统一字号、颜色、圆角和主题。
- 资料库约 30 项的“新建”菜单改为窗口内滚动浮层，修复窄窗口越界、层级遮挡和淡入过渡帧问题。
- 应用内更新增加真实下载进度、容量和下载/校验/安装阶段反馈，并修复设置页卡片缩放越界与深色悬浮白光。

## 真实验证

- 交互治理通过七张真实 Tauri 桌面截图，覆盖亮色、深色、720×680 窄屏与 DPR 1.5；运行时错误为 0。
- v1.0.13 → v1.0.14 官方应用内更新通过 GitHub 托管 Windows 12/12 生命周期检查：用户确认、SHA-256、覆盖安装、自动重启和资料保留全部成功。
- 完整开发审计、生产构建、Rust 锁定检查和生产依赖审计必须在发布候选阶段全部通过。

## 安装与更新

- v1.0.14 用户可在 v1.0.15 发布后通过应用内检查更新；下载安装前仍需用户确认并完成官方 NSIS 大小与 SHA-256 校验。
- 社区安装包不含 Authenticode 商业签名，Windows 可能显示“未知发布者”或 SmartScreen。
- 只从官方 GitHub Release 下载，并核对同页 `SHA256SUMS.txt`。

## 能力边界

- 本版本聚焦桌面交互与发布可靠性，没有把预览能力宣传为完整 Office、WPS 或 PDF 原位编辑。
- 43 类格式继续按直接编辑、有界可靠副本、只读预览和外部程序依赖四类事实运行。
- 企业签名与外部 Office 多生产者证据仍属于独立门禁。
