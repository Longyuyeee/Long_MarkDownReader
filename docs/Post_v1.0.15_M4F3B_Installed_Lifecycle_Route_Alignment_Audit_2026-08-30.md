# M4F-3B 安装生命周期与治理入口纠偏审计

日期：2026-08-30

结论：首轮托管安装生命周期发现的超时来自 M2A2 后未同步的旧验收路径，同时暴露设置页仍把用户送往已删除治理建议的工作台；本轮按实际产品需求同时修复用户路径和安装态验收，不把失败包装成环境波动。

## 实际偏移

- M2A2 已明确删除工作台独立的知识网络脉搏与治理建议，详细指标回归图谱治理面板；`WorkspaceHome.vue` 不再包含 `knowledge-network-pulse` 或 `knowledge-observation-entry`。
- R5J 仍在 `#/workspace` 等待 `knowledge-network-pulse`，首轮 GitHub Actions `33264898797` 因此在任何路由与 I/O 验收前等待 120 秒后失败。
- 设置页“关系整理效果对比”第二步仍显示“前往工作台建议”，并路由到 `WorkspaceHome`。这会把真实用户送到已经没有建议的页面，是产品路径回归，不能只修改测试绕过。

## 纠偏

- 设置页第二步改为“前往图谱建议”，进入 `Graph?focus=overview`。
- 图谱收到 `overview`、`diversity` 或 `orphans` 治理焦点时自动打开知识图谱治理面板；`relations` 仍保持链接教程路径。
- R5J 的通用工作台就绪条件改为 M2A2 主行动区 `ready`，知识网络、建议、改善入口和观察会话改走图谱治理真实路径。
- 删除当前安装态证据对已移除工作台观察入口及截图的要求；历史 G15D 已接收证据保持不变。
- R5G 等待隔离资料库配置和两个夹具完成扫描后再打开嵌入式编辑器，避免启动时配置恢复覆盖测试路由；导航超时会记录 hash、正文和崩溃面。
