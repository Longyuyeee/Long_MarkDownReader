# v1.2.33：TOML 日期时间编辑

普通字段右键“修改值…”即可调整日期、本地时间、本地日期时间和带时区日期时间。原文直接预填，不擅自转换时区、分隔符或小数精度；紧凑输入框支持回车预览，无需新增操作步骤。

日期或时间无效时在原弹窗中提示，保留当前输入与草稿，修正即可继续，也可定位源码。差异确认后只更新选中的值，保留其他字段、空白、注释、BOM 与换行；一次撤销／重做，显式保存才写盘。

继续保护未保存内容、后续输入、延迟结果、旧差异、文件切换、保存失败重试与外部冲突完整副本。保留全部既有功能、风格和正常动效。
