# E2B Draw.io 结构化编辑器审计

日期：2026-07-31
结论：E2B 已完成
发布状态：`releaseCandidate=false`

## 已交付

- `.drawio` 与 `.dio` 已作为第 41 类格式进入统一注册表，支持创建、读取、基础编辑、索引和签名保护覆盖保存。
- Rust 后端同时解析直接嵌入的 `mxGraphModel` 与“URI 编码 + raw deflate + Base64”的压缩页，并限制 10 MiB 源文件、100 页、单页 20 MiB 解压量、总计 40 MiB 解压量、单页 50,000 单元格和 96 层深度。
- 独立 Draw.io 工作面提供页面切换、本地 SVG 画布、节点筛选，以及标签、位置、尺寸、填充色和描边色修改。
- 修改只重写目标页面；压缩页按标准重新编码，未识别的模型、单元格和几何属性继续保留。
- HTTP(S) 链接与外部图片只作为数据保留并提示，工作面不自动打开链接、不加载外部图片；`javascript:`、`data:`、`file:` 会使分析失败并阻止保存。
- 保存复用通用可靠文本写入，要求打开时签名仍有效；修改后必须重新通过完整 Draw.io 分析。

## 验证边界

提交内 fixture 覆盖双页非压缩文件、节点、连线、未知属性、外部链接和外部图片。Rust 测试另外即时生成压缩页，验证解压、修改、重压缩、重新解析与未知属性保留。桌面工作面的“保存后重新分析”覆盖 LongEdit 自身复开合同；本阶段没有宣称由 diagrams.net 外部应用独立复开。

E2B 的公开能力仍是“结构化基础编辑”，不是 diagrams.net 等价编辑器。复杂形状、富文本、容器、泳道、自动布局、连接点和媒体编辑保持只读保真或降级预览。
