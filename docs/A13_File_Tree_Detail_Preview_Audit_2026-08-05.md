# A13 文件树详情浮层审计

日期：2026-08-05

阶段：UX-35

结论：文件树重复提示已收口。文件节点不再输出原生 `title`，鼠标悬浮和键盘方向键当前项共用一个带 `role="tooltip"` 的详情浮层；Esc、焦点离开和鼠标移出均可关闭。

## 修复内容

- 删除节点原生 `title`，保留名称、相对路径、创建时间、修改时间和大小组成的统一详情浮层。
- 文件节点与文件树通过 `aria-describedby` 关联详情浮层，键盘焦点停留在 Naive UI 树容器时，根据 `.n-tree-node--pending` 当前项显示同等信息。
- 键盘映射使用自定义 `data-drop-path`。Naive UI 会占用并移除节点的 `data-key` 属性，真实桌面审计已捕获并修复这一差异。

## 真实桌面验收

使用 Tauri Debug WebView2 和隔离临时资料库完成验收。两个仓库 fixture 的原生 `title` 数量为 0，两个文件节点均关联详情浮层；鼠标悬浮和方向键当前项均显示可读详情，Esc 后浮层及树级描述关联同时消失。运行时异常为 0，阻断错误页未出现。

证据位于 `docs/evidence/ux35-file-tree-preview`，两张截图已经人工检查。证据不含用户资料和完整本机路径，当前仍是开发态证据，`releaseCandidate=false`。
