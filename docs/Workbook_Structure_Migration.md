# XLSX 行列插删引用迁移契约

更新日期：2026-07-22
实施批次：S8-1B1 / FR-DATA-009

## 1. 本批能力

S8-1B1 建立行列插入/删除的唯一坐标迁移内核，并通过 Tauri 命令 `preview_workbook_structure_migration` 暴露受限预览。调用方提交目标 Sheet、行或列轴、插入或删除动作、零基起点、数量、当前公式 Sheet，以及最多 10,000 条公式和 A1 引用；Rust 返回迁移结果，不修改工作簿。

该预览用于 S8-1B2 写回事务的前置规则验证，不是已经开放的插删入口。当前工作簿工具栏仍不会执行实际行列插入或删除。

## 2. 迁移规则

- 结构插删会迁移相对、混合和绝对 A1 引用；`$` 只约束复制填充，不阻止结构变更。
- 无 Sheet 前缀的引用只在公式所属 Sheet 是目标 Sheet 时迁移；带 Sheet 前缀的引用按不区分大小写的 Sheet 名匹配。
- 插入发生在范围起点前时整体平移，发生在范围内部时扩展范围终点。
- 删除会移除被删坐标、收缩部分重叠范围，并在单元格或完整范围被删除时生成 `#REF!`。
- 支持二维单元格范围、整行范围和整列范围；超出 Excel `1,048,576 × 16,384` 边界时生成 `#REF!` 或拒绝非法变更。
- 字符串字面量、函数名、Table 结构化引用和非目标 Sheet 引用保持不变；三维引用和外部工作簿引用当前不迁移，原文保留。

## 3. 安全与边界

结构变更要求非空且不超过 31 字符的 Sheet 名、有效轴和动作、正数数量以及边界内起点；删除区间不得越过 Excel 网格。预览拒绝空请求和超过 10,000 条的批次。

S8-1B1 不读取或写回 XLSX 包，因此尚未迁移单元格节点、合并区、验证、筛选、冻结窗格、命名区域、Table、图表、drawing anchors 或维度。它只冻结这些对象后续必须共用的坐标语义。

## 4. 下一批

S8-1B2 将迁移内核接入签名保护的 OOXML 包事务：先完成整行插入/删除和所有已识别引用载体的原子写回，再以复杂 fixture 的语义重读和 ZIP 差异白名单验收。整列插入/删除在相同行为稳定后继续接入，不能另写一套迁移规则。
