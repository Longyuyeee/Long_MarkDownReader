# XLSX 行列插删引用迁移契约

更新日期：2026-07-22
实施批次：S8-1B1、S8-1B2A、S8-1B2B1、S8-1B2B2 / FR-DATA-009

## 1. 当前能力

S8-1B1 建立行列插入/删除的唯一坐标迁移内核，并通过 `preview_workbook_structure_migration` 提供最多 10,000 条公式与 A1 引用的只读预览。

S8-1B2A 新增签名保护的 `update_workbook_structure` 后端事务。当前实际写回仅支持普通目标工作表的整行插入和删除，原子迁移目标 Sheet 的 `<row>`、单元格坐标、`dimension`、所有工作表中的相关公式，以及工作簿定义名称。写回前后均经过受限 ZIP 解析、包校验、128 MB 上限和可靠替换；旧签名整批拒绝。

S8-1B2B1 在同一事务中增加工作表 XML 内部载体：合并区、自动筛选、冻结窗格、选择状态、数据验证、条件格式和内部超链接。验证与条件格式的 `sqref` 及内部公式会同步迁移，多区域引用中被完整删除的子范围会移除；真实 XLSX 插入/删除后通过结构语义重读。

S8-1B2B2 将事务扩展到关系部件：目标 Sheet 的 Table 范围和 Drawing 行锚点、所有关联图表的系列公式，以及 `calcChain.xml` 中目标 Sheet 的公式单元格坐标会同步迁移。被整段删除的合并区、筛选、验证、条件格式和超链接会移除，`mergeCells` 与 `dataValidations` 的 `count` 同步更新。

该事务尚未接入工作簿工具栏，因此不能表述为前端已开放的行插删功能。

## 2. 迁移规则

- 结构插删会迁移相对、混合和绝对 A1 引用；`$` 只约束复制填充，不阻止结构变更。
- 无 Sheet 前缀的引用只在公式所属 Sheet 是目标 Sheet 时迁移；带 Sheet 前缀的引用按不区分大小写的 Sheet 名匹配。
- 插入发生在范围起点前时整体平移，发生在范围内部时扩展范围终点。
- 删除会移除被删坐标、收缩部分重叠范围，并在单元格或完整范围被删除时生成 `#REF!`。
- 支持二维单元格范围、整行范围和整列范围；超出 Excel `1,048,576 × 16,384` 边界时生成 `#REF!` 或拒绝非法变更。
- 字符串字面量、函数名、Table 结构化引用和非目标 Sheet 引用保持不变；三维引用和外部工作簿引用当前不迁移，原文保留。

## 3. 安全边界

实际写回仍仅接受 `axis=row`。受保护目标 Sheet、普通拆分窗格、批注/Legacy Drawing、嵌入对象、数据透视表和未知扩展结构在写入前明确拒绝；完整删除 Table 或全部冻结范围也会取消事务。Table 创建、改名、列结构和汇总规则不属于本事务，整列写回仍未开放。

这些拒绝是阶段性兼容边界，不是静默丢弃。通过前置检查后，非目标工作表 XML 只进行相关公式迁移，其他包部件保持原样。公式缓存不会在本事务内重算，未来 UI 接入必须在提交后触发现有重算链路或明确等待 Excel 重算。

## 4. 验收证据

- 行插入后，目标 Sheet 的行号、单元格坐标、公式范围、跨 Sheet 公式、绝对定义名称及工作表内范围载体同步迁移。
- 对同一区间执行删除可恢复原坐标与引用。
- 冻结窗格、选择状态、合并、筛选、验证、条件格式和超链接有直接 XML 回归；冻结、合并、筛选和验证另有真实包语义重读。
- 真实包回归覆盖 Table 范围、图表系列公式和 Drawing 锚点；直接 OOXML 回归覆盖计算链 Sheet 上下文及删除条目后的继承修复。
- 完整范围对象删除会同步父节点计数；列事务、完整 Table 删除、透视/批注等拒绝边界和旧文件签名均有失败路径。
- 输出包通过重新解析与工作簿检查；新增 Tauri 命令已注册到桌面端 invoke handler。
