# v1.0.5 发布交接

`v1.0.5` 已发布：<https://github.com/Longyuyeee/Long_MarkDownReader/releases/tag/v1.0.5>

当前 `main` 包含 1.0.5 产品源码、全面更新后的 README、发布说明、安装包审计和远端下载复核回执。NSIS、MSI 与 `SHA256SUMS.txt` 已上传并验证一致；本版为 `NotSigned` 社区版，Windows 可能显示未知发布者提示。

接手后先观察真实安装反馈，不要重复发布 1.0.5。重点验证 v1.0.4 手动迁移到 v1.0.5，以及后续更高版本通过 GitHub Release + SHA-256 自动更新的端到端流程。本机因已有 LongEdit 实例运行，未强制关闭用户进程执行 1.0.5 安装生命周期，因此该项仍是明确的残余验证边界。
