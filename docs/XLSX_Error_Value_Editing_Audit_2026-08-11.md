# XLSX 错误值编辑审计

审计日期：2026-08-11
当前版本：`1.0.6`
结论：**受限能力已完成，未扩大为完整 Excel 等价声明**

## 交付内容

- 工作簿公式栏、单元格双击、清空、撤销/重做和批量粘贴现在可编辑七种经典 Excel 错误值：`#NULL!`、`#DIV/0!`、`#VALUE!`、`#REF!`、`#NAME?`、`#NUM!`、`#N/A`。
- 保存端使用 OOXML 错误单元格类型 `t="e"`，继续经过工作区路径约束、源签名冲突保护、数组区域保护、数据验证和原子写入。
- 保存后由当前 Calamine 读取引擎重新打开，逐格验证错误类型和值；普通文本、公式和未修改部件沿用既有工作簿事务边界。
- 公式缓存为错误值时仍可编辑原公式；未知或现代扩展错误不会因为显示为错误而自动取得写权限。

## 明确边界

- `#GETTING_DATA` 虽存在于 OOXML 标准集合，但当前读取引擎会在复读时拒绝，因此后端主动拒绝其类型化写入。
- `#SPILL!`、`#CALC!` 等动态数组错误和未知扩展错误不在本阶段白名单内；输入到普通单元格时只会作为普通文本，不会伪装成 Excel 错误类型。
- 本阶段不改变动态数组写回、公式缓存持久化、宏、外部链接和完整 XLSX 等价边界。
