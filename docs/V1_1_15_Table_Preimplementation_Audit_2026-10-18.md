# v1.1.15 轻量表格接续预审

本预审始于 v1.1.14 修正候选 e4650640 的固定包验证期间。现1.1.14已完成独立同包39089429186、封板main CI39090394053及原包发布/公开回下载39090908220，公开/运行时1.1.14，下一目标1.1.15；1.1.15尚未实施。以下从实际代码缺口接续，不将规划当作已实现或安装验收。

## 已具备的能力

`src/views/TableView.vue` 已有虚拟表格、逐格编辑、表头编辑、筛选/排序/冻结列、行增删与撤销/重做，以及开放 Table 的看板、图表、仪表盘等视图。`src-tauri/src/commands/table.rs` 已读写 CSV/TSV 和开放 Table，保存校验内容签名并保留编码、BOM、换行与分隔符；内部 Table 格式在 `formats/table.rs` 中有版本、行列身份与形状约束。不能把这些换名重做。

现有 `tableSaveOwnership.ts`、`table-save-lifecycle` 与实际页面测试已保护保存期间的新输入、失败草稿、跨实例保存/读取等接续。继续复用，不以“先清草稿、重载再试”避开冲突。Table 导出目前要求先保存修改，原生另存递增新文件名；CSV/TSV 可显式创建 Table 副本，不能误称源 CSV 已变成数据库。

## 代码观察和需要先复现的缺口

1. 单元格直接 `editCell` 更新正文；现有 `RowHistoryEntry` 的历史主要是新增/删除行，工具提示也明确写着“撤销行操作”。没有表格级矩形选择、跨格剪贴板解析与整批粘贴撤销链路。先从真实剪贴板复制三列多行，观察当前输入控件的结果，再确定最小修改，不将代码观察写成已证实的数据丢失。
2. 筛选/排序以 `filteredIndices` 映射到底层行，虚拟窗口只渲染部分行。粘贴和删除必须绑定稳定行列身份，不能将可见序号当真实下标，误写隐藏行或排序前的位置。新粘贴超出可见结果的语义先说明并给界面示意。
3. CSV/TSV 已有原生预算（32 MiB、20万行、512列、单元格100万字符），内部 Table 为64 MiB；前端批量操作需要独立的单次预算和可撤销快照预算，不能复制20万行对象造成卡顿。
4. CSV/TSV 和 XLSX 导出需核对引号、内嵌换行、制表符、空尾列、中文与数字外观文本（如00123、长编号、日期样式文本）。对 `=、+、-、@` 起始的文本，应先验证当前写入与外部软件解释，不静默加引号或改变用户原值来“通过”。

## 实施顺序

1. 用现有真实 Table 页面建立基线：中文任务表、三列剪贴板、混合空格/引号/换行、筛选后粘贴、排序后撤销、保存中继续输入和外部改写。生成/授权样例，保留原失败。
2. 在原表格内设计矩形选区与受限批量编辑，先给示意并实看，不添加另一套常驻配置面板。明确编辑单格和操作表格时的快捷键区别，保留看板/图表等原入口。
3. 统一编辑事务：按稳定身份记录受影响单元格、必要新增行列和视图连续性，批量操作可一次撤销/重做。取消和超限不部分改写，筛选隐藏行不被暗中修改。
4. 深化真实剪贴板导入与导出边界，保留原编码和可靠保存、冲突反馈。导出当前草稿还是已保存正文要明确，不增加代存；需要变化则先解释并修正文档。
5. 宽窄、六风格、键盘与正常动效实际页复验；固定样例记录大表粘贴/筛选响应。原生文件重开与相同安装器历版回归通过后才封板、发布和公开回下载。

## 收口场景

“从常用表格软件复制三列任务，粘到筛选后的当前表，发现贴错能整批撤销；重新编辑后保存，关掉重开，中文、空值、编号和各视图仍正确。”

原资料与未选择行摘要保持，取消/错误不隐藏，保存中输入和冲突仍受保护。源码、组件模拟接口、原生磁盘与安装态证据分层记录。不扩成完整 Excel；现有 XLSX 高频工作仍由下一既定 v1.1.16 接续。
