# F1 只读预检编辑预览接入审计

2026-10-11，接续 `d85db0b2`。本步接入现有 preflight_archive，不新增执行命令、不修改 UI、不写回正文。

## 实现

完成结构、历史、依赖检查后，为整个请求生成 editPreview 回执。只从本次各项依赖报告收集候选；任何项目缺报告则整批预览明确阻塞，不悄悄跳过。候选和影响记录合计超过 20000 项时拒绝生成，避免批次重复证据无限放大。

按来源路径去重读取，限定在资料库内，检查普通文件及路径组件符号链接、规范路径一致性；单文件 2 MiB、读取总计 32 MiB。读取以元数据长度加一封顶，检测长度变化，拒绝非 UTF-8。随后用既有扫描摘要核对整篇正文；缺失或变更的来源不输出该文档的部分预览。读取错误同时保留具体来源信息。

回执含 documents、blockers、canExecute，字段使用 camelCase。已有草稿/历史/结构等问题保留批次阻塞；canExecute 始终 false，不把预览等同归档授权。聚合期间累计预览内容上限 32 MiB，超限文档不给正文并说明原因。

## 验证

新增 3 项真实临时目录测试：归档预检生成附件相对路径预览、序列化字段正确且原文/目标不变；缺失报告及扫描后正文改变明确阻塞；读取预算、非法 UTF-8、库外来源被拒绝。

验证命令：`cargo test --locked --manifest-path src-tauri/Cargo.toml --lib archive -- --nocapture`。最终 78 passed / 0 failed，本轮新增 3 项，总数含名称筛选附带的既有压缩包测试。`git diff --check` 通过。未降低既有断言。
