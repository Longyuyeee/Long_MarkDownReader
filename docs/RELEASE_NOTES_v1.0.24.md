# v1.0.24 稳定性修复

- 首次启动自动准备默认知识库；目录不可用时可重试、重新选择或主动创建目录。
- 全局错误改为可关闭提示，保留页面操作；新建知识库支持创建多级目录。
- 统一窗口关闭、系统关闭与托盘退出，保留临时文档并保护各编辑器未保存内容。
- 快速笔记防止重复保存；自动更新安装前检查其他窗口和本地编辑器的草稿。
- 搜索结果显示来源路径，便于辨别同名文件；图谱图例占独立空间，减少文字遮挡。
- 修复 Word / PowerPoint 预览临时副本的并发重名问题，避免偶发“文件已存在”错误。
- Markdown 正常保留正文动效；检测到持续卡顿时自动降低当前文档的装饰动画和模糊效果，忽略加载瞬间与后台掉帧，切换文档重新评估；隐藏大纲时停止扫描正文。
- 修复在文件资源管理器中定位文件及使用系统应用打开媒体的权限错误，失败时保留可操作的页面提示。

社区未签名版本，Windows 可能显示“未知发布者”；安装包以 SHA-256 校验。自动更新仍使用官方 Release。
