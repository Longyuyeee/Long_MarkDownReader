# A0L CodeMirror 主题合同审计

日期：2026-08-04

对应需求：UX-24、UX-27

结论：代码侧已完成，等待下一安装包复测。

## 本步完成

- TXT/代码、JSON、YAML、XML、TOML 和 LOG 六个工作区改用同一份 CodeMirror 主题扩展，不再各自依赖默认光标、选区或提示层颜色。
- 九个应用主题均声明编辑器背景、正文、行号、光标、选区、搜索匹配、括号匹配、面板和提示层颜色。
- 语法高亮覆盖关键字、字符串、数字、注释、函数、变量、属性、类型、运算符、链接和无效内容；深色主题明确使用白色光标，高对比主题使用金色光标。
- 共享扩展只改变显示层。各格式原有的解析、诊断、只读、撤销、保存确认和源文件写入边界保持不变。

## 自动门禁

- `check:code-editor-theme-contract` 检查九套主题完整覆盖，语法文字与行号达到 4.5:1、光标达到 3:1 对比度。
- 门禁确认六个工作区均接入共享扩展，且没有残留私有 `EditorView.theme`。
- 专项门禁已接入 `ci:patch-release`。

## 安装包复测

1. 在浅色、深色和高对比主题分别打开 TXT、JSON、YAML、XML、TOML，确认输入光标始终清晰且主题实时切换后仍正确。
2. 验证选区、当前行、行号、搜索命中、当前搜索项、匹配/不匹配括号、折叠占位符与搜索面板均可辨识。
3. 使用包含注释、字符串、数字、关键字、属性和错误语法的样本，确认彩色高亮清晰但不遮挡正文。
4. 分别执行撤销、重做和保存，确认本次显示层调整没有改变“点击保存才写入源文件”的合同。

下一步：按需求顺序处理 UX-25、UX-26、UX-28，改善 JSON Path 的用户说明、为大型 JSON 树建立有界渲染，并把结构化编辑器的视觉与交互继续统一。
