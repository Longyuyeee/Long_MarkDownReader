# v1.3.0：基础功能与全界面收尾

汇总1.2系列的阅读接续、PDF批注、表格与JSON/XML/YAML/TOML编辑深化，并复查全部页面的空间、风格和操作。

- 历史入口一致：从文档菜单、侧栏历史或源码页头打开，都交给当前文件自己的比较器；所选版本可直接比较，取消保留草稿，恢复后可立即撤销。
- 结构化编辑器直接显示“历史”，减少重复菜单和点击；差异与历史恢复按钮固定在弹窗底部，小窗口可滚动查看长内容。
- 保留全部既有功能、六种界面风格、正常动效和默认单侧导航；主页面没有增加常驻介绍和操作。
- 修正中文显示名乱码；继续保护未保存内容、保存期间的后续输入及外部冲突副本。

44个页面及子页面、1056组整窗布局、864组参考区入口、新历史100项任务通过。完整发布检查、Rust1454项功能和1项性能、83组/773项安装版功能任务及新增历史入口详细断言通过，NSIS、MSI和SHA256SUMS.txt三份公开附件已重新下载核对。

未签名社区版，可手动下载安装。NSIS完成实际安装、手动升级和卸载；MSI完成构建与摘要核对。应用内1.2.45→1.3.0自动更新实际观察独立待完成。YAML多行映射字段删除仍为后续1.3.1规划，尚未实现。
