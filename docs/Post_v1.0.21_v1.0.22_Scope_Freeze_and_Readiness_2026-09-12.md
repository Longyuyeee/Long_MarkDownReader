## 范围与原需求

对应主 PRD 1.1 的日常文件查找、定位和可信反馈。已复读 LibraryMode 搜索调度/生命周期/卡片布局、SearchFeedback 和 Rust 标签搜索，以及两个桌面验收记录。本版冻结为以下两项，不新增搜索引擎、索引格式或图谱特性：

1. 搜索失败与成功空结果分离；重试保留查询；防抖、切库、清空、卸载时隔离过期响应；标签根目录不可读明确失败。
2. 紧凑搜索结果标题、命中信息与关系入口分行；标题最多两行、完整名称可访问，打开行为不变。

上述均为既有能力补强，没有偏离本地优先、安全保存主线。不涉及正文写入，不调整 43 类格式 / 91 扩展名的支持等级，更不代表完整 Excel 等价能力已经完成。
