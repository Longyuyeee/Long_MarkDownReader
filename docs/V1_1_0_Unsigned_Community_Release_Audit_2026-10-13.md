## 本版功能

- 全界面改版，保留现有格式与编辑能力；资料库、工作台、图谱、设置使用统一导航。
- 顶栏文档标签稳定排序；文档改名、编辑模式、正文宽度、导出和历史等入口更直接。
- 快速笔记直接选择保存位置，命名工作会话、智能集合、Markdown 历史差异与安全恢复。
- 多种界面风格与字体/排版自定义；文件样式、选中态和目录层级更清晰。
- 修复专注布局、Vditor 空代码预览异常、参考区查找、浮窗闪烁、文件夹展开跳动及文件点击闪烁。
- 路径暂不可用可重试；重新读取失败保留未保存草稿，不报虚假成功。

## 明确边界

- 纯文本历史差异和网页正文采集未包含于本次发布；下一版再评估。无额外强制归档步骤。
- 43 类格式边界未提升；Office/PDF 不因改版变成完全编辑器。
- 未签名安装包可能出现“未知发布者”或 SmartScreen。只从官方 GitHub 下载并核对 SHA-256。
- 应用自动更新需用户确认；候选覆盖安装不等于官方应用内自动更新观察。也可手动下载安装。
- MSI 的构建和摘要检查不等于 MSI 安装生命周期；NSIS 升级生命周期在独立 GitHub Windows runner 执行，不覆盖本机真实资料库。
