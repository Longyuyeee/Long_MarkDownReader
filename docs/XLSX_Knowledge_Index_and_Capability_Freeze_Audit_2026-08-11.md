# XLSX 知识索引与能力范围冻结审计

审计日期：2026-08-11
当前版本：`1.0.6`
阶段结论：**能力范围已冻结，下一阶段仅进行版本验收与发布收口**

## 本阶段完成

- XLSX 已接入资料库持久索引和索引未就绪时的实时回退搜索，按工作表生成可定位的正文片段。
- 搜索结果携带工作表名称；点击结果会打开对应工作簿并切换到命中的工作表，重复点击同一结果也会重新定位。
- 索引只读取工作簿内已缓存的单元格值，不执行公式、不刷新外部数据、不写入源文件。
- 资源预算固定为 128 MB 文件、4,096 个压缩条目、256 MB 总展开量、500 倍压缩比、64 个工作表、50,000 行、每行 256 列、250,000 个非空单元格和 2,000,000 字符；超过边界时有界停止或拒绝。
- 真实 `compatibility-baseline.xlsx` 验证 Summary/Details 工作表和对应内容可检索，索引前后源文件字节保持一致。

## 需求对齐

- **专业知识工作台**：XLSX 不再只是独立编辑器，工作簿内容现可进入统一资料库搜索，并能回到具体工作表。
- **完整 Excel 方向**：错误值、日期时间和本地工作表索引已经形成有界闭环；宏执行、外部数据刷新、复杂透视对象写回仍保持明确边界。
- **新格式编辑器**：当前 43 类格式和 91 个扩展名已经覆盖既定场景，本轮不为数量扩张未经验证的格式创建入口。
- **更多主题预设**：3 套核心、4 套场景预设和 19 个外观组合已由统一注册表管理；没有新的真实使用场景，本轮不重复增加近似预设。

## 范围冻结

本机可独立完成的能力增量至此冻结。以下内容不阻塞本轮收口：

- Excel/WPS/LibreOffice 三生产者动态数组写回继续等待外部生产者证据，保持 fail-closed。
- 复杂透视对象和外部数据连接只在获得真实样本、生产者复读证据及不破坏源文件的实现路径后再开启。
- 新格式创建入口需要先定义扩展名变体、模板内容和安装态证据，不在发布前临时扩张。
- 企业 Authenticode 签名仍属于外部条件；社区版继续采用公开哈希校验和显式更新确认。

## 接手后的唯一阶段

下一步进入最终版本验收：提升补丁版本 `0.0.1`，同步 package/Cargo/Tauri 与发布事实源，全面更新 README 和 Release Notes，运行补丁发布质量门，构建并复核 MSI/NSIS，发布 GitHub Release，最后验证安装、启动、应用内检查更新和覆盖升级。

除非验收暴露可复现回归，不再插入新的能力阶段。
