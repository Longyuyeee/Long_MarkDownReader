# 1.1.0 PDF 界面重构：第一步

日期：2026-10-12。基于 `a37de4a5`，继续 `codex/v110-editor-shell` / PR #48；本轮不升版、不封板。

## 范围和实际发现

按已确认的 R2 阅读与 Office 方案实现 PDF 工具分组，不删除既有能力。本轮是 PDF 顶部工具和窄窗入口的第一步，不代表全 PDF 或全界面改版完成。

实际运行生产 `PdfView` 和 PDF.js，打开仓库中的两页测试 PDF 后发现：原工具行在 1280px 下搜索与缩放已被挤出可视范围；旧样式在 760px 以下直接隐藏适宽、百分比和部分工具按钮。修改前截图保存在 `evidence/v110-pdf-redesign/00-before.png`。

## 功能映射

| 入口 | 处理 |
| --- | --- |
| 阅读 | 搜索/上下一命中/清除、缩放/100%/适宽保持在阅读工具行；翻页和页码输入保留，补输入无障碍名称 |
| 批注 | 原区域批注、页评论保留；增加批注列表的直接入口；选中文字高亮、颜色、引用、编辑/删除和保存逻辑不变 |
| 页面 | 原页面整理面板入口保留；提取/合并/插页/旋转/重排、撤销重做、验证和副本输出逻辑不变 |
| 文档工具 | 原表单、属性、永久脱敏、文字水印、OCR 按钮及处理函数全部保留 |
| 侧栏 | 九个原有标签保留，三列排列，避免文字拥挤；本轮未迁移侧栏到右侧 |
| 外部 PDF | 继续只读，不开放写入工具，只保留缩略图和目录标签 |

宽窗两行、窄窗三行；空间不足时工具行内部滚动，按钮和文字不被隐藏。切换分组回到工具行开头，避免阅读搜索停留在滚动范围之外。使用现有主题变量，PDF 原文不随主题变色。

## 验证与证据边界

- `scripts/test-pdf-redesign-browser.mjs`：六组真实组件浏览器交互通过；覆盖两页真实 PDF 渲染、搜索、翻页、缩放/适宽、页评论输入、区域模式、页面整理入口、五个文档面板、属性读取失败提示、736/480px 操作和外部只读。
- 实际查看宽窗阅读、文档工具、480px 窄窗、深色截图。无根页面横向溢出；100% 大页面在窄窗内滚动是原有阅读行为，不强制改变用户缩放。
- `vue-tsc --noEmit` 和 `npm run build` 通过。四项表单/属性/水印/脱敏静态契约通过；UX-38D1 历史契约通过，其布局结构断言更新为当前分组和滚动结构。
- UX-38D1 的原生证据仍属于旧提交，不冒充本轮验收。本轮夹具使用模拟 Tauri IPC，表单使用无表单响应、属性使用失败响应；没有模拟成功导出，也未执行真实 OCR、表单写入或 PDF 副本输出。
- 浏览器证据：`evidence/v110-pdf-redesign/`，结果中明确 `releaseCandidate: false`。复现需启动 Vite 9000，并设置 `LONGEDIT_PLAYWRIGHT_MODULE` 为可用 Playwright 模块路径后运行脚本。
