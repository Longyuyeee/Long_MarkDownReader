# 移动端：恢复核对、完整预览与取回结果

2026-10-28，阶段5D2，起点 `775fe6351`，沿用 `codex/mobile-0.1.0-foundation`。按[一次推进一个用户任务的规则](Development_User_Task_Plan_2026-09-22.md)，本轮处理“先看清这份恢复内容，再决定存到手机还是导出”。仅修改移动工作树，仅本地提交。

## 改前实测与竞品依据

[改前正式App报告](evidence/mobile-recovery-review-task-2026-10-28/before/report.json)显示版本按钮、完整正文、另存与导出同时展开。320px、200%文字下，滚到另存处已移动约700px；320×346短屏中导出按钮仍超出视口。返回页头原本已经固定，继续复用，不记为新增缺陷或能力。

本轮查阅[Notion恢复说明](https://www.notion.com/help/duplicate-delete-and-restore-content)：手机从侧栏菜单进入垃圾箱，先打开页面检查再恢复；历史版本先选择再恢复或复制部分内容，详细版本比较在移动端不可用。参考其先检查再决策的顺序，不声明本项目支持移动端差异比较。[Obsidian文件恢复说明](https://obsidian.md/help/plugins/file-recovery)按文件和快照逐步选择，复制与恢复分开；快照保留本机完整版本。参考版本选择和独立副本的意图，未安装或录制竞品。短弹层、固定操作、返回与逐版本现场保持是本项目设计判断，官方资料未证明其精确手机返回和重试行为。见[来源记录](evidence/mobile-recovery-review-task-2026-10-28/research-sources.json)。

## 用户操作与返回

| 当前任务 | 页面与动作 | 返回后保留 |
| --- | --- | --- |
| 核对恢复记录 | 文件身份、当前版本、完整预览入口、存入位置和完整记录导出入口；底部固定“存入手机资料库” | 原记录、原任务与原草稿 |
| 选择版本 | 仅两个版本的短弹层；背景不可操作，取消、遮罩、Escape或当前返回只关闭这一层 | 返回版本入口，尚未选择时不改变当前版本 |
| 查看完整内容 | 独立预览页；普通文字完整只读，超长内容继续复用既有分段与查找 | 各版本分别保留DOM、选区、滚动、查询及未应用跳转输入 |
| 导出完整恢复记录 | 独立核对文件和包含版本，再执行下载／选择保存位置 | 成功、取消和失败属于同一导出任务，返回核对仍保留真实结果 |
| 存入副本后打开失败 | 明确“副本已存入”，主操作变为“打开已存副本” | 重试同一个副本，不重复创建；切换版本不显示另一版本的副本错误 |
| 刷新读取失败 | 保留上次读到的版本；固定同编号重读，缓存版本另存放在正文行 | 核对、预览现场及上一轮读取保护继续保留 |

预览和导出各自返回核对，核对再返回原列表／原任务，逐次只消费一层。等待读写或导出回复时阻止重复动作和离开。深历史列表恢复原滚动与焦点。来源不可用不阻止读取已有本机恢复记录。

常驻页面保留实际版本、目的地、字节量、操作结果和写入未确认风险；一般解释继续使用问号。完整恢复记录导出明确包含所有已存版本，不随当前选择偷偷缩减。纯导出恢复记录不显示不存在的原文版本或源文件写入警告。浏览器只说“已开始下载”，不声称外部文件已验证。

## 设计冻结和实页核对

生产修改前冻结14状态的Vue／HTML／PNG。v1审图发现旧全局样式限制预览高度、成功结果仍用警告色、缓存失败时双固定动作挤占短屏，先冻结v2修正再接入。实测发现缓存另存入口可见副标题不在读屏名称内，冻结v3补齐；v3也保留切换版本清理外来副本错误的修正。v3全部PNG与v2逐字节相同；各版本哈希继续保留，未覆盖旧图。

[设计／实页对照](evidence/mobile-recovery-review-task-2026-10-28/comparison.html)中20张最终实页及3张改前图均逐张查看，原图未加工，键盘焦点保留。14个对应状态的坐标、尺寸、字号、行高、颜色最大差0px。读取失败、暗色、窄屏和短屏四张实页在真实下载后保留“已开始下载”，与新任务设计的“包含2份完整版本”有8个名称差异，已[逐项注明](evidence/mobile-recovery-review-task-2026-10-28/visual-comparison.json)；不声明所有文案或整图像素相同。

保留[首次版本错误串页](evidence/mobile-recovery-review-task-2026-10-28/first-failure-foreign-version-copy-error.json)及原图、[缓存副本名称不匹配](evidence/mobile-recovery-review-task-2026-10-28/first-failure-cached-copy-accessible-name.json)及原图。旧回归中的导出精确名称和内联长文预览假设也保留失败报告、原图；迁移为实际版本弹层、预览子页及导出子页操作后，保留原有内容与草稿断言。
