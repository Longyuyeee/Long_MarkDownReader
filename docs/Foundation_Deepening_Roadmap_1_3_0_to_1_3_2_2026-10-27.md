# 1.3 系列：接续基础能力，统一操作体验

本轮用户授权：先审计近期全部功能和页面，符合规范后升一个 0.1 版本。1.3.0 已完成整体收尾并正式发布；旧规划 1.2.46 未实现，也未被计为交付。

| 版本 | 用户结果 | 状态 |
| --- | --- | --- |
| 1.3.0 | 审计 1.2.0—1.2.45 与全部页面；修正历史入口、恢复焦点、弹窗空间和显示名 | 已发布并核对公开附件 |
| 1.3.1 | YAML 普通映射的多行字段整体删除，保留注释、原文、空映射身份和草稿 | 规划，接续原 1.2.46 |
| 1.3.2 | 依据真实使用问题继续统一结构化编辑入口与键盘操作；重点复查右键/定位/撤销的闭环 | 方向，具体范围先看代码与用户任务，不提前承诺未支持结构 |

交互继续沿既有右键和按需弹窗，不新增面板堆叠或页面说明。每版都保护未保存正文、迟到结果、保存重试和外部冲突；性能随版本持续处理，不以取消动效作为默认优化。

1.3.1 的范围：普通 `|` / `>`、chomp、显式缩进、BOM/EOL、空文本和唯一字段；保留独立注释及段落原文，删除后定位相邻字段或父映射。锚点、别名、标签、复杂键和含糊集合继续局部源码入口，不为补齐按钮冒险改写。原生读写与界面任务分别验证。

发布记录见 [1.3.0 审计](V1_3_0_Unsigned_Community_Release_Audit_2026-10-27.md)。
