# P1-B4D PDF 文字水印真实桌面与独立渲染审计

审计日期：2026-08-16
阶段状态：已完成并接受证据

## 1. 阶段结论与需求对齐

P1-B4 已完成收口。资料库内 PDF 能在初版左侧 Tab + 右侧编辑区结构中配置全页面单条中文矢量文字水印，先生成并复读验证，再可靠另存为新 PDF 并在同一管理工作流复开。外部 PDF、源文件覆盖、已有目标覆盖、签名/加密/PDF-A 和不受支持页面结构继续阻断。水印明确定位为可见归属，不宣称 DRM、不可移除或永久脱敏。

## 2. 真实桌面工作流

使用真实 Tauri WebView2、真实临时资料库和两页 PDF 完成：打开源文件、进入原 `PdfView` 水印侧栏、输入“项目机密 P1B4D”、设置 -33°/24%/35% 参数、验证水印副本、确认风险、另存新目标并复开。离开草稿时真实确认框包含“文字水印参数”且路由保持。1280×800 与 720×680 下侧栏宽度均为 299 px，页面无文档级横向溢出，操作区保持在原右侧工作区；全过程零 WebView 运行时错误。

## 3. 独立输出验证

独立工具链为 pypdf + Poppler + Pillow，不复用产品复读结论。验证结果包括：源 SHA-256 前后相同；目标两页均可提取完整中文水印；原页面文字保持；纵向 A4 与横向 Letter 的 MediaBox、CropBox、旋转保持；链接批注数量与标题/作者/主题元数据保持；目标 trailer 不含增量更新 `/Prev`；Poppler 144 DPI 两种比例均渲染成功，水印像素差异超过阈值且包围盒没有触及页面边缘。

## 4. 视觉复核

宽屏草稿与验证态沿用现有工具栏、Tab、提示卡、紧凑字号和 300 px 侧栏，不形成新页面或第二套视觉体系。窄屏中侧栏完整可滚动，PDF 画布维持既有横向查看行为。保存复开截图显示两页缩略图和画布均加载；Poppler 输出中灰色中文水印在纵向与横向页面上清晰、居中、无裁切，原黑色文字、蓝色链接和橙色图形仍可辨认。

## 5. 能力边界与下一步

当前水印能力仍限定为资料库内、全部页面、单条居中斜向文字和自动字号；平铺、图片水印、页眉页脚、页面子集、模板及外部 PDF 写入不在首批安全子集。下一步进入 P1-B5A，先冻结元数据副本的隐私语义、Info/XMP 一致性、允许字段、删除边界、签名/PDF-A 阻断和独立复读标准，审计完成前不开放元数据写入。
