# 1.1.0 日常工作界面重构

2026-10-12。接续用户已批准的 [R2 全界面方案](design/v1.1.0/full-ui-redesign-r2/README.md) 和 [R3 外观与显示调整](design/v1.1.0/full-ui-redesign-r3/README.md)。本批围绕继续工作、查找资料、参考摘录和快速记录整理功能位置，保留现有命令及保存行为。

## 已实施的功能位置

| 界面 | 用户常用操作与保留内容 |
| --- | --- |
| 全局导航 | 主窗口左侧提供工作台、资料库、收集箱、图谱，底部设置。窄窗口改为顶部一行。外部窗口、快速笔记和专注模式保持各自布局；仅在全局导航出现时隐藏资料库/工作台的重复快捷入口，原路由和命令仍保留。 |
| 工作台 | 先显示当前资料库、上下文新建和打开文件，再显示工作现场、固定/最近文件和待办。状态、目录、日期、优先级筛选，完成确认与撤销保留；常用视图仍可直接打开。资料整理与关联队列放进有名称的展开区域，原处理动作和反馈保留。新建补齐注册表中的其他可创建格式。 |
| 工作现场 | 自动恢复、命名保存和继续工作放在同一张卡片；新增可见的管理现场按钮，原右键/Shift+F10、重命名、仅删除记录及错误提示保留。 |
| 智能集合 | 名称和关键词在上方，目录、格式、文内标签和修改时间归入查找范围。查看/刷新、保存常用搜索、保存修改和新建其他集合保留；结果显示格式、位置、路径及正文上下文。 |
| 搜索与参考 | 搜索结果补充格式范围说明。参考区将来源、刷新、返回编辑和取消来源放在顶部，摘录插入/复制放在正文附近，打开原文件在底部。没有选择时仍显示操作及提示。关闭参考或返回编辑只收起面板并保留来源；明确点击取消来源才清除。既有搜索范围、索引状态、原文打开、选择/剪贴板及插入逻辑保留。 |
| 收集箱 | 新增独立 `/inbox` 页面，复用现有目录浏览器；快速笔记、收集目录设置、路径、进入子目录、返回上级、刷新、错误重试及按原格式打开文件均可达。资料库侧栏原收集箱仍可用。没有资料库时提供管理资料库入口，未增加强制归档。 |
| 快速笔记 | 保存到哪个资料库和目录放在正文上方，模板放在书写区旁，丢弃、保存后三种动作和保存放在底部。选择其他目录、位置记忆、草稿、失败保留与重试、窗口拖动及关闭沿用原实现。 |

原功能清单中的 27 个路由页面全部保留，本批新增收集箱后为 28 个。专用格式页面尚未全部重新布局；不能把共享导航接入视为这些页面已经重构完成。

## 风格和内容显示

19 套预设、10 个色调选项（含系统）、soft/neo/glass/airy/minimal/sharp 六类风格和四类动效设置全部保留。新界面使用现有主题令牌，并随风格调整圆角、阴影、边界、留白和列表密度。未增加持续动画或全屏模糊，也未强制降低动效。

工作台文件行和收集箱接续文件密度、平面/卡片行、彩色/单色图标设置；参考文字和快速笔记接续文档字体、字号、行距。PDF/Office 等专用文档的正文仍保留原格式排版。公共控件继续跟随当前主题及风格。
