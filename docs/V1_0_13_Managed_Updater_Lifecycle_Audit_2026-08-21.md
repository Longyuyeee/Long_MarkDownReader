# v1.0.13 托管更新生命周期审计

## 目标

在 GitHub 托管的一次性 Windows 主机上，仅使用公开 `v1.0.12` 与 `v1.0.13` Release 安装包，验证应用内更新的用户确认、SHA-256、覆盖安装、自动重启、版本确认和资料保留。

## 当前差异

- `v1.0.13` 已发布且远端附件复核通过，但 `1.0.12 -> 1.0.13` 官方更新观察仍为 pending。
- v1.0.14 发布合同要求上一公开版本的更新链先通过真实托管 Windows 验证。

## 执行合同

- 工作流只从官方 Release 下载两版 NSIS，不使用当前源码临时构建替代。
- 下载前后核对 Release 状态、Tag、目标提交、文件名、大小和 SHA-256。
- 更新器必须先显示确认界面；用户确认前不得下载或启动安装器。
- 安装覆盖原目录并由更新助手自动重启；测试脚本不得手动启动新版冒充自动重启。
- 更新后必须显示 `v1.0.13` 且报告已是最新版；覆盖与卸载后合成资料库、配置均须保留。
- 证据不得包含真实用户文档、完整用户路径、凭据或机器身份。
