# M3C-4 大图性能退出审计（2026-08-28）

## 1. 结论

M3C-4 已通过，M3 知识图谱 2.0 在语义探索、专业视觉和大图性能三条独立验收线上完成收口。真实 Tauri/WebView2 使用只读 Markdown 链式资料库完成 100、1,000、5,000 节点测试；稳定绘制均为 `0 次/秒`，稳定空闲长任务均为 `0`，运行时错误为 `0`，源文件摘要不变并可返回资料库。

当前阶段前移到 **M4-0 跨格式工作流与版本候选入口审计**。这只是范围冻结入口：运行时与公开版本仍为 `1.0.15`，开发目标仍为 `1.0.16`，`releaseCandidate=false`，不得提前提升二进制版本。

## 3. 真实导出证据

导出由产品按钮打开 Windows/Tauri 原生保存对话框，并由桌面自动化真实提交路径，保留动态文件系统授权、生产 SVG/PNG 生成和文件写入链；没有通过页面注入绕过保存权限。

| 范围 | 格式 | 事实计数 | 耗时 | 文件结果 |
| --- | --- | --- | --- | --- |
| 完整 5,000 图 | SVG | 5,000 节点 / 4,999 边 | `36,794ms` | `6,916,219` bytes，元数据与标记精确、几何有限 |
| 完整 5,000 图 | PNG | 同一可见图 | `31,101ms` | `6,255,432` bytes，`2816×2916`，PNG 签名有效 |
| 社区过滤图 | SVG | 72 节点 / 71 边 | `31,861ms` | `99,887` bytes，元数据与标记精确、几何有限 |
| 社区过滤图 | PNG | 同一可见图 | `31,366ms` | `612,419` bytes，`2168×1902`，PNG 签名有效 |

完整与过滤 PNG 均已人工查看。完整 5,000 节点图在静态全量导出中仍然稠密，过滤社区可读性明显更好；大图视觉重设计、视口裁剪和标签缓存仍属于显式延后项，不是本阶段性能与事实导出合同。

## 4. 预期—实际差异及修正

| 原预期 | 真实实际 | 修正 |
| --- | --- | --- |
| 生命周期轮询总能看到短暂 `running` | 快速 Worker 可能在轮询前完成 | 改为记录真实 `postMessage` 作业数，活跃取消另设独立探针 |
| 返回路由不保留任何监听器 | Markdown 编辑器合法拥有一个 `keydown` | 比较首次返回基线与 20 次后的监听器类型，而不是和空页面比较 |
| 全局所有剖析阶段都属于一秒视觉预算 | `build-link-graph` 是首次可见的独立后端构建阶段 | 一秒预算只覆盖明确定义的 Canvas 与社区语义阶段 |
| 5,000 节点 SVG 可先解码为图片再转 PNG | 有效的 6.9 MB SVG 在 WebView2 图像解码时稳定失败 | PNG 改为从同一节点、路由和语义样式直接绘制有界 Canvas；删除失效旧路径 |
| 选择社区后面板自动关闭 | 产品有意保留面板且过滤已生效为 72/71 | 测试再次点击真实社区入口关闭面板，不为适配脚本修改产品行为 |
| 页面注入可代替保存对话框 | Tauri 动态文件授权只随真实对话框建立 | 使用 Windows 原生对话框执行四次实际保存 |

## 5. 需求对齐与边界审计

- M3C-1 的脏帧唤醒、M3C-3 的 Worker 状态、取消和陈旧结果隔离均保持。
- SVG 和 PNG 使用相同的当前可见节点、关系路由、对象语义、颜色、箭头和标签事实；PNG 受 `8192` 单边和 `32,000,000` 像素上限约束。
- 生命周期只清除审计 WebView 的图谱布局键，不触碰真实用户关系或资料库内容。
- 未混入视口裁剪、标签缓存、保存视图、聚类折叠、全屏或视觉重做。
- 本阶段不改变公开能力矩阵和版本号，不构成 Release 冻结。
