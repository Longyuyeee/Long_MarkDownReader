# Long编辑 v1.1.24

长方案的章节整理更顺手，所有改动先留在草稿中。

- 三种编辑模式接通大纲，重复标题分别定位，随阅读高亮当前章节。
- 大纲右键可移动整节；先预览位置，再连同子标题、表格、代码和图片引用一起移动。
- 提高或降低整节标题层级，支持一次撤销；复制章节链接可在本机笔记间跳转。
- 保留未保存内容、切换文件的阅读位置与既有保存冲突处理；迟到预览不会覆盖新输入。
- 保留六种界面风格和正常动效，没有增加常驻操作面板。

引用或列表内标题可定位和复制链接，结构修改仅对可可靠映射的独立章节开放。极长文档暂停结构修改；多行 Setext 标题暂不跨语法转换。章节链接使用本机绝对路径。

Windows 社区版（community-unsigned），提供 NSIS 与 MSI。NSIS 验证既有安装生命周期；MSI 完成构建和摘要核对。可手动下载安装，真实 23→24 应用内更新观察独立登记。
