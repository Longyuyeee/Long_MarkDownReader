# F1 正文内容校验与重启只读核对

2026-10-11，接续 `eff5fb45`。后端内部步骤；无 UI 修改、无归档入口、无升版。

## 实现

新增 archive_document：流式计算正文长度与 SHA-256，拒绝非普通文件/符号链接及超过 256 MiB 的正文，读取有界，不一次加载整份正文。执行流程在历史准备前计算摘要，document-intent.json 升到 version 2 记录摘要，移动前重检来源，移动后重检目标；变化则停下，若正文已移动，回执仍保留该事实，不回滚覆盖用户后续改动。

inspect_document 从磁盘读取日志，在当前库范围内只读检查来源/目标，限制日志 64 KiB、暂存必须是指定缓存直接子目录。仅源存在且内容匹配返回 SourceMatches，仅目标匹配返回 TargetMatches；两边存在/均不存在分开返回；单边内容变化、类型异常、越界或旧/坏日志报错。日志不作为任意路径写入命令，不自动重试或清理。

## 审计边界

摘要是内容证据，不是文件系统身份锁，不能区分同内容替换，也不能排除校验与移动之间的外部修改。两次读取不是原子快照；仍无跨进程锁、草稿/依赖授权和正文保存互斥。TargetMatches 不代表历史/标签/索引完成。旧 version 1 正文日志缺少摘要，保守拒绝，不猜测升级。

正文上限 256 MiB 是本内部步骤的明确限制，非整个应用的打开/保存上限。没有大文件性能、断电、真实强杀或网络盘验收。无历史文件的事务入口仍未接入，canExecute 仍为 false。
