# 1.3.15 规划：在原文中修正文件链接

当前公开版本1.3.14。本页仅为下一版规划，尚未实现。

打开链接失败后，用户应该能在原文附近修正目标，继续写作。下一版深化已有 Markdown 文件链接编辑，沿用右键和弹窗，先支持普通行内文件链接。

1. 在可识别的正文文件链接上右键提供“更换文件目标…”，扩展现有链接编辑流程。弹窗呈现当前目标，支持从当前资料库查找和选择已支持类型的文件，确认后生成相对当前文章的地址。
2. 默认只改所选链接，保留显示文字、标题与仍有效的章节片段。引用式链接定义、图片引用和代码片段不混入这一轮处理；不能准确识别位置时保持原文并提供现有手动编辑入口。
3. 修改只进入当前草稿，一次撤销可恢复；保存继续由用户主动执行。来源文章、选区或正文在弹窗期间发生变化时，保留输入并重新确认有效位置，避免将旧修改套到新文档。
4. 链接暂时不可用时，在当前位置给出可操作的反馈。已恢复的文件可以再次打开，原有“返回链接来源”和两边的草稿接续继续可用。
5. 保留全部主题、风格、正常动效与大小窗口布局。围绕单处修改、中文与空格路径、章节片段、草稿和撤销、只读来源及失效目标检查实际操作，不新增常驻面板、批量说明卡片或自动保存。

后续再根据实际使用反馈深化引用式链接和其他资源类型，并处理 Markdown 光标行列信息在切换文档后的准确刷新；不将这些尚未实现的内容计入1.3.14。
