# Long编辑 v1.2.9：TOML 配置值编辑

在配置分区中右键一个值，选择“修改值…”即可编辑字符串、布尔或数字。弹窗预选当前原文，输入错误可原地纠正；数组、内联表和日期时间可继续定位到源码编辑，不增加页面操作区。

修复原分析丢失位置的问题，同名分区字段、带引号的点号键和表数组能够准确定位。只替换当前值，保留注释、顺序、换行、长整数和转义。沿现有差异预览进入当前草稿，可一次独立撤销；来源切换、后续输入、保存失败和外部冲突继续保护内容。保留所有现有功能、风格和正常动效。

未签名 Windows 社区版，完整发布检查与 466 项安装版功能任务通过，NSIS、MSI 与 `SHA256SUMS.txt` 三份公开附件已重新下载核对通过。应用内自动更新实际观察仍待完成，与手动安装升级分别记录。
