# v1.2.23：YAML 列表项新增与删除

当前开发目标：`1.2.23`；当前运行时版本：`1.2.23`；当前公开版本：`1.2.22`。当前阶段：**v1.2.23 YAML 列表项新增与删除候选**。

## 用户变化

YAML 提纲的列表右键“追加列表项…”，某项右键“在此项后新增…”，自动接续当前列表，只输入值，差异预览显示实际类型。某项右键“删除列表项…”直接预览。空列表可添加第一项，删除最后一项仍保留 `[]` 列表身份。

先支持普通单行文本、数字、布尔、null 项。分别处理块式缩进／短横线与流式方括号／逗号，保留其他项的顺序、字面量、独立注释、BOM 与换行。行尾注释删除后保留为独立说明；插入位置无法判断注释归属、嵌套集合、锚点、别名、标签、合并键及多文档提供局部说明与源码定位。完整重解析确认只增减目标项，不整体序列化或重排原稿。

应用仅改草稿，可独立撤销／重做，显式保存才写盘。错误保留值，源码定位后可返回输入；组合输入 Enter／229 不提交。保护后续输入、延迟结果、旧预览、文件／资料库切换、保存失败重试与外部冲突副本。保留全部现有功能、风格和正常动效，不增加常驻表单。
