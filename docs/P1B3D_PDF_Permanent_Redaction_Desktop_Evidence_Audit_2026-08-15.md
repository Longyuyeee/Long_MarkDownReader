# P1-B3D PDF 永久脱敏桌面与独立渲染证据审计

阶段结论：**P1-B3 已收口；资料库内 PDF 永久脱敏图片型副本具备真实桌面、可靠另存、复开与独立内容移除证据。**

## 1. 阶段结论与需求对齐

本阶段没有新增另一套界面或扩大写入范围，只验证 P1-B3C 在用户最初要求的“左侧资料库 + 右侧编辑区”中是否真实可用。证据绑定产品提交 `49770b03b852303acf9bb8c26c2d15fb24689e54`；测试只使用合成 PDF，不包含用户内容。

测试源文件包含两页、可见秘密标记 `SECRET-P1B3D-ALPHA-9284`、普通公开文字、链接批注、书签入口和文档元数据。目标必须保留两页与公开视觉内容，同时不得保留秘密文本、可提取文字、批注、表单、书签或源元数据。

## 2. 真实桌面工作流

`scripts/run-p1b3d-pdf-redaction-audit.ps1` 构建真实 custom-protocol Tauri，并在隔离资料库和独立 WebView2 数据目录中运行。CDP 只驱动真实界面：打开原 PDF 工作区、进入“永久脱敏”、用鼠标事件框选秘密区域、尝试离开并拒绝草稿丢弃、生成预验证、确认图片型取舍、可靠另存并等待目标自动打开。

1280×800 与 720×680 均确认脱敏面板嵌入 `.pdf-sidebar` 和 `.pdf-view`，外层横向溢出为 0，草稿、验证状态、取舍确认与保存入口可达。离开草稿时出现包含“永久脱敏框选”的统一确认，拒绝后保留当前工作区。保存后目标在同一资料库右侧工作区自动打开，两页画布就绪，运行时错误为 0。

源 SHA-256 在流程前后均为 `17c08b3a288dd40d178eeff071d20dd543b2a6facd6cc58fbf6701e0b0550cb7`；目标 SHA-256 为 `c0ec0e1a67cd189b3e6d8caeb9cd51c0ea265a0236c6f3801753aeec6d704f37`。目标字节不包含秘密标记。

- 源/目标均为 2 页，目标批注数为 0，无 AcroForm、Outlines 和源元数据；
- 目标字节不包含秘密标记；

- 公开标题、正文和页脚区域仍有 15,809 个深色文字像素，保持可读。

## 5. 能力边界与下一步

P1-B3 可以宣布收口，但能力仍严格限定为资料库内 PDF 的“另存永久脱敏图片型副本”。外部 PDF、源覆盖、已有目标覆盖、加密 PDF、签名 PDF、增量更新和复用源 OCR 继续阻断；输出失去文字搜索、选择、表单、链接、批注、书签和无障碍结构。

按既定顺序，下一阶段进入 P1-B4 水印副本安全审计：先冻结页框、旋转、资源名隔离、字体范围、透明度和可靠另存合同，再决定是否实现；不得把水印宣传为脱敏，也不得在没有复开与独立渲染证据前开放写入。
