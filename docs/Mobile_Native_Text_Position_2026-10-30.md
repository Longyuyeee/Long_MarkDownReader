# 普通文字续读原生保护

本轮按元数据审计顺序迁移排版阅读器的位置：段落、段内比例、进度、可选横向位置与内容指纹接入原生 `text-reading-v1.json`。读取失败不冒充首次阅读，不用首屏覆盖旧记录；保存失败仍能阅读、编辑和返回。正常页面不增加常驻说明，错误才显示状态与重试。[原图对照册](evidence/mobile-native-text-position-2026-10-30/review.html)保留实际页面和失败证据。

先核对 [ReadEra官方介绍](https://readera.org/) 的自动保存当前页、按需阅读菜单，以及 [KOReader官方指南](https://koreader.rocks/user_guide/) 的跳转前位置和返回。这里采用保持当前阅读、不用迟到回复打断操作的原则；未安装竞品走查，也不据此推断其内部保存机制。[交互规则和初稿](design/mobile-native-text-position-v1/Interaction.md)在接入前冻结，原型正文是示意。

实际接入包括：

- 记录按资料库和完整路径隔离，用单文档令牌和整个原生文件SHA-256比较后原子写入、读回。旧键仅原生缺失时验证迁移，原键、未知字段与其他资料保持，不静默裁成100条；超过5 MiB、版本或当前记录无效会明确失败。
- 保存队列复制输入快照并合并最新位置。返回、进入编辑、恢复草稿、资料切换和后台保护等待实际阅读框快照与保存确认，失败不拦住正文任务；尚未显示正文就取消时不误报保存失败。
- 阅读框用请求编号应答快照，并核对操作编号后才应用重试恢复。等待期间发生滚动、查找或触摸就保持当前现场；不只依赖宿主120ms后的滚动通知。主题重建保留当前段落，选择原文后迟到排版不会替换它。
- 固定控制器增加横向位置及应答协议后同步更新页面和Android CSP摘要，保持原不透明沙箱。实际图片、搜索、安全与来源返回继续联测。

实页对图发现初始原型把错误放在正文下方，实际沿用顶部状态区。保留初稿并[修订位置](design/mobile-native-text-position-v1/revision-placement/decision.json)：放在64px页头下，方便立即看到和重试。最终组件390×64、顶部64px、字号13px、颜色与修订稿一致。正常阅读和更多菜单两组390×844完整原图逐像素差异0。示意正文和简化页头／底栏未冒充实际整屏参考；没有重画、遮罩或移动截图像素。进一步检查320×372大字原图发现重试按钮被裁掉，之前滚动后再断言可达没有验证首次可见性。保留原失败画面，补充短屏紧凑状态和固定动作，严格去掉测试自动滚动后11组重新通过；实际Android横屏也验证动作完整可见、命中且状态区滚动量为0。
