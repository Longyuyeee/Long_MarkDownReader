# v1.0.15 后续 M3A-1 图谱语义与图例审计（2026-08-27）

## 1. 结论

M3A-1 已完成。知识图谱不再由各视图分别硬编码对象颜色和关系名称；11 类后端实际对象、12 类实际关系、方向、线型、明暗色、形状、字形、固定顺序和未知类型降级现在由 `shared/graph-semantics.json` 统一定义。全局图谱、局部图谱、SVG/PNG 导出和用户可见图例消费同一事实源。

真实 Tauri/WebView2 跨格式资料库产生 17 个节点、17 条边，覆盖 Markdown、PDF/批注、Table/视图、Canvas/节点、OPML/主题、PPTX/幻灯片 11 类对象；实际出现普通引用、包含、嵌入、依赖、批注、支持 6 类关系。1280×800 和 720×800 均显示同一固定顺序图例，无页面横向溢出、运行时错误为 0、可返回资料库，临时资料库 SHA-256 前后相同。

## 2. 原始需求对齐

- 用户文件仍是事实源；本阶段只改变图谱的解释与呈现，不读取额外外部数据，也不修改资料文件。
- 图谱继续负责发现，Canvas 继续负责表达和整理；没有把图谱变成打开、编辑或保存文件的前置条件。
- `FR-GRAPH-004` 要求的关系类型和方向现在有稳定用户可见编码；上下文与证据继续沿用既有节点详情和局部关系卡片。
- 按 M3 路线先建立语义地基，没有提前实现社区轮廓、动画或纯视觉光效。
- 运行时和公开版本保持 `1.0.15`，开发目标保持 `1.0.16`，`releaseCandidate=false`。

## 3. 实现与纠偏

审计前 `GraphView`、`LocalGraph` 和导出分别维护名称、颜色或默认线条，新增类型可能在不同入口显示成不同含义。本阶段以 Rust 实际输出为准收敛为注册表，并提供安全未知对象/关系，避免新格式导致图谱崩溃或无标签。

第一次真实夹具使用 Markdown 相对链接时，后端按现有合同将它识别为 `embeds`，并未产生预期的 `links-to`。测试夹具随后改用真正的 `[[Wikilink]]`，没有为迎合测试修改生产分类；重跑后六类实际关系与图例一致。
