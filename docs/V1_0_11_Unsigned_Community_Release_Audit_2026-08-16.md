# v1.0.11 无签名社区版发布审计

状态：**版本事实源已冻结，等待 Quality Gate 与安装包证据**

渠道：`community-unsigned`

企业发布候选：`releaseCandidate=false`

## 发布范围

- 发布 v1.0.10 之后完成的 P1 图片基础编辑、PDF 标准表单安全子集、永久脱敏、文字水印、文档属性和最终能力对齐。
- 继续保持原左侧资料库和右侧编辑区；外部文件独立窗口、默认打开管理、自动更新重启和所有既有安全保存边界继承。
- 43 类格式/91 个扩展名按能力层级公开，不宣称全格式同深度编辑或完整 Office/WPS/PDF 等价。

## 发布顺序

1. 提交 `1.0.11` 版本事实源并通过完整 Quality Gate。
2. 从冻结提交构建无签名 EXE、MSI 与 NSIS，记录版本、大小和 SHA-256。
3. 在 GitHub 托管一次性 Windows 执行 22 项安装生命周期与 18 项安装后工作区检查。
4. 回写候选证据并再次通过完整 Quality Gate。
5. 发布 GitHub Release，重新下载复核 MSI、NSIS 与 `SHA256SUMS.txt`。
6. 单独验证官方 `v1.0.10 -> v1.0.11` 应用内更新、自动重启和资料保留。

## 发布边界

- 当前公开稳定版本仍为 v1.0.10；在 GitHub Release 真正公开前，README 下载链接保持 v1.0.10。
- 安装包无 Authenticode 商业签名，用户需要手动下载安装或确认应用内自动更新，并核对官方 SHA-256。
- 主 Tauri 打包配置已关闭旧式 updater artifacts；构建不需要遗失的 Tauri 私钥，也不会生成或上传 `.sig`/`latest.json`。
- v1.0.4 及更早版本仍需先手动安装 v1.0.5 或当前公开版本一次。
- 无签名社区版与企业签名候选分离，企业候选继续保持 `releaseCandidate=false`。
- 候选构建、源码质量门和历史 v1.0.10 证据都不能被描述为 v1.0.11 已发布证据。
