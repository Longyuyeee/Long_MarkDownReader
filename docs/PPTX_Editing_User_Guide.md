# PPTX 日常编辑与副本交付

从资料库打开PPTX，点击可编辑对象，或点击工具栏“编辑”。右侧选择当前页的文本或备注，修改后点“加入更改”。软件内部核对安全边界并放入内存草稿，此时还没有写回原件。字符、图片说明/替换、形状和幻灯片工具仍在具名的折叠区域内；“备注与详情”可收起整个侧栏，把空间留给画布。

切换目标会保留还没加入的输入。顶部若提示还有输入未加入，请回到相应目标继续处理，或点“撤回未加入的输入”；撤回不会清掉已经加入的更改。撤销/重做针对整项更改，不自动写盘。

## 原件和副本

点击顶部“保存”或Ctrl+S，明确确认后才写入原件。多项更改会一起核对并保存，过程中短暂锁定相关控件；失败保留草稿。重新读取也需要明确处理未保存内容，读取失败不清空页面和草稿。若提示已经写入但页面复读失败，请先核对原件再重新读取，不要误以为完全没有保存而重复交付。

交给同事时，可在“可靠另存副本”输入同目录的新PPTX名称，点击“另存新PPTX”。标题、备注等多项更改可一起交付，原件不变，同名文件不会覆盖。点击“打开已验证副本”时，软件先复核副本仍包含本次更改，再打开，不会误问是否放弃已经另存的内容；读取失败或副本被外部修改则留在原页面并保留草稿。

## 能力边界

只编辑当前文件中符合安全规则的目标。复杂图表、SmartArt、组合对象等不因界面简化而删除或放开写入；单次最多64项，文件上限96MiB，具体阻塞以当前文档提示为准。外部文件仍是用户授权的只读预览。真实生产者与独立包部件检查不是当前Office视觉验收，也不是完整PowerPoint等价承诺。

当前为v1.1.18开发流程，正式公开版本以README下载区为准，旧安装包不会因文档更新自动获得这些改进。
