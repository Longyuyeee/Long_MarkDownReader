# v1.1.7 收尾补审：中断备注不能丢失重要版本

2026-10-17，按用户“先读实际代码、保护已有功能、真实用户场景、逐步审计推送”的要求继续补审。公开仍为 **1.1.6**，1.1.7 未发布。本批发现并修复一个发布前必须处理的数据保护问题，**原固定产品 `86dbccd1` 不再作为可发布候选**。

## 1. 真实复现及原因

版本保留/备注写入复用 `reliable_write::write_utf8`：先写临时文件，再把旧 `metadata.json` 改名为 `.metadata.json.longedit-bak`，最后提升临时文件。如果在旧文件已备份、新文件尚未提升时中断，主文件暂时不存在，但已确认的保留状态仍在备份中。

原 `read_metadata` 将主文件的 NotFound 直接当作空映射；之后普通数量保留和全局清理会把重要版本也当作未保留，删除对应快照。用独立临时目录还原该真实磁盘边界后，**3 个新增回归全部失败**：读取伪装成空成功、数量清理误删重要版本、全局清理误删重要版本。不是声称用户真实资料已发生丢失；复现没有操作用户的资料或缓存。

原始失败：[native-before.log](evidence/v117-metadata-recovery/native-before.log)。修复没有改预期、跳过清理场景或放宽“重要版本不得删除”的断言。

## 2. 修复方式与边界

- 健康备注读取仍使用共享保护；检测到可靠写入侧写时，不再返回空成功。
- 恢复前先释放自己的读取保护，再获取历史独占保护，并重新解析文档路径。其他读者未结束则保留材料并返回可重试错误，不带着共享租约修改目录。
- `reliable_write` 新增带校验的恢复辅助：先验证最后已提交的主文件或备份，再恢复/清理侧写。主文件损坏时，不能顺手删掉仍有效的备份；备份也损坏时同样保留恢复材料并报错。
- 创建新历史、更新保留/备注、删除版本和全局清理在各自独占保护下先核对/恢复备注，再决定哪些版本可以清理。没有修改恢复前签名核对、A→B→A、正文保存及重要版本的原规则。
- 读取备注跟随当前历史正文列表读取完成，避免“重试同时发两次读取→备注恢复需要独占→每次都被自己的列表阻塞”的循环；过期响应继续按代次丢弃。
- 备注读取失败时，已保留筛选不再显示虚假的“没有符合条件”或“暂无历史”。修复沿原错误/重试入口，不新增弹窗、常驻面板、日常步骤，不自动写回正文。

此恢复只修理应用内部的备注可靠写入状态，保留最后已确认状态；不盲目采用未提交临时文件，也不猜测损坏的当前数据应回退到哪一版。无法校验时停止处理并保留材料。保护仍为本进程参与协议的读写协调，不宣称跨进程锁或全局清理为全有全无事务；目录中更早已按要求清理的普通版本不伪称全部未动。移动预检遇到尚未恢复/损坏的历史目录仍可拒绝，不能因此丢掉记录或盲目迁移。

## 3. 旧固定包的安装失败另行保留

[构建 38940031808](https://github.com/Longyuyeee/Long_MarkDownReader/actions/runs/38940031808) 的质量门、完整原生和独立性能、MSI/NSIS、旧版安装器核验均通过，但**整体 failure**：安装流程在 v1.1.3 继承流程等待 `native text history listed` 超时，还没有执行到本版新流程，不能算安装验收成功，也不能发布。

源码核对与实际 Vue 页面确认：新历史条目每行有“比较版本”和“更多菜单”两个按钮，两条版本共四个按钮；旧驱动把所有后代按钮当作版本，仍要求总数为二。现在只定位历史版本按钮，同时保留旧版直接子按钮兼容，**仍严格要求两个版本、选择最旧版本、恢复副本正文与原文一致**，没有改产品来迁就旧选择器，也没有删除旧流程。

原失败完整日志：[superseded-installed-failure.log](evidence/v117-metadata-recovery/superseded-installed-failure.log)。旧包制品 ID `12064181114`，原 GitHub artifact 保留至 2026-10-30；本机下载遇到本地代理连接重置及后续大包传输停滞，已停止仅属于本任务的下载进程，未删除远端制品。**没有取得该原生失败截图，不将浏览器截图冒充原生截图或认定这是唯一原因**；新固定包必须实际验证修正后的驱动和全部用户流程。

现有 main `dcf008dd` 的 [CI 38942211176](https://github.com/Longyuyeee/Long_MarkDownReader/actions/runs/38942211176) 已整体 success，但不覆盖本批新修正。先前 PR #55、`86dbccd1` 的成功检查保留为历史，不能继承为本批最终通过。
