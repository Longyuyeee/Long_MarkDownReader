## 用户可以得到什么

- 原有右键移动、拖动、单项/批量改名、撤销移动统一接续 Markdown 的本地图片和文档链接。共享图片留在原位置；移动笔记修正相对地址，移动被引用的文件修正来源笔记。
- 支持普通相对地址、中文/空格编码、片段/查询、常用标题、引用定义和字面 HTML 图片/链接。代码示例和远程地址不改。不能可靠解析的相关引用会说明具体文件，不猜测替换。
- 每个实际窗口在操作前取得新鲜正文状态。涉及引用改写的草稿先保留并提示保存；不需要改写正文的普通 Markdown 草稿可随文件接续路径，磁盘不会被自动保存。仅存在于未保存正文里的新链接也会检查，外部 Markdown 编辑窗口参与同一保护。
- 移动与后台保存、创建、导入、PDF 批注/OCR 侧写协调；PDF 伴随记录随文件接续。打开的正文、标签页、收藏、近期、显示样式及文件树跟随真实结果更新。连续批次等待上一步界面更新后再继续。
- 部分失败只重试明确未执行项。意外中断保留原文及历史记录，可从文件栏右键「核对未完成的移动…」查看实际位置、完成核对或还原；发现新的修改时不覆盖，仍可导出原文副本。没有自动重放，也没有新增日常归档步骤。
