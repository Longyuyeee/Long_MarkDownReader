# v1.3.15：在原文中修正文件链接

- 在文章的本地文件链接上右键“更换文件目标…”，查找并选择当前资料库内的文件，支持软件已注册的各类目标。
- 默认只改这一处链接，保留显示文字与标题；目标含原章节时继续定位，优先识别目标的未保存草稿。
- 修改留在当前草稿，一次撤销可恢复，保存仍由用户主动执行；原文或编辑位置改变时停止旧修改并保留所选文件。
- 文件暂时缺失时提供局部“更换目标…”和重试，页面继续可操作。
- 修复即时渲染模式中标题和链接被旧的全局样式隐藏的问题，完整显示正文。
- 正确识别只读Markdown文件；返回后能直接用键盘阅读，并继续阻止修改和覆盖保存。
- 保留全部主题、风格、正常动效及现有功能。先支持可准确定位的普通行内文件链接，引用式定义、图片和代码沿用原有编辑入口。
