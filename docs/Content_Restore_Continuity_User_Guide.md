# 备份恢复后接着工作

在设置 → 隐私与诊断 → 备份资料中，可选“包含工作现场”。它记住打开的文件、固定标签、阅读位置、搜索与参考资料；磁盘内容仍按所选范围备份，未保存正文不会写入内容包。工作现场最多 128 份文件，过多时可取消勾选，另从工作台导出较小的现场。

恢复到新目录后，点击“接续工作现场…”。弹窗按新目录匹配文件，可取消勾选暂时不看的文件；找不到的文件可重新定位，整个目录改了名字则使用该项旁的“文件夹…”，一次更新子文件和参考位置。未找到的条目仍记在现场里，稍后可从工作台继续。

点击“接续所选文件”：当前没有草稿时会切到恢复的资料库并打开可用文件；当前正在编辑未保存内容时只记住恢复现场，继续留在原位置。之后自行保存当前文稿，再切换恢复的资料库，从工作台选择命名现场继续。恢复不会替你保存或丢弃草稿。

“同时恢复搜索条件与参考位置”可以按需取消。工作现场和管理备份不包含文档正文；旧内容包没有工作现场时，继续按原方式添加资料库并打开文件。只恢复进包的文件，不自动查找范围外附件。
