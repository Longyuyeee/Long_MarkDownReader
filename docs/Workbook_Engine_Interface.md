# 工作簿内核接口与兼容性门禁

更新日期：2026-07-23
状态：FR-DATA-009 S8-7D 本地透视事务写回可行性门禁

## 1. 目标

LongEdit 的工作簿工作面以完整 Excel 等价编辑为长期目标。实现必须位于稳定的 `WorkbookEngine` 契约之后，使读取、公式计算、编辑模型和 XLSX 写回可以分层组合，不把具体第三方引擎直接耦合到 Vue 页面或 Tauri 命令。

## 2. 当前契约

`src-tauri/src/formats/workbook.rs` 定义：

- `WorkbookEngine`：工作簿检查和分页工作表读取接口。
- `WorkbookDocument`、`WorkbookSheetPage`、`WorkbookCell`：前后端稳定数据模型。
- `WorkbookCapabilities`：机器可读能力矩阵，覆盖读取、公式缓存、单元格编辑、格式、公式重算、图表、数据透视、验证、打印和 XLSX 往返。

当前 `calamine-ooxml-ironcalc-v14` 组合由 Calamine 承担读取、IronCalc 承担内存依赖求值、独立 `workbook_ooxml` 内容/结构补丁层和 `workbook_styles` 样式层承担写回。前端可通过 `get_workbook_capabilities` 获取真实能力，不能根据页面控件推断兼容等级。公开分维度矩阵见 `XLSX_Public_Compatibility_Matrix.md`，机器事实源为 `shared/xlsx-compatibility-matrix.json`。

当前已支持文本、数字、布尔和公式单元格的创建、编辑或清空，并支持日期/时间和错误值读取。工作簿级与 Sheet 级命名区域会保留作用域并进入名称框导航，单一区域可切换 Sheet、选择完整范围并定位；命名区域公式可参与显式重算。S8-3A 已开放安全单一 A1 区域的创建、更新引用、改名和删除；隐藏/系统名称保持只读，被公式引用的名称拒绝改名或删除。连续区域 TSV 剪贴板、当前工作区整行/整列与最多 32 个区域选择，以及字体、填充、独立四边框、水平对齐、换行、命名样式和受限自定义数字格式均已交付。主题色（含 tint）与 Excel 64 色索引调色板会解析为可显示 RGB。填充柄支持模式复制、一维数字序列外推、基础样式复制和 A1 公式相对/混合引用迁移。工作面可显式重算当前已加载公式，并可读取和写回自定义行高、列宽及合并区域；可变尺寸网格、合并锚点渲染和结构草稿均进入撤销重做与未保存保护。保存携带读取时的内容签名，冲突时拒绝覆盖；条件格式等未编辑 OOXML 对象保持原始事件序列。

S6-11～S8-3B 已开放冻结、Table、筛选、命名区域和数据验证的受限生命周期。S8-3C1～S8-3C3C2 已覆盖基础数值、有界 `AND/OR/NOT` 多 A1 引用表达式，以及 num/min/max/percent/percentile 双色/三色色阶、标准数据条、Excel 2007 标准 3/4/5 图标集、重叠/同范围规则的优先级与规则级生命周期、共享范围显式拆分/重新组合和依赖分页求值；动态阈值由完整范围扫描解析，数据条支持负数及跨零自动轴，图标集支持严格/包含阈值、反向顺序和仅显示图标。区域/跨 Sheet/未知函数表达式、公式阈值、自定义混合图标和 `x14:` 高级视觉样式只读并保真。

S6-12 增加工作表 Drawing 关系、图表和图片结构读取。S8-4A 使用“Drawing 部件路径 + 锚点序号 + OOXML 对象 ID”建立稳定身份，并为标准 `twoCellAnchor` 开放名称/替代文本编辑和移动/缩放。S8-4B 为已有标准标题及公式型系列开放独立动作：内部一维 A1 分类/数值引用必须点数一致，写入时删除目标旧缓存并语义重读；前端按源单元格生成受限本地预览。S8-4C 支持从含表头的连续选区创建标准柱形、折线、饼图和散点图，安全删除目标图表，并在结构兼容时切换标准类型。S8-4D1 为无扩展、非组合且仅含标准单轴结构的图表开放分类轴/数值轴标题和图例位置事务；饼图仅开放图例。S8-4D2 为相同标准安全子集开放系列字面显示名，以及无逐点覆盖、自定义文本/格式/位置/样式的图表级数值、分类名、系列名和饼图百分比标签。S8-4D3 为无系列样式或仅含统一直接 RGB 填充/线条的安全系列开放颜色事务；当前主题色板提交为显式 RGB，本地预览同步轴标题、图例方位和系列颜色。S8-4D4 增加四类真实 XLSX fixture、命令边界往返、三主题视觉证据和真实 Tauri 编辑保存重开验证。所有事务校验内容签名、工作表保护、Drawing 归属与对象身份，并在写回后执行包校验和语义重读。单点/绝对锚点、复杂组合图、逐点/自定义标签、高级主题色、渐变/图片/图案填充、高级轴格式和像素级渲染尚未开放。

S6-13 增加透视表/Pivot Cache、切片器、外部链接和数据连接的脱敏结构清单。S8-7A 在独立 `workbook_linked_data` 模块中增加对象汇总和权威 `offline_read_only` 策略，并在工作面提供分组审计面板。S8-7B 解析本地来源、输出布局、缓存字段/记录、字段角色和聚合定义。S8-7C 从工作表当前值和非公式草稿生成内存聚合预览。S8-7D 进一步核对 Pivot Field items、`rowItems/colItems` 与输出区域单元格，为每个对象返回写回结构就绪度，但 `allowed` 仍固定为 `false`，没有写入命令。外部目标永不跟随，连接字符串、命令、凭据和完整路径不进入 IPC。机器事实源为 `shared/xlsx-linked-data-capabilities.json`，详细边界见 `XLSX_Advanced_Data_Object_Contract.md`。

S6-14 增加打印区域、页边距、纸张/方向/缩放、打印选项、页眉页脚和保护状态的结构化摘要。S8-5A 为单连续打印区域、纵横方向、Letter/Legal/A3/A4/A5、百分比/适页缩放和六项页边距开放独立事务；只修改目标 Sheet 页面节点与对应 `_xlnm.Print_Area`，写后执行语义重读。S8-5B 为奇数页、偶数页和首页的六个标准页眉页脚文本及四个标准标志开放独立事务；每字段限制 255 字符并拒绝不支持的控制字符，空文本清除对应节点。S8-5C 为打印网格线、行列标题、水平/垂直居中、黑白、草稿和可选首页页码开放独立事务，仅覆盖 `printOptions` 与 `pageSetup` 的对应标准属性。保护密码、哈希和盐不进入 IPC；受保护 Sheet 的页面布局、页眉页脚与打印选项写回统一拒绝，工作簿结构保护阻止打印区域定义变化。本阶段不提供分页计算、像素级打印预览、图片型页眉页脚、保护设置修改或密码解锁。

S6-15 建立 `xlsx-progressive-editing-v1` 发布档案：复杂 fixture 复合写回执行全 ZIP 部件差异白名单和语义重读；10,000×12 业务负载执行 Debug CI 性能预算；公式分页读取改为受限 OOXML 扫描并覆盖普通/共享公式。总体 `xlsxRoundTrip` 仍为计划，不以局部保真冒充完整 Excel 等价。

## 3. Fixture 门禁

基线文件位于 `src-tauri/tests/fixtures/workbook/`：

- `compatibility-baseline.xlsx`：多 Sheet、基础类型、日期/时间、错误值、全局/局部命名区域、命名公式、公式缓存、格式、条件格式、合并单元格、尺寸、冻结窗格、自动筛选、Excel Table、数据验证、柱形图、嵌入图片、透视表、切片器、外部链接、数据连接、打印布局、页眉页脚及工作簿/Sheet 保护。
- `compatibility-baseline.json`：语义单元格、文档特性和当前能力预期。

重新生成：

```powershell
cargo run --manifest-path src-tauri/Cargo.toml --example generate_workbook_fixture
```

任何工作簿引擎变更必须先通过现有语义断言。开始写回后，门禁扩展为“读取基线 -> 修改指定单元格/样式 -> 保存副本 -> 再读取 -> OOXML 结构差异报告”，且不得静默丢弃未编辑的未知部件。

## 4. 当前写回门禁

1. 只修改目标工作表中明确提交的单元格节点；新行和新单元格必须按坐标有序插入。
2. 内容编辑不修改 `styles.xml`；样式编辑只追加去重后的基础样式记录并更新目标单元格 `s` 属性，其他 ZIP 部件保持原始字节。
3. 保存前验证内容签名，写入使用同目录临时文件、恢复备份和原子替换。
4. 坐标越界、重复编辑、内容超限或编辑合并区域非左上角单元格时整批拒绝，不产生部分写入。
5. 样式变更每批最多 10,000 个单元格、最多创建 256 种新样式；命名样式必须来自 `cellStyles`，自定义数字格式最多 128 字符，颜色、字号、字体名、四边框和对齐均由后端验证。
6. ZIP 部件名不得重复；单部件解压上限 256 MB，整包解压上限 512 MB；分页范围与样式使用一次受限解包读取。
7. 冻结窗格是独立结构写回：存在未保存内容草稿时禁用，写前验证签名，且只修改目标 Sheet 的 `sheetView/pane`。
8. 数据验证规则在内容补丁前统一校验；规则结构写回仅开放列表、整数、小数、文本长度和自定义公式，拒绝重叠范围、外部工作簿引用和复杂扩展节点。无法可靠本地求值的公式/自定义规则可编辑并保真，但不宣称已经执行。
9. 任一内容、样式、尺寸、合并或冻结写回触及受保护 Sheet 时整批拒绝；保护密码校验值和哈希材料不得进入公开模型。
10. 命名区域是独立结构写回：仅开放非隐藏、非系统的单一 A1 区域；校验作用域唯一性与工作簿结构保护，写前验证内容签名，写后校验 OOXML 包。被公式引用的名称拒绝改名或删除，不自动迁移公式。
11. 条件格式是独立结构写回：开放基础 `cellIs`、有界 `AND/OR/NOT` 多 A1 引用表达式，以及 num/min/max/percent/percentile 色阶、标准数据条和 Excel 2007 标准 3/4/5 图标集。表达式限制 512 字符、8 层、8 参数和 8 引用，可见依赖缺页时按需读取；区域、跨 Sheet、名称、算术、未知函数或超限表达式只读。普通规则支持 RGB DXF；色阶、数据条和图标集直接存于规则且不追加 DXF。动态视觉规则合计最多解析 64 条、百分位累计最多 1,000,000 个数值；超限或公式阈值只读。规则由 `groupIndex + ruleIndex` 寻址，重叠及同范围受支持规则可排序、更新、删除、拆分、组合和管理 `stopIfTrue`。排序只改写 `priority`，同组更新只替换目标 `cfRule`，拆分/组合迁移原始规则事件。自定义混合图标和 `x14:` 高级样式只读。写前验证签名，写后执行包验证与语义重读。
