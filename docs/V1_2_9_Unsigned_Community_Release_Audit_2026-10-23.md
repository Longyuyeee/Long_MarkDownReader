# v1.2.9：TOML 配置值编辑

当前开发目标：`1.2.9`；当前运行时版本：`1.2.9`；当前公开版本：`1.2.8`。当前阶段：**v1.2.9 TOML 配置值编辑候选**。

## 用户操作与范围

配置值右键“修改值…”打开必要弹窗，预填并选中当前原始字面量；输入错误就地解释并保留输入，可直接纠正。字符串、布尔、整数和浮点数可改；数组、内联表、日期时间提示转到源码并定位，原文保持。沿现有差异预览应用到当前草稿，一次修改可独立撤销，不增加常驻表单或第二套保存流程。

## 准确定位与草稿保护

原分析使用的可变文档会移除原文位置，已改为保留范围的不可变解析。修复分区、同名字段、带引号的点号键、Unicode 键和表数组定位；只替换选中值范围，保留注释、顺序、换行、长整数和转义，完整候选重新校验，拒绝通过值输入夹带其他键或注释。

当前草稿、范围与分析必须匹配；来源变化清理旧菜单、参数弹窗和预览，异步结果不覆盖后续输入。沿现有保存、失败重试、外部冲突和历史恢复保护未保存内容。名称弹窗关闭后再打开差异预览，保持编辑焦点，便于直接撤销。

## 发布检查与边界

原生 TOML 模块新增 8 项范围与替换回归；页面检查明确模拟 IPC，真实 Windows 安装检查另行记录。渠道 `community-unsigned`，企业 `releaseCandidate=false`，未签名 Windows 社区版；完成固定源码构建、同包安装与公开附件核对后，可手动下载安装。1.2.8→1.2.9 应用内自动更新实际观察独立 pending，不把手动升级当作通过。

下一版 1.2.10 YAML 简单值编辑继续按[既定路线](Foundation_Deepening_Roadmap_1_2_9_to_1_2_10_2026-10-23.md)推进，尚未实施。
