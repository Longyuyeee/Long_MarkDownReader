# v1.1.30：Table 录入规则与批量纠错

在列标题右键设置必填、整数或数值范围、日期、文本长度与固定选项；数据保留原文本，不自动改写编号或补零。

- 从“数据操作”按需检查全部记录或筛选结果，查看具体问题并定位原行。
- 单项修改与批量修正先预览，再应用到当前草稿；排序后仍准确修改原记录，隐藏行及其他未保存输入保留，一次撤销或重做。
- 规则随 Table 保存，CSV/TSV 可临时使用规则，也可通过现有“创建 Table 副本”保留下来。
- XLSX 固定列表校验统一直接输入、粘贴、填充与清空的处理，非法批次整体拒绝，合法粘贴仍支持一次撤销。

带规则的 Table 使用新版结构，旧版本软件会明确拒绝打开，避免保存时丢失规则；无规则的旧 Table 继续兼容。
