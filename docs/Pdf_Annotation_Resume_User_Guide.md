# 继续整理 PDF 批注

在库内 PDF 的批注面板按摘录、页码、类型或颜色筛选，勾选需要整理的批注。切换文档或重开软件后，会自动接续这些条件、当前批注、有效的勾选项、列表分组及滚动位置，无需点击恢复。

打开指定页码或批注的引用时，先到达引用指定的位置。原 PDF 内容变更后不套用旧的批注选择；批注已删除时仅保留仍存在的项，列表变短时落到有效分组。

评论继续使用原有自动保存。保存失败时会保留评论及当前页面；恢复写入后重新切换即可，不需要额外导入。软件关闭时尚未保存的评论参与原有关闭提醒。阅读位置记不住不会妨碍阅读，也不会改动原 PDF。库外 PDF 沿用只读行为。

本机阅读记录和工作现场只保存筛选与位置、批注 ID，最多接续 200 个整理选择，不保存批注正文或未保存评论。工作现场旧文件仍可使用，正常阅读和现有整理为笔记操作保持不变。
