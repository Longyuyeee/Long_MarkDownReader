# v1.1.15 轻量表格编辑与可靠交付

候选说明，尚未封板或公开发布；实际安装验收及公开回下载完成后才发布同一原包。

- 在原表格内用Shift＋点击选择多格，复制、粘贴与清空按可见行执行，筛选隐藏行不被误改。
- 单元格、表头、看板字段和行操作加入数据撤销链，整批粘贴可一次撤销/重做，排序后仍按稳定行列身份定位。
- 多行格显示换行标记，按需打开文本区编辑，确认只修改草稿，保留原均一CRLF；普通单行保留文本输入和复制习惯。
- 修复XLSX导出丢失前导零与长编号精度，公式外观文本不生成公式；原CSV/TSV编码、BOM、换行及值继续保留。
- 保存中新增修改仍待保存，错误保留草稿；超范围和超预算整次拒绝，不部分粘贴，不代存源文件。

单次剪贴板2MiB/20,000格，撤销最近100次/8MiB。未筛选未排序可补行；筛选/排序后超出可见行或超出现有列时须先调整范围。新增列与视图配置不在数据撤销范围。CSV不携带文本类型，其他表格软件可能自动解释编号和公式，需核对导入设置；不静默加前缀改变用户原值。社区包未签名，请核对SHA-256；手动覆盖安装不等于应用内自动更新观察已通过。

操作方法与边界见[轻量表格编辑与交付说明](https://github.com/Longyuyeee/Long_MarkDownReader/blob/main/docs/Lightweight_Table_User_Guide.md)。
