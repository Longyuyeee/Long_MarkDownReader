# v1.1.29：PDF 批注与阅读笔记接续

阅读与整理之间切换时，保留批注筛选、列表分组、所选批注和阅读位置；评论可从右键或条目菜单编辑。输入后立即排入保存，离开页面也不会要求先点击别处。

- 新版生成的阅读笔记支持从“文档操作 → 更新 PDF 阅读笔记…”核对变化；也可从 PDF 整理窗口直接更新已有笔记。
- 先预览新增、变化和已删除的批注。默认保留已删除批注的摘录，可选择移除；新增范围只包含生成笔记后真正新增的批注。
- 更新只进入当前草稿，保留生成范围外的补写和其他草稿，可一次撤销、重做，再手动保存。生成范围内有用户修改时，可以保留原文并追加新版。
- 核对期间来源或草稿变化会中止旧操作；旧阅读笔记缺少可靠范围时保留原文，不能自动替换。
