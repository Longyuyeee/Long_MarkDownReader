# 1.3.11 规划：查找定位后返回原编辑位置

当前公开版本1.3.11。本页规划已实现并发布；实际结果见[本版审计](V1_3_11_Unsigned_Community_Release_Audit_2026-10-29.md)。

长文档里从编辑位置跳到查找结果后，用户常要再找回刚才编辑的地方。下一步在已有源码导航中接续“返回原位置”，减少滚动和重复查找，继续保护未保存内容。

1. 用户主动从匹配列表定位时保留原光标、选区和可见位置；通过已有编辑区右键或现有文档菜单按需返回。不增加常驻导航栏、介绍卡片或额外确认。
2. 返回只恢复当前文件的位置，不编辑、不保存，不影响撤销／重做；只读文件可用。多次定位的规则需简单可理解，记录有明确上限。
3. 正文仍是同一草稿时准确接续；内容编辑后只采用有效映射，外部重载、替换文件、切换资料库时停用不可靠旧位置。迟到操作不能抢新文件焦点。
4. 保留当前查找条件、选区、最近条件和替换预览，四格式、所有风格、大小窗口和键盘操作核对。

工程继续使用核心加受影响任务，沿用明确的已发布历史基线，不将旧数量记成本版通过；保留独立全量回归的工程入口，按需要安排。Rust实际行为或依赖变化则完整回归，当前安装器始终编译与实测。产品范围不包含跨文件替换或自动改写。

本版已完成：查找后返回原位置、连续返回与编辑映射、14组相关原生工作流及核心生命周期、当前20类结果与80类历史基线分开记录。后续见[1.3.12路线](Foundation_Deepening_Roadmap_1_3_12_2026-10-29.md)。
