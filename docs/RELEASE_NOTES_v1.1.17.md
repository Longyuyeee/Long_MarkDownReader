# LongEdit v1.1.17 · DOCX 编辑与保存深化

- 修改DOCX后直接选择“保存到原文件”或“另存新DOCX并打开”，安全检查会自动完成，不再要求先操作技术验证按钮；按需检查详情仍保留。
- 修复检查、保存和页面读取的过期回执归属，防止旧操作清理当前草稿；保存期间暂时锁定相关输入，完成或失败立即恢复。
- 同一路径从库内编辑切到外部只读，也会检查未保存草稿；不再仅凭文件路径相同而跳过保护。
- “重新读取”先明确草稿去向，取消或读取失败保留内容；已写入但页面复读失败如实提示，不假称全部成功。Ctrl+S与保存并离开使用同一显式确认流程。
- 即使编辑面板已关闭，保存失败仍有全局可见原因；资料库文本入口不会重复处理DOCX的Ctrl+S。
- 保留正文/列表/简单表格、多目标、四类受限编辑、撤销重做、目录/搜索与全部旧工具，不把复杂DOCX当成任意Word编辑器。

## 安装和能力边界

Windows x64社区未签名版（community-unsigned），可能显示未知发布者。请从本版本Release手动下载安装，核对同页SHA256SUMS.txt。企业releaseCandidate=false，应用内16→17更新观察另列。源文件签名、输出摘要、隔离复读、复杂对象及未触及部件保真、预算和回滚门禁不因界面简化而取消。生产者样例及独立ZIP/XML检查不代替当前Office视觉验收。
