# v1.2.1 移动阅读接续开发与发布记录

当前开发目标：`1.2.1`；当前运行时版本：`1.2.1`；当前公开版本：`1.2.0`。当前阶段：**v1.2.1 移动阅读接续候选**。

## 1. 审计结论

基线 v1.2.0 已发布。本版实现同库移动、改名后接续阅读与命名工作现场，当前正在验证，尚未发布。

## 2. 需求对齐

沿现有文件右键、拖放和批量改名；正常成功不增加确认。移动前捕获当前位置，只按成功回执接续成功项与文件夹后代。保留未保存正文与已有冲突保护，复制不抢走源记录，不新增跨库剪切。

## 3. 当前开发状态

- 新增统一阅读元数据接续，在原生移动完成、更新标签与路由前执行。
- 接续 PDF、Table、XLSX、画布等现有位置，命名工作现场的文件、当前标签、搜索与参考定位；保留 24 实时 / 128 暂存的界限。
- PDF 来源签名由大小与修改时间组成，与路径无关；接续时保留原签名，继续由阅读器核对来源与批注 ID，不冒充内容一致。
- 目标已有记录、记录损坏或存储失败时保留原记录，给出局部提示；不使文件操作失败，不遮住编辑器。
- 只迁移定位元数据，不迁移编辑器草稿，不隐式保存正文。

本地新增任务测试 23 项通过；实际 App/Vue 右键流程 3 项通过（长文移动前后均为 1800 px、现场引用跟随、未保存正文不代存）。原有图片/链接接续浏览器回归 3 项、12 个风格与窗口组合通过。浏览器原生 IPC 与文件系统为模拟，不能代替真实安装包检查；固定产品与原生安装包结果待完成后补录。

补充处理旧组件卸载写回旧路径的情况，避免过期记录复活并干扰撤销移动；只对当前进程的旧视图拥有者生效，显式重开原路径即可建立新阅读记录。Windows 原生规范路径与用户配置路径分别定位同一资料库的已有记录。旧组件在卸载时即使观察到新路由，也不能在新阅读器接管前写入目标记录。

首个候选 `17d63ba5f8311e93b39cca93b44c88687f9ee77b` 的独立源码流水线 39777777284 已完整通过；构建 39777757076 在完成发布检查后主动停止，不作为发布包。活动目标记录的接管保护另补一项回归后，使用修订候选重新构建。

## 4. 发布边界

本版不实现 PDF 批注撤销重做；该功能保留在 1.2.2。仍为 Windows x64 未签名社区版，可能出现“未知发布者”，附件按 SHA-256 校验。自动更新实际观察与手动安装升级分开记录，未观察的不记通过。

渠道为 `community-unsigned`；企业能力矩阵保持 `releaseCandidate=false`。1.2.1 未发布前使用 1.2.0 正式包；发布后可手动下载安装，1.2.0→1.2.1 应用内自动更新观察独立记录，不能用安装包升级结果代替。

## 5. 接手后的顺序

先完成本版三个用户任务和必要回归，再构建固定产品，同一安装包完成实际安装流程后发布。之后按既定路线推进 1.2.2 PDF 批注撤销重做。

补充统一检查内存、持久记录和其他窗口暂存队列中的目标位置，避免打开着的源文件覆盖尚未载入内存的目标记录；增加三项交叉层回归。修订候选 `2c1f3be6987f15b6efad8cc59a05fd73ebfba188` 的构建 39779947910 在完整产品检查期间主动停止，未作为发布包。最终修订的本地类型检查、23 项接续测试、3 项实际右键任务及 26 项受影响回归通过。

首轮同包复查 39785155654 的检查脚本截断了 Windows 扩展路径中的问号。实际 PDF 已移动并保持第 2 页；原始失败报告、截图及精确条件回归见[独立记录](evidence/v121-review-failure-39785155654/Iteration.md)。只修检查脚本，复用构建 39781503881 的原始安装器继续完整复查；本轮失败不作为发布依据。
