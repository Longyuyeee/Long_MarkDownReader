# Long编辑 v1.1.12 · 本地资料内容备份与可靠恢复

在现有资料库能力上补齐“把已保存资料备份起来，恢复到新位置继续工作”，不增加日常保存步骤。

- 设置 → 隐私与诊断新增独立“资料内容备份”：可选整个资料库或子目录，按文档与数据、附件、PDF 批注及可选 Markdown/TXT 历史预检；显示数量、大小和未包含内容。
- 新内容包使用版本化清单、相对路径和逐文件 SHA-256；导出前后复核源资料，发生变化要求重新预检。只创建新 ZIP，不覆盖同名包。
- 恢复先完整校验，默认只写入全新目录，不覆盖或合并现有资料；保留相对图片、PDF 配套批注、修改时间，以及选中历史的保留状态/备注并绑定新路径。
- 完成后明确显示位置和摘要，可自行添加为资料库；不自动切库、不代存或替换当前草稿。取消、源变化、损坏包、空间预算及目录冲突给出明确结果。
- 保留管理备份、模板导入导出、六种界面风格和全部现有功能；内容弹窗适配窄短窗口，正文滚动、底部操作保持可达。

## 使用与边界

内容包最多 512 MiB（未压缩），单文件最多 128 MiB、10000 个文件条目；大库请选择子目录。历史默认不选。隐藏/依赖目录、已知敏感配置、应用凭据、当前未保存内容和范围外链接目标不自动收集；具体排除项见预检。模板继续用模板导入导出。

内容包可能包含私人资料，**未脱敏、未加密**，请自行妥善保管。管理备份仍是原来的脱敏管理信息备份，不含正文，两个入口不能混用。异常中断留下的自有暂存和核对日志不会被冒充完成或自动全量重试。

资料库范围若与应用配置或缓存目录重叠，内容预检与导出会拒绝执行；请使用独立资料文件夹，避免把应用配置当作普通附件。

Windows x64 未签名社区版，系统可能提示未知发布者；企业发布候选保持 false。应用内管理更新与整包安装验收分别记录，不将本次安装验收冒充自动更新已通过。

安装器将使用同包独立验收通过的原始 MSI/NSIS，附件 SHA-256 见 SHA256SUMS.txt。发布前仍须完成固定安装包、真实 WebView/原生磁盘、完整既有回归和公开回下载，不能仅凭开发测试视为正式发布。
