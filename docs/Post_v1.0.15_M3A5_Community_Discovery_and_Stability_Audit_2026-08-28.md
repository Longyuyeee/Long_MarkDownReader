# Post-v1.0.15 M3A-5 社区发现与稳定性审计

日期：2026-08-28

阶段：M3A-5

发布候选：否

## 1. 原始需求与本次边界

本阶段直接对齐 `Post_v1.0.15_Professional_Capability_Enhancement_Roadmap_2026-08-25.md` 的 M3A：引入成熟社区发现算法，生成稳定社区 ID、主题摘要和可筛选聚类；同一固定图谱重复构建后，社区结果应当可解释且基本稳定。`Professional_Knowledge_Workspace_Design.md` 同时要求 Louvain/Leiden 结果只能作为建议，不能写回用户数据。

本次只完成语义探索层的社区计算、摘要、筛选与返回，不提前实现属于 M3B 的社区轮廓、语义缩放、色带和远中近景镜头，也不把计算结果持久化到资料库。

## 2. 实际实现

- 引入 MIT 许可的 `graphology@0.26.0` 与 `graphology-communities-louvain@2.0.2`，使用成熟 Louvain 实现，不自造未经验证的聚类算法。
- 将有向语义图确定性投影为无向简单加权图：忽略自环，同一对象对之间的多条语义关系累计为权重；节点 ID 和无向边键均固定排序。
- Louvain 固定 `randomWalk=false`、`fastLocalMoves=true`、`resolution=1`。无连接节点作为独立社区处理。
- 社区 ID 由排序后的成员节点 ID 计算双 32 位稳定哈希；标题或标签变化不会改变成员不变社区的 ID。稳定性承诺限定为同一固定资料库/固定节点身份的重复构建，不宣称资料库迁移后路径绑定节点 ID 仍相同。
- 社区摘要包含高频标签、代表节点标题、对象类型计数、节点数和内部关系数。社区面板展示算法、社区数与模块度，并明确标注“只用于当前视图探索，不写回文件或用户关系”。
- 选择社区后只显示其诱导子图，持续显示聚焦范围，并提供显式“返回全部”操作；打开社区探索会退出邻居聚焦和最短路径，避免多个筛选状态叠加。

## 3. 独立算法审计

固定夹具由两个各含 3 个节点的完全子图、一条跨组桥边和一个孤立节点组成。审计结果：

- 产出两个预期稠密社区和一个孤立社区，共 3 个社区；
- 连续运行 20 次，成员分区与社区 ID 完全一致；
- 反转节点顺序并打乱边顺序后，结果签名不变；
- 只修改节点标题后，成员派生社区 ID 不变；
- 策略文件固定算法版本、投影规则、稳定性边界、只读策略及下一阶段。

## 4. 真实桌面审计

真实跨格式 Tauri 资料库包含 17 个节点和 17 条关系，覆盖 11 类对象与 6 类实际关系。最终结果如下：

| 项目 | 预期 | 实际 |
| --- | --- | --- |
| 社区分区 | 可解释、非空、覆盖固定图谱 | 5 个社区，规模为 4/4/3/3/3 |
| 模块度 | UI 可见且可复核 | 0.670 |
| 重复构建稳定性 | 同一资料库重新进入图谱后 ID 不变 | 5 个社区 ID 全部一致 |
| 社区筛选 | 仅显示所选诱导子图 | 17 节点/17 边 → 4 节点/3 边 |
| 返回全部 | 恢复完整图谱 | 恢复 17 节点 |
| 响应式 | 1280 与 720 宽度无页面横向溢出 | 均通过 |
| 用户数据安全 | 不写回源文件 | 审计前后目录 SHA-256 一致 |
| 运行稳定性 | 无运行时错误且可返回资料库 | 0 错误，返回通过 |

证据位于 `docs/evidence/post-v115-m3a5-community/`，包括 `desktop.json`、宽窄社区面板、社区聚焦及语义图例截图。该证据不包含用户内容，`releaseCandidate=false`。

## 5. 偏移纠正与下一接续点

此前部分当前状态文档把“社区发现”描述成 M3A 的最后一步，容易让后续直接进入 M3B。但原始路线的 M3A 还明确要求双节点比较、邻居固定和选择历史。本文同步纠正接续顺序：

1. **M3A-6 双节点比较**：建立两个节点的一致差异/共同邻居/关系证据视图，并独立验证；
2. **M3A-7 邻居固定与选择历史**：完成可撤销的探索会话状态，不写回用户图谱；
3. 完成 M3A 退出审计后，才进入 M3B 社区轮廓、语义缩放和视觉镜头。

M3A-5 已通过，当前接续点固定为 **M3A-6 双节点比较**。
