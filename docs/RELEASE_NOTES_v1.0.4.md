# Long编辑 v1.0.4

v1.0.4 是一次面向真实安装反馈的体验收口版本，重点解决安装版界面偏差、控制台弹窗、跨页面状态丢失和多格式工作区可用性问题。

## 主要变化

- 设置页重新分类，格式能力矩阵、隐私诊断、知识网络观察与主题预设使用更明确的中文说明和返回路径。
- 修复 Tauri 对话框 ACL 报错、检查更新失败提示、资料库索引交互和外部修改误报。
- 文件树增加格式辨识；标签页保持可读宽度、支持滚轮横向滚动并移除原生滚动条干扰。
- Markdown 默认所见即所得；文本、日志、代码、HTML、JSON、YAML、XML、TOML 工作区统一显式保存、撤销/重做、主题对比度和专业编辑布局。
- CSV/TSV 支持冻结前 N 列，改善固定列透明度、窄窗口布局和“转换为表格”的目标说明、保存位置与覆盖确认。
- 工作簿、PDF、DOCX/ODT、PPTX/ODP、Canvas、Draw.io、Mermaid、OPML 与知识图谱完成有界体验审计。
- 修复后台窗口路由加载挂起和发布能力页在开发版本领先公开版本时的崩溃。
- 隐藏外部程序探测与辅助进程窗口，解决安装后反复出现控制台或 `reg.exe` 错误窗口的问题。

## 验证

- 前端生产构建与 Rust `--locked` 检查通过。
- Windows 隔离安装生命周期：18/18。
- 安装态功能检查：15/15。
- 安装态关键路由：11/11。
- 41 类格式体验矩阵：29 类已验证、6 类有限能力、6 类依赖外部程序。

## 安装说明

本版本是无 Authenticode 签名社区版。Windows 可能显示“未知发布者”或 SmartScreen 提示，请只从本项目官方 GitHub Release 下载，并核对 `SHA256SUMS.txt`。

原自动更新私钥当前不可用，因此 v1.0.4 仅提供手动下载的 NSIS 与 MSI，不提供 `latest.json` 或 `.sig`。已安装用户需要下载新安装器进行覆盖安装。
