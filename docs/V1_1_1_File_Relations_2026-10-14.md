# 所有类型的资料都能直接添加关系

2026-10-14，接续用户反馈：知识图谱中不知道如何建立关系，教程只解释Markdown，希望在“专注”旁增加统一入口。与本分支其他体验改动一并开发；公开安装包仍是1.1.0，尚未发布本轮变化。

## 用户操作

1. 打开文件，在“专注”旁点击 **添加关系**；或从知识图谱顶部、选中资料的详情、文件关系上下文打开同一个弹窗。
2. 当前文件自动成为起点，搜索并选择要关联的另一份资料。可以更换起点，笔记、PDF、表格、图片、JSON及普通附件均可选择。
3. 选择 **相关资料、引用、参考依据、依赖、整理自、支持、父级、子级、包含**，可填写关系说明。弹窗显示方向及两个文件的预览，说明各类型的实际含义。
4. 点击 **添加关系** 后立即显示在图谱中，可继续添加或返回阅读。原文件内容不变，已有未保存草稿也不受影响。

弹窗中“这份文件已有的手动关系”可以查看和移除已存关系；图谱详情也可移除手动关系，资料文件保留。保存失败只在弹窗内提示并保留选择和说明，支持重试；重复添加同一类型关系更新说明，不产生重复记录。

## 图谱引导与布局

- 图谱顶部新增可见的“添加关系”，窄窗口保留文字。教程改成“打开入口→选择两份资料→选择类型并保存”，以Markdown和电子表格为例，明确适用于所有文件类型。
- Markdown正文双向链接的教程作为补充折叠说明；原语义关系写入/删除能力保留在“Markdown正文关系”中。
- 选中资料的详情优先显示打开、添加关系和聚焦邻居；固定右侧关系、思维导图中心、可编辑画布、项目笔记和保存视图仍保留在“更多图谱操作”。
- 关系统计用“指向这里 / 指向其他”，只统计有方向的关系；相互关联仍计入总关系数。关系类型显示名称与弹窗一致，避免在创建后出现另一套术语。
- 六种风格、原布局、导出、筛选、画布/思维导图与动效设置接续。此轮不是重写整个图谱引擎或新增所有格式的阅读器。

## 保存与文件生命周期

新增 `commands/file_relations.rs` 与统一弹窗、文件选择器。手动关系保存到当前资料库的 `.longedit/file-relations.json`，以相对路径保存两份文件、类型及说明；不向PDF、Office、JSON或Markdown中插入格式相关语法。

- 文件目录选择只读取名称和路径，最多显示200个匹配项，支持继续输入名称查找；不以是否可自动解析正文限制关联。
- 原生图谱构建读取手动关系，并为尚未自动进入图谱的文件添加文件节点。连线带有“手动添加的关系”和用户说明，合并时保留手动记录ID；关系摘要、局部图谱及关系上下文接续同一图谱数据。
- 保存/移除后使当前窗口相关缓存失效并刷新图谱、局部图谱和关系摘要。
- 应用内移动文件或重命名文件/文件夹时迁移关系路径；关系保存失败会尝试恢复原位置。已不可用的目标不阻断其余关系构建，恢复到原路径后仍可识别已有记录。
- 索引快照记录手动关系文件摘要；添加或移除关系后，旧快照不会继续被当作最新状态，重开应用也能识别变化。

当前是**当前资料库内的文件级关系**，未扩展到库外文件或页码、单元格等内部对象级关系。复制资料库时应连同 `.longedit` 目录一起保存；管理设置备份原本不包含资料文件，本轮不改变该范围。
