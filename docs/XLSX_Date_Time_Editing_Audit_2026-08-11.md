# XLSX 日期时间编辑审计

审计日期：2026-08-11
版本基线：`1.0.6`
结论：**日期时间编辑由计划提升为受限可用**

## 本阶段完成

- 已有日期型单元格可输入 `YYYY-MM-DD`、`YYYY-MM-DD HH:mm[:ss[.SSS]]` 或 `HH:mm[:ss[.SSS]]`。
- 编辑接入现有草稿、撤销/重做、区域粘贴和点击保存事务；清空或改成普通文本仍被允许。
- Rust 后端严格验证真实日历日期和时间，在写盘前读取 `workbookPr@date1904`，分别按 1900/1904 纪元生成 Excel 序列。
- 1900 日期系统正确处理 1900-03-01 之后的 Excel 闰日偏移；不会接受现实中不存在的 `1900-02-29`。
- 写回沿用既有单元格样式，因此日期数字格式、字体、填充、边框和其他 OOXML 部件保持原样。
- 自动回归覆盖两种日期系统、日期、带毫秒日期时间、纯时间、非法闰日拒绝及保存后 Calamine 语义复读。

## 公开边界

- 普通空白单元格不会仅凭输入文本被自动转换为日期，避免隐式套用错误格式。
- `DurationIso` 表示持续时间而非时间点，当前保持只读。
- 日期公式仍按公式编辑链处理；本阶段不扩大 Excel 日期函数计算范围。
- 该能力是有界 XLSX 编辑，不代表与 Excel 全部日期格式、时区或日历行为等价。
