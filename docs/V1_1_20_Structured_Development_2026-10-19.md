# v1.1.20 结构化编辑深化

当前开发目标：`1.1.20`；当前运行时版本：`1.1.20`；当前公开版本：`1.1.19`。本版已达到未签名社区版（community-unsigned）可发布状态：保存与未保存内容保护、提纲右键、路径定位和修改差异预览已完成，固定安装包及独立同包验证通过，尚未创建正式 Tag/Release。

## 已实现

- 四格式共用文件/编辑器/读取代数/正文/签名归属。分析后不使用新路径组装旧正文写入；回执不更新另一文件；保存中的新增输入保持未保存。
- 标签缓存绑定已加载文档；未完成原生保存继续参与窗口关闭和整理保护，新实例读取同一文件等待旧写入完成。
- 重新读取取消、失败或迟到时保留草稿及既有诊断；非法源码确认绑定原文件/正文。Ctrl+S 由当前专用编辑器处理，父级不重复保存。
- 冲突复用比较弹窗，可继续编辑、另存副本，或先保留同目录 UTF-8 草稿副本再使用磁盘版本。空/非法草稿也保留，副本失败不替换编辑区，原件不覆盖。
- JSON 格式化、压缩及六类原有结构修改，经草稿核对与差异预览后应用到内存，可整项撤销；继续使用原生 token/range 保留数字、注释和未修改范围。
- 四格式提纲右键定位/复制路径/复制源码及 Enter 定位；JSON Pointer 搜索支持中文、`~`、`/`、空键和数组。过期提纲/诊断不跳到新正文旧范围。
- 修复 JSON 窄窗标签行膨胀；保存比较适配 CodeMirror 换行规范化，保留原编码/BOM/换行惯例，同时尊重末尾换行编辑。

正式 UI 前已生成并实看 [交互示意](../design/v1120-structured-editing-proposal.png)。保留全部原工具、六风格、正常动效及 SVG 严格限制；不新增格式、IDE、自动保存或日常整理步骤，常规保存仍一次操作。
