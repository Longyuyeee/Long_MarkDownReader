# YAML 工作面架构决策

更新日期：2026-07-24
状态：A4-Y1 后端分析与保存门禁已实现

## 1. 决策摘要

- YAML 源码文本是唯一事实源；首版不把解析对象重新序列化覆盖用户文件。
- Rust 使用精确版本 `saphyr 0.0.11` 和 `saphyr-parser 0.0.11` 执行 YAML 1.2 权威解析、事件统计、诊断和带位置结构大纲。
- 前端语言支持必须在实际工作面提交中加入，不保留未消费依赖。
- 有效 YAML 可进入可靠保存；无效 YAML 默认阻断覆盖，只允许在独立确认后按原始源码保存。
- 保存继续复用 A1 的工作区守卫、内容签名、编码/BOM/换行保真、可靠替换和写后语义重读。

## 2. 保真边界

YAML 包含注释、锚点、别名、标签、多文档、块标量、复杂键和多种标量样式。解析树不等同于可无损往返的源码表示，因此：

- A4 首版只提供源码编辑，不提供对象树序列化写回。
- 结构大纲只用于导航和理解，不直接修改源码。
- 未编辑的注释、空白、字段顺序、锚点、标签和标量样式全部由原始文本自然保留。
- 后续若开放结构化编辑，必须使用带范围的局部补丁，并单独证明注释和锚点语义不受影响。

## 3. 分析模型

`YamlSourceAnalysis` 返回：

- 有效性和多文档数量。
- 节点数、最大深度。
- 锚点、别名、标签和块标量数量。
- 最多 20,000 条带文档编号、路径、类型、源码范围、行列和预览的结构大纲。
- 稳定错误码、字节位置、行列和可定位诊断。

安全预算：

| 项目 | 上限 |
|---|---:|
| 单文件分析 | 8 MiB |
| 节点数 | 100,000 |
| 最大深度 | 128 |
| 大纲条目 | 20,000 |
| 单条预览 | 120 字符 |

超过源码、节点或深度预算时分析结果为无效，不进入可覆盖保存状态。大纲超过显示预算时返回截断标记。

## 4. 依赖与许可

| 依赖 | 固定版本 | 用途 | 许可 |
|---|---:|---|---|
| `saphyr` | `0.0.11` | YAML 1.2 带位置文档树 | MIT 或 Apache-2.0 |
| `saphyr-parser` | `0.0.11` | 锚点、别名、标签和块标量事件 | MIT 或 Apache-2.0 |

前端候选 `@codemirror/lang-yaml 6.1.3` 为 MIT，待 A4-Y2 工作面实际消费时再加入锁文件。

## 5. 分批顺序

1. A4-Y1：权威分析、特殊构造统计、结构大纲、稳定诊断、保存门禁和 fixture。
2. A4-Y2：格式注册、独立路由、CodeMirror YAML 工作面、诊断定位、大纲导航和可靠保存。
3. A4-Y3：有界索引、统一标签/最近/搜索接入、全量回归、真实 Tauri 验收清单和阶段审计。

## 6. 当前限制

- A4-Y1 尚未在共享格式注册表中声明 YAML，因此用户入口还未开放。
- 无效源码的显式保存能力只存在后端参数，前端确认流程尚未接入。
- 复杂键只以受限标签进入大纲，不承诺可直接编辑或生成稳定语义路径。
- 真实桌面打开、冲突、重启和大文件交互证据仍属于 A4-Y3/A5。
