## 1. 审计结论

审计范围为 v1.2.0 至 v1.2.45 的 45 次功能深化，以及当前全部 28 个主要页面和 16 个子页面。实际产品差异涉及 71 个文件；发布脚本和文档变化另行核对，不计作用户功能。基本界面没有重新堆积常驻操作，主编辑区、默认单侧导航、正常动效、六种风格和所有既有入口保留。

发现并修复的问题：

1. 外层历史列表对 JSON/JSONC、YAML、XML、TOML 仍调用 Markdown 恢复器，点击旧版本无法正确比较。现在由当前编辑器接手，直接比较所选版本；取消保持草稿，恢复只进入草稿，一次撤销回到恢复前内容。纯文本同样接入自己的历史比较器。
2. 结构化页头的“文档操作”只放了一项历史入口，和外壳重复且多一次点击。改为明确的“历史”按钮，命令入口和历史功能均保留。
3. 历史恢复后焦点没有明确回到编辑区。恢复后可以立即继续输入或撤销，无需补点正文。
4. 共享差异与历史弹窗缺少一致的窗口高度约束；历史差异较长时，恢复按钮会被挤到小窗口下方。另有一处作用域样式没有命中传送到外层的卡片内容。现在限定对应弹窗的内容区域滚动，差异与恢复操作留在固定页脚，长错误可换行；96组长差异窗口组合实际逐个检查三个恢复/取消按钮可触达。
5. package.json 的中文显示名真实存在乱码，已与原生产品名“Long编辑”统一，并纳入既有品牌检查。

## 2. 需求对齐

| 规范 | 此轮处理 |
| --- | --- |
| 功能从用户任务出发 | 阅读接续、批注、表格、结构化编辑分别核对完整任务，检查入口是否能完成操作。 |
| 右键、弹窗，不在页面摊开 | 新增字段、复制、改名、排序、删除沿右键；参数按需弹出；差异只在变更时出现。 |
| 少重复文字，介绍按需 | 保留失败原因、未保存状态和真实限制；删除重复菜单层级。没有为说明新增整行。 |
| 把空间还给主要内容 | 28 个主页面和 16 个子页面按整窗复查；页头按钮、参考区、窄正文区同时检查。 |
| 全部风格与动效 | soft、neo、glass、airy、minimal、sharp；沿原有动效，不为通过检查关闭动画或缩小字号。 |
| 草稿和失败恢复 | 核对保存后继续输入、迟到结果、撤销回原文、换文件、失败重试和外部冲突副本；旧确认不能改写新草稿。 |
