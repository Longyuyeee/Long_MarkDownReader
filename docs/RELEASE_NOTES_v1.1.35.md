# v1.1.35 · 附件引用与草稿接续

已正式发布于 2026-10-21T20:16:35Z，原安装器公开下载与摘要核对通过。

- “查看引用”现在包含当前窗口的未保存 Markdown，同一篇以草稿为准；新增或删除引用立即按当前内容查询。
- 结果区分“未保存”和“已保存”，显示行号及引用处数。打开结果保留已有输入，不用先保存。
- 查询期间或打开前内容变化时，提示刷新；读取失败只在弹窗说明，可刷新或关闭，保持主界面可用。
- 继续使用原右键和附件弹窗，没有新增常驻表单，兼容全部六种风格与正常动效。

范围：仅库内可读取的 Markdown 与当前窗口完整草稿；其他窗口、库外文件和其他格式不包含。查询不自动保存、不清理附件，空结果不代表文件可以删除。沿用单篇 2 MiB、总计 32 MiB、20000 条目限制，超限会说明。

Windows 社区未签名安装包，支持手动安装；34→35 应用内自动更新观察仍单独 pending。
