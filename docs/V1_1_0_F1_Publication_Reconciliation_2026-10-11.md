# F1 历史发布状态的只读核对

2026-10-11，接续 `feda8089`。内部后端步骤，无 UI 修改、无自动恢复、无发布版本。

## 实现

新增 inspect_publication，在同进程历史 lease 内先验证暂存，再读取有大小限制的准备/发布日志。核对日志版本、两份清单相等、来源及目标身份与调用方提供的路径一致；实际目标只由当前调用重新计算，不跟随磁盘日志指定位置操作。

返回 NotStarted（无发布意图且无标记）、TargetAbsent（有意图但目标不存在且无标记）、TargetMatches（目标快照集合、逐文件长度/摘要全部匹配）。有标记但目标不存在，或目标有额外/缺失/不同内容、日志损坏或身份不符时返回错误。目标目录及快照拒绝符号链接和异常类型；目录枚举限于清单数量，文件读取有长度上限。

不依赖内存 PublishedHistory，不信任 published 标记作成功证明；目标匹配无需标记存在。不写、不删、不重试、不清理暂存。

## 重要边界

TargetMatches 名称刻意不用 Published/Completed：相同内容可能由其他操作生成，不证明文件所有权，更不证明正文已移动或链接/标签/索引一致。TargetAbsent 也不是自动重试许可。当前来源快照是否已变、正文身份、外部进程替换、跨进程锁与断电原子性仍需上层协调。只读核对不是自动恢复流程或启动扫描。

内存和扫描仍沿用暂存上限，未做大批量恢复性能验收。当前归档入口未开放，canExecute 仍为 false。
