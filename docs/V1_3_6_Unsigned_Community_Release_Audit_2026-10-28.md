# v1.3.6：选区内查找与替换

当前开发目标：`1.3.6`；当前运行时版本：`1.3.6`；当前公开版本：`1.3.5`。当前阶段：**v1.3.6 选区内查找与替换候选**。

JSON、YAML、XML、TOML沿用现有源码查找面板，主动启用“仅选区”后限制查找、上一项／下一项、选中全部和替换范围，显示当前匹配数量。未启用时仍按全文查找；普通选文Ctrl+F仍带入查找词。范围标示随草稿编辑及撤销／重做接续，替换不自动写回。

各文件独立接续范围和查找输入；范围只在正文指纹一致时恢复。范围失效时保留输入、暂停查找和替换，用户可重新选区或关闭范围。只读文件仍可查找，保留既有保存和未保存内容保护。保持全部风格、正常动效和现有面板布局，不增加常驻介绍。JSON大文件分段查找沿原有边界；跨文件替换和软件重启后的持久化不计入本版。

检查进行中；community-unsigned，企业releaseCandidate=false。当前可手动下载安装的公开版本仍为1.3.5。本版尚未发布。NSIS实际安装、手动升级及卸载，与MSI构建和摘要分别记录；应用内1.3.5→1.3.6自动更新实际观察独立pending。

## 正则边界修正

补查发现，仅过滤全文匹配会使贪婪正则先消耗选区外文字，漏掉选区内可用的匹配。已将范围同时约束到实际游标，覆盖贪婪及跨行正则、捕获组替换和范围边界；数量、导航、全部选择、替换与高亮共同采用同一选区边界。

原生替换语法、键盘、焦点、只读保护与事务沿用CodeMirror；通过一个独立的查询工厂适配接入有界游标，并将原有依赖固定为已安装的6.7.1，未升级依赖。工厂属于内部兼容边界，由原生命令测试及实际安装任务约束；高亮只缓存当前正文的偏移，不保留正则匹配输入。后续升级依赖需继续通过这些行为检查。

旧产品54ea92469b06c966480e022106e5efb0897fd9a5的构建40700502107已取消，未进入安装复查和发布；旧源码检查不作为修正后产品的证据。修正后的本地完整98步检查、41项针对性及类型检查通过，四格式8组／72组风格窗口及上版查找和位置接续各8组／72组回归通过。最终固定源码及安装包结果将在下文另行记录。
