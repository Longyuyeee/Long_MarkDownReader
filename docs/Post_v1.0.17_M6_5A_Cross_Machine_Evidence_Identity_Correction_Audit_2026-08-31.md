# v1.0.18 M6-5A：跨电脑证据身份纠偏审计

日期：2026-08-31

阶段：M6-5 前置纠偏

发布候选：否

## 1. 结论

换机后首次执行当前开发审计，发现若干历史源码与 JSON 证据哈希失败。Git 索引中的 LF 内容、历史证据内容和产品代码均未漂移；失败来自 Windows 全局 `core.autocrlf=true` 把工作区文本展开为 CRLF，而部分检查器直接对工作区原始字节与 LF 证据摘要比较。

本阶段没有修改产品运行代码、版本、安装包、Tag 或 Release。检查器现在只把 LF 与 CRLF 视为受控文本的等价表示，并要求其中一种表示同时匹配历史字节数与 SHA-256；JPG 等二进制证据继续按原始字节核验。`.gitattributes` 同时把全部证据 JSON 与 `SHA256SUMS.txt` 标记为二进制证据，避免新克隆再次发生自动换行转换。
