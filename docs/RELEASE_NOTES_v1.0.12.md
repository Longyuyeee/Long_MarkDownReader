# Long编辑 v1.0.12

v1.0.12 是图片查看与基础编辑体验增强版本，同时修正 PDF 已实现能力在公开格式矩阵中的陈旧说明。

## 主要变化

- 图片查看支持以鼠标光标为锚的滚轮缩放，放大后可按住拖动横纵平移。
- 双击图片可在 100% 实际大小与适应窗口之间切换，方向键也可平移视口。
- PNG、JPEG、WebP、BMP 的可靠副本编辑新增亮度、对比度与饱和度调整，并提供一键恢复原色。
- 图片调整继续沿用源文件只读、新目标另存、摘要锁定和写后复开验证；GIF、ICO、AVIF 与外部图片继续只读。
- 格式能力页已准确公开 PDF 标准表单安全子集、永久脱敏图片型副本、文字水印和四字段文档属性，不再显示早期“表单只读”旧状态。

## 真实验证

- Rust 像素测试 6/6 通过；独立像素采样、源 SHA-256 不变和目标复开均通过。
- 真实 Tauri WebView2 在 1280×800 与 720×680 下验证图片调整和导航，无页面级溢出或运行时错误。
- 原生鼠标事件验证光标锚定缩放、双轴拖拽和双击切换；锚点漂移低于 2%。
- 完整 Quality Gate、无签名 MSI/NSIS 打包、托管安装生命周期和远端附件哈希复核均已通过。

## 安装与更新

- v1.0.11 用户可在 v1.0.12 发布后通过应用内检查更新；安装前需要明确确认，下载后严格核对官方 NSIS 的大小与 SHA-256。
- 社区安装包不含 Authenticode 商业签名，Windows 可能显示未知发布者或 SmartScreen。
- 只从官方 GitHub Release 下载，并核对同页 `SHA256SUMS.txt`；不发布旧 Tauri 更新器的 `latest.json` 或 `.sig`。

## 能力边界

- 图片调整是基础像素操作，不提供图层、蒙版、局部选区、直方图或专业色彩管理。
- PDF 仍不是任意正文重排编辑器；签名、加密、XFA、主动内容及不满足安全合同的结构保持阻断。
- DOCX、PPTX、XLSX 继续是有界基础编辑或可靠副本，不宣称完整等价 Microsoft Office。
