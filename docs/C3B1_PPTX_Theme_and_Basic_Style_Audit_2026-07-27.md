# C3B1 PPTX 主题继承与基础样式审计

更新日期：2026-07-27
阶段判定：**C3B1 已完成；C3B 视觉继承与对象渲染部分完成**

## 1. 本批目标与结论

本批在 C3A 安全结构化只读工作面之上建立第一条可验证的视觉继承链，不增加 PPTX 写回能力。

已完成：

1. 按 `slide -> slideLayout -> slideMaster -> theme` 关系链读取每页实际布局、母版和主题。
2. 解析主题颜色表、主字体/正文字体和母版颜色映射，支持 `srgbClr`、`sysClr` 与 `schemeClr` 基础解析。
3. 按幻灯片、布局、母版、默认白色的优先级解析页面背景，并记录背景来源。
4. 解析对象直接填充、描边颜色、描边宽度、无填充和旋转。
5. 解析基础字号、字体、颜色、粗体、斜体、下划线、水平对齐和垂直锚点。
6. 主舞台和只读放映消费上述样式；缩略导航至少消费真实页面背景，不再全部强制白底。
7. 合成 fixture 覆盖完整主题/母版继承；PowerPoint 16 与 LibreOffice Impress 真实 fixture 继续进入回归。

当前结论是 PPTX 已从“仅按坐标近似摆放对象”进入“具备基础主题和直接样式继承”。这仍不是 PowerPoint 像素级等价渲染，也不能把 C3B 或 C3 整体标记完成。

## 2. 新增模型契约

`PptxSlide` 新增：

- `backgroundColor`
- `backgroundSource`：`slide`、`layout`、`master` 或 `default`
- `themeName`

`PptxObject` 新增：

- `rotation`
- `fillColor`、`noFill`
- `lineColor`、`lineWidth`
- `textStyle`：字号、字体、颜色、粗斜体、下划线、水平对齐和垂直锚点

所有字段来自只读 OOXML 解析。没有新增保存命令，未知或不支持的视觉语义仍保持在原包中，不会被改写。
