# Long编辑 v1.0.21

状态：候选验证中，尚未公开发布。

v1.0.21 是知识图谱交互精修补丁，不扩大源文件写回范围。

## 主要变化

- 普通图谱根据节点密度设置可读缩放下限；83 节点真实场景最低为 58%，连续缩小不再误入社区泡泡总览。
- 社区总览只用于至少 240 个可见节点且聚合有效的大图，并移除稳定布局后的逐帧缓存重建，解决图标闪烁和乱动。
- 社区标题不再通过 Canvas 最大宽度压扁字形，改为一致字体与有界截断。
- 单节点详情收为右下角卡片，桌面宽度上限 380px、高度上限 520px，不再占满底部。
- 布局、主题和思维导图深度使用统一应用浮层选择器；专业、多彩、专注三种画布具有明确不同的视觉层次。

## 真实验证基线

Windows/Tauri/WebView2、1440×900、DPR 1.25、真实资料库 45 个源文件、83 节点/81 连接。连续缩小 48 次后稳定在 58%，社区总览为 false；等待 550ms 后布局帧号仍为 120，连续动画为 false；详情卡片为 380×468px，约占视口 13.72%；运行时错误为 0，测试前后 45/45 文件 SHA-256 一致。

正式发布前还必须完成完整 `ci:patch-release`、真实 MSI/NSIS 构建、从公开 v1.0.20 到 v1.0.21 的隔离安装生命周期、制品 SHA-256 和远端回下载复核。

## 安全与兼容性

支持 Windows 10/11 x64。社区安装包为 `NotSigned`，Windows 可能显示未知发布者或 SmartScreen 提示；只应从官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。
