# v1.0.15 后 M1B1B PPTX 多操作事务基础审计

日期：2026-08-26  
状态：后端事务基础通过，前端草稿尚未接入  
版本：不提升版本

## 目标与结果

本阶段把 PPTX 从“一次验证并保存一个操作”推进为 1–64 个有界操作的确定性事务。事务按顺序在同一内存输出上执行，只在全部操作通过后产生统一输出摘要；原文件保存只校验一次源签名并可靠写入一次。

新增事务预览与事务原文件保存命令。空事务、超过 64 个操作、同一目标重复修改、失效对象摘要和外部修改均明确阻断。最终输出必须通过 PPTX 结构复读、每步语义复读和完整事务逐字节重放；写后失败沿用 M1B1A 的原文件恢复保护。

## 预期与实际差异

| 项目 | 修正前实际 | 目标 | 修正后实际 |
| --- | --- | --- | --- |
| 多操作事务 | 无 | 支持 | 后端支持 1–64 个操作 |
| 确定性重放 | 单操作 | 完整事务一致 | 通过 |
| 冲突目标 | 保存时自然失败 | 提前明确拒绝 | 通过 |
| 三生产者组合操作 | 无 | 3/3 | 3/3 通过 |
| 前端统一草稿 | 无 | 下一阶段 | 仍关闭 |

首次编译因测试的 `unwrap_err()` 要求内部成功类型实现 `Debug` 而停止；补充诊断派生后保持原冲突断言并重跑通过，没有降低行为要求。

## 真实测试

Microsoft PowerPoint、WPS Presentation、LibreOffice Impress 三份真实 PPTX 均执行两操作事务：修改真实文本对象并反转真实幻灯片顺序。预览期间源字节不变；保存输出与预览逐字节一致，目标文字可从重开模型提取，结构、语义和确定性重放通过。旧签名再次保存被拒绝且文件不再变化；重复文本目标在执行前被拒绝；临时目录无可靠写入旁路文件。M1B1A 三生产者单操作原文件保存同时完成回归。

证据：[`docs/evidence/post-v115-m1b1b-pptx-transaction/`](./evidence/post-v115-m1b1b-pptx-transaction/)
