# 本机元数据分块与原生内存验证

在移动分支codex/mobile-0.1.0-foundation、基线287d6497e上，处理审计中保留的原生大包故障。五类元数据改为小块IPC和Rust文件读写；同一API29模拟器上，原来的超限直连探针现在正常返回5 MiB限制，四类5 MiB记录和512 KiB书签均完整保存、读回。正常阅读页沿用原设计，保留失败重试、定位弹窗、问号说明和逐层返回。[实页原图册](evidence/mobile-native-metadata-memory-2026-10-30-final/review.html)包含原始失败、设计对照、采样与数据保护记录。

接入前先冻结[交互约束](design/mobile-metadata-transfer-v1/Interaction.md)，复核[KOReader用户指南](https://koreader.rocks/user_guide/)中的阅读屏、按需菜单、小屏PDF及内存注意事项；[Play Books离线说明](https://support.google.com/googleplay/answer/16914689?hl=en-CA)以完成后的状态表达可用性；[calibre Content server](https://manual.calibre-ebook.com/server.html)补充手机浏览器离线任务参考。未称作本轮竞品安装走查，也未据这些资料推断其内部存储。对应本项目的决策是：后台保护数据，收到真实保存确认后才报告成功，正常页面不增加技术说明或进度面板。

## 定位与实现

旧APK精确复现：writeSourceReading一次传入5 MiB＋1字节，返回Java分配失败，日志显示目标／增长上限16,777,216字节。系统heapsize属性为512m，不能把该属性误写成实际ART增长上限；原记录摘要未变。新包在Rust转发前处理同一请求，返回预期预算错误。由此定位到旧的整包Android插件转发链；日志未提供足够堆栈区分JNI、Jackson参数解码中的具体分配位置。旧链后续还会整串解码、构造JSONObject并整串回传。本轮没有调整堆配置或添加largeHeap。

- 覆盖普通文本位置、分段长文现场、PDF位置、PDF批注恢复及书签。保持文件名、版本、5 MiB／512 KiB整封套预算及仓库接口，不裁剪外来记录或未知字段；浏览器预览保持独立。
- 前端每块最多16 KiB原始字节，以base64传输；核对偏移、长度、规范base64和整份SHA-256，再严格解码UTF-8。中文／emoji可以跨块，BOM不会被剥离，孤立代理项拒绝替换。实际最大请求为21,923个ASCII字符。
- Rust同一互斥锁处理新通道及五类旧命令。目录来自原生filesDir，文件名固定枚举；页面不能提供绝对路径。核对大小、严格UTF-8、版本、封套对象、重复关键字段及完整JSON；封套访问器跳过外来值，不建立全部资料的JSON树。
- 最多4个会话，各自最多5 MiB有效字节；闲置120秒在后续命令清理，结束／异常路径主动释放。会话有效数据上限20 MiB不等于进程总预算，读取、校验、读回和WebView仍有额外分配。读会话是稳定快照，写会话在提交前不触碰正式文件。
- 提交重新读取并比较当前文件摘要，使用本次随机临时文件、文件fsync、原子替换及目录fsync，随后读回字节确认。冲突／损坏／未来版本不覆盖。Android遗留.bak先完整验证再恢复；原生错误不回退浏览器。提交前失败清理本次临时文件；进程在提交中被强杀可能留下随机未提交文件，本轮未自动清理。

## 实页与验证

分页栏、定位层继续使用[已冻结组件](design/mobile-native-source-position-v1/revision-root/freeze.json)，本轮没有改页面样式。[几何核对](evidence/mobile-native-metadata-memory-2026-10-30-final/alignment.json)确认分页栏390×61、应用坐标y711，定位层尺寸及左右边距一致。浏览器28px预览条造成弹窗中心差14px已单列；320×372、200%字号的标题、关闭与两项操作均可见／可命中。原生CSS视口393.09px，保留完整截图；冻结稿正文是示意，未声称Android整屏像素一致，截图未重画或移动像素。

[内存记录](evidence/mobile-native-metadata-memory-2026-10-30-final/memory-summary.json)含37次主进程采样，Dalvik已分配列最高2,841 KiB；新包两个原生日志未出现OOM。采样不是绝对峰值，也未包含全部渲染器进程。带采样的开发模拟器上，5 MiB完整写入再读回约6.4–8.2秒，512 KiB约0.7秒，不作为发行性能指标。

保留失败：初次预览服务未启动，两份回归连接拒绝；旧PDF脚本查找旧常驻缩放入口超时，随后使用现有新版设置／导航任务脚本通过；初次host测试解析了无关桌面Tauri依赖而中止，将插件Tauri依赖限定Android后执行实际元数据测试；首次归档遗漏Python UTF-8编码而失败，原部分目录保留，完整图册另存-final。没有为通过测试重新加入旧入口。

## 数据与候选收尾

测试前后采集files、shared_prefs、app_webview完整TAR及提供器TAR。175个既有文件和302个提供器文件逐项核对，103资料、9草稿、12条最近身份和4项待接收保持。五个元数据文件在各原生阶段结束均还原原字节，三个已捕获旧WebView键在冷启动后仍相同。

首次严格收尾发现WebView日期缓存由10/29/26变为设备当天10/30/26。[失败TAR差异](evidence/mobile-native-metadata-memory-2026-10-30-final/first-closeout-diff.json)保留；逐XML节点证明仅日期变化后，在停止应用后从已核对摘要的基线TAR恢复该缓存。[最终保护](evidence/mobile-native-metadata-memory-2026-10-30-final/closeout-final.json)仅允许安装派生profileInstalled变化，24字节结构及时间与实际APK更新时间一致；其他既有文件严格相同。实际输入法、辅助服务、旋转、联网和夜间设置保持，专用9559转发移除、sync后停止AVD。
