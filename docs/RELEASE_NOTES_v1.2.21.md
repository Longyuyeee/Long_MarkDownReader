# v1.2.21：YAML 字段新增与删除

在 YAML 提纲的映射或字段右键“新增字段…”，自动使用当前映射，输入名称和值后预览；名称保持字符串键，预览显示值的实际类型。支持空文档、空映射和归属明确的块式／流式映射。

字段右键“删除字段…”直接预览，先支持单行简单值；保留其他字段和注释，最后一项删除后仍是空映射。多行、集合或锚点依赖等复杂内容局部说明并提供源码定位。

应用仅改草稿，可独立撤销／重做，显式保存才写盘。输入错误保留名称和值，继续保护后续输入、失败重试与外部冲突副本；保留全部功能、主题和正常动效，不增加常驻表单。
