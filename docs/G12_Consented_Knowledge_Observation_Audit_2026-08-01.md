# G12 用户授权知识网络匿名观察审计（2026-08-01）

## 结论

G12 已实现真实资料库观察所需的授权与隐私边界。设置页新增“知识网络匿名观察”：先从当前资料库计算聚合指标并向用户展示预览，只有用户明确确认并自行选择本地 JSON 保存位置后才会写出回执。LongEdit 不会自动上传、发送或同步该回执。

导出的匿名观察回执不包含正文、文件名、对象 ID、绝对路径、凭据或其他可还原资料库内容的数据。

当前状态为 `consented-aggregate-observation-export-implemented-user-execution-next`。能力已经实现，但尚未由用户在其真实资料库上授权执行，因此不能声称真实资料库观察完成，`releaseCandidate=false` 不变。

## 回执内容

允许写出：对象数、关系数、已连接数、孤立数、覆盖率、对象类型计数、关系类型计数和四档连接度分布。

明确排除：文档正文、文件名、对象 ID、绝对路径、资料库名称、保存搜索、凭据和原始错误文本。后端使用 `create_new` 写入，拒绝覆盖已有文件；前端必须先预览、再明确确认、再选择保存位置。

## 验证

Rust 隐私回归使用带有虚构机密标题、对象 ID 和 `C:\\Users\\Alice\\SecretVault` 路径的图谱，序列化观察回执后逐项确认这些内容均未泄漏。机器合同同时锁定命令注册、预览确认流程、无自动上传声明、聚合字段与排除矩阵。

## 下一步

下一步必须由用户决定是否在真实资料库上执行：软件先展示聚合预览，用户可取消，或保存本地 JSON 后自行检查。只有用户主动提供该匿名回执，才能进行覆盖率、孤立比例、关系语义分布和连接度分析。不得要求或上传资料库正文，也不得用合成资料替代真实资料库结论。

本阶段不改变 R5N 发布边界。正式 1.0.0、自动更新与 GitHub Release 仍需代码签名、签名 Windows 10/11 客户端证据及人工批准。
