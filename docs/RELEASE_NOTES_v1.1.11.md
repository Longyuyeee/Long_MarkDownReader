# Long编辑 v1.1.11 · 图谱探索更连贯

## 在图谱中继续探索

- 图谱刷新保留当前视角、有效选择及节点位置；失败保留最近有效图，底部提示并可重试，刷新时仍可浏览和拖动。
- 请求按资料库与代次核对；切库、离开页面后的迟到成功或错误不能覆盖新图，旧库坐标不会写进新库。
- 从直接邻居局部视图返回时恢复之前的相机；思维导图刷新保留模式、中心及视角。
- 治理主题先于图谱完成加载时，点击不再被忽略；图谱就绪后接着定位到所选主题。
- 搜索定位进入可辨认的实际节点，长名称按像素宽度处理，选中/悬停名称优先避让；悬停和详情保留全文。
- 平移画布保留选择，空白单击才清除，单击节点选择、双击才打开文件。短窗中详情、缩略图和重试操作不互相遮挡。
- 复用拓扑索引与缩略图静态点层，减少重复工作；保留现有五种布局、三种图谱主题、六种界面风格及正常动效。

这些改进只影响图谱浏览和设备上的布局状态，不自动保存文档正文，不删除节点/关系或原有工具。浏览器与真实安装态证据分开登记；不以单项时间数据宣称所有场景都更快。

Windows 10/11 x64 未签名社区版，系统可能显示“未知发布者”；提供 MSI、NSIS 与 SHA-256。应用内自动更新需要独立观察，不能由手动安装或 Release 成功推断通过。
