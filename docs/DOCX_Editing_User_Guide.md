# DOCX 日常编辑与保存

从资料库打开DOCX，点击正文、列表或受支持的表格单元格，或在“页面编辑”的目标列表中选择。修改先留在内存草稿，正文会显示草稿效果；切换目标和关闭面板不会自动保存或清空。修改清单可定位、移除单项，工具栏可撤销/重做；一次最多32项。

## 保存原件或给同事一份副本

直接点击工具栏“保存”、面板“保存到原文件”或按Ctrl+S，确认后才覆盖原件。软件自动检查当前原件是否被外部修改、隔离修改是否保真以及写盘后能否复读，不需要先点技术验证。保存期间短暂锁定相关输入，完成或失败后恢复。

不想覆盖原件时，在“或者另存副本”填写同目录的新DOCX名称，再点“另存新DOCX并打开”。遇到同名文件不会覆盖，草稿会保留，换一个名称后重试。安全检查详情仍可展开，但不是保存的额外前置步骤。

切换页面时可继续编辑、明确放弃，或保存后离开。“重新读取”会询问是否放弃草稿；取消和读取失败保留草稿。若提示文件已经写入但页面重新读取失败，先核对原件再重新读取，不要因未看到新页面就反复另存。

## 不能直接改的内容

可在原有“文本、字符、段落、图片说明”中编辑受支持目标；段落样式只选择当前文件已有定义。复杂域、修订、复杂表格/对象以及附属内容的限制仍以当前文档提示为准，不能通过删除它们来开放编辑。DOCX不是完整Word排版编辑器。外部文件只有用户授权的只读预览，不提供写回；直接构造外部地址不会绕过授权。
