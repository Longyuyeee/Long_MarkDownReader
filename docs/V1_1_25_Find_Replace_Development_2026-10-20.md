# 1.1.25 当前文档查找替换：开发与发布接续

当前开发目标：`1.1.25`；当前运行时版本：`1.1.25`；当前公开版本：`1.1.24`。当前阶段：**v1.1.25 当前文档查找替换候选**。

已实现：Markdown 三模式和外部 Markdown 的文档菜单、Ctrl+H 紧凑弹窗；TXT 接续原查找入口。支持整篇/打开前选区、上一处/下一处、大小写、Unicode 整词、逐个替换与全部替换预览。改动只落当前草稿，可一次撤销，继续显式保存及冲突副本。选择重复文字时按准确源码范围操作，不根据第一个同名文本猜位置。

沿用原生 Ctrl+F；Markdown 基于源码匹配，可包含语法和代码。无法可靠映射的可视选区不开放选区修改；会导致额外 Markdown 规范化的替换提示到源码模式操作，不改原稿。结构化专用编辑器沿用现有查找。正文/结果 2 Mi 字符、查找词 4096、10000 命中限制均在修改前检查，不部分替换。
