# Long编辑 v1.2.4：表格选区填充

选中表格单元格后右键“填充选区…”，一次输入即可填入整组选区。默认只填空白，也可替换选区内的值；全部目标先校验，失败保留输入，成功后可一次撤销、重做。筛选排序后仍按原选中行列修改，保留隐藏行、已有值、前导零和长编号。

单元格右键统一提供复制、剪切、粘贴及清空，剪切在复制成功后才清空草稿。修复从同文件行引用定位时重新读取磁盘、丢失未保存表格和历史的问题；当前草稿直接接续，保持已有保存失败重试与外部冲突保护。

适用于已有 Table、CSV/TSV 编辑范围。原有功能、风格和正常动效保留，不增加常驻表单。未签名 Windows 社区版；固定产品构建、完整发布检查、426 项安装版功能任务和 NSIS 安装升级检查通过，公开附件核对尚待完成。应用内更新实际观察独立记录。
