# 接续 PDF 批注与阅读笔记

在 PDF 批注条目上右键，或点击条目旁的菜单，选择“编辑评论…”。评论在弹窗编辑，不跳离当前阅读位置；选中批注下方原有的评论框仍可使用。切换到笔记后返回 PDF，会在本次应用运行中恢复筛选、列表分组、勾选和阅读位置。来源 PDF 变化时不恢复旧批注定位。

新版“整理为笔记”生成的内容带有隐藏的生成记录。打开这篇 Markdown，选择“文档操作 → 更新 PDF 阅读笔记…”，先看变化再更新当前草稿；PDF 整理窗口选择已打开的笔记后也可直接进入更新预览。更新后可撤销/重做，需手动保存，不会代存其他笔记。

默认只更新原来选择的批注。勾选“加入生成笔记后新增的批注”，才加入后来新增的内容；原来没有选中的批注仍不加入。已删除批注默认保留摘录，也可以明确勾选移除。

生成范围之外的补写完整保留。若在生成内容内部做过修改，不直接替换，可选择“保留原文，追加新版”，或取消保留原笔记。旧笔记没有可靠的生成记录时不猜测替换范围，可从 PDF 重新整理后插入或新建。源码模式可以看到隐藏记录，请保留这些标记；删除或损坏后只保留原文，不自动接续。
