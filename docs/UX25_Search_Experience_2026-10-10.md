# UX25-1 搜索体验：现有能力与首个改进

## 当前进展：固定参考与带来源摘录（UX-N2 首个切片）

搜索内容预览可以“固定为参考”，在编辑区旁保留 Markdown / 普通文本原文、PDF 提取文字或已有批注。切换笔记、搜索词、筛选和侧栏时保持参考；点击其他结果的预览会替换当前参考。切换知识库或关闭面板清除参考；暂不跨页面卸载或重启保存。窄窗口改为上下布局，不覆盖主编辑区。

在参考文字中选择需要的段落，可“复制选中文字及来源”，然后粘贴到笔记。来源采用当前知识库相对路径，PDF 保留页码和批注标识；在 Markdown 中点击来源链接可打开对应文件。复制失败可重试；更换资料时清除旧选区和复制状态。尚不直接插入主编辑器，也不提供源文件改名后的链接追踪。

相关 17 项回归通过，覆盖固定参考后的搜索变更、跨库清理、迟到响应、复制失败重试、特殊路径及真实来源点击路由。TypeScript 检查与生产前端构建通过；尚未进行真实桌面视觉验证，未生成安装包。

参考仍为磁盘上的有界文字预览，保留部分内容提示，不能视为全文阅读或 PDF 原版排版；已有未保存草稿不受影响。下一步根据这一流程完善参考入口和写笔记时的摘录操作。以下为历史切片。


## 当前进展：文内多处匹配导航

打开 Markdown / 普通文本正文结果后，提供可关闭的“上一处 / 下一处 / 重新定位”导航条，显示当前位置与匹配总数并首尾循环。Markdown 保留编辑模式、按当前可搜索的编辑内容计数；范围读取的文本明确标注“已加载内容”。无匹配时保留说明和重新定位入口。

输入时只使计数失效，下一次跳转重新读取当前草稿，不逐键扫描全文。Markdown 跨行内格式的文字仍可匹配，不将两个段落拼成伪命中；长段落滚动依据关键词实际位置。导航不改写文档、不重置撤销历史，关闭导航条不关闭文档。匹配采用字面、不区分大小写、非重叠规则。

验证：搜索相关回归及新增的跨节点定位、段落边界、长段落滚动用例均通过（合计 31 项）；TypeScript 检查与生产前端构建通过。尚未做真实桌面交互验证。

下一步继续处理阅读资料时的摘录与来源衔接，优先减少“看资料—切笔记—找回来源”的操作。当前仍为 v1.0.25 开发分支，未发布安装包。以下为历史切片。


## 当前进展：打开正文结果后定位关键词

Markdown / 普通文本正文结果现在携带独立定位意图，打开后选中当前内容中的首处匹配；重复点击同一结果可以再次定位。Markdown 保留当前编辑模式，不重新读取或改写文档；文本编辑器只更新选区和滚动位置。文件名、标签匹配不冒充正文命中。Markdown 渲染后不可见的标记、已修改草稿或文本范围模式中尚未加载的匹配，会给出对应提示和文内查找建议。

同时修复 Markdown 恢复已有草稿时错误清除未保存标记的问题，并阻止旧文件加载回调更新新文件状态。搜索仍依据磁盘索引，而定位使用当前编辑内容；本轮是首处匹配定位，不是逐处搜索导航。

本轮搜索相关 28 项定向回归通过，TypeScript 检查与生产前端构建通过。定向回归覆盖 Unicode 选区偏移、重复打开、草稿选区、Markdown 等待正确文档及失效提示。下一步从实际使用角度串联搜索、预览、打开和返回，并完善多处匹配的文内查找衔接。未构建新安装包，版本仍为 v1.0.24。以下为历史切片。


## 当前进展：返回搜索结果

UX25-1D 的返回体验已实现：打开结果时记住选中项和列表滚动位置，侧栏提供“返回刚才的搜索结果”，切回文件页并定位、聚焦原结果。离开页面再回来时，在本次应用会话中按知识库恢复关键词、格式筛选和选中项，重新搜索完成后恢复位置，不复用旧结果列表。查询或筛选改变时清除旧选择；结果变化时提示重新选择，刷新失败时保留恢复目标供重试。

本轮只改前端，搜索/预览/返回相关 24 项回归及生产前端构建通过，覆盖离页恢复、失败重试、结果消失和跨库隔离。会话最多记住 8 个库，关闭软件后不保留；这不是常用搜索保存功能。下一步补齐 Markdown/普通文本命中定位；之后再集中体验整个“搜索—预览—打开—返回”流程。以下为历史切片。

## 当前进展：只读内容预览

UX25-1C 已接入“预览内容”：Markdown/普通文本展示原文，PDF 展示对应页的提取文字、已有 OCR 或批注。面板无遮罩、不切换当前编辑文档，可选择复制；支持关闭、Escape、重试以及确认后打开文件。切换查询、知识库、格式筛选或侧栏时关闭旧预览；快速切换结果和关闭后的迟到响应不会覆盖当前内容。

预览读取磁盘内容，不显示未保存草稿；最多展示命中附近约 8,000 字符，并提示截断。PDF 文字预览不等于原页排版，无法提取时提供打开文件入口；暂不新增 OCR。其他格式继续使用原摘要和打开功能。

本轮预览/搜索相关前端 30 项、Rust 搜索模块 13 项回归及生产构建通过，不重复旧安装流程；未构建新安装包。下一步 UX25-1D：返回搜索结果时恢复查询、筛选、选中项和位置，并补齐 Markdown/文本定位。以下为此前切片记录。

## 当前进展：同文件结果分组与可定位的多命中

2026-10-10 第二个切片已实现：同一文件的结果集中展示，显示本组条数；同名但不同路径的文件保持分开。每条结果继续保留原有打开入口、摘要、页码/对象标识，不让用户先打开文件才能辨别不同位置。

- 索引搜索：有页码、批注或对象定位信息的同文件同类命中最多返回 5 项；相同定位身份去重后再计数，避免重复项挤占有效结果。
- PDF 实时搜索：正文与已有 OCR 文本均最多返回 5 个匹配页，批注保留最多 5 项，并统一命中附近摘要。缓存路径使用相同的有界多命中规则。
- 未具备逐处定位信息的结果仍保持原有限制，特别是 Markdown/普通文本，不宣称本轮已支持全文每处匹配访问。
- UI 明示“限量展示，不代表全部匹配次数”；全局上限仍为 200 项，组内条数是实际展示结果数，包含可能的文件名命中，不能当成正文出现次数。
- 保留后端相关性顺序：文件按首次出现排序，组内按原结果顺序排列；前端只去掉完全相同的结果身份与摘要，不把同页不同批注合并。

验证完成：前端 34 项、Rust 搜索模块 12 项、生产前端构建及既有文件/对象路由合同均通过。PDF 双页样例在实时与缓存搜索均返回两页；去重、每类上限及不同对象身份有独立回归。真实桌面视觉和安装包验收尚未进行。下一步进入 UX25-1C：选择结果后查看有界只读预览；Markdown/文本定位能力和跨页返回恢复仍待独立实现。以下首个切片与盘点表保留为历史。

## 用户任务

用户希望先判断搜索结果是否相关，再打开对应位置；不应为了看完摘要而离开正在编辑的文档。当前版本保持 v1.0.24；本文件记录下一版开发，不代表已发布。

## UX25-1A 盘点结果

| 环节 | 已有能力 | 实际缺口与处理顺序 |
| --- | --- | --- |
| 搜索反馈 | 防抖、重试、失败/空结果区分、跨库过期响应保护 | 复用，不重写调度 |

| 摘要 | 找到匹配行并返回最多约 220 字符 | 原实现截取行首，长行后部关键词会消失；先改为围绕命中位置取摘要 |
| 多命中 | 索引结果附带路径、类型、定位信息 | `search_segments` 对同文件同类命中有限制（通常一项、批注五项）；不能仅前端分组就宣称支持全部命中 |
| 打开定位 | `openManagedObject` 复用已有页码/对象定位；Markdown/文本使用文件路由 | 后续核实段落/行定位和失效提示，不伪造定位成功 |
| 返回恢复 | 当前库内搜索状态随组件保留 | 路由切换后的查询、筛选、选中项和滚动恢复仍需专项实现与验证 |

## 首个实现切片：UX25-1B 摘要可辨识

- 命中行摘要包含匹配位置，保留前后文和截断标记；支持中文、emoji 和大小写转换后长度变化的字符。实时正文搜索与索引片段搜索共用此逻辑。
- 标题与摘要增加字面关键词高亮，保留原字符，通过 Vue 文本插值输出，不将文档内容作为 HTML 执行。
- 独立的“查看命中摘要”入口在原列表展开已有摘要，允许选择复制文字，不触发打开、不切换标签、不改动草稿。
- 标注“搜索摘要，非全文”，不把有限摘要当作文件预览。现有文件打开及图谱入口保持原行为。

本切片不包含完整文件预览、同文件多命中分组或跨页面返回恢复。下一步核实多命中的稳定身份、上限与定位合同，再完善分组及独立命中访问；UX25-1C 文件预览单独实施。未使用索引的 PDF 批注仍使用原摘要取法，后续需统一。
