# P1-B2B5 PDF 单选组可靠副本审计

日期：2026-08-15
状态：已完成；下一入口为 P1-B2B6 Choice 下拉/列表字段审计

## 1. 需求对齐与结论

本阶段继续服务“在管理器内完成日常阅读、基础编辑和体系化管理”的初始目标。单选组编辑被接入原左侧资料库、右侧 PDF 工作区，没有新增窗口、路由或另一套视觉体系。输出仍是可靠新副本，不覆盖源 PDF，也不代表支持任意 PDF 正文编辑。

安全子集要求父字段与至少两个页面 Widget 明确关联；每个 Widget 的 `/AP /N` 必须同时包含非空 `Off` 和恰好一个非空导出状态；组内导出状态必须唯一。动作、歧义字段树、重复导出值、缺失外观、push button、XFA、JavaScript、签名和加密 PDF 均继续阻断。

## 2. 实现审计

- 后端统一枚举每个按钮 Widget 的真实导出状态，不依赖 `Yes` 等假定值。
- 写入时父字段 `/V` 使用所选导出 Name；选中 Widget `/AS` 使用同名状态，其余 Widget `/AS` 强制为 `Off`。
- 保存后重新解析规范字段树与所有 Widget，逐个复核有效值、正常外观和互斥 `/AS`。
- UI 只在安全结构成立时显示原生 radio 控件，选项顺序来自关联 Widget；控件沿用现有字号、主题色、圆角与侧栏宽度。
- 纯按钮副本不嵌入文本字体，也不重写原有外观流。

## 4. 自动门禁

`npm run check:p1b2b5-pdf-radio-copy` 复核后端互斥算法、UI 安全条件、fixture 字段树、契约、截图完整性、宽窄屏、源文件不变、字段/Widget 回读和双向像素变化。Rust 测试 `writes_mutually_exclusive_radio_widget_states` 覆盖合法切换和非法导出值拒绝；既有文本、Unicode 与复选框回归测试继续保留。
