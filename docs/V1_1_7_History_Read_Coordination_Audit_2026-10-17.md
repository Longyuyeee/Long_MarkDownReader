## 代码审计与最小修正

`HistoryVersionList.vue` 与其宿主会分别请求历史正文列表、版本备注。原有 `history_coordination` 只有进程内 fail-fast 独占租约；两个只读请求也可能互报忙。暂停前 `0e045ad2` 已移除正文列表的租约来允许并行，但单纯无锁又不能防止读取期间由保存保留策略、清理或移动改变目录。这是代码并发边界风险，不声称已复现用户历史丢失。

本批将该协调器改为**同缓存共享读取、修改独占**：

- `list_history`、`get_history_metadata` 在路径解析前获取共享读取保护，允许同缓存、跨线程同时读取。
- 保存快照、保留/备注、删除、全局清理、移动历史及比较/恢复原有独占协调保留，读写互斥；失败快速返回，不在 UI 线程等待锁。
- 最后一个读取结束后释放占用；读取报错或调用退出也释放。规范化缓存身份沿用 Windows 大小写、分隔符和尾斜线规则，不同缓存不互相阻塞。
- 恢复前磁盘/历史签名核对、草稿保护、重要版本保留、A→B→A 时间线均未改。
- 列表读取抽出目录级函数以便真实磁盘测试；仅缺少历史目录返回空，文件占位、坏 UTF-8 或读条目失败仍报错。未发布临时侧写不显示为历史。

保护只覆盖本进程参与该协议的操作，不冒充跨进程文件锁或正文/备注两个独立 IPC 请求的事务快照；外部改动仍需错误反馈和恢复时签名核对。

本批没有正式 UI 修改，沿用本版已确认示意；没有删功能、关动效、新增日常操作或接管用户桌面。仅为浏览器驱动增加独立端口及输出目录选项，保留原断言，避免占用用户 9000 和覆盖旧证据。
