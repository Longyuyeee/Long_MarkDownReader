# 品牌图标实心金色审计

日期：2026-08-03
状态：完成，待补丁版本打包验证

## 需求对齐

根据用户反馈，原金色线框 `L` 在窗口标题栏、任务栏和 16px/32px 小尺寸场景下识别度不足。本步保留深海军蓝圆角底、原有位置和钢笔/书页轮廓比例，将中心 `L` 改为实心金色，并在第二轮反馈后整体等比放大约 15%，不改变产品名称或其他 UI 结构。

## 资产处理

- 保留 `longedit-icon-v1.0.1.png` 作为已发布版本历史母版。
- 新增 `longedit-icon-v1.0.2.png` 作为实心金色当前母版，并恢复透明圆角外区。
- 由当前母版重新生成 Tauri 的 PNG、ICO、ICNS、Windows、iOS 和 Android 图标集合。
- `icon.png`、`public/icon.png` 与 `src-tauri/icons/icon.png` 使用同一 512px 输出。

## 审计结果

人工复核 1254px 母版、512px 主图和 32px 小图，放大后的实心 `L` 均保持清晰，四周仍有安全留白，透明圆角和深蓝背景完整。`check:brand-icon-contract` 校验新旧母版分离、关键尺寸、主 PNG 同步和平台图标存在，并已加入补丁发布门禁。

本步只完成品牌资产替换，不声称 `1.0.2` 安装包已经生成；后续打包时仍需检查 Windows 文件图标、任务栏图标和安装程序图标的真实显示。
