# v1.2.11：XML 属性值编辑与准确数字预览

当前开发目标：`1.2.11`；当前运行时版本：`1.2.11`；当前公开版本：`1.2.10`。当前阶段：**v1.2.11 XML 属性值编辑候选**。

## 用户操作与范围

XML 元素右键“修改属性…”打开必要弹窗，多属性时按需选择，预填并选中可读原值；输入 `&`、尖括号、单双引号和多行文字会按原引号正确转义，空值与有意空白也可保留。弹窗内切换属性暂存各自输入，差异预览只应用当前选中的一个属性。错误原地解释且保留输入，不增加常驻属性表。

支持现有普通属性和带前缀属性；同名兄弟元素按完整路径及实际原文范围定位。命名空间声明、未解析实体、特殊控制字符和未提供准确范围的属性保留源码入口。SVG 沿现有图形与源码能力使用，不在本版加入属性弹窗；XML 叶节点文字编辑留待 1.2.12。

## 原文与草稿保护

属性范围从 quick-xml 原始标签和值的借用范围推导，再对照原文、引号验证，不搜索字段名或重写整份文件。修复 BOM 前缀后的字节定位；只替换当前属性值，保留其他属性、顺序、空格、注释、处理指令、换行和长数字。实体与原始属性空白按 XML 版本读取，未改动可读值时保留原有写法；修改后再次验证实际可读值与输入一致。

沿已有差异预览、独立撤销、显式保存、失败重试、外部冲突和历史接续。来源变化关闭旧菜单、弹窗与差异，异步返回不覆盖后续输入。补齐未闭合元素和根外正文诊断；仍可通过已有“按源码保存”明确保留无效源码。保留全部现有功能、风格和正常动效，长路径和窄窗口下保持操作可达。
