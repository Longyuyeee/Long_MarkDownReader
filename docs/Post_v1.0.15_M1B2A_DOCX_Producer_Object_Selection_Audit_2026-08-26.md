# v1.0.15 后 M1B2A DOCX 生产者对象选择审计

日期：2026-08-26  
状态：通过  
版本：保持 `1.0.15`，`releaseCandidate=false`

## 1. 目标与结论

本阶段使用 Microsoft Word、WPS Writer、LibreOffice Writer 各一份基础 DOCX 和超链接 DOCX，盘点页眉页脚、表格、图片布局、段落样式与超链接的真实读取和编辑边界。本阶段只选择下一对象，不开放新写回能力。

结论是现有 DOCX 能力没有路线图最初假设得薄弱：安全正文、普通表格单元格、原生超链接标签、基础字符样式与内联图片替代文字已有隔离编辑、草稿历史和显式保存。真正一致存在于三生产者、但尚未编辑的是**段落样式引用**。因此 M1B2B 选择“简单顶层段落在 `word/styles.xml` 已有样式之间切换”，页眉页脚、浮动图片、合并表格结构和 WPS 域超链接继续只读。

## 2. 预期与实际差异

| 对象 | 预期 | 当前真实结果 | 结论 |
| --- | --- | --- | --- |
| 页眉页脚 | 三生产者评估 | Word `3/3`，WPS/LibreOffice 基线均为 `0/0` | 跨生产者证据不足，不选择 |
| 表格 | 常用内容可编辑 | 三份均有 1 表；安全单元格目标 `5/6/6` | 已有能力；合并结构继续只读 |
| 图片 | 三生产者可定位 | 均有 1 图；替代文字目标 `1/1/0` | 布局与 LibreOffice 元数据证据不足 |
| 字符样式 | 三生产者基础编辑 | 安全目标 `13/0/0` | 不是跨生产者通用能力 |
| 段落样式 | 至少可读取并选择已有样式 | 定义数 `21/2/8`，三份均有样式引用 | 选为 M1B2B 最小对象 |
| 超链接 | 原生标签有界编辑，域链接只读 | Word/WPS/LibreOffice 为 `2/0/2`；WPS 4 个域链接保持只读 | 当前边界正确 |

修正前的宽泛预期是五类常用对象都需要新增编辑；实际只有段落级样式切换同时满足三生产者事实、明确用户价值和较小包结构影响。该差异缩小了开发范围，避免重复实现或冒险触碰证据不足对象。

## 3. 真实测试

- Rust 直接解析 6 个真实物理 DOCX，并输出文件大小、SHA-256、对象计数和可编辑目标数。
- 校验器将每个摘要重新与生产者 manifest、超链接矩阵和磁盘文件计算结果比对。
- Word/WPS/LibreOffice 基础文件均确认 1 个表格、1 个图片、至少 1 个节和已引用段落样式。
- 超链接可编辑标签数严格复核为 `2/0/2`，没有把 WPS 域代码误判为安全标签。
- 既有隔离补丁回归继续要求只修改 `word/document.xml`，其他包部件逐字节保持，并执行结构与语义复读。

首次门禁运行发现校验脚本把矩阵内相对文件名错误解析到仓库根目录，导致 `ENOENT`；Rust 对象库存本身已通过。修正为相对 `fixtures/docx/producers/` 解析后，六份证据和门禁均通过。这一差异已保留为审计过程的一部分。

既有 `check:docx-producer-matrix` 的生产者矩阵、超链接矩阵和桌面证据均通过，但历史 UX-33J 已安装证据因应用版本已变化到 `1.0.15` 而按合同拒绝。M1B2A 没有修改 UI 或安装包，因此不复用旧安装截图作为当前证明；M1B2B 接入前端后必须重新采集当前版本的真实安装态证据。

机器证据：[`docs/evidence/post-v115-m1b2a-docx-object-selection/`](./evidence/post-v115-m1b2a-docx-object-selection/)

## 4. M1B2B 验收边界

下一阶段只实现简单顶层正文段落的已有样式切换：

1. 候选样式必须已定义于当前文件 `word/styles.xml`，不得创建、删除或改写样式定义。
2. 目标仅限安全顶层正文段落；表格、页眉页脚、域、批注、脚注尾注和复杂段落属性必须拒绝。
3. 预览和撤销不写盘；只有点击保存才进入现有签名、隔离补丁、可靠覆盖与重开验证链路。
4. 修改目标、`word/document.xml` 未改区段及所有其他包部件分别核对；未知关系、媒体、页眉页脚和高级对象逐字节保持。
5. 三生产者临时副本均完成修改、撤销/重做、显式保存和结构语义重开；失败、旧签名和不存在样式不得改变源文件。

达到上述后才考虑 UI 公开；本阶段不提升版本、不更新 README 或 Release。
