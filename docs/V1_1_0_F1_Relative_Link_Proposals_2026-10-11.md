# F1 归档相对链接提案审计

2026-10-11，接续 `c9d3bdc5`。仅后端只读提案，不修改 UI、不写回正文或移动文件。

## 本步实现

批次引用影响新增可空 proposedTarget。仅对 rewrite_required 且有精确原文范围的引用尝试生成，以批次映射后的引用者目录和预期目标计算相对路径。因此同批改名的出链、留在原处的外部入链使用各自正确的基准目录。

磁盘路径按分段 UTF-8 百分号编码，避免空格、中文、文件名中的 #/% 被误解释为 Markdown 或 URL 语法。原查询/片段分隔符保留，已有有效百分号转义不重复编码，其他后缀字节编码；不合法百分号序列拒绝。生成后调用现有受限相对路径解析器，只有解析路径与预期路径相符才返回提案。未来目标可能尚不存在，missing 仅允许路径预测，不代表文件存在或移动成功。

复杂语法没有精确范围、越界或无法定位的目标不生成提案；原影响分类及证据仍保留，不把空提案视为无需处理。same_destination 和不同目标候选不生成不必要的替换。

## 验证

新增 3 项测试：

- 临时库内附件名称含中文、空格、#/%，查询和中文片段生成后接入内存预览，并验证原文件不变、目标未创建。
- 同批笔记改名生成新相对目标，外部 index 入链生成归档目录路径。
- 带标题的未支持编辑语法不猜测范围，非法后缀转义和库外路径不生成提案。

## 审计边界与下一步

仍是整批全部成功后的路径预测，不适用于部分失败后的实际状态。文件身份、草稿、并发写入、跨库引用和复杂语法覆盖限制仍在，complete=false、canExecute=false 保持。未验证 UI/阅读器中的中文锚点跳转或所有查询语义，不能据后端路径测试声称用户闭环完成。

下一步将逐条提案按文档聚合成可核对的批次计划，区分无须改写、可预览和阻塞项，绑定来源快照，不能只取成功提案遗漏其余依赖。随后接草稿/保存协调、安全写回、恢复、标签/索引及已批准的用户界面。UI 修改前后实际查看页面；新增部分失败/恢复状态先示意审批。
