## 社区发布说明

v1.0.17 仍采用经用户批准的无 Authenticode 签名社区发布通道，Windows 可能显示“未知发布者”。只允许从官方 GitHub Release 下载，必须校验 SHA-256；应用自动更新也必须在用户确认后校验官方 NSIS。

渠道事实为 `community-unsigned`，当前 `releaseCandidate=false`。公开前不提供非官方的手动下载安装入口。

本文件只建立候选边界。真实质量门、打包差异、安装生命周期和远端附件回下载结果必须在各自阶段继续写入审计，不得把“准备中”表述为“已发布”。
