# Android 重设计候选：接收、返回与新笔记恢复

后续观察：已在无CDP、无UIAutomator连续连接时复现空树，并在同一API29上用真正TalkBack完成恢复→菜单→收到列表→系统返回，焦点回文档操作。辅助服务树与实际读屏结果不一致，完整采集原因仍未解决，详见[读屏与采证边界](Mobile_Accessibility_Boundary_2026-10-29.md)。下文保留原候选阶段结论，未改记旧失败。

2026-10-29，起点 `bfb171347`，沿用移动工作树和 `codex/mobile-0.1.0-foundation`。按一次推进一个用户任务的规则，实际操作“编辑未保存笔记 → 收到其他应用的内容 → 分层核对 → 返回原稿 → 导出副本 → 重启继续”。本轮使用预留序号1002049构建初候选和修正版，均为本地debug候选，没有推送或发布。

## 用户实际遇到的问题与修复

在专用API29模拟器创建 `AndroidTask-20261029.md`，输入中文、emoji和三行未保存文字；原生分享、导出后终止测试应用，再从“继续阅读”进入。完整私有草稿仍在，但页面给出了“先阅读已保存文件”，底部又重复显示一个“继续草稿”。这份新笔记尚未生成源文件，阅读选项不成立。[改前原图](evidence/mobile-redesign-native-2026-10-29/native/reopen-draft-choice.png)与文件清单同时保留。

冻结设计后，仅调整 `MobileApp.vue` 的恢复选择：

- 新笔记显示“新笔记草稿还在”“这份笔记尚未保存。”及一个继续动作。
- 根据实际读到的源文件签名和读取状态决定是否提供“先阅读文件”。不只根据草稿签名判断；草稿创建后外部出现同名文件时，仍能阅读实际文件并看到冲突提醒。
- 恢复卡片可见时去掉重复底栏；选择阅读真实原文件后，底栏继续提供返回草稿的入口。

没有改写恢复内容、保存策略、接收协议或格式引擎。原有授权失败、外部变化和实际未保存状态仍保留可见；没有把风险说明藏进问号。

## 竞品依据与设计

本轮重新核对[Obsidian手机说明](https://obsidian.md/help/mobile)：编辑工具、导航与菜单按当前任务区分；[Notion手机导出](https://www.notion.com/help/export-your-content)：从当前页进入导出，选项确认后打开系统分享菜单。继续采用按需进入子页、完成后回原任务的顺序。这些是官方资料研究，未安装或录制竞品，也不据此声称它们有本项目的草稿保护或重试实现。

[Android返回指南](https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture)区分系统回退与自定义回调的职责。本轮实际使用系统Back检查键盘与页面层级；API29按键不能验证API35以上的预测性手势、取消动画或根页系统预览。

## 未通过的无障碍边界

B的恢复页最初可取得正常原生节点。再次分享文字并打开文档菜单后，UIAutomator多次仅返回WebView根节点，菜单、收到列表及返回后的编辑器截图均正常，触摸与系统Back也有效。已有辅助服务仍绑定；只读DOM诊断显示body、app、workspace未设inert或aria-hidden，编辑器和按钮存在。原因仍未确定，不能直接归咎于产品、测试工具或WebView，也没有用DOM节点冒充Android无障碍节点。

## 其他首次失败与验证

- Windows PowerShell5把Tauri的普通stderr提示作为终止错误；修正原生命令日志捕获，按真实退出码判断，仍保留失败诊断。首次辅助函数的局部退出码变量也被专项检查拒绝，修正后再运行。
- Cargo成功行带ANSI颜色，原脚本未识别而拒绝已知符号链接复制方案；只对匹配归因的副本打包条件去色，编译失败或其他打包错误仍拒绝继续。PowerShell5、7最终各22项打包检查通过。
- 新建笔记先保存在私有草稿，源文件尚不存在。最初核对脚本错误要求一个空源文件，现比较创建时的真实来源状态，未写出假文件来满足断言。
- 浏览器初稿用例同时匹配背景和弹层的“新建笔记”，现限定实际弹层；原失败保留。最终三组专项通过，含已有文件阅读返回、外部新建同名文件和源码不写入断言。
- 本轮四次axe扫描无违规；大字短屏的strong／p因裁切重叠仍有未决项。实际计算颜色对比度7.571:1另作补充，未抹去自动未决结果。
- 最终文字发送器曾因Android任务栈显示了包发送页而找不到动作；只在测试发送器入口增加clear-top后实际重试成功，没有改消费端Intent或绕过授权。
