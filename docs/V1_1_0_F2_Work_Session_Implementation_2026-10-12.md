## 第一批实现

- 工作台身份区下一行“工作现场 / 继续工作 / 命名保存”，保留原工作台功能，未占用主编辑区。
- 版本化命名记录按资料库隔离，保存失败明确提示；不持久化正文、草稿或外部文件。重复名称/数量上限有提示，不静默覆盖。
- 恢复命名记录打开主编辑区，当前未保存标签按原对象保留，包括大小写不同的同一路径；在途文本保存阻止切换。
- 标签自动恢复改为库级存储；旧全局记录按所属路径过滤迁移，保留旧记录与损坏数据以便恢复，不加载跨库标签/收藏/最近文件。
- 命名记录接入既有搜索条件和工作面阅读状态接口；排除 view-state 中的 draft/selection，不覆盖未保存文件的当前阅读状态。搜索结果重新计算，不缓存旧结果正文。
