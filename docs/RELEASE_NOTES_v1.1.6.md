# Long编辑 v1.1.6

本版深化文件整理：移动或改名之后，本地图片、文档链接、打开的正文和历史记录继续接上。

- 继续使用原来的右键、拖动、单项或批量改名、撤销移动。Markdown 的相对图片及文档链接自动跟随调整，共享图片无需复制搬家。
- 同一文件夹内改名时，无关的旧失效链接不会要求额外修复；修改文件类型前会保护尚未保存的正文。
- 保护所有打开窗口中的未保存修改。需要改写的正文会提示先保存，无关草稿不丢失；仅写在草稿里的新链接也会检查。无需改写正文的普通 Markdown 草稿可随文件接续路径，不会被自动保存。
- PDF 的批注及 OCR 记录随 PDF 移动、改名；收藏、近期文件、标签页和自定义文件显示样式同步接续。
- 整理中断后，从文件栏右键「核对未完成的移动…」处理实际位置。支持完成核对、还原和导出原文副本，已有新修改不会被覆盖；部分失败只重试未执行项。

自动维护范围为资料库内可见 UTF-8 Markdown 的本地引用，支持常用相对链接、图片、标题、引用定义和字面 HTML 地址；代码示例及远程链接保持原样。不能可靠判断或超出检查预算时，会保留原文件并给出具体提示。Office、PDF 等二进制正文内部链接不属于自动改写范围。

全部现有功能、六种界面风格和正常动效保留。当前为待安装核验的发布候选；正式公开附件和安装摘要以最终发布记录为准。
