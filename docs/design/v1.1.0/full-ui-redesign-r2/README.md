## 统一结构与使用规则

- 全局导航固定为工作台、资料库、收集箱、知识图谱，设置位于底部，和资料导航共同组成一个左侧导航区域。默认启动仍进入资料库/编辑器；工作台用于继续工作，不增加强制首页流程。历史只在资料导航中出现，不增加重复的全局历史入口。
- 顶部保留当前资料库、跨文件/命令入口、快速笔记。资料导航保留文件、大纲、最近、智能集合、标签、关系、历史全部七项；可收起、可拖宽，窄窗口使用完整抽屉。大纲、标签、链入/链出、历史列表均由左侧对应入口打开，主编辑器右侧不再重复这些导航。
- 文档标签与保存靠近正文。正文工具只展示常用操作，其余全部进入有名称的菜单。**主编辑区右侧默认关闭，仅在用户主动打开参考资料时出现。** 参考只负责来源正文/摘要、定位、摘录复制/插入、刷新/重关联、主区打开及关闭，不带大纲/关系/历史等导航页签。关闭或临时收起保留引用和工作现场。没有参考来源时先提供选择来源的简短引导，不默认占据整列。
- 关系详情、历史差异和 AI 按任务打开局部工作区、对话框或抽屉，不变成第二套常驻导航。专用格式的页面/工作表导航、源码与预览分栏、选中对象属性保留；仅在有对应任务时显示属性面板。
- 高密度编辑器以内容为主，格式专属工具按任务分组；不强行把表格、阅读器、图谱都变成 Markdown 工具栏。图片不是新的格式能力承诺，现有读写/副本边界继续有效。
- 页面错误使用局部提示，提供可执行的恢复动作。原始错误留在可展开的详情；草稿和其他文件操作保留。确认覆盖/删除等既有确认内容仍保留。
- 现有 19 套外观预设、10 个色调选项（含跟随系统）、六类界面风格、代码高亮、正文背景、高级定制、四种动效节奏和智能性能降级全部继续保留。全局栏、左导航、正文工具、菜单、弹窗、状态和专用格式面板统一跟随主题令牌，不写死深色侧栏或青绿色强调色。六张风格示例不替代其余预设，不重置已有外观配置。
- 常用操作保留文字和快捷键。实际文案、快捷键、图标和功能开关沿用代码的真实能力统一整理，不用图中示例数据替换运行合同。
