# 外观与功能接续规则

2026-10-12。R2 静态设计的实施约束。来自现有 `src/config/themePresets.ts`、`src/styles/themes.scss`、`src/views/SettingsView.vue`，不以图片取代现有配置或新增格式能力。

## 布局与外观分别处理

功能位置随任务和窗口宽度调整，色调、质感和动效由用户配置决定。主编辑器保持单一左侧导航区；打开参考仅增加临时资料对照区，不带大纲/关系/历史导航。六类风格不改变功能菜单、快捷键、保存/导出边界和设置数量。

整个界面使用现有颜色、圆角、边框、阴影、间距和动效变量，包含全局栏、导航、工具栏、菜单、弹窗、专用编辑器面板和错误状态。浅色主题不固定保留深色侧栏。图表/图谱、编辑器正文、代码高亮和导出继续使用现有主题注册表及各自已有配置。用户的旧配置不重置。

| 风格 | 延续的视觉特征 | 重构处理 |
| --- | --- | --- |
| 柔和 soft | 12px 基础圆角、柔和扩散阴影、低强度渐变 | 控件和卡片保持柔和层次，正文清晰 |
| 新拟态 neo | 4px 基础圆角、科技边线、方向投影和对侧高光 | 延续现有科技质感，控制装饰范围 |
| 玻璃 glass | 14px 基础圆角、透明层叠、边缘高光 | 保留晶透风格，沿用当前无 blur 策略 |
| 呼吸 airy | 10px 基础圆角、较大间距、纸张和轻阴影 | 留白更舒适，窄窗口保留操作入口 |
| 极简 minimal | 6px 基础圆角、清晰分隔、弱阴影、紧凑间距 | 主编辑和数据工作保持直接清楚 |
| 锐利 sharp | 0–2px 圆角、硬边框、硬质投影 | 保留边界、焦点和选中状态的辨识度 |

动效选项继续保留舒展 calm、轻快 swift、华丽 expressive、减少 reduced。智能性能降级继续沿用原有策略；本轮 UI 重构不将所有用户的动效强制切到“减少”。主题中的既有动效默认值也继续保留。

## 每批实施如何保留功能

以 [完整功能位置表](README.md) 和 [35 个源码入口盘点](source-inventory.json) 为基础，每批修改只移动呈现和入口。保留下列内容：

- 全部 27 个独立路由页面和 8 个共享流程，以及每页专属的读写、刷新、保存、副本、导出、查找、导航和编辑工具。
- 资料导航七入口、文件及标签上下文菜单、命令与快捷键、资料库/Git、快速笔记、智能集合和工作现场的所有既有动作。
- 设置的全部八类、高级选项、说明文本、确认内容、默认应用、格式开关、更新、备份、诊断和可选 AI。
- 草稿、历史、引用、恢复动作、范围读取及外部文件状态；关闭面板不清空数据，收起工具不取消命令。
- 格式专属的结构、缩略图、工作表、对象属性、批注、源代码/预览和知识治理内容；不为统一外观压成相同工具栏。

每批交接记录写明旧入口移动到哪里，新增的菜单须有清楚名称；若某能力未在静态图中展开，仍按源码和完整保留表接入。图片仅确认布局、质感和层级，不是删减高级功能的授权。验证集中在当批发生变化的实际用户操作，不为静态图启动安装或重复完整验收。
