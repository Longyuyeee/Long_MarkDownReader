## 用户操作规则

- 七个入口保留文件、大纲、最近、智能集合、标签、关系、历史，始终一行图标。悬停提示、键盘焦点和辅助名称保留；不在右侧再复制导航。
- 新建主入口只保留一个，新建文件夹和今日笔记移入其菜单。选文件夹在其中创建，选文件在同级目录创建，未选中时使用资料库根目录；多选时使用最后选中的项目确定新建位置，菜单注明位置。
- 当前选中文件是可创建的格式时，将同格式创建放在前面，所有其他格式和笔记模板仍通过有名称的子菜单可达。
- 今日笔记默认仍存到 Daily；已有明确选择时存入对应目录。日期命名和 Markdown 创建能力保留。菜单文案明确默认 Daily，避免暗中保存到不明位置。
- 文档显示可以跟随风格，或独立使用简洁、纸张、排版；字体可跟随排版、无衬线、衬线、等宽；字号 12–28，行距 1.3–2.4。现有窄/中/宽正文宽度入口保留。
- 文件行可以跟随风格，或选择紧凑、舒适、宽松；可以平面或卡片行；图标可彩色或单色。目录层级、扩展名、拖动、选择、单个文件标记及右键动作保持。
- 显示选项不改文件正文或写回原文件样式。Markdown、外部 Markdown 和快速笔记共用文档显示；源码保留等宽，PDF/Office 保留原有文档排版。
- 恢复显示默认值仅重置上述新增显示选项，不重置主题、动效、代码高亮、文章背景、单个文件显示标记或资料库。
- 全部 19 套预设、10 个色调选项、6 类界面风格、4 类动效节奏继续保留，智能降级继续沿用原有策略。

## 本批已接入的代码

1. 主编辑：七个图标、合并后的上下文新建菜单、选中目录解析、文档操作中的显示设置入口。修复文件树未同步受控选中状态的问题，以最后选中的项目为新建目标；名称带 `.md` 等扩展名的文件夹仍按目录处理。
2. 外观：共享表面和文档/文件显示样式；六种风格影响形态和密度；修复 Naive UI 控件圆角不随风格重新计算的问题。
3. 设置：文档与文件显示编辑器及实时预览；旧设置全部保留。
4. 配置：前端和 Rust 新增 displayPreferences，旧配置自动使用显示默认值；新设置保留到管理备份并在恢复时接续。

这批完成的是主编辑调整和全局显示基础。全局四入口导航以及工作台/搜索/参考、阅读/Office、数据/图形/媒体各自的布局细化仍按 R2 顺序分批继续，不能据此称全部 27 个页面已经重构完成。
