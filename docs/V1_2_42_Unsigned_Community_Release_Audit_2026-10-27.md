# v1.2.42：TOML 多行数组项复制排序

当前开发目标：`1.2.42`；当前运行时版本：`1.2.42`；当前公开版本：`1.2.41`。当前阶段：**v1.2.42 TOML 多行数组项复制排序候选**。

## 用户变化

普通三单引号／三双引号数组文字项沿现有右键复制为新项、上移／下移和差异确认，无新增表单或常驻控件。修改只进入草稿，一次撤销／重做，显式保存。保留所有功能、风格及正常动效。

生产解析器确认普通数组和完整条目范围。复制原始文字、段落、转义与可明确归属的结束行注释；末项缺少逗号时在注释前补齐必要分隔符。排序交换完整文字及附着注释，逗号保留所在槽位，独立注释和空行原位不动。BOM／CRLF、引号形式及无关数字拼写保持原样；重新解析证明只增加一个原值或交换相邻两项，并采用新解析范围选中结果。

嵌套数组、内联表、数组表、点键及含混注释保持局部源码入口；原文和输入保留。已有单行数组和多行正文编辑继续可用。保护迟到结果、后续输入、旧差异及文件切换；保存占用失败重试、外部原件不变及完整副本独立检查。NSIS实际安装、手动升级与卸载，和MSI构建摘要分别记录。
