# M5-3 ODP 简单幻灯片正文副本工作区审计

审计日期：2026-08-31

当前公开/运行时版本：`1.0.16`

开发目标：`1.0.17`

阶段结论：**通过；ODP 提升为资料库内有界简单正文编辑与可靠新副本，下一步进入 M5-4 质量债务与发布就绪审计。**

## 1. 开发目标与需求对齐

M5-3 已把 M5-2 隐藏后端接入真实 ODP 工作区。资料库内简单页按后端库存列出可编辑正文，草稿只驻留内存，支持撤销、重做、Ctrl+S、路由离开保护和工具栏重新读取保护；保存仅允许源目录中的新 `.odp` 文件，返回可靠凭据后自动打开副本。源文件、已有目标、备注、版式、媒体、动画和复杂对象均不会写回。

PowerPoint 自定义形状页继续执行整页阻断。视觉复核发现首版直接展示多个底层结构代码，虽安全但不适合用户阅读；现已合并为“检测到自定义形状及其未验证内部结构”，并明确说明为避免页面语义被部分修改，本页全部正文保持只读。外部 ODP 仍只调用无库存的只读读取命令，安装关联没有扩大。

格式事实源现按真实产品能力从 `preview-only / none` 提升为 `basic-edit / copy`，writer 为 `odf-slide-text`；描述明确限定为资料库内简单正文可靠副本，不宣称完整 Impress/PowerPoint 等价编辑。

## 2. 真实测试：预期、实际、差异与修正

审计每次现场生成全新的 LibreOffice Impress 和 Microsoft PowerPoint ODP。两份简单源各包含 2 个正文目标；PowerPoint 另生成一个自定义形状复杂页。真实 Tauri WebView 在隔离资料库完成选择、草稿、撤销/重做、重载保护、另存和自动重开；输出再由 PowerPoint 进行语义复开，并由 LibreOffice 导出 PDF。

| 环节 | 预期 | 实际 | 修正 |
| --- | --- | --- | --- |
| 工作区复用 | ODS 的保存流程可直接复用 | ODP 需要独立正文库存、整页阻断说明和更严格的保存凭据检查 | 增加 ODP 专用草稿与目标选择，同时复用统一撤销、离开保护和自动打开能力 |
| 工具栏重新读取 | 直接调用 `load` 即可 | `load` 会清除未保存内存草稿 | 重新读取先进入与路由离开一致的确认对话框；真实测试验证取消后草稿仍在 |
| 测试定位 | 可按刷新按钮的 `title` 定位 | 全局工具提示治理会移除原生 `title` | 产品增加 `aria-label="重新读取 ODF"`，审计按无障碍名称定位 |
| 复杂页说明 | 展示后端全部阻断代码 | 安全但底层代码过多、可读性不足 | 将自定义形状内部原因合并为用户可理解的整页只读说明 |
| Windows 编码 | PowerShell 默认读取 Node JSON 即可 | Windows PowerShell 5 用本地代码页读取 UTF-8 中文，导致 JSON 解析失败 | 运行器显式使用 UTF-8；说明字符串保持代码页无关 |
| Office 生命周期 | PowerPoint COM `Quit` 总能成功 | 一次审计遗留后台实例导致关闭失败 | 运行器记录启动前进程，仅清理本次新建实例；文件本身仍必须通过后续真实复开 |

最终两份可靠副本分别为 **12,108 bytes**（LibreOffice 源）和 **43,938 bytes**（PowerPoint 源）。PowerPoint 对两份副本均找回替换正文、确认原正文消失；PowerPoint 源的备注保持。LibreOffice 分别输出 **15,900 bytes** 和 **14,109 bytes** PDF。三份源文件前后 SHA-256 完全一致，真实 WebView 运行时错误为 0。

宽屏证据展示了未保存草稿保护对话框；`720×720` 证据滚动到完整正文选择和编辑区域，工具栏、面板与页面无横向溢出；复杂页证据显示明确整页阻断。结构化证据不包含本地绝对路径，原始 Office 文件不提交。

## 4. 版本收口与接续点

M5-3 产品目标已经完成，但当前仍不能打包 `1.0.17`。本阶段重新执行全仓 Rust 测试，实际为 **544 通过、4 失败、5 忽略**：原有两个工作簿断言与一个 PPTX 注册表断言逐项独立复跑后仍失败；新增的知识索引快照陈旧性测试在全量并发运行中失败，但随后单独复跑通过，说明还存在时间或并发敏感的不稳定性。版本号仍为 `1.0.16`，候选安装包和 v1.0.17 Release Notes 尚未生成，因此 `releaseCandidate=false`。

唯一接续点为 **M5-4 v1.0.17 质量债务与发布就绪审计**：逐项检查 3 个稳定失败的真实需求与当前实现，并消除知识索引测试的并发/时间不稳定性，重新取得全仓 Rust 零失败；随后运行完整发布门禁，再判断是否具备版本原子提升、安装包、README、Release Notes 和 GitHub Release 的条件。不得跳过失败直接打包。
