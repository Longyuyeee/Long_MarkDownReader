## 1. 结论

M3B 专业视觉与镜头系统通过退出审计。M3B-1 至 M3B-11 已形成同一套可解释的信息层级：对象/关系图例、远中近语义缩放、社区轮廓与远景摘要、曲线和平行关系、选中路径标签与方向流动、有界且 reduced 安全的相机、适应选择、语义缩略导航，以及克制的节点状态外环。

聚类展开/折叠和图谱全屏不继续并入 M3B。现有社区摘要和过滤子图已提供有界的聚类进入/返回，代理节点折叠会新增布局、选择和持久化风险；三档桌面窗口已经保持控制栏、图例、详情、路径面板、缩略图和主画布可用，全屏不是本阶段信息表达验收的必要条件。治理外环继续等待规范化逐节点合同。

当前接续点前移到 **M3C-0 大图性能基线选择审计**。必须用 100、1,000、5,000 节点真实图谱重新记录布局、平移、缩放、选择、镜头、脏帧、后台停转和反复进出行为，再选择最小性能实现；不得用 M3B 的 17 节点视觉证据代替 M3C。

## 2. 退出范围与验收方法

- 同会话组合：图例 → 三档窗口 → 节点聚焦 → 中景轮廓 → 远景社区 → 社区进入/返回 → 真实最短路径 → 缩略图键盘导航 → 返回资料库。
- 主题/动效：暗色 calm、暗色 reduced、浅色 reduced、高对比 reduced。
- 窗口：1280×800、1000×700、720×680。
- 数据：真实临时资料库，11 类对象、6 类关系、17 节点、17 边、七档真实文件时间。
- 安全：每个会话计算源资料库前后 SHA-256，监听 WebView 运行时错误，并实际返回资料库。
- 历史保持：重新读取 M3B-1～11 已有真实桌面证据，选择阶段通过政策链和审计文档保持边界。

## 4. 真实结果

- 4/4 真实 Tauri 会话通过；每个会话均实际走完整组合流程。
- 图例在详情关闭时仍显示 11 类对象和 6 类关系。
- 1280/1000/720 三档均保持主画布、图例、缩略图和末端控制命令可见；普通与路径状态均无页面横向溢出。
- 全局图有 2 条确定性平行/互反曲线路由；真实 NorthStar → Evidence 路径为 4 节点、3 边、3 标签和 3 份边证据。
- calm 路径动效相位与帧推进；三个 reduced 会话完全静止，静态标签和箭头保持可读。
- 节点聚焦在 calm 完成有界过渡，在 reduced 直接到位；缩略图方向键导航均改变相机姿态且视口框保持界内。
- 状态环近景/中景均为 8，路径和远景均为 0；选择和路径语义优先级未回退。
- 代理聚类、产品图谱全屏和治理状态环仍不存在，退出审计未把缺失能力伪装为完成。
- 四会话运行时错误 0，源资料库 SHA-256 前后一致并成功返回资料库。
