# XLSX 录入与检查

单元格右键选择“检查所选区域…”或“检查筛选结果…”。筛选结果按表格或筛选区域内的真实单元格检查，不包含标题和隐藏行；所选区域则包含所选的隐藏单元格。滚动屏幕不会改变范围。

检查弹窗列出单元格位置、原内容、规则和适用范围。点击“定位”返回原位置；“修改…”先预览，再应用到当前草稿，可撤销，最后使用原有保存按钮保存。关闭预览不会修改内容。期间文档、选区或草稿变化，旧结果不会继续应用。

整数、小数、日期、文本长度及固定列表在直接输入、粘贴、清空和已有填充操作中使用一致规则。非法批量输入整批不改；合法批次可一次撤销，保留其他草稿。已有日期或带日期规则的空单元格可输入 YYYY-MM-DD，按工作簿自身的 1900/1904 日期系统保存。数值范围使用精确十进制比较。

规则编辑沿用原有弹窗，立即写入工作簿，因此先保存现有草稿后才能编辑规则。“仅提示”的规则在检查中显示问题，但不阻止输入。公式结果、公式边界、区域列表等不能可靠计算的条件显示“需另行核对”，原规则保持。日期规则目前可检查已有规则，创建与编辑仍以已有支持范围为准。

单次最多检查 10,000 个单元格。超过范围会要求缩小范围，不将部分结果称为完整检查。外部只读工作簿可检查和定位，编辑仍需使用现有受管理工作簿入口。
