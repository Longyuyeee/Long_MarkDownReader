# v1.2.3：批注一起整理，一次撤回

选中多条 PDF 批注后，从现有右键或“···”菜单统一改色、删除，并可一次撤销或重做整批操作。菜单和删除确认会显示所选条数及筛选隐藏项，避免误删；右键未选中的批注仍只操作当前条目。

撤销保留批注顺序、勾选和筛选条件。保存失败保留修改并可原地重试，外部冲突不覆盖；取消或等待弹窗期间更换文件、选择和评论都不会套用过期操作。PDF 原文与已有阅读笔记不变，评论框仍保留自己的文字撤销。

固定产品构建、Rust 功能与性能回归、419 项安装版功能任务及 NSIS 安装升级检查通过。公开附件核对尚待完成。

未签名社区版，Windows 可能提示未知发布者。NSIS 实际安装流程与 MSI 构建摘要分别记录；应用内自动更新观察独立 pending。
