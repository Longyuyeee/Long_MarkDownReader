对应 Draft PR：#6

审计结论：**G8-2B 已收口。知识图谱已从独立可视化页面变为 Markdown、PDF、Table、Canvas、OPML、工作台和搜索中的统一导航层；后续主线立即切换到 PDF 页面级基础编辑。**

## 1. 与用户原始目标的对齐

用户的基础目标不是建设一个只擅长 Markdown 或只展示图谱的工具，而是：

1. 在同一管理器中发现、阅读和基础编辑日常文件；
2. 覆盖 PDF、图表、思维导图、Excel/表格、WPS/Office、TXT、JSON 和开发常用格式；
3. 通过文件树、标签页、搜索、集合、最近记录和关系把内容成体系管理；
4. 所有编辑都要安全保存、可重开，并明确部分兼容边界；
5. 知识图谱应增强日常管理，但不能成为基础阅读和编辑的前置条件。

本批只负责关闭“知识图谱存在感弱”的当前缺口，不代表 PDF、DOCX/PPTX 或 WPS 已完成。为防止增强线继续挤占基础格式需求，后续权威顺序冻结为：

**PDF 页面级基础编辑 → DOCX 基础工作面 → PPTX 基础工作面 → WPS/OpenDocument/旧版 Office 审计与受控转换 → 统一发布矩阵。**

G8-3 搜索关系解释、G8-4 代码/配置关系提取和 G8-5 图谱—思维导图协同转为并行增强队列，不再阻塞上述专业格式主线。

## 2. 本批交付

### 2.1 同标签上下文

- 图谱后端为根文件生成大小写不敏感的 `shares-tag` 语义关系；
- 显示共同标签证据，不把普通共存文件误报为关系；
- 结果继续受单文件最多 80 条关系的上限约束。

### 2.2 智能集合上下文

- 关系侧栏显示当前文件命中的已保存智能集合；
- 最多求值 8 个集合，复用正式 `search_knowledge` 路径和对象类型过滤；
- 点击集合回到统一 Library 搜索，不创建第二套集合数据。

### 2.3 会话级有界缓存

- 图谱上下文与集合成员关系使用仅驻留内存的 30 秒缓存；
- 最多保存 32 个条目，并在命中时刷新最近使用顺序；
- 手动刷新按知识库和文件路径精确失效；
- 缓存不写入用户文件，也不替代可重建知识索引。

### 2.4 专业格式真实证据

真实 Tauri Debug/WebView2 已验证：

- PDF 文件侧栏显示 Markdown 入链及原文证据；
- Table 文件显示 Grid/Chart 视图结构关系，并可定位到 `Relation Coverage` 图表视图；
- Canvas 显示文本节点、文件节点、Table 图表嵌入和语义连线；
- Markdown 显示同标签文件和所属智能集合；
- OPML 继续显示规划层级，事实、结构、规划、语义关系不混用。

## 3. 界面结构结论

关系上下文由应用壳层统一挂载，保持在当前工作面的右侧抽屉中。Markdown 仍在 Library 右侧标签区内编辑；PDF、Table、Canvas、OPML 等专业画布仍使用原有专业工作面，但不会为了查看关系再打开一个新的关系页面。侧栏使用现有主题变量、11–14px 信息层级和相同圆角/阴影语义，不引入另一套视觉系统。

“以当前文件为中心”仍可进入独立局部图谱，这是明确的深度探索动作，不是打开文件时的默认跳转。

## 5. 当前原始需求达成状态

| 原始需求域 | 当前状态 | 已有能力 | 仍需完成 |
|---|---|---|---|
| 统一日常管理 | 基础闭环 | 文件树、标签、最近、搜索、集合、状态与统一路由 | 批处理和发布矩阵增强 |
| TXT/JSON/开发格式 | 基础闭环 | TXT、JSON/JSONC、YAML、XML、TOML、配置和常见代码轻量编辑 | 更深代码语义属于增强项 |
| 图表/思维导图 | 可用闭环 | Mermaid、Canvas、OPML、Open Table 图表可编辑并进入关系体系 | 更复杂图表和图谱—脑图协同 |
| Excel | 渐进式基础编辑 | 多工作表、单元格、样式、公式、结构与部分图表安全写回 | 不等价于完整 Excel |
| PDF | 阅读研究闭环 | 阅读、搜索、文本层、批注、OCR、页级索引和关系 | 页面旋转/排序/删除/提取/合并/拆分/安全另存 |
| DOCX/PPTX | 未形成内置工作面 | 仅有需求与兼容边界 | 先读后编的公开 OOXML 子集 |
| WPS/开放办公格式 | 未支持 | 已有风险和转换原则 | 规范、许可、保真、外部打开或受控副本转换 |
| 知识图谱 | 日常导航闭环 | 工作台摘要、搜索摘要、文件侧栏、证据、定位、标签和集合 | 搜索解释、代码关系、脑图协同转增强队列 |

因此当前产品已经能覆盖大量日常管理和基础编辑，但**尚未达到全部原始格式需求完成**。下一阶段的完成判据必须以 PDF 页面操作的真实写回和重开为准，而不是继续增加图谱展示项。
