# v1.2.25：TOML 数组项直接改值

数组项右键“修改值…”，弹窗自动带入原文字面量；只改一个值，不必删除再新增。差异显示实际类型，应用后保留展开并选中新值，可独立撤销／重做，显式保存才写盘。

支持普通数组里的单行文本、数字、布尔和日期时间，以及范围明确的多行数组；保留其他项、逗号、注释、表归属、BOM 与换行，不整体格式化。复杂内容局部反馈并定位源码，无效输入仍保留，可继续修正。

保护未保存内容、后续输入、旧结果与差异、文件切换、失败重试和外部冲突副本。保留全部功能、风格和正常动效，无常驻表单。

未签名社区版；完整发布检查与 593 项安装版功能任务通过，NSIS、MSI 与 `SHA256SUMS.txt` 三份公开附件重新下载核对通过。应用内自动更新实际观察仍待完成，与手动安装升级分别记录。
