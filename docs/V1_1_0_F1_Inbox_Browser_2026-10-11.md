# F1 收集箱入口：第一批实现

日期：2026-10-11，承接 `62f01358`。用户已确认 UI-F1-02 / UI-F1-03 的方向。本轮仅实现 UI-F1-02 的目录浏览基础，不宣称归档完成，不发版。

## 已实现

- 在资料库文件侧栏的原工具栏下新增收集箱入口，原七个侧栏页签、新建、搜索、文件树、编辑器和格式工具保留。
- 默认读取当前库 Inbox，复用受库边界约束的 `scan_directory`，不自动创建或移动文件。列表仅展示现有扫描接口支持的资料与目录，不是磁盘全部文件的清单。
- 文件点击复用 `handleNodeSelect`，在主编辑区打开；子目录进入/上一级、手动刷新及快速笔记刷新事件订阅可用。
- 加载、读取失败和空列表分别显示。路径显示短面包屑，悬停查看完整路径；返回全部文件恢复原树视图，输入搜索词退出收集箱视图并保留查询。
- 加入请求代次与卸载检查，旧请求不能覆盖切库或目录切换后的列表；返回父级使用实际访问栈，不通过拼接不受限路径向库外跳转。
