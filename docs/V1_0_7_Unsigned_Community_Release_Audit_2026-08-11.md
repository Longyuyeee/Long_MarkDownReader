## 当前结论

- package、Cargo、Tauri、Windows 生命周期、性能、能力矩阵和社区发布策略统一提升为 `1.0.7`。
- 本版范围固定为 XLSX 经典错误值编辑、已有日期时间单元格编辑、按工作表的本地缓存值索引及索引容器安全预算。
- v1.0.6 的外部打开、默认应用、安装态和托管更新证据保留为上一公开版本基线，不冒充 v1.0.7 当前安装包证据。
- README 继续链接已发布的 v1.0.6，并明确 v1.0.7 正在准备；新附件通过哈希复核前不创建失效下载入口。

## 本阶段门禁

1. 完成本地 `ci:patch-release` 与远端 Quality Gate，冻结产品源码提交。
2. 从冻结提交构建 MSI/NSIS，确认版本资源为 `1.0.7`、签名状态为 `NotSigned`。
3. 记录安装器大小、SHA-256 与 `SHA256SUMS.txt`，在 GitHub 托管的一次性 Windows 上完成安装生命周期。
4. 候选证据回写并通过第二次 Quality Gate 后发布 GitHub Release，再从远端重新下载三个附件逐项复核。
5. 使用官方 v1.0.6 与 v1.0.7 Release 执行应用内发现、确认、下载校验、覆盖安装和资料保留观察。

## 发布边界

- `v1.0.7` 尚未发布，当前公开稳定版仍为 `v1.0.6`。
- v1.0.4 及更早版本需要手动下载安装 v1.0.5 或更高版本后，才能进入受控应用内更新链。
- 安装包无 Authenticode 商业签名，必须保留未知发布者提示和 SHA-256 校验说明。
- 不发布旧 Tauri 私钥链要求的 `latest.json` 或 `.sig`；受控更新使用固定 GitHub Release 与附件摘要。
- 宏执行、外部数据刷新、未验证复杂 Office 对象写回和企业签名不属于本补丁承诺。
