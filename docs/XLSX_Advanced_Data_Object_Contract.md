# XLSX 高级数据对象契约

更新日期：2026-07-24
状态：S8-7A～S8-7D、S8-7E1、S8-7E2A～S8-7E2E 已完成，S8-7E2F 待开发

## 1. 目标

LongEdit 对透视表、切片器、外部工作簿链接和数据连接采用“先识别、先审计、默认离线”的渐进式策略。当前版本让用户看清工作簿包含哪些高级对象、对象来自哪里、是否存在加载时刷新风险，同时不把只读识别包装成可刷新或可编辑能力。

机器事实源为 `shared/xlsx-linked-data-capabilities.json`。前端必须使用后端返回的 `summary` 与 `policy`，不能根据是否显示按钮自行推断安全等级。

## 2. 当前权威策略

当前模式固定为 `offline_read_only`：

| 策略 | 当前值 | 含义 |
| --- | --- | --- |
| `metadataVisible` | `true` | 可显示经过脱敏的结构元数据 |
| `refreshAllowed` | `false` | 不执行透视缓存、连接或外部数据刷新 |
| `objectEditingAllowed` | `false` | 不修改高级对象定义 |
| `externalTargetsFollowed` | `false` | 不跟随外部关系，不访问网络或知识库外文件 |
| `sensitiveFieldsExposed` | `false` | 连接字符串、命令、凭据和完整路径不进入 IPC |

此策略由 Rust 后端构造并随 `WorkbookLinkedData` 返回。界面只能收紧策略，不能放宽策略。

## 3. 对象能力

| 对象 | 读取 | 定位 | 刷新 | 编辑 | 未编辑往返 |
| --- | --- | --- | --- | --- | --- |
| 透视表 | 支持安全元数据 | 本地 Sheet 可定位 | 禁止 | 计划中 | 字节级验证 |
| 切片器 | 支持安全元数据 | 关联 Sheet 可定位 | 禁止 | 计划中 | 字节级验证 |
| 外部工作簿链接 | 脱敏读取 | 禁止跟随目标 | 禁止 | 计划中 | 字节级验证 |
| 数据连接 | 脱敏读取 | 不适用 | 禁止 | 计划中 | 字节级验证 |

后端汇总对象总量、本地工作表来源透视表数、连接来源透视表数、切片器数、外部链接数、连接数和刷新风险数。`refreshOnLoad` 只作为风险提示，不会触发实际刷新。

## 4. 用户界面

工作簿工作面提供“高级数据对象审计”入口，包含：

- 总对象数、本地透视表数、外部来源对象数和刷新风险数；
- 按透视表、切片器、数据连接和外部工作簿分组的对象清单；
- 本地对象的 Sheet 定位入口；
- 来源类型、缓存或连接标识、刷新风险和离线状态；
- 明确的安全策略说明与敏感字段脱敏说明。

界面不得显示刷新、查询或编辑已可用的暗示；被禁止的能力应以策略状态说明，而不是静默失败。

## 5. 安全与保真门禁

1. OOXML 外部关系只分类和计数，不解析或访问关系目标。
2. 连接字符串、命令文本、认证信息和完整外部路径不得序列化到公开模型。
3. 计算阶段若检测到真实外部工作簿链接，必须在进入公式引擎前拒绝。
4. 当前高级对象写回只允许“未编辑保真”；其他工作簿编辑不得改写对应 OOXML 部件。
5. `compatibility-baseline.xlsx` 必须持续覆盖透视表、Pivot Cache、切片器、外部链接和连接。
6. 机器合同、Rust 模型、命令 fixture 断言和前端安全文案由 `npm run check:workbook-contract` 联合校验。

## 6. S8-7B 重建候选审计

S8-7B 已能稳定读取并展示：

- 数据源 Sheet 与范围；
- 透视表输出布局区域；
- Pivot Cache 字段名称与文本、数值、日期、布尔、错误、空值或混合类型；
- Cache Records 声明记录数、实际记录数及每条记录字段宽度；
- 行、列、筛选和值字段角色；
- 值字段来源索引、显示名称和聚合函数。

首批结构验证聚合为 `sum/count/average/max/min/product/countNums`。透视表只有在来源为本地工作表、来源与布局完整、缓存字段及记录存在、字段数量一致、值字段引用有效且聚合位于验证清单时，才标记为 `candidate_for_rebuild`；否则保持 `inspection_only` 并返回具体阻断原因。

Cache Records 的根节点 `count` 不作为单一可信依据；实现会扫描实际 `<r>` 数量，并核对每条记录的字段宽度与 Cache Fields 数量。声明数量不一致或记录错位都会降级为 `inspection_only`。

“重建候选”不是“允许刷新”。全局 `refreshAllowed=false` 继续具有最高优先级，S8-7B 不计算结果，也不修改 Pivot Cache、透视表定义或工作表输出区域。

真实 fixture 固定包含 3 个缓存字段、2 条 Cache Records、1 个行字段、1 个列字段、1 个 `sum` 值字段和输出布局；普通单元格写回后 Pivot Table、Cache Definition、Cache Records 及关系部件必须逐字节保持。

## 7. S8-7C 内存聚合预览

S8-7C 只为 `candidate_for_rebuild` 的本地透视表生成内存聚合预览，不开放连接型或外部来源刷新。实现已经：

- 从工作表当前值读取来源区域，并叠加当前未保存的非公式草稿，不信任陈旧 Cache Records 作为事实源；
- 使用带类型的行/列键分组，保留文本、数值、日期、布尔与空值之间的区别；
- 验证 `sum/count/average/max/min/product/countNums`：数值类聚合忽略非数值，`count` 统计非空值，`countNums` 只统计数值；
- 对值字段错误、来源公式草稿、筛选字段、超限来源和分组爆炸返回稳定拒绝，不产生部分结果；
- 返回独立预览模型，不覆盖工作表单元格、Pivot Cache、透视定义或原文件；
- 用真实 fixture、命令边界和独立聚合语义 fixture 对照结果，并验证签名冲突和文件字节不变；
- 保持连接型透视表、外部链接、查询和切片器离线只读。

首批硬限制为 50,000 条来源记录、256 个来源字段、10,000 个分组和 10,000 条草稿。页面筛选字段仍未建模，因此存在页面字段的透视表不能进入预览。

## 8. S8-7D 事务写回可行性审计

S8-7D 已增加逐透视表的 `writeback` 审计模型，但没有增加写入命令。审计逐项核对：

- 行列维度对应的 `<pivotField><items>` 是否存在、实际项数是否与声明一致；
- `<rowItems>` 与 `<colItems>` 是否存在且实际项数与声明一致；
- `<location>` 声明的输出区域是否在所属工作表中具有可验证单元格；
- 页面筛选字段是否仍处于明确阻断状态；
- 对象是否已先通过 S8-7B 重建候选门禁。

对象状态只有 `blocked` 与 `structure_candidate`。两种状态下 `allowed` 都固定为 `false`；`structure_candidate` 只说明包内结构足以进入后续隔离原型，不代表刷新或写回已开放。

当前真实兼容 fixture 被稳定判定为 `blocked`：它包含来源、缓存、字段角色和输出位置声明，可以用于 S8-7B/S8-7C，但缺少字段 items、`rowItems/colItems` 和输出区域单元格，不能作为安全写回证据。界面明确展示各门禁和阻断原因。

## 10. S8-7E2A 隔离重建影响计划

S8-7E2A 新增签名保护的 `preview_workbook_pivot_rebuild` dry-run 命令与工作簿审计界面，不增加用户文件写回：

## 11. S8-7E2B 隔离 Cache 重建

## 12. S8-7E2C 隔离 Pivot items、行列项与输出同步重建

## 13. S8-7E2D 新 sharedItems 与输出布局扩缩容

S8-7E2D 已在 E2C 单值标准布局上补齐动态维度集合：

- Cache Records、Pivot Field items、`rowItems/colItems` 使用协调后的同一索引集合；

真实 producer fixture 已覆盖两条动态路径：替换原隐藏行列项为新文本/日期时，sharedItems 各新增并移除一项，输出从 `A3:D7` 扩展为 `A3:E8`，总计为 6；合并可见维度值时，sharedItems 共移除两项，输出收缩为 `A3:C6`，至少 7 个旧坐标被清空且总计保持 4。命令和界面继续只返回内存副本审计结果，不写用户文件。

## 16. S8-7E3A 标准 Pivot 可靠新副本

- 新命令只接受一个行字段、一个列字段、一个 `sum` 值字段且无页面筛选的本地 Pivot。
- 保存请求同时绑定源文件签名和最近一次隔离输出摘要；任一变化都要求重新验证。
- 目标固定为源文件同目录的新 `.xlsx`，源路径和已存在目标均拒绝。
- 可靠写入使用原子新文件创建；落盘后核对完整字节并重读 OOXML 与 Pivot 布局/聚合语义。
- 保存前后核对源字节、签名和摘要；验证失败只清理与本次输出完全相同的未验收目标。
- 多度量和单轴保存、多层轴、页面字段、切片器、外部连接以及原件覆盖继续阻断。
