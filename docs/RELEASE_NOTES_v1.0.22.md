# v1.0.22 搜索可靠性补丁

状态：2026-09-22 已正式发布，MSI、NSIS 与 SHA256SUMS 三个公开附件已回下载核验。官方 1.0.21→1.0.22 应用内更新观察尚未完成。

本版补强日常“找到资料、辨认结果、安全保存”的体验，不新增搜索引擎或图谱特效。

- 搜索失败不再显示成“没有找到”，支持保持原查询重试；切换资料库、清空查询后，旧请求不会覆盖当前结果。
- 标签搜索遇到资料库根目录不可读时明确报错。
- 紧凑搜索结果将标题、命中信息和关系入口分行，长标题保留完整名称提示。
- 修复纯文本保存后迅速切换文件时出现保存报错、旧标签状态不一致的问题；保存回执归属原文件，后续编辑的草稿不会被旧回执覆盖。

固定产品 `cc58aa68` 已完成托管双包、安装生命周期与 TXT 保存截图核对；独立安装态搜索运行 `35743671363` 的 4 项用户任务通过，8 张搜索原图已直接审阅，涵盖暗色紧凑侧栏、离线反馈、键盘重试和准确打开。最终图谱提示观察 `35744511959` 通过，未在该环境复现持续加载或消息遮挡；不等于全部大库性能验收。

已知显示限制：本包实际版本为 1.0.22，但侧栏可能仍显示 DEV，能力页的“当前公开版本”保留构建时 1.0.21 文案。这是静态发布状态文案，不代表实际安装版本回退；公开版本以本 Release、安装包版本和 SHA-256 为准。下个补丁优先解耦运行版本与开发路线文案，不把该问题隐藏为已修复。

社区安装包采用 NotSigned（未签名），Windows 可能提示未知发布者；只从官方 Release 手动下载安装并核对 SHA-256。自动更新观察必须在正式发布后单独执行，不能用候选安装验收代替。

边界：子目录/单文件读取保持 best-effort；不新增索引格式，不宣称全树诊断或新的性能指标。见当前开发交接文档。
