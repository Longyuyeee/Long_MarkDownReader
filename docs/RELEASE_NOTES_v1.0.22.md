# v1.0.22 搜索可靠性补丁（候选，未发布）

本版补强日常“找到资料、辨认结果、安全保存”的体验，不新增搜索引擎或图谱特效。

- 搜索失败不再显示成“没有找到”，支持保持原查询重试；切换资料库、清空查询后，旧请求不会覆盖当前结果。
- 标签搜索遇到资料库根目录不可读时明确报错。
- 紧凑搜索结果将标题、命中信息和关系入口分行，长标题保留完整名称提示。
- 修复纯文本保存后迅速切换文件时出现保存报错、旧标签状态不一致的问题；保存回执归属原文件，后续编辑的草稿不会被旧回执覆盖。

当前公开版仍为 v1.0.21。修复候选 `cc58aa68` 已完成托管双包、安装生命周期与 TXT 保存截图核对；独立安装态搜索用户场景仍待运行结果和原图审阅。因此尚无 v1.0.22 正式发布，不应将自动检查或候选包写成发布完成。

社区安装包采用 NotSigned（未签名），Windows 可能提示未知发布者；只从官方 Release 手动下载安装并核对 SHA-256。自动更新观察必须在正式发布后单独执行，不能用候选安装验收代替。

边界：子目录/单文件读取保持 best-effort；不新增索引格式，不宣称全树诊断或新的性能指标。见当前开发交接文档。
