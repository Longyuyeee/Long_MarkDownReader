# Long编辑 v1.1.1

这一版让资料库里的常用操作更直观，集中解决收集箱、集合、标签和关系页面看不懂，以及切换文件时闪动的问题。

## 主要改进

- **所有类型文件都能添加关系**：文档工具栏“专注”旁新增“添加关系”，图谱中也可直接添加。选择两份资料、说明关系即可保存，笔记、PDF、表格、图片及其他附件都能参与；原文件内容保持不变。图谱说明改为实际操作步骤，原有 Markdown 正文链接与图谱工具保留。
- **收集箱更容易开始使用**：默认目录还没创建时显示正常空状态，点击“新建笔记”自动准备位置并打开笔记；目录失效时提供局部重试和更换位置。
- **智能集合按用途组织**：先看“我的集合”和常用示例，再按需设置条件；结果以文件列表呈现，原有全部筛选、编辑、删除和定位能力保留。
- **文内标签用来找笔记**：查看当前笔记标签、点击主题找到相关笔记，也可直接添加标签。添加进入当前草稿，继续使用原保存操作；修正标签篇数重复统计和大写 MD 漏查。
- **关系页更清楚**：“我提到的 / 提到我的”区分引用方向，优先显示资料及引用句；同名文件可选择路径，读取失败可局部重试。
- **切换更平滑**：同类表格切换保留上一屏直到新内容就绪，记住各自阅读位置；侧栏交叠过渡沿用用户动效设置，取消离开未保存文件不会选错标签。

## 下载与升级

支持 Windows 10/11 x64，提供 NSIS 和 MSI，普通用户建议选择 NSIS。
可从本 Release 下载，或在软件中检查更新并确认下载安装。升级保留既有资料库和配置。
本版为未签名社区版，Windows 可能提示“未知发布者”或 SmartScreen，请核对附件 `SHA256SUMS.txt` 的 SHA-256。

## 使用说明与范围

手动关系关联当前资料库内的整份文件，记录保存在资料库的 `.longedit/file-relations.json`；整体搬迁资料库时请保留此目录，应用内移动或改名会同步关系位置。这不改变原有 43 类格式的阅读、编辑和只读边界。

现有主题、六类界面风格、动效设置及原有操作继续保留。纯文本历史差异和网页正文采集仍留待后续版本。

发布事实与安装包验证见 [发布审计](https://github.com/Longyuyeee/Long_MarkDownReader/blob/main/docs/V1_1_1_Unsigned_Community_Release_Audit_2026-10-14.md)。
