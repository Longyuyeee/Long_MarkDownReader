# v1.0.15 M2A3 工作台导航与待办筛选审计

日期：2026-08-26  
阶段：M2A3  
结论：通过，不提升版本

## 开发目标

把收藏、最近文件和项目 Canvas 收敛为单一“继续工作”区域，并让同一文件全局只出现一次；待办支持按状态、来源文件、优先级和日期筛选，已完成任务可恢复，所有写入继续遵守确认、签名保护和撤销边界。

## 预期与修正前实际

| 项目 | 预期 | 修正前实际 |
| --- | --- | --- |
| Canvas 导航 | 同一文件只出现一次 | 收藏、最近、常用 Canvas 最多重复 3 次 |
| 待办筛选 | 状态、文件、优先级、日期均可筛选 | 只有未完成任务列表 |
| 已完成任务 | 可查看并恢复 | 完成后只能依赖即时撤销 |
| 元数据 | 用于筛选但不干扰任务标题 | 尚无优先级和日期语法 |

## 实现结果

- “继续工作”按固定、最近、项目画布分组，使用规范化路径全局去重；Canvas 只归入固定或项目画布，不被修改时间列表抢占。
- 待办识别 `!high`、`!medium`、`!low` 或中文优先级标签，以及 `@due(YYYY-MM-DD)` 日期；标题会隐藏这些机器标记。
- 后端分别返回最多 24 条未完成和 24 条已完成任务，保持源签名、行号和原文本检查。
- 已完成任务可从工作台恢复；每次写入后刷新全部任务签名，避免同一 Markdown 连续操作被旧签名误拒绝。
- 修正了分组展示上限边界：只有实际展示的项目才进入去重集合。
