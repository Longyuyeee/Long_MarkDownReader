# M5-2 ODP 简单幻灯片正文可靠副本基础审计

审计日期：2026-08-31

当前公开/运行时版本：`1.0.16`

开发目标：`1.0.17`

阶段结论：**通过；唯一接续点为 M5-3 ODP 简单页正文副本工作区与真实桌面审计**

## 1. 开发目标审计

M5-2 已实现隐藏的 ODP 后端可靠副本基础：库内读取可返回有界正文库存；含复杂对象的幻灯片整页阻断；候选正文带摘要锁；补丁只修改 `content.xml`，其他 ZIP 部件逐字节保持；保存只允许同目录新文件，拒绝覆盖源文件和已有目标；落盘后重新核对字节、结构、语义和源摘要。

Tauri 命令 `save_odp_slide_text_copy` 已注册，但产品工作区尚未调用它。ODP 注册表仍为 `preview-only`、writer 为 `null`、保存模式为 `none`，因此本阶段没有提前宣称用户可编辑。

## 2. 真实测试：预期、实际与修正

测试现场由 LibreOffice Impress 26.2.4.2 和 Microsoft PowerPoint 16.0 分别生成简单 ODP，并由 PowerPoint 另生成含自定义形状的复杂页。Rust 后端完成库存、真实新文件写入、重复目标拒绝和语义复读；输出再由 PowerPoint 语义打开、由 LibreOffice 隔离配置导出 PDF。

| 步骤 | 预期 | 实际 | 修正 |
| --- | --- | --- | --- |
| XML 特殊符号替换 | `&`、`<` 转义后仍属于简单正文 | 首轮单元测试把 `&amp;` 误判为富文本，语义复读拒绝 | 只允许 XML 五个预定义实体，并锁定连续纯文本区间；嵌套结构仍阻断 |
| PowerPoint 简单文本框 | 与 LibreOffice 一样是直接裸文本段落 | 实际有一个非空样式 span、一个空 span，以及空的 `svg:title/desc` | 保留样式包装，只替换唯一连续非空 span 文本；字段、多非空 span 和任意复杂结构仍阻断 |
| 复杂对象处理 | 跳过复杂形状本身即可 | 真实 PowerPoint 自定义形状页得到 0 个候选、1 个阻断页 | 固化整页阻断，不让同页普通文本进入候选 |
| 可靠副本 | 内存补丁通过即可 | 实际还必须验证新文件不覆盖、落盘字节一致、语义复读、PowerPoint 重开和 LibreOffice 渲染 | 所有层均纳入真实退出矩阵 |

最终 LibreOffice 源为 12,118 bytes，可靠副本为 **12,061 bytes**；PowerPoint 源为 44,304 bytes，可靠副本为 **43,935 bytes**。两份副本在 PowerPoint 中都找回替换标记和未修改稳定标记，原标记均消失；PowerPoint 备注仍保留。LibreOffice 分别导出 15,665 bytes 和 13,736 bytes PDF，输出重开前后摘要不变。三个真实源文件的 SHA-256 在整个测试前后保持一致。

Rust 真实生产者结果为：两份简单源各 2 个候选、0 个阻断页；复杂源 0 个候选、1 个阻断页；每份简单源只改变 `content.xml`，其他部件保持，二次写入同一目标均被拒绝。

补充执行全仓 `cargo test --locked` 的实际结果为 **545 通过、3 失败、5 忽略**。3 项失败逐项独立复跑后仍可重现，但均不经过本阶段 ODP 路径：两个 2026-07 遗留工作簿断言期待在空白区域创建样式/合并，而当前实现实际不创建；一个 PPTX 注册表测试仍期待旧 `Copy`，当前正式事实源为 `BoundedOverwrite`。本阶段没有通过修改工作簿逻辑或削弱断言来掩盖差异；这 3 项登记为 `1.0.17` 打包前必须清零的版本收口阻断项。M5-2 专项合成测试为 2/2，真实生产者测试为 1/1，当前开发总审计通过。

## 3. 需求与安全边界对齐

- 真实测试使用本机 LibreOffice 与 PowerPoint 生成文件，不以静态 mock 代替生产者。
- 每次失败都记录预期、实际与修正，没有通过降低断言取得成功。
- 库内 ODP 只获得隐藏库存和保存命令；外部 ODP 继续只读。
- 备注、列表、字段、图片、媒体、动画、母版和复杂对象继续不可编辑。
- 任意复杂对象导致整页阻断；源文件和已有目标均不可覆盖。
- 证据仅含项目自有标记和去路径化结果，原始生产物留在临时目录且不提交。

## 4. 接续点与版本收口审计

唯一接续点为 **M5-3 ODP 简单幻灯片正文副本工作区与真实桌面审计**：在库内 ODP 右侧工作区接入库存驱动的正文选择、草稿、离开保护、明确阻断原因和可靠另存；外部 ODP 保持只读；必须完成真实 Tauri 宽/窄窗口、源文件保护、输出自动重开以及 LibreOffice/PowerPoint 双生产者复开。

当前不能版本收口或打包 `1.0.17`：用户工作区尚未实现，格式注册表仍未提升，真实桌面交互证据不存在，并且全仓 Rust 测试仍有 3 个非预期失败。运行时/公开版本继续为 `1.0.16`，`releaseCandidate=false`。只有后续工作区、退出审计、Rust 测试债务清零和完整发布门满足后，才进入版本原子提升、安装包、README 与 Release Notes 收口。
