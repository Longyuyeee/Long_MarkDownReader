# v1.2.17：保存状态更准确

JSON/JSONC、YAML、TOML、XML 和 SVG 源码编辑中，撤销或改回已保存的原文后，会正确恢复已保存状态，减少多余保存和关闭确认；结构化操作回到原文同样适用。

保存期间继续输入、切换文件或保存失败，草稿仍被保护。保存成功只确认实际提交的内容，后续修改不会被误标为已保存。未知恢复草稿仍保守保留，外部冲突沿原有比较与副本处理。

大 JSON 分段预览保持只读，读取和翻页不会产生虚假的未保存标记或关闭确认。

沿现有状态栏、标签、保存按钮和关闭交互，不增加页面上的操作；保留全部主题、正常动效和既有功能。下一版计划完成 XML 子元素创建与元素重命名，尚未实施。
