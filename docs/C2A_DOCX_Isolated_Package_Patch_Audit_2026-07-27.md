## 1. 阶段目标

C2A 只建立后续 DOCX 基础编辑需要的安全底座：

1. 读取时返回源文件签名和 `word/document.xml` 摘要；
2. 补丁同时校验源文件签名与目标部件 SHA-256；
3. 只允许替换既有 `word/document.xml`，不允许新增、删除或隐式改写其他部件；
4. 未修改 ZIP 部件通过 `raw_copy_file` 保留压缩数据；
5. 输出先写入系统临时目录，以独占创建方式避免覆盖；
6. 临时副本执行字节复读、SHA-256 核对和完整 DOCX 结构重开；
7. 最后再次核对源文件字节、摘要和签名，证明预览没有改变用户原件。

本阶段不实现段落编辑语义，不接入 DOCX 工作面按钮，也不返回可保存的隔离包字节。

命令只返回审计报告，不返回输出包，不存在对应保存命令。

## 3. 安全边界

### 输入门禁

- 源文件必须位于当前知识库并通过 `.docx` 扩展名检查；
- 源文件不超过 64 MiB；
- 替换后的主文档 XML 不超过 32 MiB；
- 文件签名必须与读取时一致；
- 目标部件摘要必须是 64 位十六进制 SHA-256 且与当前包一致；
- 输入包与输出包都必须通过现有 DOCX 有界解析器。

### 差异门禁

输出包部件清单必须与源包完全一致，实际变化清单必须严格等于：

```text
word/document.xml
```

任何其他部件内容摘要变化都会使整个预览失败。

### 暂未开放

- 段落、标题、列表或表格对象定位；
- 修订、域、内容控件和复杂绘图中的局部编辑；
- UI 编辑状态和撤销重做；
- 返回隔离输出字节；
- 另存新 DOCX；
- 覆盖原 DOCX。

- 临时副本独占创建并同步写入；
