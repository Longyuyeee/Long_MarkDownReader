# A0G 资料库上下文与图谱返回审计

日期：2026-08-04
范围：UX-12
状态：代码完成，待安装版复测

## 根因

- 图谱“返回资料库”只导航到 `LibraryMode`，没有携带活动文件的 `path`；资料库标签仍存在，但嵌入式 CSV/TSV/XLSX 编辑器从空路由读取路径，因此显示“路径无效或知识库尚未配置”。
- 应用此前在 `App.onMounted()` 后才恢复配置，直接路由组件可能先于活动资料库和标签恢复开始读取文件。
- 路由往返会卸载编辑器，表格滚动位置和 XLSX 活动 Sheet 没有会话级恢复。

## 本步完成

- 应用启动改为显式 `bootstrap()`：先恢复配置和标签，再启动路由并挂载组件；配置加载可等待、并发去重，并暴露 `configReady`。
- 初始资料库路由、全局资料库导航守卫和 `LibraryMode` 挂载恢复都会在缺少 `path` 时补回活动标签路径。
- 图谱顶部返回和教程返回统一使用 `returnToLibrary`，显式携带当前活动文件路径。
- Table 与 Workbook 在读取前等待配置，并在路由路径缺失时使用活动标签路径兜底。
- 新增有界、仅内存的工作区视图状态：CSV/TSV/开放 Table 恢复横纵滚动；XLSX 恢复横纵滚动和活动 Sheet。状态不写入本地存储，不持久化完整路径。
- 保留现有脏编辑离开守卫：存在未保存编辑时不会静默进入图谱并丢失草稿。

## 机器审计

- 新增 `check:library-context-restoration` 并接入补丁发布门禁。
- 生产构建、托管文件路由、UI 一致性和当前开发状态检查通过。

## 安装版复测

1. 分别打开 CSV、TSV、开放 Table 和 XLSX，滚动到中部；XLSX 切换到非首个 Sheet。
2. 从文件关系进入图谱，再点击返回资料库，确认原标签仍激活、文件直接可用且滚动/Sheet 恢复。
3. 对 CSV 和 XLSX 制造未保存修改后进入图谱，确认离开保护生效；取消离开后草稿仍在。
4. 冷启动并恢复上次标签，确认不会短暂显示“路径无效或知识库尚未配置”。
5. 连续往返图谱三次，确认不会新增重复标签或丢失活动文件。

安装版复测通过前，UX-12 只标记为“待复测”。
