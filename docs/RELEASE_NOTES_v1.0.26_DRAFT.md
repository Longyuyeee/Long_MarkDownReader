# v1.0.26 发布说明（草稿，尚未发布）

本版聚焦资料库搜索与参考阅读，减少“打开”和“参考”的混淆。

- 点击搜索结果，直接在主编辑区打开。
- 需要对照资料时，使用独立的“在侧边参考”；不再先预览再固定。
- 参考明确标为只读，支持在主编辑区打开或关闭；选文后可复制摘录及来源。
- 搜索结果支持上下键导航；窄窗参考上下排列，返回编辑后可继续输入。
- 修复返回编辑时焦点落回搜索按钮的问题，保留未保存草稿与显式保存原则。

参考显示磁盘上的有界内容，不是实时草稿镜像；本版不包含摘录一键插入、多参考栏或跨重启恢复。

发布状态：功能冻结与 Debug 流程验证完成，版本迁移、安装包和安装态验收尚待执行。当前下载仍请使用 v1.0.25。不得将本草稿作为已发布 Release 上传。
