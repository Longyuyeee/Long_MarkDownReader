# OPML 思维导图编辑器设计与兼容边界

更新日期：2026-07-20
状态：F7-2 首批交付完成

## 1. 产品定位

OPML 工作面解决“图谱能看关系，但不能像思维导图一样主动整理层级”的问题。它不是把知识图谱切换成树形布局，也不是生成不可继续编辑的 Mermaid 图片，而是直接编辑一棵可折叠、可搜索、可拖拽重组的树。

用户文件 `.opml` 是唯一事实源；JSON Canvas 是可继续自由排布的投影视图。两者职责如下：

| 工作面 | 主要职责 | 磁盘格式 |
|---|---|---|
| OPML 思维导图 | 层级梳理、折叠、快速增删、备注和大纲编辑 | 开放 OPML 2.0 |
| JSON Canvas | 自由空间表达、跨格式节点、任意连线和分组 | 开放 JSON Canvas |
| 知识图谱 | 从内容关系中发现连接和治理问题 | 可重建索引，不是事实源 |

## 2. 交互模型

- “思维导图”视图按层级从左到右布局，以曲线显示父子关系。
- “树形大纲”视图提供紧凑的内联标题编辑和层级浏览。
- 两种视图编辑同一数据模型，切换不会转换或复制数据。
- 支持根主题、子主题和同级主题创建，缩进、减少缩进、删除、全部折叠和全部展开。
- 将主题拖到另一个主题上会真实改变父子层级；禁止拖到自身或自己的后代，避免循环。
- 搜索匹配标题与备注，并保留命中节点的祖先路径；搜索期间临时穿透折叠状态。
- 标题、备注、折叠和结构变更进入最多 100 步会话撤销/重做，并在 1.5 秒后自动保存。
- 保存使用内容签名检测外部修改，冲突时拒绝覆盖。

## 3. OPML 稳定模型

标准字段使用 `outline@text` 和嵌套 `outline`。LongEdit 使用不破坏其他 OPML 工具的下划线扩展：

- `_longeditId`：稳定节点身份；外部文件没有该字段时，读取期间生成身份并在下次保存写入。
- `_note`：节点备注。
- `_collapsed`：默认折叠状态。

未知 outline 属性保存在 `attributes` 中并往返写回；`head` 中除 `title` 外的简单文本元数据也会保留。保存输出规范化的 UTF-8 OPML 2.0 XML，因此不承诺字节级排版、注释和属性顺序不变，但承诺树结构、标题、备注、折叠状态、简单 head 元数据和受支持的未知属性语义往返。

## 4. 安全和规模门禁

- 文件必须位于当前知识库，扩展名必须为 `.opml`。
- 单文件上限 8 MB，最多 10,000 个节点，最大 64 层。
- 节点标题最多 2,000 字符，备注最多 20,000 字符，节点 ID 必须唯一。
- XML 使用流式解析，不加载外部实体、不访问网络，也不解析 DTD。
- 写入采用同目录临时文件、备份恢复和原子替换。
- Canvas 投影生成前通过 JSON Canvas 校验，输出文件不覆盖已有文件。

## 5. Canvas 投影

投影以 OPML 文件节点为入口，主题转换为 text 节点，父子层级转换为 `contains` 边。节点按深度分列，并根据同层节点数量分布纵向位置。投影是新建 `.canvas` 文件，不反向覆盖 OPML；用户可在 Canvas 中继续加入 PDF、Table、Markdown 或 Mermaid 节点。

## 6. 索引与格式契约

`shared/file-formats.json` 将 OPML 声明为可读取、编辑、创建和索引，路由为 `MindMap`。索引只提取标题、主题标题和备注，不把 XML 标签或内部属性作为正文。创建、文件树扫描、搜索结果打开和 Canvas 文件节点跳转均继续消费统一格式注册表。

## 7. 当前边界

- 首批不支持自由拖动主题坐标；自由空间排布由 Canvas 承担。
- 暂不提供附件、图标、任务进度、富文本和多人实时协作。
- 外部 OPML 的复杂 head 子树、XML 注释、处理指令和混合内容会在规范化保存时被简化。
- Canvas 投影是单向快照，不在两个文件之间建立隐藏双向同步。
- OPML 节点尚未作为全局知识图谱的独立实体；当前以 OPML 文件级对象参与统一搜索和打开路由。

## 8. 验收证据

- 真实 fixture 覆盖三层树、备注、折叠、head 元数据和未知 outline 属性。
- Rust 回归覆盖解析—序列化—再解析、陈旧签名拒绝、Canvas 投影和语义索引。
- `check:format-contract` 验证 OPML 注册、可靠写入、Canvas 投影和节点预算没有脱离统一扩展框架。
