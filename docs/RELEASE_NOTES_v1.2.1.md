# v1.2.1 — 移动文件后接着工作

- 同一资料库内移动、改名文件或文件夹后，接续阅读位置、表格视图和画布视野。
- 保存过的工作现场、搜索定位和参考资料跟随实际成功的文件操作；批量部分失败仅更新成功项。
- 继续保护未保存正文，不自动保存，不覆盖目标已有的阅读记录；复制保持源记录。
- 沿原有右键、拖放和弹窗使用，无需额外设置。

Windows x64 未签名社区版，安装时可能出现“未知发布者”。请从官方 GitHub Release 下载并核对 SHA-256。应用内自动更新仍沿用已有确认流程，实际升级观察单独记录。
