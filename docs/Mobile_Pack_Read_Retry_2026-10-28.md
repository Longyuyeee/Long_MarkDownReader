# 移动端：附件包读取失败后继续原任务

2026-10-28，阶段5C2，起点 `09e99b9f5`，沿用移动分支 `codex/mobile-0.1.0-foundation`。按照[一个用户任务的开发规则](Development_User_Task_Plan_2026-09-22.md)，本轮处理“读取失败后，继续核对同一份附件包”，不重建已有整包导入和安全写入。只修改移动工作树，仅本地提交。

## 实页观察与竞品依据

[改前报告](evidence/mobile-pack-read-retry-2026-10-28/before-report.json)确认：首次读取附件包列表失败时仍显示“暂无导入记录”；普通详情发生读取异常后没有原地重试；暂存包字节缺失时，存储层返回失败详情而不抛异常，同样没有重试。附件包的刷新原本就会清除旧错误，没有把文字导入上轮的问题照搬过来重复开发。

本轮读取竞品官方说明，未安装或录制竞品。[Bear](https://bear.app/faq/import-your-notes/)支持TextBundle V2及压缩TextPack，iOS从侧栏菜单进入导入；据此继续保留明确的手机导入任务入口。[Joplin](https://joplinapp.org/help/apps/import_export/)说明导入可以携带正文及资源，JEX用于保留笔记与元数据再导入；据此继续把完整包和明确存入作为边界。这些文档没有证明它们当前Android读取失败页使用哪种按钮，具体重试、风险提示和返回契约属于本项目判断。[来源记录](evidence/mobile-pack-read-retry-2026-10-28/research-sources.json)保存了查阅方式及边界。

## 接入的用户路径

- 列表错误与真实空列表分开，失败刷新保留上次列表并标明尚未更新。重读成功只清理列表错误，不混入详情或写入错误。
- 历史记录、刚选择的附件包、收到的附件包共用已有详情读取逻辑。分别识别异常抛出和“原来可核对、现在返回failed详情”；显示“重新读取这份附件包”，沿用同一编号。
- 点击重试后保留并禁用按钮，处理中消费返回并阻止重复请求。原本已经保存为包格式错误的记录继续显示原有失败原因，不伪装成临时读取失败；错误码前缀通过既有的人类可读错误转换清理。
- 未读到完整内容时没有存入入口。内容未知时，移除确认明确提醒可能移除未存入的正文和附件；取消只关闭确认。包内图片返回先收起预览，再回详情，再回原记录、滚动及焦点。
- 核对成功后仍需明确“将笔记和附件存入手机资料库”。重读不重新选择、不自动新建笔记；确认后的独立文件夹、原始换行、附件字节、固定目标和回执保护继续复用。

“源不可用”验证分清两层：本轮浏览器控制的是本机暂存包字节缺失或读取异常，不是Android URI授权。测试恢复合成包字节后可重新核对，不意味着按钮可以修复永久丢失的包。永久缺失继续显示存储层给出的重新选择源包原因；返回导入记录后可以重新选择，已有记录不会被静默替换。收到的内容原有确认回执仍按既有逻辑执行；native preparing记录的重新核对也可能更新其状态，不声称所有元数据读取都是无写入操作。

本轮运行时仅修改 `PackImportPanel.vue`。存储适配器、整包解析、摘要、路径安全、固定目标、原子发布、回执、父页面、接收中心、任务位置及Android包导入实现均与起点一致，详见[来源核对](evidence/mobile-pack-read-retry-2026-10-28/provenance.json)。

## 设计与实际页面

修改业务代码前，冻结[9状态设计、HTML及PNG](evidence/mobile-pack-read-retry-2026-10-28/design-freeze-v1.json)，包括列表失败／恢复、详情失败／恢复、暂存包不可用、移除风险、旧列表、深色和窄屏大字。新按钮保留现有组件样式作用域，避免静态原型与真实按钮间距不同；文本框内容写入原型，保留正常字号和真实焦点。

[设计／实页对照](evidence/mobile-pack-read-retry-2026-10-28/comparison.html)包含9对原图。已逐张查看最终正式App截图；[324项坐标及字体／颜色／名称核对](evidence/mobile-pack-read-retry-2026-10-28/visual-comparison.json)没有差异。截图未做模糊、缩字、焦点移除或像素加工。冻结HTML保留采集到的空行缩进，Git属性仅在这些原始快照上允许该空白并保留原字节。

320px、200%文字下，滚到重试按钮时页头离开视口，文件名也可能部分滚出；顶部返回需向上滚回。这是已有整体滚动弹层的限制，不能称为完整手机页面布局已经验收。短屏保留该真实位置，未裁掉标题制造整页可见效果。下一项应优先审计固定返回入口与长正文／附件清单的分层，再继续图片来源不可用流程。
