# v1.2.0 界面与基础体验已发布

当前开发目标：`1.2.1`；当前运行时版本：`1.2.0`；当前公开版本：`1.2.0`。当前阶段：**v1.2.0 已发布**。

[v1.2.0 正式下载](https://github.com/Longyuyeee/Long_MarkDownReader/releases/tag/v1.2.0)，发布时间 `2026-10-22T11:51:04Z`。本版完成现有界面的空间整理、整窗与小窗口适配，并复查既有基础功能。渠道 community-unsigned，企业 releaseCandidate=false。

## 交付内容

- 资料库、工作台、图谱、各格式阅读编辑页面和公共弹窗减少重复标题及说明，将低频操作放入具名菜单、右键或按需面板，帮助通过圆形问号查看。
- 保留六种风格、明暗主题、文档排版、文件显示样式及正常动效；文件导航维持单行入口，左侧主导航以选中色区分。
- 结构化文件、工作簿、Table、开放文档、演示文稿、Canvas、思维导图和 draw.io 按实际内容区宽度适配；收起属性区保留输入。图谱筛选与工具可完整弹出。
- 修复参考区打开后工作簿操作栏被压至零宽，以及窄窗口 Markdown 的文档操作按钮被遮挡；保存、模式和导出入口可继续触达。
- 继续保留文件管理、图片和链接接续、搜索、集合、标签、关系、现场、历史及备份。未保存内容沿原保存、关闭与冲突保护处理，普通操作错误保持局部呈现。
