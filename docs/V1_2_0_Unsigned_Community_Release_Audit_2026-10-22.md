# v1.2.0 界面与基础体验发布候选

当前开发目标：`1.2.0`；当前运行时版本：`1.2.0`；当前公开版本：`1.1.37`。渠道 community-unsigned，企业 releaseCandidate=false。

本版汇总已完成的全界面内容空间调整、整窗适配、菜单与提示修正。44 个页面及子页面、776 组布局和 13 项整窗交互已完成，另有 3 项共享控件检查。最终阶段补查真实保存、移动改名接续、关闭草稿保护及同一安装包的安装升级流程。尚未把本候选声明为正式发布。

## 当前进度

- 已对齐应用、Tauri、Cargo 和当前能力说明中的版本身份。
- 上一正式版为 v1.1.37，升级检查使用其原始公开安装包。
- 本版功能回归、生产构建、同包安装检查和公开附件核对的结果将在完成后追加，不沿用旧版结果冒充本版通过。

社区安装包可能显示“未知发布者”；SHA-256 与自动更新状态随实际结果记录。

当前公开版本支持手动下载安装；本版安装包完成检查后提供下载。

## 最终功能复查

- 保存与历史：8 项交互、38 组布局通过，覆盖历史回看、局部读取错误、保护失败、外部变化及保护过程中继续输入。
- 文件移动接续：3 项交互、12 组布局通过，覆盖入链文档未保存时阻止移动、移动后编辑区与缓存接续、未完成移动的恢复入口。
- 外部 Markdown 与 TXT：2 项冲突保护检查通过，保留编辑内容并禁止未确认的覆盖。
- 以上使用真实 Vue 页面与用户输入，IPC/磁盘为夹具模拟；原生与安装结果单独记录。[本轮浏览器结果](evidence/v120-final-browser/)。

## 安装复查修正

首轮检查助手已适配文档模式及导出入口；随后在真实安装版发现工作簿参考区组合下操作栏宽度为零。共享文件身份栏的收缩规则已修正，48 组工具／保存操作与 72 组受影响完整窗口检查通过，需重新构建安装包。两轮失败分别保留在 [入口适配记录](evidence/v120-review-failure-39747333044/Iteration.md) 和 [工作簿布局记录](evidence/v120-review-failure-39749494725/Iteration.md)。旧安装包不作为可发布结果。

最终窄页头修正：补齐 18 类编辑页的 864 组参考区组合检查，全部入口可触达，另有四种窗口状态的模式和导出检查通过。此修正将重新构建安装包，历史包及失败记录仍保留。
