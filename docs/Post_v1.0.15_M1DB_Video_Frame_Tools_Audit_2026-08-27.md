# M1D-B 视频逐帧、截图与位置记忆审计

日期：2026-08-27
开发目标：`1.0.16`
运行时与当前公开版本：`1.0.15`
结论：M1D-B 通过，下一步进入 M1D-C 字幕与结构化格式对象选择审计。

## 1. 开发目标

在视频源始终只读的前提下，为现有流式视频工作区增加可理解的逐帧检查、原尺寸 PNG 截图和播放位置恢复。所有能力必须在真实 Tauri/WebView2、真实解码帧和 1080p/4K 视频上验证，不能只检查按钮存在。

## 2. 实现边界

- 支持按 24、25、30、50、60 fps 时间基准前进或后退一帧，并提供 `,` / `.` 键盘操作。
- 截图从当前已解码视频帧生成 PNG；后端复核尺寸、源文件身份、输出摘要和目标复读，已有目标绝不覆盖。
- 播放位置按源文件大小与修改时间绑定，只保存哈希键、时间和身份信息，不保存完整路径或文件名。
- WebM 时长为 `Infinity` 时执行有界时长探测，再恢复播放位置。
- 外部视频继续只读预览，不开放应用内截图写入；视频源文件永不写回。

## 4. 真实测试修正

1. 首次夹具生成器没有把画布尺寸注入 WebView 表达式，视频生成前报 `width is not defined`。这是测试代码错误，修正后重跑。
2. 第二次测试在前一次 `seeked` 事务结束前点击后退，禁用按钮按预期忽略点击。测试改为等待逐帧事务完整结束，再验证反向移动。
3. 第三次测试发现真实产品缺陷：Tauri 资产视频能播放，但 Canvas 因跨源污染无法导出截图。图片与视频元素已统一启用匿名跨源加载；随后同一 1080p/4K 门禁完整通过。
