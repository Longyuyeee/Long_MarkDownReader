# F1 主编辑区保存回执与草稿保护

2026-10-11，接续 `5251c5d7`。目标仍为 1.1.0，运行版本仍为 1.0.26，**尚未封板**。

## 代码审计与修复

LibraryMode 的 saveCurrentFile 原先在 await 写入后，无条件清空标签 dirty，并把 saved.content 写入当时的全局 vditor。这会覆盖等待期间的新输入，或污染已经切换到的文档。该结论来自代码审计，本轮没有在旧版本实窗制造丢字。

现在固定提交正文、编辑器对象和资料库；回执到达时比较最新正文与提交正文。若不同，保留最新正文及 dirty，同时更新已成功写入的磁盘签名，供下一次保存做冲突检查；删除为完整空正文也保留。只有原标签仍在、仍激活且编辑器对象未被替换时，才可能同步格式化后的磁盘正文到编辑器。同一组件中同一标签的重复保存提示稍后重试，不自动排队写旧正文。Git 自动提交也绑定发起保存时的资料库。

主编辑区标签正文变化触发窗口活动上报。新增窗口级 pendingSaves 计数加入既有 dirty 保护，保存成功或失败均在 finally 释放；不同保存相互独立、释放幂等，不因路由组件销毁而提前移除。仍是保守 dirty，不是独立 saving 协议或归档执行许可。

未改页面布局、样式或新增弹窗，仅沿用现有消息提示。未为了通过验收降低条件。
