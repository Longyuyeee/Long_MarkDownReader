# 章节链接随资料接续

在 Markdown 大纲的标题上右键，选择“复制章节链接”，粘贴到另一篇笔记即可。默认地址按当前资料库内的位置定位，不带本机盘符；整个资料库更换位置后，在该资料库中打开笔记仍可定位。

库内移动、改名会沿已有文件操作接续可识别的章节地址。通过文件右键“复制到…”复制笔记或文件夹时，章节链接和配套目标笔记沿实际目标一起映射；仍使用原预览、重名处理和失败项重试，不增加主页面入口。

点击链接会保留当前输入，并优先使用目标文件已经打开的草稿；不会为了定位而读取旧磁盘正文覆盖草稿。重名标题按复制时的明确锚点定位。标题已改名或删除时会局部提示并打开原文，不自动猜测另一个标题；原文找不到时保留当前页面和输入，可从资料库查找后重新复制链接。

原有普通相对链接和本机绝对路径链接继续可用；大纲右键的“复制本机章节链接”保留原本机地址形式。默认章节链接用于 Long编辑 内当前资料库，不能作为公共网页分享地址，也不会自动在其他资料库猜测同名文件。旧绝对链接不会批量自动转换。

未保存正文继续沿已有文件操作保护：移动本身不改变引用时保留草稿；如果改名会影响未保存笔记的章节地址，先按原提示处理这份草稿，取消保持原样。复制始终以已保存文件为准，自己的补写和草稿不会被代存。代码块里的链接示例保持原样。

标题或位置超出可接续的长度时，会提示改用“复制本机章节链接”；不会复制一个应用自身无法接续的地址。
