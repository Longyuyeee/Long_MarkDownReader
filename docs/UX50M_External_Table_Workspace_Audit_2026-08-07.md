# UX-50M / EA-4C 外部 Table、CSV、TSV 工作区审计

日期：2026-08-07

## 本阶段结论

EA-4C 已完成 `.table.json`、`.csv`、`.tsv` 的外部直开、网格编辑与显式保存。用户可从系统文件选择器、Windows 启动参数或格式能力页进入专用表格工作区，不需要先建立资料库或导入副本。

外部能力现为：

- `edit`：26 类，只有点击保存并确认覆盖后才写回源文件。
- `preview`：8 类，只读且没有写回入口。
- `import`：9 类，继续要求导入、转换或系统打开。

## 需求与格式边界

- CSV 与 TSV 始终按原扩展名、原分隔符、原编码、BOM 和换行符写回，不会静默转换成 `.table.json`。
- `.table.json` 保留列 ID、行 ID、冻结列、表格、看板、图表和仪表盘视图；保存继续执行结构验证与 64 MiB 上限。
- 外部编辑保留行列编辑、筛选、排序、冻结前 N 列、视图切换、撤销重做和虚拟滚动。
- 保存前明确提示将覆盖外部源文件；草稿只驻留内存，只有保存按钮或 `Ctrl+S` 才写回。
- 读取返回源文件签名。保存前再次校验签名，外部程序修改过源文件时拒绝覆盖并提示重新打开。
- 外部模式不提供“创建 Table 副本”或导出按钮，因为这些操作需要用户明确选择受管理的资料库目标；不会静默写入当前目录。
- 安装器关联仍只有 `.md/.markdown`；是否让 Long编辑默认打开 Table、CSV 或 TSV，继续由用户在 Windows 中逐项确认。
