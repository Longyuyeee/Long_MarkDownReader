## 实际观察与竞品

初次采集时本地预览端口未启动，[连接失败报告](evidence/mobile-pack-record-read-2026-10-29/before/report.json)保留，不计为产品故障。确认端口空闲及已有构建身份后，为隔离工作树启动仅监听本机的静态预览和证据页服务；没有重启应用或原生服务。

[改前正式App报告](evidence/mobile-pack-record-read-2026-10-29/before-v2/report.json)确认三个断点：首次列表读取失败仍显示“0 条记录”；已核对清单在再次读取失败后被清空；短屏大字的详情重试仍位于正文，旁边另有无效下载和固定移除动作。原页头已有吸顶保护，记录摘要和包本体也会保留，继续复用，不误报为已有数据丢失。

本轮查阅[Notion手机导出](https://www.notion.com/help/export-your-content)：从当前页菜单进入导出，选择格式后交给手机分享菜单；参考按当前对象逐步完成任务的顺序。[Obsidian手机说明](https://obsidian.md/help/mobile)把导航返回／前进及菜单与桌面Ribbon区分，参考按需触达操作。[Acrobat手机副本](https://helpx.adobe.com/acrobat/mobile/view-manage-files/save-copy.html)先选择文件位置、再选择副本动作和目的地，参考先辨认对象再执行。未安装或录制竞品；这些资料不证明其本机保留记录、缓存清单和精确重试／返回行为。对应处理是本项目的设计判断和本地实测，见[来源记录](evidence/mobile-pack-record-read-2026-10-29/research-sources.json)。

## 用户操作与返回

| 当前情况 | 页面和操作 | 保留内容 |
| --- | --- | --- |
| 首次列表失败 | 显示真实错误，底部“重新读取记录”；不显示0条或空列表说明 | 不写入或移除任何保留包 |
| 列表刷新失败 | 明确仍是上次读取的记录，旧列表继续可进入 | 原列表、原导出任务及记录身份 |
| 首次详情失败 | 文件名、附件数与包体积继续显示，固定“重新核对清单” | 同一条记录编号，失败不伪装为无附件 |
| 已核对后读取失败 | 明确“仍显示上次核对的完整清单”，固定同编号重读 | 完整清单DOM和非零滚动；不因失败清空旧内容 |
| 正在读取／核对 | 保留并禁用主要动作，返回和重复点击等待当前回复 | 不跳到别的记录，不启动未经核对的下载 |
| 重读成功 | 清除对应读取错误，焦点转到可见下载／导出动作 | 同一保留包，复用原有完整包核对和导出协议 |
| 移除或查看帮助 | 移除是正文入口，继续使用既有风险确认；返回仅取消当前层 | 原详情、错误、缓存清单及真实入口焦点 |
| 返回列表或原任务 | 详情先返回原记录行；历史再回原导出或设置 | 选中行、列表滚动、原导出快照和受保护草稿 |

记录页与详情使用独立滚动正文，底部只保留当前主要动作，避免短屏被成组操作占满。保留真实错误、上次内容状态及移除风险，一般解释继续放问号。确实读取成功且没有记录时，才显示“0 条记录”和空状态。

## 设计与实际页面

生产修改前冻结十状态Vue／HTML／PNG。v1审图发现深色错误文字叠在固定浅底，以及首次失败重复列表标题；v2先修主题配色、删去重复标题，并修正短列表大字采集参数。v3精简固定列表重试名称，避免200%文字多占一行动作高度。v4把正常详情也统一为一个固定主要动作，移除放正文并保留风险确认。各版本独立保存，未覆盖旧图；只在对应设计冻结后接入生产修正。

[设计／实页对照](evidence/mobile-pack-record-read-2026-10-29/comparison.html)包含十状态参考和十三张最终实页，全部最终原图及五张改前图已逐张查看。名称、坐标、尺寸、字号、行高、颜色差异为0，见[核对结果](evidence/mobile-pack-record-read-2026-10-29/visual-comparison.json)。焦点、原始图片和字体保持，不声明整图像素相同；只适配导入路径后，设计组件与生产组件完全匹配。

保留两类测试失败及原图：[列表／详情失败注入未隔离](evidence/mobile-pack-record-read-2026-10-29/first-failure-fixture-list-detail-isolation.json)、[旧测试寻找禁用下载按钮](evidence/mobile-pack-record-read-2026-10-29/first-failure-old-disabled-download.json)。分别调整为列表读取前撤去详情注入，以及核对“不可下载、可以原地重读”的实际入口；不删除字节、原文、草稿或损坏保护断言。这两处是测试假设迁移，不计为新增产品故障。

## 最终验证与限制

`npm run build:mobile`通过，同一候选执行29组浏览器检查：记录重读6组、导出分层11组、原附件包6组、上一轮来源重试6组；另有记录与来源各4组注入延迟回复检查。报告无页面错误或外部请求。新专项四次axe扫描无违规；短屏大字标题有一处背景重叠未决，保留原报告，补采透明标题的实际背景，原图及计算颜色人工核对为12.173:1，见[颜色补查](evidence/mobile-pack-record-read-2026-10-29/contrast-review.json)，不记为axe自动解决。

覆盖首次失败／旧列表／确实为空的区别、可读及不可读摘要、同编号首次和缓存重读、等待防重复与返回、迟到回复忽略、六份上限内记录的深列表焦点和精确滚动、短屏缓存清单非零滚动与DOM保留、帮助／移除确认逐层取消，以及来源不可用时的完整包重试。

实际下载与此前保留包逐字节相同，独立Python ZIP／CRC和二进制成员检查通过。原附件包回归继续核对完整原文、草稿、BOM及混合CRLF／CR／LF。原资料库不可用时，其原文、私有草稿的内容、签名与revision7未改；见[完整包证据](evidence/mobile-pack-record-read-2026-10-29/archive-content-review.json)。浏览器只报告下载开始，未冒充外部保存已回读。

生产修改限于 `PortableExport.vue`、父任务的记录页样式接线和对应CSS。存储、路径与预算、TextPack／ZIP生成、编辑器、恢复和Android插件保持起点不变；父组件与全局样式也验证了精确增量，见[源码、组件与服务身份](evidence/mobile-pack-record-read-2026-10-29/provenance.json)。没有重复运行未受影响的全量历史测试。
