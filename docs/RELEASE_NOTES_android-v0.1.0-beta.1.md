# Long编辑 Android 0.1.0 beta.1

Long编辑的首个 Android 预览版面向 Android 10 及以上的 ARM64 手机，需要 Android System WebView 111 或更新版本。

- 用手机资料库打开本地文件，搜索文件名和正文，回到最近阅读的位置。
- 阅读和编辑 Markdown 与纯文本，浏览 JSON、YAML、XML、TOML，查看源码。
- 查看 PDF 目录、页面和书签，添加批注并整理阅读笔记。
- 导入、导出文本和附件包，核对未保存的草稿。

## 下载安装

1. 在本发布页下载 `LongEdit-Android-arm64.apk`。同页提供 `SHA256SUMS.txt`。
2. 在手机的下载列表里打开 APK。系统若提示授权，按提示允许当前浏览器或文件管理器安装应用。
3. 打开 Long编辑，使用「添加资料」导入文件，或从设置连接已有文件夹。

如果你装过之前的安卓调试版，正式预览版会作为另一款应用安装。可先从调试版导出笔记、附件包和需要保留的内容，再在预览版导入。若继续使用原有外部文件夹，请在预览版重新授权。

反馈时请附手机型号、Android 版本、Long编辑版本、文件格式和复现步骤。[提交问题](https://github.com/Longyuyeee/Long_MarkDownReader/issues)
