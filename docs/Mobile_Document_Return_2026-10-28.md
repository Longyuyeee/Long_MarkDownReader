# 移动端：让文档返回名称与实际来源一致

2026-10-28，阶段5B，起点 `bc8668b23`。沿用移动分支 `codex/mobile-0.1.0-foundation`，按[一个用户任务的开发规则](Development_User_Task_Plan_2026-09-22.md)处理上一轮确认的返回断点。桌面工作目录未修改，本轮仅本地提交。

## 实际问题与竞品依据

[改前记录](evidence/mobile-document-return-2026-10-28/before-report.json)复现：从设置恢复记录打开独立副本，箭头的无障碍名称是“返回资料库”，实际返回“设置”。源码还把关闭中播报写死为资料库，并按这个可变名称查找关闭前需要聚焦的真实按钮。最近、搜索及密码取消有同类命名问题。

本轮读取官方说明与官方文档仓库，未安装或录制竞品，也不据公开文档推测其草稿实现：

| 来源 | 可确认的行为 | 本项目取舍 |
| --- | --- | --- |
| [Obsidian手机端](https://help.obsidian.md/mobile)，[同页官方文档源](https://github.com/obsidianmd/obsidian-help/blob/master/en/Getting%20started/Mobile%20app.md) | 手机导航提供返回／前进，不可用时变灰 | 返回继续按实际历史执行，名称与所消费的一层一致；沿用原有箭头。 |
| [Notion手机端](https://www.notion.com/help/notion-for-mobile) | 手机使用可直接触达的图标，没有桌面悬停状态；分栏收为单列 | 返回入口保持可直接触达，目的地通过准确名称表达，页面不增加常驻说明。 |
| [Android返回栈](https://developer.android.com/guide/navigation/backstack?hl=en) | 后进先出，普通返回消费当前目的地 | 查找、结构等子任务先处理，完成后才返回文档来源；没有迁移为Android Navigation。 |

具体名称是本项目的设计判断，不声称竞品使用同样文案。[调研来源](evidence/mobile-document-return-2026-10-28/research-sources.json)记录了查阅日期和方式。

## 已接入的行为

| 文档真实来源 | 根返回名称与关闭中播报 |
| --- | --- |
| 资料库或其中的文件夹 | 返回资料库／正在返回资料库…；原目录和筛选继续恢复 |
| 最近打开 | 返回最近打开／正在返回最近打开… |
| 搜索结果 | 返回搜索结果／正在返回搜索结果… |
| 设置中的恢复任务 | 返回设置／正在返回设置… |

来源状态改为响应式引用，成功接纳新文档后名称随之更新。沿用既有来源提交时机和历史对象，不把保存恢复这样的临时层当作新根来源；打开失败继续保留原文档的来源。

关闭前使用返回按钮本身的DOM引用聚焦，保留原有iframe关闭兼容处理。修改名称后仍能定位同一按钮；关闭处理中重复返回继续只消费当前任务。

PDF根入口和密码页的取消名称接入同一来源。PDF批注／查找详情、阅读笔记来源以及文档查找／结构页仍按既有优先级处理。例如先“返回文稿”关闭当前查找，再“返回搜索结果”；PDF从阅读笔记打开时，先“返回阅读笔记”，不跳过它。

本轮不增加常驻解释或修改箭头布局。视图历史、存储、恢复写入、任务位置、密码挑战、PDF读取位置、引用和文字导出模块均未修改；原文、私有草稿及PDF字节继续保留。

## 设计与实页核对

[规则与页面对照](evidence/mobile-document-return-2026-10-28/comparison.html)包含6种外形参考和16张最终实页。此次保留已有外形，先导出正式基线DOM、冻结样式与预期无障碍名称；参考并非新增视觉皮肤。原型目标页使用静态基线样本，主题、查询、焦点与返回链的完整验证以正式App专项为准。

v1删除预览条后按剩余高度渲染，导致窄屏提示区的视口比例高度不同。v2在源码修改前改用相同的完整浏览器视口和App采集区域；只有窄屏参考PNG发生变化，另外五张与已查看v1原图逐字节一致。两版[冻结记录](evidence/mobile-document-return-2026-10-28/design-freeze-v2.json)、源码、样式和原图均保留，没有覆盖旧稿。

[测量](evidence/mobile-document-return-2026-10-28/comparison.json)覆盖188个共同布局坐标，最大差值 **0px**；预期返回名称、计算字体与图标路径一致。普通状态390×844，窄屏320×627、200%字号。副本名称包含真实生成标识，参考与实页的具体字形不同；不声明逐像素一致。

两版参考及16张最终原图已查看，见[查看记录](evidence/mobile-document-return-2026-10-28/visual-review.json)与[复制映射](evidence/mobile-document-return-2026-10-28/original-copy-map.json)。保留关闭前的真实按钮焦点、编辑光标和失败输入；没有通过清除焦点或处理截图对齐。

保留首次未等待iframe正文就绪的搜索副本图、菜单名称匹配失败，以及早期裁掉全屏恢复页页头／PDF原文未加载完成的采集。最终截图按真实任务就绪条件采集；全屏恢复覆盖预览条时采集整个实际视口。没有把早期采集问题记为产品失败或覆盖原图。
