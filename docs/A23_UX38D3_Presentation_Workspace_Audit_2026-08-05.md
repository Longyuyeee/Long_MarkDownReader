# UX-38D3 PPTX 与 ODP 工作区审计

## 结论

UX-38D3 已完成。PPTX 与 ODP 均通过真实 Tauri Debug WebView2 的打开、图谱往返、窄宽布局和源文件完整性验收，文档媒体格式族至此完成 UX-38 分组收口。

PPTX 保持“基础编辑副本”边界：文本、备注、有限字符样式、图片替换、白名单形状与幻灯片生命周期操作都先在隔离副本验证，源 PPTX 始终只读，结果只能另存为同目录新副本。ODP 继续保持结构化只读预览，不提供编辑或保存入口。

## 产品变更

- PPTX 按文件恢复当前幻灯片、详情面板和画布双向滚动位置。
- PPTX 响应式布局按实际工作区容器宽度切换，避免资料库侧栏存在时仍误用宽屏三栏布局。
- ODP 按文件恢复当前幻灯片；加载态和卸载态不得以空工作表状态覆盖已保存的演示文稿上下文。
- 路由显式定位继续优先于历史状态，能力注册表与保存边界未扩大。
