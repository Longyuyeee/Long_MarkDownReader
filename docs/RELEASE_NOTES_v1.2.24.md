# v1.2.24：TOML 数组项新增与删除

TOML 提纲数组按需展开，显示序号和短值，点击定位源码。数组右键“追加数组项…”，条目右键“在此项后新增…”或“删除数组项…”。新增只输入值，预览显示实际类型；空数组可补首项，删除末项保留 `[]`。

支持普通单行文本、数字、布尔与日期时间项，以及范围明确的多行数组。保留其他原文、顺序、字面量、逗号、独立注释、表归属、BOM 和换行；复杂结构或不明确的注释归属局部解释并定位源码，输入仍保留。

修改后保留已展开状态，自动刷新条目，继续保护延迟读取、后续输入、来源切换、保存失败重试和外部冲突副本。差异确认仅应用到草稿，可撤销／重做，保存后才写盘。保留全部功能、风格与正常动效，不新增常驻表单。
