# 当前文档查找与替换

Markdown 在“文档操作 → 查找替换…”或 Ctrl+H 打开；外部 Markdown 在右上角文档操作菜单。TXT 在原查找替换入口或 Ctrl+H 打开。原 Ctrl+F 原生查找继续可用。

先在正文选择一段文字再打开，会默认只查“打开前的选区”；也可以明确选择“整篇文档”。弹窗显示当前文件、命中数量及源码行附近的原文，使用上一处/下一处核对。大小写和整词匹配按需勾选；查找和替换均可粘贴多行，正则符号按普通文字处理。

“替换这一处”直接改当前草稿。“预览全部替换…”先核对数量和示例，再点“应用 N 处替换”。留空替换内容表示删除，`$&` 等字符会原样写入。替换后可通过编辑器的撤销按钮一次还原，仍需点击保存才能写回文件。遇到外部修改继续沿用现有比较与副本流程。

切换文件会关闭旧弹窗，正文有新变化时旧匹配失效；刷新后仍需重新核对范围。不会自动把失效的选区扩大成整篇文档。读取/保存中暂不能开始，原稿始终由所属文档保留。

Markdown 的匹配基于源码，因此语法、代码和链接中的文字也在范围内。三模式均可使用；无法准确对应源码的选区会先停用替换，需在源码模式重新选择，或明确选择整篇文档，不会自动扩大范围。若所见即所得或 IR 的替换会连带改变源码排版，弹窗提示到源码模式处理，原稿不改动。只读文本可以查找，不能替换。

当前范围为 Markdown 三模式和 TextEditor 文本编辑入口。JSON/JSONC、YAML、XML、TOML 的专用结构化源码编辑器保留原生查找，PDF、Office 等二进制格式不执行字符串替换。本版不做整库批量替换。查找词最多 4096 字符，正文和替换结果最多 2 Mi 字符，最多 10000 个命中；超限提示缩小范围，不执行部分替换。
