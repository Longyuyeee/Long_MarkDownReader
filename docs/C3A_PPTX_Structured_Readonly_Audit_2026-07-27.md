## 1. 本批目标与结论

本批从 DOCX C2E 的已验证基线进入 PPTX 主线，目标不是只注册 `.pptx`，而是建立可继续扩展的安全解析、真实生产者证据和应用内只读工作面。

已完成：

1. `.pptx` 进入 schema v2 共享格式注册表、统一 Library 右侧工作面和可恢复路由。
2. Rust 新增有界 OOXML 解析内核，按 `presentation.xml` 与关系文件恢复真实幻灯片顺序。
3. 解析基础文本、图片关系、基础形状/组合/图形框架对象、对象坐标、备注、隐藏页和页面尺寸。
4. 输出生产者、主题、母版、图表、SmartArt、动画、嵌入对象及未知演示部件兼容画像。
5. 应用内提供缩略导航、页码跳转、文本/备注/对象搜索定位、图片预览、备注面板和只读放映。
6. Microsoft PowerPoint 16 与 LibreOffice Impress 26.2 已生成项目自有真实 fixture，并由原生产程序复开。
7. 新增独立生产者矩阵、SHA-256/重开/覆盖门禁和真实 fixture Rust 复读回归。

因此 C3 已从“未开始”进入“结构化阅读可用”，但仍不能标记完成，也不能宣传为 PowerPoint 高保真等价阅读器。

## 2. 安全与保真边界

| 边界 | 当前门禁 |
|---|---|
| 原始文件 | 全程只读，没有 `write_pptx` 或保存命令 |
| 文件大小 | 96 MiB |
| ZIP 条目 | 12,000 |
| 解压总量 | 384 MiB |
| 单 XML 部件 | 32 MiB |
| 幻灯片 | 2,000 |
| 对象 | 100,000 |
| 可检索文本 | 2,000,000 字符 |
| 图片预览 | 48 张、单张 6 MiB、总量 24 MiB，且执行文件签名白名单 |

动画、切换、图表、SmartArt、嵌入对象和未知部件只进入兼容画像或占位，不执行、不转换、不写回。当前工作面根据 OOXML 坐标近似呈现基础对象；无法证明的主题/母版/布局继承不会被伪装成像素级还原。
