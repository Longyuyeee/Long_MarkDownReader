# v1.0.26 搜索与参考交互：功能冻结审计

日期：2026-10-10。公开/运行版本仍为 v1.0.25；本记录是 v1.0.26 的源码收尾，不是已发布声明。

## 本版解决什么

围绕“我查到资料后要打开阅读，只有需要对照写作时才放到侧边”，冻结以下范围，不再用新增格式或新增模块扩大本版：

- 点搜索结果标题、摘要、路径：在主编辑区打开；侧边不自动出现。
- 点独立的“在侧边参考”：一步打开只读参考，取消预览后再固定的中间步骤。
- 搜索词变化不替换参考；普通打开不主动替换参考。仅显式参考动作替换，跨库清空；不承诺跨路由卸载或重启保留。
- 选文才出现摘录操作；复制摘录及来源链接，粘贴后可回到原资料。
- 窄窗口上下排列；“返回编辑”关闭参考并将焦点交回可见、可写的正文。

上一提交 `61ad9ff8` 已实现主要入口。本轮修复了真实操作复现的焦点缺陷：新进程中点击参考，再点“返回编辑”，原先回到搜索触发按钮，无法直接续写。现在等待面板关闭渲染后聚焦可写编辑器；只读页面回到主区域，不冒充可编辑。

## 观察与验证

独立启动本次编译的 Tauri Debug + WebView2；生成 Note.md/Budget.md，不读用户资料库、不安装或替换现有程序、不改用户剪贴板。按钮通过 CDP 鼠标输入点击，正文通过 Input.insertText 输入；场景导航、选文 Range、剪贴板载荷拦截属于自动化步骤，不宣称整套全手工验收。

验证脚本要求新进程。曾尝试在脏编辑器中 Page.reload，触发未保存保护导致自动化超时；没有去掉保护，而是改为每次独立启动。重复利用窗口曾掩盖焦点错误，故可复现入口固定为隔离启动脚本。

## 发布收尾顺序

功能范围已冻结，后续只处理阻断发布的缺陷，按下面顺序推进：

1. 对上述提交完成最终审计并推送；不继续追加摘录直插、收件箱或历史差异。
2. 原子迁移 v1.0.26 运行身份与当前合同，保留 v1.0.25 为公开版本；清空新候选门禁，不继承上一版安装通过记录。
