# v1.0.16 之后的 v1.0.17 专业能力路线

当前公开/运行时版本：`1.0.16`

开发目标：`1.0.17`

## M5-0 范围选择回执

v1.0.16 发布与更新链收口后，真实代码盘点比较了 ODP 有界正文、YAML/XML/TOML Schema 模式，以及图谱聚类折叠/全屏。ODP 已有安全包、正文/备注解析、搜索、定位、只读 UI 与 LibreOffice fixture；Schema 和图谱候选仍缺多项基础合同，因此本轮只选择 ODP。

真实基线重跑得到 Rust 20 通过、0 失败、1 个显式 artifact 测试忽略，LibreOffice 26.2.4.2 可独立打开并导出 ODP，但作者备注仍未保留。唯一接续点为 **M5-1 ODP 幻灯片正文生产者保真与对象选择审计**。该阶段不写产品功能、不开放备注、不提升版本；通过后才决定是否进入有界正文可靠副本实现。

## M5-1 生产者保真与对象选择回执

LibreOffice Impress 26.2.4.2 与 Microsoft PowerPoint 16.0 分别生成两页 ODP，并经过 ZIP/XML 盘点、PowerPoint 语义重开与 LibreOffice 隔离 PDF 渲染。最终两种生产者的简单正文均为 4/4 找回，渲染成功且源摘要不变；LibreOffice 路径实际未保留备注。

真实修正还证明，带 LibreOffice 自定义形状的幻灯片会在 PowerPoint 中出现整页 0 个形状，不能只把复杂形状本身标为只读。因此只选择**无复杂对象幻灯片上的直接文本框段落**，含复杂对象的整页阻断。唯一接续点为 **M5-2 ODP 简单幻灯片正文可靠副本基础**：只做后端库存、拒绝规则、段落替换、可靠新副本和双生产者复开，不开放 UI、不覆盖源文件、不提升版本。

## M5-2 简单页正文可靠副本基础回执

后端现已实现库存驱动的 ODP 简单正文补丁、复杂对象整页阻断、目标摘要锁、`content.xml` 单部件修改、其余部件保持、源冲突保护和拒绝覆盖的新副本写入。真实 LibreOffice/PowerPoint 简单源各识别 2 个候选；真实 PowerPoint 自定义形状页为 0 候选、1 个阻断页。

两份真实副本均由 PowerPoint 找回替换正文和稳定正文、移除原正文，PowerPoint 备注保持；LibreOffice 分别导出 15,665/13,736 bytes PDF，三份源文件摘要不变。测试期间还根据实际 XML 修正了预定义实体误判，以及 PowerPoint 单一样式 span/空 `svg:title/desc` 的安全保留。唯一接续点为 **M5-3 ODP 简单幻灯片正文副本工作区与真实桌面审计**。补充全仓 Rust 测试还有 3 个非预期失败，已登记为版本收口债务；在 M5-3 及该债务清零前不提升格式注册表、不打包 `1.0.17`。

## M5-3 简单页正文副本工作区回执

资料库内 ODP 已接入库存驱动的正文选择、内存草稿、撤销/重做、路由离开与重新读取保护、可靠新副本和自动打开。自定义形状页执行整页阻断，底层结构代码已合并为清晰用户说明；外部 ODP 继续只读。格式事实源据此提升为 `basic-edit / copy`，不宣称完整演示文稿编辑。

真实 Tauri 对 LibreOffice/PowerPoint 两份新生成源分别产出 12,108/43,938 bytes 副本，应用内自动重开成功；PowerPoint 找回替换正文、移除原正文并保持备注，LibreOffice 输出 15,900/14,109 bytes PDF。三份源摘要不变，720×720 无横向溢出，运行时错误 0。全仓 Rust 最新为 544 通过、4 失败、5 忽略；3 项独立复跑稳定失败，知识索引项单独复跑通过但暴露间歇性。唯一接续点为 **M5-4 v1.0.17 质量债务与发布就绪审计**：全部清零后再运行完整发布门并决定是否版本收口。

## M5-4 质量债务与发布就绪回执

M5-3 登记的四个 Rust 问题已经按真实代码根因清零。Workbook 修复了以有值范围截断 OOXML 布局造成的 `D6:E6` 合并区和 `D9 #FFF2CC` 空白样式复读丢失；PPTX 断言与已验收的 `bounded-overwrite` 事实对齐；知识索引缓存命中仍比较真实来源摘要，不再依赖文件监视器事件先到达。

修正后逐项 4/4 通过，全仓 Rust 为 548 通过、0 失败、5 忽略；完整 `ci:patch-release` 通过，前端 6,275 模块、43 格式/91 扩展名、Rust 编译和生产依赖 0 漏洞均满足门禁。唯一接续点为 **M5-5 v1.0.17 原子版本迁移与候选安装包构建**：版本事实必须原子更新，真实 MSI/NSIS 必须记录大小、SHA-256 与 `NotSigned`，不得跳过安装生命周期直接公开发布。
