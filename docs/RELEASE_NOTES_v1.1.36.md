# v1.1.36：按当前文件找到操作

- 命令窗口增加“资料 / 操作”切换，输入中文即可找到附件、历史、来源核对、阅读笔记和录入检查。
- 根据当前文件提供可用操作，直接打开已有面板或弹窗，保留右键和原有菜单。
- 切换文件后不会执行旧命令结果；检查与历史查看保留未保存正文。

- 附件引用列表正确显示 Windows 和网络资料库的相对路径。
