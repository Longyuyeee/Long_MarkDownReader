# v1.3.2：结构提纲键盘导航与定位接续

- JSON字段路径与YAML、XML、TOML提纲可用上下键、Home/End浏览，Enter定位源码后继续编辑。
- 分析刷新后保留有效选择；文字位置变化使用最新范围。行焦点只在原文件列表内恢复，不抢正文、搜索框或弹窗焦点。
- 筛选、空结果、重复路径、展开数组与换文件分别处理；切换文件保留未保存正文，保存仍由用户明确触发。
