# P2-C 图片导航真实桌面审计

审计日期：2026-08-20  
阶段状态：accepted

## 目标与边界

在现有图片工作区内补齐高频查看交互：鼠标滚轮应以光标位置为锚缩放，按住图片应能横纵拖拽，双击应在实际大小与适应窗口之间切换。该阶段不改变格式保存边界，不把只读格式宣传为可编辑，也不引入图层、蒙版或专业色彩管理。

## 修正前差异

实施前检查 `MediaViewerView.vue`，预期存在 `wheel`、`pointerdown`、缩放处理和拖拽起点处理；实际四项均缺失，检查结果为 `FAIL`。原工作区只能依赖按钮或键盘缩放，放大图片后不能直接按住画布移动。

## 实现

- 滚轮使用归一化增量进行连续缩放，并按缩放前后的内容比例维持鼠标下方视觉锚点。
- Pointer Events 与指针捕获驱动双轴拖拽，离开元素或取消输入时可靠结束拖动。
- 双击在 100% 与适应窗口之间切换；方向键可按 80 px 平移。
- 可滚动画布尺寸由图片缩放后尺寸和视口最小尺寸共同决定；触摸默认行为与滚动链被限制在查看区域。

## 真实验收

真实 Tauri WebView2 使用 2400×1600 PNG 和 CDP 原生鼠标事件执行滚轮、按下、移动、释放与双击，不以直接修改 DOM 状态代替用户输入。

| 观察项 | 预期 | 实际 |
| --- | --- | --- |
| 光标锚定缩放 | 横纵漂移均不超过 6% | x 1.63%，y 0.56% |
| 双轴拖拽 | 横纵滚动量均改变 | +150 px / +100 px |
| 双击切换 | 到 100%，再次双击回到适应窗口 | 319% -> 100% -> 37% |
| 窄窗口 | 720×680 无页面级横向溢出 | overflow 0 |
| 宽窗口 | 1280×800 无页面级横向溢出 | overflow 0 |
| 运行时 | 无未处理错误 | 0 |

宽窄截图已人工复核，工具栏、左侧导航与图片视口没有相互覆盖。证据位于 [`evidence/p2c-image-navigation`](./evidence/p2c-image-navigation)，`manifest.json` 约束截图与运行数据摘要，证据不包含用户文档内容。

## 结论

P2-C 通过。图片查看已从按钮式缩放补强为可直接探索大图的鼠标交互，且保持既有源文件与另存边界。下一步运行当前开发综合门禁；只有完整增强包、打包与安装更新生命周期均通过时，才进入 v1.0.12 发布。
