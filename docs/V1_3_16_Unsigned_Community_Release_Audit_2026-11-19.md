# v1.3.16：Windows 输入死锁修复

当前开发目标：`1.3.17`；当前运行时版本：`1.3.16`；当前公开版本：`1.3.16`。当前阶段：**v1.3.16 已发布**。

本版只修复输入期间键盘与焦点消息重入引起的 Windows 原生死锁，升级 Tauri 至 2.12.5，实际解析 Tao 0.37.3，前端 API 同步到 2.12.5。原文档、主题、动效与已有编辑入口保持原有行为。用户现场的恢复文件和内存数据仅存放在本机，不进入发布包或公开证据。

community-unsigned（未签名社区版），企业 releaseCandidate=false；支持手动下载安装。当前公开版为 1.3.16，发布状态由原始构建、实际安装与公开下载回执确认。

原生对照运行 [44451757888](https://github.com/Longyuyeee/Long_MarkDownReader/actions/runs/44451757888) 已通过：旧 Tao 0.34.5 复现死锁，新 Tao 0.37.3 持续响应。该结果属于独立的底层对照，发布检查核对当前锁定版本与测试夹具保持一致，不冒称本版已重新执行。详见[诊断记录](Windows_Input_Deadlock_Fix_2026-11-19.md)。

版本提升前的正式资源构建已经通过。首次直接 Cargo 优化编译未内置正式界面资源，已废弃；正式安装包统一通过 Tauri CLI 构建。本版 1.3.16 的固定源码完整质量检查、Rust 回归、MSI／NSIS 打包、同包安装与升级均已通过，已正式发布。沿用 1.3.15 的核心与受影响工作流范围，未受影响历史结果独立引用，不计为当前重跑。

原规划的引用式文件链接单处修正顺延到 [1.3.17](Foundation_Deepening_Roadmap_1_3_17_2026-11-19.md)，不混入本次修复。
