# v1.3.16：Windows 输入死锁修复

当前开发目标：`1.3.16`；当前运行时版本：`1.3.16`；当前公开版本：`1.3.15`。当前阶段：**v1.3.16 输入死锁修复候选**。

community-unsigned（未签名社区版），企业 releaseCandidate=false；验证完成后支持手动下载安装。当前公开版仍为 1.3.15，候选版不提前计为发布完成。
