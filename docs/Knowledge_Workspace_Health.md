# 知识库健康治理契约

更新日期：2026-07-22  
实施批次：W7-3 / FR-WB-003

## 1. 产品范围

专业工作台把知识健康呈现为可行动清单，而不是不可解释的单一分数。现有图谱健康继续负责断链、歧义链接和孤立笔记；W7-3 增加精确重复文件与未处理 PDF 批注，并与本地索引状态共同构成完整治理面。

治理结果只读，不自动删除、合并或改写用户文件。用户点击条目后回到统一文件路由；点击批注后精确打开 PDF 页码和批注对象。

## 2. 判定规则

- **重复文件**：两个或更多已登记格式文件的字节完全一致。扫描先按大小分组，再计算 MD5 候选摘要，最终重新读取并逐字节比较，摘要相同本身不作为最终证据。
- **未处理批注**：有效 PDF sidecar 中的批注没有被任何 Markdown `longedit://pdf` 精确引用。匹配键为知识库相对 PDF 路径和批注 ID。
- **断链、歧义和孤立内容**：继续消费既有图谱健康分析，不复制第二套关系判定。
- **索引状态**：继续使用 `missing/building/ready/stale/corrupt/error` 状态模型；索引仍是可删除、可重建缓存。

“未处理”只描述批注尚未进入 Markdown 知识引用，不表示批注内容无效。重复文件也只提供核对线索，不推断哪个副本应被删除。

## 3. 扫描与安全边界

- 所有路径通过 `WorkspaceGuard`，只扫描共享格式注册表中的知识库文件。
- 继续跳过符号链接、隐藏项和附件目录；最多扫描 100,000 个目录条目。
- 单个重复候选文件最大 64 MB，单次累计哈希最大 512 MB；最多返回 24 组，每组最多 8 个文件。
- 最多返回 48 条未处理批注。达到文件、哈希、分组或批注上限时设置 `truncated`，前端明确说明结果为部分清单。
- PDF 批注读取复用 sidecar 校验，不修改原 PDF；Markdown 引用解析复用正式格式适配器。

## 4. 失败隔离与验收

工作台概览、图谱健康、索引状态和治理扫描并行且独立加载。治理扫描失败只在治理队列内提示，不阻断收藏、最近文件、待办、Canvas 或智能集合。

自动化回归覆盖完全相同文件分组、不同内容不误报、已有精确引用的批注排除、未引用批注保留，以及工作台生产类型检查。W7-3 完成后 Rust 回归总数为 126 项。
