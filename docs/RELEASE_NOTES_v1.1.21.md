# v1.1.21 · 跨资料库复制

在文件栏选择一份或多份资料，右键“复制到…” → 选择目标资料库 → 确认预览，即可把已保存的资料复制到另一个项目。

- 文件右键“复制到…”可选择另一个资料库，在原弹窗内自动预览目标名称、重名处理和关联资源。
- 复制已保存文件，源文件与未保存草稿保留；不存在的目标目录自动创建，重名保留两份。
- Markdown 可识别的本地图片、附件和关联笔记随复制接续相对引用；无法自动接续的引用先列出，再由用户决定。
- 部分失败只重新核对未完成项；回执丢失先核对同一次复制结果，避免重复创建。
- 完成后可定位目标，保留文件显示样式。同库复制、移动、改名、回收及全部现有主题和工具继续保留。

其他格式原样复制，历史、手动关系和 PDF 批注等管理记录不随带。常规操作不增加常驻面板。发布状态以 [发布记录](https://github.com/Longyuyeee/Long_MarkDownReader/blob/main/docs/V1_1_21_Unsigned_Community_Release_Audit_2026-10-19.md) 为准。

支持 Windows 10/11 x64，提供 EXE 和 MSI。社区版未使用 Authenticode 商业证书，Windows 可能显示“未知发布者”；请从本仓库 Release 下载并使用同页的 `SHA256SUMS.txt` 核对安装包。
