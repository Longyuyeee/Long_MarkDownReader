# v1.1.21 · 跨资料库复制

当前为开发候选，尚未正式公开。

- 文件右键“复制到…”可选择另一个资料库，在原弹窗内自动预览目标名称、重名处理和关联资源。
- 复制已保存文件，源文件与未保存草稿保留；不存在的目标目录自动创建，重名保留两份。
- Markdown 可识别的本地图片、附件和关联笔记随复制接续相对引用；无法自动接续的引用先列出，再由用户决定。
- 部分失败只重新核对未完成项；回执丢失先核对同一次复制结果，避免重复创建。
- 完成后可定位目标，保留文件显示样式。同库复制、移动、改名、回收及全部现有主题和工具继续保留。

其他格式原样复制，历史、手动关系和 PDF 批注等管理记录不随带。常规操作不增加常驻面板。发布状态以 [发布记录](V1_1_21_Unsigned_Community_Release_Audit_2026-10-19.md) 为准。
