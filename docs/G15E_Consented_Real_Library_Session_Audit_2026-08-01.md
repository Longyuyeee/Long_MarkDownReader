# G15E 真实资料库改善观察会话审计（2026-08-01）

## 结论

G15D 已使基线和复查入口在原应用窗口中可发现，但真实资料库执行仍需要用户记住跨页面顺序。G15E 在设置页原有“知识网络匿名观察”下增加四步引导：预览并保存基线、前往工作台执行一项建议、明确确认治理完成、选择原基线并预览复查。它沿用现有设置页字号、按钮、边框和主题变量，不创建新窗口或独立工作区。

当前状态为 `consented-real-library-session-runner-integrated-hosted-execution-next`，`releaseCandidate=false`。本阶段实现产品引导、机器合同和安装态验证器，不声称已经读取或验证任何真实资料库。

## 授权与隐私边界

- 保存基线和保存对比仍分别经过聚合预览、用户确认与系统保存位置选择；引导不会自动触发导出。
- 治理动作由用户自行选择并完成；“我已完成一项治理”只推进界面步骤，不检查、记录或修改具体内容。
- 会话只在 `sessionStorage` 保存 `{ schemaVersion, phase }`，不保存资料库名称、绝对路径、资料库指纹、正文、文件名、对象 ID、基线路径或回执位置。
- 复查时仍要求用户重新选择基线并确认它来自当前资料库，因为隐私设计刻意不建立隐藏的资料库指纹。
- 软件不会自动上传基线、对比回执或任何会话信息，用户可以取消文件选择或随时重置引导。
