# 结构化文件编辑

JSON/JSONC、YAML、XML、TOML 仍使用原保存按钮或 Ctrl+S。

- 在“结构与诊断”按字段、路径或值筛选，Enter 定位第一项，点击问题跳到源码。JSON 可输入 `/items/0/name` 形式的 JSON Pointer。
- 右键提纲节点可定位、复制路径/源码。JSON 既有字段修改、改名、成员增删也可从右键打开；重复键等原有结构修改限制继续保留。
- 格式化、压缩和结构修改按需显示差异。“取消”保持原草稿，“应用到草稿”可 Ctrl+Z 撤销，保存后才写文件。YAML/XML/TOML 保留各自工具，不转成 JSON 修改。
- 保存期间可以继续输入；新输入仍显示未保存，再次保存即可。
- 外部修改发生时可比较、继续编辑或另存当前副本。使用磁盘版本前先保留同目录“当前副本”；副本失败不替换草稿。
- 重新读取先确认放弃未保存内容，取消或失败仍保留草稿。大 JSON 沿用分段只读，不强行加载全文构建树。
- 新文件无法打开时，原标签里的未保存内容仍保留；可以重试或返回原标签。未成功载入的新目标不会使用旧草稿保存。

JSON Schema 沿用现有局部支持范围，不是四种格式通用校验。SVG 沿用严格限制，不能用“按源码保存”绕过。
