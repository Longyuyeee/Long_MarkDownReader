# Long编辑 v1.1.4

这一版继续完善日常使用中的基础功能，保留现有布局、六种显示风格和动效。

- **批量重命名**：多选文件后右键进入，支持名称前后添加文字、查找替换和添加序号。先预览再执行，保留 `.table.json` 等扩展名；重名和无效名称逐项显示，失败时只重试未完成项目。已打开的标签、收藏、最近访问、显示样式、手动关系和历史随新路径接续。
- **模板导入与导出**：模板管理的“更多操作”可导出当前模板或全部已保存模板，也可导入模板文件。导入时选择、预览并处理同名项；原有模板和资料库默认设置保留。
- **历史局部恢复**：在 Markdown 和 TXT 的历史差异弹窗中，通过“恢复此处”只找回需要的一段，其他修改保留。恢复到编辑区后可撤销，保存仍由用户决定；Markdown 保留阅读位置。

Windows x64 提供 EXE 与 MSI 安装包。社区版未签名，Windows 可能显示发布者提示。升级前保存正在编辑的文档，安装后原有资料库和设置会保留。

完整说明和下载见 [README](https://github.com/Longyuyeee/Long_MarkDownReader#readme)。官方应用内更新观察与安装器覆盖升级分别记录，本轮不以覆盖升级替代应用内更新观察。
