# A15 OPML 专业画布审计

## 本阶段结论

UX-37A 已完成 OPML 脑图工作面的专业画布升级，但 UX-37 总项仍保持进行中，产品知识图谱画布留给 UX-37B。

- 提供树状、组织、放射、时间线四种布局，以及专业、多彩、专注三套画布主题。
- 支持空白区平移、鼠标中心缩放、适合窗口、Shift 框选、Ctrl 多选、成组自由拖动和方向键移动。
- 新增主题后直接进入改名，双击已有主题也可改名；节点结构与画布位置共用撤销/重做历史。
- OPML 编辑改为内存草稿；自动保存和离开自动保存已删除，投影 Canvas 也不能旁路写盘。只有点击保存或 `Ctrl+S` 才写入源文件。
- 布局和节点坐标使用 OPML 可往返的 LongEdit 扩展字段；未知第三方属性继续保留。
