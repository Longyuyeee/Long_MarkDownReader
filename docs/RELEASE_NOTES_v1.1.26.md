# v1.1.26：文件右键菜单修复与结构化源码历史

文件栏右键里的“更多操作”“新建”等多级菜单现在能正常向侧边展开，支持滚动和窗口边缘定位，保留全部操作与六种风格。

JSON/JSONC、YAML、XML、TOML 可从“文档操作 → 历史与差异…”查看保存记录、比较差异、恢复局部或整篇，以及恢复为同类型副本。沿用已有历史搜索、保留标记和备注，不增加常驻面板。

恢复只应用到当前草稿，可一次撤销，仍需显式保存；恢复前保护原草稿，继续输入或切换文件会使旧恢复失效。保存记录保留原始源码，副本接续现有编码、BOM 和换行策略，保留注释及布局。外部改动继续使用既有冲突流程。

首批支持资料库内上述格式（含 .yml），外部文件和 SVG 沿用原能力。源码即使有语法问题仍可比较，保存继续按该格式原规则处理。既有读取编码、NUL、大文件与 20 MiB 完整历史对比边界保持。

Windows 社区安装包未签名，请从本 Release 下载并核对 SHA256SUMS.txt。MSI 提供构建与摘要核对，完整安装生命周期以 NSIS 为准。25→26 应用内更新观察单独待补，可手动下载安装。
