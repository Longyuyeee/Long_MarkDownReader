# v1.0.22 候选切片：搜索失败提示与重试

依据主 PRD 1.1 的日常文件查找闭环及“修复问题优先于增加功能”。实际入口为 LibraryMode.vue 的 searchQuery watcher：普通搜索调用 search_knowledge，标签调用 search_by_tag；catch 清空列表，界面仅区分 loading/empty。因此后端失败被误呈现为没有匹配；等待新查询时旧结果仍显示。

冻结范围：独立显示失败/空结果/等待；失败可显式重试并保留关键词及格式过滤；重试不自动重建索引、不写文件；查询清空、资料库切换、卸载后不得回写旧响应。不扩展查询语法、标签覆盖或索引算法。运行时与公开版仍为 1.0.21，本切片不等于 v1.0.22 已发布。

验收：普通与标签失败、空结果、重试成功、快速切词旧成功/旧失败、清空、库切换和卸载；用户可见错误使用固定说明，避免原始异常暴露本地路径/敏感信息。组件预览仅证明提示布局，不替代 Tauri 后端/真实资料库测试。
