# v1.0.15 后 M3C-1 稳定脏帧与生命周期循环审计

日期：2026-08-28

进入基线：`main` / `aa1d412f5ad2ef129b0971eb53b9dcc49835adbd`

阶段：M3C-1

发布候选：否

## 1. 结论

M3C-1 已完成。图谱不再无条件执行 `simulate → draw → requestAnimationFrame`；只有力布局尚未稳定、相机过渡或 calm 选中路径动效会保持连续帧。指针、选择、过滤、缩放、平移、尺寸、主题等状态通过显式脏帧唤醒；失焦、隐藏、返回资料库和卸载会取消循环。窗口恢复不再把已稳定布局强制退回第 40 帧。

同一真实 100/1,000/5,000 节点 Tauri/WebView2 资料库中，稳定绘制从三档均 `132 次/秒` 降为 `0 次/秒`；失焦绘制均为 1、资料库内为 0。三档恢复焦点前后均保持 `layout frame 121 → 121`、稳定且无连续循环。5,000 节点缩放从 `8010ms` 降到 `65ms`，说明之前的交互积压主要受无条件大图绘制影响。

M3C 尚未完成：5,000 节点布局稳定仍需 `186338ms`，超过 `120000ms`，最长主线程任务仍为 `15634ms`；人工截图继续显示全局社区与标签严重拥挤。当前接续点选择为 **M3C-2 大图主线程阶段剖析选择审计**，先分别量化构建、布局、语义派生和绘制成本，再决定 Worker/布局替换或视口裁剪/标签缓存，不能凭总耗时猜测方案。

## 2. 冻结目标与实现边界

- 稳定且没有相机/路径动效时，1 秒内主 Canvas 绘制 `<=2` 次。
- 失焦最多 2 次、返回资料库 0 次；焦点恢复不得重启已稳定布局。
- 力布局、相机过渡和 calm 路径必须继续逐帧推进；reduced 路径必须保持静止。
- 同一真实大图继续执行缩放、完整图平移、Canvas 框选、有界聚焦、源摘要和返回能力测试。
- 1,000 节点继续执行 20 次进入/退出和 heap 前后采样。
- 不引入空间索引、Worker、布局替换、视口裁剪、标签缓存、保存视图或视觉层级重做。

## 4. 连续动效真实回归

重新执行暗色、浅色、高对比三主题 × calm/reduced 六个真实 Tauri 会话：

- 三个 calm 会话在 1280×800 和 720×680 下均为 3 段真实路径、1 段顺事实方向和 2 段逆事实方向；相位、帧和像素均变化，失焦后帧静止，恢复后继续推进。
- 三个 reduced 会话在两档窗口下相位、帧和像素均不变化，失焦/恢复仍静止。
- 六会话均为 11 类对象、6 类关系、运行时错误 0、源摘要不变并返回资料库。

这证明脏帧没有通过“关闭全部 RAF”换取数字，而是保留了合法连续任务。

## 5. 测试差异与纠偏

| 差异 | 原因 | 修正 |
| --- | --- | --- |
| 首次调用了不存在的两条 npm 简写 | 根据脚本文件名猜测命令，没有先读取 `package.json` | 读取真实脚本注册后改用 `check:ux37b-knowledge-graph-canvas` 和完整 M3B-5 名称；两项通过 |
| M3C-0 以“最近 12 个连续绘制帧几何相同”判断稳定 | M3C-1 成功后稳定图本来就不再产生 12 个重复帧，该条件会把正确停转误判为超时 | M3C-1 改为同时读取真实 Canvas 的 `layoutSettled=true` 与 `loopContinuous=false`；绘制次数继续由独立 Canvas 探针计数 |
| 5,000 节点布局没有随空转修复改善 | 本阶段只移除稳定后的循环，布局阶段仍合法连续执行 | 不放宽 `120000ms` 预算，保留 `186338ms` 失败并选择 M3C-2 阶段剖析 |
| 5,000 节点视觉仍拥挤 | 脏帧只改变调度，不改变层级细节 | 截图保留真实现状；裁剪/标签缓存继续延后，未伪装为 M3C-1 完成项 |
