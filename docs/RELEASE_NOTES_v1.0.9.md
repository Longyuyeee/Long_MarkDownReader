# Long编辑 v1.0.9

v1.0.9 是自动更新重启恢复补丁。官方 `v1.0.7 -> v1.0.8` 托管测试证明下载、SHA-256、覆盖安装和新二进制写入均成功，但更新助手没有让新版应用保持运行；本版只修复这一发布阻断问题，不扩大格式或 Office 能力范围。

## 主要变化

- 更新助手等待 NSIS 成功退出后再额外延迟，降低旧单实例锁与安装器收尾竞态。
- 每次启动新版后检查进程是否持续存活；立即退出时自动重试，只有稳定进程才视为重启成功。
- 在更新缓存目录写入脱敏 `relaunch.log`，只记录阶段、退出码、重试次数和进程号，不记录文档正文、知识库路径、API 密钥或凭据。
- 外部文件继续使用独立 `external-*` 顶层窗口，主资料库不被占用，外部文件不进入软件内标签页。

## 安装与更新

- v1.0.9 发布前，公开稳定附件仍为 v1.0.8；v1.0.8 用户可手动重新打开已经覆盖安装成功的应用。
- v1.0.9 必须完成冻结质量门、MSI/NSIS、一次性 Windows 安装生命周期和官方 `v1.0.8 -> v1.0.9` 自动重启 12/12 检查后才收口。
- 社区安装包仍为 `NotSigned`，请只从官方 GitHub Release 下载并核对 `SHA256SUMS.txt`。

## 能力边界

- 本补丁不新增宏执行、外部数据刷新或完整 Excel/Word/PowerPoint 等价写回。
- 自动重启只有在安装器成功且新版进程持续存活后才成立；失败日志不包含用户内容。
