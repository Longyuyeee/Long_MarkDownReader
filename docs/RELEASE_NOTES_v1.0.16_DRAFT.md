# Long编辑 v1.0.16 开发版说明（草案）

> 这是 `main` 上的开发记录，不是公开 Release，不对应可下载的 v1.0.16 安装包。M4F-1 已把候选二进制身份迁移到 1.0.16，但当前公开版本仍为 v1.0.15；只有完整发布门禁通过后才会创建 Tag 和 Release。

## 已完成并通过真实验收

- XLSX：数据验证、条件格式和 Table 对象进入统一内存草稿，支持撤销、重做、离开保护和一次显式保存；大表具有有界分页缓存。
- PPTX：受限文本、备注、字符样式等对象进入统一草稿和确认覆盖事务；高级对象继续只读。
- DOCX：已有段落样式编辑经过 Word、WPS Writer、LibreOffice Writer 的 3 个生产者、9 个来源组合复开验证。
- ODS：简单文本、有限数值和文件已有命名样式可可靠另存新副本；源文件不覆盖。
- JSON：10/50 MiB 大文件使用 512 KiB 渐进只读、分段导航和流式全文搜索；小文件继续完整编辑和树形分析。
- 视频：资料库视频支持前后逐帧、原尺寸 PNG 截图、播放位置记忆，以及同目录同名 VTT/SRT 字幕选择和关闭。
- 工作台：围绕“继续工作、今天要做、需要处理”收敛；Markdown 待办与内部 Table 显式布尔任务行支持确认写回、恢复、撤销、筛选和原对象定位，并保留千文件性能门禁。
- CSV/TSV：创建开放 Table 副本前完整披露来源、候选目标、不覆盖策略和转换损失；成功后自动打开实际创建的首个或编号目标，源文件保持不变。
- OPML：投影到 Canvas 前完整披露来源、候选目标、编号策略、保留内容和元数据/折叠/布局损失；目标是自动打开且不与源文件同步的独立快照。
- 知识图谱：语义探索、专业视觉和大图性能三线均已通过退出审计；除稳定语义、证据、社区、路径与专业视觉外，100/1,000/5,000 节点 Worker 有界布局、稳定脏帧、资源清理以及完整/过滤 SVG 和直接 Canvas PNG 真实导出均已验收。Workbook/ODS 工作表、PPTX/ODP 幻灯片与有界 DOCX 标题现作为显式内部对象进入图谱，支持 `contains` 层级及从图谱、关系上下文精确打开。
- 跨格式定位与行动：搜索、图谱和关系上下文共享统一对象定位合同；Table、OPML、DOCX、ODS、ODP、PPTX、Workbook 的已选内部对象可精确打开。工作台写回严格限定为 Markdown 待办和内部 Table 布尔任务，PDF 未引用批注只读定位，其他格式不制造通用任务语义。
- 受控输出与清理：CSV/TSV→Table、OPML→Canvas、图谱→项目笔记和图谱→Canvas 均披露来源、目标、编号策略与转换损失，自动打开真实目标并保护来源；本周期仅删除四个已有结构化替代指标的可重建大图导出负载。

## 明确边界

- 不宣称完整 Excel、Word、PowerPoint 或 OpenDocument 等价编辑。
- ODS 公式、自定义样式和 ODP 编辑仍关闭。
- 大 JSON 渐进模式只读，不构建全文树形。
- 视频播放取决于 WebView/系统解码器；外部窗口字幕、嵌入字幕拆封、字幕编辑和转码尚未提供。
- YAML/XML/TOML 的 Schema provider/mapping 尚未提供；未配置 Schema 时不制造业务错误。
- 当前 `releaseCandidate=false`，本草案不会替代正式 Release Notes。
