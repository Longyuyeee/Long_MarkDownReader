# F1 批次移动引用影响审计

2026-10-11，接续 `c4618bf3`。本步为后端只读预检，无 UI 修改、正文写回或执行入口。

## 用户问题与实现

用户把互相引用的两篇笔记一起归档到同一目录时，原相对链接可能仍然有效。此前逐文件预测会把另一篇笔记当作留在原地，误报需要改写。

现按整批来源与目标映射计算：出链目标和入链引用者若也在计划中，使用各自计划位置判断原链接是否仍指向预期位置。保留 same_destination、rewrite_required、different_target、needs_review 分类及原证据；同批改名或留在原地的入链仍可能需要改写。

命令层仅在整批既有结构、草稿声明及历史检查无问题时生成批次预测。若其中一项不通过，仍返回依赖候选，但不把有效子集当成完整计划；通过 limitation 明示无法预测。依赖扫描失败仍独立报错。

## 审计边界

- 批次预测显式标记 `batch_projection_assumes_all_planned_moves_succeed`，不是部分成功后的实际状态；部分失败必须按落盘事实重新核对。
- complete=false、canExecute=false 和依赖候选门禁均保持；路径一致不证明文件身份或内容一致。
- 未保存状态仍来自调用者声明，不等于执行时草稿锁。自定义语法、外部修改、跨库入链、精确改写与安全写回仍未闭环。
- 不移动正文或附件、不改引用、不修改历史、不开放归档按钮；未进行 UI 或大库性能验收。
