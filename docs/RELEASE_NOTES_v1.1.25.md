# v1.1.25：当前文档查找与替换

在长方案中改一个词时，可以先选中一段，再打开“文档操作 → 查找替换…”或 Ctrl+H，仅修改这段内容。弹窗集中显示查找、替换、范围和匹配结果，不占用日常编辑空间。

- 支持整篇文档或打开前的选区、上一处/下一处、大小写与整词匹配，查找及替换可粘贴多行。
- 逐个核对后直接替换；全部替换先预览数量与片段，再一次应用、一次撤销。替换符号按字面量写入。
- 支持资料库及外部 Markdown 三模式、TXT 文本编辑入口。保留原 Ctrl+F 原生查找和既有六种风格、正常动效。
- 替换只改当前草稿，仍需保存。新输入、切换文档或正在保存使旧预览失效，继续使用原保存冲突与副本流程。

Markdown 按源码匹配，包含语法和代码。可视模式无法准确对应的选区、会改变额外源码排版的替换，会提示在源码模式处理并保留原稿。结构化专用编辑器沿用原查找；不对 PDF/Office 做源码字符串替换，不做整库替换。超出文本/结果 2 Mi 字符、查找词 4096 字符或 10000 命中时，提示缩小范围，不部分修改。

[使用方法](https://github.com/Longyuyeee/Long_MarkDownReader/blob/main/docs/Document_Find_Replace_User_Guide.md)。Windows 社区安装包未签名，安装时可能出现未知发布者提示。请从本 Release 下载并核对 SHA256SUMS.txt。MSI 提供构建与摘要核对，完整安装生命周期以 NSIS 为准。24→25 应用内更新观察单独待补，可手动下载安装。
