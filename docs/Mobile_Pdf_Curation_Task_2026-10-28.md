# 移动端：选择摘录并保存阅读笔记

2026-10-28，阶段 4D2C，起点 `8c0410719`，移动分支 `codex/mobile-0.1.0-foundation`。按[一个用户任务的开发规则](Development_User_Task_Plan_2026-09-22.md)与[移动交互顺序](design/mobile-interaction-v2/interaction-spec.md)推进“选择摘录 → 核对完整笔记 → 明确保存 → 打开或继续选择”。桌面工作目录未修改。

## 观察与竞品依据

[改造前记录](evidence/mobile-pdf-curation-task-2026-10-28/before-report.json)与五张原图确认：整理页仍同时展开整篇生成、筛选、多选、编辑、删除和原文跳转。保存后回到混排工具，只有一行成功提示；预览底栏常驻说明，挤占正文。

## 本轮接入

- 新独立任务组件承载选择、筛选、预览和保存结果。选择页只有查询、筛选、摘要及原生勾选框；整张条目标签也可点按。不再重复编辑、删除或回到原文操作。
- 固定页头更多里放筛选、选择当前结果、仅看已选、清空和重读。每批显示50条，但批量选择针对完整当前结果；超过200条整批拒绝，不截成前200条。原来全部批注生成能力通过无筛选时选择全部结果保留。
- 整理任务和普通批注列表的查询／筛选各自保留；返回保留未应用筛选、输入 DOM 原值／选区、勾选、展开批次、滚动和焦点。重读后重新找到原条目；筛选外的已选内容仍进入笔记，并显示数量。
- 预览显示全部已选摘录和自己的想法，按原文页码排序。返回不写文件；相同快照保留预览位置，选择变化后的新快照从顶部开始。批注未完成输入保留继续入口，完成或放弃前不预览。
- 保存前核对 PDF 和批注版本。失败保留预览和选择；返回再预览同一快照仍沿用原目标。提供器模拟已写入但回执丢失时，只读核对同一目标及完整内容，不能另建重复副本或覆盖不同内容。
- 成功有独立结果页、打开入口及按需展开的真实文件名。继续选择、再看预览都不写文件；再次明确保存才创建另一份独立快照。笔记内原文链接经真实 Markdown 阅读 iframe 打开原 PDF，返回仍到笔记。
- 一般规则放在问号中。选择上限、内容预算、来源变化和保存失败在当前任务就地显示；删除常驻的整理说明和旧预览底栏说明。

原批注格式、排序／筛选／笔记整理、存储、删除恢复和原文链接引擎，以及独立编辑组件与基线一致。有效的侧车样本包含引号／方括号编号和额外桌面字段，选择及生成后原样保留。修正了直接把条目编号拼进 CSS 选择器的兼容性问题。
