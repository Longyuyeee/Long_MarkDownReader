# Mermaid 图表工作室 1.0

状态：S4-4 / FR-DIAGRAM-004 已实现  
文件格式：普通 UTF-8 `.mmd` / `.mermaid`

## 1. 产品定位

图表工作室用于编辑流程图、时序图、思维导图、类图、ER 图、甘特图等文本图表。Mermaid 源码是唯一事实源，SVG 只作为实时渲染结果，不写入源文件，也不建立私有数据库副本。

它与 JSON Canvas 分工如下：

- Mermaid 适合结构化、可版本化、可由文本生成的专业图表。
- Canvas 适合自由空间布局、混合资料节点和手工思维导图。
- Mermaid 文件可作为标准文件引用嵌入 Canvas，但不把两个编辑模型强行合并。

## 2. 当前能力

- 知识库识别、创建、重命名和打开 `.mmd` / `.mermaid`。
- 源码与 SVG 实时双栏预览，输入 350 ms 后增量触发渲染。
- 解析错误摘要和行号定位；点击错误选中对应源码行。
- 流程图、时序图、思维导图、类图、ER 图和甘特图模板。
- 默认、中性、森林和深色主题，以及 50%–200% 预览缩放。
- `Ctrl+S` 可靠保存、未保存离开保护和外部修改冲突检测。
- Mermaid `11.16.0` 精确锁定；工作室路由与图类型均按需加载。
- 常用 `flowchart` / `graph` 提供结构面板，可从源码识别节点、形状、连线和标签；表单修改立即回写源码并刷新预览。
- 结构修改只替换对应源码字符区间，不重新生成整张图，因此注释、frontmatter、`classDef` 和未识别的高级语法保持原样。
- 当前有效预览可导出为 SVG 或 PNG；SVG 固定数值尺寸并保留矢量文字，PNG 提供 1×、2×、3× 倍率。
- 导出背景可选透明、当前主题或白色；系统“另存为”对话框决定目标位置。
- Canvas 工具栏可添加 `.mmd` / `.mermaid` 文件节点；节点显示严格安全模式实时预览，双击或点击“编辑源图表”进入图表工作室。
- Canvas JSON 只保存标准 `type: "file"` 和相对文件路径，不复制源码、SVG 或增加 Mermaid 私有字段；跨画布复制沿用现有相对路径重定位。

## 3. 安全与资源边界

- 文件必须位于当前授权知识库，并通过 `WorkspaceGuard`。
- 后端最大接受 2 MB UTF-8 源码，拒绝空内容和 NUL 字符。
- 实时预览最多解析 200,000 字符，避免超大文本长期占用 WebView。
- Mermaid 使用 `securityLevel: strict`，编码 HTML 标签并禁用图内点击功能。
- 导出层再次移除脚本、事件属性、外部链接、外部 CSS 资源、嵌入对象、图片和 `foreignObject`，只处理当前源码与主题对应的最新有效 SVG。
- PNG 限制最大边 8192 px、最多 3200 万像素；SVG 输入尺寸最大 16384 px，避免超大 Canvas 或图像解码占用。
- Canvas 内嵌预览最多解析 200,000 字符，并只为可视区域内已挂载的节点加载 Mermaid；源文件读取仍通过 `WorkspaceGuard`。
- 保存前比较长度、修改时间和内容哈希组成的签名；发现外部修改时拒绝覆盖。
- 写入复用可靠写入服务，中断时可以恢复旧文件。

## 4. 已知边界

- 当前错误行号来自 Mermaid 解析器；少数词法错误可能只有错误摘要而没有精确行号。
- 结构化表单只覆盖常用流程图子集：矩形、圆角、菱形、圆形、子程序、六边形，以及 `-->`、`-.->`、`==>` 连线。其他图类型继续使用源码编辑。
- 一行多段链式连线只暴露第一段；仅以 ID 出现、没有显式形状定义的节点会显示但不可通过表单修改。高级语法始终可在源码中编辑。
- SVG 文字仍依赖查看设备上可用字体；未嵌入商业字体文件，跨设备排版可能有小幅差异。
- PNG 是当前 WebView 对清理后 SVG 的栅格化结果，不包含可编辑文本。
- Canvas 节点不直接修改 Mermaid 源码；“可编辑”指始终跳转到同一个源文件进行编辑，以避免 Canvas 与图表工作室产生双份事实源。
- 大量同时可见的复杂 Mermaid 节点仍可能增加 WebView 渲染负担；画布虚拟化会卸载视口外节点，但不会把可见图表降级成静态截图。
- Mermaid 主题是工作室预览设置，暂不写入源码 frontmatter。

## 5. 验收证据

- 浏览器渲染验证覆盖流程图、时序图、思维导图、类图、ER 图和甘特图六类模板。
- Rust 测试覆盖格式大小/NUL/空内容、创建、读取、可靠写入、陈旧签名、知识库越界，以及结构分析、frontmatter 保留和节点/连线精确回写。
- TypeScript 类型检查和生产构建覆盖导出数据流；导出只接受最新有效预览，并对格式、倍率和尺寸做运行时校验。
- Canvas 格式测试覆盖标准 Mermaid 文件引用节点；组件复用图表后端读取校验、严格 Mermaid 配置、保存事件和窗口聚焦刷新。
- TypeScript、Vite 生产构建和 Tauri debug 构建进入统一质量门禁。
