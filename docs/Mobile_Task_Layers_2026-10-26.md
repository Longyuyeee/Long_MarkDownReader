# 移动端阶段 1B：导入任务逐层返回

本轮推进一个用户任务：**查看收到或选中的资料，进入子步骤后仍能回到刚才的位置，确认后再打开。** 在独立手机分支 `codex/mobile-0.1.0-foundation` 开发，桌面工作目录未改动。阶段 1B 继续进行，恢复、导出和外部冷启动来源链尚未整体迁移。

## 实际观察与处理

修改前在正式生产构建复现两处问题：文本导入详情进入移除确认，系统返回直接关闭整个任务；详情进入资料库选择，返回后详情被卸载。见 [修改前记录](evidence/mobile-task-layers-2026-10-26/before/report.json)。该记录的 `passed` 表示采集成功，其中两个缺陷字段均为 `true`，不能当作产品验收通过。

| 用户正在想什么 | 当前行为 |
| --- | --- |
| 我还没决定删除，先返回 | 移除使用居中确认框。Back、Esc、点击蒙层或保留只取消确认，恢复详情、原滚动与移除入口焦点。 |
| 我想看一下原文件夹，随后继续核对 | 资料库选择作为导入任务的子层；父组件保持挂载并隐藏、设为 inert。取消或选中资料库后回到同一份详情，保留正文。 |
| 我暂时不想停止访问 | 停止访问确认返回资料库选择，再返回才回导入详情；取消不撤销授权。 |
| 我刚才查看的是哪一条记录 | 文本、PDF、附件包详情返回各自历史；恢复原记录焦点和列表滚动。文本历史的展开数量保留。 |
| 我只想收起刚看的图片 | 附件包图片预览先收起，再次返回才退出详情；移除确认优先于图片预览。 |
| 帮助看完，接着做刚才的事 | 问号打开触屏帮助。返回关闭帮助并回到详情；确认框内集中显示后果、保留和移除。 |
| 已存入却没打开，该怎么办 | 成功存入后更新接收凭据；打开失败保留任务并提供“打开已导入笔记”。恢复后重试同一目标，不生成重复文件。 |

顶部返回接入与系统桥相同的逐层处理。子资料库选择的关闭按钮只关闭该子层；导入任务根部的关闭按钮退出任务，暂存记录继续保留。PDF 的“稍后处理”仍明确退出接收任务。处理中消费返回，防止异步存入被重复操作打断。

详情中收起了重新选文件的按钮；选择新文件从记录页发起。删除后果、接收状态、错误和未保存提示继续保留。已移入问号的格式、预算等说明保持按需查看，删除了重复的成功引导和“没有附件”的常驻说明。

## 源码与验证

`MobileApp.vue` 记录子面板的真实父层和焦点、滚动，保留父组件；三个导入组件暴露当前步骤的返回能力和确认状态。`taskPosition.ts` 只保存运行期间的 DOM 焦点与滚动，不持久化查询、文件名、弹窗或授权信息。原有格式引擎、文件存入事务、草稿持久化和原生授权协议未重写。

确认框集中使用 `alertdialog`，只呈现当前决定。隐藏父内容设为 inert，键盘焦点留在可见层；取消默认聚焦保留动作。资料库切换期间阻止重复点击。

新增专项逐项断言原笔记、未保存草稿、待存入正文和 PDF 字节。对处理中连续返回、存入成功后模拟读取失败及重试进行实际操作，确认只有一个目标副本。原始失败尝试继续保留在本机，精选证据与哈希纳入版本库。旧 PDF 回归仍测量已删除的说明块，本轮更新为问号入口、卡片、真实预览和固定操作的有效布局检查，保留所有文件与草稿保护断言。

本地复现：完成移动构建并启动静态预览，设置 `LONGEDIT_MOBILE_PREVIEW_URL`（本轮为 `http://127.0.0.1:9012/mobile.html`），按需设置 `LONGEDIT_PLAYWRIGHT_MODULE`，再执行上述专项。`LONGEDIT_TASK_LAYERS_OUTPUT` 可指定新的采集位置。

- [确认框原型与正式页面](evidence/mobile-task-layers-2026-10-26/comparison/comparison.png)：原型原样渲染，正式页面来自生产构建；原始 AI 图未修改。

- [320px / 200% 字号确认](evidence/mobile-task-layers-2026-10-26/final/320-confirmation-200.png)、[PDF 确认](evidence/mobile-task-layers-2026-10-26/final/pdf-remove-confirm.png)、[打开失败保留任务](evidence/mobile-task-layers-2026-10-26/final/open-failed-keeps-detail.png)。专项截图取实际视口，不将长页面视口外的背景拼入弹窗截图。

390px 基准下，原型与正式确认框均为两侧 24px、宽 342px、内边距 24px、圆角 18px、标题 20px；实际两个按钮均高 48px。实际确认后果更完整，框高 260.375px，原型为 241.188px，二者按内容自然居中。保留动作在前且默认聚焦；移除使用警示色。父任务、示例资料和预览标记不同，不声称背景及字形逐像素一致。

本轮先修正返回行为，再核对截图时发现确认框仍是底部卡片，随后调整为居中确认框并重跑受影响检查；没有通过修改参考图消除差异。当前全文档详情仍沿用旧面板布局，完整二级页面、底部操作栏及三项根导航继续在既定后续阶段迁移。
