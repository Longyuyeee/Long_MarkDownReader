# 1.3.17 规划：引用式文件链接的单处修正

1.3.16 已发布 Windows 输入死锁修复，原功能计划顺延至本版。以下尚未实现。

1. 在现有右键菜单和更换目标弹窗中，支持可准确定位的完整、折叠及快捷引用式文件链接，不新增常驻面板。
2. 默认仅更换所选使用处，必要时转为行内链接；保留显示文字、有效标题和章节，其余引用及共享定义原文不变。
3. 核对来源正文、编辑模式、标签和资料库，保护两边未保存内容，支持一次撤销。无法精确映射时保持原文并使用现有编辑入口。
4. 接续普通行内链接、图片操作、文内导航与保存；检查三种 Markdown 模式、中文／空格路径、共享引用，以及全部风格和大小窗口。

不扩展批量重写定义、跨资料库目标或图片迁移。Markdown 光标行列切换后的刷新准确性继续列入后续基础编辑清单。
