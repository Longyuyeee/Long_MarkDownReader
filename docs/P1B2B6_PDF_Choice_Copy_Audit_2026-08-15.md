# P1-B2B6 PDF 单选 Choice 可靠副本审计

日期：2026-08-15
状态：已完成；AcroForm 安全标准字段子集收口，下一入口为 P1-B3 永久脱敏安全审计

## 1. 需求对齐与结论

本阶段继续对齐最初的基础需求：在统一管理器里完成日常阅读、基础编辑和体系化管理。Choice 编辑直接接入初版“左侧资料库、右侧编辑区”的 PDF 表单侧栏，没有新增窗口、路由或视觉体系；字号、颜色、间距、圆角和控件高度继续消费现有主题变量。

已开放的安全子集是标准 AcroForm `Ch` 字段中的单选下拉框或列表框：字段必须可填写、无动作、不是自由输入、不是多选，`/Opt` 必须完整解析为 2～512 个非空选项，导出值必须唯一。复杂结构、缺失或超限选项、重复导出值、复杂塑形展示值、XFA、JavaScript、签名和加密 PDF 均继续阻断。

本阶段不把“可输入任意文本的下拉框”或“多选列表框”宣传为已支持；这两类写回已进入明确的 `notPlanned` 安全边界。至此 PDF 表单的中文单行文本、标准复选框、标准单选组和有界单选 Choice 已形成可发布的基础编辑子集。

## 2. 数据模型与写入审计

- 检查器区分 `combo` 与 `list`，记录自由输入和多选标志，枚举 `/Opt` 的标量选项或 `[导出值, 展示值]` 映射，并读取规范 `/I` 索引。
- UI 的原生 `select` 使用导出值作为真实值、展示值作为可见文本；只有所有安全条件同时满足时才出现编辑控件，其余 Choice 仍保留只读结构审计信息。
- 保存预验证以导出值匹配选项，不允许 UI 文本或任意字符串绕过 `/Opt`；展示值还要通过字体和复杂塑形边界。
- 副本将字段 `/V` 写为所选导出值，将 `/I` 写为唯一选项索引，并重新生成非空 Widget `/AP /N`，外观文本使用展示值。
- 保存后重新打开目标文件，复核 `/V`、`/I`、完整选项映射、有效 Widget 值和非空正常外观；源摘要和目标不覆盖仍为强制门禁。
