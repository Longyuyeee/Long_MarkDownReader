# 长 Markdown 的章节整理

在左侧切换到大纲，点击标题即可定位。相同标题会分别对应正文中的各节。正文滚动时，大纲跟随当前章节；所见、即时渲染和源码模式均可使用。

右键大纲标题（键盘可用 Shift+F10），选择“上移章节…”或“下移章节…”，核对目标章节和内容后移动。移动整节包含其子标题、正文、表格、代码和图片引用。选“提高一级”或“降低一级”会一起调整子标题，不能超出 H1—H6。一次撤销可恢复原稿。

“复制章节链接”复制带唯一片段的 Markdown 链接，可粘贴到本机另一篇笔记。文件路径是本机绝对路径，跨设备或改名后不保证有效；不是共享链接。

这些操作先修改草稿，仍需按保存。预览打开后继续输入或切换文件会拒绝迟到的改动，保留最新正文。外部修改触发原有保存冲突处理，可另存当前副本。

引用、列表内标题可定位和复制链接。当前模式不能可靠对应源码时，结构操作禁用。超长文档（2 MiB 或 4000 标题以上）保留阅读，暂停结构修改。多行 Setext 标题可移动，暂不跨语法转换层级。
