# Long编辑 v1.2.11：XML 属性值编辑

打开 XML 的“元素与问题”，在结构提纲中右键目标元素，选择“修改属性…”，选择已有属性并直接编辑可读值；特殊符号自动转义，保留其他属性、注释、排版和换行。支持空值、多行文字、前缀属性和同名兄弟元素的准确定位。命名空间声明等内容保留源码入口，不增加常驻表单。

修改沿现有差异预览、独立撤销及保存流程接续草稿，错误可原地纠正，切换文件和异步结果继续保护未保存内容。保留全部现有功能、风格和正常动效。

同时修正 YAML 提纲的长数字预览，按原文显示数字与原有记法，文件内容不变。

未签名 Windows 社区版，完整发布检查与 483 项安装版功能任务通过，NSIS、MSI 与 `SHA256SUMS.txt` 三份公开附件已重新下载核对通过。应用内自动更新实际观察仍待完成，与手动安装升级分别记录。
