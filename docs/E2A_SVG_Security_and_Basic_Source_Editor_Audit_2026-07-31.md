# E2A SVG 安全合同与基础源码编辑审计

审计日期：2026-07-31

## 结论

E2A 已完成。SVG 已作为第 40 类格式接入统一 Library 工作区，支持创建、XML 语法高亮与折叠、实时诊断、草稿恢复、全文索引、最近文件、净化预览和带源签名冲突保护的可靠保存。

本阶段没有把 SVG 当作可信 HTML 执行。Rust 后端按安全白名单重写预览，只保留基础图形、文本、渐变、裁剪、遮罩和局部片段引用；前端仅把净化结果放入 `image/svg+xml` Blob，并通过 `<img>` 显示。

## 安全边界

- DOCTYPE、实体声明和 XML 语法错误直接阻断预览与保存。
- `script`、`foreignObject`、动画、链接、图片、未知元素和处理指令不进入预览。
- `on*` 事件属性、`style`、外部 `href`、外部 `url(...)` 和超限视口属性被诊断并移除。
- 不安全源码可以留在草稿中继续修复，但不能覆盖磁盘文件。
- 合法保存复用统一可靠文本写入，外部修改会触发 `expectedSignature` 冲突并保留草稿。
- 源码上限为 5 MiB，`width`、`height` 和 `viewBox` 数值上限为 16,384；同时限制 20,000 个元素、100,000 个属性和 64 层深度。

## 对齐与验证

格式注册表、发布能力矩阵、D2 安全降级通道和 E0 高级路线图均已同步。定向 Rust 测试覆盖安全 fixture、主动内容、外部引用、错误根元素、DOCTYPE 和保存前阻断；Vue 类型检查与 Vite 生产构建通过。

产品状态仍为 `releaseCandidate=false`。E1B 与 E1C 的外部生产者证据阻塞不变。
