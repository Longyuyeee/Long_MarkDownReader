# M1D-C 字幕与结构化 Schema 对象选择审计

日期：2026-08-27
开发目标：`1.0.16`
运行时与当前公开版本：`1.0.15`
结论：M1D-C 选择审计通过，下一步进入 M1D-C1 外部字幕 sidecar 播放。

## 1. 开发目标

以真实 Tauri/WebView2 结果比较视频字幕与 YAML/XML/TOML Schema 两条增强方向，选择一个可独立验收的最小任务。不得因为代码中缺少入口就推测实际效果，也不得同时启动字幕编辑、视频转码和完整 Schema Studio。

## 2. 真实样本

- WebView2 现场编码 1280×720 WebM，确保使用当前系统真实解码链路。
- 与视频同名的规范 WebVTT、SRT sidecar，各含两个时间片段。
- YAML、XML、TOML 分别包含相同业务对象；三者语法合法，但 `port="eighty"`、`enabled="yes"` 违反预期的整数/布尔约束。
- 所有样本位于一次性临时资料库，测试前后逐文件比较 SHA-256，仓库不保留样本正文。

## 4. 选择结论

下一步选择 **M1D-C1 外部字幕 sidecar 播放**：

- 它直接补足已可播放视频的明显用户缺口，实际结果容易通过时间片段和画面验证。
- 首批仅处理资料库内视频旁的 `.vtt` / `.srt`，解析后在内存中生成 WebVTT track；用户可选择轨道或关闭字幕。
- 视频、字幕源文件均只读，不自动转换或写回。
- 嵌入字幕拆封、字幕源码编辑、视频转码继续关闭。

Schema 方向不是取消，而是延后到独立的 provider/mapping 审计。JSON Schema、YAML 映射、XSD 与 TOML 约束并非同一标准，若没有来源、版本、缓存和离线边界，直接增加“Schema”按钮会制造错误安全感。
