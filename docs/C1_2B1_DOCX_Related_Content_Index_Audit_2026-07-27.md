## 1. 本批交付

DOCX 只读模型新增页眉、页脚、脚注、尾注和批注正文。每项内容保留类型、来源部件、引用编号、批注作者/日期和正文锚点，不把 OOXML 包转换为新的文档事实源。

主文档段落与表格会记录 `commentReference`、`commentRangeStart`、`footnoteReference` 和 `endnoteReference`。阅读工作面可以从正文跳到对应附属内容，也可以从批注或注释返回正文引用。

Library 右侧 DOCX 工作面新增：

- 附属内容只读区域；
- 正文引用与附属内容双向定位；
- 覆盖正文和附属内容的文内搜索；
- 页眉页脚、脚注、尾注和批注读取状态；
- 全局搜索结果中的 DOCX 位置标签。

共享格式注册表已将 DOCX 索引能力从 `planned` 提升为 `supported`，索引适配器为 `docx`。实时搜索和持久化知识索引都调用权威 DOCX 解析器，不对 ZIP 二进制做通用文本解码。

## 2. 安全边界

- DOCX 文件上限保持 64 MiB。
- ZIP 条目、解压总量、单 XML 部件、结构块和表格单元格预算保持不变。
- 附属内容最多 10,000 项，总可见文本最多 500,000 字符。
- 所有附属 XML 拒绝 `DOCTYPE`。
- 脚注/尾注分隔符不会作为用户正文展示或索引。
- 当前仍不写回 DOCX，不开放批注回复、接受修订或域更新。
- 无法解析的 DOCX 不进入正文搜索结果，不使用乱码或 ZIP 标记伪造索引内容。

## 3. 索引与定位

持久化索引为 DOCX 保存三类搜索段：

| 类型 | 定位 |
|---|---|
| 文件标题 | 文件级 |
| 标题、段落、列表、表格文本 | `docx-block` |
| 页眉页脚、脚注、尾注、批注 | `docx-*` 附属对象 |

搜索结果新增可选的 `locatorKind`、`locatorObjectId` 和 `locationLabel`。旧索引快照可继续反序列化；DOCX 从不可索引变为可索引后，来源摘要会使旧快照失效并要求重建。
