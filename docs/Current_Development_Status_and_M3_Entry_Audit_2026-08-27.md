## 4. 与最初需求的对齐

### 4.1 已对齐

- **多格式编辑器**：格式注册、直接编辑、只读预览、显式转换和外部打开边界已经形成统一事实源；所有可编辑格式继续遵守“只在点击保存后写回”。
- **Excel 深化**：公式、样式、数据验证、条件格式、表格、图表和高级数据对象已形成较深的有界能力及生产者证据，方向与“完整 Excel 等价编辑器”愿景一致。
- **主题与界面**：多主题、场景预设、代码可读性、管理页和窄窗口适配均已进入持续门禁，不再是只存在于截图中的效果。
- **工作台**：已从格式统计和重复治理卡片转为可继续工作、处理待办和解决问题的行动入口，符合此前删除无用能力、强化工作流的要求。
- **真实性原则**：关键阶段均记录预期、修正前实际、修正后实际、源文件摘要和真实 Tauri 运行结果，没有用静态合同替代全部验收。

### 4.2 必须继续保持的边界

- 当前 XLSX/DOCX/PPTX/ODF 是经过证据约束的专业编辑与可靠副本能力，仍不等于 Microsoft Office 全对象、宏、外部数据和任意高级对象的完全等价实现。
- 旧二进制 Office/WPS、系统解码媒体和外部生产者能力继续保持显式依赖或安全降级，不得扩大宣传。
- 没有真实签名，后续 M4 只能按无签名社区版事实完成发布与更新生命周期。

## 5. M3 修正前代码审计

现有 `GraphView` 并非空白原型，已经具备以下能力：

- 关系网络与思维导图两种视图，五种布局和三种画布主题；
- 搜索、类型/关系筛选、孤立对象治理、关系证据和 Markdown 语义关系编辑；
- 节点邻居列表、拖拽、多选、框选、右键菜单、滚轮缩放、适应视图和撤销/重做布局；
- 布局位置保存与恢复、页面失焦暂停动画、卸载时清理动画帧与监听器；
- 自定义力导向布局已使用空间网格降低局部碰撞计算，并按缩放级别减少标签和边细节。

与 M3 退出条件相比，当前缺口是：

1. 对象类型和关系类型虽已存在，但缺少稳定、统一且用户可见的语义图例与编码合同。
2. 现有邻居遍历主要服务思维导图层级，没有面向用户的一至三层聚焦、双节点比较、选择历史和独立验证的最短路径流程。
3. 尚无成熟社区发现算法、稳定社区 ID、社区摘要和社区筛选。
4. 尚无社区远景、语义缩放、缩略导航图、聚类展开/折叠和路径方向流动等 M3B 完整镜头系统。
5. M0 的 100/1000/5000 结果证明数据构建可完成，但还没有证明当前图谱 UI 在三档规模下的稳定布局、平移、缩放、选择、返回、长任务和 20 次进入退出生命周期。

因此，当前最薄弱且最值得投入的部分确实是知识图谱；但应先补语义和可验证交互，再增加炫酷视觉，避免把视觉变化误当成功能完成。

## 6. 下一步固定执行顺序

### M3-0：选择与性能基线审计

1. 使用 M0 固定 100/1000/5000 节点图谱，在真实 Tauri 中记录首次可见、布局稳定、平移、缩放、节点选择、返回资料库和运行时错误。
2. 在 100 和 1000 节点图中验证邻居、边方向与证据定位；在 5000 节点图中验证不会卡死、空白或失去返回能力。
3. 连续进入退出图谱 20 次，记录监听器、动画帧、主线程长任务和内存趋势。
4. 明确写出预期、修正前实际和差异；此步骤不先改视觉。

### M3A：第一个最小语义闭环

优先选择“**稳定对象/关系语义注册表 + 图例**”作为第一个实现。该能力是最短路径、社区发现、语义缩放和主题视觉的共同基础，且可用固定输入独立验证。

随后按顺序推进：一至三层邻居聚焦与返回、双节点最短路径及独立算法对照、关系证据回跳、社区发现与稳定性。每个子步骤使用同一真实图谱记录预期与实际差异，完成审计、文档、提交和推送后再进入下一项。

### M3B、M3C 与 M4

- M3A 通过后进入 M3B：社区轮廓、语义缩放、路径表达、缩略图、聚类镜头、主题与减少动效。
- M3B 通过后进入 M3C：Worker/成熟布局评估、可见区域绘制、脏帧刷新、5,000 节点和 20 次生命周期收口。
- M3 全部退出条件通过后才进入 M4，统一跨格式定位、清理临时资产、重采发布证据并判断是否提升版本。
