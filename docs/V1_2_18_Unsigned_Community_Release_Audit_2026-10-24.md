# v1.2.18：XML 子元素创建与元素重命名

当前开发目标：`1.2.18`；当前运行时版本：`1.2.18`；当前公开版本：`1.2.17`。当前阶段：**v1.2.18 XML 创建与重命名候选**。

## 用户变化

XML 元素提纲右键“添加子元素…”与“重命名元素…”，沿必要弹窗输入、差异预览、应用到草稿和独立撤销。新增子元素支持空容器、自闭合容器和明确子元素布局，可输入普通文字并转义，默认命名空间按 XML 继承规则处理；混合正文、外部注释或处理指令归属不明确时局部提示并定位源码，保留输入。重命名仅修改准确开始/结束标签的本地名称，保留已有前缀及命名空间绑定、属性与全部内部原文；根元素、自闭合、同名兄弟均沿最新提纲接续。应用后选中并定位当前元素。

不重排或整体序列化文件。保留 BOM、换行、其他源码，以及全部既有功能、主题和正常动效。保存期间继续输入、文件切换、失败重试和外部冲突沿 1.2.17 保存基线与现有草稿保护接续。不增加常驻表单。
