# XLSX 行列隐藏与分组契约

更新日期：2026-07-22
实施批次：S8-1A / FR-DATA-009

## 1. 能力范围

工作簿编辑器支持对整行或整列执行隐藏、取消隐藏、建立分组和取消分组。分组层级映射 OOXML `outlineLevel`，范围为 0–7；隐藏映射 `hidden`，现阶段不伪造 Excel 的自动汇总行，也不修改单元格、公式或其他工作表结构。

前端只有在单一连续的整行或整列选择上开放行列操作。隐藏行压缩为 8 px、隐藏列压缩为 12 px，保留可点击恢复轨道；表头通过视觉标记和提示文本显示隐藏状态及大纲层级。

## 2. 写回事务

- 独立命令 `update_workbook_outline` 校验知识库路径、XLSX 类型、内容签名和目标 Sheet。
- 单次最多修改 10,000 个行列状态；行号、列号和 0–7 级大纲均由 Rust 后端验证。
- 受保护 Sheet 整批拒绝；不存在部分写入，也不尝试绕过 Excel 保护。
- 行状态只重写目标 `<row>` 的 `hidden/outlineLevel/collapsed` 属性；列状态复用 `<col>` 区间拆分，保留原列宽、样式和其他属性。
- 写回继续使用可靠原子替换，并在落盘前执行 XLSX 包安全校验。

## 3. 保真与验收

真实兼容 fixture 覆盖不同列宽下的 B:C 分组，证明区间会按原宽度拆分而不会错误合并。往返测试验证隐藏、分组、取消隐藏、取消分组、旧签名拒绝、8 级越界拒绝和受保护 Sheet 拒绝。

差异门禁要求 ZIP 部件集合不变，且除目标工作表 XML 外所有部件逐字节一致。`sheet_structure` 能力因此扩展为支持行高、列宽、隐藏、分组和合并区域；整行整列插入/删除仍未开放。
