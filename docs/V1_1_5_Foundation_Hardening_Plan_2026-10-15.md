# v1.1.5 基础能力加固

2026-10-15，用户确认继续推进至可收尾发版。当前公开版 1.1.4；本版只处理安全导入和搜索一致性，不加入多步撤销、全库标签改写或新平台。

## 用户任务与验收边界

1. 外部资料拖入资料库，以及外部笔记“存入资料库”：同名默认保留两份，正文和本地图片不覆盖已有文件；图片失败明确反馈，不宣称整份导入完成。多文件逐项执行，只重试失败项。未保存的外部笔记先要求用户保存，不自动代存。
2. 命令面板和资料库搜索共享知识搜索实现，明确当前库/全部库；保留命令、主题和最近文件，结果默认进入主编辑区。快速输入、清空、关闭和进入命令模式均阻止旧结果回填；加载、无结果和失败分别表达。
3. 搜索支持多关键词、精确短语与排除词，普通关键词仍直接可用；保持既有格式筛选、集合、参考和命中定位。不得把搜索条件当成正文定位文字。

## 实施顺序

- 第一批：原生安全导入与真实文件系统回归，先复现旧覆盖行为；界面示意见 `design/v115-foundation-proposal.html`，保留整体布局与六种风格。
- 第二批：复用知识索引的跨库搜索及查询规则，补齐命令面板请求生命周期；验证中文、TXT/JSON、混合格式、失败与乱序返回。
- 第三批：实际组件页面宽窄/六风格检查、类型与完整质量门；产品版本迁移为 1.1.5，再冻结源码、生成固定安装器并验证真实安装态流程。
- 每批自审、文档记录、提交并推送。未取得固定包安装证据前，不将本版标记为可发布；未公开前 README 下载保持 1.1.4。

## 第一批实现与审查

旧路径先抽取不改变行为的函数，加入三项真实磁盘回归：已有正文不覆盖、已有图片不覆盖、缺失图片不得报告成功。修复前 **3 项全部失败**，分别观察到正文/图片字节被替换及缺失图片被忽略。

修复将资料先写入目标目录内的独占隐藏临时文件，同步后使用已有系统级无覆盖原语发布；同名原文件或目录均保留，复合扩展名保持。Markdown 通过 CommonMark 解析器识别图片，仅改写导入副本的图片目标；本地图片放在新建的独立 `.assets` 目录，保留正文换行、标题及图片查询/片段，代码块与代码示例不改写。缺失、越界、被占用等失败不发布正文，只清理本次创建项，不递归删除现有内容。网络及 data 图片保持原引用。

迁移边界：Markdown 最多 20 MiB、512 个图片目标；仅处理所选文档目录内可解析的普通相对本地图片。复杂或无法可靠定位的语法明确拒绝，不猜测替换，不偷偷读取授权目录外的附件。附带图片迁移不是完整附件归档或通用文档链接搬迁。

新增多文件原生命令逐项授权、在文件操作锁内执行，返回成功和失败项。页面按原选择顺序保留结果，仅重试失败项；导入后的目录刷新失败单独反馈，不重新复制已经成功的文件。外部笔记含未保存编辑时要求用户先保存。

原生相关回归已覆盖真实磁盘同名项、图片字节、缺失图片、复合扩展名、CommonMark 行内/引用图片及 HTML 图片、保留 CRLF、代码示例、远端引用、越界拒绝、并发导入和 Windows 文件占用。一次图片夹具的引用定义起初没有正确分段，未被 CommonMark 识别；修正为合法语法并增加“导入前应识别三项图片”的前置断言，原迁移断言不降低。

实际 Vue 页面使用 LibraryMode 原生拖入回调适配器（IPC 模拟）验证 **3 组流程 / 六风格宽窄 12 组布局**：逐项结果、只重试失败项、导入成功但目录刷新失败。测试初期漏模拟实际 `save_folder_order` 命令，补齐夹具后原断言通过；没有改产品来绕过错误或把刷新失败当成文件失败。动效为 `calm`，未设减少动效。已直接查看 [实际部分失败页](evidence/v115-safe-import-development/partial-result.png)，报告见 [组件流程](evidence/v115-safe-import-development/report.json)。
