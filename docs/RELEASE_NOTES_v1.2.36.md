# v1.2.36：YAML 段落文字编辑

YAML `>`、`>-`、`>+` 段落字段现在可右键“修改值…”，直接编辑预填的正文。自动处理段落和缩进，保留折叠块形式、注释与其他字段，无需手动维护 YAML 语法。

确认前展示差异，只修改草稿，一次撤销／重做，显式保存才写盘。输入无法沿用当前格式时局部提示并保留文字，可定位源码继续；普通值与 `|` 多行文字继续使用原有入口。

继续保护未保存内容、迟到结果、旧差异、文件切换、保存失败重试和外部冲突完整副本。保留全部既有功能、风格和正常动效。
