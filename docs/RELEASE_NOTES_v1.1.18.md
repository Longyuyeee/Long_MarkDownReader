# LongEdit v1.1.18 PPTX 编辑与副本交付

- 点选幻灯片对象即可定位现有安全编辑目标，增加本页备注入口；文本、备注、字符、图片、形状、幻灯片和演示工具全部保留。
- 标题、备注等多项更改现在可一起另存新PPTX，不必为了交付副本覆盖原件；同名文件仍禁止覆盖。
- 修复检查与保存的异步归属，操作期间短暂锁定相关控件，旧回执不能修改另一份文档；Ctrl+S不会误触资料库的文本保存。
- 重新读取成功才替换当前页面和草稿，取消或读取失败保留内容；已写入但页面复读失败会如实提示。
- 未加入更改的输入可按目标接续，离开时保护；安全统计与高级工具折叠，减少右栏占用，保留六风格、正常动效和窄屏操作。

Windows x64社区未签名版，可能显示未知发布者；请从本版本Release手动下载安装并核对SHA256SUMS.txt。企业releaseCandidate=false，17→18应用内更新观察单列。原生64项/96MiB、源文件保护、部件保真、确定性重放与复读门禁保留；真实生产者样例和独立ZIP/XML不等于当前Office视觉验收，也不承诺完整PowerPoint能力。
