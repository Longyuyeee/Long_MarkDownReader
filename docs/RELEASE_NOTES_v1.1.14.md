# v1.1.14 写作与文章交付

候选说明，尚未封板或公开发布。验收完成后再以同一固定安装器发布，不把以下功能实现等同于安装验收成功。

- 修复 Markdown 文档 PDF 导出入口，导出前查看当前草稿，通过系统打印另存 PDF，不代存原稿。
- 独立 HTML 携带授权本地位图，离开原目录仍可阅读；缺图、超限和失败明确反馈，在线图片不自动下载。
- 原有快速创建保留，按需填写文章标题与模板字段；参数不递归展开，未知变量保留，显示真实目录。
- 本地图片选择、粘贴和编辑区拖入沿相邻资源目录复制为相对引用，共享图片不搬走；修改正文仍须手动保存。
- Markdown 导出仅正文，取消与真实错误分开处理；另存新文档拒绝已有文件，避免覆盖原稿。

交付字体依赖阅读电脑安装情况，提供后备字体而不复制系统字体；交互图和应用内来源链接请核对预览与原库依赖。社区包未签名，Windows 可能显示“未知发布者”；请核对同页 SHA-256。应用内自动更新与手动覆盖安装分别验收，不提前声称更新观察已通过。

操作入口和资源边界见[模板写作与文章交付说明](https://github.com/Longyuyeee/Long_MarkDownReader/blob/main/docs/Writing_Delivery_User_Guide.md)。
