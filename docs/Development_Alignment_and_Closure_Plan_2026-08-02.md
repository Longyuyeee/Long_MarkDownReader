# 开发对齐与收口计划

审计更新：2026-08-15
当前版本：`1.0.10`
当前阶段：**P1 图片基础编辑：A2 右侧工作区与可靠副本已验收，A3 裁剪、压缩和隐私清理待开发**

## 1. 审计结论

最初确定的专业知识工作台、完整 Excel 方向、新格式编辑器和更多主题预设仍然对齐。v1.0.3/v1.0.4 安装反馈形成的体验问题已经完成有界实现；当前 43 类格式、11 套能力配置、统一主题与安全保存边界均有自动化合同。

EA-5C 已完成外部打开与默认应用汇总：29 类直接编辑、8 类只读预览、6 类显式转换；37 类/85 扩展名默认应用候选只由用户逐项触发。该阶段最初随 `v1.0.6` 建立发布证据，当前 package、Cargo、Tauri 与发布事实源均已推进到 `v1.0.10`；历史版本数据只作为审计轨迹，不代表当前版本。

能力范围已在 XLSX 错误值、日期时间和按工作表知识索引阶段冻结。官方 `v1.0.9 -> v1.0.10` 应用内更新已在 GitHub 托管一次性 Windows 完成 12/12 检查；当前版本事实源和发布后更新链均已收口。

## 2. 需求对齐

- **完整 Excel 方向**：多工作表、公式、样式、图表、筛选、动态数组和部分透视结构已经形成；七种经典错误值及已有日期型单元格均已完成受限编辑与保存复读。宏执行、日期自动类型推断与少数复杂生产者对象仍是明确边界，不能宣称完全等价 Excel。
- **工作簿格式边界**：当前正式注册的工作簿扩展名只有 `.xlsx`；`.xlsm`、`.xlsb` 与旧 `.xls` 不属于软件内 XLSX 编辑承诺。宏工作簿和二进制工作簿只有在建立独立解析、保真与三生产者复开证据后才能登记。
- **新格式编辑器**：当前注册 43 类格式、91 个扩展名，其中 30 类为已验证、7 类为有限能力、6 类依赖外部程序；资料库内 PNG/JPEG/WebP/BMP 已在右侧媒体工作区支持基础编辑并可靠另存，GIF/ICO/AVIF 与外部图片只读，视频使用按需流式读取。
- **更多主题预设**：3 套核心、4 套场景预设和 19 个外观组合仍由统一主题注册表驱动。
- **专业知识工作台**：资料库、搜索、标签、保存视图、引用、图谱、历史、备份和文件上下文保持统一工作流。

## 4. 发布边界

- v1.0.6 采用无 Authenticode 签名社区渠道，可能出现未知发布者或 SmartScreen；正式 Release 已附带并远端复核 SHA-256。
- v1.0.5 是新受控更新链首版。v1.0.4 用户需要手动迁移一次，之后支持应用内检查、确认、校验和覆盖安装。
- 不发布旧 Tauri 更新器要求的 `latest.json` 或 `.sig`；更新信任来自固定 GitHub Release、严格附件名和 GitHub 附件 SHA-256。
- 企业签名候选仍为 `releaseCandidate=false`，与用户批准的无签名社区发布分开。
