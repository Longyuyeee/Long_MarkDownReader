# 开发对齐与收口计划

审计更新：2026-08-11
当前版本：`1.0.8`
当前阶段：**`1.0.8` 无签名社区版待发布**

## 1. 审计结论

最初确定的专业知识工作台、完整 Excel 方向、新格式编辑器和更多主题预设仍然对齐。v1.0.3/v1.0.4 安装反馈形成的体验问题已经完成有界实现；当前 43 类格式、11 套能力配置、统一主题与安全保存边界均有自动化合同。

EA-5C 已完成外部打开与默认应用汇总：29 类直接编辑、8 类只读预览、6 类显式转换；37 类/85 扩展名默认应用候选只由用户逐项触发。package、Cargo、Tauri 与发布事实源已提升到 `1.0.6`，冻结源码的质量门、本地 MSI/NSIS 构建及 GitHub 托管安装生命周期均已通过；`v1.0.6` Release 与三项公开附件也已完成远端校验。

能力范围已在 XLSX 错误值、日期时间和按工作表知识索引阶段冻结。v1.0.7 已完成发布与更新链收口；随后补齐的代码文件创建、自动更新重启和外部文件独立窗口已通过 UX-51 本地实现与真实桌面审计，package、Cargo、Tauri 与现行发布事实源现已提升到 `1.0.8`。

## 2. 需求对齐

- **完整 Excel 方向**：多工作表、公式、样式、图表、筛选、动态数组和部分透视结构已经形成；七种经典错误值及已有日期型单元格均已完成受限编辑与保存复读。宏执行、日期自动类型推断与少数复杂生产者对象仍是明确边界，不能宣称完全等价 Excel。
- **新格式编辑器**：当前注册 43 类格式、91 个扩展名，其中 30 类为已验证、7 类为有限能力、6 类依赖外部程序；图片和视频已经进入独立媒体工作区，视频使用按需流式读取。
- **更多主题预设**：3 套核心、4 套场景预设和 19 个外观组合仍由统一主题注册表驱动。
- **专业知识工作台**：资料库、搜索、标签、保存视图、引用、图谱、历史、备份和文件上下文保持统一工作流。

- Markdown、文本、日志、代码、结构化文件、表格、Office、PDF、图形和媒体均保持显式保存或明确只读边界。
- package、Cargo、Tauri、Windows 生命周期、性能策略、能力矩阵和社区发布策略已同步到 `1.0.6`；Release `367990618` 已发布，Tag 绑定候选证据提交 `257c12e`，三项远端附件哈希一致。
- v1.0.6 安装器已由 GitHub 托管可丢弃 Windows 完成 22 项生命周期和 18 项安装工作区检查；证据绑定产品提交 `9349c334` 和 runner 安装器 SHA-256。

- UX-01 至 UX-41 基础清单已全部回写为“已完成”或“已完成（有界）”；后续体验扩展继续由独立专项合同约束。

- XLSX 已接入资料库持久索引与实时回退搜索：仅按工作表读取缓存单元格值，搜索结果可直接定位工作表；公式执行、外部刷新和源文件写入均不属于索引链。文件、工作表、行列、非空单元格及字符均设有固定预算。

## 4. 发布边界

- v1.0.6 采用无 Authenticode 签名社区渠道，可能出现未知发布者或 SmartScreen；正式 Release 已附带并远端复核 SHA-256。
- v1.0.5 是新受控更新链首版。v1.0.4 用户需要手动迁移一次，之后支持应用内检查、确认、校验和覆盖安装。
- 不发布旧 Tauri 更新器要求的 `latest.json` 或 `.sig`；更新信任来自固定 GitHub Release、严格附件名和 GitHub 附件 SHA-256。
- 企业签名候选仍为 `releaseCandidate=false`，与用户批准的无签名社区发布分开。

## 5. 接手后的顺序

1. 提交 v1.0.8 候选证据并等待第二轮 Quality Gate。
2. 发布 GitHub Release，从远端重新下载 NSIS、MSI 与 `SHA256SUMS.txt` 复核。
3. 在一次性 Windows 上执行官方 `1.0.7 -> 1.0.8` 应用内更新，重点验证安装完成后自动重启和资料保留。
4. 完成后恢复仅处理可复现回归或新增真实生产者证据的维护模式。

按当前发布流程计算，剩余 **2 个版本收口阶段**：Release 与远端附件复核、官方更新链观察。Excel/WPS/LibreOffice 三生产者数组写回属于外部证据门禁，环境未到位时继续 fail-closed。
