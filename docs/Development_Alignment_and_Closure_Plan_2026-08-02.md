# 开发对齐与收口计划

审计更新：2026-08-03  
当前版本：`1.0.2`  
当前阶段：**`1.0.2` 补丁打包与社区发布执行**

## 1. 审计结论

最初确定的专业知识工作台基础、完整 Excel 方向、新格式编辑器和更多主题预设仍然对齐。当前阶段不是继续无边界增加编辑功能，而是把已经完成的能力、UI 治理和品牌资产形成可验证的 v1.0.2 补丁发布。

P0、UI-1、UI-2、UI-3 与 UI-4 均已完成。受管文件路由、共享界面结构、字号、颜色与状态语义、管理页面壳层、真实桌面视觉证据和发布事实均已进入自动化门禁。

## 2. 需求对齐

- **完整 Excel 等价编辑器方向**：工作簿基础与高级能力持续增强，已覆盖多工作表、公式、样式、图表、筛选、动态数组及部分数据透视结构；宏执行和少数复杂生产者兼容仍属于明确边界，不能宣称完全等价 Excel。
- **新的文件格式编辑器**：格式注册表共 41 类格式，29 类为已验证、6 类为有限能力、6 类依赖外部程序。
- **更多主题预设**：当前共 19 个预设，其中 3 个核心主题、4 个经过门禁的场景预设和 12 个兼容外观组合，均由唯一主题注册表驱动。
- **专业知识工作台**：资料库、搜索、标签、集合、引用、图谱、关系面板、历史和备份保持统一工作流，内部文件入口保留资料库上下文。

## 3. 当前开发状态

- 41 类格式映射到 10 套发布能力配置，界面与能力合同使用同一事实源。
- 核心壳层完成 45 张真实 Tauri 截图，11 类主要编辑器完成 99 张截图，共 144 张；覆盖专业浅色、专业深色、高对比与 100%/125%/150% 等效缩放。
- 品牌图标已统一为深蓝底、放大的实心金色 `L` 和金色编辑笔尖，并覆盖全部平台资产。
- package、Cargo、Tauri、发布矩阵和当前产品策略已提升为 `1.0.2`。
- v1.0.1 已发布，v1.0.2 尚需完成质量门禁、安装包、哈希和 GitHub Release 回执。

## 4. 发布边界

- v1.0.2 是未签名社区补丁，不是企业 Authenticode 签名候选；能力矩阵继续为 `releaseCandidate=false`。
- 原 Tauri 自动更新私钥当前不可用，因此只发布手动安装的 NSIS、MSI 和 `SHA256SUMS.txt`，不发布 `latest.json` 或 `.sig`。
- 保留既有自动更新公钥，避免破坏历史版本的信任连续性。
- v1.0.0 的完整安装生命周期证据作为历史证据继承，v1.0.1 是当前覆盖安装基线；本补丁重点验证构建、契约和安装包事实。

## 5. 接手后的顺序

1. 运行 `npm run ci:patch-release`，修复任何版本、UI、格式、Rust 或依赖门禁问题。
2. 在关闭更新产物生成的临时发布配置下构建 v1.0.2 NSIS 与 MSI。
3. 检查安装包版本、图标、未签名状态和 SHA-256，写入发布说明与审计文档。
4. 推送最终候选提交，确认 GitHub Quality Gate 成功。
5. 创建 `v1.0.2` 标签与 GitHub Release，上传两个安装包和 `SHA256SUMS.txt`。
6. 将 Release URL、标签提交、质量门禁和附件回执写回发布策略与本审计文档，再推送主分支。

本阶段完成标准是：README 与应用显示真实版本，质量门禁成功，GitHub Release 可下载，安装包哈希可核对，自动更新限制公开且没有伪造签名资产。
