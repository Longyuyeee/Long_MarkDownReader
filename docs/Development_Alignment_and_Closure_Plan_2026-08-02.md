# 开发对齐与收口计划

审计更新：2026-08-10
当前版本：`1.0.5`
当前阶段：**EA-5C 外部打开与体验有界收口完成**

## 1. 审计结论

最初确定的专业知识工作台、完整 Excel 方向、新格式编辑器和更多主题预设仍然对齐。v1.0.3/v1.0.4 安装反馈形成的体验问题已经完成有界实现；当前 43 类格式、11 套能力配置、统一主题与安全保存边界均有自动化合同。

EA-5C 进一步完成外部打开与默认应用汇总：29 类直接编辑、8 类只读预览、6 类显式转换；37 类/85 扩展名默认应用候选只由用户逐项触发。EA-5B2B 的真实 NSIS 生命周期、升级、单实例文件转交、卸载和回滚证据已经入库，因此当前具备进入 v1.0.6 社区补丁打包的条件。

## 2. 需求对齐

- **完整 Excel 方向**：多工作表、公式、样式、图表、筛选、动态数组和部分透视结构已经形成；宏执行与少数复杂生产者对象仍是明确边界，不能宣称完全等价 Excel。
- **新格式编辑器**：当前注册 43 类格式、91 个扩展名，其中 30 类为已验证、7 类为有限能力、6 类依赖外部程序；图片和视频已经进入独立媒体工作区，视频使用按需流式读取。
- **更多主题预设**：3 套核心、4 套场景预设和 19 个外观组合仍由统一主题注册表驱动。
- **专业知识工作台**：资料库、搜索、标签、保存视图、引用、图谱、历史、备份和文件上下文保持统一工作流。

## 3. 当前开发状态

- UX-40 至 UX-49 已完成文档切换、侧栏、文件标记、横向导航、画布交互、Table 看板、下拉控件、命令条、自动更新和媒体播放收口，P0、UI-1、UI-2、UI-3 与 UI-4 均已完成。
- 43 类格式映射到 11 套发布能力配置，产品界面与发布审计消费同一事实源。
- Markdown、文本、日志、代码、结构化文件、表格、Office、PDF、图形和媒体均保持显式保存或明确只读边界。
- package、Cargo、Tauri、Windows 生命周期、性能策略、能力矩阵和社区发布策略已同步到 `1.0.5`。
- v1.0.5 安装器已由托管可丢弃 Windows 完成 22 项生命周期和 18 项安装工作区检查；证据绑定产品提交 `328d16d` 和安装器 SHA-256。
- UX-01 至 UX-41 基础清单已全部回写为“已完成”或“已完成（有界）”；后续体验扩展继续由独立专项合同约束。

## 4. 发布边界

- v1.0.5 仍是无 Authenticode 签名社区版，可能出现未知发布者或 SmartScreen；必须发布 SHA-256。
- v1.0.5 是新受控更新链首版。v1.0.4 用户需要手动迁移一次，之后支持应用内检查、确认、校验和覆盖安装。
- 不发布旧 Tauri 更新器要求的 `latest.json` 或 `.sig`；更新信任来自固定 GitHub Release、严格附件名和 GitHub 附件 SHA-256。
- 企业签名候选仍为 `releaseCandidate=false`，与用户批准的无签名社区发布分开。

## 5. 接手后的顺序

1. 统一提升 package、Cargo、Tauri、能力矩阵和社区发布策略到 `1.0.6`。
2. 全面更新 README 与 Release Notes，明确 43 类格式、外部打开、逐格式默认候选和有界 Office/媒体能力。
3. 运行完整质量门，构建无签名 MSI/NSIS，记录版本资源、大小、SHA-256 与 `NotSigned` 状态。
4. 发布 `v1.0.6` 并从远端下载复核；随后使用已安装 `1.0.5` 验证受控自动更新和用户资料保留。

`1.0.6` 发布后继续观察系统解码器差异和自动更新链；后续可继续推进更完整的 Excel/Office 能力，但不扩大未经验证的公开承诺。
