# Long编辑 v1.1.10 · 标签与集合整理更可靠

Windows 10/11 x64 社区版。本版深化现有标签与集合，让查找、继续整理和安全修改更可靠，不增加另一套管理流程。

## 找资料与继续整理

- 集合按文件归组续载，不再停留在前 200 个命中；一个文件的多个位置保留在同一项中，能分别打开。
- 名称、路径、修改时间和相关度针对整个查询排序。未读完整时明确说明，不把部分数量当总数。
- 刷新等待或失败保留旧结果；未提交的集合条件切换侧栏后仍可继续，目录失效沿“调整条件”修复，保存的集合不静默丢失。
- 标签统计与标签查找使用同一识别规则，处理反引号、BOM 等分隔边界；同篇笔记同标签只计一次。大量笔记可分批统计与续载，固定标签在暂时无笔记时仍保留。

## 明确确认的标签整理

- 在标签笔记列表选择最多 64 篇，通过预览添加、改名或移除标签；只处理本次选择，不自动整理整个库。
- 操作会修改已保存的 Markdown 正文（按已有识别规则，包含代码块中的同名标签），预览会明确提示；不移动文件，不自动代存草稿，也不改写其他集合的含义。
- 本窗口未保存笔记排除；其他窗口相关草稿先阻止执行。正文从预览后被修改则不覆盖；写入前保留原文历史，BOM 与换行保持。
- 部分失败逐文件给出已完成、未执行或需核对，不自动全量重试或回滚覆盖。结果为进程内短期收据；原文历史按现有历史机制保留。

## 边界与安装

保留现有功能、六种风格、正常动效、显式保存及主区打开/参考逻辑。统计和查询仍有来源/载荷预算，超过时显示尚未查全；批量整理每文件 UTF-8 上限 20 MiB、预览前后文合计 32 MiB、5 分钟过期，不是跨进程操作系统文件锁。

社区 Windows x64 安装包为 NotSigned，系统可能显示“未知发布者”。发布时提供 MSI、NSIS 与 SHA-256 校验；应用内自动更新的独立观察不能由发布成功推断。企业签名、macOS/Linux 安装支持及未实现格式能力没有在本版提升。

## 实际验证

同一份安装器通过本版 13 项及历版 109 项功能检查、22 项安装生命周期、18 项工作区、11 项路由、7 项备份恢复和 4 项版本身份检查；两份集合在实际备份、恢复和重载后逐字段一致，同 EXE 真正退出重启通过。完整复核运行 [39036911453](https://github.com/Longyuyeee/Long_MarkDownReader/actions/runs/39036911453)；详细边界与原始证据见[发布审计](https://github.com/Longyuyeee/Long_MarkDownReader/blob/main/docs/V1_1_10_Unsigned_Community_Release_Audit_2026-10-17.md)。
