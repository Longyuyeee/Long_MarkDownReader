用户于 2026-10-14 确认按顺序推进现有基础功能。功能按使用场景放置：文件操作进右键，配置和选择进弹窗，低频操作归入有名称的菜单；不在主页面堆叠表单、说明卡片或新常驻区域。

公开版本为 1.1.2；文件管理第一批和侧栏精简已正式交付，源码与发布记录已合并主分支。下一开发目标为 1.1.3，自定义模板已在开发分支实现，后续接续多文档操作。

## 第一批：文件管理

- 文件右键直接显示移动到、复制到、创建副本、剪切、复制、粘贴和移到回收站。单击打开一份文件，Ctrl/Shift 多选保留当前正文；多选使用同一菜单。右键未选中的项目只针对该项，不误处理之前的多选。
- 目录选择与手动输入路径放在弹窗；新目录会创建，同名项目保留两份，`.table.json` 等复合扩展名保持。失败项目与成功项目分别反馈，重试不再次复制成功项。
- 移动与撤销同步已打开标签、路径、收藏、最近访问和文件显示样式；复制继承独立样式。目标目录按需加载、展开并选中结果；复制后保留当前编辑文档。
- 回收站通过文件栏空白处右键、项目右键“更多操作”打开。列表使用弹窗，选择恢复或永久删除；原位置重名时保留回收内容、提示先移开同名项。回收站存储于当前资料库 `.longedit/trash`，整体搬迁资料库时可随库保留。
- 回收保留历史和原路径的手动关系、样式，不自动删除 Markdown 引用的共享图片。恢复回原位置后原关系继续有效。永久删除菜单原有能力保留在“更多操作”，回收站永久删除需独立确认。
- 剪贴板为应用内当前资料库的文件剪贴板；“撤销上次移动”记住本次应用会话的最近一次成功移动，包含原有拖动移动。跨库剪贴板和持久化操作历史未在本批实施。
- 文件栏聚焦时使用 Ctrl+C/X/V、F2、Del；正文中的 Delete 不再误删侧栏选中文件。普通 Del 进入回收站，Shift+Del 沿用永久删除。正在保存或移动的项目保持相应操作互斥。
- 低频项归组，菜单限高、短窗可滚动；关闭右键菜单后卸载实例，避免已移除的菜单项仍被子菜单用作定位锚点。打开动画和弹窗动效继续沿用现有设置。

## 本批验证

实际组件页面流程 **8 组、12 组布局** 通过：[结果](evidence/v112-file-management/results.json)，覆盖副本、移动/撤销、新路径、失败重试、剪切粘贴、编辑区 Delete、回收/恢复、多选和永久删除；六种风格与宽窄布局。另 [3 项真实输入手势](evidence/v112-file-management/selection-gestures.json) 验证 Shift 范围选择、单击打开及 Ctrl+C/V。浏览器原生 IPC 使用独立夹具，原生文件系统另测，不当作新安装包结果。

原拖动六组流程通过：[回归结果](evidence/v112-file-management/drag-regression/results.json)。文件样式五项规则、原文件树菜单、主题与字体检查通过。原生新六项文件系统测试全部通过，覆盖复合扩展名、源文件保留、重名、多级目录、目录复制、回收重开/冲突、关系接续与回收项永久删除。最终 `npm run build` 通过类型检查与生产打包（35.03 秒）；没有制作新安装器或替换用户正在使用的程序。

实现：`LibraryFileOperations.vue` 使用按需弹窗；`libraryFileOperations.ts` 保存应用内剪贴板和本会话撤销；Rust `commands/file_management.rs` 实际执行复制、移动、回收和恢复，不使用页面模拟写盘。

## 第二批：自定义笔记模板（2026-10-15）

已实现于 `codex/custom-note-templates`，详见 [使用与接续记录](V1_1_3_Note_Templates_2026-10-15.md)。新建菜单选择模板或打开管理弹窗；当前 Markdown 笔记可从文档操作菜单保存为模板，包含尚未保存的编辑内容。支持新增、编辑、删除、内置模板另存、自定义默认模板、标题/日期/时间变量与快速笔记复用。主页面不增加常驻表单或说明区域。

实际 Vue 页面 7 组流程、六风格 12 组弹窗布局、新 4 项原生测试、原配置 9 项与管理备份 5 项回归通过；类型检查、生产构建与主题检查通过。此处是开发完成记录，不代表 1.1.3 已制作安装包或发布。

下一步先深化多文档操作：标签右键固定/关闭其他/恢复关闭、拖动排序和阅读位置接续。实施前核对现有能力，补齐缺口，不重复制作已有功能。另记录 760px 主工作区在切回资料库后出现新建按钮被编辑工具栏遮挡的情况，随多文档布局一并排查；本批弹窗在该宽度下的布局验证已通过。
