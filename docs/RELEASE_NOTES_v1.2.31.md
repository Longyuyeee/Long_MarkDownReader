# v1.2.31：YAML 字段上移／下移

普通字段右键“上移”“下移”，直接预览差异，不增加填写步骤或常驻按钮。确认后只应用到当前草稿，保持字段选择和高亮，一次撤销／重做，显式保存才写入文件；第一个／最后一个字段对应方向禁用，筛选结构时仍按完整同级顺序调整。

先支持同一普通映射内相邻单行标量字段，保留字段名、原值、引号、数字写法、冒号空白、缩进及明确行尾注释，独立注释保留原位，BOM 与换行不变；块式和无含糊注释的流式映射均可使用。复杂集合、多行值、引用／标签／合并、多文档、紧凑缩进或注释归属不明时局部说明并定位源码，保留草稿。

保护未保存内容、后续输入、延迟结果、旧差异、文件切换、保存失败重试及外部冲突完整副本。保留全部既有功能、风格和正常动效。
