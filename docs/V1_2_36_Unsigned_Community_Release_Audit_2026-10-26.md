# v1.2.36：YAML 段落文字编辑

当前开发目标：`1.2.36`；当前运行时版本：`1.2.36`；当前公开版本：`1.2.35`。当前阶段：**v1.2.36 YAML 段落文字编辑候选**。

## 用户变化

已有普通 YAML `>`、`>-`、`>+` 字段沿右键“修改值…”直接编辑可读段落，预填真实折叠后的正文，无需手动维护块标记、缩进和折行。修改仍保留 `>` 形式；空段落、额外缩进、尾部空格与结尾换行按文字语义处理，必要的换行标记变化在已有差异中呈现。

保留其他字段、注释、BOM 与原换行格式；无变化时完整保留原有物理折行。普通字段、引号键、嵌套与列表映射字段按解析器确认的范围修改，不整体序列化文档。锚点、标签、合并键、复杂键、多文档、根块及无法确认归属或表达的格式继续定位源码，局部提示并保留输入；既有 `|` 多行文字和普通值编辑保持可用。

复用现有弹窗与差异，确认后只改草稿，一次撤销／重做，显式保存才写盘。继续保护预填失败、延迟结果、后续输入、旧差异、文件切换、保存失败重试和外部冲突完整副本。保留全部功能、风格和正常动效，不新增常驻表单。
