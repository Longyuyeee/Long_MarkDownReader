# 手机端资料入口、最近与根导航

本轮按阶段 2A 只推进“回到手机后，在当前资料库找到上次读过的资料；阅读、搜索或查看设置后继续原来的浏览”。沿用移动工作目录和分支，未修改桌面目录、原生存储协议或文档格式引擎。

## 实际观察与竞品依据

[改前实页采集](evidence/mobile-library-root-2026-10-27/before/report.json) 确认五个问题：底栏有四项；继续阅读指向另一资料库；接收横幅占用资料页；最近是独立根入口；同名最近记录没有相对路径。`captureCompleted` 表示观察完成，缺陷字段 `true` 不是功能通过。

| 官方资料 | 可以确认的行为 | 本项目采用的判断 |
| --- | --- | --- |
| [Notion 移动工作区](https://www.notion.com/help/workspaces-on-mobile) | 移动底栏有稳定的工作区、搜索、收件和创建入口；工作区名称位于顶部并可切换。 | 根导航承担稳定目的地；资料库位于资料页顶部，接收使用稳定按钮和徽标。三个目的地是本项目选择，不是照搬其底栏。 |
| [Obsidian 手机端](https://obsidian.md/help/mobile)、[Quick switcher](https://obsidian.md/help/plugins/quick-switcher) | 手机端可从导航进入找笔记；快速切换器可按名称找笔记，空词显示最近笔记。 | 让按名称查找和最近容易到达；把最近作为资料的一种查看方式。限定当前资料库是本项目的范围一致性决定。 |
| [Material Android 导航栏](https://github.com/material-components/material-components-android/blob/master/docs/components/BottomNavigation.md) | 小屏导航栏承载3–5个目的地，使用图标和文字，也可有徽标。 | 选择资料、搜索、设置三个主目的地；全部/最近是资料页内分段，不增加第四个根入口。 |

调研为官方文档复核，未安装、运行或录制竞品；未引入账户、同步、订阅或竞品专有功能。

## 正式行为

- 底栏收敛为资料、搜索、设置。全部和最近都选中“资料”；再次点资料或品牌不会清掉当前视图和筛选。
- 全部保留当前文件夹、名称筛选、展开批次、滚动和焦点。最近保留自己的名称筛选和位置；进入搜索、设置再回来，恢复最后使用的资料视图。
- 继续阅读和最近限定当前资料库，最近条目显示相对路径。根目录条目标为“资料库根目录”，移除重复文件名；其他资料库的身份仍保留在设备历史中，切换库即可查看。
- 设备仍保留最近12条打开身份，不迁移或改写既有记录格式，不清除其他库的记录。最近按实际打开顺序更新；返回会定位对应身份，条目移动时不承诺旧坐标完全不动。
- 从最近新建，去向明确为当前资料库的根目录，名称页显示位置。即使全部视图停在旧文件夹，也检查根目录重名；失败保留名称，成功后回最近能看到新笔记。
- 资料、搜索、设置的根页共用收件按钮和数量徽标。接收事件不展开页面、不挪动资料内容，也不抢名称查找的焦点。阅读/编辑中的旧接收提醒本轮保留，后续阅读页迁移处理。
- 最近读取失败保留上次完整列表，成功重试只清除它自己的错误。范围、历史预算和新建规则收进问号，没有新增常驻教程。

内部继续复用原有 `recent` 视图键；根导航实际只有三项。`peek` 只读隐藏文件夹的元数据，不将它提升为最后访问视图，避免搜索/设置切换意外选回全部。视图记录仍受128项内存上限约束，文件内容和草稿继续由原会话管理。

实测修复了收件可访问名称遗漏数字、浏览器默认蓝色点按高亮，以及分段容器48px但按钮只有40px的问题。分段维持40px视觉区域，真实按钮扩为48 CSS px，并以边缘触摸验证：[改前目标](evidence/mobile-library-root-2026-10-27/touch-target-before.json)、[改后边缘点按](evidence/mobile-library-root-2026-10-27/touch-target-after.json)。键盘焦点轮廓仍保留。

实页沿用“文件夹优先、按名称”的排序，与静态示例顺序不同；最近根目录说明替换了设计中的重复名称；从阅读返回的文件夹条目保留焦点底色。实际父目录返回文字保持同一行，避免了静态参考中的断行；现有SVG图标、字重和阴影仍有细微差异，不宣称所有像素完全相同。

## 验证与后续

本轮构建通过，291项逻辑测试、52组浏览器任务通过；所列无障碍专项共25次扫描未检出违规。axe 对分段伪元素背景有一项无法判定，对实际前景/背景补测为浅色5.38:1、深色7.90:1，均超过普通文字AA的4.5:1，见 [颜色补测](evidence/mobile-library-root-2026-10-27/segmented-contrast.json)。这些结果不等于原生读屏通过。

结果、构建及源码摘要见 [验证清单](evidence/mobile-library-root-2026-10-27/verification.json)。验证覆盖同名文件选择、跨库范围、独立筛选、搜索/设置返回、新建重名及根目录去向、170项列表展开与返回、旧历史加载、接收事件焦点、读取失败重试、320px/200%文字/深色/短屏及自动无障碍检查。原文件、既有草稿与接收记录均按身份核对。

浏览器用例按新的根导航名称调整入口，保留存储与内容断言；宽泛的“笔记19.md”按钮定位改为实际文件行，避免与继续阅读入口混淆。失败候选与未通过的初次采集保留，不把它们计为成功。

本轮未启动模拟器、未生成APK，也未验证Android真实键盘、系统返回、TalkBack、实体机或iOS。CSS像素与真实设备dp仍需原生验收；浏览器任务通过不替代这些出口。
