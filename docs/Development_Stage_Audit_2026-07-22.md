# 开发阶段审计（2026-07-22）

审计基线：`main` / `e3f5c20`（S8-2A Excel Table 结构编辑）

## 1. 当前结论

项目已经越过“基础工作台搭建”阶段，进入以 XLSX 渐进式编辑为主线的专业能力扩展期。知识库、图谱、索引、专业工作台、主题预设、开放 Table、OPML、Canvas、PDF 批注和 Mermaid 均已有可用闭环；当前主要未收口目标是完整 Excel 等价编辑，以及少量平台级 E2E 和视觉回归门禁。

当前公开口径仍必须是 **“XLSX 渐进式编辑，以兼容性矩阵为准”**。S8-2A 已把 Excel Table 编辑从“计划”升级为“受限”，但不能据此宣称完整 Excel 等价。

## 2. 已完成开发

## 6. Excel 等价后续主阶段

从当前基线到完整 Excel 等价目标，按风险和依赖关系仍有 7 个主阶段：

1. **S8-3 规则与名称编辑**：命名区域增删改、公式/自定义数据验证、条件格式执行与规则编辑。
2. **S8-4 图表与绘图编辑**：创建、移动、缩放、系列/轴/标题/样式编辑及可验证渲染。
3. **S8-5 页面与保护编辑**：打印区域、页面设置、页眉页脚；保护操作只在明确凭据和安全模型下开放。
4. **S8-6 公式语义扩展**：扩大 Excel 函数覆盖，补齐易失函数、数组公式和动态数组溢出语义。
5. **S8-7 高级数据对象**：透视表、切片器、外部链接和数据连接按“可编辑、可刷新或明确保真”分别验收，不隐式访问外部资源。
6. **S8-8 等价发布审计**：复杂真实工作簿差异、性能、故障恢复、桌面 E2E、视觉矩阵和公开兼容声明逐项收口。

每个主阶段仍可拆分为多个可推送批次。只有 S8-8 的公开矩阵、真实 fixture 和发布声明全部达到目标，才可以重新评估“完整 Excel 等价”的产品表述。
