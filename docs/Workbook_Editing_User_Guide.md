# XLSX 日常操作说明

本文对应 v1.1.16 候选的实际界面；正式发布状态以 [发布审计](V1_1_16_Unsigned_Community_Release_Audit_2026-10-18.md) 和 README 下载区为准。它补充日常操作，不替代 [XLSX 公开兼容性矩阵](XLSX_Public_Compatibility_Matrix.md) 与 [发布兼容声明](XLSX_Release_Compatibility_Statement.md)。

## 选中、复制与粘贴

从资料库打开 `.xlsx`，点击单元格后使用网格和公式栏。拖动选择连续区域；在筛选输入框、公式栏等文字控件里，删除和复制/粘贴操作属于该输入框，不会顺带清空所选网格。再次点击网格后，方向键继续移动单元格。

- **Ctrl+C / Ctrl+V**：复制当前选区，在目标左上角粘贴。支持带制表符、引号、换行及空尾格的文本字段。应用内复制还附带受限类型信息，区分普通文本与真实公式，不携带来源文件路径。
- **更多 → 粘贴文本（自动识别）**：沿用纯文本输入语义。`00124`、超出可靠精度的长数字作为文本；常规数字作为数字；以 `=` 开头的输入按公式解释。需要保留应用内“等号开头的普通文本”类型时，使用 Ctrl+V。
- **Ctrl+X / Ctrl+V**：剪切移动公式时保持原引用；复制公式才按目标位置平移相对引用。剪切清空和目标粘贴分别保留撤销记录。剪贴板操作未完成时若继续编辑或切换目标，会拒绝清除旧选区或应用过期结果。
- **Ctrl+Z / Ctrl+Y**：整批粘贴或填充可以一次撤销、重做。剪切移动需分别撤销粘贴和清空两个步骤。

外部软件的纯文本剪贴板没有 LongEdit 的类型记录；其他软件也可能自行解释从这里复制的编号或等号文本，请检查其导入方式。粘贴不是完整的 Excel 样式/对象复制。

## 只复制筛选后的结果

1. 打开工具菜单中的“数据、Table 与规则”。选择筛选字段，在“包含筛选”里输入文字；需要时选择排序字段与方向。
2. 查看“会话结果”数量，使用“上一条 / 下一条”跳到原网格中的对应行。
3. 点击“复制筛选结果”。剪贴板包含表头和匹配行，并采用当前会话排序；不混入未匹配行，不重排原工作表，不改变当前选区或草稿。

这是会话中的查找/结果复制，不是把原生工作表的行隐藏或自动改写。最多分析前 50,000 数据行，界面会提示范围；超出复制预算时需要缩小筛选范围，不会悄悄只复制一部分。Ctrl+C 仍复制当前选区，不自动改成复制筛选结果。

## 填充与保存

选择数字种子后拖动填充柄，可继续可靠的数字序列，例如 `0.1、0.2` 后接 `0.3`。文本编号不当数字序列，真实公式按目标相对位置平移。日期、错误等不支持填充的类型会明确拒绝；不能把本轮改进当作完整公式引擎或任意复杂对象写回。

修改先留在草稿中，最后点击“保存”或 Ctrl+S 才写回文件。操作超限、目标未加载、类型不支持或状态过期时，整批拒绝，不只写入前半部分；保存失败时保留草稿供核对和重试。复制筛选结果本身不会触发保存。

当前相关预算为每批 10,000 格、工作面前 256 列、文本和类型记录各 10 MiB、单格 32,767 字符、公式 8,192 字符。工作表、已有格式/图表/页面工具和原有受保护写回边界均继续保留。
