# Long编辑 v1.2.12：XML 文字编辑

打开 XML 的“元素与问题”，在结构提纲中右键目标元素，选择“修改文字…”。弹窗显示可读原文，预览后只修改当前文字，保留其他节点、属性、注释和排版。

支持普通文字、CDATA 与成对空元素；特殊符号自动转义，CDATA 中的 `]]>` 自动处理，空值和有意空白保留。复杂混合内容提供源码定位，错误可原地纠正，不增加常驻表单。

沿现有独立撤销、草稿接续、保存失败重试和冲突副本保护未保存内容；保留全部现有功能、风格和正常动效。

未签名 Windows 社区版，完整发布检查与 491 项安装版功能任务通过，NSIS、MSI 与 `SHA256SUMS.txt` 三份公开附件已重新下载核对通过。应用内自动更新实际观察仍待完成，与手动安装升级分别记录。
