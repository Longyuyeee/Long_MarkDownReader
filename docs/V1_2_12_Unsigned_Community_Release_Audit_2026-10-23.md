# v1.2.12：XML 叶节点文字编辑

当前开发目标：`1.2.12`；当前运行时版本：`1.2.12`；当前公开版本：`1.2.11`。当前阶段：**v1.2.12 XML 叶节点文字编辑候选**。

## 用户操作与范围

打开 XML 的“元素与问题”，在结构提纲中右键元素选择“修改文字…”。弹窗预填并选中当前可读文字，预览后应用到草稿；不增加常驻表单。已有属性修改、源码操作、全部风格和正常动效保留。

支持无子元素的连续普通文字、连续 CDATA 文字块及成对空元素。普通文字自动转义并保留有意空白；CDATA 的 `]]>` 自动拆分为相邻段，重新打开仍可连续编辑。只替换当前准确范围，保留其他节点、属性、注释、处理指令、换行及长数字。相邻注释或处理指令不参与替换；被它们隔成多段的文字、混合内容、子元素、自闭合标签、未知实体及不支持字符保留源码入口，局部解释并定位。

沿现有差异预览、独立撤销和显式保存接续草稿。输入错误保留在弹窗中纠正；来源切换关闭旧菜单、参数和差异，过期结果不覆盖后续输入。失败重试、外部冲突与副本继续使用现有保护。CDATA 中会被 XML 规范化的特殊换行字符留在弹窗纠正，不静默改变输入。
