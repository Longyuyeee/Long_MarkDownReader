# 阶段 1B：核对附件包导出记录后继续原任务

本轮在手机分支 `codex/mobile-0.1.0-foundation` 推进一个完整任务：**从当前笔记准备导出，查看清单或保留记录，再回到原导出；取消、失败与重试都保留当前工作。** 阶段 1B 仍在进行，桌面工作目录未改动。

## 实际观察与任务设计

在修改前的生产构建中复现：进入导出记录会清空当前导出预览；记录里的移除确认按返回，会关闭整个面板。[修改前报告](evidence/mobile-export-continuity-2026-10-26/before/report.json) 两个缺陷字段均为 `true`，其中 `passed` 仅表示采集成功。

| 用户当前任务 | 现在的界面与返回结果 |
| --- | --- |
| 导出当前笔记和附件 | 完整二级任务页，显示文件身份、附件数量、未保存状态与主要导出动作。原笔记和草稿保持原状态。 |
| 看一下将携带哪些文件 | 独立附件清单；返回原预览，恢复原位置和清单入口焦点。 |
| 找到之前保留的附件包 | 记录列表每项只有一个详情入口。日期、附件数与体积帮助辨认，重试和移除进入详情后再显示。 |
| 核对一条记录 | 详情显示这一份包的清单；返回列表时恢复选中的记录、非零滚动位置与焦点。 |
| 暂时不移除 | 确认框覆盖真实详情，默认聚焦“继续保留”。Back、Esc、蒙层或保留只取消确认。 |
| 移除没有成功 | 保留确认框、完整记录和错误，允许安全取消或重试；错误属于当前步骤。 |
| 文件核对或导出失败 | 保留记录身份与原任务。损坏清单不显示为空清单，重新核对通过后才启用导出。 |
| 系统操作还在进行 | 返回与重复操作被消费；核对完成后继续同一任务。 |
| 从设置查看历史 | 记录根页返回设置入口；从当前导出进入历史，则先返回当前导出。 |

操作链为：笔记 → 导出预览 → 附件清单，或导出预览 → 导出记录 → 记录详情 → 移除确认。每次返回消费当前步骤；预览根部的返回才退出导出任务。顶部返回与已有 Android 返回桥共用处理。

删去了无附件时重复解释、检查成功后的套话以及列表里常驻的成组操作。格式、预算和携带范围仍由可点击问号提供。保留未保存提醒、真实结果、记录身份、损坏或失败原因及移除后果。

参考稿与实页仍有明确差异：参考数据估计 78 B，实际附件是 74 B，保护包是 854 B；记录页显示真实日期；浏览器动作是下载，Android 动作是选择位置；帮助使用现有问号和图标。草图记录页的徽标被通用 flex 规则拉宽，正式实现遵循 40px 基准并随大字号扩展，差异保留在对照图中。参考图和原有首页、阅读 AI 图均未重画，不声称字形、占位图标或示例数据逐像素一致。

实际核对发现并修正了三个问题：父面板焦点覆盖子页返回、底栏按钮卸载导致焦点无法恢复，以及清单按钮残留浏览器灰底造成深色对比度不足。另修正了字号、任务栏 1px 高度差和触屏点击的蓝色高亮。候选失败留在本机，精选 [对比度失败记录](evidence/mobile-export-continuity-2026-10-26/iterations/contrast-failure.json) 和截图随证据保存。

## 源码与验证

`PortableExport.vue` 保留同一份已核对导出数据，用明确的预览、清单、历史、详情步骤管理当前任务；各步骤分别保存结果和错误，底栏入口不因子页跳转卸载。`taskPosition.ts` 支持指定真实滚动容器，兼容固定底栏与极短视口。视口变化后，返回还会使选中记录标题进入可见区域，详情重新打开时复位实际滚动容器，防止被固定任务栏遮住。

`MobileConfirmation.vue` 把确认层挂在任务外，父任务保持显示并设为 inert；帮助仍在更上层。确认层包含可滚动后果、焦点循环、Esc/蒙层取消和忙碌保护。`MobileApp.vue` 接入返回能力和页标题，内部页切换的焦点由该任务恢复。未改动 TextPack 生成、存储、校验、原生桥或草稿协议。

原附件包回归按新的实际入口进入清单和详情，保留全部字节、草稿、损坏、容量和重试断言。文字导出回归中一处旧说明文案断言更新为现有未保存提醒，文件保护检查不变。没有重复运行未受影响的全部历史专项。

本地复现：构建移动版并启动静态预览，设置 `LONGEDIT_MOBILE_PREVIEW_URL`（本轮 `http://127.0.0.1:9012/mobile.html`）和需要的 `LONGEDIT_PLAYWRIGHT_MODULE`，运行新专项。`LONGEDIT_EXPORT_LAYERS_OUTPUT` 指定新采集目录。设计比较运行 `node scripts/render-mobile-export-comparison.mjs`，保留先行参考图；新设计版本使用独立的 `LONGEDIT_EXPORT_REVIEW_OUTPUT`。
