# P1-B4B PDF 隔离矢量文字水印后端审计

审计日期：2026-08-15
阶段状态：后端完成，原右侧工作区待接入

## 1. 需求对齐与阶段结论

本阶段继续服务“在统一管理器内阅读和基础编辑 PDF，并形成可靠、成体系的资料管理”目标。交付仅是资料库内 PDF 水印可靠副本后端，不新增路由、不打开独立界面，也不把水印宣称为脱敏、DRM 或防复制。用户入口继续关闭，待 P1-B4C 在初版左侧 Tab + 右侧编辑区结构内接入。

## 2. 已实现的安全子集

- 源文件限制为资料库内 `.pdf`、1～512 页、最大 128 MiB，输出最大 256 MiB。
- 首批只支持全部页面、单条居中斜向文字；文字 1～64 个 Unicode 字符，角度 -60～60 度、透明度 0.08～0.5、受限 DeviceGray。
- 文字使用内置 Noto Sans CJK SC 2.004 字体子集、Identity-H 与 ToUnicode，中文可显示且可提取。
- 自动字号由旋转后文字包围盒同时约束横轴和纵轴，限制 18～72 pt；无法安全放置时阻断。
- 加密、签名/认证、PDF-A 标记、异常页框、非 90 度倍数旋转、非 1 UserUnit、复杂塑形、Emoji、双向覆盖和控制字符保持阻断。

## 3. 隔离写入与保真

引擎完整载入源文档并执行非增量全量重写。每页解析继承的 CropBox、MediaBox、Rotate 与 Resources，把资源字典复制为页面私有字典，再分配不冲突的 Font/ExtGState 名称。水印作为最后一个内容流追加，使用平衡 `q/Q`、`/Artifact << /Subtype /Watermark >> BDC` / `EMC`、私有透明度和嵌入字体；不修改共享或继承资源对象。

预览输出绑定源 SHA-256 和输出 SHA-256。保存只允许同资料库内新 `.pdf` 目标，拒绝覆盖源文件和已有目标；落盘字节必须与预览完全一致，保存前后源摘要必须不变，失败的新目标会被清理。

## 4. 自动验证与视觉复核

Rust 测试覆盖中文水印、两页源文件、90 度旋转页、签名阻断、双向覆盖阻断、源文件不变、已有目标拒绝和源覆盖拒绝。生成结果重新载入并验证：

- 页数、顺序、MediaBox、CropBox 与 Rotate 不变；
- 表单、链接、批注、书签、附件、标签和元数据清单不变；
- 每页恰好一个带私有标记且边界平衡的水印流；
- 每页均可提取预期 Unicode 水印文字；
- Trailer 不含 `Prev` 或 `XRefStm`，确认不是增量追加旧修订。

Poppler 144 DPI 首次渲染发现按对角线估算字号会造成首尾轻微裁切，因此改为按旋转后的文字包围盒同时计算横纵最大字号。第二次渲染的两页中文水印完整、居中、透明且原正文未被遮蔽，视觉缺陷已归零。

## 5. 能力边界与后续顺序

当前命令已注册但没有 UI，因此公开能力仍为关闭。P1-B4C 将在原 `PdfView` 右侧工作区加入文字、角度、透明度、灰度、预览和可靠另存，并明确展示“可被移除、可搜索、不等同于脱敏”的提示。P1-B4D 再完成真实 Tauri 宽窄屏、保存复开和独立 Poppler/pypdf 证据。之后仍有 P1-B5 元数据副本和 P1 最终总收口，不能把 B4B 误报成全部 PDF 能力完成。
