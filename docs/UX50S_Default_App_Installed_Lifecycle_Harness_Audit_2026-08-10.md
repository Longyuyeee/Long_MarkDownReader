# UX50S 默认应用安装生命周期探针审计

日期：2026-08-10
阶段：EA-5B2A 完成

## 审计结论

- U2 可丢弃 Windows 生命周期现以 `C:\LongEdit EA5B 外部\冷启动 思维导图.opml` 启动首次安装态实例，WebView 探针必须观察到授权后的外部 OPML 工作区。
- 首实例运行期间，探针再次启动同一安装目录中的 LongEdit，并传入 `二次打开 记录.txt`；第二进程必须以成功状态退出，首实例必须切换到该外部 TXT 工作区。
- 探针在安装态“格式能力”页真实展开并点击 OPML 与图片两种代表格式，覆盖 `edit` 和 `preview` 两类策略。
- PowerShell 生命周期要求 `.opml/.png/.avif` 出现 `LongEdit.ExternalFile` 候选，未选择的 `.json` 不得出现该候选；ProgID 命令必须指向隔离安装目录。
- 候选准备前后都会比较 `.opml/.png` 的扩展名默认值与 Windows `UserChoice`，任何变化都会让任务失败。
- 静默卸载后必须移除候选值、ProgID、能力清单和 `RegisteredApplications` 入口，同时保持原默认值与 `UserChoice` 不变。
- 独立证据 JSON 和安装态截图已加入 R5K 证据包必需成员；测试仍拒绝在非 Windows Sandbox、非 GitHub 托管 runner或未明确标记的可丢弃虚拟机中执行。

## 需求对齐

- 每种格式由用户主动选择：通过真实“格式能力”按钮触发。
- 编辑和预览格式都可选择：以 OPML 和图片作为代表安装态覆盖，37 类/85 扩展名的完整边界继续由统一注册表契约锁定。
- 未选择格式不接管：以 JSON 反向验证。
- 外部打开适配完整工作区：冷启动 OPML 与二次打开 TXT 都要求 `external=1` 专用工作区。
- 不自动修改系统默认应用：安装前后比较默认值和 `UserChoice`。
- 卸载恢复：要求只移除 LongEdit 自有注册并生成独立证据。
