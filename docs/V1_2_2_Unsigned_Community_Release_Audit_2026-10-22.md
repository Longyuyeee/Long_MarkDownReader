# v1.2.2：PDF 批注撤销与重做

当前开发目标：`1.2.2`；当前运行时版本：`1.2.2`；当前公开版本：`1.2.1`。当前阶段：**v1.2.2 PDF 批注撤销重做候选**。

## 1. 审计结论

当前为开发候选，尚未发布。当前公开版本为 1.2.1。

## 2. 需求对齐

深化现有 PDF 批注；撤销、重做放入批注右键、每条批注菜单和面板菜单，按实际操作命名。连续评论合并撤回，评论输入框保留自己的文字撤销。保留所有功能、风格、正常动效与页面整理的独立撤销。

## 3. 当前开发状态

已实现新增、编辑评论、改色、删除的有界内存历史，最多 80 次且限制内容量。撤销恢复批注顺序及当前选择，随后沿原自动保存链落盘；不自动更新阅读笔记正文。切换 PDF、来源变化或重新读取时清空历史，不写入阅读位置或工作现场元数据。

新增原子读取批注及版本、保存前核对 PDF 来源和 sidecar 版本；冲突保留未保存评论及外部文件。普通保存失败可原地重试；重新读取需明确放弃当前批注修改。等待中的新增批注弹窗也核对来源，避免写入已切换的文件。

当前已通过 5 项历史模型测试、2 项原生保存回归及前端构建；浏览器 7 组用户任务通过，包含大小窗口和六种视觉风格。安装包中的实际操作检查尚未完成，结果后续据实补充。

## 4. 发布边界

`community-unsigned` 未签名社区安装包，企业 `releaseCandidate=false`；同一固定产品与同包复查、公开附件核对通过后才标记发布。发布后可手动下载安装。1.2.1→1.2.2 应用内更新实际观察独立 pending。保留旧版本全部未完成观察，不将手动安装升级当作应用内自动更新。

## 5. 接手后的顺序

完成必要回归与固定安装包检查，更新 README 和 Release。1.2.2 完成后，本轮两版路线结束；下一轮继续深化现有基础功能，先从实际任务缺口规划再实施，沿右键、菜单与弹窗，不增加常驻介绍与表单。
