# v1.1.2 社区版发布记录

状态：发布准备中。用户于 2026-10-15 授权升级版本、更新 README 和发布 Release；正式公开版暂为 v1.1.1，尚未将候选安装包当作已发布版本。

## 交付范围

本版包含文件右键移动/复制到、创建副本、应用内剪切/复制/粘贴、多选、撤销上次移动与资料库回收站；收集箱、集合、标签和关系面板精简。保留全部原有操作、43 类格式的能力边界、六种风格与动效设置。实现与已有功能验证见 [基础功能路线](Foundation_Features_Upgrade_Plan_2026-10-14.md) 和 [侧栏记录](V1_1_2_Compact_Sidebar_2026-10-14.md)。

## 发布进展

源码位于 [PR #50](https://github.com/Longyuyeee/Long_MarkDownReader/pull/50)。文件管理开发提交的 GitHub Quality Gate 已通过；当前统一提升到 1.1.2，候选质量检查、MSI/NSIS 构建、1.1.1 升级和新增原生文件操作检查将以固定源码运行。结果、安装包摘要和公开附件回下载核对在实际完成后补入。

## 验证与范围

已有实际组件功能流程、六风格布局和 Rust 临时文件系统回归通过，不冒充新安装包验证。剪贴板限当前资料库，撤销限当前会话最近一次成功移动；模板等路线后续项不在本版。

渠道为 community-unsigned；企业能力矩阵仍保持 releaseCandidate=false。本版继续保留“未知发布者”与 SHA-256 说明，可从官方 Release 手动下载安装。正式公网自动更新观察独立记录，安装器升级通过不替代官方自动更新观察。
