# C3B3 PPTX 对象分级渲染与真实缩略图审计

更新日期：2026-07-27

阶段判定：**C3B3 已完成；C3B 只读视觉实现已收口；C3 整体仍为部分完成**

## 1. 本批结论

本批完成 PPTX 连接线、自由形状、基础表格、复杂图形框架和缩略图的分级只读呈现。主画布、缩略导航与放映模式现在共用同一个对象内容组件，不再维护三套容易漂移的近似实现。PPTX 原件仍严格只读，没有新增保存、覆盖或外部内容执行命令。

已完成：

1. 识别 `cxnSp` 和线形几何，保留水平/垂直翻转、虚线类型、线头与线尾，并处理纯竖直连接线。
2. 将 `custGeom` 标记为自由形状；无法等价重建路径时使用明确的分级外观，不伪装成精确几何。
3. 解析基础 DrawingML 表格的列宽、行高、单元格文本、`gridSpan/rowSpan` 和水平/垂直续格；合并续格不会重复显示。
4. 按关系类型区分图表、SmartArt、视频、音频、一般媒体和嵌入对象，并显示类型化只读卡面及关联部件。
5. 缩略图直接消费 `slide.objects`、对象坐标、背景与内部媒体，不再用标题和纯文本生成近似缩略图。
6. 抽出 `PptxObjectContent.vue`，由主画布、缩略图和放映模式共同消费图片裁剪、连接线、表格、复杂对象与文本。
7. 更新兼容警告：基础表格不再被误报为占位；复杂图形框架明确说明为分级只读呈现且不执行外部内容。
8. 格式契约门禁新增 C3B3 解析字段、定向测试、共享渲染器和真实对象缩略图检查。
