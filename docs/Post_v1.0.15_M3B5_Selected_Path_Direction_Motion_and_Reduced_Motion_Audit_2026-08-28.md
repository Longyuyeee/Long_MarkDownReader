# v1.0.15 后 M3B-5 选中路径方向动效与减少动效审计

日期：2026-08-28

进入基线：`main` / `949ff2ae3ac5d5640cf44dc6ec1908d7c7d4dc24`

阶段：M3B-5

发布候选：否

## 1. 开发目标与进入事实

M3B-5 只补齐路线图 7.2 中“选中路径方向流动”和“尊重减少动效”。进入时 M3B-4 已提供确定性曲线、事实方向箭头、3 个静态标签、3 条路径证据和安全相机；图谱尚未读取应用或系统减少动效，窗口失焦也不会主动停止 RAF。

本阶段明确区分两种方向：箭头继续表达关系事实的 `source → target`，流动表达用户选择的路径 `start → end`。流动不得扩散到非路径关系，静态标签和证据不得依赖动画。缩略导航、聚类镜头、状态外环和 M3C 脏帧/大图性能继续延后。

## 2. 实现结果

- 新增纯函数方向合同，能够在同一路径中区分顺事实遍历、逆事实遍历和非路径边；流动虚线统一按用户选定的起点到终点推进。
- 普通动效仅在活动最短路径曲线上叠加克制的流动虚线；原关系色、线型、切线箭头和静态标签保持独立。
- `calm`、`swift`、`expressive` 使用有界速度，长时间失焦后的单帧增量限制为 100ms，避免恢复时跳变；无有效时间增量时保留当前相位。
- 应用设置为 `reduced` 或系统 `prefers-reduced-motion: reduce` 时，相位和流动帧计数保持为 0，Canvas 仍绘制完整静态路径、标签和证据。
- 页面隐藏或窗口失焦时取消图谱 RAF；重新可见并聚焦后恢复。组件卸载时同时清理 RAF、媒体查询、失焦/聚焦和可见性监听。

## 3. 预期—实际差异与修正

| 检查点 | 预期 | 首轮实际 | 修正与最终结果 |
| --- | --- | --- | --- |
| 普通动效 | 相位、帧数和 Canvas 像素均变化 | 三主题宽窄屏均变化 | 保持实现；人工截图确认流动层没有盖住标签 |
| 减少动效 | 相位、帧数和 Canvas 像素均不变化 | 三主题宽窄屏均静止 | 保持实现；静态 3 标签和 3 条证据仍完整 |
| 路径方向 | 真实路径同时验证顺向和逆向事实边 | 首轮只记录“3 段”，无法证明方向构成 | 增加顺/逆计数；最终固定为 1 段顺向、2 段逆向，均按 `NorthStar → Evidence` 流动 |
| 恢复语义 | reduced 恢复后应明确记录仍静止 | 首轮字段用 `framesAdvanced=true` 表示“仍为 0”，名称与事实相反 | 改为 `framesAdvanced=false`、`framesStable=true` 并重跑全部证据 |
| 零时间增量 | 普通动效相位不应无故归零 | 代码预检发现 `elapsed<=0` 会返回 0 | 改为保留当前相位；reduced 仍强制为 0 |

所有修正后均重新执行完整三主题、双动效模式真实 Tauri 矩阵，没有删除失败检查或放宽目标。

## 4. 真实桌面结果

真实隔离资料库仍为 17 节点/17 边，活动 `NorthStar → Evidence` 路径为 4 节点/3 边、3 个静态标签和 3 条完整证据。路径包含 1 段顺事实方向、2 段逆事实方向，验证了流动方向和事实箭头方向可以独立表达。

暗色、浅色、高对比主题分别以 `calm` 和 `reduced` 启动真实 Tauri，共 6 个隔离会话；每个会话在 `1280×800` 和 `720×680` 对同一 Canvas 做 320ms 前后像素对照。普通模式相位、帧数和像素全部变化；减少动效模式全部不变。普通模式失焦后帧数稳定、状态为 `paused`，恢复后继续推进；reduced 全程保持静止。

6 个会话运行时错误均为 0，资料库审计前后 SHA-256 一致，路径相机/面板仍安全，并全部成功返回资料库。证据位于 `docs/evidence/post-v115-m3b5-selected-path-direction-motion-reduced-motion/`，不含用户内容。

## 5. 阶段审计与接续

M3B-5 的目标已完成，但整个 M3B、M3C 和 v1.0.16 均未完成。普通聚焦状态下图谱仍持续 RAF；本阶段只保证无活动页面、失焦和减少动效路径流动的边界，不宣称完成 M3C 脏帧或大图 CPU 收口。

下一接续点冻结为 **M3B-6 导航与镜头系统选择审计**。应先对真实代码和当前画面审计缩略导航、适应选择、平滑聚焦、聚类展开/折叠和全屏的缺口，再选择最小实现；不得直接堆叠全部导航控件。
