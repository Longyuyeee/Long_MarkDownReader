# v1.0.10 无签名社区版发布审计

状态：**版本事实源已冻结，等待 Quality Gate 与安装包证据**

渠道：`community-unsigned`

## 发布范围

- 仅发布 UX-52 应用内默认打开管理增量。
- 37 类外部格式可逐项启用、关闭并读取真实默认状态。
- Windows `UserChoice` 只读不写，最终默认选择继续由系统确认。
- v1.0.9 的自动更新、独立外部窗口、格式能力和安全保存边界全部继承。

## 发布顺序

1. 提交 `1.0.10` 版本事实源并通过完整 Quality Gate。
2. 从冻结提交构建无签名 EXE、MSI 与 NSIS，记录版本、大小和 SHA-256。
3. 在隔离 Windows 执行安装生命周期与默认应用启用、关闭、状态回读。
4. 发布 GitHub Release，重新下载并复核 MSI、NSIS 与 `SHA256SUMS.txt`。
5. 单独验证官方 `v1.0.9 -> v1.0.10` 应用内更新链。

## 发布边界

- 当前公开稳定版本仍为 v1.0.9；在 GitHub Release 真正公开前，README 不切换下载链接。
- 安装包无 Authenticode 商业签名，必须保留未知发布者、官方来源和 SHA-256 提示。
- v1.0.4 及更早版本仍需手动下载安装受控更新版本一次。
- 无签名社区版与企业签名候选分离，企业候选继续保持 `releaseCandidate=false`。
- 不能把候选构建、源码质量门或历史 v1.0.9 证据描述为 v1.0.10 已发布证据。
