# 1.1.28 引用来源与关系核对

当前开发目标：`1.1.28`；当前运行时版本：`1.1.28`；当前公开版本：`1.1.27`。当前阶段：**v1.1.28 引用来源与关系核对候选**。

## 1. 审计结论

参考面板的具名菜单与手动关系菜单打开同一核对弹窗。区分文件缺失、不可读和位置无法确认；选择新文件后预览，保留能核对的页码、批注和文字锚点，也可明确只关联文件。手动关系只改变选定端点，保留身份、方向、类型和说明；关系或新来源在预览后变化时拒绝覆盖。

失效的文内来源/PDF 链接沿用草稿内修复，替换只处理可准确识别的 Markdown 链接目标，不改代码、围栏和普通文字。原始草稿绑定文件、编辑器和内容快照；修改后可撤销、需手动保存。修复未保存内容不写入磁盘，不代存其他文档。

开发中；版本身份已切为候选。发布构建、实际安装复核与公开附件核对尚未完成，当前下载保持 1.1.27。企业 releaseCandidate=false，社区 community-unsigned 包仍为未签名手动下载安装，27→28 应用内更新观察独立待补。

## 2. 需求对齐

入口位于具名菜单和按需弹窗，不新增常驻表单。沿用既有移动/改名接续、参考阅读、图谱和草稿保护；不把已交付能力重新列为新功能。

## 3. 当前开发状态

核心候选已实现。类型检查、14 项原生相关修复测试、21 项来源/预览及安装约束测试通过；实际 Vue 页面 9 项交互检查通过，六种风格已截图。页面使用 mock IPC，不能代替真实安装验证。完整发布质量检查已分段通过（含原生编译与生产依赖 0 漏洞）；原始中止与续跑日志保留。初包在真实安装中发现一次撤销被延迟历史消耗的问题，尚未发布。已改为原位更新链接，最终 9 项页面与 5 项预览同步/延迟历史/三模式回滚检查通过（均为 mock IPC），正在重新固定产品构建新包；旧包和全部失败记录保留。

## 4. 发布边界

当前公开版本仍为 1.1.27。位置不明确时保持原记录，或由用户明确取消定位后仅关联文件；较大 PDF/不可解析格式不虚报定位已修复。源码链接修复范围为 2 MiB 以内、能准确定位目标的当前 Markdown 草稿，不静默跨笔记批量改写。

## 5. 接手后的顺序

完成页面交互、原生原文与关系冲突检查，固定产品后构建双安装包，同包安装复核，再更新 README、Release 和下一版计划。
