# v1.2.35：TOML 多行文字编辑

TOML 三单引号多行文字字段现在可右键“修改值…”，直接编辑预填的正文，无需维护引号。保留开头换行形式、注释和其他字段，支持嵌套及可确认归属的字段。

确认前展示差异，只修改草稿，一次撤销／重做，显式保存才写盘。输入无法沿用当前格式时局部提示并保留文字，可转到源码继续；普通值、日期时间和数组项操作继续保留。

继续保护未保存内容、迟到结果、旧差异、文件切换、保存失败重试和外部冲突完整副本。保留全部既有功能、风格和正常动效。
