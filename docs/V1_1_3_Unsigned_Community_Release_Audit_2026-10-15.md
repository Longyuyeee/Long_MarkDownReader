# v1.1.3 基础功能深化发布记录

当前为候选准备阶段，公开版仍为 1.1.2。范围包含自定义模板、多文档操作、标签与集合、手动关系维护、TXT 历史，以及窄窗口入口遮挡修复。

延续 community-unsigned 社区正式发布方式，`releaseCandidate=false`。发布后的 Windows MSI/NSIS 支持手动下载安装；正式应用内自动更新观察独立记录，不以安装器覆盖升级替代。

功能已实现并完成本地验证：模板 7 组流程/12 组弹窗布局、基础功能 7 组流程/12 组实际入口操作、699 项 Rust 功能测试、1 项独立性能回归（5 项历史忽略）通过。生产构建、主题、界面、文件路由、版本身份及开发状态检查通过。固定安装包构建与安装检查完成后，在本文件记录实际结果，再更新 README 和公开 Release。没有把浏览器模拟 IPC 当作实际安装结果。

下一步完成针对性流程，冻结产品源码，构建 Windows MSI/NSIS，核对安装后的新功能并发布相同安装包。版本身份及公共附件以发布完成后的记录为准。
