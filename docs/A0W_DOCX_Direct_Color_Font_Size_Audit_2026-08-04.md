# A0W DOCX 字色与字号编辑审计

日期：2026-08-04  
需求：UX-33F 安全对象与格式扩展  
结论：直接 RGB 字色和受限字号已进入可靠编辑链路，UX-33 保持“进行中”。

## 风险选择

当前可靠事务只允许 `word/document.xml` 变化。页眉页脚、批注、脚注、域和部分超链接涉及独立部件或关系，尚未具备跨部件差异白名单与回滚证明，因此本阶段不开放这些对象。

本阶段选择安全单运行的直接格式，因为目标身份、字节范围和语义复读均已由现有字符格式内核建立，可在不扩大 OOXML 部件写入范围的前提下增加用户可见能力。

## 本阶段完成

- `editableStyleTargets` 增加直接 RGB 字色和 OOXML 半磅字号状态。
- 支持添加、修改和清除 `w:color@w:val`，只接受 6 位 RGB；主题色、自动色和颜色变换保持只读。
- 支持添加、修改和清除 `w:sz@w:val`，用户入口限制为 8–72 磅。
- 样式摘要包含粗体、斜体、下划线、字色和字号，陈旧状态不能提交。
- 页面编辑器提供颜色色块、继承按钮和字号菜单；草稿即时显示，并进入整份撤销/重做与多目标清单。
- 单项和批量隔离验证、可靠覆盖、可靠另存均携带新增字段并复读最终语义。

## 安全边界

- 仍只开放单运行、单文本节点，运行属性只能来自白名单。
- 字体族、字符样式引用、主题色、复杂下划线、语言、上下标、突出显示和多运行富文本继续只读。
- 页眉页脚、批注、脚注、尾注、域、内容控件、浮动图片和嵌入对象继续只读。
- 所有编辑仍只驻留内存，必须由用户点击保存才写盘。
