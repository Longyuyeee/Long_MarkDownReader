# Long编辑 v1.1.8 · 搜索更完整，接着找不丢现场

本版继续深化已有资料库搜索和 `Ctrl+P` 命令面板：大资料库可接着查，结果来源和未查全状态更清楚，打开资料时仍保护正在写的内容。

## 找全资料，也看得懂结果

- 资料库搜索与命令面板按文件分组，支持继续加载，不再把旧的前 200 个命中当作全部结果；文件内的具体位置继续保留。
- 可按相关性或修改时间查找，跨资料库时逐库显示状态。离线或未查全的资料库不会被掩盖成“没有结果”。
- 大资料库分步准备，结果只在一致的视图中续载；资料变化或会话过期时，保留已看的结果，并在列表底部原位置提供重新搜索/重试。
- 返回搜索保留已加载深度，重新搜索准备时不把旧结果瞬间清空；真正的零结果仍清楚区分。

## 从结果回到正确位置

- 普通打开仍进入主编辑区，只有明确选择“在侧边参考”才打开只读参考，不替换当前正文。
- 保留 PDF 页码与批注、Word 正文块、PPT 对象与备注、表格工作表定位；同一文档连续定位也会响应新的目标。
- 跨资料库打开继续保护未保存草稿，不自动保存或丢弃；搜索、排序、恢复与参考不会改写源文件。

## 发布与兼容边界

未签名 `community-unsigned` 社区版，`releaseCandidate=false` 不代表企业签名 RC。Windows 可能提示“未知发布者”，请仅从本项目正式 GitHub Release 手动下载安装，并核对 SHA-256。应用内自动更新仍保留独立观察状态，不用覆盖安装验证冒充自动更新通过。

搜索有资源预算，不能承诺任意规模全部一次返回；跨库异常明确显示，不虚报完整总数。工作簿定位到工作表，不宣传为单元格级定位。支持打开/定点阅读不代表完整 Office 编辑等价。
