# M1D-A 大 JSON 渐进读取与流式搜索审计

日期：2026-08-27
开发目标：`1.0.16`
运行时与当前公开版本：`1.0.15`
结论：M1D-A 通过，下一步进入 M1D-B 视频逐帧与截图工具。

## 1. 开发目标

修复 JSON 工作区在真实 10 MiB 文件上长时间无响应、50 MiB 文件只能拒绝打开的问题。大文件不得进入全文 CodeMirror 和完整结构分析；小文件继续保持完整编辑、树形与显式保存。

## 2. 实现边界

- 打开 JSON 时先读取 512 KiB 首段；大于 4 MiB 自动进入渐进只读模式。
- 当前段支持上一段、下一段、字节位置和进度显示。
- 全文件搜索按 1 MiB 顺序读取，最多保留 100 条结果；结果可以跳转到命中数据块。
- 大文件关闭保存、树形和结构编辑，并解释原因；源文件始终不写回。
- 小于等于 4 MiB 的 JSON 继续使用完整分析和编辑路径。

## 4. 真实测试修正

第一次新审计脚本误用了端口 `14201`，而 E2E Tauri 固定访问 `14200`，WebView 得到连接拒绝；这是测试环境错误，修正后重新生成样本。

第二次测试发现搜索按 1 MiB 命中后仍用 512 KiB 跳转，关键词位于数据块后半段时只能跳到附近。产品逻辑已改为按命中搜索块加载 1 MiB，随后重新执行完整测试并通过。
