# v1.1.12 本地内容备份：代码接续审计

本页是下一既定版本的只读审计，不表示功能已实现。当前仍完成 v1.1.11 安装验收与发布，不把备份工作混入已固定的图谱产品。方向来自已确认的 [十三版路线](Foundation_Deepening_Roadmap_1_1_8_to_1_1_20_2026-10-17.md)，不是另起新模块或云平台。

## 实际代码与用户缺口

- `src-tauri/src/commands/backup.rs` 的管理备份只有固定五个 ZIP 条目：脱敏配置、三个合同和清单。包上限 16 MiB、单条目 4 MiB；导入校验摘要和允许清单，明确排除正文、缓存正文、凭据、绝对路径和外库内容。保留原语义，不把现有管理恢复宣传成文档恢复。
- `src/views/SettingsView.vue` 隐私页已明确说明不包含正文；恢复逐库重新映射并确认覆盖管理配置，当前模板保留。新内容备份需要独立、具名入口，不能给旧“导出”暗加用户正文或扩大旧 ZIP 白名单。
- `src-tauri/src/commands/history.rs` 历史位于应用缓存 `history_v2`，由源文件完整路径映射；`services/archive_history.rs` 已有协调、枚举和摘要逻辑。只拷贝资料库目录不能承诺带上历史，换根后也不能照搬旧路径键。必须明确选择、检查归属并重新绑定相对路径。
- `formats/pdf_annotations.rs` 的批注带源 PDF 名称、大小、修改时间和可选 fingerprint。正文、相对资源和批注应成组核对，不能只验证 ZIP 能解开。
- `services/workspace_guard.rs` 已有规范路径/越库拒绝（含符号链接）约束。内容清单、写入目标及解压仍要各自验证，不能依赖前端路径字符串或旧管理包的固定条目检查替代。

## 下一轮实施顺序

1. 样例盘点：Markdown 相对图片、PDF 批注、结构化文件、现有历史和模板；标明哪些是库内内容、哪些是应用管理元数据、哪些永不包含。先给导出/恢复示意，保留原管理功能。
2. 原生只读预检：用户选择范围，生成版本清单、相对路径、大小、SHA-256 与容量预算；处理重解析点、外链、同名/大小写碰撞、文件在读取期间改变。失败项有具体原因，不伪装完整备份。
3. 内容包可靠写入：仅写用户明确选的新路径，临时包完成并校验后发布；取消/空间不足不留“成功”包、不覆盖已有备份。无自动上传、无凭据和未保存草稿。
4. 恢复预检与默认新目录：拒绝路径穿越、绝对路径、重复/坏摘要、解压炸弹和未知必需版本；清楚展示可恢复、未包含、无法恢复项目。默认恢复到新目录，原资料和当前草稿不变。
5. 从真实恢复副本打开资料：验证图片引用、PDF 原页/批注和可选历史归属；坏包、断电/取消、目标冲突、空间不足均保留证据，不为验收放宽断言。
6. 完整现有能力回归、六风格与宽窄实际页面检查、固定版本/源码/安装包、真实输入/磁盘/重启与同包独立复核，通过才封板发布；更新摘要仍在 README 末尾。

范围判断：先完成可解释、可校验、不会覆盖原库的本地恢复闭环；多机同步、云端托管、自动调度和全盘备份均不在本版。具体支持边界需在实际样例和示意后写清，不先承诺任意外部链接或所有缓存都可迁移。
