# P2-A PDF 能力登记一致性审计

审计日期：2026-08-20

结论：通过。v1.0.11 的 PDF 实际能力、格式注册表和发布能力矩阵已重新对齐。

## 1. 目标与真实差异

预期：格式能力页应准确说明已经通过真实桌面与独立文件验证的 PDF 能力，并同时展示限制。

修正前实际结果：机器对比返回 `FAIL`，公开说明缺少“表单填写、永久脱敏、水印、文档属性”四项；同时仍错误显示“表单目前只读检查，填写副本尚未开放”。这与 P1-B2B3 至 P1-B5D 已冻结证据不一致。

## 2. 本步修正

- `shared/file-formats.json` 现在登记页面操作、安全表单子集、永久脱敏、文字水印和文档属性可靠副本。
- `shared/release-capability-matrix.json` 明确单行文本、复选框、单选组与单选 Choice 的开放边界，并继续阻断自由输入/多选 Choice、复杂按钮、XFA、签名、加密与主动内容。
- 永久脱敏明确说明输出为图片型副本，会失去文字搜索和交互能力。
- 新增 `check:p2a-pdf-capability-alignment`，防止后续实现与公开能力再次漂移。

## 3. 需求与安全对齐

- 用户看到的是实际可用能力，不再低估现有版本。
- PDF 仍为 `copy` 保存模式，源文件永不覆盖。
- 本步没有扩大 PDF 编辑范围，也没有改写历史发布证据。

## 4. 后续顺序

1. P2-B：补强图片基础编辑，优先加入可量化、可复开的色彩调整，同时保留源文件和隐私元数据清理边界。
2. P2-C：使用真实图片在 Rust 像素层、Tauri 桌面宽窄布局和另存复开三个层级对比预期与实际。
3. P2-D：根据真实验证结果更新总交接文档；外部 Office 生产者矩阵仍等待对应环境，不以合成结果冒充完成。
