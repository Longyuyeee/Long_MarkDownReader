# v1.0.26 参考写作闭环（用户调整后的范围）

2026-10-10，用户要求：完成参考写作的功能闭环后再发布下一版。此要求取代此前“交互修正冻结后直接进入打包”的安排；不再把摘录直插归入下一版。公开/运行版本仍为 v1.0.25，本轮不发布。

## 已实现的闭环

1. 搜索结果默认在主编辑区打开；显式选择“在侧边参考”才打开只读资料。
2. 在 Markdown 笔记中选定位置，再到参考中选文，点击“插入到 文件名”。使用 Vditor 的 Markdown 插入接口，保留插入前后的撤销边界；选区存在时在选区末尾插入，不覆盖选中文本。缺少有效位置、切换笔记或只读时不猜测插入点，不自动改动内容。
3. 摘录带来源链接。文本来源携带第一段非空选文的前 160 字作为查找锚点；PDF 保留页码和批注定位。匹配多个结果时沿用前后命中导航，找不到时明确提示；这不是唯一段落 ID，不承诺内容改写后仍能精确定位。旧链接仍可打开文件。
4. 参考有“刷新参考”，读取磁盘已保存内容，不修改当前草稿；刷新清空旧选文，失败不展示旧正文或保留可插入的旧摘录。
5. 点击失效来源，先校验文件可访问性；可编辑 Markdown 笔记可输入当前库内的新相对路径进行重新关联。验证新文件存在后，只替换当前笔记中完全相同的来源 URL；取消、无效路径、只读、期间切换笔记/库或正文变化均不改内容。
6. 重新关联后留在笔记中供核对和撤销，再次点击链接才打开新文件。关联只改草稿，必须显式保存；不会自动追踪重命名，更不会改写全库引用。

直接插入仅面向可编辑 Markdown 笔记；其他编辑器保留复制摘录及来源的降级入口。参考不是实时草稿镜像，也不是全文阅读器。不包含任意多栏、跨重启参考恢复或全库自动修复引用。

## 本轮验证事实

- 新进程 Tauri Debug + WebView2，使用生成资料库、隔离用户数据目录；测试结束只关闭脚本创建的进程。不操作用户资料库、不安装新版本、不改系统剪贴板。
- 22 项流程记录通过：主区打开、直接插入、一次撤销/重做、源段落查找、参考刷新、窄窗、IR/源码模式插入撤销、失效来源取消/重关联/撤销/重做、显式保存保留草稿、已修复链接打开移动后文件、失败刷新清理过期正文等。
- 32 项相关单元/组件回归通过，包括只读、无插入位置、目标变更、来源越界、迟到响应和真实 Vue 卸载后的搜索失效处理。
- 最终源码 `npm run ci:patch-release` 通过，包含生产构建、当前开发审计、Rust locked check 和生产依赖审计（0 漏洞）。本轮未修改 Rust 产品代码，不把此前 570 项 Rust 测试算作本轮重跑。
- 复现脚本：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run-v126-reference-loop.ps1`。机器报告绑定源码和 Debug 二进制 SHA-256。
- [机器报告](./evidence/v126-reference-loop/search-flow.json)、[宽窗](./evidence/v126-reference-loop/reference-wide.png)、[窄窗](./evidence/v126-reference-loop/reference-narrow.png)。画面已人工查看；截图未经修饰。

自动化边界：按钮通过 CDP 鼠标输入、输入/撤销通过键盘事件；选文 Range、路由场景准备、剪贴板载荷拦截属于自动化辅助。报告不是全手工验收，更不是安装包验收。

保留失败尝试 `attempt-save-toolbar-obscured.json`：重新关联提示覆盖工具栏时，自动化立即点击保存没有触发按钮。调整为等待提示消失后真实点击，再验证磁盘内容；没有删除显式保存断言。搜索恢复测试补充新 selectionchange 清理依赖，并把“必须是卸载钩子第一行”的静态检查改为检查钩子内容；卸载取消和迟到响应的行为测试原样保留。

另保留 `attempt-mode-control-obscured.json`：模式切换也会被短暂提示遮挡，最终脚本统一验证点击点确实属于目标控件才发出鼠标输入，超时仍报错。画面观察发现的跨文档链接浮层残留已在实际加载文档时清理，同时清除旧插入位置，避免把上一笔记的位置带入新文档。

## 发布前仍需做什么

上述 Markdown 用户流程已形成可用闭环，但不能把它扩称为所有格式均已验收：

1. 完整发布质量门禁通过后固定产品提交；确认新增交互未破坏普通文本/PDF 参考入口、只读降级和来源页码。
2. 原子迁移 v1.0.26，构建固定候选 MSI/NSIS，完成安装态及覆盖升级验收；不继承 v1.0.25 安装通过结果。
3. 所有发布门禁通过后再更新公开版本、Release、下载附件和校验文件。当前禁止提前发布。

UX25-0 旧版应用内更新观察仍独立待完成，不能以覆盖安装代替。快速记录、历史差异等不属于这一闭环，继续留在后续路线。
