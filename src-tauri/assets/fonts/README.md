# Bundled PDF form font

`NotoSansCJKsc-Regular.otf` is Noto Sans CJK SC Regular 2.004 from the official `notofonts/noto-cjk` repository:

- Source: `Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf`
- SHA-256: `2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`
- License: SIL Open Font License 1.1, retained as `OFL-1.1.txt`

LongEdit keeps the original font unchanged in the application. Generated PDF form copies use `subsetter` to embed only the glyphs required by the edited field values.
