### 适合怎样的工作？

| 你的任务 | 可以这样使用 |
| --- | --- |
| 学习、阅读与摘录 | 搜索课程资料，在侧边参考报告或 PDF 提取文字，把选文和出处整理到 Markdown 笔记 |
| 项目资料与会议记录 | 为项目建立资料库，用模板记录会议，保存工作现场，并用智能集合追踪相关文件 |
| 技术文档与配置整理 | 在同一资料库中阅读 Markdown，检查 JSON 结构，编辑 YAML/XML/TOML 和轻量代码源码 |
| 表格与报告审阅 | 打开 CSV、Table、XLSX、PDF 与 Office 工作区，按实际能力编辑或生成可靠副本 |
| 灵感、方案与知识组织 | 用 OPML、Canvas、Mermaid、Draw.io 表达思路，再通过知识图谱探索已有资料之间的联系 |

Long编辑不是完整的 Office 套件、IDE 或专业媒体编辑器；具体可编辑范围见下方[格式能力](#格式能力)。

## 快速开始

1. **安装并启动**：普通用户优先选择上面的 NSIS 安装程序。
2. **选择资料库**：添加一个本地目录，或选择已有资料库；顶部资料库名称可展开切换列表。
3. **打开你的第一份资料**：从文件树选择文件，或在“搜索文件与正文”中查找；结果默认在主编辑区打开。
4. **创建自己的记录**：点击“快速笔记”，选择资料库、保存位置与模板，再记录内容。
5. **按需要打开参考**：搜索结果旁选择“在侧边参考”，对照阅读不会替换当前草稿。
6. **确认保存与接续**：可编辑草稿使用“保存”或 `Ctrl+S` 写入；在工作台保存命名工作现场，方便之后继续。

刚开始不必配置所有选项。先选资料库、打开文件、写一份笔记，等需要时再使用集合、图谱和个性化设置。

## 日常工作流

### ① 找资料 → 打开 → 对照 → 写自己的内容

搜索和参考是两种不同意图，界面明确区分：

| 你点击的操作 | 内容出现的位置 | 是否替换当前内容 |
| --- | --- | --- |
| 搜索结果的打开操作 | 主编辑区，进入对应格式工作区 | 切换到目标文档；未保存内容受保护 |
| “在侧边参考” | 独立的只读参考区 | 不替换当前草稿 |
| 将参考选文及来源插入 | 当前 Markdown 的插入位置 | 插入可撤销，仍需手动保存 |

打开自己的 Markdown 笔记并选定插入位置后，可将参考选文及来源直接插入。参考区在窄窗口自动改为上下布局，避免把正文挤得过窄。

参考展示磁盘上的部分文字；PDF 参考为提取文字，完整版面可在主编辑区打开。支持手动刷新和失效来源重新关联；阅读位置、搜索条件和参考资料身份按资料库记住，重启后重新读取内容，不保存参考选文，不自动跟踪全库重命名。

资料库搜索与 `Ctrl+P` 命令面板使用相同的关键词规则：`项目 预算 -旧版` 要求同时含前两个词，并排除“旧版”；`"交付范围"` 匹配连续短语。命令面板可选择当前资料库或全部已配置资料库，不扫描整台电脑。结果按文件分组，可继续搜索、加载更多文件，并按相关性或修改时间排序，不再把旧的前 200 个命中当作全部。跨库逐库显示状态，离线、不可读或达到处理预算不会假装成完整空结果；源资料变化后，保留已加载结果并在底部原位置提供重新搜索。跨库打开前请先保存当前草稿，软件不会代存或丢弃修改。

### ② 想到就记，保存时就选好位置

快速笔记可直接选择**资料库、保存位置和模板**。日常记录可以留在收集箱，也可以直接放入项目目录，不需要强制进行额外的归档操作。保存失败会保留内容，重试不会因为同一次保存操作而重复创建笔记。

收集箱从“新建笔记”开始使用，首次新建会自动准备文件夹。空目录与暂时无法访问会明确区分；路径失效时可重试或更换位置，继续使用其他区域。

### ③ 把常用筛选变成智能集合

智能集合是动态查找资料的视图，不是另一份文件副本。按目录、标签、时间、对象类型和关键词组合条件，源资料变化后重新查询，即可得到符合条件的内容。

例如：为项目相关资料建立集合，或把某个目录里带指定标签的笔记集中查看。文件依然留在原来的目录，不需要为了加入集合而搬家。

默认先看“我的集合”，也可以从最近修改、全部笔记或标签示例开始；需要新建或调整时再展开筛选条件。文内标签则用于按主题找笔记，点击标签即可查看相关笔记。

集合结果按文件归组，可继续加载；名称、路径、修改时间和相关度针对整个查询排序，而不是只排当前一页。刷新失败保留已看的结果和滚动位置，未提交条件切换侧栏后仍可继续。统计尚未查全会明确提示，不将部分数量当总数。

需要整理标签时，可选最多 64 篇笔记，先预览添加、改名或移除的影响，再明确确认。它会修改已保存的 Markdown 正文（包含代码块中的同名标签），不移动文件、不改其他集合条件、不自动代存草稿。未保存或外部变化的文件受保护；写入前保留原文历史，部分失败逐项显示已完成、未执行或需核对，不自动全量重试。

### ④ 保存现场，下次从这里继续

在工作台给当前工作现场命名，保留资料库内打开的文档标签、当前选中文档和支持的视图状态。切换任务后，再选择对应现场继续阅读与整理。

换电脑或调整资料目录时，从“管理现场”导出，再在另一处导入并选择目标资料库。软件先列出可用与缺失文件，可重新定位、先保存记录或继续可用部分；缺失项不会静默删除，相同来源不会重复添加。导出只记录库内相对路径、顺序、固定标签与阅读位置，默认不携带搜索和参考，勾选后才包含；文件名和搜索词仍可能涉及隐私，请谨慎分享。

**工作现场不保存正文或未保存草稿，也不是文件备份。** 换机需另行复制原文件，或使用[资料内容备份](docs/Content_Backup_User_Guide.md)迁移所选资料；恢复现场时，当前未保存的标签和活动文稿受保护，不会自动代存。新迁移文件最多 128 份资料、256 KiB，超过正文缓存数量的阅读位置按需恢复。

### ⑤ 先看历史差异，再决定如何恢复

Markdown 和资料库内 TXT 的历史提供差异预览，区分当前来源与历史版本的增删内容。可以恢复为独立副本，也可以在保护当前草稿后替换编辑区；完整差异块还可点击“恢复此处”，只找回需要的一段，保留其他修改。恢复可撤销，仍需手动保存；简化或截断的差异不提供局部恢复。

恢复前会核对当前文件与历史来源是否变化。发现来源过期时先拒绝执行，而不是用旧结果覆盖新内容。本版不把这一能力泛化为所有格式的历史恢复。

也可以查找历史正文和备注，按日期回看、跳转差异，通过条目右键保留重要版本。Markdown/TXT 保存遇到外部修改时，直接比较后继续编辑、另存副本，或先保护草稿再读取磁盘版本；普通 Markdown 保存会保留修改前后快照。重要版本保留在本机历史缓存中，不是独立备份，迁移或清理缓存前应另行备份。

### ⑥ 给不同类型的资料建立关系

在文档工具栏“专注”旁点击 **添加关系**，选择另一份文件和关系类型，按需补充说明，保存后即可在图谱中看到联系。PDF、表格、图片和其他附件也能使用，不需要先写 Markdown 链接；图谱顶部及选中文件后也有同一入口。

关系页直接查看当前文件的手动关系，通过每条关系的菜单修改类型和说明或移除；“我提到的 / 提到我的”继续查看正文引用，图谱用于查看整个资料网络。手动关系关联当前资料库内的整份文件，单独保存于 `.longedit/file-relations.json`，原文保持不变；整体搬迁资料库时请保留此目录，应用内改名或移动会同步关系位置。

### ⑦ 整理文件，删错也能找回

在文件栏右键选择“移动到”“复制到”或“创建副本”；按住 Ctrl/Shift 多选后可一次处理多项。目录选择使用弹窗，输入新目录会自动创建，重名时保留两份。移动后，打开的文档、收藏、关系和显示样式继续跟随。

多选文件后右键选择“批量重命名…”，可添加前后缀、查找替换或添加序号。先预览原名称、新名称和冲突，再执行；保留 `.table.json` 等复合扩展名，失败时只重试未完成项目。改名、移动和回收恢复在系统执行时仍拒绝覆盖其他程序刚创建的同名内容。

文件右键“更多操作 → 管理附件…”或文档操作菜单，可查看当前 Markdown 草稿的引用、位置和失效状态，按文档修复引用；原附件与库外原件保留，仍需保存笔记。[附件管理用法](docs/Attachment_Management_User_Guide.md)。

文件栏空白处右键“最近操作…”可查移动、改名和复制记录，文件右键位于“更多操作”中；重启后继续查看位置、按项还原。“撤销上次移动”保留当前会话的批次撤销，重启后进入持久记录选择还原项。后续编辑或同名冲突会保留现状；复制只查看，清除记录不删除文件。

普通删除进入资料库回收站，可从文件栏空白处右键或“更多操作”打开回收站恢复。剪切、复制和粘贴使用应用内当前资料库的文件剪贴板。回收内容保存在资料库的 `.longedit/trash`，整理记录保存在 `.longedit/file-operations`；整体搬迁资料库时请一并保留 `.longedit`。

外部文件拖入资料库时，同名正文和图片保留两份，不覆盖已有资料。Markdown 的普通本地图片复制到独立 `.assets` 目录，原文和原图不变；多文件导入逐项反馈，只重试未完成项。若文件已经导入、只是目录刷新失败，刷新列表即可，不需要重新导入整批文件。外部笔记有未保存修改时须先保存，再存入资料库。

图片迁移限 UTF-8 Markdown、单份 20 MiB、512 处所选文档目录内的普通相对图像路径。缺失、越界或无法可靠识别的资源明确失败；不承诺搬迁任意附件、文档超链接，或后续单独移动文档时自动重写资源引用。完整边界见[安全导入说明](docs/RELEASE_NOTES_v1.1.5.md#支持边界)。

### ⑧ 让经常写的内容成为模板

在“新建 → 笔记模板 → 管理模板”新增或修改模板，也可从当前 Markdown 的“文档操作 → 保存为模板…”保存当前草稿。支持标题、日期、时间变量；默认模板按资料库选择，快速笔记可复用。模板保存在本机，管理备份不包含模板正文。

需要换电脑或分享模板时，在模板管理的“更多操作”导出当前模板或全部已保存模板；导入时勾选、预览正文，同名项可保留两份或跳过。模板文件保留变量，不携带本机目录和资料库默认设置；原有模板及未保存编辑保持不变。

需要填写作者、项目等字段时，选“填写模板后新建…”，核对资料库、目录和预览后创建；模板可写 `{{param:作者}}`，未知变量保留，字段内容不会再次展开成变量。原有一键创建和快速笔记流程不增加必填步骤。

文章写好后，从 Markdown 的“导出”先预览当前草稿：**独立 HTML** 携带授权本地位图，换目录也能阅读；**Markdown 仅正文** 保留原图片引用依赖；**打印 / PDF** 在原生打印页选择浏览器“另存为 PDF”，保存后核对文件。不同虚拟打印机的文字层可能不同，页眉页脚可能包含来源路径，可在更多设置关闭。图片可通过“更多格式 → 本地图片…”、粘贴或拖入编辑区，按相对路径复制到文档旁的资源目录；不搬走共享图片，不自动下载在线图片，不代存原稿，也不覆盖已有交付文件。[操作说明与资源边界](docs/Writing_Delivery_User_Guide.md)。

标签右键可固定、关闭其他/右侧未固定标签或恢复关闭；可拖动排序，使用 Ctrl+Shift+T 恢复最近关闭的文档入口。Markdown 和文本保留阅读位置；已明确放弃的未保存内容不会随关闭入口恢复。文内标签可右键固定常用项，智能集合支持顺序调整和多个标签同时筛选。

### ⑨ 把 PDF 批注整理成可追溯笔记

在 PDF 侧栏“批注”按页码、颜色、类型和摘录/评论筛选，勾选需要的条目后“整理为笔记”。预览保留原页、摘录、可选评论及来源；可按页码或颜色组织。每组列表50条，每次最多200条，隐藏选择会显示数量，不会静默丢掉勾选。

插入时看清目标文件名和所属文件夹，只追加到最新草稿，不替你保存；也可选择库内新名称创建笔记，已有文件不会被覆盖。原 PDF 和批注不因整理笔记而被改写。

在 Long编辑 中点击笔记来源，先核对内容摘要再返回原页/批注；同名替换不会被当成原来源。文件移动后可明确验证新相对路径、只重新关联草稿，仍需手动保存。旧链接和已删批注会在侧栏顶部说明情况。[完整用法](docs/PDF_Reading_Notes_User_Guide.md)。

### ⑩ 从复制一片表格，到放心保存

在 CSV、TSV 或开放 Table 中，单击照常编辑；**Shift＋点击**选择可见多格，直接粘贴多行多列，或复制、清空选区。筛选后的隐藏行保持不变；贴错了，用 **Ctrl+Z** 一次撤销整批，再用 Ctrl+Y 重做，排序后仍定位到原来的行。

多行单元格显示换行标记，点旁边的 **↵** 打开文本区，确认后只是写入草稿，仍由你点击保存。保存、重开和导出时保留中文、空尾格、前导零与长编号；XLSX 导出的公式外观文本保持文本。CSV 本身没有列类型，其他软件可能自行解释，请核对导入方式。

单次剪贴板最多 2 MiB／20,000 格，历史最多 100 次／8 MiB；新增列与视图配置不属于数据撤销。范围或容量超限会整次拒绝，不留下贴了一半的结果。[完整操作与边界](docs/Lightweight_Table_User_Guide.md)。

### ⑪ 让已有 XLSX 接着填、筛、保存

选中工作簿区域后直接 Ctrl+C / Ctrl+V，带引号、换行和空尾格的文本保持字段边界，前导零与长编号保留文本类型。应用内复制区分普通文本与真实公式：复制公式按目标平移相对引用，剪切移动保持原引用；纯文本菜单另明确标为“粘贴文本（自动识别）”。输入框中的删除、复制和粘贴仍属于输入框，点击网格后再用方向键移动。

在“数据、Table 与规则”筛选和排序后，点击“复制筛选结果”，一次复制表头与匹配行，不混入其他行、不重排原网格。Ctrl+C仍复制选区。数字种子填充可可靠接续`0.1、0.2、0.3`，文本编号不当数字序列；粘贴和填充可整批撤销，最后仍需显式保存。

工作面前256列、每批10,000格及文本/类型记录各10MiB等边界保留，复杂内容仍按公开兼容矩阵处理，不宣称完整Excel等价。[实际入口、保存与兼容边界](docs/Workbook_Editing_User_Guide.md)。

### 阅读与写作：让内容处在中心

- Markdown 支持所见即所得、IR 与源码模式，常用格式工具、正文宽度、导出和历史靠近编辑区。
- 多文档标签与快速笔记、命令入口共享紧凑顶栏；点击切换不改变标签顺序。
- 当前文档名称可以点击改名，不必只从文件树寻找重命名操作。
- 专注模式减少周围导航干扰；需要参考时主动展开，不默认占用正文空间。
- 历史快照与正文保存分开：快照用于保留历史，不能代替对源文件的明确保存。

### 资料组织：从目录，到集合，再到关系

- 多个本地目录可以分别作为资料库，切换时保护未保存内容。
- 文件、目录、最近访问、大纲、标签、集合、关系与历史保留各自入口。
- 文件树通过缩进与层级引导表达父子关系；文件可使用独立图标、文字颜色和背景标记。
- 搜索、保存视图与智能集合用于找到内容；链接、反向链接与图谱用于理解联系。
- 点击“添加关系”即可关联库内任意类型文件；不改变该格式原有的阅读、编辑或只读范围。
- 路径暂不可用时可以重试；重新读取失败会保留当前未保存内容，不把空内容误当作读取成功。

### 结构与源码：为数据提供专用工具

- JSON/JSONC 支持源码与结构查看、字段路径定位、结构风险提示，以及有界的本地 JSON Schema 辅助。
- 大 JSON 渐进只读，使用分段导航和流式搜索，不强行构建全文树形或写回。
- YAML、XML、TOML 提供源码、结构导航与轻量诊断，不冒充完整 Schema 服务。
- 代码与配置文件提供语法高亮和轻量编辑工具，不执行程序、不提供编译或调试环境。
- `.env` 的敏感变量值默认遮罩，并排除全文索引与知识图谱；查看和编辑需逐文件明确确认。

### 表格、文档与演示：只开放已验证的编辑范围

- CSV/TSV/Table 支持网格、冻结列和看板；转换创建新副本并先披露损失，不直接覆盖来源。
- XLSX 提供工作表、公式、样式、图表、筛选及页面工具，复杂结构按能力限制写回。
- DOCX/PPTX 提供受控的基础对象、文字与样式编辑，并通过预览、冲突检查和输出复读保护保存。
- PDF 页面提取、合并、插入、重排和旋转生成副本；批注与 OCR 结果以独立附加文件保存。
- PDF 表单、文字水印、属性及永久脱敏仅开放已验证子集；永久脱敏使用图片型输出，会失去文字搜索与交互能力。

### 图形、导图与媒体：不同表达，统一入口

- 知识图谱侧重探索已有资料之间的关系；思维导图、Canvas、Mermaid 和 Draw.io 用于主动构建表达。
- OPML 可以在披露转换边界后生成独立 Canvas 投影，不与来源自动同步。
- SVG 提供源码与净化预览，限制危险协议和外部资源。
- 图片提供缩放、平移，以及支持格式的基础裁剪和调整；编辑结果另存为副本。
- 视频采用流式播放，支持逐帧、截图、位置记忆和同名字幕，不承担专业剪辑或转码。

### 可选 AI：按自己的服务配置

设置中可配置兼容 OpenAI API 格式的服务，包括本地 Ollama 回环地址；API Key 使用操作系统凭据库存储。AI 并非使用资料库的必要条件。

使用远程服务时，请把相关请求内容视为会发送到你配置的服务提供方，先确认隐私与费用；“本地优先”不代表远程 AI 请求也在本机完成。

| ODS / ODP / 旧 Office / WPS | ODS 支持简单值和已有命名样式的可靠副本，ODP 支持简单正文页的可靠副本；旧 Office 转换，WPS 原生格式交给外部程序 | ODS 公式与自定义样式只读；ODP 复杂对象整页阻断，备注、版式、动画及外部打开只读；`.wps/.et/.dps` 不在软件内编辑 |

格式事实源位于 [`shared/file-formats.json`](shared/file-formats.json)，发布边界位于 [`shared/release-capability-matrix.json`](shared/release-capability-matrix.json)。

“43 类格式”是注册格式族数量，不是 43 种完全等价编辑器。“30 类已验证”也不意味着所有功能都可无损写回。软件按具体格式显示完整编辑、有限编辑、只读、可靠副本或外部依赖；格式能力页可查看实际支持范围。

## 设计原则

- **本地优先**：文档、索引和知识关系默认留在本机，不要求云端账号。
- **显式保存**：编辑不会在后台悄悄覆盖源文件，危险覆盖和格式降级需要确认。
- **能力诚实**：完整编辑、有限编辑、只读预览、可靠副本和外部依赖不会混为一谈。
- **恢复优先**：外部修改、路由错误和索引损坏提供比较、重载、隔离或重建路径。
- **用户控制**：默认应用、自动更新、外部程序接管和删除操作都由用户明确触发。
- **隐私可审计**：诊断和管理备份移除文档正文、完整路径、API Key、凭据与缓存正文。

### 保存、恢复与备份不是同一件事

| 机制 | 保存什么 | 不能替代什么 |
| --- | --- | --- |
| 正文保存 | 明确写入支持格式的文件内容 | 不能替代跨设备备份 |
| 历史快照 | 支持格式的历史内容，供比较与恢复 | 不能代替点击“保存” |
| 工作现场 | 资料库内文档身份、标签与支持的视图状态 | 不保存未保存的正文草稿 |
| 阅读与参考记忆 | 阅读位置、搜索条件和参考来源身份 | 不保存参考摘录正文，不保证自动跟踪所有改名 |
| 管理备份 | 脱敏设置与能力合同，恢复时重新映射本机资料库 | 不备份实际文档、API Key 或操作系统凭据 |
| 资料内容备份 | 所选已保存文档/数据、附件、PDF 批注及可选 Markdown/TXT 历史 | 不含未保存草稿，不是整份应用环境镜像，也不是加密包 |

在“设置 → 隐私与诊断 → 资料内容备份”选择整库或子目录，先核对数量、大小和未包含清单，再导出新 ZIP。恢复时完整校验后写入全新目录，保留相对资源、配套批注和选中历史；完成后由你自行添加资料库，不自动切换或覆盖当前草稿。

内容包最多 512 MiB（未压缩）、单文件 128 MiB、10000 个文件条目，大库可按子目录分包；历史默认不选。内容未脱敏、未加密，可能包含私人资料，请妥善保管。应用配置/缓存重叠范围会拒绝备份，网络共享和断线恢复不在本版验收范围内。详见[操作说明与边界](docs/Content_Backup_User_Guide.md)。

换电脑时可使用内容备份迁移所选资料，或另行复制/同步实际资料目录；只带走管理备份或工作现场，不代表文档也已经迁移。

## 主题与交互

个性化不止是切换明暗。配色、界面质感、正文排版和文件标记可以分开调整，既能一键选择，也能继续 DIY。

| 调整层次 | 可选择的方向 |
| --- | --- |
| 核心与场景预设 | 专业浅色、专业深色、高对比；长文阅读、护眼研读、编码专注、创意图谱 |
| 配色与界面质感 | 19 个注册主题与外观组合；柔和、霓虹、玻璃、轻盈、极简、锐利等质感 |
| 文档显示 | 跟随风格、简洁、纸张、排版，按阅读习惯选择 |
| 字体与排版 | 正文字体与代码高亮主题；正文 12–28 px、行距 1.3–2.4、字距、段后间距、左对齐或两端对齐 |
| 文件列表 | 紧凑、舒适或宽松密度，平面或卡片行，彩色或单色图标 |
| 单个文件标记 | 独立图标、背景标记和文字颜色，保留主题下的选中辨识 |
| 动效与辨识 | 沉稳、利落、表现力或减少动效；高对比预设强化文字、焦点和边界 |

正文字体可选择无衬线、衬线、等宽、微软雅黑、宋体、楷体、仿宋、思源/Noto、Consolas，或填写自定义已安装字体名称。字体需要本机实际安装，缺失时自动回退，软件不会替你下载所有字体。

显示设置提供实时预览，**只改变阅读显示，不改写文档正文**。PDF 和 Office 继续保留原文档排版。主题库会合并视觉配置重复的组合，注册组合数不等于界面中完全不同的主题卡片数量。

紧凑工具栏和标签支持横向滚轮导航；左侧导航根据可用宽度在“图标 + 文字”和纯图标之间自适应。动效用于提示状态，不要求用户依靠动画才能理解操作。

## 常见问题

<details>
<summary><strong>需要注册账号或把资料上传到云端吗？</strong></summary>

本地资料库不要求云端账号，文档、索引和知识关系默认在本机处理。检查更新和下载会访问 GitHub；配置并使用远程 AI 时，相关请求会访问你选择的服务。这些联网行为与本地文件工作区是不同边界。

</details>

<details>
<summary><strong>智能集合、资料库和工作现场有什么区别？</strong></summary>

资料库是实际文件所在的本地目录；智能集合是对这些资料的动态筛选；工作现场是打开哪些文档、当前看哪一份以及支持的视图状态。集合不会复制文件，现场也不保存未保存的正文。

</details>

<details>
<summary><strong>点击搜索结果，为什么没有自动打开在侧边？</strong></summary>

打开资料通常表示要阅读或编辑这份文件，所以默认进入主编辑区。需要边看边写时，明确选择“在侧边参考”；参考内容不会替换当前草稿。

</details>

<details>
<summary><strong>为什么有些格式只能只读或另存副本？</strong></summary>

复杂格式的可靠写回需要逐项验证。Long编辑优先保留源文件与已知结构，不把能预览误写成能完整编辑。PDF、图片和部分 Office 操作使用副本；旧 Office/WPS 原生格式可能依赖兼容外部程序，详见格式能力页。

</details>

<details>
<summary><strong>文件被其他软件修改了，或者目录暂时无法访问，怎么办？</strong></summary>

先保留当前草稿，再使用界面提供的重载、比较或重试入口。不要把重新读取当作自动保存；读取失败时，软件不会以空内容替换未保存草稿。遇到冲突可先保留副本，再决定采用哪份内容。

</details>

<details>
<summary><strong>怎样反馈问题，才能更容易复现？</strong></summary>

通过 [GitHub Issues](https://github.com/Longyuyeee/Long_MarkDownReader/issues) 描述你想完成的任务、实际点击步骤、预期结果与实际结果，并提供软件版本、Windows 版本及文件类型。截图和最小示例请先移除个人资料、路径、密钥与其他敏感内容。

</details>

### v1.2.9 TOML 配置值编辑

TOML 配置值右键“修改值…”编辑字符串、布尔或数字，弹窗预选当前原文，输入错误原地纠正。修复原文位置丢失，同名分区字段、带引号点号键与表数组准确定位。只替换当前值，保留注释、顺序、换行、长整数和转义；沿现有差异预览及独立撤销接续草稿，来源切换、保存失败与外部冲突继续保护内容。数组、内联表和日期时间保留源码入口，不增加常驻表单，保留全部既有功能、风格及动效。

### v1.2.8 字段与数组项复用

字段右键“复制为新字段…”、数组项右键“复制此项”，副本紧邻原内容。建议名称自动避开已有字段并选中，重名保留输入原地纠正。完整节点、长数字、转义和内部注释保持，一次复制可独立撤销，与移动和改值接续；源码和树形定位跟随副本。邻接注释归属不清就地说明，保存失败、外部冲突和来源变化继续保护草稿。保留全部原有功能、风格和正常动效，不增加常驻表单。

### v1.2.7 数组项位置调整

JSON/JSONC 数组项右键上移或下移，边界禁用，保留长数字、转义、内部注释和原有排版。沿现有差异预览应用到当前草稿，可一次撤销重做；源码焦点及树形选择跟随原记录。邻接注释归属不清时就地说明并保持内容，保存失败、外部冲突或来源变化继续保护草稿。节点菜单按小窗口可用空间展开并滚动，保留全部原有操作与风格。

### v1.2.6 表格列位置调整

右键列标题可向左或向右移动，标题、所有行值、类型、录入规则和各视图列宽保持对应，排序与看板、图表和仪表盘仍引用原字段。列移动、新增列均可一次撤销重做，与填充、行操作和其他未保存编辑交错使用；保存失败及冲突保留草稿。保留全部现有入口、风格和正常动效，不增加常驻操作区。

### v1.2.5 表格行插入与复制

右键行号可在原记录上方、下方插入空行，或复制当前草稿后只修改不同字段，每次操作都可一次撤销。排序时位置插入明确禁用，筛选隐藏新增空行时自动显示并定位。删除确认固定最初记录，等待期间的草稿和来源变化不会导致误删另一行。页面不增加常驻表单，原有入口、风格和正常动效保留。

### v1.2.4 表格选区填充

选中单元格后右键“填充选区…”，默认只填空白，也可替换选区。全部目标先校验，失败保留输入，成功一次撤销重做；排序、筛选后仍操作原选中行列。同一文件的行引用直接定位到当前草稿，保留未保存修改与历史。操作集中在右键与弹窗，不增加常驻表单。

### v1.2.3 批注批量整理

勾选批注后，在原有右键或“···”菜单统一改色或删除。菜单显示所选总数及筛选隐藏数，删除确认明确范围；一次撤销恢复整组批注、顺序和勾选，保留筛选。普通改色不增加确认，页面不增加常驻工具条，PDF 原文和阅读笔记保持原样。

### v1.2.2 批注撤销与保存保护

批注误操作可以从右键、每条批注菜单或搜索旁的“···”撤销重做。恢复后的批注沿原自动保存链落盘；保存失败可原地重试，其他窗口或外部程序修改过来源时保留当前评论供核对。切换文件清空旧历史，评论输入框保留文字撤销，阅读笔记正文不会被连带改写。

### v1.2.1 移动阅读接续

在右键、拖放与批量改名中继续原来的阅读和整理，命名现场、搜索定位及参考来源跟随成功项。当前阅读位置即时捕获，旧组件卸载不会重新写回过期路径；未保存正文不代存，复制保留源阅读记录。

### v1.2.0 界面与基础体验

减少重复标题与说明，按需打开属性和图谱工具，把空间留给正文、表格及画布。小窗口与六种风格统一适配，保留文件管理、保存保护、历史、搜索、关系和各格式既有能力。[完整窗口复查](docs/UI_Full_Window_Review_2026-10-22.md)。

### v1.1.37 PDF 批注接续

PDF 批注筛选、勾选、当前批注、列表分组和滚动位置自动接续；来源变化不套用旧选择，明确引用优先。评论保存失败时保留输入与页面。[使用方法](docs/Pdf_Annotation_Resume_User_Guide.md)。

### v1.1.36 上下文操作

### v1.1.35 附件引用和草稿接续

附件“查看引用”自动纳入当前窗口的完整未保存 Markdown，同一路径以草稿为准；区分来源，变化后可刷新，打开复用草稿。[使用方法](docs/Attachment_Management_User_Guide.md)。

### v1.1.34 章节链接随项目接续

大纲右键复制库内章节链接，随资料库、移动改名和跨库复制接续，保留原文和草稿；查找替换后的单次撤销同时修复。[使用方法](docs/Portable_Chapter_Links_User_Guide.md)。

### v1.1.33 阅读成果随资料接续

### v1.1.32 恢复后接续工作现场

备份时可选记录工作现场，恢复后按需接续文件与阅读位置；缺失目录可一次映射，当前有草稿则先记住现场。[使用方法](docs/Content_Restore_Continuity_User_Guide.md)。

### v1.1.31 XLSX 连续录入与检查

XLSX 单元格右键按需检查所选区域或筛选记录，定位并预览修正草稿。规则贯通输入、粘贴、清空和已有填充，保护其他草稿，可一次撤销。[详细说明](docs/RELEASE_NOTES_v1.1.31.md)。

### v1.1.30 Table 录入规则与纠错

列头右键设置录入规则，“数据操作”按需核对，先预览再修正草稿，保留隐藏行与未保存内容，可一次撤销。CSV 规则可随 Table 副本保留；XLSX 非法列表粘贴整体拒绝。[详细说明](docs/RELEASE_NOTES_v1.1.30.md)。

### v1.1.29 PDF 批注与阅读笔记接续

批注右键编辑和返回位置保持；阅读笔记从文档菜单按需预览更新，保留用户补写和未保存内容，可一次撤销与重做。[详细说明](docs/RELEASE_NOTES_v1.1.29.md)。

### v1.1.28 引用来源与关系核对

参考资料与关系菜单按需核对来源；失效文内来源链接可在草稿中修复、撤销与重做，保留未保存内容和代码中的示例。[详细说明](docs/RELEASE_NOTES_v1.1.28.md)。

### v1.1.27 标签整理与集合复用

文内标签从右键进入范围选择与影响预览；集合条件可导入、导出到其他资料库，修正失效目录和中心，保留同名集合与所有草稿。[详细说明](docs/RELEASE_NOTES_v1.1.27.md)。

### v1.1.26 文件菜单与结构化历史

资料库右键多级菜单正常展开，保留全部文件动作。结构化源码可从文档菜单比较保存历史，恢复局部、整篇或同类型副本；保护原稿，只改当前草稿，一次撤销，仍需显式保存。[详细说明](docs/RELEASE_NOTES_v1.1.26.md)。

### v1.1.25 查找替换

文档操作菜单或 Ctrl+H 打开查找替换，明确整篇文档或打开前的选区，逐项核对或预览后一次替换。支持大小写、整词、多行文字，改动只在当前草稿，可一次撤销，仍需保存。覆盖资料库与外部 Markdown 三模式、TXT，保留原 Ctrl+F。[使用方法](docs/Document_Find_Replace_User_Guide.md)。

### v1.1.24 长文组织

左侧大纲右键可复制章节链接、预览后移动整节、提高或降低标题层级。子标题、代码、表格与图片引用随整节移动；只改草稿、可一次撤销、仍需保存。引用和列表内标题保留定位与复制，结构修改只对可靠源码映射开放。[使用方法](docs/Markdown_Chapters_User_Guide.md)。

### v1.1.23 附件管理

### v1.1.22 文件整理记录
