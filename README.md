## 知识库管理

把课程资料、项目文件或个人笔记所在的文件夹添加为资料库。文档保留原有目录和格式，资料库可在顶部随时切换。

- **整理文件**　在文件树用右键移动、批量重命名或回收文件，也可以把外部文件拖进资料库。用快速笔记把新想法存进收集箱或项目目录。
- **找回资料**　搜索文件名和正文，用标签按主题浏览，或把常用筛选保存为智能集合。给当前打开的一组文档保存「工作现场」，下次从工作台继续。
- **关联知识**　在笔记中引用文件与章节，也能给 PDF、表格、图片直接添加关系。用知识图谱查看关联，并从节点打开原资料。

## 多格式支持

桌面版注册了 **43 类格式、91 个扩展名**。从同一资料库打开文件，会进入适合该格式的编辑、阅读或预览工作区。

| 常用格式 | 可以做什么 |
| --- | --- |
| Markdown · TXT · LOG | Markdown 和 TXT 支持编辑与历史对照，LOG 提供日志查看。Markdown 可切换所见即所得、即时渲染与源码。 |
| JSON · YAML · XML · TOML | 查看语法和结构，定位字段并编辑。大 JSON 渐进只读，支持分段导航。 |
| CSV · TSV · Table | 编辑网格，筛选、冻结列、批量粘贴。Table 可按需要切换视图。 |
| XLSX | 在工作簿中切换工作表，编辑单元格与公式，使用筛选和样式。 |
| PDF | 查目录、搜索、批注，把摘录整理成带出处的 Markdown 笔记。 |
| DOCX · PPTX · ODS · ODP | 阅读及部分基础编辑。复杂内容按应用提示只读或另存副本。 |
| Canvas · OPML · Mermaid · Draw.io · SVG | 使用画布、思维导图或图形编辑器整理想法。 |
| 图片 · 视频 | 浏览图片、基础调整后另存，或播放视频并加载同名 VTT/SRT 字幕。 |

完整编辑、只读、另存副本与外部打开以文件工作区的提示为准。旧 Office/WPS 原生文件可能需要外部程序。[完整格式与保存能力](shared/release-capability-matrix.json)

## 界面与外观

左侧找资料，顶部切换文档，中间专心处理内容。参考区按需打开，文件整理和低频动作放在右键或菜单中。长文阅读时可按 <kbd>F11</kbd> 进入专注模式。

在 **设置 → 外观** 可分别调整浅色／深色配色、控件质感与动效节奏。正文的字体、字号、行距和阅读宽度可单独调整，文件列表也支持密度、图标和颜色标记。

## 操作指南

### 快速开始

1. **添加资料库**　在 Windows 启动 Long编辑，打开 **设置 → 资料库**，填入库名称，选择已有文件夹或输入新路径，点击 **添加库**，再点击 **切换**。
2. **打开资料**　在左侧文件树点击文档，或用 **搜索文件与正文** 找到它。顶部标签可切换已打开的文件。
3. **写下第一篇笔记**　点击顶部 **快速笔记**，选择资料库与保存位置，写完点击 **保存**。编辑已打开的文档时也可按 <kbd>Ctrl</kbd> + <kbd>S</kbd> 将草稿写入文件。

### 按任务查找

| 我想做什么 | 从哪里开始 |
| --- | --- |
| 边查资料边写 | 在搜索结果选择 **在侧边参考**。把参考里的选文和出处插入当前 Markdown。 |
| 给两份资料建立关系 | 在文档工具栏点 **关系**（宽窗口显示 **添加关系**），选另一份文件和关系类型，再去 **图谱** 查看。 |
| 保存常用搜索 | 在资料库侧栏打开 **智能集合**，按目录、标签或格式设置条件，保存为集合。 |
| 整理项目文件 | 在文件栏右键选择 **移动到**、**批量重命名** 或 **管理附件**。误删后可从文件栏菜单打开 **回收站**。 |
| 恢复上次的工作 | 打开 **工作台**，将当前打开的文档保存为 **工作现场**，下次按名称打开。 |
| 把 PDF 批注变成笔记 | 在 PDF 侧栏打开 **批注**，勾选条目后点 **整理为笔记**。[PDF 阅读笔记指南](docs/PDF_Reading_Notes_User_Guide.md) |
| 找回旧内容或迁移资料库 | 从文档菜单查看 **历史与差异**。迁移时在 **设置 → 隐私与诊断** 导出 **资料内容备份**。[备份与恢复指南](docs/Content_Backup_User_Guide.md) |

工作现场保存文档标签和视图状态。正文草稿通过保存写入文件，迁移资料使用内容备份。

## 开发与反馈

项目使用 Vue 3、TypeScript、Tauri 2 与 Rust。Windows 开发需要 Node.js 22、Rust stable、WebView2 和 Visual Studio C++ 构建工具。

```powershell
git clone https://github.com/Longyuyeee/Long_MarkDownReader.git
cd Long_MarkDownReader
npm ci
npm run tauri dev
```
